# 交互设计｜角色成长与资产管理

适用范围：角色状态、境界进度、功法知识与研习、主修改修、法宝炼化、随身资产、宗门地产、突破、死亡和转世的信息职责。本文不固定页面节点、视觉样式或动效。

## 1. 信息分层

| 信息组 | 核心内容 | 关键边界 |
| --- | --- | --- |
| 当前世状态 | 境界、标准 CP、有效修为、属性、生机、元气、神念、寿元 | 转世时多数重建 |
| 知识与研习 | 已学道功 / 法门、独立经验、掌握度、研习位、触类旁通、阈值内容 | 知识与进度跨世保留 |
| 构筑与装备 | 当前主修、战斗法门招式、攻击 / 防御 / 飞遁法宝 | 读取合法调整时点 |
| 随身经济 | 灵石、丹药、材料、功法道具和其它可转移物品 | 死亡可丢失；普通交易已移除 |
| 宗门资产 | 贡献点、节点主导权、建筑、建设 / 改建状态、待结算地产收入 | 跨世保留，归玩家所代表宗门 |

真灵与执念不属于本方案面板。灵石与宗门贡献必须分栏，不能暗示可兑换。

## 2. 境界与修为反馈

玩家必须同时看到：

- 当前大境界、小境界及当前小境界自身 `0—100%`；
- 内置标准 CP 记录与当前有效修为；
- 当前主修、掌握阶段和本次修为转化率来源；
- 所在地基础灵气、当前回合固定加法及本单位实际灵气；
- 下一大境界瓶颈、所需破境丹和本回合能否突破；
- 重伤或其它明确状态造成的零修炼原因。

标准 CP 与有效修为必须明确分开。当前有效修为精确公式尚未裁决时，交互稿只能标记来源和待配字段，不得以示例固化旧折算公式。回合末结果应按“先自动修炼、后自动研习”展示，并说明跨越了哪些小境界阈值。

## 3. 突破与渡劫预览

突破确认不得再展示破境成功概率。界面应说明：

- 角色已到瓶颈、仍存活且不重伤；
- 当前节点允许停留；突破本身无功能费，只有普通停留费；
- 选中的破境丹、消耗时点及失败后必须重新持丹；
- 炼气突破筑基使用固定 `Q2` 筑基丹并确定晋升；
- 后四次进入哪一场固定难度渡劫、敌人摘要与失败后果；
- 本枚丹药 `Q1—Q5` 对应的护劫护盾及其按当前最大生命计算的预览值；
- 渡劫允许逃遁，逃遁会结束本次突破并保留实际伤势，但不返还行动、丹药和战斗消耗；
- 成功后立即进入新境界，当轮末会取得新境界第一笔 CP。

护劫护盾与其它护盾的最终叠加顺序尚未裁决时，应显式标记，不得用界面顺序替代规则。

## 4. 小洞天结算

小洞天不再显示剩余停留回合、继续停留或主动退出选项。玩家取得奖励后，应预览并在本回合末一次结算十个内部时间单位：

- 修为最多到当前未完成瓶颈；
- 自动研习位全程锁定，功法满掌握后离位但不补位；
- 恢复、丹药持续、法宝炼化和寿元逐单位推进；
- 转世角色可以连续越过历史已完成突破，最多到第一个历史未完成瓶颈；
- 结算结束后本次入口关闭。

结果可以汇总展示，但必须允许展开查看中途境界、掌握阶段或来源档位变化，不能把十单位伪装成一个无法解释的倍率。

## 5. 功法、研习位与掌握

每部知识条目至少展示：

- 整数掌握度、内部研习经验与该功法经验上限；
- 当前五阶段与标准倍率；
- `25 / 50 / 75` 已解锁内容和下一门槛；
- 主、副研习标签及当前触类旁通来源；
- 是否在研习位、共享顺序、预计基础 `B` 分配和后置经验；
- 达到 `100` 后自动离位，及下一回合空位提醒。

| 阶段 | 掌握度 | 标准倍率 |
| --- | ---: | ---: |
| 初识 | `0—24` | `0.70` |
| 熟悉 | `25—49` | `0.85` |
| 熟练 | `50—74` | `0.95` |
| 精通 | `75—99` | `1.00` |
| 圆满 | `100` | `1.10` |

研习位入口应区分一道功位与三法门位，支持开始阶段学习道具、宗门兑换、放入、移除和排序。提交移动计划后展示锁定状态；本轮中途新学功法和洞天中空出的位不能即时补入。

触类旁通统一显示为“`XX` 类功法触类旁通 `+Y%`”，允许展开实际生效标签与来源。多标签只取最高汇总值，界面不得误加总。

## 6. 主修改修确认

设置或切换主修只在回合开始即时阶段开放，每回合最多一次，死亡或重伤时禁止。目标只需已学习且阶级不低于当前主修；不要求最低掌握度，也不限制大境界内阶段。

确认前至少预览：

- 新旧道功阶级、掌握阶段与已解锁内容；
- 标准 CP 保持不变；
- 按新主修重新确定后的当前有效修为和可能变化的小境界状态；
- 大境界与历史最高境界保持不变；
- 主修限定属性、被动和招式的启停；
- 旧道功招式退出、新道功招式追加到自动战斗列表末尾；
- 两部道功研习经验与掌握度都不转移。

不得显示“折算后的标准 CP”“换功损失系数”或境界阶段窗口。有效修为公式未关闭前，预览应明确为待配计算结果，不能由界面自行补造。

## 7. 法宝与炼化

三个固定法宝位必须按攻击、防御、飞遁区分。法宝详情同时展示当前归属、整数炼化度、是否跨过生效门槛、当前实际效果和下一回合末增量：

```text
r <= 50：加成和招式不生效
r > 50：实际效果 = 基础效果 × r / 100
```

死亡掉落、普通转移、炼器取得和来源未明确分别以 `0 / 50 / 100 / 30` 初始化。任何明确转移确认都要提示取得方初始化结果；方案中不存在绑定状态。

## 8. 随身经济与宗门资产

资产信息需要区分：

- 物品阶级与 `Q1—Q5` 品级，及无品质灰框；
- 当前回合常规资源开放上限；
- 某件新产物是否允许数量 / 品级成熟及实际成熟来源；
- 坊市逐商品购买上限、订单完成回合和自动领取状态；
- 节点的停留费、功能费、商品 / 配方实际消耗与本轮待结算地产收入；
- 宗门贡献白名单、固定贡献值、兑换目录和不可与灵石互换的提示；
- 建筑等级、稳定经营收益、建设 / 改建完成回合和当前主导宗门。

被动经营收益不读取物品成熟，主动取得的合格物品才读取；界面需在收益明细中标明来源，避免玩家误解为遗漏加成。

## 9. 死亡与转世预览

死亡结果必须分清：

- 保留的知识、掌握、历史最高境界、宗门身份、贡献点和地产；
- 清空的当前修为、当前世属性、灵石与其它随身物品；
- 每件或每单位资产独立 `10%` 成为战利品，其余系统回收；
- 死亡后才到账的地产收入不参与本次掉落，转世开始时先交付；
- 下一回合在原始出生座位转世，不额外空过回合；
- 灵石只补足到基础经营节点基准标价 `0.5` 倍的下限，不重新赠送破境丹、原料、法宝或特色资源；
- 已完成突破自动跨越，历史未完成瓶颈仍需重新持丹挑战。

落后者专属追赶和玩家退出后的地产处理尚未裁决，交互稿必须显示为缺口。

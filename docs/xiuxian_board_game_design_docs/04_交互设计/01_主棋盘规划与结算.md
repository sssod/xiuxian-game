# 交互设计｜主棋盘规划与结算

适用范围：大厅开局、主棋盘回合状态、阶段计时、世界更新、隐藏规划、同步移动、行动输入、连接 / 托管 / 退出、主动结束与统一结算反馈。本文只定义稳定信息职责，不固定节点布局、样式或动效。

## 1. 交互目标

玩家在任一时刻都应能回答：当前处于哪个阶段、自己还能做什么、已经锁定什么、系统在等待谁、暂停原因与下一步。主棋盘必须表现同时规划和同步结算，不能伪装成玩家依次行动。

## 2. 大厅与开局

大厅必须展示房主设置的目标席位 `2—4`、当前席位、每名玩家的宗门占用、准备与连接状态。玩家自由选择未被占用宗门；准备后宗门锁定，取消准备不自动放弃占用。发生近同时宗门冲突时，落后者保持未选择并收到稳定顺序冲突提示。

席位满员、宗门唯一且全员准备后显示 `10` 秒自动开局倒计时。任一条件失效立即取消并说明原因；重新满足后从完整倒计时开始。大厅本身不显示强制关闭倒计时，房主也不显示强制开局入口。房主离开时应提示身份已移交给最早加入的连接玩家。

## 3. 回合阶段表达

| 阶段 | 标准基础时限 | 玩家输入 | 必须展示 |
| --- | ---: | --- | --- |
| 回合开始更新 | 不计输入时限 | 通常无输入 | 资源阶级、建筑等级、建成 / 改建、物品成熟、订单、转世与灵气变化 |
| 待退隐处理 | 不计输入时限 | 无 | 本回合实际退隐角色、个人结果回收和地产保留摘要 |
| 即时阶段 | `60` 秒 | 学习功法、研习位 / 构筑、服丹、改修、贡献、领取与整理 | 当前合法行动、限次项、待领取、空位提醒、完成 / 撤回状态 |
| 隐藏规划 | `90` 秒 | 目的地、路线、移动组合、主要行动类型 | 自己的完整计划、费用预估、合法性、锁定项和提交状态 |
| 同步移动 | 不计输入时限 | 只响应相关中断 | 共享时间、实际位置、关隘收费、停止点与相关相遇 |
| 行动细节输入 | `45` 秒 | 为已承诺行动补对象、数量或投入 | 原行动类型、当前合法参数、费用、失败条件与超时默认 |
| 事件 / 竞争短响应 | `30` 秒 | 只由相关玩家输入 | 参与者、隐藏状态、安全默认与剩余时间 |
| 统一行动结算 | 不计输入时限 | 只处理相关竞争输入 | 队列、暂停原因、参与者和恢复位置 |
| 回合末 | 不计输入时限 | 通常无输入 | 内部时间、修炼、研习、炼化、寿元、地产收入、洞天投放和飞升判定 |

全局阶段必须显式标识，不得只靠按钮是否可点击让玩家猜测。

每名玩家另有 `180` 秒整局跨阶段个人思考储备。界面分别显示基础时限与本人剩余储备，不能把二者合成无法解释的单一倒计时。所有相关玩家完成后显示 `3` 秒收束；锁定前撤回会取消收束。不可操作演算和播放不消耗输入时间。

## 4. 世界状态栏职责

回合开始至少展示：

- 当前外界回合与 `90—120` 分钟 / `20—24—28` 仅为验收锚点、不是倒计时；
- 当前常规资源最高开放阶级；
- 当前全局建筑等级；
- 当前全图灵气固定增量；
- 已成熟的物品阶级；
- 本轮固定小洞天投放与当前开放洞府；
- 玩家自己的订单、建设 / 改建、待结算收入和转世提醒。

不同机制必须分栏或明确标名，不能重新包装为一个“世界资源阶段”百分比。

## 5. 即时阶段

入口需区分普通准备、宗门贡献和免费领取。通用玩家交易与即时坊市采购不显示。

切换主修和研习位调整应明确“提交移动计划后锁定”；主修每回合最多一次。宗门贡献允许批量选择白名单物品并立即看到固定贡献值与兑换结果，但必须持续提示贡献点不能支付普通灵石费用。

即时“完成”在阶段锁定前可撤回，但已单独确认并结算的即时行动不回滚。超时时保留已确认结果，丢弃未确认编辑并结束本人即时输入。

## 6. 隐藏规划与提交

玩家只看到自己的目的地、路线、境界骰池、移动法门、可选法宝和主要行动；其他玩家只显示是否提交，不显示内容。

提交前预检查：

- 移动组合、理论最大距离、实际骰池、派生单格耗时及元气 / 灵石 / 耐久成本；
- 路线上的已知关隘过路费与硬阻挡；
- 主要行动类型和当前可知最低条件；
- 突破选定丹药、固定小洞天目标等规划期锁定例外；
- 提交后哪些内容不可更改。

提交在共同锁定前可以撤回；其他玩家只看到提交状态。基础时限与本人思考储备都耗尽后执行“留驻”：不移动、不使用移动资源、不执行主要行动，但正常回合末成长。界面不得自动采用最后一份屏幕草稿。

## 7. 同步移动与局部中断

同步移动期间持续显示玩家实际位置、到达或停止时刻和已发生的可见结果。路线只随实际移动显现。相遇或强制事件只中断相关玩家；无关玩家不应重复确认。

固定地点小洞天竞争需要显示到达顺序、当前挑战者和后续候补；严格同刻挑战者分别进入独立 PVE，不能表现成 PVP 或竞价。

## 8. 两段式行动输入

抵达后只为已锁定行动补参数：

- 采集：一种目标资源和生产力投入；
- 坊市：多种商品及各自数量；
- 炼丹 / 炼器：一个配方和生产数量；
- 购地 / 改建：出价、建筑类型或目标建筑；
- 请教师长：一部合法本宗门功法；
- 地点疗伤：目标与合法投入。

未抵达则行动直接失效。抵达后没有合法参数时，明确显示“行动失败 → 抽取当前地点途中事件池的独立代偿事件”，不得允许换行动。

参数超时与客观无合法参数必须使用不同提示。前者表示玩家主动放弃，不支付未确认费用，也不取得代偿；竞争超时表示不出价、不追加或放弃资格。强制事件必须显示模板预设的无额外消费、低风险安全默认。

## 9. 竞争暂停

暂停时至少展示目标、地点、参与者、竞争类型、等待输入和恢复位置。无主节点首次争购必须显示为灵石暗标并说明落选不支付、同价按到达顺序；固定小洞天不显示战斗 / 竞价选择。

连续战斗显示参战顺序与最终统一掉落性质，但中间不展示尚未判定战利品。独立渡劫不暂停无关玩家。

普通竞争只暂停全局行动队列，不能伪装为整个游戏冻结。主动结束表决则必须显式显示为全局暂停：全部游戏输入、计时、战斗和结算冻结，只有表决、连接检测与重连继续。

## 10. 掉线、重连与托管

玩家状态区公开显示连接正常、断线保护、MVP 安全托管或待退隐，但不泄露隐藏计划。掉线者本人应看到：

- 单次 `60` 秒与整局累计 `180` 秒断线保护余额；
- 断线期间输入计时和个人思考储备冻结；
- 保护耗尽后当前输入采用的安全默认；
- 重连只接管尚未锁定输入，不回滚托管结果；
- 不泄露隐藏信息的个人追赶摘要。

连接正常的玩家可以主动开启 / 退出 MVP 安全托管；确认入口说明托管只维持自动系统，不主动移动、消费、竞价、换功、调构筑、发起冲突或逃遁。房主不显示控制他人托管的入口。

连续掉线计时与断线保护必须分开表达：`60 / 180` 秒决定何时停止等待，连续 `10` 分钟决定永久失去重连资格。重连会立即暂停连续累计，稳定 `30` 秒后清零；稳定期内再掉线则续算。

## 11. 永久退出与待退隐

主动永久退出需要连接正常并二次确认。确认后显示“待退隐”，说明未锁定输入使用安全默认、已锁定因果链继续，角色只会在最近一次尚未开放的回合开始即时阶段第一步实际移除。若当前即时阶段已经开放，则明确显示延至下一回合，不能在移动、战斗或结算中途消失。

退出确认至少列明：个人数值停止维护、随身资产系统回收、退隐不产生死亡掉落、个人订单 / 收入回收、地产保留为退隐宗门地产、稳定供养作废、其他玩家费用由系统回收，以及只剩一名玩家也不会自动胜利。

全员暂时离线时显示“世界已冻结，连接资格计时继续”。最后一个未退隐席位也达到 `10` 分钟阈值后，结果页显示全员退隐、共同中止、无胜者，不播放无人回合。

## 12. 主动结束表决

任一连接正常且未退隐玩家可发起，同一回合最多一次。表决界面必须展示：

- `30` 秒表决倒计时、每名未退隐玩家的响应状态和全局暂停说明；
- 掉线、托管、AI、房主均不能代投；
- 全员同意后的 `3` 秒撤回缓冲；
- 规划未锁定时在当前不可拆分即时结算后结束，规划已锁定时完整结算本轮；
- 同轮合法飞升优先，否则结果为“共同中止、无胜者”。

结果页可以显示公开历程与最终状态，但不得按修为、地产、资产或战力排序成替代名次。

## 13. 回合末结果

结果按来源分组并可展开：

```text
自动修炼（先）
→ 自动研习（后）
→ 恢复 / 丹药 / 法宝炼化 / 寿元
→ 地产稳定收益与待结算收费
→ 物品、建筑、小洞天和其它世界结果
→ 飞升共同胜利
```

小洞天十单位可汇总播放，但要能展开中途境界、掌握阶段、满掌握离位和耗尽结果。主动产物与被动经营收益应标明是否读取物品成熟。

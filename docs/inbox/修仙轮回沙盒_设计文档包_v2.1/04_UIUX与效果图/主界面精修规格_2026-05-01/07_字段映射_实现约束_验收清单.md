## 1. 字段映射

### 1.1 顶部角色信息

| UI 文案 / 组件 | 建议字段 | 示例 |
|---|---|---|
| 姓名 | `character_name` | `陆青岚` |
| 境界 | `cultivation_realm` | `炼气七层` |
| 所属宗门 | `sect_name` | `云麓宗` |
| 宗门职位 | `sect_role` | `外门弟子` |
| 头像 | `character_avatar_ref` | 临时占位 / 资源引用 |

展示格式：

```text
{character_name}｜{cultivation_realm}
{sect_name}｜{sect_role}
```

不再展示：

```text
A-2
```

### 1.2 状态数值条

建议字段：

```text
vitals = [
  { key, label, current_value, reserved_value, max_value }
]
```

当前样例：

```text
生机：72 / 20 / 100
元气：58 / 8 / 80
神念：36 / 6 / 60
```

实现校验：

```text
current_value <= max_value - reserved_value
reserved_value >= 0
max_value > 0
```

若服务端返回 `current_value > max_value - reserved_value`，客户端必须按 `max_value - reserved_value` 截断显示，并记录数据异常。

## 2. 实现约束

### 2.1 客户端职责

客户端负责：

- 展示状态。
- 收集玩家意图。
- 发起即时行动校验请求。
- 发起进入个人行动规划的 UI 状态切换。
- 展示服务器返回的验证结果、错误、警告和日志摘要。

客户端不得：

- 本地权威结算行动。
- 本地绕过服务器修改世界状态。
- 本地直接驱动宗门 AI 选择持续行动。

### 2.2 服务端职责

服务端负责：

- 权威校验。
- 回合结算。
- 状态 mutation。
- 产出结果包。
- 产出日志、回放和可见性数据。

宗门系统输出应通过 S1 / 房间权威结算路径汇入，不直接绕过结算总线。

### 2.3 禁用旧术语

开发中不得新增以下字段或 UI 文案作为活跃概念：

```text
quarter
current_quarter
action_slot
QuarterReplay
SectDecisionIntent
宗门主行动
宗门决策阶段
六个朔望行动格
时间暂停
```

## 3. 验收清单

### 3.1 顶部区域

- [ ] 左上角色卡显示头像。
- [ ] 第一行只显示姓名和境界，例如 `陆青岚｜炼气七层`。
- [ ] 第二行只显示所属宗门和宗门职位，例如 `云麓宗｜外门弟子`。
- [ ] 不显示 `A-2` 小标。
- [ ] 不显示 `时间暂停` 文本。
- [ ] 阶段条在顶部区域水平居中。
- [ ] 房间摘要仍露出房间名、回合、世界日、时辰、宏观周期。
- [ ] 倒计时和未锁定状态可见。

### 3.2 状态数值条

- [ ] 生机 / 元气 / 神念均显示。
- [ ] 保留值显示为右侧锁定上限段。
- [ ] 锁定段与空槽有视觉差异。
- [ ] 当前填充不会越过 `最大值 - 保留值`。
- [ ] hover / click 可显示 `当前 / 保留 / 最大`。
- [ ] 数值浮层压在数值条 UI 上，不撑开角色卡。

### 3.3 地图区域

- [ ] 地图顶部中间显示位置浮窗。
- [ ] 位置浮窗显示当前位置、正在查看、计划目标。
- [ ] 角色卡中不再显示当前位置。
- [ ] 图层面板下移，不遮挡位置浮窗。
- [ ] 当前所在地和选中目标节点高亮可见。
- [ ] 路线预估浮窗可见。

### 3.4 左侧区域

- [ ] 显示待处理变动中心标题。
- [ ] 左侧展开态宽度为 `320px`。
- [ ] 筛选标签完整，默认以 `必看` 为主。
- [ ] P0 安全状态可见。
- [ ] P1 风险卡可定位地图。
- [ ] 宗门当前持续行动卡不提供宗门主行动输入。
- [ ] 左侧没有阶段级主按钮。
- [ ] `LeftRail_Collapsed` 折叠态存在独立节点或变体。

### 3.5 右侧区域

- [ ] 右侧节点为 `04_Right_ContextPanel`。
- [ ] 右侧显示 `当前位置 / 正在查看 / 计划目标` 三态。
- [ ] 目标模板降级为 `GoalTemplateCompact`。
- [ ] 选中对象摘要显示 `正在查看：黑石岭矿脉`。
- [ ] 非当前位置节点只显示对象级操作和抵达后可能处理事项。
- [ ] 非当前位置节点不显示可直接执行的即时行动按钮。
- [ ] 当前位置即时行动列表以状态变体存在，滚动容器开启裁切。

### 3.6 底部区域

- [ ] 显示 `回合时间预算条`。
- [ ] 默认显示 5 个天级分段。
- [ ] 每段显示 `第 N 天` 与 `待规划`。
- [ ] 显示 `进入个人行动规划`。
- [ ] `PhaseCTA_Group` 包含当前阶段唯一主 CTA。
- [ ] 显示 `继续上一计划` 或 `托管本回合` 等阶段级次按钮。
- [ ] 不出现小时排程表。

## 4. 待确认问题

- 角色头像最终资源来源和风格待确认。
- 生机 / 元气 / 神念颜色是否进入正式设计 token 待确认。
- 数值条 hover 与 click 同时存在时的固定显示规则待实现阶段细化。
- 多人房间中玩家席位编号是否需要独立显示，若需要应放入房间成员状态，而不是角色境界旁。

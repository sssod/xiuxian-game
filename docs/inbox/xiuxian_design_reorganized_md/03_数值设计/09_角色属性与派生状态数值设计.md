# 数值设计｜角色属性与派生状态数值设计

## 1. 设计定位

本文负责角色属性相关的具体数值公式、系数字段、百分比乘区和派生状态上限计算。它回答的是“体魄 / 精力如何形成最终值，生机 / 元气 / 神念最大值如何计算，多个增幅来源如何合并”。

文档边界：

| 文档 | 负责内容 |
| --- | --- |
| `docs/inbox/xiuxian_design_reorganized_md/02_系统设计/02_角色与真灵设计/02_角色属性.md` | 角色属性字段语义、来源 / 持续性口径、寿元和年龄阶段边界、UI 展示原则、旧字段迁移 |
| 本文 | 体魄 / 精力最终值公式、生机 / 元气 / 神念最大值公式、公式乘区规则、系数字段与数值调参边界 |

角色属性系统文档是字段语义和模块边界主文档；本文是它的数值配套文档。实现或调参时若需要公式，以本文为准；若需要判断字段是否属于先天、后天、临时、寿元状态、派生状态或资质，以角色属性系统文档为准。

## 2. 通用公式口径

本游戏常规数值公式优先采用单乘区结构：

```text
result =
  (base_value +/- flat_delta_total)
  * (100% +/- percent_delta_total)
```

规则：

- 同一公式里的多个绝对值来源先加减合并，再进入乘区。
- 同一百分比乘区内的多个增减幅来源用加减法汇总，不互相独立连乘。
- 默认无增减幅时，百分比乘区为 `100%`。
- 不默认设置多个独立乘区，除非有明确设计理由。
- 年龄阶段是体魄 / 精力最终值计算中的例外独立乘区，不并入生机、元气或神念的增幅系数。

百分比字段统一使用 `*_percent` 命名。文档中的 `100%` 表示数值表可用百分数或等价倍率保存，具体序列化形式由实现层统一。

## 3. 体魄与精力最终值

体魄 / 精力最终值拆分为先天最终值和后天最终值，供生机、元气等公式读取。

年龄比例公式：

```text
age_ratio = age / lifespan_limit
```

年龄阶段由 `age_ratio` 和年龄阶段数值表派生。具体分段阈值待补。

### 3.1 体魄

```text
base_physique_innate_final =
  base_physique.innate_value
  * physique_aging_phase_multiplier

base_physique_acquired_final =
  (
    base_physique.acquired_permanent_delta
    + base_physique.temporary_modifiers_total
  )
  * physique_aging_phase_multiplier

base_physique.effective_value =
  base_physique_innate_final
  + base_physique_acquired_final
```

### 3.2 精力

```text
base_vigor_innate_final =
  base_vigor.innate_value
  * vigor_aging_phase_multiplier

base_vigor_acquired_final =
  (
    base_vigor.acquired_permanent_delta
    + base_vigor.temporary_modifiers_total
  )
  * vigor_aging_phase_multiplier

base_vigor.effective_value =
  base_vigor_innate_final
  + base_vigor_acquired_final
```

说明：

- `temporary_modifiers_total` 是当前有效临时修正的合计值；它属于后天来源，但不回写为永久后天属性。
- `physique_aging_phase_multiplier` 和 `vigor_aging_phase_multiplier` 由年龄阶段数值表提供，默认无影响时为 `100%`。
- 年龄阶段乘区只在体魄 / 精力最终值计算中出现。其他公式读取 `base_physique_*_final` 或 `base_vigor_*_final` 时，不再额外乘一次年龄阶段。
- 年龄阶段不影响 `aptitude_bone`、`aptitude_comprehension`、`aptitude_root`、`root_affinity_tags`、`root_affinity_profile` 或神念基础值。

## 4. 生机最大值

生机最大值读取体魄最终值：

```text
bar_vitality_max =
  (
    base_physique_innate_final * vitality_innate_physique_coeff_percent
    + base_physique_acquired_final * vitality_acquired_physique_coeff_percent
    + vitality_flat_bonus
  )
  * vitality_amplifier_percent
```

规则：

- 常规情况下，`vitality_innate_physique_coeff_percent` 与 `vitality_acquired_physique_coeff_percent` 相同。
- 分成先天 / 后天系数只是为了后续数值调参和特殊效果预留。
- `vitality_flat_bonus` 是生机绝对值加成合计，可以来自后天永久、临时状态、资源效果、伤势修复或事件结果。
- `vitality_amplifier_percent` 是生机增幅系数合计；多个来源在同一乘区内用加减法汇总，不互相独立连乘。
- 年龄阶段影响已经体现在 `base_physique_innate_final` 与 `base_physique_acquired_final` 中，不在生机公式中再次计算。

## 5. 元气最大值

元气最大值读取精力最终值：

```text
bar_qi_max =
  (
    base_vigor_innate_final * qi_innate_vigor_coeff_percent
    + base_vigor_acquired_final * qi_acquired_vigor_coeff_percent
    + qi_flat_bonus
  )
  * qi_amplifier_percent
```

规则：

- 常规情况下，`qi_innate_vigor_coeff_percent` 与 `qi_acquired_vigor_coeff_percent` 相同。
- 分成先天 / 后天系数只是为了后续数值调参和特殊效果预留。
- `qi_flat_bonus` 是元气绝对值加成合计，可以来自后天永久、临时状态、资源效果、功法效果或事件结果。
- `qi_amplifier_percent` 是元气增幅系数合计；多个来源在同一乘区内用加减法汇总，不互相独立连乘。
- 年龄阶段影响已经体现在 `base_vigor_innate_final` 与 `base_vigor_acquired_final` 中，不在元气公式中再次计算。

## 6. 神念最大值

神念最大值不读取体魄、精力、年龄阶段或悟性资质，使用独立基础常量：

```text
bar_mind_max =
  (mind_base_value + mind_flat_bonus)
  * mind_fixed_multiplier_percent
```

规则：

- `mind_base_value` 默认为所有角色相同的常量。
- `mind_base_value` 只用于避免无加成时神念为 0 造成计算异常。神念为 0 在语义上接近角色死亡，因此不应让常态角色以 0 作为神念上限基准。
- `mind_flat_bonus` 是神念绝对值加成合计，可以来自后天永久、临时状态、功法、资源效果或事件结果。
- `mind_fixed_multiplier_percent` 是神念固定系数乘区；多个来源在同一乘区内用加减法汇总，不互相独立连乘。
- 神念公式不承接年龄阶段乘区。

## 7. 推荐缓存字段

基础属性数值缓存：

```text
BaseAttributeWithAging {
  innate_value: number
  acquired_permanent_delta: number
  temporary_modifiers: Array
  temporary_modifiers_total: number
  aging_phase_multiplier: number
  innate_final_value: number
  acquired_final_value: number
  effective_value: number
}
```

派生状态数值缓存：

```text
DerivedBarBalanceCache {
  vitality_innate_physique_coeff_percent: number
  vitality_acquired_physique_coeff_percent: number
  vitality_flat_bonus: number
  vitality_amplifier_percent: number

  qi_innate_vigor_coeff_percent: number
  qi_acquired_vigor_coeff_percent: number
  qi_flat_bonus: number
  qi_amplifier_percent: number

  mind_base_value: number
  mind_flat_bonus: number
  mind_fixed_multiplier_percent: number
}
```

说明：

- 缓存字段可以由数值表、永久调整和临时修正合并后生成。
- 缓存字段不是独立事实来源；事实来源仍是角色属性、状态记录、资源效果、功法效果、事件结果和数值表。
- 如果实现层不缓存这些字段，也必须保证输出结果能按本文公式追溯。

## 8. 待补规则

- 体魄 / 精力年龄阶段分段阈值。
- `physique_aging_phase_multiplier` 与 `vigor_aging_phase_multiplier` 曲线。
- 生机、元气、神念各系数表。
- 生机、元气、神念绝对值加成来源表。
- 生机、元气、神念增减幅来源合并规则细表。

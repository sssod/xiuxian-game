# 系统设计｜资源、物品、坊市与生产

适用范围：灵石经济、节点收费、资源采集、坊市采购、炼丹与炼器订单、物品阶级与品级，以及随世界进程发生的常规资源开放和物品成熟。宗门贡献的宗门差异与地产建筑等级由关联专题维护。

## 1. 经济边界

1. 灵石是首轮 MVP 的唯一普通流通货币，用于节点购买、建筑建造与改建、停留费、功能使用费、关隘过路费、商品价格、配方投入和资源采集的生产力投入。
2. 宗门贡献点是与灵石隔离的宗门进度，只承担多余物品回收、宗门特色兑换和宗门特殊建筑成本；两者不能互换，也不能互相替代支付。
3. 首轮不引入债务、破产、强制出售、通用玩家交易或坊市回购。玩家不能预付已知费用时，不能提交对应主动行为。
4. 灵石、贡献点、修为 CP、掌握度、元气、行动次数、事件进度和节点主导权都不是物品，不读取物品成熟。

宗门贡献白名单、兑换目录和成本见《[宗门、地产与建筑经营](07_宗门地区经营.md)》。

## 2. 节点收费与到账

一般可使用节点采用两层收费：角色移动结束并停留时收取一次停留费；玩家随后每次发起收费功能或主要行动时，再收取一次固定功能使用费。功能费以发起合法功能为条件，不以最终结果成功为条件。

| 情况 | 固定费用去向 |
| --- | --- |
| 无主节点 | 系统回收 |
| 其它宗门主导节点 | 转入该主导宗门本回合待结算收入 |
| 自有节点 | 停留费、固定功能费和关隘过路费免除 |

商品价格、配方材料与单位灵石投入、采集生产力投入、法宝耐久等实际消耗不属于所有权优惠，自有节点仍需正常支付。

停留费、功能费和过路费在发生时立即从付款者扣除。有主节点的收款方按费用发生时的主导权锁定，收入在全部移动、行动与事件结算后，与地产持续产出一起于回合末到账；本轮尚未到账的收费不能用于支付本轮其它行为。无主节点费用在发生时直接回收。

规划时若玩家无法支付已知过路费，对应路线通常不合法。若同步主导权变化或事件使费用在结算时变化、玩家突然无法全额支付，则扣除其当前全部灵石，不产生欠款；依赖该费用的功能或通行失败，资产不会被强制出售。

## 3. 资源采集

资源采集占用一次主要行动。玩家合法抵达资源节点后：

1. 从“节点模板目录 ∩ 当前建筑等级目录 ∩ 当前回合常规资源阶级上限”中主动选择一种目标资源；一次行动不能混采多种原料。
2. 支付一次固定功能费，并在 `1—当前建筑等级投入上限` 间选择灵石生产力投入；自有节点只免固定费。
3. 系统按目标资源基础转化表和投入灵石生成基础数量。建筑等级主要提高投入上限与目录，不默认提高同一种资源的单位灵石转化率；例外必须逐级显式配置。
4. 对基础产物逐物品应用当前有效的数量成熟和品级成熟，随后立即进入玩家资产。

合法采集不进行成功率判定。节点不维护共享库存、全节点单回合总容量、枯竭度或所有者预留份额；同轮多名玩家分别支付并独立结算，互不削减产量。重点 PVE 或惊喜事件“提前一阶投放”的例外不会扩展普通采集目录。

资源节点的回合末被动供养与主动采集相互独立；被动供养只读取建筑等级表，不读取物品成熟。详细经营价值见《[宗门、地产与建筑经营](07_宗门地区经营.md)》。

## 4. 坊市采购

坊市采购占用一次主要行动，不属于即时行动。合法抵达后，玩家可以在一次采购中选择一种或多种目录商品：

- 每个商品分别拥有自己的单回合购买上限，不存在整次采购共享的总单位上限；
- 每名玩家独立读取上限，其他玩家购买不会占用额度；
- 一次采购只收取一次固定功能费，各商品价格按数量另付并由系统回收；
- 自有坊市只免固定功能费，不免商品价格；
- 合法购买的物品在行动结算时立即进入资产，并在生成时读取当前有效的品质成熟规则；
- 坊市不维护库存、扣减或刷新状态，也不向玩家回购物品。

目录和逐商品上限由坊市当前建筑等级决定，同时受当前回合常规资源阶级开放上限约束。

## 5. 炼丹与炼器订单

首轮 MVP 不制作炼丹法门、炼器法门或深度制作流程。炼丹与炼器由特定建筑提供的地点主要行动承接，使用固定“资源 → 成品”配方。

第 `N` 回合提交订单时：

1. 一次行动只选择一个配方，并在该配方的 `1—单次生产数量上限` 内选择数量；
2. 配方资源与成品按数量线性变化，固定功能费每份订单只收一次；配方中的额外灵石必须列为单位资源；
3. 立即扣除资源和功能费，订单保证成功，不读取玩家功法掌握，也不另做制作成功率或基于技能的制作质量判定；成品模板自身的随机品级仍在收获时按本文件规则生成；
4. 合法性、配方、数量、投入、功能费和基础产量按下单时的建筑等级锁定。之后建筑升级、关闭、封锁或失效不取消订单、不退款，也不追溯改变基础结果。

订单在第 `N+1` 回合开始时完成。角色仍位于下单建筑时可通过免费即时行动领取；若提交移动计划前未领取，系统自动把成品放入资产并记录日志。首轮不建立订单库存，成品不滞留、不失效，也不要求以后返回。

收获时对每件新成品读取当时世界状态允许的品级成熟。升级建筑可以扩展配方和提高生产上限，但不能绕过常规资源阶级开放。

## 6. 三条独立世界节奏线

资源阶级开放、物品阶级成熟和建筑自然升级是三套独立机制，不得合并为“世界资源供给阶段”或统一倍率。

| 机制 | 读取条件 | 允许改变 |
| --- | --- | --- |
| 常规资源阶级开放 | 当前外界回合 | 哪些阶级可以进入常规节点、配方和坊市目录 |
| 物品阶级成熟 | 本局历史最高已达大境界 | 已被越过阶级的合格主动产物数量与同阶品级分布 |
| 建筑自然升级 | 当前外界回合 | 建筑成本、稳定收益、收费、目录、投入与容量的逐级表 |

常规资源阶级开放时点为：第 `1` 回合炼气阶、第 `5` 回合筑基阶、第 `9` 回合金丹阶、第 `13` 回合元婴阶、第 `17` 回合化神阶、第 `21` 回合大乘阶。新阶在对应回合开始时开放，之后不回退。开放只表示允许投放，不要求每个来源自动提供该阶，也不增加数量、改变品级或追溯既有物品。

重点 PVE 与惊喜事件可以逐奖励项配置最多提前一个阶级的产物；该例外不解锁其它常规来源。

## 7. 物品阶级成熟

设 `H` 为本局历史最高已达大境界阶级，`T` 为产出物品阶级。当且仅当 `H > T` 时，`T` 阶物品从先行者越过该阶后的下一外界回合开始成熟。成熟永久保留，每个阶级只发生一次，不因触发者死亡或转世回退，也不会随 `H` 后续提高重复叠乘。当前最高境界同阶物品不成熟；基础 MVP 中大乘阶物品不会因本机制成熟。

来源先生成基础结果，再逐项读取物品模板的“允许数量成熟”和“允许品级成熟”开关。成熟只允许：

- 增加合格物品数量；
- 在物品阶级不变的前提下，提高取得同阶高品级的概率。

成熟不提升物品阶级，不修改节点基础转化公式、生产力投入上限、建筑等级、事件槽位或总预算、固定配方、商品上限和高级资源开放时点。已生成物品不追溯改变。

### 7.1 来源和类别边界

| 物品 / 来源 | 数量成熟 | 品级成熟 |
| --- | --- | --- |
| 普通可堆叠原料、普通怪物材料 | 默认允许；模板可关闭 | 有随机品质且模板允许时生效 |
| 未经过加工、适合堆叠的普通消耗品 | 模板允许时生效 | 有随机品质且模板允许时生效 |
| 经过炼制或加工的普通成品 | 关闭 | 有随机品质且模板允许时生效 |
| 后四类破境丹 | 固定关闭 | 固定允许；提高护劫护盾高档位投放概率 |
| `Q2` 筑基丹 | 关闭 | 固定品级，不判定、不成熟 |
| 法宝、功法载体、命名秘宝、唯一物品 | 默认关闭 | 仅随机品质且模板允许时生效 |
| 固定品质物品 | 关闭或按模板 | 不改判，继续显示固定品级颜色 |
| 无品质属性物品 | 关闭 | 关闭，显示灰色边框 |
| 建筑 / 节点回合末被动经营收益 | 关闭 | 关闭 |
| 玩家主动采集、采购、订单收获等结果 | 按模板 | 按模板 |

成熟原料的数量与品质改善、成品自身的品质成熟可以在同一生产链分别生效，但成品不得再次获得数量成熟。原料品质只有在配方显式读取时才影响成品；否则不会自动增加成品数量或品级。

### 7.2 数量成熟

普通合格原料的默认一次性数量倍率锚点为 `1.5`：

```text
成熟期望数量 = 基础数量 × 1.5
```

结果非整数时无状态随机取整：先发放向下取整数量，再以小数部分为概率额外发放 `1` 个。每次生成独立结算，不跨玩家、节点、物品或回合保存余数；结果不得少于原本的基础整数数量。模板可以关闭或显式覆盖 `1.5`，但不得仅因来源不同临时改变同一模板倍率。

### 7.3 品级成熟

同阶五档品级固定为：

| 代码 | 品级 | 边框色 |
| --- | --- | --- |
| `Q1` | 下品 | 绿色 |
| `Q2` | 中品 | 蓝色 |
| `Q3` | 上品 | 紫色 |
| `Q4` | 极品 | 金色 |
| `Q5` | 绝品 | 红色 |

每个随机品质来源先配置一张完整 `Q1—Q5` 基础权重表。未成熟时判定一次；成熟后对同一基础权重独立判定多次并取最高品级。默认总计判定 `2` 次，少数经测试需要更强追赶的模板可配置总计 `3` 次；这不是两层成熟，也不开放任意次数。次数跟随物品模板，来源仍只提供基础权重。

同一次来源生成的一批可堆叠原料只执行一组品质判定，整批使用同一结果；丹药、法宝等按件物品逐件独立判定。固定品质和无品质物品不参与多次取高。

高品级原料可以 `1:1` 替代配方要求的同类低品级原料，不能自动拆成多份低品级原料；超出门槛的价值不返还。成品品级只修改模板明确字段，不使用覆盖全部物品的隐藏统一品质倍率。

### 7.4 价值约束

同类、同规模的成熟 `T` 阶标准节点或奖励，其长期期望价值不得达到或超过未成熟 `T+1` 阶标准节点或奖励；首轮以“不高于下一阶未成熟标准期望价值的 `80%`”作为调参验收锚点。偶发极品低阶物品可以高于普通高阶物品，但不能让高境界玩家长期回流低阶生态成为最佳策略。

该约束必须按完整生产链同时校验原料数量、原料品级、成品品级、建筑上限和行动成本。若不满足，应优先调整例外模板倍率、基础品质权重或物品用途，不得恢复按玩家境界区分的个人倍率。

## 8. 破境丹经济特例

用于从 `T` 境突破至 `T+1` 境的破境丹属于起点 `T` 阶物品。炼气突破筑基所用筑基丹固定为 `Q2 中品`，所有来源均生成同一蓝框版本，不判品质，也不读取成熟。

后四类破境丹保留 `Q1—Q5` 随机品级，关闭数量成熟并开启品级成熟。坊市购买和委托炼制都在新物品生成时读取当前世界状态；成熟不提高单价、配方投入、灵石费用、产量、行动或等待时间。生成后品级固定，并直接映射为渡劫时的五档护劫护盾；丹药不预存某名角色的绝对护盾值。

突破与护劫护盾规则见《[角色成长、突破与转世](05_角色成长突破与转世.md)》。

## 9. 当前缺口

- 各类停留费、功能费、过路费、商品价、配方投入和节点标价绝对值；
- 首批资源节点、坊市目录、固定炼丹 / 炼器建筑、配方与成品表；
- 各来源完整 `Q1—Q5` 权重、逐模板成熟开关、三次取高模板和偏离 `1.5` 的例外；
- 全链路价值验算与宗门贡献最终回收表。

上述内容只能标记为待配置，不得在实现期静默补值。

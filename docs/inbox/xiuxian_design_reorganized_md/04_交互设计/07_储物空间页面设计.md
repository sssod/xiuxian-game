# 交互设计｜储物空间页面设计

## 当前状态

未检索到独立视觉稿。本页只列系统约束。

## 必须表达

- 随身资产、个人储藏、宗门库存、节点库存、市场挂牌、事件锁定、后手封存等资产位置。
- 可堆叠物品与独立实例物品的差异。
- 物品是否 combat_ready、是否绑定、是否可用于当前行动 / 事件 / 战斗。
- 残余效果不只在背包显示，还需在角色状态中提示。

## 不应表达为

- MVP 不做背包格子、重量、通用负重上限。
- 不以装备栏决定法宝和道具可用性。

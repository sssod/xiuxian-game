## 1. 区域职责

底部区域负责展示天级回合时间预算条，并提供当前阶段唯一阶段级主 CTA。

当前状态是折叠态：

- 显示 5 天预算占位。
- 未显示完整行动指令规划器。
- 不允许玩家手动排小时表。

## 3. 左侧说明

标题：

```text
回合时间预算条
```

状态：

```text
未进入个人行动规划
```

主界面内说明文案留空。

以下说明移至主 Frame 外注释区：

```text
当前回合默认 5 天。这里只显示天级预算，小时级 world_hour / hour_tick 由服务端结算。
```

规则：

- 使用“回合”与“天”表达玩家可理解的规划单位。
- 小时级 `world_hour` / `hour_tick` 只作为服务端结算语义，不在折叠预算条中要求玩家排布。

## 4. 天级分段

当前分段：

```text
第 1 天｜待规划
第 2 天｜待规划
第 3 天｜待规划
第 4 天｜待规划
第 5 天｜待规划
```

每个分段：

| 项 | 值 |
|---|---|
| 节点 | `C_DayBudgetSegment_Instance_empty` |
| 单段尺寸 | `172 x 72` |
| 间距 | `10` |
| 默认状态 | `待规划` |

规则：

- 默认 5 天来自当前配置，不是硬编码永久规则。
- 若未来回合时长可配置，分段数量由配置生成。
- 折叠态只展示天级占位；展开态才展示行动块。

## 5. 右侧操作

按钮：

```text
进入个人行动规划
继续上一计划
托管本回合
```

提示标签：

```text
即时行动仍可用
```

以下说明移至主 Frame 外注释区：

```text
进入规划后，即时行动冻结
```

主界面内 `BudgetSubHint` 留空。

以下说明移至主 Frame 外注释区：

```text
阶段级按钮只在此处出现；右侧仅处理当前对象。
```

规则：

- `进入个人行动规划` 前必须处理硬阻断。
- `继续上一计划` 只能生成待确认意图，不可直接锁定提交。
- `托管本回合` 必须进入托管确认或检查流程，不可绕过锁定确认。
- 进入规划后，右侧当前位置即时行动和左侧即时行动提醒应同步冻结或变更状态。

## 6. 禁止项

底部区域不得出现：

- 六个朔望行动格。
- `action_slot`。
- `quarter`。
- 玩家手动小时表。
- 宗门主行动计划格。

## 7. 展开态预留

展开后应支持：

- 地图点选目标。
- 自动生成移动与持续行动指令队列。
- 在天级预算条中显示行动块。
- 点开行动块查看小时级预估。

展开态仍不允许玩家直接编辑小时级排程。

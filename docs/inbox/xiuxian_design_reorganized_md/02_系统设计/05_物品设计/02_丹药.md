# 物品设计｜丹药

## 1. 当前定版口径

丹药、灵材、符箓、临时增益资源，不优先设计为独立持续行动，而是统一作为“行动资源输入项”挂载到对应行动或事件选项上。

明确不做：

- MVP 不设计独立持续行动“丹药炼化”。
- MVP 不允许即时服用修为丹药后直接增加修为。
- MVP 不允许丹药绕过时间预算产生收益。

## 2. 典型对应关系

| 资源 | 对应行动 / 语境 |
| --- | --- |
| 修为丹药 | 主动吐纳的额外资源输入 |
| 临时悟性丹 | 研习功法的额外资源输入 |
| 解毒丹 / 避瘴丹 | 毒瘴区域移动、探索、采集、战斗语境输入 |
| 疗伤丹 | 休整 / 治疗 / 医疗事件选项输入 |
| 定心丹 | 巩固根基 / 突破准备 / 突破事件链选项 / 研习功法输入 |
| 战斗丹药 | 战斗事件链指令或战斗准备输入 |

## 3. 修为丹药结算

```text
cultivation_resource_aura_input =
Σ(unit_aura_rate_i × applied_effective_hours_i × resource_quality_factor_i)

raw_aura_input = environment_aura_input + cultivation_resource_aura_input
```

之后统一进入：根骨安全承载、根骨转化效率、灵根与道功相性、道功基础转化率、状态修正、修为进度和修炼压力。

## 4. 残余效果

行动开始但未完全消耗资源时，生成 ActiveResourceEffect。残余可跨行动、跨回合保存，但受策略限制：

- stable_suspend：稳定暂存。
- slow_decay：缓慢散逸。
- stimulating_decay：刺激性衰减。
- forced_release：强制释放；MVP 不作为常规内容使用，仅预留字段。

## 5. 巩固根基处理

巩固根基可以选择性收束残余修为药性，但不转化为修为进度；主要用于止损、减压、稳定根基。

## 6. UI 口径

资源输入 UI 采用“行动内折叠项”。角色已有残余效果必须在角色面板或行动规划器中常驻提示。事件资源输入作为事件选项附加条件显示。

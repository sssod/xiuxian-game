# 修仙轮回沙盒｜设计文档重编包

本包按照《设计文档框架》重排 Library 中已检索到的项目文档内容。整理目标是把原 Notion 导出的人工编辑文档、后期机制修正稿和数值草案，重编为可继续维护的 Markdown 文档结构。

## 整理规则

1. **优先级**：当前用户指令 > Library 当前文档 > 后期修正稿 / 收敛稿 > 原始系统草稿 > 未人工审核补齐稿。
2. **冲突处理**：有前后冲突时，以 2026-05-07 至 2026-05-08 的机制修正稿、功法收敛稿、修炼公式补充、数值方案为准；保留早期方案的设计历史。
3. **缺失处理**：未检索到足够细节的菜单，只列出相关约束文档和待补项，不在本轮补写新规则。
4. **猜测处理**：框架映射或编号歧义处采用最可能归类，并在文档中显式标注“整理猜测”。
5. **独立文档**：框架中的“流程设计”和“角色与真灵设计”每个二级菜单均已单独成文。

## 目录

- `00_INDEX/`：索引、来源、冲突处理、缺口清单。
- `02_系统设计/`：按框架重排的系统与玩法文档。
- `03_数值设计/`：0507–0508 两个数值草案拆分映射，并收纳角色属性相关公式与派生状态数值口径。
- `04_交互设计/`：当前可由机制文档约束出的 UI/UX 文档；缺少 Figma 细节者只列约束。

## 重要限制

本整理使用 Library 检索到的文档片段和上下文重排。若后续需要“逐字保留所有原始段落”，建议从 Notion 导出的原始 Markdown 文件进一步提供为当前对话附件，或允许使用可直接读取全文的文件源。本轮已经尽量保留检索到的原始规则、字段、流程、决议与设计历史，不主动创造未定内容。

# 系统设计｜自动战斗、重点 PVE 与逃遁

适用范围：战前构筑、冷却驱动自动执行、普通与重点 PVE 分类、强制渡劫、胜负、逃遁、连续战斗和死亡资产结算。竞价入口由行动专题维护。

## 1. 战斗类别

首轮必须区分四类战斗，不能共用一套随回合升档规则：

| 类别 | 难度演进 | 预览与入口 |
| --- | --- | --- |
| 普通途中随机战斗 | 不使用不可逆升档 | 由途中事件触发 |
| 地图重点 PVE | 事件模板可配置按外界回合升档，也可各档相同 | 玩家主动挑战前公开当前档位、敌人摘要、逃遁与失败后果 |
| 固定地点小洞天入口重点 PVE | 作为地图重点 PVE，可按模板随回合升档；洞府开放时不冻结难度 | 小洞天挑战主要行动触发 |
| 四场强制渡劫 PVE | 按目标境界固定战力预算，不随回合、失败次数或玩家状态升降 | 突破行动确认后触发，公开固定敌人、丹药护盾与后果 |

重点 PVE 用于把守高价值资源、关键建筑、特殊路线、小洞天或飞升前置，推动玩家建设战斗构筑。各事件档位只读取自己的升档回合，达到后不因玩家死亡、转世或落后回退；模板可以自行决定战力曲线，甚至让各档战力相同。

强制渡劫是升档机制的明确例外。金丹、元婴、化神、大乘四个目标境界各自使用一套固定敌人；晚挑战、重试、逃遁或死亡都不改变敌方基础难度，不使用战力匹配、失败保底或隐藏动态难度。详细突破结果见《[角色成长、突破与转世](05_角色成长突破与转世.md)》。

## 2. 战前构筑

正式战斗采用冷却驱动、战前构筑、战中自动执行。战前构筑包含：

- 当前主修一本道功及其已解锁招式；
- 最多 `5` 个已装配战斗法门招式；
- 攻击、防御、飞遁三个固定法宝位；
- 攻击 / 防御法宝提供的有效招式；
- 所有有效招式合并后的玩家手动左右顺序。

飞遁法宝不提供循环战斗招式，只提供常驻被动、移动或逃遁加成。法宝效果必须先跨过炼化门槛。意外战斗读取本回合移动前完成的配置，不在开战时重新开放换装、服丹、改修或研习位调整。

当前主修切换后，旧道功招式退出，新主修已解锁招式追加至列表末尾。法门离散强化不创建额外候选招式，除非阈值本身是“新增能力”。

## 3. 自动执行

1. 开战时所有具有冷却的招式先等待一次完整基础冷却；常驻被动从开战时生效。
2. 同一角色多个招式同刻就绪时，从列表左到右扫描。
3. 冷却未完成、资源不足、条件不成立或无合法目标的招式被跳过，不阻塞右侧。
4. 元气不足的已就绪招式保持等待；恢复后继续按左右顺序尝试。
5. 双方同刻存在可触发招式时，由本场稳定战斗随机结果决定双方先后。
6. 没有始终可用的基础攻击；低冷却战斗法门招式承担持续输出入口。

## 4. 首轮效果范围

首轮战斗只支持：

- 生机、元气或神念直接伤害；
- 护盾；
- 直接伤害增伤 Buff；
- 直接伤害减伤 Buff；
- 已确认的固定元气损伤与吸收。

不支持命中、闪避、暴击、伤害浮动、元素克制、持续伤害或控制。知识来源允许字段读取当前掌握倍率；法宝招式不读取知识掌握倍率，而读取炼化度。

## 5. 状态、胜负与平局

战斗直接读取并回写生机、元气、神念和正常跨战斗状态，不在开战或战后自动回满：

```text
生机 <= 0 → 死亡并战败
否则神念 <= 0 → 重伤并战败
```

元气归零本身不结束战斗。普通战斗最长 `60` 秒；超时且双方均未战败时直接平局，不比较剩余属性、伤害量或资源。平局双方保留实际状态，原定行动失败，竞争目标无人获得；飞升前置平局不能开始飞升。

## 6. 护盾与 Buff

通用护盾只保护生机。所有普通护盾与护劫护盾生成后立即写入一个统一总护盾值；来源只写生成日志，不保存来源余额、独立持续时间、同源刷新状态或受击优先级。所有护盾持续整场战斗，直到被伤害消耗或战斗结束。

每场战斗开始：

```text
总护盾 = 0
→ 锁定开战最大生命
→ 总上限 = 开战最大生命的 100%
→ 普通单次生成上限 = 开战最大生命的 50%
→ 渡劫时先加入护劫护盾
→ 其它开战护盾按稳定事件顺序加入
→ 每次加入后裁剪到总上限，溢出作废
```

普通护盾每次触发：

```text
计算本次最终生成量
→ 裁剪到普通单次 50% 上限
→ 加入统一总护盾
→ 裁剪到总量 100% 上限
→ 溢出作废
```

同一招式以后再次触发时视为一次新的普通护盾生成；只要总护盾曾被消耗，就可以补充新的容量。新护盾不替换、不压缩已有总护盾。护劫护盾可以超过普通单次 `50%` 上限，但仍计入 `100%` 总上限。战中最大生命变化不追溯扩大、缩小或裁剪本场上限；下一场重新快照。

受到生机伤害时，先应用通用增减伤，再由统一总护盾一比一吸收，剩余伤害才进入体魄减伤与正伤害最低 `1` 点规则。神念伤害继续绕过护盾。胜利、失败、逃遁、中止或普通战斗结束都清空总护盾；连续战斗下一场从 `0` 重建。

最小验算以开战最大生命 `1000` 为夹具，不能混入正式配置：

1. `Q5` 护劫加入 `800`，普通开战护盾请求 `300`，只写入 `200`，总护盾为 `1000`。
2. 普通招式单次请求 `700`，先裁为 `500` 再加入总护盾。
3. 普通招式生成 `300`、受击后总盾剩 `100`、再次生成 `300`，新总盾为 `400`。
4. 总盾 `1000` 受到通用增减伤后 `1200` 生机伤害，盾归零，剩余 `200` 进入体魄减伤。
5. 战中最大生命改为 `1200` 或 `800`，本场单次 / 总量上限仍为 `500 / 1000`。
6. 战斗结束尚余 `450` 也全部清除；连续战斗下一场从 `0` 开始。

Buff 可以配置最大层数和共享持续时间；再次生效刷新持续时间。可变数值 Buff 强制单层，新值无条件替代旧值，不比较来源强弱。

## 7. 通用逃遁

逃遁是角色通用操作，不要求飞遁法宝或法门。普通战斗默认允许；普通事件可以显式禁止，但四场强制渡劫当前明确允许逃遁，不得再标记为禁逃。

- 初次尝试可以直接发起；失败后等待 `5` 秒才可重试；
- 失败使角色所有招式的当前剩余冷却各增加 `1` 秒；
- 每次尝试独立判定，不累计失败补偿；
- 成功立即脱离并视为本场战败，放弃原定主要行动；
- 成功后按地图规则选择相邻 `1` 格内合法落点免费移动；无合法地点时留在原地；
- 飞遁法宝只增加成功率，仍受炼化；最终成功率可以达到 `100%`。

渡劫逃遁还会判定本次突破失败：主要行动、破境丹、法宝耐久、非破境丹药和其它已消耗资源不返还；保留战斗结束时实际生命、元气、伤势、冷却和跨战斗状态，护劫护盾清除。下一次必须重新持丹挑战，敌人仍为固定模板。

## 8. 连续战斗

多人连续战斗的参战顺序由到达时间与竞争类型决定。场间保留生机、元气、神念和正常跨战斗状态；护盾每场清空。中途不结算死亡掉落，整段结束后才统一为所有阵亡者生成结果并交给最终合法胜者。

固定地点小洞天的严格同刻挑战不是多人连续战斗：参与者各自独立挑战同一套 PVE，以通过者战斗用时和稳定随机结果决定资格。

四场渡劫同样使用每名玩家独立战斗；其他玩家不能加入、协助、攻击渡劫者或通过节点主导权改变战斗。严格同一外界时刻发生的多场渡劫分别结算，结束后再把状态和境界结果返回共享流程。

## 9. 死亡资产结算

死亡角色失去全部随身可转移资产。每件独立物品或每个堆叠单位（包括每单位灵石）独立以 `10%` 成为战利品，其余系统回收；胜者不能选择。无合法玩家胜者时全部回收，不生成地图拾取物。死亡掉落法宝对新归属者以炼化度 `0` 初始化。

知识、掌握、宗门贡献和地产不是本场随身掉落。完整跨世后果见成长与地产专题。

# 数值设计｜投放数值设计

## 1. 当前结论

投放数值由阶段预算、资源槽、事件生成预算、宗门库存、市场、NPC 库存和世界窗口共同控制。

## 2. 阶段预算机制

- 玩家首次突破到某大境界后，世界激活对应阶段预算。
- 预算进入节点资源槽、宗门库存、市场交易、机会窗口、NPC 库存和事件投放。
- 高于当前预算境界的 NPC 默认只按背景速度成长，不发生明显修为提升或突破。
- 不高于当前预算境界的 NPC 与其他玩家可受预算打开影响。

## 3. 投放不等于赠送

预算打开提供机会，不自动赠送修为。玩家仍需通过探索、宗门、市场、节点、事件、NPC 关系和风险选择创造高价值闭关条件。

## 4. 待补

- 每个境界资源包模板表。
- 阶段预算每个宏观周期的具体点数。
- 节点资源槽如何从预算池抽样。
- 玩家资源充足倍率如何避免重复套利。

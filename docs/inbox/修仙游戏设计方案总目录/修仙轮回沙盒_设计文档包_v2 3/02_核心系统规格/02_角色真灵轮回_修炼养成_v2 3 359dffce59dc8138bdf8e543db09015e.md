# 角色、真灵、轮回与修炼养成（v2.3）

## 1. 系统定位

角色系统负责当世角色成长，真灵系统负责跨世连续性。修炼、功法、资源输入、突破、死亡、转世和后手共同构成长期成长闭环。

核心实体：

```
TrueSpiritState
CharacterState
CultivationState
MethodState
LifeLedger
ReincarnationRecord
ContingencyRecord
```

---

## 2. 真灵状态

```
TrueSpiritState {
  true_spirit_id: String
  owner_player_id: String
  current_character_id: String | null
  reincarnation_count: int
  life_ledger_refs: Array
  inherited_memory_tags: Array
  known_contingency_refs: Array
  karmic_trace: Dictionary
  exposure_level: hidden | suspected | exposed
}
```

`exposure_level` 影响高阶 NPC、宿敌、后手争夺和多人间接竞争。暴露信息进入可见性系统，不直接向所有玩家公开。

## 5. 功法与掌握度

功法学习来自完整功法载体。残页、章节和片段用于合成、线索、权限、事件投放或内容收集。

```
MethodState {
  method_state_id: String
  character_id: String
  method_template_id: String
  learned_from_carrier_id: String
  mastery_level: int
  mastery_progress: number
  compatible_realms: Array
  active_tags: Array
  unlocked_effect_refs: Array
  last_practiced_world_day: int
  last_practiced_world_hour: int
}
```

掌握度影响：

```
修炼效率；
突破模板；
事件选项；
战斗策略；
资源输入兼容；
心魔与走火风险；
宗门评价和 NPC 关系。
```

---

## 6. 行动资源输入

丹药、灵材、符箓和临时增益资源通过 `ActionResourceInputBinding` 绑定具体行动或事件选项。

规则：

```
资源输入不作为默认独立行动；
行动入队时校验当前拥有和可用；
行动开始前再次校验；
行动开始或事件选项生效时消耗；
未用完效果生成 ActiveResourceEffect；
局部时停期间角色自身资源变化暂停；
C1 追赶只补确定性资源效果。
```

---

## 7. 小境界与瓶颈

小境界推进由修炼状态、功法、资源、地点和风险共同决定。

小境界选择事件按普通个人事件处理：

```
本人局部时停；
外部世界 N1；
gap≤1 游戏日；
选择后 C1 追赶。
```

小境界结果进入个人日志和可见性系统，必要时影响宗门传闻。

---

## 8. 大境界突破

大境界突破结构：

```
准备期
→ 开启突破短指令
→ 突破挑战 B1
→ 个人结果报告
→ 后续选择
```

准备期可作为长期低交互行动。开启突破必须当前满足条件。突破挑战使用 `FormalEncounterState`，每轮资源消耗与策略选择进入结果包。

---

## 9. 死亡与转世

死亡触发：

```
寿元耗尽；
战斗失败；
突破失败；
重大事件结果；
资源反噬；
后手或因果冲突。
```

死亡结果写入：

```
LifeLedger；
ReincarnationRecord；
可继承后手；
可见传闻；
资产去向；
真灵暴露变化；
下一世初始条件。
```

转世流程：

```
生成 ReincarnationRecord
→ 结算后手与遗产
→ 选择或生成新当世角色入口
→ 绑定 TrueSpiritState
→ 建立新 CharacterState
→ 写入 TimelineReplay
```

角色系统必须输出：

```
修炼进度日志；
功法掌握变化；
资源输入消耗；
ActiveResourceEffect 变化；
瓶颈与小境界事件；
突破挑战结果；
伤势、寿元、心魔变化；
死亡与转世记录；
真灵暴露与轮回账本变化。
```

所有状态变化通过 S1 结果包回写。

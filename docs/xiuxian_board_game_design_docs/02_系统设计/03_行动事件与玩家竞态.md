# 系统设计｜行动、事件与玩家竞态

适用范围：即时行动、主要行动、两段式承诺、行动失败、仇敌关系、战斗 / 竞价选择和多人竞争顺序。经济公式、地产细则与战斗执行分别由关联专题维护。

## 1. 行动预算

每个正常外界回合，每名玩家拥有一次地图移动和一个主要行动。回合开始即时阶段可以执行任意次当前合法的即时行动；移动开始后不重新开放即时窗口。

行动类型与参数采用两段式承诺：

```text
移动前：目的地、路线、移动组合、主要行动类型
抵达后：对象、投入、数量及其它具体参数
```

移动后不能更换主要行动类型。固定地点小洞天须在规划时锁定目标洞府；突破须在规划时选定一枚合法破境丹，但只在抵达后确认时消耗。其它行动按各自专题列出的字段补充参数。

## 2. 回合开始即时行动

当前确认的即时行动包括：

- 学习并消耗已持有的普通功法道具；
- 调整研习位、装备、法宝位、法门招式和招式顺序；
- 服用允许在该时点使用的普通丹药；
- 设置或切换主修道功，每回合最多一次；
- 通过专用宗门贡献入口批量贡献物品或兑换宗门内容；
- 领取上一回合完成的炼丹 / 炼器订单；提交移动计划前未领取时自动入包；
- 查看已知信息、整理库存和其它不直接产生收益的资产操作。

首轮 MVP 已移除通用“交易”即时行动：不开放玩家间直接交易，也不能以即时行动向坊市购买。坊市采购是主要行动。宗门贡献是独立专用即时行动，不代表通用交易恢复。

宗门贡献入口不要求玩家位于宗门驻地或自有节点，可在地图任意地点使用；首轮不设每回合操作次数或贡献数量上限。宗门特殊建筑仍须现场执行经营主要行动，不能通过贡献入口远程施工。

“研习功法”不再是通用主要行动，普通掌握成长改由研习位自动结算。首轮不引入符箓物品及其获取、装备或效果，也不制作炼丹 / 炼器法门的深度制作流程。

主动战斗不作为脱离地点或事件的通用自由行动；重点 PVE、小洞天入口、相遇和其它战斗由其明确行动或事件入口触发。

## 4. 生产与经营行动的锁定

合法炼丹或炼器订单在提交并扣除资源后锁定，之后建筑升级、关闭或封锁不取消、不退款。一次行动只选一个配方，但可在配方上限内生产多份。

首次购买待开发优质地块时，玩家必须在同一次经营行动中提交建筑类型。单人购买预付“地块标价＋当前等级建造成本”；多人争购同时提交购地出价和建筑类型，预留“出价＋建造成本”，但排名只比较购地出价。胜者支付两部分，落选者均不支付。已建地块改建支付目标建筑完整成本，旧建筑无残值返还。

## 5. 抵达失败与无合法参数

玩家未抵达目标时，原定主要行动不执行，角色停在实际落点并进入对应途中内容。移动中断事件完全替代原定主要行动，事件结束后不能恢复本轮移动或行动。

若角色成功抵达，但补充参数时没有任何合法选项，主要行动失败，并从当前地点途中事件池抽取一次独立代偿事件。界面不得允许改选其它主要行动。代偿事件通常不产生玩家间目标竞争，但可以按模板触发单人战斗。

## 6. 仇敌关系与隐藏计划

规划阶段不公开其他玩家的目的地、路线、移动组合或主要行动意图。通用规则不提供窃取隐藏计划的能力。

仇敌是宗门之间的方向性宣战关系：任一方成立即可使双方在移动相遇时触发强制事件。第 `N` 回合设置后，第 `N+1` 回合不能解除，最早于第 `N+2` 回合移动前解除。普通地产收费、节点争购和资源转移都不自动建立仇敌；普通宗门关系、仇敌关系的建立与解除、公开范围和完整效果仍待外交专题裁决。

## 7. 竞争工具

### 7.1 无主节点首次争购

无主节点多人同轮争购固定使用灵石暗标，不允许改为直接战斗，也不建立仇敌。最高出价者支付自己的出价并取得主导权，其他人不支付。

最高出价同价时，以共享移动时间轴上更早抵达者胜出；严格同刻抵达时，使用本局稳定随机种子在同价者中裁定。不追加竞价轮次。

### 7.2 其它目标竞争

战斗与竞价是其它明确竞争事件可以调用的通用工具：

1. 明确禁止武斗的事件固定竞价；
2. 其它竞争由参与者分别选择战斗或竞价；
3. 任一参与者选择战斗，全体进入战斗；只有所有人都未选择战斗时才进入竞价；
4. 竞价最高出价者取得目标；通用支付资源、最低出价、败方支付与平价细则仍待经济和事件模板关闭。

固定地点小洞天是独立例外：不竞价、不默认 PVP，按到达顺序挑战同一入口重点 PVE。

## 8. 多人战斗顺序

道中相遇战按先到者先参战；抵达后的目标竞争战按先到者后参战。严格同刻到达时使用稳定随机结果决定相对顺序。

连续战斗保留生机、元气、神念和正常跨战斗状态；护盾每场清空。死亡战利品只在整段连续战斗结束后统一结算并归最终合法胜者，中间不产生可拾取资产。

## 9. 当前缺口

- 地点专有疗伤的首批地点、费用与恢复表；
- 通用竞价的支付资源、最低出价、败方支付和平价规则；
- 普通宗门关系与仇敌关系的完整建立、解除和效果表；
- 事件模板、代偿事件池和首批重点 PVE 入口；
- 多人阶段计时、未提交、掉线与退出规则。

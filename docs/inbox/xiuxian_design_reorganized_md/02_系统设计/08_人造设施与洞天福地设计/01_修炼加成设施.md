# 人造设施与洞天福地设计｜修炼加成设施

## 1. 当前结论

修炼加成设施是资源槽附属设施的一类，不是独立建筑槽。资源槽的通用字段、简化类型、人工扩展规则和一槽一设施类别约束，以《../07_地图节点设计.md》为准；本文只说明修炼加成设施如何读取资源槽并进入修炼、突破和维护结算。

修炼加成设施作为 RealmInputFitMatrix、ResourceEffectBalance、NodeRealmSupport、SectSupportBalance 的输入之一，影响境界段有效修炼效率，但不应绕过行动时间、资源输入、主修道功和状态压力。设施效果必须来自节点灵气、资源槽规模、设施规模、维护状态、资源消耗、权限和角色状态，不提供无来源全局倍率。

## 2. 设施范围

MVP 可先保留以下修炼相关设施类别：

- 修炼房 / 静室。
- 聚灵阵；修炼房可以内含聚灵阵，但仍属于同一设施类别。
- 洞府维护设施；个人洞府本身是 `personal_cave` 设施类型，只有在模板声明闭关、聚灵或修炼席位能力时才计入修炼加成设施。
- 灵泉维护 / 灵液收集类辅助设施。
- 加工设施：用于灵石 → 聚灵石等修炼资源前置处理。
- 突破场地 / 护法阵。

同一个资源槽只能附属一类设施。若一个 `aura_node` 已用于灵田、传送阵、市场或宗门行政设施，就不能同时承载修炼房或聚灵阵；必须经过拆除、迁移、改造或事件流程后才能更换设施类别。

若自然资源槽已被个人洞府、宗门洞府区或普通藏宝占用，也不能继续建设修炼房、静室或聚灵阵。只有清理、迁移、拆除或事件处理对应洞府 / 藏宝后，该资源槽才能重新进入修炼设施建设流程。

## 3. 资源槽接口

修炼加成设施优先读取以下资源槽：

| 资源槽类型 | 修炼设施口径 |
| --- | --- |
| `aura_node` | 常规修炼设施的主要承载位；可提供环境灵气输入、闭关席位和聚灵阵基础 |
| `material_deposit` | 只有灵泉、灵液池等模板允许时，才提供修炼资源辅助或炼丹辅助 |
| `space_site` | 可承载洞府、仓储、防护、隐蔽和休整设施；修炼加成弱于专门灵气节点，除非附属设施明确投入资源 |
| `blessed_land` | 可作为参悟、突破或特殊修炼地点，但只能使用保全、封禁、参悟、突破场地等受限操作 |
| `opportunity_site` / `special` | 只在机会窗口或定制模板允许时提供临时修炼、突破或护法机会 |

人工常规扩展出的 `aura_node` 可以用于建设修炼房、静室或聚灵阵类设施。MVP 规则为：

1. 该资源槽无特殊属性，不提供特殊相性、特殊突破机会或稀有变体。
2. 该资源槽灵气浓度低于当前地图节点平均灵气浓度。
3. 该资源槽规模可设定，影响席位、维护成本、设施规模上限和常规修炼环境输入。
4. 节点资源槽总数量在 MVP 暂不限制，但每个修炼设施仍按自身规模、维护、人力和资源消耗结算。

## 4. 缺口

- 设施模板表。
- 设施维护成本。
- 设施与节点资源槽、宗门库存、人力占用的接口。
- 设施对修炼、突破、资源加工的具体倍率。
- 资源槽品级、节点等级、资源槽规模、设施规模和设施等级之间的产能公式。

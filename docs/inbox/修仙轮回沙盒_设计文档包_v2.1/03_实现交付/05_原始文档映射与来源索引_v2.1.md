# 原始文档映射与来源索引（v2.1）

## 0. 文档定位

本文用于说明本交付包如何对应旧 sources 文档。开发人员可先读 v2.1 整理文档；需要追溯设计理由时，再回到原始文档。

---

## 1. 本版修订依据

v2.1 整包基于以下资料收束：

1. 旧开发交付包中的总览、核心体验、术语表、S1–S14 系统文档。
2. UI/UX v1.1 中的大世界地图主界面、决策 / 结算阶段、被动挂起口径。
3. 已确认的新方案：可配置回合时长、默认每回合 5 个游戏天、天级预算条、小时级内部结算、固定 / 可选投入持续行动、移除玩家宗门指令、宗门 AI 唯一持续行动。

## 3. 废弃旧入口

以下旧文档内容不再作为开发依据：

- 6 个朔望行动格。
- 初始节点 + 第一个目标节点的持续行动限制。
- 宗门即时行动域。
- 宗门经营命令。
- 宗门主行动输入、等待宗门反馈、宗门反馈冻结摘要。
- 同宗多人宗门输入不可见与冲突解析相关流程。
- `current_quarter` 作为玩家最小回合字段。

---

## 4. 保留旧原则

以下旧原则继续保留：

- S1 作为权威结算总线。
- 客户端只提交意图。
- 本地单人也走服务端结算模型。
- 全员锁定或超时托管后结算。
- 事件、战斗、突破输出结果包。
- 资产容器与日志可信。
- 后手必须有原因链。
- 大地图作为 UI 主界面核心。
- 决策阶段 / 结算阶段分离。
- 结算阶段不可主动暂停，只能被动挂起。

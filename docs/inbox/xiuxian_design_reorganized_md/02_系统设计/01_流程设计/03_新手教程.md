# 流程设计｜新手教程

## 1. 当前定位

新手教程不是强制主线，而是通过第一阶段流程模拟，让玩家从“真灵初次显化、当前角色低认知、低资源、低控制力”的状态开始，自然理解真灵名、当前角色、地图、背包、货币、行动规划、移动、事件选择、功法学习和入门检测。

教程叙事必须遵守新的主体设定：

- 玩家控制的当前角色是由真灵塑造出的当世承载者，不拥有世俗背景身份。
- 世界主线剧情直接与真灵、真灵名和真灵线索关联，不与当前角色的家族、门第、职业或凡俗履历关联。
- 初次角色可以有姓名、性别、年龄、出生位置、外观、属性和物资，但这些不是世俗身份。

## 2. 第一阶段主流程

```text
首次进入游戏房间
→ 真灵初始化：选择预设真灵名 / 自定义真灵名
→ 展示真灵背景故事
→ 创建初始化角色
→ 查看角色自知信息、初始日志与地图起点
→ 起点区域信息获取
→ 行动规划教学
→ 基础学艺 / 初始功法接触
→ 远行准备
→ 移动事件
→ 抵达入门节点
→ 执行特殊持续行动“拜入宗门”
→ 入门事件：登记姓名与来处 → 检测资质 → 判定分配 → 传授功法
→ 进入外门弟子正式修炼循环
```

说明：

- 预设真灵名进入专属剧情线，初始化角色使用预设属性、出生位置、性别、年龄与外观，只允许自定义角色姓名。
- 自定义真灵名进入通用弱剧情线，初始化角色使用通用预设属性与年龄，允许自定义角色姓名与性别，出生位置与外观随机生成。
- 教程地点应读取初始化角色的出生位置。若需要固定教学内容，应以“起点区域”“附近入门节点”“可接触学艺点”组织，不再硬绑定某个世俗出生身份。
- 云麓宗、武馆、山路等仍可作为示例内容或默认教学路线，但不是由玩家角色的世俗身份触发。

## 3. 新手教学目标

- 让玩家理解“真灵名”和“当前角色姓名”的区别：真灵名关联跨世主体和主线，角色姓名关联本世操作与社会交互。
- 让玩家理解角色状态、日志、自知信息和隐藏信息的差异。
- 让玩家理解行动规划、即时行动、移动行动、持续行动、结算、事件与结果包。
- 让玩家理解资源准备：铜钱、干粮、功法学习成本、远行补给。
- 让玩家理解功法不是纯数值：轻身功法可支持逃遁，战斗功法可改善迎战反馈。
- MVP 阶段让玩家理解资质在角色生成时已确定，并通过入门检测一次性确认和展示；机缘或特定场景中的资质信息遮蔽与再揭示属于后续扩展。
- 让玩家理解当前角色不携带世俗背景身份；后续身份、关系和宗门地位来自实际游玩结果。

## 4. 关键教程节点

### 4.1 真灵与初始化角色

教程第一步展示真灵初始化结果：

- 预设真灵名：展示专属真灵背景故事，并说明当前角色是该真灵第一次显化的当世承载者。
- 自定义真灵名：展示通用真灵背景故事，并说明该真灵进入通用弱剧情线。
- 当前角色面板只展示角色姓名、年龄、性别、出生位置、外观、已知状态与自知信息，不展示家庭背景、门第身份或凡俗职业。

### 4.2 起点区域与基础信息

玩家以低认知状态进入世界，先通过角色日志、新手提示、起点区域交互理解基础 UI 与世界信息。

起点区域可以是村庄、小镇、荒野边缘、山门外围或其他安全教学节点。无论具体地点如何，都只承担空间与资源教学，不承担世俗身份说明。

### 4.3 行动规划与提交

教学闭环：

```text
移动行动 + 持续行动
→ 提交
→ 结算
→ 事件
→ 对话选择
→ 结果包
```

### 4.4 即时交易

准备干粮通过即时行动 / 交易完成，不占用行动规划中的持续行动排期，用于教学“即时行动 vs 持续行动”。

### 4.5 远行移动事件

移动事件不是随机插曲，而是远行风险的主要承载方式。事件解决后应能返回移动主流程。

移动事件可以根据起点区域和目标入门节点变化，但不得以“玩家原本属于某个家族 / 职业 / 身份”为前置条件。

### 4.6 入门事件

抵达山门只是空间条件；身份改变来自“拜入宗门”特殊持续行动触发的入门事件。

入门事件中的登记步骤应改为登记姓名、年龄、来处和当前可公开信息。检测资质、判定分配、传授功法仍然保留，但不再登记或验证世俗背景身份。

### 4.7 真灵主线提示

第一阶段可以埋入一次轻量真灵主线提示，用于建立“世界主线与真灵相关”的认知。该提示不要求玩家完成主线，也不应压过行动、移动、资源和入门教学。

## 5. 后续承接

第一阶段结束后，下一阶段建议：

```text
外门日常
→ 选择功法修炼
→ 功法经验与境界进度
→ 宗门任务 / 资源获取
→ 首次瓶颈
→ 首次突破尝试
```

后续系统应在合适时机教学转世重修后的角色初始化：

```text
本世结束 / 主动转世
→ 结算执念
→ 自定义新角色姓名、性别、年龄、出生大致区域与外观预选择
→ 消耗执念设定属性、出生具体位置与初始物资
→ 进入新世流程
```

这部分不是首次新手教程的强制内容，但 UI 与术语应在第一阶段避免与其冲突。

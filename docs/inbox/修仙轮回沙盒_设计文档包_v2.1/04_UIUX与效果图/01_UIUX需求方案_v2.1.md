# 修仙轮回沙盒 UI/UX 需求方案（v2.1）

## 0. 设计结论摘要

本项目核心界面定义为：

> **大世界地图驱动的回合行动工作台。**

玩家不是从角色详情页、宗门后台或当前节点卡开始游戏，而是在一张可自由拖动、可缩放、带战争迷雾与节点可见性层级的大世界地图上，理解自己、宗门、节点、资源、风险、传闻和世界演化之间的关系。

新版核心调整：

```text
季度行动工作台 → 回合行动工作台
6 个朔望行动格 → 天级回合时间预算条
宗门主行动输入 → 移除
宗门经营命令 → 移除
宗门反馈等待 → 移除
宗门面板 → 查看宗门当前 AI 持续行动、库存权限、资源申请和日志
```

---

## 1. 主界面布局

```text
顶部：回合阶段条 / 结算动态进度条 + 当前角色摘要 + 房间状态
中心：可拖动 / 可缩放大世界地图
左侧：待处理变动 / 重要传闻，可折叠
右侧：目标模板 / 当前选中对象摘要 / 宗门摘要，可折叠
底部：回合时间预算条 / 行动指令规划器，可折叠
地图浮层：节点上下文面板、路线预估、战争迷雾说明、图层切换
系统入口：左下常用入口（修为、物品、功法、传讯、宗门、日志），右上设置；库存合并入物品，轮回账本合并入日志
```

---

## 2. 顶层阶段机

### 2.1 决策阶段

```text
回合开始
→ 报告阅读
→ 信息处理 / 个人即时行动
→ 个人行动规划
→ 锁定提交
```

顶部阶段条显示：

```text
回合开始 → 信息处理 / 即时行动 → 个人行动 → 锁定提交
```

### 2.2 结算阶段

结算阶段顶部切换为动态进度条：

```text
结算开始 → 移动推进 → 行动执行 → 宗门 AI → 节点事件 → 插入事件 → 结果回写 → 回合结束
```

结算阶段不能主动暂停。只有插入事件链或多人交叉事件链会进入被动挂起态。

---

## 3. 大地图画布

大地图画布必须支持：

- 拖动平移。
- 缩放。
- 点击节点。
- 悬停摘要。
- 地图图层切换。
- 战争迷雾。
- 已探索节点查看。
- 路线与可达性预估。
- 当前角色位置标记。
- 宗门势力范围或控制节点标记。
- 传闻 / 风险 / 秘境窗口标记。
- 当前目标、个人行动目标和后手感应点高亮。

地图表现形式：

```text
规则层：有向带权节点图
表现层：区域底图 + 节点 + 路线 + 势力范围 + 战争迷雾
```

---

## 4. 战争迷雾与节点可见性

推荐节点可见性：

| 状态 | UI 表现 | 可查看内容 | 可交互内容 |
|---|---|---|---|
| 未知 | 被迷雾覆盖 | 无 | 无 |
| 传闻 | 模糊节点 / 问号 / 传闻标记 | 传闻摘要、可能区域 | 可设为关注目标，不可直接行动 |
| 已探索 | 正常节点标记 | 已知基础信息、上次记录 | 可查看详情，即使当前不可达 |
| 情报过期 | 节点标记带旧情报纹理 | 历史信息 + 过期提示 | 可查看，可规划但风险提示增强 |
| 当前可见 | 高亮或清晰节点 | 当前最新可见状态 | 可查看，可规划，可执行合法交互 |
| Debug 全知 | 开发视图 | 全量状态 | 调试操作 |

已探索节点不可因不可达而隐藏。

## 5. 节点上下文面板

节点上下文面板包含三种模式：

1. **当前位置模式**：你人在这里，可执行当前位置特殊即时行动和当前位置持续行动。
2. **选中节点模式**：你正在查看这里，不要求当前可达。
3. **计划目标模式**：当前计划或目标模板正在指向这里。

顶部必须显示：

```text
当前位置：云麓宗山门
正在查看：黑石岭矿脉
计划目标：黑石岭矿脉
```

非当前位置节点不显示可直接执行的即时行动按钮，只显示：

```text
抵达后可能处理事项
```

---

## 6. 回合时间预算条

底部从旧 6 个朔望行动格改为：

```text
回合时间预算条
```

默认显示：

```text
第 1 天｜第 2 天｜第 3 天｜第 4 天｜第 5 天
```

展开后进入行动指令规划器。

行动块示例：

```text
第 1 天：赶赴镇集 + 坊市采购
第 2 天：镇集 → 黑石岭
第 3 天：探索黑石岭
第 4 天：探索黑石岭
第 5 天：探索黑石岭
```

点开可显示小时级预估，但不允许玩家手动排小时表。

---

## 7. 个人即时行动 UI

个人即时行动入口：

```text
当前位置节点上下文面板
全局事务抽屉
```

类型：

- 当前位置特殊即时行动。
- 通用个人即时行动。
- 传讯。
- 回信查看。
- 委托结果接收。
- 已完成成品接收。
- 资源领取。

特点：

- 不占用回合时间预算。
- 点击后立即提交服务器校验。
- 必须早于个人行动指令规划。
- 进入行动规划后冻结。

---

## 8. 个人行动规划器

进入行动规划后：

- 个人即时行动冻结。
- 底部展开回合时间预算条。
- 玩家通过地图点选目标节点、选择移动方式、选择持续行动。
- 系统自动生成线性行动指令队列。

推荐操作流：

```text
点击地图目标节点
→ 显示路线预估、耗时、风险、权限门
→ 加入移动指令
→ 选择抵达后持续行动
→ 选择投入天数或投入剩余时间
→ 预算条显示行动块
```

锁定前风险确认显示：

- 硬错误。
- 高风险提醒。
- 未处理高价值个人即时事务。
- 重要世界传闻。

硬错误阻止提交，提醒不阻止锁定。

---

## 9. 宗门面板

宗门面板不再包含：

- 宗门经营命令。
- 宗门主行动输入。
- 等待宗门反馈。
- 宗门主行动反馈卡。

新版宗门面板页签：

```text
宗门概览
宗门当前持续行动
库存与权限
资源申请
身份 / 贡献 / 门内声望
宗门日志与传闻
```

宗门当前持续行动示例：

```text
宗门当前重点：强化黑石岭驻守
进度：40%
预计仍需：约 3 回合
投入：人力中、材料低、灵石低
风险：边境冲突升温
可亲自介入：前往黑石岭驻守 / 协助调查
```

---

## 10. 结算阶段地图表现

结算阶段不跳转到完全独立页面。大地图仍为核心画面，用于展示：

- 玩家移动轨迹。
- 当前指令执行进度。
- 事件触发点。
- 宗门 AI 持续行动推进。
- 节点状态变化。
- 传闻生成。
- 战争迷雾 / 情报更新。

结算中不允许主动暂停。只有插入事件链或多人交叉事件链会进入被动挂起态。

---

## 11. 回合结果报告

结算结束后展示：

```text
原计划 vs 实际结果
```

示例：

```text
原计划：
第 1 天：前往镇集并采购避瘴符。
第 2 天：前往黑石岭。
第 3～5 天：探索黑石岭。

实际：
第 1 天：前往镇集，采购成功。
第 2 天：前往黑石岭途中遭遇妖兽，延误 7 小时。
第 3 天上午：抵达黑石岭。
第 3～5 天：探索黑石岭，实际投入约 2.4 天。

结果：
发现矿脉异动线索，获得少量矿材，行踪暴露上升。
```

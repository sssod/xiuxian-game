# 02_核心体验_玩家目标_设计基石_v2.2

# 核心体验、玩家目标与设计基石（v2.2）

## 0. 文档定位

本文整理核心体验层内容，用于约束后续系统、数值、UI 和内容生产。

系统实现时不要把本文当成数值表；本文只定义“为什么玩家会觉得这个游戏成立”。

---

## 1. 核心体验总命题

玩家长期追求的不是单一战斗力，而是跨世叠加后的资源获取效率。

```
修为提升
→ 接触更高阶资源
→ 提高单位时间预算收益
→ 增强生存和事件处理能力
→ 获得更高宗门身份与资源权限
→ 更容易影响宗门 AI 和世界节点
→ 布置更高质量后手
→ 失败或死亡后转化为下一世更优起点
```

因此，战斗、非战斗能力、功法、宗门职位、资质、法宝、后手、地图控制，本质上都应回到同一问题：

> 它是否让玩家在本世或下一世更高效地获取、保存、转化或保护资源？
> 

---

## 2. 主循环：个人成长

```
修炼
→ 到达瓶颈
→ 准备突破
→ 尝试突破
→ 成功进入更高阶段
→ 获得更高资源获取效率
→ 接触更高风险与更高价值窗口
→ 继续修炼
```

修炼不是简单填经验条。它是玩家将地点灵气、丹药药力、宗门资源、功法效率、角色资质、回合时间预算共同转化为修为和功法成长的过程。

丹药药力不是即时经验包。它必须依附主动吐纳、研习、休整、探索、突破事件选项等具体语境，按实际兼容小时转化为收益、风险修正或残余药性。

突破不是简单升级按钮。它是对玩家前一阶段路线选择、资源积累、风险控制、宗门支持、地点选择、功法匹配的集中审判。

---

## 3. 负反馈循环：失败与转世

核心负反馈链路：

```
尝试突破
→ 突破失败
→ 本世受损、停滞或死亡
→ 转世重修
→ 使用前世资源、失败标签、后手、账本信息塑造更好基础
→ 更高效率地回到同等修为
→ 再次冲击瓶颈
```

突破失败不应只是惩罚。它必须同时产生：

- 明确失败原因标签。
- 下一世可执行的修正方向。
- 轮回账本记录。
- 可能的后手回收目标。
- 对路线、功法、资源、突破地点、宗门关系的新理解。

理想玩家感受：

> 这一世没过关，但我知道为什么没过关。下一世我能更快回来，并用更好的基础重试。
>

## 4. 三条并行成长线

### 4.1 当世角色成长

当世角色负责承担本世行动后果，包括：

- 修为阶段。
- 功法掌握度。
- 生机、元气、神念。
- 宗门身份与关系。
- 当世库存。
- 伤势、状态、寿元压力。
- 本世探索信息。
- 当前连续行动与路线状态。

当世角色死亡后，大部分内容不默认跨世继承。

### 4.2 真灵长期成长

真灵负责长期身份感和跨世容量，包括：

- 真名。
- 真灵强度。
- 执念容量。
- 正式后手容量。
- 轮回履历。
- 道韵。
- 后手感应。

真灵强度不直接稳定提高每世修炼速度。它主要提高执念容量与正式后手容量，避免与资质和功法形成重复收益。

### 4.3 世界与宗门成长

世界不是背景菜单，而是状态机会变化：

- 节点控制权变化。
- 资源槽丰度、枯竭、污染、异变。
- 建筑建设、损坏、维护。
- 秘境窗口开启或关闭。
- 宗门库存与声望变化。
- 宗门 AI 当前持续行动推进、完成或中止。
- 传闻传播。
- 正式后手暴露或被干扰。

玩家和 AI 宗门共同推动世界演化。

## 5. 新版行动体验定位

本版玩家每回合的核心问题是：

```
上一回合实际发生了什么？
我当前是否要延续原计划？
本回合我最重要的 1～3 件事是什么？
它们大约占用几天？
哪些事件、风险或资源变化会影响行动合法性？
```

玩家不是在做小时级日程管理，而是在进行指令式取舍。

每回合默认 5 游戏天只是配置。这个尺度的目的不是世界观包装，而是降低单回合决策深度：

```
旧深度：一个长期周期内同时规划许多目标。
新深度：本回合只处理少量指令，长期行动跨回合延续。
```

---

## 6. 宗门的体验定位

宗门不是玩家本体，而是组织性资源平台。

玩家应感受到：

- 初期宗门提供庇护、基础功法、任务和最低资源入口。
- 中期玩家通过贡献、声望、职位和关键关系获得更多资源与权限。
- 后期玩家可通过身份、贡献、关键 NPC 支持、亲自介入、事件选择和资源投入，影响宗门 AI 的长期倾向。
- 玩家死亡或转世后，宗门仍然作为世界组织存在，并继续由 AI 演化。

本版不让宗门变成玩家每回合直接操作的 4X 队列。宗门同一时间只有 1 个持续行动，其他日常运营走常态结算。

高地位价值不是“多几个宗门按钮”，而是：

- 更多宗门情报。
- 更高资源申请权限。
- 更容易触发议事 / 委派 / 支持事件。
- 对宗门 AI 当前重点有更高被动影响权重。
- 更容易将个人行动转化为宗门世界影响。

## 7. 地图和世界的体验定位

地图节点应是有决策意义的地点，而不是纯地理填充。

节点有价值的原因包括：

- 影响移动耗时、危险和路线。
- 挂载资源槽、建筑槽、事件槽、隐藏层、后手层。
- 是宗门控制、影响力争夺或 AI 持续行动目标。
- 是玩家修炼、交易、探索、突破、回收后手的地点。
- 是传闻、秘境、重大事件或地图认知的锚点。

世界演化不追求完整生态模拟，而是通过节点状态、宗门 AI、事件压力、资源变化和传闻构成低成本活世界。

---

## 8. 物品和经济的体验定位

物品不是单纯奖励图标。获得物品后，玩家应自然产生选择：

- 自己使用。
- 上交宗门。
- 出售或交换。
- 修复、炼制、拆解。
- 储存为突破准备。
- 作为正式后手封存。
- 用于事件选择或战斗指令。

物品价值围绕资源效率建模：

- 提高修炼效率。
- 降低突破风险。
- 提高战斗结算质量。
- 增加行动成功率。
- 提高宗门产出或宗门 AI 行动质量。
- 支撑跨世后手。

修为丹药、悟性丹、避瘴丹、疗伤丹和定心丹的核心价值不是创造额外行动入口，而是让玩家在某个已经选择的行动里更高效、更安全或更可控地转化时间预算。

---

## 9. 事件的体验定位

常规事件的本质是：

> 系统抛出一个局面问题，玩家通过选项表达解题姿态，并承担后果。
> 

事件不能只是阅读文本，也不能只做暗骰。选项应代表不同解题姿态：

- 正面应对。
- 出奇制胜。
- 逃避推诿。
- 解构问题。
- 欺诈蒙骗。

新版事件还承担一个重要功能：

```
消耗小时、延误或提前行动、修正后续指令触发时点。
```

因此回合结束报告必须显示“原计划 vs 实际结果”，让玩家理解为什么服务端权威结算改变了行动产出。

---

## 10. 多人体验定位

MVP 多人默认：

```
分宗并行 + 间接竞争 + PvE 沙盒演化
```

玩家之间不需要直接交易、直接合作或强 PvP，也不应把决策阶段变成实时抢操作。

多人压力主要来自：

- 不同宗门 AI 对节点的争夺。
- 玩家行动改变节点资源、传闻和机会窗口。
- 宗门库存、突破资源、秘境窗口的间接竞争。
- 正式后手、遗产、世界日志和可见性导致的信息不完全。

# 物品设计｜灵石及聚灵石

## 1. 当前结论

灵石是主经济循环通货，但不是万能资源。高阶灵气需求需要通过聚灵石、阵法、设施或特殊资源转换。

## 2. 灵石

```yaml
SpiritStoneStack:
  amount: number
  owner_container_ref: string
  bind_state: string | null
  ledger_refs: list
```

规则：

- 灵石不分等级。
- 灵石可支付交易与基础修行消耗。
- 高阶需求不直接吞普通灵石，避免通胀向顶级需求无损传递。

## 3. 聚灵石

灵石加工进入 MVP，但 MVP 只打通一条路径：

```text
灵石 + 加工设施 + 时间 / 人力 / 技艺修正
→ 聚灵石
```

聚灵石规则：

- 聚灵石是独立物品，不是灵石高阶面额。
- 聚灵石拥有 Tier 与 Quality。
- MVP 主要用于引入“高密度灵气物品”的接口。
- 可作为高阶阵法、突破、洞府维护、法宝充能、特殊配方等统一高密度资源接口。
- MVP 暂不在消耗环节增加复杂阶级和品级限制。

## 4. 缺口

- 加工设施模板。
- 损耗率、时间、人力、技艺修正公式。
- 聚灵石在突破、洞府维护、阵法、法宝充能中的消耗表。

# 数值设计｜功法设计基准建模

## 1. 当前结论

功法数值分为道功与法门两条主线。道功参与修为收益与上限；法门参与能力、指令、事件选项与效率。

## 2. 道功参数

应至少建模：

- 理论最高上限。
- 掌握度当前上限。
- 单位时间效率修正。
- 灵根 / 路线标签适配。
- 资源输入兼容性。
- 突破路线标签。

## 3. 法门参数

应至少建模：

- 解锁行动标签。
- 解锁战斗指令。
- 解锁事件选项。
- 效率修正。
- 掌握度曲线。

## 4. 待补

- 道功吸收速度表。
- 掌握度经验曲线。
- 灵根相性表。
- 法门使用相性与指令效果。

## 2. 产品与单局定位

| 项目 | 当前裁决 |
| --- | --- |
| 玩家人数 | `2—4` 人 |
| 标准局长 | `90—120` 分钟；期望第 `24` 外界回合完成飞升 |
| 数值验收区间 | `20—24—28`；不是强制结束回合 |
| 终局上限 | 无系统强制最终回合、现实时间上限或替代胜者 |
| 互动基调 | 竞争为主、合作为辅；地产扩张是常态经济对抗，直接战斗是高风险升级 |
| 受众与复杂度 | 合家欢基础规则，保留功法、移动、经营与战斗构筑深度 |
| 回合特征 | 同时规划、同步移动、统一行动结算 |
| 首个主题 | 六境飞升胜利 |

玩家主动提前结束尚未产生飞升胜利的对局，其发起、同意门槛和无胜者表达仍待多人流程裁决。

## 3. 核心单局循环

```text
回合开始世界更新与即时准备
→ 隐藏规划目的地、路线、移动组合和主要行动
→ 共享时间轴同步移动、相遇与关隘结算
→ 抵达后补充对象、数量和投入
→ 独立行动或多人竞争统一结算
→ 每内部时间单位先自动修炼、后自动研习
→ 地产供养、收费、世界事件与飞升判定
```

每个正常回合，每名玩家拥有一次移动和一个主要行动。移动前锁定行动类型，抵达后补参数；未抵达则行动失效，抵达后无合法参数则行动失败并触发地点代偿事件。

回合开始可学习功法道具、调整研习位与构筑、服丹、改修、处理宗门贡献和领取订单。通用玩家交易已移除；坊市采购是主要行动。

## 4. 首个主题与成长终点

首个主题只使用：

```text
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → 飞升
```

炼气至化神各有初期、中期、后期、圆满四段，统一占本境总 CP 的 `15% / 20% / 25% / 40%`；大乘无局内小境界。标准局从炼气初期 `0%` 开始，基准首次到达为筑基 `R5`、金丹 `R9`、元婴 `R13`、化神 `R17`、大乘 `R21`、飞升 `R24`。

达到大乘后，玩家前往主题指定地点执行无参数飞升主要行动。首次达到大乘时只公告当时位置与基础身份。合法飞升开始前可被路线、事件和竞争阻拦；开始后不再失败。同轮完成且不存在阻止关系的玩家共同获胜，回合末结束对局。

## 5. 地图、地产与经济摘要

- 首轮使用一张固定六边格地图，包含四个远距离出生区域和共享竞争区域；每个出生区至少两条通往共享区的路线，不能被永久封锁。
- 只有预标记的已有建筑、已有资源节点和待开发优质地块可经营；同一节点只有一个主导宗门，不存在持续地区影响力轨道，首轮不支持有主节点常态易主。
- 五个可选宗门同局不重复；宗门是玩家经营资产与特色预设的身份包装，不限制发展路线。
- 无主节点首次争购使用灵石暗标；待开发地块购买时必须同步锁定建筑。建筑按 `R1—6 / R7—12 / R13—18 / R19+` 四级全局时序自动升级。
- 常规地产每回合末提供稳定供养，其他玩家收费只是附加收入。常规建筑以当前等级取得后约 `4—6` 回合回收基础投资为锚点；资源节点被动供养约为一次标准主动采集净收益的 `25%—35%`。
- 灵石是唯一普通货币。宗门贡献与灵石隔离，只用于多余物品回收、宗门特色兑换、请教师长和特殊建筑，精确表最后校准。
- 常规资源阶级按 `R1 / R5 / R9 / R13 / R17 / R21` 开放；物品阶级成熟、建筑自然升级和全图灵气加法是三条独立节奏线。
- 合格普通原料数量成熟默认 `×1.5` 并无状态随机取整；品质成熟默认两次取高，少数模板三次取高。五档品级为下 / 中 / 上 / 极 / 绝，绿 / 蓝 / 紫 / 金 / 红；无品质为灰框。

## 6. 行动、功法与战斗摘要

当前主要行动包括突破、购地 / 初建 / 改建、采集、坊市采购、炼丹 / 炼器订单、固定小洞天挑战、请教师长、地点专有疗伤和飞升。

普通功法掌握通过研习位自动成长：一道功位、三法门位；标准基础预算 `B = 20`。每部功法独立保存经验并显示 `0—100` 掌握度，五阶段倍率为 `0.70 / 0.85 / 0.95 / 1.00 / 1.10`。五宗门初始三部功法共 `15` 部，三套通用高阶路线共 `9` 部，首批合计 `24` 部与 `72` 项阈值内容。

切换主修只在回合开始、每回合最多一次，死亡或重伤时禁止；目标已学且阶级不低于当前主修即可，不要求最低掌握度或境界阶段窗口。改修不改变标准 CP，只按新主修重新确定有效修为，可以改变本大境界内表现，但不能改变大境界和历史最高境界。精确有效修为公式仍待裁决。

战斗采用冷却驱动、战前构筑、战中自动执行。普通途中战斗不升档；地图重点 PVE 和小洞天入口可按事件模板随回合升档；金丹、元婴、化神、大乘四场强制渡劫分别使用目标境界固定敌人，不随回合或失败次数变化。

炼气突破筑基消耗固定 `Q2` 筑基丹后确定完成。后四次消耗随机 `Q1—Q5` 破境丹并进入渡劫；品级只提供最大生命 `10% / 20% / 35% / 55% / 80%` 护劫护盾锚点。渡劫允许逃遁；失败、逃遁或死亡不保留资格，每次重试重新消耗丹药。

## 7. 小洞天、死亡与转世摘要

- 固定小洞天在 `R10` 首批投放“玩家数－1”个独立地点，之后每十回合一个；随机事件入口另算，不设单局预算帽。
- 取得小洞天只在当轮末结算一次十个内部时间单位，不连续停留。普通角色封顶于当前瓶颈；研习、恢复、丹药、炼化与寿元照常逐单位推进。
- 死亡不淘汰玩家。已学知识、掌握、历史突破、宗门贡献和地产跨世保留；当前境界 / CP、当前世属性、灵石与随身物品清空。
- 灵石与其它随身物品逐件 / 逐单位以 `10%` 成为合法战胜方战利品，其余回收。下一回合在原始出生座位转世，先取得死亡后地产收入，再把灵石补足到基础经营节点标价 `0.5` 倍下限。
- 历史上已完成的突破自动跨越，不再消耗丹药或重打渡劫。后期灵气形成基础追赶；落后者专属追赶、易主事件和退出归属仍待裁决。

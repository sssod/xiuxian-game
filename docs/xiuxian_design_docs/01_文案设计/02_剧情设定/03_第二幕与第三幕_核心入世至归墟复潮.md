# 文案设计｜剧情设定｜第二幕与第三幕：核心入世至归墟复潮

适用范围：`docs/xiuxian_design_docs/01_文案设计/02_剧情设定` 中的核心地域入世、四证合流调查、四方摊牌、四极失衡和断木再开事件。

来源说明：本文由包外草稿 `docs/inbox/mainline_outline_shanhai_duanmu_v0_2_1.md` 拆分并吸收到正式设计文档包；正式解释以本文和同目录关联文件为准，源稿只保留为历史参考。

## 1. 当前定位

本文负责第一大事件之后的中段主线：玩家无论是否轮回都进入核心地域，接触四大势力与迎墟者，并在调查旧史、宗门分裂、真名危机和四极失衡中推进至终局前置。

## 2. 内容边界

本文维护中段剧情链和玩家选择语义。势力理念的世界观来源见 `../01_世界观设定/04_当世势力与外围组织.md`；终局选择见 `04_第四幕_重定天地与结局.md`。

## 3. 拆分摘要

1. 第二幕通过主动轮回路线和不牺牲撤离路线的差异，把第一大事件后果带入核心地域。
2. 四证合流让玩家恢复、质疑或改写真灵曾经对“道”的选择，而不是寻找固定前世身份。
3. 第三幕让个人修炼、宗门经营、地图探索和归墟危机汇流，迎墟者显性化，但太初、太极、混沌和太素也可能各自走向极端。

## 4. 第二幕：核心入世（源稿 §10）

### 10.1 无论如何都进入核心地域

第一大事件后，不管玩家是否牺牲，都进入新的大阶段：**核心地域入世**。

| 路线 | 进入核心地域时的状态 |
|---|---|
| 主动轮回 | 新一世，修为较低，但天资更高，带一个可选执念，旧区域大多保留 |
| 随宗撤离 | 当前世继续，修为保留，宗门难民身份进入核心，旧区域大范围入墟 |

### 10.2 第二大阶段的主要内容

进入核心地域后，玩家开始接触四大势力与迎墟者：

| 接触对象 | 玩家首次接触形式 |
|---|---|
| 太极 | 天衡司审查撤离名单，要求登记真名 / 宗门 / 功法 |
| 太初 | 归元医盟救治撤离者，提出修复灵脉方案 |
| 混沌 | 开隙会暗中帮助未登记者进入核心或寻找失散 NPC |
| 太素 | 铸界工坊清点撤离资产、分配避墟器与债契 |
| 迎墟者 | 在难民、散修、小宗门幸存者中传播“归墟重启”思想 |

此阶段的主题从“地方求生”升级为“选择理解世界的方式”。

### 10.3 主动轮回路线进入核心后的叙事差异

玩家新一世进入核心地域，可能以以下方式开局：

- 作为小宗门幸存者的后辈。
- 被三生梦院 / 玄箓符院记录为“镇墟者转世”。
- 被天衡司列入“异常真灵延续”观察名单。
- 被太初归元宗外围组织视为可贵的镇墟气机样本。
- 被混沌开隙会认为其证明“死亡不是秩序终点”。
- 被太素记录为旧区域债契或阵材权益继承人。

叙事关键词：**低修为，高天资，有旧地保全，有真灵镇痕。**

### 10.4 不牺牲撤离路线进入核心后的叙事差异

玩家以当前角色进入核心地域，可能以以下方式开局：

- 作为有一定修为的撤离修士。
- 亲历宗门失地，对归墟有直接仇恨或恐惧。
- 被天衡司要求解释为何没有启动镇墟阵眼。
- 被小宗门幸存者评价为“保住了自己”或“保住了撤离队”。
- 被太素债契绑定，因为撤离成本需要偿还。
- 被迎墟者诱导：既然故土已失，不如承认世界不可救。

叙事关键词：**保留修为，背负失地，资源更紧，旧地入墟。**

### 10.5 四证合流调查结构

第二幕不应写成单纯身世揭秘，而是让玩家意识到：自己不是在找一个固定前世身份，而是在恢复、质疑或改写真灵曾经对“道”的选择。

| 证物 | 来源 | 指向势力 | 揭示内容 |
|---|---|---|---|
| 一炁根髓 | 断木遗址 / 灵脉根井 | 太初 | 有人试图把建木余脉重新并为一气 |
| 天衡律印 | 宗门档案 / 封绝法台 | 太极 | 绝地天通之后仍有秩序派维护封绝 |
| 无界裂片 | 秘境隐藏层 / 异兽迁徙路线 | 混沌 | 某些界隙不是自然出现，而是被人为撕开 |
| 归墟潮刻 | 海眼 / 归墟漂木 / 水脉污染 | 归墟 / 迎墟者 | 潮汐周期被人为提前，迎墟者正在行动 |
| 铸界残契 | 太素工坊 / 撤离舟 / 阵材账本 | 太素 | 四极大阵不是抽象秩序，而是需要材料、债务和维护的工程 |

玩家不必固定按顺序取得五类证物。不同路线可以先接触不同势力，形成叙事自由。

### 10.6 调查分支

#### 分支 1：宗门档案线

玩家通过宗门贡献、职位、关系、事件评价逐渐获取断木档案。档案不会给出完整真相，而是提供秩序派解释。

**内容重点：**

- 建木转封在太极档案中被称为“断木之变”。
- 重、黎名号只出现在律令、碑文、功法名中。
- 档案强调归墟倒灌与神民混杂。
- 档案回避宗门雏形争夺建木支脉的利益问题。
- 档案会把太极一系的胜利解释为“人道得存”。

**玩家选择：**

- 相信宗门档案，支持封绝。
- 质疑档案删改，寻找民间 / 遗迹证据。
- 利用档案权限换取资源。
- 将档案内容写入山海图，但保留“未考”标记。

#### 分支 2：断木遗址线

玩家探索神山、断木遗址、无影木、通天根。这里主要揭示建木不是被简单砍断，而是被封绝、分脉、镇压、转入隐藏层。

**内容重点：**

- 地上断木只是外壳。
- 地下根系仍在某些节点呼吸。
- 太初方试图用根井收束灵气。
- 太极方在遗址中留下封绝阵基。
- 太素方在阵基中留下可维护、可抵押、可拆卸的器物结构。

**玩家选择：**

- 修复局部根系。
- 加固封绝阵基。
- 拆除阵基，进入隐藏层。
- 把遗址交给宗门、太初方、散修联盟、太素工坊或自行保管。

#### 分支 3：归墟海眼线

玩家调查海眼、弱水、归墟漂木、归墟潮刻。这里要明确区分“归墟本体是灾害”和“迎墟者是反派组织”。

**内容重点：**

- 归墟潮有自然周期，但现世周期被人为缩短。
- 迎墟者偷取潮刻，制造提前潮。
- 某些被污名为“引潮”的真灵记录可能是替罪。
- 真正可审判的是引潮仪式的执行者，而不是归墟本体。

**玩家选择：**

- 净化污染。
- 利用归墟材料修炼高风险功法。
- 追查迎墟者。
- 与太极方合作封海眼，或与混沌方合作开界隙绕开封锁。

#### 分支 4：真灵旧名线

玩家通过轮回账本、真灵藏宝、山海图真灵故事发现自己的真名曾出现在不同版本的历史残痕中。山海图可以保留残缺、误读、佚名、被抹去的真名等文本风味，但不扩展成多个山海图版本互相冲突的核心玩法。

**内容重点：**

- 真灵支线是支流，不是主线门槛。
- 预设真灵看到更明确的旧史疑案。
- 自定义真灵可以通过承道接入任意真灵故事。
- 真名暴露会带来太易、太极、迎墟者等不同风险。

**玩家选择：**

- 继承旧名。
- 质疑旧名。
- 改写旧名。
- 利用旧名换取传承、资源或谈判筹码。

### 10.7 第二幕结尾事件：四方摊牌

玩家集齐至少三类关键证据后，四方势力不再只是伏笔，而开始主动接触玩家。

| 势力 | 向玩家提出的说法 | 给出的短期好处 | 隐含代价 |
|---|---|---|---|
| 太初方 | “差异是灾源，归一可救山海。” | 修复灵脉、提高修炼效率、降低资源冲突 | 真灵差异被吞并 |
| 太极方 | “越界是灾源，封绝可保众生。” | 稳定突破、减少归墟潮、获得宗门权威 | 天路更难恢复，自由受限 |
| 混沌方 | “边界是牢笼，无界才有新生。” | 开启隐藏层、突破权限限制、获得古法 | 身份和地图稳定性下降 |
| 太素方 | “先让阵基不裂，再谈谁对谁错。” | 物资、撤离、器械、节点封存 | 债务、抵押、器物化风险 |
| 迎墟者 | “山海已死，归墟是重启。” | 获得高风险力量、快速清除敌对节点 | 污染扩散，世界崩坏 |

第二幕结尾可以安排一次“断木残响审问”：玩家进入断木遗址深处，听见多段互相矛盾的残响，但没有任何一段是完整历史。玩家获得结论：真相不是单一档案，而是现世必须做出的选择。

## 5. 第三幕：四极失衡 / 归墟复潮（源稿 §11）

### 11.1 幕目标

把个人修炼、宗门经营、地图探索和主线危机合并。归墟潮汐周期缩短、神山秘境频繁显现、异兽迁徙冲击宗门节点、宗门争夺断木遗址与山海残传、高阶突破触发“天路不通”，迎墟势力显性化。

### 11.2 第三幕世界状态

| 系统 | 变化 |
|---|---|
| 地图 | 海眼、神山、断木遗址、隐藏层出现周期性灾变；更多节点变为灰影或失联 |
| 宗门 | 进入紧急状态，资源申请、节点驻守、档案权限与主线绑定 |
| 功法 | 山海高阶功法与开辟级终局功法残篇开始出现，但仍以数值、资源、路线、宗门权限、世界事件状态为前置 |
| 真灵 | 真名暴露风险提高，真灵藏宝与无主遗留设施被多方争夺 |
| 山海图 | 记录人物志、地方志、功法志、真灵故事进度，给道韵或执念奖励，但不触发大事件 |
| 归墟 | 自然潮 + 人为提前潮叠加，世界压力上升 |
| 四极大阵 | 阵法完整度下降，灵力储备降低，飞升截流机制变得更明显 |

### 11.3 四极失衡表现

| 方位 | 失衡表现 |
|---|---|
| 太极北极 | 封绝过强，修士突破失败增多，真名审查扩大 |
| 太初东极 | 灵脉归元化扩散，小宗门功法传统被吞并 |
| 混沌南极 | 界隙叠合，隐藏层失控，地图节点错位 |
| 太素西极 | 阵基材料短缺，撤离债务激化，器物化风险上升 |
| 四海外缘 | 归墟潮压持续逼近，迎墟者活动频繁 |

### 11.4 主线事件链

#### 事件 M3-1：三潮并发

同一周期内发生三类潮：

1. **灵脉归根潮**：太初方启动根井，多个节点灵气被抽回。
2. **界隙错位潮**：混沌方撕开隐藏层，地图节点重叠。
3. **归墟黑潮**：迎墟者提前引发海眼喷发。

太极方随即启动区域封绝，宗门进入战时管理。太素方则开始按契约优先修复“高价值阵基”。

**玩家选择：**

- 帮太极方封锁灾区。
- 帮宗门疏散与净化。
- 追查迎墟者源头。
- 偷入被封锁遗址寻找终局功法残篇。
- 与太初 / 混沌 / 太素方暂时交易，换取解决局部危机的能力。

#### 事件 M3-2：宗门分裂

宗门内部出现五派：

| 宗门内部派别 | 倾向 |
|---|---|
| 归元派 | 接受太初方援助，主张统一灵脉管理 |
| 律令派 | 接受太极方管制，主张扩大封绝 |
| 开界派 | 接受混沌方技术，主张打开隐藏层找新路 |
| 铸界派 | 接受太素债契和器械，主张先保资产、阵基与撤离通道 |
| 镇潮派 | 坚持归墟是灾害，优先清剿迎墟者与净化海眼 |

玩家的宗门关系不再只是资源系统，而成为主线局势变量。

#### 事件 M3-3：真名狩猎

随着玩家掌握旧史，真名成为多方争夺目标：

- 太初方需要真名作为归一阵的气机样本。
- 太极方需要真名登记越界风险。
- 混沌方需要真名作为溶解身份的钥匙。
- 太素方可能把真名相关藏宝、后手、洞府权益计入债契。
- 迎墟者需要真名作为引潮祭品或污名工具。
- 太易中立势力可能提供藏名、改名、抹名服务，但有代价。

**真名状态建议：**

| 状态 | 效果 |
|---|---|
| hidden 隐名 | 支线安全，部分高阶线索不可见 |
| declared 宣名 | 获得谈判资格与旧传承入口，风险上升 |
| exposed 暴名 | 四方主动追踪，真灵支线推进加快但危机加剧 |
| rewritten 改名 | 改写前世评价，部分旧后手失效 |
| erased 抹名 | 避开部分追踪，但山海图与轮回账本出现空洞 |

#### 事件 M3-4：迎墟者显性化

迎墟者不再伪装，开始破坏封绝结构。他们宣称：

> 绝地天通只是把伤口缝住。  
> 山海不是被救下来的世界，而是迟迟不肯沉没的残骸。  
> 与其让太初吞并、太极囚禁、混沌撕裂，不如归墟重启。

迎墟者应成为第三幕的主要外显敌人，但不是唯一终局敌人。因为太初、太极、混沌也各自可能走向极端。

#### 事件 M3-5：终局 NPC 入场

| 终局 NPC | 入场方式 | 可敌对 / 可非敌对条件 |
|---|---|---|
| 太初残响 / 一炁君 | 从归元根井苏醒 | 玩家若保护差异化灵脉则敌对；若大量归一节点可临时合作 |
| 太极残响 / 天衡君 | 从断木律印显化 | 玩家若多次越界、暴名、破坏封绝则敌对；若镇潮贡献高可合作 |
| 混沌残响 / 无界君 | 从界隙叠合处显形 | 玩家若加固边界则敌对；若开界路线高可交易 |
| 太素铸界者 | 从阵基账本、神材炉心或铸界府显形 | 可交易，也可能因债契、器化风险与玩家冲突 |
| 迎墟祭主 / 归墟化潮主 | 从海眼祭仪中出现 | 默认敌对，可审判、击败、镇封，不建议做可加入势力 |
| 太易卜者 | 真名危机时出现 | 可帮助藏名，也可能抹除玩家身份 |
| 太始源胎 / 异兽王 | 异兽迁徙线出现 | 视玩家生态处理而定 |

### 11.5 第三幕结尾事件：断木再开 / 天根入海

迎墟者启动“天根入海”仪式，试图让归墟潮沿断木余根倒灌。太初方趁机启动万气归根，太极方启动永断天衡，混沌方启动无界重开，太素方试图接管阵基与节点资产。四个方案同时撕扯同一套断木遗产。

玩家必须先解决迎墟者制造的即时灾害，再进入终局选择。这样可确保归墟压力始终是世界级灾害，而不是普通阵营谈判。

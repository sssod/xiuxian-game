本文负责沉淀《山海断木纪》主线草稿中的最高优先级世界观裁决，供世界背景、主线剧情、支线剧情和系统约束共同读取。本文只记录已经纳入正式包的文案设计口径，不继续引用包外草稿作为运行时设计依据。

## 2. 内容边界

本文维护世界观层面的高层裁决：太极胜利、绝地天通代价、三大核心宗门、归墟性质、外围沦陷、轮回抉择和归墟地图表现。具体历史过程见 `03_天地源流与绝地天通.md`；地理与阵法见 `02_地理格局与四极镇墟大阵.md`；剧情幕结构见 `../02_剧情设定/01_主线总纲与阶段结构.md`。

## 3. 拆分摘要

1. 太极一系是上一次归墟大劫的最大胜利者，但胜利代价是飞升旧路被封，修士无法绕过终局条件直接举霞飞升。
2. 大乘期是普通修为段终点，渡劫 / 飞升准备保留为终局阶段；飞升后上界和真仙期不进入 MVP 或正式版常规地图内容。
3. 太初、太极、混沌三大核心宗门与迎墟者构成主线主要载体；太素承担四方镇守、阵材与交易职能。
4. 归墟是自然灾害，迎墟者才是可审判、可击败的显性反派组织。
5. 第一大事件以外围沦陷和主动轮回抉择为主线转折，轮回同时承担数值重开与世界保全意义。

## 4. 核心裁决摘要（源稿 §0）

### 0.1 新增最高优先级裁决

1. **太极一系是上一次归墟大劫的最大胜利者。** 他们以绝地天通、天地分层、律令封绝、四极镇墟大阵应对并阻止了那一次归墟灾难。
2. **绝地天通的最大玩家层代价是此世无法沿旧路直接举霞飞升。** 大乘期是普通修为经验条终点，渡劫 / 飞升准备是终局阶段。飞升后上界和真仙期不作为 MVP 或正式版常规地图内容；飞升可以作为特定终局路线的结局之一。
3. **太极、太初、混沌各有一个核心宗门。** 这三大核心宗门是当世人道三极，是主线剧情的主要载体之一，但 MVP 阶段玩家不可直接接触其本山，只通过外署、巡使、分院、代理宗门、外围组织与理念影响间接接触。
4. **太极、太初偏传统意义正道，混沌偏传统意义魔道。** 但本作不设定魔修必须以人为祭而修行。三大势力与三大宗门是理念之争、行事风格之争，而非简单善恶二元。
5. **三大核心宗门加迎墟者才是主线剧情的主要载体。** 太初、太极、混沌是三大主要势力源头；迎墟者是借归墟行动的显性反派；归墟本体仍是自然灾害，不是可外交、可加入的势力。
6. **预设真灵剧情支流衍生一圈小型宗门与组织。** 这些小势力分布于低等级外围地图节点，是玩家初期活动、真灵支线、宗门感情锚点和第一大事件的主要承载者。
7. **世界地理以昆仑神山为中心。** 太极、太初、混沌、太素四大势力镇守四个方向；外围环绕一圈小型势力；再往外是大海；大海外为归墟肆虐之地。
8. **整个世界由上一次归墟灾难时设置的阵法保护。** 随着时间流逝与灵力流失，阵法衰败，归墟灾难再次迫近。迎墟者活动频繁，最早从世界边缘出现归墟痕迹。
9. **第一个大事件是外围沦陷。** 小型宗门撤离，玩家进入世界核心地域，开始接触太极、太初、混沌、太素与迎墟者势力。
10. **第一大事件高潮是玩家选择是否消耗此世修为镇压一地。** 若选择牺牲，则主动轮回，解锁一个可选执念，本地区域不会完全沦陷；若不牺牲，则保留修为随宗门撤离，但宗门原所在区域大范围被归墟侵入。
11. **无论玩家如何选择，都会进入新的大阶段与新世界区域。** 区别是保留当前修为，还是获得更高天资重新开始。
12. **归墟入侵优先表现为地图节点隐藏 / 失联。** 主动轮回保护大部分地图节点，因此真灵藏宝大概率仍在；不轮回则旧区域大量节点被隐藏，藏宝线索更容易失联。

### 0.2 与既有基线保持一致的口径

1. 玩家不是太初、太极、混沌本身，也不是大道或神明本体，只是一缕开辟余气在当前世的承载者。
2. 真灵名、前世线索、山海图条目只提供剧情入口、相性提示、旧史压力和收藏目标，不锁定功法、阵营或结局。
3. 山海图是统一成就 / 图鉴 / 收藏系统，不是多个宗门版本互相冲突的史书，也不是主线关卡入口。
4. 归墟本体是自然灾害；可对抗、可审判、可击败的是迎墟者、借墟者、破界者，以及被归墟污染后仍保留意志的个体。
5. 绝地天通 / 建木断仍是山海最大前史事件。颛顼、重、黎不作为可直接交互神话 NPC，也不提供回到过去改变建木断结果的玩法，只通过档案、碑文、残响、宗门解释、功法名与遗迹痕迹出现。

## 5. 已吸收到正式包的新增裁决项（源稿 §20）

1. **太极定位修订**：太极一系是上一次归墟大劫的最大胜利者，其绝地天通方案成功保住现世，但造成此世无法沿旧路直接举霞飞升。
2. **修为阶段裁决**：大乘期是普通修为经验条终点；渡劫 / 飞升准备保留为终局阶段，承接终局势力、终局 NPC、大阵状态和归墟潮压博弈。飞升后上界和真仙期不作为 MVP 或正式版常规地图内容，飞升可作为特定结局之一。
3. **核心宗门裁决**：太极、太初、混沌各有一个核心宗门，是当世人道三极；MVP 阶段玩家不可直接进入三大核心宗门本山。
4. **正魔口径裁决**：太极、太初偏传统正道，混沌偏传统魔道，但不设定魔修必须以人为祭；三者是理念与行事风格之争。
5. **太素地理裁决**：太素作为四方镇守之一，承担铸界、阵材、法宝、交易与大阵维护功能，但不是三大理念宗门之一。
6. **世界地理裁决**：世界以昆仑神山为中心，四方镇守，外围小宗门环，再外为大海与归墟肆虐之地。
7. **第一大事件裁决**：第一个大事件为外围沦陷，小宗门撤离，玩家选择是否消耗此世修为镇压一地。
8. **轮回引导裁决**：主动轮回可解锁一个可选执念，获得更高天资，并保护大部分本地区域节点；不轮回则保留修为，但旧区域大范围被归墟隐藏。
9. **归墟地图机制裁决**：归墟入侵优先表现为地图节点隐藏 / 失联，而不是普通敌方占领。主动轮回保护节点后，真灵藏宝大概率仍保留。
10. **主线载体裁决**：三大核心宗门与迎墟者是主线剧情主要载体；预设真灵支线作为小支流，最终汇入主线终局。

**版本**：v2.1  
**日期**：2026-04-30  
**定位**：根据已确认的“可配置回合时长 + 指令式个人行动 + 小时级内部结算 + 宗门 AI 唯一持续行动”方案，对 sources 中整套设计文档进行统一修订后的开发交付包。

---

## 1. 本交付包用途

本交付包用于替代旧版以“季度 / 6 个朔望行动格 / 宗门主行动输入”为核心的文档口径。新版统一为：

```text
可配置时长的回合制
+ 个人线性行动指令
+ 天级 UI 时间预算条
+ 小时级服务端内部结算
+ 宗门 AI 自行演化
+ 每宗门同一时间最多 1 个宗门持续行动
```

核心变化：

1. **玩家最小推进单位统一称为“回合”**，当前默认每回合 5 个游戏天，但该值仅是配置。
2. **取消 6 个朔望行动格**，改为按“天”显示回合时间预算条。
3. **玩家不做小时级排程**，只输入少量线性行动指令；小时只用于服务端结算。
4. **持续行动拆为固定执行时间与可选投入执行时间**。
5. **移除玩家宗门即时指令、宗门建议、宗门提议、宗门主行动决策流程**。
6. **宗门由 AI 自行维护唯一宗门持续行动**，玩家通过个人行动、身份、贡献、资源申请和事件结果间接影响宗门。
7. **字段统一**：将旧 `quarter / action_slot / tick` 等语义拆为 `turn_id / world_day / world_hour / hour_tick / macro_period_id` 等字段。

## 4. 本版优先级

开发引用规则时，建议优先级如下：

```text
当前 Figma 主界面 artifact（仅限节点级布局 / 组件位置 / 最新视觉状态）
→
v2.1 UI/UX 需求方案
→
v2.1 术语表 / 字段统一
→ v2.1 房间回合推进 / 行动经济 / 宗门 AI
→ v2.1 运行时状态 / 字段迁移表
→ v2.1 其他核心系统文档
→ v2.0 回合行动经济与宗门 AI 持续行动方案
→ 旧版 sources 文档
```

旧版中出现以下口径时，以本包为准：

- “季度作为玩家最小行动回合”。
- “6 个朔望行动格”。
- “tick 默认对应 15 天或行动格”。
- “玩家宗门即时指令 / 宗门主行动建议 / 宗门提议 / 宗门决策阶段”。
- “每季度一个宗门主行动”。
- `quarter / action_slot / tick` 混用的字段。

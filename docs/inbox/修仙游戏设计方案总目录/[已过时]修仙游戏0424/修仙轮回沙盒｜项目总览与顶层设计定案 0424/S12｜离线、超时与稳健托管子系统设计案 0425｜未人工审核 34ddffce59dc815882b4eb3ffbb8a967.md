## 1. 子系统定位

S12 定义玩家未及时提交决策时，系统如何不阻塞房间，同时不自动把玩家玩坏。

一句话定位：

> S12 负责在玩家离线或超时时生成保守、低风险、可解释的替代行动。
> 

## 2. 托管原则

托管目标优先级：

```
保命 / 避险
> 不暴露核心后手
> 延续安全连续状态
> 巩固修炼或基础修炼
> 维持低风险宗门职责
> 休整 / 警戒 / 停留
```

托管不是自动收益最大化，也不是 AI 帮玩家推进主线。

## 3. 禁止托管行为

托管不得主动执行：

- 高风险突破。
- 主动计划转世。
- 主动叛宗。
- 主动发动宗门战争。
- 主动暴露核心后手。
- 主动回收高风险后手。
- 主动进入高危秘境。
- 主动进行强 PvP 或袭击其他玩家。
- 消耗稀有不可逆资源。
- 做重大不可逆路线选择。

## 4. 允许托管行为

托管可以执行：

- 闭关修炼的安全延续。
- 巩固境界。
- 基础修炼。
- 休整 / 疗伤。
- 警戒 / 停留。
- 领取基础俸禄。
- 维持低风险宗门职责。
- 洞府和后手维护。
- 自动防御。
- 保命撤退。

## 5. 托管触发

S12 由 S1 调用。

触发条件：

1. 玩家在决策阶段超时未提交。
2. 玩家明确设置本季度托管。
3. 房间恢复后存在缺失决策。
4. 插入事件链需要离线玩家做低风险响应。

托管生成的行动必须走 S3 行动合法性校验。

## 7. 托管行动生成规则

最小生成顺序：

1. 检查角色是否危险：重伤、资源枯竭、高危节点、敌对事件。
2. 若危险，优先休整、撤离、警戒或请求宗门保护。
3. 若存在安全连续状态，尝试延续。
4. 若无连续状态，选择当前位置可执行的基础修炼、巩固或低风险职责。
5. 若当前位置无安全行动，选择停留 / 警戒。

## 8. 离线世界影响

离线玩家可以受到世界影响，但不能被系统自动玩坏。

允许：

- 宗门局势变化影响其职位和资源环境。
- 节点事件改变当前位置附近风险。
- 库存、传闻、世界窗口变化。

禁止：

- 离线期间被托管主动带去死亡。
- 离线期间自动暴露核心正式后手。
- 离线期间自动投入不可逆稀有资源。

## 9. 事件链中的托管响应

如果离线玩家被动卷入事件：

- 先选择保守防御 / 撤离 / 稳定。
- 不主动追击、冒险、献祭或赌突破。
- 战斗中可使用低消耗基础防御、逃遁、保命道具，但避免消耗稀有资产，除非将死亡或重大损失。

## 10. 托管日志

每次托管必须写入：

- 托管原因。
- 生成行动。
- 被禁止的高风险行为。
- 资源消耗。
- 事件结果。
- 玩家回归后的摘要。

玩家回归时应看到可读报告，而不是只看到状态变化。

## 11. 与其他系统的接口

- S1：触发托管、接收托管计划。
- S2：读取角色状态、死亡风险、真灵与后手保护信息。
- S3：校验并结算托管行动格。
- S5：读取低风险宗门职责。
- S9：判断是否可消耗保命道具。
- S10：处理被动事件响应。
- S11：保护正式后手，不自动暴露。
- S14：持久化托管设置和日志。

## 12. MVP 验收标准

1. 玩家超时后房间可继续推进。
2. 托管能生成合法 S3 行动计划。
3. 托管不会主动突破或做高风险不可逆选择。
4. 托管可以保护重伤角色或高危位置角色。
5. 玩家回归后能看到托管摘要。

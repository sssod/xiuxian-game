# 文案设计｜世界观设定｜地理格局与四极镇墟大阵

适用范围：`docs/xiuxian_design_docs/01_文案设计/01_世界观设定` 中的世界地理、四极镇守、镇墟大阵和修为上限世界观解释。

## 1. 当前定位

本文负责说明山海世界的空间结构、昆仑神山中心格局、四方镇守、外围宗门环、四海与归墟边界，以及四极镇墟大阵如何解释飞升旧路封锁、大乘后渡劫期、终局飞升边界和飞升后上界 / 真仙期不作为常规地图内容的口径。

## 2. 内容边界

本文只维护地理与大阵的文案设定。地图节点的系统状态、归墟隐藏节点和藏宝可达性由 `../02_剧情设定/07_系统数值交互约束.md` 承接，并最终进入地图节点系统文档。

## 3. 拆分摘要

1. 世界以昆仑神山为中心，四方镇守、外围小宗门环、四海缓冲和归墟荒外构成主地理层级。
2. 四极镇墟大阵是上次归墟大劫后保存现世的核心结构，同时封死通天旧路。
3. 大乘期不是世界最高境界，而是普通修为段的终点；其后保留渡劫 / 飞升准备作为终局阶段。四极镇墟大阵解释的是为何不能直接举霞飞升，以及飞升结局必须通过终局条件争取；飞升、上界和真仙期不作为常规地图内容。

## 4. 世界地理与四极镇墟大阵（源稿 §2）

### 2.1 地理总结构

世界采用“昆仑为心、四极镇守、外围宗门环、四海缓冲、归墟荒外”的同心结构。

```text
                归墟肆虐之地
        ─────────────────────
                  外海 / 四海
        ─────────────────────
              外围小宗门环带
        ─────────────────────
    太初东极      昆仑神山      太素西极
                  / 中枢阵眼
    混沌南极                    太极北极
        ─────────────────────
              四极镇墟大阵内域
```

### 2.2 五层地理说明

| 层级 | 名称 | 功能 | 主线阶段 |
|---|---|---|---|
| 第 0 层 | 昆仑神山 | 世界中心、旧神庭门户、四极大阵中枢阵眼 | 中后期才真正接触 |
| 第 1 层 | 四极镇守区 | 太极、太初、混沌、太素镇守四方 | 第一大事件后进入 |
| 第 2 层 | 外围小宗门环带 | 玩家初期活动区，小型宗门、真灵支流组织、低等级节点 | MVP 初期核心舞台 |
| 第 3 层 | 四海缓冲带 | 阵法与归墟之间的潮汐缓冲区，海眼、潮刻、漂木多发 | 第一大事件前兆区 |
| 第 4 层 | 归墟肆虐之地 | 世界之外 / 世界边缘被归墟侵蚀的不可稳定地带 | 前中期不可常规进入 |

### 2.3 四方镇守建议

| 方位 | 镇守势力 | 核心意象 | 地图风格 | 主线功能 |
|---|---|---|---|---|
| 东方 | 太初 | 初阳、一气、生发、万气归源 | 青金色灵脉、根井、气泉、神木残影 | 灵脉修复、万气归一、太初正道 |
| 北方 | 太极 | 北辰、天衡、律令、封绝 | 冰白黑金、法台、律碑、封阵 | 绝地天通秩序、现世正统、飞升封锁 |
| 南方 | 混沌 | 无界、裂隙、反开辟、越界 | 赤黑荒原、界隙、错位山门 | 魔道 / 非正统路线、破界、反秩序 |
| 西方 | 太素 | 神材、铸界、法宝、交易 | 白金矿山、铸炉、商盟、器城 | 阵法维护、撤离物资、器械与债务 |

太素西极不是第四个主线理念宗门，而是四极大阵的材料、器械、法宝、交易与阵基维护中枢。这样既保留太素偏中立、可交易、可走向众生器化风险的定位，也满足地理上四大势力镇守四方的结构需求。

### 2.4 四极镇墟大阵定位

**四极镇墟大阵**是上一次归墟大劫后留下的世界级防护结构。其总纲来自太极一系的绝地天通理念，核心目的不是让修士飞升，而是把世界从归墟倒灌中保留下来。

它有三重功能：

1. **隔绝归墟**：把归墟潮挡在四海之外。
2. **封绝通天**：切断建木旧路与上层神庭路径。
3. **抽取飞升余力**：把原本足以支持举霞飞升的天地上升之力，转化为维持大阵的镇墟之力。

因此，绝地天通不是“太极恶意断人前程”，而是一次成功但代价极重的世界手术。它使现世得以存续，也使此世修士无法沿旧天路直接举霞飞升。

### 2.5 太极为何是最大胜利者

上一次归墟大劫中，各方都给出过方案：

| 势力 | 大劫中的方案 | 结果 |
|---|---|---|
| 太初 | 以万气归一压回归墟裂口 | 局部有效，但会吞并差异，难以被所有宗门接受 |
| 太极 | 绝地天通、天地分层、四极镇墟 | 成功保住现世，成为最终方案 |
| 混沌 | 打破旧界，借无界重开寻找新路 | 风险过高，被视为扩大灾难 |
| 太素 | 铸造阵基、法器、镇墟材料 | 成为大阵维护者与战后利益中枢 |
| 迎墟者前身 | 接受归墟重启 | 被定为叛逆与灾害协助者 |

所以现世并不是“多势力均势的普通世界”，而是**太极方案胜利后的世界**。太初、混沌、太素都仍有强大影响，但它们是在太极秩序框架下分守四方、各怀旧案。

### 2.6 大乘之后的渡劫与飞升边界

玩家普通修为段建议定为：

```text
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 / 飞升准备
```

**大乘期是普通修为经验条的终点，不是世界最高境界。渡劫 / 飞升准备保留为终局阶段。**

大乘圆满之后不再开放普通经验条式境界成长，也不把道韵或执念改造成渡劫期专属纵向养成。这个阶段的稳定成长和决策重心转为以下方向：

| 大乘后终局准备方向 | 作用 |
|---|---|
| 渡劫 / 劫数与世界博弈 | 与终局势力、终局 NPC、四极大阵状态、归墟潮压和世界事件互动，决定是否具备飞升、另开、续断或其他终局路线条件 |
| 法门 / 道功深修 | 深度研习既有法门，补全或掌握更高阶法门、终局道功或终局功法残篇，形成大乘后主要纵向成长方向 |
| 外物战力筹备 | 追求法宝、符箓、阵器、丹药等外物，提升终局交锋、探索、生产和宗门任务处理能力，但不增加新境界 |
| 终局道功后转世重修 | 获得或锁定终局道功、关键法门或终局路线条件后，以死亡 / 转世换取新世更稳定的成长路径、资源规划和结局准备 |
| 宗门职位 / 世界影响 | 改变区域、宗门、节点、NPC 立场和终局变量，使玩家能参与或干预终局势力行动 |
| 轮回与地图保全 | 用死亡 / 转世作为横向成长、路线重开和地图保全机制，不把前世普通修为、职位或普通资产直接搬到下一世 |
| 道韵 | 真灵层长期可选追求，可影响承道方向、真灵路线、支线奖励或结局权重；可遇不可求，不能作为稳定数值目标规划 |
| 执念 | 与轮回深度绑定的转世初始化选项，不是渡劫阶段才开启的成长轴；其预算、消费和关闭由真灵与轮回规则维护 |

道韵与执念从游戏开始到终局都可以成为玩家追求项，但它们属于真灵与轮回层，不是进入渡劫期后才出现的普通纵向养成。执念尤其应服务转世重修和新一世初始化；道韵可以作为承道和终局权重的稀有奖励，但不应被设计成稳定可刷的阶段目标。

渡劫期不应被移除，但也不建议做成普通经验条和普通地图阶段。飞升、上界和真仙期不作为 MVP 常规地图内容，正式版也不将其纳入可反复经营、探索和推进的常规地图内容；飞升可以作为接木、另开等终局路线的结局之一，也可以作为失败标签、神话传闻、终局目标、结局演出或极少数前史残响。

### 2.7 大乘后渡劫失败标签

大乘圆满后进入渡劫 / 飞升准备时，系统可显示类似失败标签：

| 标签 | 文本含义 |
|---|---|
| 天路不通 | 建木旧路已封，无法上达神庭 |
| 霞光不至 | 举霞之力被四极大阵截流 |
| 重黎律响 | 绝地天通律令自动响应，阻止越界 |
| 断木反照 | 建木残脉显影，但不形成完整通道 |
| 镇墟夺灵 | 玩家飞升所需灵力被大阵抽走，用于抵御归墟 |

这些标签解释的不是“境界被删除”，而是旧天路被四极镇墟大阵截流。玩家越接近渡劫与飞升准备，就越直接感受到太极胜利的代价，并被推向终局势力与 NPC 博弈。

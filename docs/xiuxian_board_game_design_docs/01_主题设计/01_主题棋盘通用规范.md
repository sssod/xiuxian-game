# 主题设计｜主题棋盘通用规范

适用范围：故事主题棋盘与通用修仙棋盘框架之间的职责、主题配置包和显式覆盖边界。

## 1. 设计定位

本游戏是一套可承载多个故事主题的多人修仙棋盘框架。通用框架维持回合、成长、移动、行动、经济、经营、竞争与自动战斗的共同规则；主题棋盘负责地图、内容、初始预设和胜利目标。

主题可以改变故事与地图机会，但不能静默改写通用行为。确需例外时，必须在主题文档中声明覆盖条目、原因、适用范围和玩家提示。

## 2. 通用框架职责

通用框架负责：

- `2—4` 人房间和同步回合阶段；
- 回合开始即时行动、隐藏规划、同步移动、行动结算与回合末结算；
- 六边格路径、移动时间、相遇、事件、战斗与竞价；
- 修为、境界、突破、寿元、死亡、转世和跨世保留；
- 道功、法门、研习、招式、法宝、丹药和物品品级职责；
- 灵石、节点收费、资源生产、物品成熟和宗门贡献边界；
- 特定经营节点、建筑等级、主导权和持续供养；
- 房间大厅、阶段计时、未响应安全默认、掉线 / 重连 / 托管、即时阶段退隐与全体一致主动结束；
- 主题胜利条件触发与回合末统一判定接口。

## 3. 主题棋盘职责

每个主题必须自带：

1. 地图拓扑、出生区域、地点类别、特殊连接与关隘；
2. 地点事件、途中事件、固定事件、随机事件和重点 PVE；
3. 可投放道功、法门、招式、法宝、丹药、资源、建筑、敌人与奖励；
4. 属性、境界、灵气、移动、经济和战斗数值表；
5. 胜利目标、终局地点、终局事件、公告和共同胜利规则；
6. 宗门预设、特色资源、贡献目录与主题专有覆盖项；
7. 完整初始状态配置包。

## 4. 初始状态配置包

同一主题默认使用等强度的公共底盘，不制造随机先天强弱。配置至少包含：

| 配置组 | 必填内容 |
| --- | --- |
| 成长起点 | 大 / 小境界、当前进度与绝对 CP |
| 宗门预设 | 可选宗门、初始道功、移动法门、战斗法门与掌握度 |
| 研习与构筑 | 默认研习位、已装配招式、法宝位与特色例外 |
| 当前世属性 | 属性、三条状态、年龄、寿元、灵根与负面状态 |
| 经济与物资 | 初始灵石、普通物资、破境丹与宗门特色资源 |
| 地图座位 | 固定出生区域、出生点组合与宗门外观映射 |

首个飞升主题已确认统一从炼气初期 `0%` 开始，三部宗门初始功法掌握度均为 `25`，公共灵石锚定基础节点标价 `1.5` 倍，不赠送破境丹，并使用统一属性底盘；详细数值和仍待配置项见《[局长与成长节奏](../03_数值设计/01_局长与成长节奏.md)》。

## 5. 主题覆盖规则

主题覆盖必须：

1. 明确指出被覆盖的通用规则和新结果；
2. 不用内容模板暗中改写所有玩家都应知道的基础行为；
3. 在开局或对应事件开始前展示；
4. 不破坏同步结算、支付与产出可追溯性、跨世资产归属或胜利判定；
5. 不依赖旧正式包、阶段稿、handoff 或实现代码解释。

未在主题中显式重述或链接到本包权威专题的包外规则均不生效。

## 6. 首个主题的配置状态

飞升主题的局长、六境、统一开局、宗门数量、固定地图结构、主要行动、经济 / 地产框架、渡劫、转世和多人韧性基础闭环已经确认。当前标准多人配置为：目标席位满员且全员准备后 `10` 秒开局；`60 / 90 / 45 / 30` 秒阶段时限加每人 `180` 秒思考储备；`60 / 180` 秒断线保护；MVP 无策略托管；连续掉线 `10` 分钟进入待退隐；主动结束须全部未退隐玩家亲自一致同意。

仍未完成的是首张地图逐节点表、五宗门特色内容、`S0 / 1A / 境界 CP / 属性 / 移动 / 价格 / 战斗` 绝对表、功法与物品内容、敌人、事件、UI 内容与双语文本。专属追赶、外交和动态关隘障碍范围仍需裁决或明确延期。

这些缺口必须在对应阶段门中显式登记，不能由制作期默认填补。

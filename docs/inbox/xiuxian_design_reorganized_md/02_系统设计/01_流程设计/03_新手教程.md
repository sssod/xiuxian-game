# 流程设计｜新手教程

## 1. 当前定位

新手教程不是强制主线，而是通过第一阶段流程模拟，让玩家从“低认知、低资源、低控制力”的凡人少年开始，自然理解角色、地图、背包、货币、行动格、移动、事件选择、功法学习和入门检测。

## 2. 第一阶段主流程

```text
初次创建真灵
→ 以 10 岁凡人少年投生
→ 村庄信息获取
→ 行动格教学
→ 武馆学艺
→ 远行准备
→ 山路移动事件
→ 抵达云麓宗山门
→ 执行特殊持续行动“拜入宗门”
→ 入门事件：登记身份 → 检测资质 → 判定分配 → 传授功法
→ 进入外门弟子正式修炼循环
```

## 3. 新手教学目标

- 让玩家理解角色状态、日志、自知信息和隐藏信息的差异。
- 让玩家理解行动格、即时行动、移动行动、持续行动、结算、事件与结果包。
- 让玩家理解资源准备：铜钱、干粮、功法学习成本、远行补给。
- 让玩家理解功法不是纯数值：轻身功法可支持逃遁，战斗功法可改善迎战反馈。
- 让玩家理解资质不是开局全公开，而是在入门检测、机缘或特定场景中揭示。

## 4. 关键教程节点

### 4.1 村庄与基础信息

玩家以低认知状态进入世界，先通过角色日志、新手提示、村庄交互理解基础 UI 与世界信息。

### 4.2 行动规划与提交

教学闭环：

```text
移动行动 + 持续行动
→ 提交
→ 结算
→ 事件
→ 对话选择
→ 结果包
```

### 4.3 即时交易

准备干粮通过即时行动 / 交易完成，不占用季度行动格，用于教学“即时行动 vs 持续行动”。

### 4.4 远行移动事件

移动事件不是随机插曲，而是远行风险的主要承载方式。事件解决后应能返回移动主流程。

### 4.5 入门事件

抵达山门只是空间条件；身份改变来自“拜入宗门”特殊持续行动触发的入门事件。

## 5. 后续承接

第一阶段结束后，下一阶段建议：

```text
外门日常
→ 选择功法修炼
→ 功法经验与境界进度
→ 宗门任务 / 资源获取
→ 首次瓶颈
→ 首次突破尝试
```

## 6. 缺口

- 新手任务具体文本、UI 高亮、引导顺序尚未定。
- 云麓宗、武馆、山路事件的内容表未定。
- 新手失败分支（杂役、记名、被拒、凡俗路线）只作为后续分支保留。

# 数值设计｜修为境界与期望游玩时间建模

## 1. 当前结论

标准修士修炼年限是世界观背景墙，不应直接变成玩家现实等待时间。玩家通过主动搜集、集中和消耗资源，把标准年限压缩成少量游戏年的有效修炼收益。

## 2. 修为绝对值

修为绝对值是角色当前累计修为规模的稳定数值，字段名为 `cultivation_points`。它用于小境界 / 大境界阈值、收益结算、NPC 成长速度校准、突破开启条件和调试展示。

表格字段和公式字段可使用 `cp_` 前缀表示 cultivation points，但正文优先写“修为绝对值”，避免直接使用缩写造成歧义。

修为绝对值不直接线性换算成战斗力。战斗表现还必须读取境界倍率、小阶段倍率、根基质量、主修道功、状态、装备和战斗模板。

推荐大境界圆满阈值按约 ×5 递增：炼气 1,000、筑基 5,000、金丹 25,000、元婴 125,000、化神 625,000、炼虚 3,125,000、合体 15,625,000、大乘 78,125,000。

## 3. 小境界修为绝对值上下界

小境界阈值使用修为绝对值上下界，而不是在系统设计文档中维护比例表。本节是小境界修为上下界的唯一信源；其他文档只引用本节，不重复维护比例表。

配置原则：

1. 每个小阶段都有独立的修为绝对值下界 `cp_lower_bound` 与上界 `cp_upper_bound`。
2. 玩家界面显示该小阶段自身进度 `0%-100%`，由当前 `cultivation_points` 在该阶段上下界之间换算。
3. 不同小阶段的修为绝对值跨度可以不同，允许后续按节奏、资源密度、瓶颈强度和玩法内容逐段定制。
4. 第一大境界默认分 9 层；第二大境界开始默认分初期 / 中期 / 后期 / 圆满四段。
5. 下表是默认种子配置，不是硬编码比例；后续平衡可直接改每一行上下界。

炼气默认种子：

| 小阶段 | 修为绝对值下界 | 修为绝对值上界 | 设计含义 |
| --- | ---: | ---: | --- |
| 1 层 | 0 | 30 | 快速建立第一次修炼反馈 |
| 2 层 | 30 | 70 | 延续新手反馈 |
| 3 层 | 70 | 120 | 进入稳定吐纳节奏 |
| 4 层 | 120 | 180 | 需要初步资源或地点选择 |
| 5 层 | 180 | 270 | 中段成长确认 |
| 6 层 | 270 | 390 | 开始拉长单层跨度 |
| 7 层 | 390 | 550 | 后段资源经营压力上升 |
| 8 层 | 550 | 750 | 接近第一次瓶颈 |
| 9 层 | 750 | 1,000 | 圆满与筑基准备 |

筑基默认种子：

| 小阶段 | 修为绝对值下界 | 修为绝对值上界 | 设计含义 |
| --- | ---: | ---: | --- |
| 初期 | 1,000 | 2,000 | 刚入境界，战力质变但根基未厚 |
| 中期 | 2,000 | 3,000 | 稳定期 |
| 后期 | 3,000 | 4,200 | 主要战力成型 |
| 圆满 | 4,200 | 5,000 | 准备突破，瓶颈、资源和风险成为核心 |

后续大境界默认可沿用四段结构，但不要求复用筑基的跨度比例。每个大境界应根据期望游玩时间、资源投放、宗门权限、节点强度和突破准备内容单独配置修为绝对值上下界。

显示进度换算：

```text
minor_stage_display_progress =
  clamp(
    (cultivation_points - cp_lower_bound)
    / (cp_upper_bound - cp_lower_bound),
    0,
    1
  )
```

## 4. 玩家现实体验

玩家主线成长体验按境界线性增长，而不是指数增长。F1 中 1 游戏年约 12 分钟现实时间；玩家核心玩法不是挂机，而是创造高价值闭关条件。

## 5. 阶段预算

玩家首次突破到某大境界后，世界激活对应阶段预算。预算打开提供资源机会，不自动赠送修为。

## 6. 维护说明

本文是小境界修为绝对值上下界的当前维护入口。若后续调整境界阈值、单个小阶段跨度、显示进度换算或大境界圆满阈值，应直接更新本文，并同步检查修炼公式文档中对 `cp_lower_bound / cp_upper_bound` 的引用是否仍然成立。

## 9. 包内规则

1. 一项详细规则只设一个专题维护位置，其他文档不复制完整正文。
2. 未决内容必须显式标记，不得用“建议”“默认”伪装成用户裁决。
3. 本包必须自解释；包外来源只出现在来源说明或维护记录中。
4. 同名概念不代表规则继承；采用内容必须在本包重新表述。
5. 当前阶段不写程序状态机、数据结构或实现机制。
6. 稳定信息职责进入交互文档；节点级布局与视觉细节以后续 UI artifact / Figma 为准。

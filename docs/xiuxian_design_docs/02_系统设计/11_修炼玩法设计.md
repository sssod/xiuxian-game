# 系统设计｜修炼玩法

## 1. 设计定位

修炼玩法负责玩家如何通过行动、资源、环境、功法和状态管理推进修为。它回答“玩家做什么、看到什么、如何规划和止损”，不负责定义每小时收益公式、境界段数值表或页面具体布局。

修炼不是挂机等待。本文维护主动吐纳、闭关修炼、自动运转、研习功法、巩固修为、体内药性消化、资源输入、残余效果、F1 低交互消化和玩家反馈边界。境界结构、CP / 法力公式、功法成长、丹药物品、持续状态和页面表达由对应文档维护。

## 2. 当前结论

1. 玩家主动修炼以行动规划为入口；修为丹药可以从物品入口直接服用，但只创建体内药性，不即时发放完整修为。
2. 主动吐纳是获得主 CP 的主要行动；研习功法获得目标功法经验，不直接获得 CP 或法力。
3. 自动运转提供少量被动收益，通常可触发小境界升级，但不能完成大境界突破。
4. 巩固修为允许在当前大境界任意时点主动执行，用于填充当前大境界巩固 CP 条，提高当前大境界纯度和法力；它不替代主动吐纳推进境界。
5. 体内药性由兼容修为增长流逐步消化；主动吐纳和闭关修行片段效率最高，自动 / 被动运转低效消化，修为事件是否消化由事件模板声明。
6. 正常吐纳、正常功法运转和常规闭关中的自然修行不默认增加经脉压力；经脉压力主要来自丹药、灵材、符箓、阵法灌注、强行吸收外源灵气和不适配高阶资源。
7. 资源输入仍可采用行动内折叠项；已服用药性、残余效果和经脉承载在角色面板或行动规划器中常驻提示。
8. CP 表示角色当前累计标准修为点，字段名为 `cultivation_points`；境界推进看 CP，战斗出力和突破短板提示主要看法力。
9. 法力由当前及历史大境界记录按 `CP × 纯度 × 道功放大系数` 派生；普通巩固修为只能修改当前大境界纯度，不能补历史大境界。
10. 洞天 / 时间阵法闭关不是免费收益；玩家必须绑定资源年、功法、寿元承载、风险阈值和中断策略，资源不足时仍耗寿但低效。

## 4. 核心循环或触发入口

玩家通过指令管理入口或修为相关页面规划修炼行动。修炼的基础循环是：

```text
在 N1、事件、宗门、地图、市场和 NPC 互动中创造高价值修炼条件
→ 规划主动吐纳、闭关、资源输入或巩固修为
→ 服务端校验行动、地点、状态、功法和资源输入
→ 按世界小时与实际兼容小时结算
→ 在 F1 中快速消化低交互等待
→ 通过小境界反馈、瓶颈提示和突破准备调整下一轮经营
```

常见入口包括：

1. 行动指令队列中提交主动吐纳、闭关修炼、研习功法、巩固修为、疗伤或显式托管。
2. 修为页面查看进度、瓶颈、风险、残余效果和突破准备，并跳转到可执行行动。
3. 角色页面查看经脉压力、根基、伤势、心魔、残余药性和寿元等影响修炼的状态。
4. 宗门、洞府、地图节点、设施、事件或 NPC 互动为修炼提供地点、资源、护法、机会窗口或限制。

中断点包括行动被事件打断、角色状态恶化、资源释放结束、残余药性散逸、进入瓶颈、触发小境界升级、达到突破准备语境、F1 被同步处理事件（P0）或交锋中断，以及 C1 追赶后需要重新提示行动结果。

## 5. 规则与状态

### 5.1 行动类型

| 行动 | 玩家意图 | 主要收益 | 玩法边界 |
| --- | --- | --- | --- |
| 主动吐纳 | 投入时间推进当前境界段 | 修为进度、高效消化体内药性、资源输入转化 | 是体内修为药性最高效的常规消化流；只读取主修道功掌握度，不增加掌握度 |
| 闭关修炼 | 长时间低交互修炼 | 批量推进修为、消化体内药性、环境收益和资源年 | 可进入 F1；内部按修行片段或兼容小时结算 |
| 自动运转 | 非吐纳状态下的低额自然推进 | 少量修为、低效消化体内药性或稳定性收益 | 不能完成大境界突破；不主动消耗未服用丹药 |
| 研习功法 | 学习或提高道功 / 法门掌握 | 功法经验、可修上限、提示型或知识型收益 | 不直接给修为 |
| 巩固修为 | 提高当前大境界纯度 | 填充巩固 CP 条、提高当前大境界纯度和法力 | 当前大境界任意时点可执行；不增加主 CP，不推进境界，不增加功法研习度，不补历史大境界纯度 |
| 突破准备 | 为大境界突破集中处理短板 | 资源、地点、护法、状态、法力和当前大境界纯度准备 | 不等同于开启突破 |
| 显式托管 | 玩家主动设置低交互保守行动 | 低收益、低风险、减少离线损失 | 不主动发起高风险突破 |

### 5.2 主动吐纳

主动吐纳是修为推进的核心行动，也是常规最高效的体内药性消化流。玩家选择持续时间、地点、主修道功和兼容资源输入后，系统按实际兼容小时结算。

主动吐纳读取：

1. 当前境界与小阶段。
2. 当前主修道功和掌握度。
3. 所在节点灵气、设施、机会窗口和宗门支持。
4. 角色资质、伤势、心魔、经脉压力、药性容量和当前大境界纯度语境。
5. 行动内选择的资源输入。
6. 角色体内已经激活的药性状态、经脉承载和叠加限制。

主动吐纳不应被设计成“立刻获得修为”的按钮。即使角色体内已有药性，修为收益也必须随主动吐纳实际执行小时、转化效率、相性和经脉承载逐步结算。

正常主动吐纳本身不增加经脉压力。只有体内药性、额外外源资源、强行灌注、不适配资源、污染环境或带伤冲修等来源，才可能增加经脉压力或其他状态压力。

主动吐纳、闭关修炼和自动运转不增加当前主修道功的功法掌握度。若玩家希望提升道功或法门掌握，必须通过研习功法等功法系统行动承接。

### 5.3 自动运转

自动运转表示角色在多数非吐纳、非突破、非重伤状态下维持的低额修行。

规则：

1. 自动运转可以产生少量修为或稳定性收益。
2. 自动运转可以触发普通小境界升级。
3. 自动运转不能完成大境界突破。
4. 自动运转不应消耗玩家未服用、未绑定或未显式选择的关键资源。
5. 自动运转可以低效消化已经服用并允许被动消化的体内药性，但效率明显低于主动吐纳和闭关修行片段。
6. 自动运转结果应进入日志，但普通 UI 不需要展示完整数值公式。

自动运转的目的不是替代主动吐纳，而是让连续世界中角色不会因为没有显式闭关就完全停摆。

### 5.4 巩固修为

巩固修为是独立于主 CP 推进的修炼选择。它可在当前大境界任意时点主动执行，不要求当前小阶段已满、不要求进入瓶颈，也不要求突破准备已开启。它用于填充当前大境界巩固 CP 条，提高当前大境界纯度，并由此提高当前大境界法力。

它可以用于：

1. 提高当前大境界纯度。
2. 提高当前大境界法力。
3. 在突破前改善“修为进度够但法力偏虚”的短板。
4. 选择性收束残余修为药性，减少散逸或压力风险；巩固过程使用与主动吐纳类似的环境 / 体内药性输入流程，不新增专门的巩固资源类型。

巩固修为不能用于：

1. 增加主 CP。
2. 推进当前境界或小阶段。
3. 增加道功或法门研习度。
4. 修改已经锁定的大境界纯度。
5. 把残余修为药性无条件直接转化成主 CP。
6. 免费修复所有压力和伤势。
7. 绕过大境界突破开启条件。

当角色体内存在稳定残余药性时，巩固修为默认不自动消耗；界面必须让玩家明确选择“保留药性”或“收束药性”。刺激型或强制释放型药性应强提示风险，建议继续主动吐纳、闭关修炼或巩固修为收束。

玩家反馈示例：

```text
修为进度已达标，但法力偏虚。巩固修为可提高当前大境界纯度，从而提升法力。
```

```text
本大境界已进入下一阶段，上一大境界修为记录已锁定，普通巩固无法再补足历史纯度。
```

### 5.5 丹药服用与体内药性

修为类丹药可以直接服用。服用后消耗对应丹药，并在角色持续状态系统中创建体内药性状态。直接服用不等于即时获得完整修为。

```text
服用修为丹药
→ 校验丹药、容器、状态、经脉承载、叠加组和禁用语境
→ 创建体内药性
→ 后续由兼容修为增长流逐步转化、散逸或触发副作用
```

体内药性至少记录：

1. 来源丹药、药性类型、剩余有效时长或剩余额度。
2. 经脉负载、叠加组、同类上限和互斥规则。
3. 最适合的消化流，例如主动吐纳、闭关修行片段。
4. 是否允许自动 / 被动运转低效消化。
5. 散逸、刺激、反噬或事件锁定策略。

兼容消化口径：

| 修为增长流 | 是否消化体内药性 | 体验定位 |
| --- | --- | --- |
| 主动吐纳 | 是 | 专注修炼，高效吸收体内药性 |
| 闭关修炼中的修行片段 | 是 | 长时间低交互批量吸收 |
| 自动 / 被动运转 | 是 | 非专注状态下缓慢消化，不替代主动吐纳 |
| 主动运转 | 待裁决 | 若未来作为独立行动或法门流存在，可作为中高效引导药性渠道 |
| 修为类事件 | 由事件模板声明 | 只消化事件结算前已经激活的体内药性，不允许事后服丹回溯放大事件收益 |
| 移动、交易、普通社交 | 默认否 | 不属于修为增长流 |
| 战斗或突破交锋中 | 默认否 | 不提供交锋中即时服丹涨修为入口，特殊模板必须单独声明 |

药性结束可以表现为完整转化、稳定残余、缓慢散逸、刺激性散逸、强制释放或事件锁定。巩固修为可以收束残余药性、降低散逸或副作用风险，但不把残余修为药性直接转为主 CP。

经脉承载限制同服丹药时，不只看数量，也看总负载、药性类型、叠加组和强刺激互斥。示例：

```text
当前经脉承载：60 / 100
清灵丹负载：20
赤焰速元丹负载：50

可以再服用清灵丹：60 + 20 <= 100
不能再服用赤焰速元丹：60 + 50 > 100
```

### 5.6 行动资源输入

行动资源输入是玩家在规划某个行动时选择额外投入一类资源。资源只在行动实际执行期间按兼容小时生效，并进入该行动的结算管线。

示例：

```text
行动：主动吐纳 2 天
额外输入：木髓液 × 1

行动：研习《青木养真诀》1 天
额外输入：启悟丹 × 1

行动：探索毒瘴谷
额外输入：避瘴丹 × 1
```

行动资源输入不改变行动本身类型：

1. 主动吐纳仍然是主动吐纳。
2. 研习功法仍然是研习功法。
3. 探索、移动、治疗、突破事件选项仍然保留原语境。
4. 资源只是挂载输入，不成为默认独立行动入口。

修为丹药默认不再通过主动吐纳行动输入项挂载；它从丹药详情或储物空间直接服用，形成体内药性。事件或行动模板若明确声明“现场服丹”选项，应按事件 / 行动资源输入校验，但仍不得即时发放完整修为或回溯已结算结果。

### 5.7 修为丹药规则

修为类丹药的当前口径是“直接服用生成体内药性”。主动吐纳、闭关修行片段、自动 / 被动运转和明确允许的修为事件再按不同效率消化药性。

合法：

```text
直接服用清灵丹，形成 12 小时体内药性；随后主动吐纳 6 小时消化其中一部分。
闭关前查看体内药性和经脉承载，确认本次闭关预计消化清灵丹药性。
灵泉事件选项明确允许现场服用清灵丹，并只从该选项生效后计算药性。
```

非法：

```text
即时服用清灵丹，立即获得完整修为。
单独执行丹药炼化 12 小时。
事件完成后服用清灵丹，回溯放大刚才的修为事件收益。
战斗或突破交锋中临时服丹，直接改写已结算阶段。
```

修为增长结算中存在两条输入流：

| 输入流 | 玩法含义 |
| --- | --- |
| 环境灵气流 | 节点灵气、资源槽灵气、资源槽附属设施如修炼房 / 聚灵阵 / 灵液池维护设施等，受道功环境灵气吸收上限和状态限制 |
| 体内药性流 | 已服用丹药持续释放的定额灵气包，主要受药性容量、体魄承载、服用规则和释放时长限制，最终仍按道功转化率生成 CP 或巩固填充 |

修为丹药不是提高节点灵气浓度、提高聚灵阵效果或简单提高最终倍率，而是先成为体内药性，再在兼容修为增长流中释放额外灵气输入。丹药不直接即时增加法力；法力由 CP、纯度和道功放大系数派生。

### 5.8 残余效果

当行动时间短于资源完整有效时长、行动被事件打断，或资源只消耗了部分兼容小时，系统生成残余效果。

残余效果应表达：

1. 资源名称。
2. 剩余可生效小时。
3. 当前稳定性。
4. 后续可承接行动或消化流。
5. 散逸、反噬或经脉压力风险。

稳定残余示例：

```text
体内仍有未尽药性：清灵丹，约 6 小时。
执行主动吐纳、闭关修炼或允许消化的自动运转可继续承接。
若长时间不处理，药性可能散逸。
```

刺激型残余示例：

```text
体内仍有烈性药性：赤焰速元丹，约 4 小时。
非修炼行动期间可能快速散逸并造成经脉压力。
建议：继续主动吐纳、闭关修炼或巩固修为收束。
```

### 5.9 F1 与低交互消化

闭关修炼、主动吐纳、研习功法、巩固修为、疗伤和显式托管等长期低交互行动可以按规则进入 F1。

F1 的玩法意义：

1. 压缩现实等待。
2. 快速消化玩家已创造的高价值修炼条件。
3. 让低交互行动不阻塞多人房间体验。

F1 不改变数值单位。修炼、资源输入、残余效果、压力变化和小境界判定仍按世界小时与实际兼容小时结算。

洞天、时间阵法和宗门时间阵中的闭关必须额外声明：

```text
局部时间域配置；
预计主观年数；
资源可支撑年数；
资源不足年份处理；
预计寿元消耗；
功法研习与道功修炼时间拆分；
心魔 / 经脉 / 药性 / 阵法风险阈值；
出关、中断和无安全默认时的处理策略。
```

闭关承诺不消除事件。F1 中处理等级为 `summary / auto` 的闭关相关事件和低风险预设结果可写入结果摘要；重大心魔、突破契机、资源耗尽且无预设、洞天受袭、控制权变化、公共决策和高风险不可逆选择必须中断到 N1 / B1 / P0。

资源不足时，角色仍按所在时间域消耗寿元，但修为收益大幅降低，并提高心魔、经脉、枯坐和状态恶化风险。普通 UI 必须提示“资源不足，继续闭关会耗寿低效”。

## 8. UI 展示边界

普通玩家 UI 应优先展示可决策信息：

1. 当前小阶段自身进度。
2. 当前法力、巩固 CP 条，以及角色属性页 / 修为详情中的当前大境界纯度。
3. 本次行动预计收益区间。
4. 当前体内药性、剩余时间、预计消化量和散逸风险。
5. 是否会消耗行动资源输入。
6. 经脉承载、药性容量、经脉压力、伤势或心魔是否接近风险阈值。
7. 是否接近瓶颈或突破准备语境。
8. 巩固修为、疗伤、继续吐纳、处理药性或换地点等可执行修正路径。
9. 若涉及洞天 / 时间阵法，展示现实预计耗时、外界预计经过时间、洞天内预计修炼年数、预计寿元消耗、资源可支撑年数、资源不足年份、预计有效修炼年数和本次 F1 中断策略。

丹药的直接服用入口属于丹药详情、储物空间或快捷使用确认；修炼行动界面负责展示体内药性预计消化量、经脉承载和风险。行动资源输入仍放在具体行动界面内，采用行动内折叠项。玩家选择具体行动后，只显示与该行动兼容的额外资源输入。

主动吐纳界面示例：

```text
行动：主动吐纳
计划投入：12 小时
体内药性：
- 清灵丹：剩余 12 小时，主动吐纳预计高效消化

可用额外资源输入：
- 木髓液：适配木系道功，释放稳定

预计本次消化：清灵丹 12 / 12 小时
```

如果行动时间不足：

```text
行动：主动吐纳
计划投入：6 小时
体内药性：清灵丹，完整药性 12 小时
预计本次消化：6 / 12 小时
剩余：约 6 小时药性，将暂留体内；自动运转可低效消化，长时间不处理可能散逸
```

不采用修为页默认全局资源栏作为修炼配置主入口，避免修为页变成背包搜索和倍率堆叠界面。丹药详情和储物空间可以提供直接服用确认，但必须显示体内药性、经脉负载、叠加限制和“不即时获得完整修为”的提示。已有体内药性和残余效果仍应在角色面板或行动规划器中常驻提示。

Debug / QA 信息不进入普通 UI，例如完整公式追踪、原始效率倍率、裁剪前后倍率、境界段内部 ID、完整随机权重和后台状态枚举。

## 9. MVP 范围

MVP 应实现：

1. 主动吐纳、闭关修炼、自动运转、研习功法、巩固修为和显式托管的基础行动语义。
2. 主动吐纳读取地点、主修道功、角色状态、体内药性和玩家显式资源输入，并按实际兼容小时结算。
3. 修为类丹药可直接服用并生成体内药性；服用不即时获得完整修为。
4. 主动吐纳、闭关修行片段和自动 / 被动运转可按不同效率消化体内药性；修为事件是否消化由事件模板声明。
5. 正常修行不默认增加经脉压力；丹药、灵材、符箓、阵法灌注、强行吸收外源灵气和不适配资源可增加经脉负载或压力。
6. 行动中断、药性未完全释放或转化效率不足时生成或保留残余效果，并提示后续可承接行动和风险。
7. 闭关、吐纳、研习、巩固修为、疗伤和托管按房间规则进入 F1 候选。
8. 普通 UI 展示进度、预计收益区间、体内药性、经脉承载、资源消耗、残余效果、风险阈值和可修正路径。
9. 洞天 / 时间阵法闭关的资源年、寿元、风险和中断策略摘要。

MVP 不实现：

1. 复杂多资源自动配比、背包全局资源搜索或自动最优修炼方案。
2. 玩家未直接服用或显式选择时自动消耗关键丹药、符箓、灵石或稀有材料。
3. 残余药性被巩固修为无条件直接转化为主 CP。
4. 自动运转完成大境界突破。
5. 完整高阶修炼事件链、长期宗门护法协作和复杂 C1 重算 UI。

## 10. 验收约束

1. 任意修为类丹药都不能在服用确认时直接提供完整修为进度；必须先成为体内药性，再由兼容修为增长流逐步消化。
2. 体内药性和修炼资源只在兼容修为增长流、兼容行动或明确允许的事件中按有效小时释放；行动中断时必须保留已消耗、未消耗和残余效果边界。
3. 主动吐纳、研习功法和巩固修为的收益类型必须区分，不能互相替代。
4. 主动吐纳、闭关修炼和自动运转不得写入道功掌握经验、功法掌握经验或掌握等级变化。
5. 自动运转可以推进普通小境界，但不得完成大境界突破。
6. 巩固修为不能增加主 CP、推进境界、增加功法研习度、修补历史大境界纯度，也不能免费清除所有压力、伤势或风险。
7. F1 只压缩低交互等待；内部可批量结算，但不得跳过资源、寿元、压力、事件和结果包。
8. 洞天内主观时间不足资源支撑时，必须耗寿低效并提高风险，不能继续高效修炼。
9. 普通 UI 必须展示玩家做决策所需的收益、消耗、残余和风险信息，不展示 Debug / QA 公式追踪。
10. 所有字段和接口建议必须保持系统设计、数值设计和交互设计分工，不把公式表或 UI 节点坐标写回本文。

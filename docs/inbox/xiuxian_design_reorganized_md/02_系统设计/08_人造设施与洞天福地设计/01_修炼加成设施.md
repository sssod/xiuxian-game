# 人造设施与洞天福地设计｜修炼加成设施

## 1. 当前状态

当前 Library 中未检索到修炼加成设施的完整设施表。本文件只整理接口和约束。

## 2. 当前可确定口径

修炼加成设施作为 RealmInputFitMatrix、ResourceEffectBalance、NodeRealmSupport、SectSupportBalance 的输入之一，影响境界段有效修炼效率，但不应绕过行动时间、资源输入、主修道功和状态压力。

## 3. 可能设施类型

- 宗门静室。
- 聚灵阵。
- 灵脉节点设施。
- 洞府维护设施。
- 加工设施：用于灵石 → 聚灵石。
- 突破场地 / 护法阵。

## 4. 缺口

- 设施模板表。
- 设施维护成本。
- 设施与节点、宗门库存、人力占用的接口。
- 设施对修炼、突破、资源加工的具体倍率。

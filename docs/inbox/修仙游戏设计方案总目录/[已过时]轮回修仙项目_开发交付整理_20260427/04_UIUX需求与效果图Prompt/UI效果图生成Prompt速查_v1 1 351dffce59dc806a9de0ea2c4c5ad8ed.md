# UI 效果图生成 Prompt 速查

**版本**：v1.1

**用途**：从 UI/UX 需求稿快速生成 ChatGPT / 图像工具可用的界面提示词。

**画幅默认**：PC 横屏 16:9，1920×1080。

**视觉默认**：古典修仙卷轴感 + 清晰策略面板 + 克制装饰 + 中高信息密度 + 分层折叠 + 地图观感优先。

**核心变化**：主界面从“当前所在地节点卡为中心”改为“大世界地图画布为中心”；新增战争迷雾、地图图层、结算动态进度条、结算被动挂起态、原计划 vs 实际结果面板等组件。

不要显示完整宗门面板，不要显示可编辑行动规划器，不要显示其他玩家输入。

## 28. 负向约束通用补充

所有 Prompt 可按需追加以下负向约束：

```
不要做成 MMORPG 热血战斗 HUD。
不要做成动作游戏快捷栏。
不要做成纯视觉小说对话框。
不要做成现代金融仪表盘。
不要做成手机竖屏界面。
不要让角色立绘占据主要空间。
不要显示其他玩家输入、投票过程或提交状态。
不要显示 Debug ID、数据库字段、随机 roll。
不要让当前节点卡占据中心主视觉。
不要隐藏已探索但当前不可达的节点。
不要在结算阶段显示主动暂停按钮。
```

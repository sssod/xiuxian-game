# 人造设施与洞天福地设计｜修炼加成设施

## 1. 当前状态

当前 Library 中未检索到修炼加成设施的完整设施表。本文件只整理接口和约束。

## 2. 当前可确定口径

修炼加成设施作为 RealmInputFitMatrix、ResourceEffectBalance、NodeRealmSupport、SectSupportBalance 的输入之一，影响境界段有效修炼效率，但不应绕过行动时间、资源输入、主修道功和状态压力。

MVP 阶段，修炼加成设施不是独立建筑槽。它必须附属于一个合法资源槽，并读取该槽的资源类型、品级、节点等级、规模上限、维护状态和控制权。普通灵气节点属于 `aura_node` 资源槽，可以建造修炼房、静室、聚灵阵或同类修炼设施；修炼房可以包含聚灵阵，但仍占用该资源槽唯一设施类别。

同一个资源槽只能建造一类设施。设施的规模、等级、维护状态和服务名额可以变化，但不能在同一资源槽内同时叠加修炼房、炼丹房、矿场和仓储等多类设施。

## 3. 可能设施类型

- 宗门静室。
- 聚灵阵。
- 灵脉节点设施。
- 洞府维护设施。
- 加工设施：用于灵石 → 聚灵石。
- 突破场地 / 护法阵。

## 4. MVP 资源槽对应

| 资源槽类型 | MVP 可建设施类别 | 说明 |
| --- | --- | --- |
| 灵气节点 | 修炼房 / 静室 / 聚灵阵类修炼设施 | 修炼房可内含聚灵阵；提供环境灵气输入和闭关席位 |
| 灵泉 / 灵液池 | 灵泉维护 / 灵液收集 / 炼丹辅助设施 | 可以提供修炼环境输入或炼丹辅助，不等于直接发放修为 |
| 洞府空间 / 可建空间 | 洞府维护 / 仓储 / 防护阵设施 | 以储物、隐蔽、防护和休整为主 |
| 洞天福地 | 保全 / 封禁 / 参悟 / 突破场地类操作 | 属于不易改造资源，通常不允许常规修炼房替换 |
| 灵田 / 药谷 | 灵植园 / 药园 | 主要产出材料，不作为修炼房基础槽 |
| 矿脉 | 采矿场 / 炼矿前置设施 | 主要产出矿石或炼器材料，不作为修炼房基础槽 |

## 5. 缺口

- 设施模板表。
- 设施维护成本。
- 设施与节点资源槽、宗门库存、人力占用的接口。
- 设施对修炼、突破、资源加工的具体倍率。
- 资源槽品级、节点等级、设施规模和设施等级之间的产能公式。

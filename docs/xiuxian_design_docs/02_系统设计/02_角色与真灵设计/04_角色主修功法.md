# 系统设计｜角色主修功法

## 1. 设计定位

角色主修功法负责维护当前世角色“以哪一门道功作为修炼路线核心”的运行时规则。本文中的“主修功法”是玩家界面和旧文档常见泛称；规则层精确名称为“主修道功”。只有道功能成为主修，法门不能设为主修。

本文是角色修为状态与道功模板之间的桥梁文档，负责主修道功设置、更换窗口、锁定记录、小境界升级约束、大境界突破读取口径和相关数据字段。不重新定义道功、法门、功法载体、修炼公式、境界数值表或突破交锋完整流程。

玩家层面上，主修道功让“选择修炼路线”成为当前世重要决策：玩家不是只选择一个收益倍率，而是在选择当前大境界的可修上限、资源适配、突破路线标签、奖励结构和失败风险来源。

## 2. 当前结论

1. 角色同一时间只能有一个主修道功；未设主修道功时，角色不能获得正常修为增长。
2. 主修道功只允许由已学会的道功承担；法门不能设为主修，也不能决定修为上限或突破模板类型。
3. 常规改修窗口只在大境界第一小阶段开放，离开第一小阶段后，本大境界主修路线锁定。
4. 每个大境界需要记录最终锁定的主修道功，并附带本大境界 CP、纯度、法力放大系数、巩固条和法力快照，用于后续读取突破路线标签、奖励结构、失败标签池和历史法力。
5. 小境界升级必须受当前主修道功支持范围限制；自动运转可以触发普通小境界升级，但不能完成大境界突破。
6. 大境界突破读取当前大境界最终锁定的主修道功记录；临近突破时不得临时换功规避挑战。

## 4. 核心循环或触发入口

主修道功围绕“学习、设置、修炼、锁定、突破读取”循环维护。

1. 学习：角色通过完整道功载体研习入门，创建对应 `MethodState`。
2. 设置：玩家在允许窗口内选择已学会且支持当前阶段的道功设为主修。
3. 修炼：主动吐纳、闭关和自动运转读取当前主修道功，结算 CP 推进、法力派生和当前可修上限；不增加道功掌握度。
4. 升级：小境界进度达标时，系统校验当前主修道功是否支持下一小阶段。
5. 锁定：角色离开大境界第一小阶段后，当前大境界主修记录锁定。
6. 突破：大境界突破读取当前大境界最终锁定的主修道功记录，而不是临时读取玩家刚切换的功法。

常见中断点包括未设主修、目标道功未学会、目标不是道功、当前阶段不受支持、角色状态禁止换修、当前大境界改修窗口已关闭、突破模板缺失或突破前置条件不满足。

## 5. 规则与状态

### 5.1 主修道功定义

主修道功是当世角色当前正在运转、并以内化灵气为修为为目标的核心道功。

它是角色修为状态与道功模板之间的桥梁：

```text
CharacterState / CultivationState
→ 当前主修道功记录
→ MethodState
→ DaoMethod
→ 修为上限、吐纳收益、自动运转、资源适配和突破路线读取
```

规则：

1. 角色同一时间只能有一个主修道功。
2. 主修道功不等于装备栏，不占用装备位，也不阻止角色使用法门、法宝或道具。
3. 未设主修道功时，角色不能获得正常修为增长。
4. 主修道功决定主动吐纳与自动运转读取的修炼路线、当前可修上限、小境界支持范围、大境界突破路线标签、奖励结构和失败标签池。
5. 主修道功不决定法门能否使用，不决定法宝和道具是否占用装备或物品栏，也不允许绕过突破准备、资源、地点、状态和事件挑战。

### 5.2 设置主修的前置条件

设置主修道功时至少需要校验：

1. 目标功法类型为道功。
2. 角色已经学会该道功并拥有对应 `MethodState`。
3. 该道功支持角色当前境界或当前目标修炼阶段。
4. 角色状态没有被封印、重伤、昏迷、特殊事件等规则禁止换修。
5. 当前处于允许更换主修道功的窗口，或存在明确事件、剧情、宗门安排或特殊规则授权。

法门即使已经学会，也只能作为能力、指令、事件选项或效率修正来源，不能被设为主修。

### 5.3 改修窗口

主修道功常规只在大境界第一小阶段开放无时间成本更换。

抽象示例：

```text
A-1
B-1
C-1
D-1
……
```

包装示例：

```text
炼气 1 层
筑基初期
金丹初期
元婴初期
……
```

离开第一小阶段后，本大境界主修路线锁定，直到进入下一大境界第一小阶段。主修道功切换不消耗普通行动队列槽，不占用固定行动执行时间预算。它是角色修炼路线选择，不是研习功法、合成载体或装备切换。

### 5.4 锁定记录

每个大境界需要记录该大境界最终锁定的主修道功，并固化本大境界 CP、纯度、法力放大系数和法力结果，用于后续读取突破模板、奖励结构、失败标签池和历史法力。

规则：

1. 在大境界第一小阶段内，当前大境界的主修记录可以被常规更换覆盖。
2. 离开第一小阶段后，当前大境界主修记录锁定。
3. 已固化根基不会因为之后进入更高大境界并更换主修道功而改变。
4. 大境界圆满、临近下一次大境界突破时，不能临时更换主修道功以规避突破难度。
5. 旧大境界的法力不得因未来新道功拥有更高 `mana_amplifier` 而回溯重算。
6. 普通巩固修为不能修改已经锁定的大境界主修记录、纯度或法力。

示例：

```text
角色在 B-1 期间从《青木养真诀》改为《青木长生经》。
进入 B-2 后，B 阶主修记录锁定为《青木长生经》。
之后即使进入 C-1 并改修另一门道功，B 阶已固化根基仍读取《青木长生经》。
```

### 5.5 与小境界升级的关系

小境界升级必须受当前主修道功支持范围限制。

规则：

1. 当前小阶段进度达到 100% 后，系统先校验主修道功支持范围。
2. 若主修道功支持下一小阶段，且状态合法，则可进入下一小阶段。
3. 若主修道功只支持到当前小阶段上限，该道功不能把角色推进到下一小境界 0%。
4. 自动运转通常可以触发普通小境界升级，但仍受主修道功支持范围限制。
5. 自动运转不能完成大境界突破。

示例：

```text
某道功只支持到金丹初期 100%。
角色达到金丹初期 100% 后，不能依靠该道功自动进入金丹中期 0%。
```

设计目的：

1. 避免旧主修道功的小境界升级奖励污染当前大境界后续阶段。
2. 避免功法支持范围被阶段自动升级绕过。
3. 让“当前可修上限”成为有效路线约束。

### 5.6 与大境界突破的关系

大境界突破读取当前大境界最终锁定的主修道功记录。

读取内容包括：

1. 突破路线标签。
2. 挑战倾向。
3. 奖励结构。
4. 失败标签池。
5. 功法阶级与品级配置。
6. 资源转化方向和短板检查。

大境界突破开启前至少需要校验：

```text
当前境界段进度达标
MethodState 掌握度满足目标阶段要求
根基、经脉压力、伤势、心魔等状态满足下限
当前地点允许突破
主修道功突破模板可用
开启阶段所需资源可用
```

掌握度影响的是“是否满足目标阶段承载和开启条件、执行表现是否稳定、相关风险是否更清晰”，而不是把一门道功的突破模板类型改造成另一门道功。

### 5.7 主修更换不做什么

MVP 不做：

1. 废功重修。
2. 正式改修折算。
3. 功法上限后的免费续接换主修。
4. 临近大境界突破时临时换功降低挑战。
5. 中途换主修惩罚。
6. 已学道功掌握经验按比例转移到新道功。
7. 残页或篇章直接补足主修道功进度。

当前待裁决方向：

1. 临时方向可以记录“按转化率比值折算 CP”，但不得写成定稿。
2. 正式版更建议按单位 CP 法力密度折算，避免切换主修道功凭空增加 CP 或法力。

参考公式仅作为待裁决方向：

```text
old_effective_density =
  old_purity * old_mana_amplifier

new_effective_density =
  new_default_purity * new_mana_amplifier

new_cp =
  old_cp
  * old_effective_density
  / new_effective_density
  * switch_loss_factor

new_cp = min(new_cp, old_cp)
```

该方向满足：

1. 切到更凝实、更高放大系数的道功时，CP 会折损。
2. 切到更虚浮的速成功法时，CP 不会凭空增加。
3. 已经沉淀出的历史法力不按新道功回溯重算。

不因为以下原因开放免费换主修：

1. 当前道功理论上限达到。
2. 当前掌握度上限达到。
3. 玩家后悔选择主修。
4. 玩家想临时换更优突破模板。
5. 玩家本世想继续但当前路线不够理想。

## 8. UI 展示边界

普通 UI 应展示：

1. 当前主修道功名称、类型、掌握度、当前可修上限和理论最高上限。
2. 当前是否处于可无时间成本更换本大境界主修道功的窗口。
3. 离开第一小阶段后，本大境界主修道功将锁定的常驻提示。
4. 未设主修、目标不是道功、目标未学会、阶段不受支持、角色状态禁止换修等不可用原因。
5. 大境界突破将读取的已锁定主修记录摘要。
6. 本大境界主修记录对应的 CP、纯度、法力和是否已锁定。

MVP 不在 B-1 → B-2 等小境界升级结算关口插入“是否继续突破小阶段”的强制确认事件。原因是小境界升级发生在结算阶段，插入确认会打断主动吐纳或自动运转结算，并可能让玩家产生行动规划未成功的损失感。

提醒应常驻在主修功法更换界面、主修道功详情界面、角色修为摘要区，以及接近第一小阶段结束时的提示或日志。

示例文案：

```text
当前处于筑基初期，仍可无时间成本更换本大境界主修道功。
当修为推进至筑基中期后，本大境界主修道功将锁定，直至进入金丹初期。
```

普通 UI 不展示内部锁定记录 ID、完整失败标签池、奖励配置引用、原始倍率、公式缓存或 Debug 追踪字段。

## 9. MVP 范围

MVP 应实现：

1. 当前主修道功记录，且同一时间只能有一个。
2. 仅已学会道功可设为主修，法门不能设为主修。
3. 大境界第一小阶段的常规改修窗口。
4. 离开第一小阶段后的大境界主修锁定记录。
5. 锁定记录附带本大境界 CP、纯度、法力放大系数和法力摘要。
6. 小境界升级时校验主修道功支持范围。
7. 大境界突破读取已锁定主修记录。
8. 未设主修、禁止换修、阶段不支持、状态不合法等基础不可用反馈。
9. 功法页面和修为页面的常驻主修提示。

MVP 不实现：

1. 废功重修、正式改修折算或主修经验转移。
2. 中途换主修惩罚。
3. 功法上限后的免费续接换主修。
4. 临近大境界突破时临时换功降低挑战。
5. 小境界升级关口的强制确认事件。
6. 残页或篇章直接补足主修道功进度。
7. 法门、法宝或道具占用主修位。

## 10. 验收约束

1. 任何可被设为主修的功法必须是道功，不能是法门、法宝、道具、残页或篇章。
2. 角色同一时间只能存在一个当前主修道功。
3. 未设主修道功时，不得让角色获得正常修为增长。
4. 主修道功切换不得占用普通行动队列槽，也不得伪装为研习功法或装备切换。
5. 大境界第一小阶段以外，不得开放常规无条件改修。
6. 离开第一小阶段后，当前大境界锁定记录不得被临时换功覆盖。
7. 小境界升级必须校验当前主修道功支持范围。
8. 自动运转可以触发普通小境界升级，但不得完成大境界突破。
9. 大境界突破必须读取当前大境界最终锁定的主修记录，而不是读取临时切换意图。
10. 掌握度只能影响承载、开启条件、稳定性、风险清晰度或相关表现，不能把一门道功的突破模板类型改造成另一门道功。
11. MVP 不得用当前道功理论上限达到、掌握度上限达到或玩家后悔作为免费换主修理由。
12. UI 不得把完整失败标签池、奖励结构引用和公式追踪暴露为普通玩家信息。
13. 主修切换不得按新道功回溯重算历史大境界法力。
14. 普通巩固修为不得修改已锁定大境界主修记录中的纯度和法力。

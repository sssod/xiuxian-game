## 8. 后续工作入口

优先关闭：

1. 标准 CP 不变前提下的有效修为精确公式；
2. 护劫护盾与其它护盾的叠加顺序和上限；
3. 多人计时、未提交、掉线、退出和主动提前结束；
4. 首张地图、五宗门特色和经济 / 功法 / 敌人正式内容表；
5. 绝对 CP、属性、移动、价格和战斗数值；
6. 专属追赶、外交、退出归属与 P1 交互 / 双语验收。

详细顺序与验收见阶段门文档。

## 9. 包内规则

1. 一项详细规则只设一个专题维护位置，其他文档只给摘要和链接。
2. 未决内容必须显式标记，不得用“建议”或“默认”伪装成裁决。
3. 本包必须自解释；包外来源不能成为规则依赖。
4. 集中记录保留历史替代关系，但不再维护当前详细规则。
5. 当前阶段不写程序状态机、数据结构或实现机制。
6. 稳定信息职责进入交互文档；节点布局与视觉细节以后续 Figma 为准。

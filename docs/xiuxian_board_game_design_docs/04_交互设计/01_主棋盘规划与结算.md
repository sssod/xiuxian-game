# 交互设计｜主棋盘规划与结算

适用范围：主棋盘的回合状态、世界更新、即时行动、隐藏规划、同步移动、两段式行动输入、竞争暂停和统一结算反馈。本文只定义稳定信息职责，不固定节点布局、样式或动效。

## 1. 交互目标

玩家在任一时刻都应能回答：当前处于哪个阶段、自己还能做什么、已经锁定什么、系统在等待谁、暂停原因与下一步。主棋盘必须表现同时规划和同步结算，不能伪装成玩家依次行动。

## 2. 回合阶段表达

| 阶段 | 玩家输入 | 必须展示 |
| --- | --- | --- |
| 回合开始更新 | 通常无输入 | 资源阶级、建筑等级、建成 / 改建、物品成熟、订单、转世与灵气变化 |
| 即时阶段 | 学习功法、研习位 / 构筑、服丹、改修、贡献、领取与整理 | 当前合法行动、限次项、待领取与空位提醒 |
| 隐藏规划 | 目的地、路线、移动组合、主要行动类型 | 自己的完整计划、费用预估、合法性、锁定项和提交状态 |
| 同步移动 | 只响应相关中断 | 共享时间、实际位置、关隘收费、停止点与相关相遇 |
| 行动细节输入 | 为已承诺行动补对象、数量或投入 | 原行动类型、当前合法参数、费用与失败条件 |
| 统一行动结算 | 只处理相关竞争输入 | 队列、暂停原因、参与者和恢复位置 |
| 回合末 | 通常无输入 | 内部时间、修炼、研习、炼化、寿元、地产收入、洞天投放和飞升判定 |

全局阶段必须显式标识，不得只靠按钮是否可点击让玩家猜测。

## 3. 世界状态栏职责

回合开始至少展示：

- 当前外界回合与 `90—120` 分钟 / `20—24—28` 仅为验收锚点、不是倒计时；
- 当前常规资源最高开放阶级；
- 当前全局建筑等级；
- 当前全图灵气固定增量；
- 已成熟的物品阶级；
- 本轮固定小洞天投放与当前开放洞府；
- 玩家自己的订单、建设 / 改建、待结算收入和转世提醒。

不同机制必须分栏或明确标名，不能重新包装为一个“世界资源阶段”百分比。

## 4. 即时阶段

入口需区分普通准备、宗门贡献和免费领取。通用玩家交易与即时坊市采购不显示。

切换主修和研习位调整应明确“提交移动计划后锁定”；主修每回合最多一次。宗门贡献允许批量选择白名单物品并立即看到固定贡献值与兑换结果，但必须持续提示贡献点不能支付普通灵石费用。

## 5. 隐藏规划与提交

玩家只看到自己的目的地、路线、境界骰池、移动法门、可选法宝和主要行动；其他玩家只显示是否提交，不显示内容。

提交前预检查：

- 移动组合、理论最大距离、实际骰池、派生单格耗时及元气 / 灵石 / 耐久成本；
- 路线上的已知关隘过路费与硬阻挡；
- 主要行动类型和当前可知最低条件；
- 突破选定丹药、固定小洞天目标等规划期锁定例外；
- 提交后哪些内容不可更改。

提交撤回、规划时限和未提交默认尚未裁决，界面不得自行假定。

## 6. 同步移动与局部中断

同步移动期间持续显示玩家实际位置、到达或停止时刻和已发生的可见结果。路线只随实际移动显现。相遇或强制事件只中断相关玩家；无关玩家不应重复确认。

固定地点小洞天竞争需要显示到达顺序、当前挑战者和后续候补；严格同刻挑战者分别进入独立 PVE，不能表现成 PVP 或竞价。

## 7. 两段式行动输入

抵达后只为已锁定行动补参数：

- 采集：一种目标资源和生产力投入；
- 坊市：多种商品及各自数量；
- 炼丹 / 炼器：一个配方和生产数量；
- 购地 / 改建：出价、建筑类型或目标建筑；
- 请教师长：一部合法本宗门功法；
- 地点疗伤：目标与合法投入。

未抵达则行动直接失效。抵达后没有合法参数时，明确显示“行动失败 → 抽取当前地点途中事件池的独立代偿事件”，不得允许换行动。

## 8. 竞争暂停

暂停时至少展示目标、地点、参与者、竞争类型、等待输入和恢复位置。无主节点首次争购必须显示为灵石暗标并说明落选不支付、同价按到达顺序；固定小洞天不显示战斗 / 竞价选择。

连续战斗显示参战顺序与最终统一掉落性质，但中间不展示尚未判定战利品。独立渡劫不暂停无关玩家。

## 9. 回合末结果

结果按来源分组并可展开：

```text
自动修炼（先）
→ 自动研习（后）
→ 恢复 / 丹药 / 法宝炼化 / 寿元
→ 地产稳定收益与待结算收费
→ 物品、建筑、小洞天和其它世界结果
→ 飞升共同胜利
```

小洞天十单位可汇总播放，但要能展开中途境界、掌握阶段、满掌握离位和耗尽结果。主动产物与被动经营收益应标明是否读取物品成熟。

## 10. 当前缺口

- 阶段时限、提交撤回、未提交安全默认；
- 掉线、重连、托管、永久退出、房主离开和中止；
- 首张地图、节点数量、完整行动内容和错误提示；
- 玩家主动提前结束整局的流程；
- 正式中英文术语、日志颗粒度与 Figma 节点布局。

# 角色与真灵设计｜角色绑定法宝

## 1. 当前状态

当前 Library 中未检索到“角色绑定法宝”独立系统稿。本文件从 S9、战斗、经济系统与物品设计相关内容中抽取当前可确定边界。

## 2. 当前结论

MVP 不使用传统装备栏 / 换装备 / 换法宝概念。随身携带且满足条件的法宝、道具、术法、神通，都可能成为行动、事件或战斗指令来源。

法宝可以：

- 提供主动指令。
- 提供被动生效效果。
- 在战斗、事件、防护、突破或后手中触发。
- 受损、失灵、破碎、修复、拆解或回收。

## 3. 绑定关系口径

“绑定法宝”应理解为：某法宝与角色、真灵、宗门权限、后手封存或事件条件之间存在调用权限，而不是装备栏槽位。

可能绑定类型：

```yaml
ArtifactBinding:
  artifact_id: string
  owner_ref: character | true_spirit | sect | sealed_legacy
  bind_state: unbound | character_bound | spirit_bound | sect_authorized | legacy_sealed
  combat_ready: bool
  use_permission_tags: list
  durability_state: intact | worn | damaged | broken
  charge_state: number | null
  spirit_state: string | null
```

## 4. 战斗中的法宝

- 战斗指令来源包括法宝技能、消耗道具、已学术法神通、基础指令、事件特殊指令。
- 被动法宝在触发效果、替角色承受后果、抵抗状态或遭到针对性破坏时，也可能受损、失灵或破碎。
- 战斗不允许中途“换装备”；可用性由随身状态、权限、状态、充能、耐久与事件条件决定。

## 5. 后手与跨世

高价值法宝可作为正式后手封存物或普通遗产。普通遗产可能被发现、搬空、污染、转移或破坏；正式后手必须可追踪、有日志、失效有原因。

## 6. 缺口

# 经济系统设计｜世界凭空产出

## 1. 当前结论

“凭空产出”不等于无约束刷物品。事件、宝藏、NPC 掉落、秘境奖励等隐性或实例化内容，应受分阶生成预算和来源语境约束。

## 2. 生成预算规则

经济系统需要同时维护：

1. 库存流转：已经显性存在的资源和物品在容器之间移动。
2. 生成预算：事件、宝藏、NPC 掉落、秘境奖励等“凭空生成”内容受分阶预算帽约束。

规则：

- 一旦物品由事件 / 宝藏 / 隐性状态实例化，就按物品完整预算价值扣除生成预算。
- 后续出售、拆解、损坏、销毁、上交、封存，不返还生成预算。
- 生成预算用于控制世界投放，不是玩家可见资源，也不是资产回收池。

## 3. 资产生成请求

```yaml
AssetGenerationRequest:
  source_system: string
  generation_context: object
  tier_budget_ref: string
  reward_profile_ref: string
  target_container_ref: string | null
  event_locked_first: bool
  visibility: string

AssetGenerationResult:
  success: bool
  generated_assets: list
  budget_value_spent: number
  target_container_ref: string
  ledger_entry: string
  failure_reason: string | null
```

## 4. 后手与遗产

正式后手不是凭空生成，而是显性物品储存、封存、跨世追踪。普通遗产则可能随世界演化被发现、污染、转移或破坏。

## 5. 缺口

- 各阶预算点数未定。
- RewardProfile、宝藏、秘境、NPC 掉落模板未定。
- 预算消耗与多人可见性的具体联动未定。

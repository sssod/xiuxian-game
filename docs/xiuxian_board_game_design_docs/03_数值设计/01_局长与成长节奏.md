# 数值设计｜局长与成长节奏

适用范围：目标局长、境界到达锚点、小境界 CP 结构、环境灵气、标准研习参考路线、初始状态预算与死亡追赶验收。本文固定数值推导口径，不补造尚未配置的绝对表。

## 1. 局长目标

标准局支持 `2—4` 人，目标现实时长为 `90—120` 分钟，期望在第 `24` 个外界回合完成飞升。数值验收区间为 `20—24—28`：

- 第 `20` 回合是最早合理胜利；更早通常表示成长或机缘过强；
- 第 `24` 回合是期望胜利；
- 第 `28` 回合是最晚标准胜利；更晚属于延长对局。

该区间不是强制终局。首个主题没有系统强制的最终回合或现实时间上限，也没有加时专属全局加速或替代胜者。第 `28` 回合后继续使用既有全图灵气、建筑等级和物品成熟状态。飞升前可以由任一连接正常且未退隐玩家发起全体一致结束表决；通过时只产生共同中止、无胜者结果，详细流程由《[单局流程与同步回合](../02_系统设计/01_单局流程与同步回合.md)》维护。

## 2. 大境界与终局锚点

| 首次到达 | 基准外界回合 |
| --- | ---: |
| 筑基 | `5` |
| 金丹 | `9` |
| 元婴 | `13` |
| 化神 | `17` |
| 大乘 | `21` |
| 完成飞升 | `24` |

约每四个外界回合推进一个普通大境界。达到大乘后预留约三个回合用于终局移动、重点 PVE 前置和其他宗门阻拦。小洞天与高效率道功可以提前，渡劫失败、重伤、经济准备和路线竞争可以延后；这些锚点不是强制截止。

## 3. 大境界 CP 结构

炼气至化神的每个大境界固定使用 `15% / 20% / 25% / 40%` 四段，累计阈值为 `15 / 35 / 60 / 100`。总 CP 以标准节点、标准道功参考路线约四个内部时间单位到瓶颈为配表锚点；不要求四个小境界各占一整回合，也不要求绝对 CP 相同。

若仅为说明而假定四轮分别取得本境总量 `25%`，四轮结束状态约为：中期 `50%`、后期 `60%`、圆满 `37.5%`、抵达瓶颈。这只验证“前段反馈快、圆满耗时最长”，实际收益仍受灵气、道功和掌握影响。

各境总 CP 可以不同，但四段比例不可按境界改写。总 CP 与阈值开局固定，不随实际回合、世界状态或个人进度重算。必要取整与 `1A` 绝对 CP 一并配置。

## 4. 灵气相对单位与回合加法

全图灵气使用整数相对单位 `A`。节点基础灵气和回合增长都配置为整数个 `A`，不使用百分比或小数。

| 节点档位 | 基础灵气锚点 |
| --- | ---: |
| 低灵气节点 | `3A` |
| 普通标准节点 | `5A` |
| 高灵气修炼节点 | `7A` |

特殊灵地与小洞天可以配置高于 `7A` 的整数基础值，仍读取同一回合加法。每回合固定增量为：

| 外界回合 | 全图固定增量 |
| --- | ---: |
| `1—4` | `+0A` |
| `5—8` | `+1A` |
| `9—12` | `+2A` |
| `13—16` | `+3A` |
| `17—20` | `+4A` |
| `21+` | `+5A` |

因此普通标准节点依次为 `5A / 6A / 7A / 8A / 9A / 10A`，低灵气节点为 `3A—8A`，高灵气节点为 `7A—12A`。固定加法保持节点间绝对差，不会发生高低倒置；第 `21` 回合后停在 `+5A`，不无限线性增长。

## 5. 各境总 CP 的参考环境

| 大境界 | 标准参考回合 | 普通标准节点实际灵气 |
| --- | --- | ---: |
| 炼气 | `1—4` | `5A` |
| 筑基 | `5—8` | `6A` |
| 金丹 | `9—12` | `7A` |
| 元婴 | `13—16` | `8A` |
| 化神 | `17—20` | `9A` |

每境固定总 CP 应以标准道功参考路线在对应环境经过四个内部时间单位的标准 CP 写入量反推：

```text
节点灵气输入 L_node
= 节点基础灵气 + 当前回合全图固定增量

实际灵气吸收效率 A_dao
= α_template × M_dao × 其它明确吸收修正

本单位写入标准 CP
= L_node × A_dao
+ L_pill × A_dao
+ 明确绕过吸收的直接标准 CP 奖励
```

标准路径不使用丹药或直接奖励，因此只读取第一项。正式配表必须先确定 `1A` 的绝对 CP、参考道功 `α_template` 与逐单位实际 `M_dao` 路径，再得到各境总 CP；大乘不另配置四段成长量。节点与丹药来源精确汇总后统一按 `0.01` 标准 CP 写入，不逐来源取整。

先行玩家早于锚点进入高境界时，实际灵气可能低于该境参考档，形成自然减速；落后或转世玩家晚于锚点进入低境界时，固定 CP 不变却使用更高的后期灵气，形成不读取名次的自然加速。不得为追赶动态抬高任何角色的境界需求。

## 6. 标准道功参考路径

开局默认把初始道功、初始移动法门和初始战斗法门放入研习位。境界 CP 的标准参考路径让三部共同共享 `B = 20`；某部达到掌握度 `75` 后，在下一回合开始主动移出，直至三部均到 `75`。参考不要求任一初始功法到 `100`。

该路径使用统一开局悟性，不使用丹药、小洞天、请教师长、事件经验、额外功法或其它专项收益；必须逐内部时间单位读取主修道功当时的掌握阶段与实际 `M_dao`，不能把四回合固定假设为 `25` 或预先按 `75` 计算。玩家可以只研习主修以换取更快修炼，但会牺牲移动与战斗法门进度，境界总 CP 不因此动态变化。

第 `9—10` 回合附近应开放取得通用高阶功法的标准路线。只使用初始道功仍能修至大乘，但后期效率较低，预计落入标准胜利区间后段或延长对局；标准改修参考回合与全程初始道功的具体延迟仍待高阶道功表联合验算。研习数值详见《[功法研习与内容预算](04_功法研习与内容预算.md)》。

修为强度与境界总 CP 分开配表：

```text
S_total
= 当前身体已经重新达到并完成的各大境界固定总 CP 之和
+ 当前大境界内标准 CP

修为强度
= (S0 + S_total) × β_template × M_dao
+ 其它不重复读取本道功掌握的合法修正
```

`S0` 提供炼气初期 `0%` 的非零强度但不推进境界。高品级道功改修时，新 `β_template × M_dao` 立即作用于本世完整累计量；不得保存历史道功强度快照或要求玩家重修已完成境界。

## 7. 突破、小洞天与死亡预算

- 炼气突破筑基确定成功；后四次固定渡劫未完成通常使本次路线延迟 `1—2` 回合，不设独立破境概率。
- 一次小洞天在取得当回合末结算十个内部时间单位，普通角色最多推进至当前瓶颈，约可节省三个正常成长回合；随机入口是额外惊喜，不纳入单局硬预算。
- 转世角色利用当前回合灵气和历史突破自动跨越重修。无小洞天时约 `2—3` 个后续回合重新进入历史最高境界；取得一次小洞天时争取在该十单位结算内重新进入。这是调参参考，不是严格保证。

## 8. 标准开局数值包

1. 所有玩家从炼气初期、当前小境界进度 `0%` 开始，标准 CP 为零；由待配的统一 `S0` 提供非零修为强度。
2. 首个主题固定提供 `5` 个宗门，同局宗门不重复。选择宗门即取得其一部初始镇派道功、一门基础移动法门和一门初始战斗法门，三部掌握度均为 `25`；道功自动设为主修。
3. 初始战斗法门在 `25` 解锁一项入门攻击；初始道功在 `25` 只提供一项被动或恢复类开局收益；初始移动法门在 `25` 建立可用移动能力。已解锁招式按宗门模板默认顺序装配，玩家可在合法准备时点调整。
4. 初始研习位默认放置上述三部功法，其余法门研习位留空；第一回合开始可自由调整。
5. 攻击、防御、飞遁三个法宝位默认全空。只有宗门把唯一特色开局资源配置为法宝时，该宗门例外携带并装配一件。
6. 所有宗门使用相同初始灵石，锚定“炼气期基础经营节点基准标价的 `1.5` 倍”：应允许首回合买一个基础节点后仍支付少量通行、功能或生产投入，但正常情况下不能连续购买两个基础节点。
7. 开局不赠送破境丹、其它统一原料、普通丹药或法宝。每个宗门另有一个等价值特色资源槽，可为普通丹药、法宝、额外法门或额外灵石，但不能是破境丹；具体内容、额外法门掌握度和法宝初始炼化度待内容表。
8. 所有宗门使用相同的体魄、精力、根骨、悟性、灵根等级、初始年龄和寿元上限。灵根标签可以不同，但品级与总体强度相同。生机、元气、神念从可支配上限满值开始，保留值为 `0`，无伤势、重伤、经脉过载或其它负面状态。

宗门差异来自模板特色，不得通过初始掌握度、基础数值或隐藏预算制造先天强弱。

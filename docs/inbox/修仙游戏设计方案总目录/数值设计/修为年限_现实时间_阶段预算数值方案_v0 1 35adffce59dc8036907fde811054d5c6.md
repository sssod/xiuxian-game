# 修为年限、现实时间与阶段预算数值方案

版本：v0.1

日期：2026-05-08

适用范围：修仙题材文字 / 策略 / 选择导向 / 个人成长 + 宗门经营 + 沙盒演化游戏

定位：数值框架收敛稿，可作为后续写入 Library / Notion 的稳定规则草案

---

## 1. 设计结论摘要

本方案采用以下核心口径：

```
标准修士修炼年限 = 世界观背景墙 / NPC 默认成长尺度 / 寿元压力参考 / 数值底表
玩家现实体验时间 = 线性增长目标
玩家实际成长速度 = 由阶段预算、资源集中、灵地、丹药、宗门支持、功法掌握和主动决策压缩
```

因此，不再把“标准修士需要几十年 / 几百年”直接换算成玩家现实中的等待时间。玩家不是来游戏里受苦，也不是来挂机修仙。标准年限负责支撑修仙世界的漫长尺度；玩家路径负责提供高密度选择、资源组织和阶段性突破反馈。

最终推荐：

```
1. 标准年限保留为背景墙。
2. 玩家主线推进现实耗时随境界线性增加，而不是指数增加。
3. 玩家资源充足路径与标准修士的倍率差距随境界提升而拉大。
4. 沙盒世界产出采用阶段预算机制。
5. 玩家首次突破到某大境界后，世界激活对应阶段预算。
6. 高于当前预算境界的 NPC 默认只按背景速度成长，不发生明显修为提升。
7. 不高于当前预算境界的 NPC 与其他玩家受预算打开影响，资源可得性和修炼速度提高。
8. 预算打开提供机会，不自动赠送修为。
```

## 4. 标准修士背景年限

标准修士年限用于世界背景、NPC 默认成长、寿元压力和数值底表，不直接决定玩家等待时间。

| 阶段 | 标准修士背景年限 | 用途 |
| --- | --- | --- |
| 炼气 → 筑基 | 8 年 | 新手阶段背景尺度 |
| 筑基 → 金丹 | 30 年 | 普通宗门弟子与精英分层 |
| 金丹 → 元婴 | 80 年 | 宗门骨干到高层的分水岭 |
| 元婴 → 化神 | 180 年 | 老祖级别成长尺度 |
| 化神 → 炼虚 | 360 年 | 世界层级跃迁尺度 |
| 炼虚 → 合体 | 600 年 | 高阶世界长期尺度 |
| 合体 → 大乘 | 900 年 | 顶级势力尺度 |
| 大乘 → 渡劫 | 1200 年 | 终局背景尺度 |
| 渡劫 / 飞升 | 不建议纯年限 | 应以劫数、因果、世界事件和终局挑战为主 |

关键结论：

```
标准修士年限是背景墙。
玩家不应该按这个年限直接等待。
玩家通过主动搜集、集中和消耗资源，把标准年限压缩成少量游戏年的有效修炼收益。
```

## 5. 修为绝对值 CP 建议

建议继续使用 `cultivation_points` 作为内部累计稳定修为值。CP 主要用于：

```
1. 小境界 / 大境界阈值判断；
2. 修炼收益、资源收益和闭关收益结算；
3. NPC 成长速度与世界背景年限校准；
4. 突破开启条件；
5. 调试面板和高级详情展示。
```

不建议将 CP 直接线性换算成战斗力。

推荐 CP 阈值采用每个大境界圆满约 ×5 的递增结构：

| 境界 | CP 范围 | 圆满阈值 | 标准背景年限 |
| --- | --- | --- | --- |
| 炼气 | 0–1,000 | 1,000 | 8 年 |
| 筑基 | 1,000–5,000 | 5,000 | 30 年 |
| 金丹 | 5,000–25,000 | 25,000 | 80 年 |
| 元婴 | 25,000–125,000 | 125,000 | 180 年 |
| 化神 | 125,000–625,000 | 625,000 | 360 年 |
| 炼虚 | 625,000–3,125,000 | 3,125,000 | 600 年 |
| 合体 | 3,125,000–15,625,000 | 15,625,000 | 900 年 |

玩家主线成长体验应该按境界线性增长，而不是指数增长。

| 阶段 | 标准背景年限 | 玩家现实目标 | 主动经营 / 选择 | F1 闭关消化 | 设计定位 |
| --- | --- | --- | --- | --- | --- |
| 炼气 → 筑基 | 8 年 | 1–1.5 小时 | 35–60 分钟 | 20–40 分钟 | 新手阶段，快速给第一次质变 |
| 筑基 → 金丹 | 30 年 | 2 小时左右 | 60–75 分钟 | 45–60 分钟 | 第一次完整资源循环 |
| 金丹 → 元婴 | 80 年 | 3 小时左右 | 75–100 分钟 | 75–90 分钟 | 中期核心循环 |
| 元婴 → 化神 | 180 年 | 4 小时左右 | 100–130 分钟 | 100–120 分钟 | 第一阶段大后期 |
| 化神 → 炼虚 | 360 年 | 5 小时左右 | 120–160 分钟 | 120–150 分钟 | 世界层跃迁 |
| 炼虚 → 合体 | 600 年 | 6 小时左右 | 150–190 分钟 | 150–180 分钟 | 高阶资源竞争 |
| 合体 → 大乘 | 900 年 | 7 小时左右 | 180–230 分钟 | 170–210 分钟 | 顶级宗门 / 世界竞争 |

MVP 优先目标：

```
炼气 → 筑基：1–1.5 小时
筑基 → 金丹：2 小时
金丹 → 元婴：3 小时
元婴 → 化神：4 小时
```

## 7. 时间档位换算

默认假设：

```
1 游戏日 = 24 游戏小时
1 游戏年 = 360 游戏日
F1 = 2 秒现实时间 / 1 游戏日
N1 = 15 秒现实时间 / 1 游戏小时
B1 = 60 秒现实时间 / 1 游戏小时
```

换算结果：

| 速度 | 1 游戏日 | 1 游戏年 |
| --- | --- | --- |
| N1 | 6 分钟 | 36 小时 |
| F1 | 2 秒 | 12 分钟 |
| B1 | 24 分钟 | 不用于长期修炼 |

因此：

```
N1 只用于主动决策、短行动、事件处理、队列编辑。
F1 用于资源已投入后的低交互闭关消化。
B1 用于突破挑战、正式交锋和秘境关键交锋。
P0 用于公共阶段事件和同步保护。
```

特别强调：

```
N1 不是年级修炼的主承载速度。
F1 不是玩法目标，只是压缩低交互等待的手段。
玩家核心玩法不是挂机，而是在 N1 / 事件 / 资源经营中创造高价值闭关条件。
```

## 8. 玩家实际游戏年与有效修炼倍率

按 F1 换算，1 游戏年约等于 12 分钟现实时间。若玩家每阶段只进行有限 F1 闭关，则实际游戏年远低于标准背景年限。

| 阶段 | 标准背景年限 | 玩家 F1 闭关现实时间 | 对应实际游戏年 | 需要的有效修炼倍率 |
| --- | --- | --- | --- | --- |
| 炼气 → 筑基 | 8 年 | 20–40 分钟 | 1.7–3.3 年 | ×2.4–×4.8 |
| 筑基 → 金丹 | 30 年 | 45–60 分钟 | 3.75–5 年 | ×6–×8 |
| 金丹 → 元婴 | 80 年 | 75–90 分钟 | 6.25–7.5 年 | ×10.7–×12.8 |
| 元婴 → 化神 | 180 年 | 100–120 分钟 | 8.3–10 年 | ×18–×21.6 |
| 化神 → 炼虚 | 360 年 | 120–150 分钟 | 10–12.5 年 | ×28.8–×36 |
| 炼虚 → 合体 | 600 年 | 150–180 分钟 | 12.5–15 年 | ×40–×48 |
| 合体 → 大乘 | 900 年 | 170–210 分钟 | 14.2–17.5 年 | ×51–×63 |
| 大乘 → 渡劫 | 1200 年 | 190–230 分钟 | 15.8–19.2 年 | ×62–×76 |

这张表体现本方案的关键差异：

```
标准修士靠普通吐纳、普通洞府、低密度丹药和常规宗门配给。
玩家靠主动争夺节点、申请宗门资源、消耗稀缺丹药、抢机会窗口、集中灵地时段和突破准备，压缩有效修炼年。
```

## 9. 有效修炼年公式

建议在 CP 公式之外增加中间量：

```
effective_cultivation_years_gained
```

推荐公式：

```
effective_years_gained =
    calendar_years_spent
  × aptitude_factor
  × method_factor
  × aura_factor
  × facility_factor
  × sect_support_factor
  × resource_package_factor
  × budget_access_factor
  × risk_state_factor
```

再转成 CP：

```
cp_gain =
  required_cp_for_current_stage
  × effective_years_gained
  / standard_years_for_current_stage
```

标准修士：

```
resource_package_factor ≈ 1.0
budget_access_factor ≈ 1.0
总倍率 ≈ ×0.8–×1.2
```

资源充足玩家：

```
resource_package_factor × budget_access_factor × active_play_factor
= ×3 到 ×70+
```

这样可以同时成立：

```
普通修士 80 年结婴；
资源充足玩家用 6–8 个游戏年完成金丹到元婴；
现实体验约 3 小时；
高境界 NPC 不会无故继续飞升；
预算打开后同境界玩家和 NPC 会变快。
```

## 11. 阶段预算机制

阶段预算机制用于解释沙盒世界为何随玩家境界推进而开放新资源。

推荐新增稳定规则层：

```
WorldStageBudgetState
```

推荐字段：

```
WorldStageBudgetState {
  active_budget_realm: Realm
  unlocked_realm_history: Array<Realm>
  unlocked_by_character_refs: Array<CharacterRef>
  current_macro_period_id: String
  budget_pools: Dictionary<Realm, RealmBudgetPool>
  next_realm_leakage_rate: number
  catchup_policy: Dictionary
  high_realm_npc_progress_policy: Dictionary
}
```

每个境界对应一个预算池：

```
RealmBudgetPool {
  realm: Realm
  total_budget_points_per_macro_period: number
  node_resource_budget: number
  sect_inventory_budget: number
  market_trade_budget: number
  opportunity_window_budget: number
  npc_personal_budget: number
  method_carrier_budget: number
  breakthrough_material_budget: number
  active: bool
}
```

预算激活规则：

```
on_major_breakthrough_success(character, new_realm):
    if character.is_player_controlled
       and new_realm > WorldStageBudgetState.active_budget_realm:
        WorldStageBudgetState.active_budget_realm = new_realm
        activate_budget_pool(new_realm)
        schedule_budget_distribution(next_macro_period)
```

关键口径：

```
预算激活是系统事实，不等于公开传闻。
是否公开某玩家突破，由可见性、宗门传闻、玩家选择和事件结果决定。
```

## 12. 阶段预算投放比例

推荐每个阶段预算按以下方向投放：

| 预算出口 | 建议占比 | 作用 |
| --- | --- | --- |
| 节点资源槽 | 35%–45% | 灵草、矿材、灵脉波动、妖兽材料、秘境产物 |
| 宗门库存 / 任务 | 20%–25% | 宗门资源申请、护法、丹药、功法载体 |
| 市场 / 交易 | 10%–15% | 坊市、商队、黑市、拍卖 |
| 机会窗口 / 事件 | 15%–20% | 秘境窗口、遗迹、机缘事件、争夺事件 |
| NPC 个人库存 | 5%–10% | NPC 可交易、可赠予、可争夺、可掉落资源 |

预算不应瞬间刷满，而应在 1–3 个宏观周期内逐渐显现：

```
突破当刻：个人结果、宗门反应、少量相关机会。
下一个宏观周期：节点资源槽开始出现新阶段资源。
第二个宏观周期：宗门库存、市场、NPC 资源开始扩散。
第三个宏观周期：该阶段资源成为稳定世界预算。
```

## 13. 先锋资源与预算打开

为了让第一个突破到新境界的玩家合理成立，需要区分“先锋资源”和“阶段预算”。

### 13.1 先锋资源

先锋资源是突破前就能少量获得的下一阶段关键资源。

建议：

```
next_realm_leakage_rate = 5%–10%
```

来源：

```
高风险节点；
一次性秘境；
宗门特殊申请；
师承任务；
遗迹；
黑市；
强敌掉落；
后手遗产；
小概率事件。
```

先锋资源不足以让整个世界大量成长，但足以让一个主动玩家集中资源完成突破。

### 13.2 阶段预算

玩家突破成功后，对应阶段预算正式打开：

```
先锋玩家：靠稀缺资源、冒险和集中投入突破。
其他玩家 / 同境界 NPC：在预算打开后更容易获得同阶段资源。
高于玩家境界的 NPC：仍缺乏自己境界需要的高阶预算，因此不会明显进步。
```

## 14. NPC 成长分层规则

NPC 成长由其境界是否高于当前阶段预算决定。

### 14.1 高于当前预算境界的 NPC

条件：

```
npc.realm > WorldStageBudgetState.active_budget_realm
```

规则：

```
只走标准修士背景速度；
无法稳定获得本境界所需资源；
每个宏观周期修为进度变化很小；
默认不发生小境界晋升；
默认不发生大境界突破；
除非剧情、后手、宗门重大事件或专属资源池触发。
```

建议数值：

```
visible_progress_cap_per_macro_period = 0.1%–0.5%
breakthrough_allowed = false by default
minor_stage_advance_allowed = scripted_only
```

世界解释：

```
高境界 NPC 的修炼瓶颈不是缺时间，而是缺同境界预算资源。
```

### 14.2 不高于当前预算境界的 NPC

条件：

```
npc.realm <= WorldStageBudgetState.active_budget_realm
```

规则：

```
可以吃到阶段预算；
资源可得性提高；
宗门任务、市场、节点资源、机会窗口都可能提升其修炼效率；
但 NPC 仍低于玩家主动路径倍率。
```

建议倍率：

| NPC 类型 | 预算打开后的有效修炼倍率 |
| --- | --- |
| 普通 NPC | ×1.2–×2 |
| 宗门重点培养 NPC | ×2–×4 |
| 天才 / 亲传 / 关键竞争者 | ×4–×8 |
| 剧情级竞争者 | ×8–×12，但需要显式记录来源 |

### 14.3 其他玩家

其他玩家比 NPC 更接近主角路径：

```
低参与玩家：×2–×4
正常参与玩家：×5–×12
资源集中玩家：接近领先玩家倍率
显式托管玩家：倍率明显降低，错过高价值机会
```

预算打开不会自动赠送修为；其他玩家仍需要决策、行动、争夺和突破。

## 15. 玩家资源包机制

玩家高倍率不应来自纯数值光环，而应来自可追踪的阶段修炼资源包。

推荐资源包类型：

| 资源包 | 作用 |
| --- | --- |
| 灵地时段包 | 提供高 aura 兼容小时 |
| 丹药药力包 | 提供高 CP 转化，但增加经脉压力 |
| 灵材辅助包 | 降低副作用或提高突破准备质量 |
| 宗门护持包 | 降低风险，提高闭关稳定性 |
| 功法参悟包 | 提高 `MethodState` 掌握度，间接提升修炼效率 |
| 突破专用包 | B1 突破轮内可消耗资源 |
| 秘境机缘包 | 高收益、高风险、可能附带状态标签 |

资源包不直接给等级，而是提供：

```
effective_cultivation_years
compatible_hours
risk_modifier
meridian_pressure_delta
method_mastery_delta
breakthrough_quality_modifier
```

推荐主循环：

```
发现资源线索
→ 争取节点 / 宗门 / 市场 / 事件
→ 获得阶段资源包
→ 绑定到闭关行动
→ F1 短闭关消化
→ 小境界 / 瓶颈反馈
→ 重复 2–4 次
→ 突破准备
→ B1 突破挑战
```

## 16. 小境界节奏

### 16.1 炼气 1–9 层

炼气总标准背景年限为 8 年，但玩家实际通过资源压缩。建议炼气小层不均分，前期反馈更快，后期形成第一次瓶颈。

| 炼气层数 | 累计进度 |
| --- | --- |
| 1 层 | 3% |
| 2 层 | 7% |
| 3 层 | 12% |
| 4 层 | 18% |
| 5 层 | 27% |
| 6 层 | 39% |
| 7 层 | 55% |
| 8 层 | 75% |
| 9 层 / 圆满 | 100% |

### 16.2 筑基以上

| 小阶段 | 境界内 CP 进度 | 设计含义 |
| --- | --- | --- |
| 初期 | 0–25% | 刚入境界，战力质变但根基未厚 |
| 中期 | 25–50% | 稳定期 |
| 后期 | 50–80% | 主要战力成型 |
| 圆满 | 80–100% | 准备突破，瓶颈 / 资源 / 风险成为核心 |

达到 80% 后：

```
bottleneck_state = approaching
```

达到 100% 后：

```
bottleneck_state = reached
允许玩家执行突破准备或开启大境界突破。
```

## 17. 突破与战斗力提升

### 17.1 突破流程

大境界突破不应是概率按钮，而应保持当前项目已有结构：

```
准备期
→ 开启突破短指令
→ 突破挑战 B1
→ 个人结果报告
→ 后续选择
```

CP 达标只是开启条件。真正突破要看：

```
突破地点；
突破资源；
功法掌握；
根基品质；
经脉压力；
心魔状态；
护法与宗门支持；
B1 轮内策略和资源取舍。
```

### 17.2 突破后的立即提升

突破成功后应立即提升，但提升来源不是 CP 瞬间暴涨，而是：

| 来源 | 占比感 | 具体变化 |
| --- | --- | --- |
| 境界倍率 | 40%–50% | `realm_power_multiplier` 进入新境界 |
| 属性质变 | 20%–30% | 体魄、神识、灵力上限、经脉承载上限提升 |
| 修为稳定度 | 10%–20% | 新境界 fullness 从低值起步，巩固后提高 |
| 术法 / 行动解锁 | 情境性强 | 飞行、婴火、神识离体、天地元气调用等 |

战斗力推荐公式：

```
combat_power =
  base_stat_score
  × realm_power_multiplier[realm]
  × minor_stage_multiplier
  × foundation_quality_factor
  × method_mastery_factor
  × current_cultivation_fullness_factor
  × state_factor
  + equipment_spell_bonus
```

推荐境界倍率：

| 境界 | 战斗境界基准倍率 |
| --- | --- |
| 炼气 | 1 |
| 筑基 | 3 |
| 金丹 | 10 |
| 元婴 | 32 |
| 化神 | 100 |
| 炼虚 | 320 |
| 合体 | 1,000 |
| 大乘 | 3,200 |
| 渡劫 | 10,000 |

小阶段倍率：

| 小阶段 | 倍率 |
| --- | --- |
| 初期 | 1.00 |
| 中期 | 1.25 |
| 后期 | 1.55 |
| 圆满 | 1.90 |

## 18. 阶段循环示例

### 筑基 → 金丹，目标现实时间约 2 小时

```
阶段 1：稳定筑基根基
现实 20–30 分钟
玩法：宗门资源申请 / 洞府选择 / 小资源包闭关
结果：筑基初期 → 中期

阶段 2：争取金丹资源线索
现实 30–40 分钟
玩法：节点探索 / 宗门任务 / 市场交易 / NPC 关系
结果：获得 1–2 个核心修炼包

阶段 3：集中闭关消化
现实 30–45 分钟
玩法：F1 闭关，处理轻微闭关波动
结果：筑基后期 / 圆满

阶段 4：突破准备与 B1
现实 20–30 分钟
玩法：资源确认、护法、突破挑战
结果：金丹成功 / 失败 / 根基品质变化
```

### 金丹 → 元婴，目标现实时间约 3 小时

```
阶段 1：金丹初期巩固
阶段 2：寻找元婴资源线索
阶段 3：争夺或交换关键资源
阶段 4：中长闭关消化资源
阶段 5：突破准备、护法、B1 挑战
```

### 元婴 → 化神，目标现实时间约 4 小时

```
阶段 1：元婴稳定与功法掌握
阶段 2：世界层级资源线索出现
阶段 3：宗门、秘境、NPC 与市场多线竞争
阶段 4：高风险闭关与心魔 / 经脉压力管理
阶段 5：化神突破准备
阶段 6：B1 突破挑战与世界影响
```

## 21. 可写回文档的稳定口径

以下文本可直接写入数值设计文档：

```
修为标准年限用于世界观、NPC 默认成长、寿元压力和数值底表，不直接决定玩家现实等待时间。

玩家主线成长采用线性现实体验目标：
炼气至筑基约 1–1.5 小时；
筑基至金丹约 2 小时；
金丹至元婴约 3 小时；
元婴至化神约 4 小时；
后续每阶段约增加 1 小时。

玩家资源充足路径通过阶段预算、资源集中、宗门支持、灵地、丹药、功法掌握和机会窗口，将标准修炼年限压缩为少量游戏年内的有效修炼收益。

沙盒世界产出采用阶段预算机制。
当玩家首次突破到某大境界后，世界激活对应阶段预算。
预算进入节点资源槽、宗门库存、市场交易、机会窗口、NPC 库存和事件投放。
预算激活不等于公开突破，公开性由可见性与传闻系统处理。

高于当前预算境界的 NPC 默认只按背景速度成长，不发生明显修为提升或突破。
不高于当前预算境界的 NPC 与其他玩家可受预算打开影响，提高资源可得性和修炼速度。
预算打开提供机会，不自动赠送修为。

玩家核心玩法不是等待闭关，而是通过探索、宗门、市场、节点、事件、NPC 关系和风险选择，创造高价值闭关条件，并在 F1 中快速消化，在 B1 中完成突破挑战。
```

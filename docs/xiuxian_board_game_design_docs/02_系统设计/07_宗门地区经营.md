# 系统设计｜宗门、地产与建筑经营

适用范围：宗门身份、特定经营节点、唯一主导权、购地与建筑、持续供养、收费、宗门贡献和跨世地产归属。灵石收费结算和主动生产由经济专题维护。

## 1. 设计定位

地图占地与轻量地产经营是首个主题的核心对抗层，不是可从首轮 MVP 延期的接口。常态循环为：

```text
积攒灵石
→ 抢先购买仍无主的特定节点
→ 取得稳定灵石 / 资源供养
→ 扩大经营与资源收入
→ 反哺修炼、移动和战斗构筑
→ 前往更高价值区域继续扩张
```

地产竞争以“跑马圈地”和先占无主节点为主。其他玩家停留或使用节点产生的收费是附加收入，不是基础回报；直接战斗只在玩家主动升级冲突或事件明确触发时出现。

## 2. 宗门身份

首个主题固定提供 `5` 个可选宗门，支持 `2—4` 人且同局不可重复。玩家在大厅查看完整预设并自由选择尚未被占用的宗门；准备后锁定选择，取消准备不自动放弃占用。近同时确认同一宗门时按服务器 / 会话稳定收到顺序处理，落后者保持未选择。该规则显式替代旧“随机生成顺序、玩家依次选择宗门”。所有宗门确定且全员准备后，再独立分配固定地图出生座位；宗门身份与出生区域拓扑解耦。

玩家以所属宗门名义取得、建造和经营地产，是该宗门在本局中的唯一决策代表。宗门不模拟会否决玩家的内部组织。宗门提供初始功法、特色资源、特产、特殊法宝、建筑外观和贡献目录等差异，但不锁定发展路线；任一宗门都可学习其它合法功法、取得各种资源与法宝，并选择经营、移动、战斗或修炼路线。

盟友与仇敌属于宗门外交关系，不包装成玩家个人关系。普通收费和争购不自动建立仇敌；首轮不制作盟友折扣、免租或其它盟友功能。

## 3. 可经营节点与主导权

只有主题地图预先标记的特定节点可以购买经营，普通六边格不可购。经营节点分为：

| 类型 | 当前规则 |
| --- | --- |
| 已有建筑节点 | 可被宗门购买主导；建筑类型不可改建，可随全局等级升级 |
| 已有资源节点 | 可被宗门购买主导；提供被动供养和主动采集功能 |
| 待开发优质地块 | 购买时必须锁定初建建筑，建成后可再次改建 |

同一节点同时只有一个主导宗门，不存在持续地区影响力、共同影响力投入或多方轨道。首轮 MVP 不支持有主节点常态易主：主要行动、道具、建筑和战斗都不能夺取；未来若需要追赶，优先通过显式事件引入。

主导宗门代表使用自有节点时免停留费、固定功能费和关隘过路费，也不受自己设置的关隘障碍阻挡；商品、配方、生产力、材料和耐久等实际消耗仍正常支付。所有权优惠不扩展给盟友。

## 4. 首次取得无主节点

首次购买是经营主要行动。单人合法购买时按标价付款并立即取得主导权；多人同轮争购时自动进入灵石暗标，最高出价者支付自己出价，落选者不支付。首次争购不允许直接战斗，也不建立仇敌。同价按更早抵达者优先，严格同刻由稳定随机种子裁定。

本回合新取得主导权的节点立即参与本回合末持续产出结算。

待开发优质地块购买时必须同时提交拟建建筑类型：

- 单人支付地块标价与按提交时全局建筑等级锁定的建造成本；
- 多人争购预留“购地出价＋对应建造成本”，竞价只比较购地出价；胜者支付两部分，落选者均不支付；
- 购得当回合仍按空地现状结算基础持续收益，拟建建筑的功能、收费和新增产出尚未生效；
- 建筑类型立即公开为“建设中”，下一外界回合开始完成，读取届时全局建筑等级并开放功能；第一笔建成建筑持续收益在该回合末结算。

首轮不允许只买空地而不提交开发预案。

## 5. 改建

只有已建待开发优质地块可以改建；已有建筑节点不能改建。改建是一次独立经营主要行动，提交时按目标建筑和当前全局建筑等级支付完整建造成本，旧建筑不返还灵石、材料或残值，也不设累计次数上限或额外冷却。

提交当回合旧建筑继续提供原功能、收费和持续收益；下一外界回合开始切换为目标建筑，读取届时等级并开放新功能，新类型第一笔持续收益在该回合末结算。已锁定改建不因代表角色死亡而取消。

## 6. 全局建筑等级

建筑等级只读取外界回合，不读取玩家境界、物品成熟或单栋建造时间：

| 外界回合 | 全局建筑等级 |
| --- | ---: |
| `1—6` | 一级 |
| `7—12` | 二级 |
| `13—18` | 三级 |
| `19+` | 四级 |

等级在对应回合开始时统一更新。已有、有主、无主、新建和改建建筑均读取当前等级；自动升级不消耗玩家行动、灵石、材料或贡献点。模板可以配置低于四级的自身上限，达到后保持最高级，不制造无意义层级。

建筑等级可以按模板分别提高：新建 / 改建 / 取得成本、主导宗门持续收益、他人使用费用、生产力投入上限、配方目录与上限、坊市目录与逐商品上限。不得使用一个统一倍率放大所有字段。目录扩展仍受当前回合常规资源阶级上限约束。

后期新建按较高等级成本付款并直接取得当前等级能力；早期已持有建筑免费升级、不补差价。新建或改建成本按提交时锁定，若完成回合恰逢升级，仍保留旧成本但建成即使用新等级。

## 7. 稳定经营收益与收费

首轮不设置常规维护费、地税或逐回合材料消耗。玩家灵石为零时地产仍正常提供收益；事件可以显式造成临时停产、损坏或一次性修复，但不能隐式生成欠款、强制出售或破产。

每个外界回合结束时，有主经营节点自动向宗门代表结算持续灵石、资源或组合收益，不要求角色返回或消耗行动。当前规则：

1. 常规经营建筑必须提供不依赖其他玩家到访的稳定收益；其他玩家支付的费用是额外不稳定收入，不计入基础回收期。
2. 常规功能建筑默认提供灵石稳定收益，也可附带少量原料副产物。被动收益只读取当前建筑等级，不读取物品成熟；原料仍受常规资源阶级开放约束。
3. 炼丹房、炼器工坊等转化建筑不得被动产出其核心成品，只能提供灵石或少量原料；核心成品必须由主动订单取得。
4. 关隘、宗门特殊建筑、事件建筑等战略模板可以不提供常规稳定收益，但必须显式标记并说明替代价值。
5. 常规经营建筑以“按当前等级新取得并投入使用后，约 `4—6` 个外界回合收回基础投资”为首轮校准目标。只计稳定收益，不计到访收费、未来升值、出售或夺取补偿。
6. 持续收益应随等级提高，不能只提高后建成本和收费。停留费与功能费可以增长，但原则上慢于建筑产能、功能上限或同阶段主要行动收益，避免把落后玩家排除在必需功能外。

费用发生、收款锁定与回合末到账见《[资源、物品、坊市与生产](08_资源物品坊市与生产.md)》。

## 8. 资源节点的被动供养

资源节点每回合末独立提供被动供养，与所有玩家主动采集互不扣减。首轮不记录共享库存、总开采容量、枯竭度或所有者预留份额；主导宗门也可在自有节点主动采集，只免固定功能费，生产力投入仍消耗。

同等级标准资源节点的每回合被动供养价值，以“一次标准主动采集净收益”的 `25%—35%` 为首轮锚点。标准主动采集使用该等级预设标准投入，净收益按基础长期期望价值扣除可变灵石投入和标准固定功能费，不计偶发极品、路线成本或玩家间收费转移。

因此持有约 `3—4` 个同档标准资源节点时，合计被动供养接近一次标准主动采集净收益；规模经营可以形成优势，但少量地产不能完全替代持续移动与主要行动。购买价仍须满足常规 `4—6` 回合回收期。

被动供养只读建筑等级表，不读取物品数量或品级成熟；主动采集在生成基础原料后才读取物品成熟。两条来源不得互相包装后重复加速。

## 9. 宗门贡献

每个宗门分别配置：可贡献物品白名单、固定单件贡献值、兑换目录和宗门特殊建筑。玩家在回合开始可用专用即时行动批量提交白名单物品，物品立即销毁并转化为贡献点；不建立宗门库存、寄存仓或可再次取回的实体物品。

贡献值：

- 不读取坊市售价、建筑等级、回合、物品成熟、主导权、库存或取得来源；
- 同一模板的购买品、生产成品、事件奖励和战利品使用同一宗门配置值；
- 同一物品可被不同宗门接受并给出不同固定值，但五宗门整体回收预算需等强度；
- 应显著低于该物品通过可重复灵石路径取得时的完整价值，使“买物品再贡献”是合法但低效的单向消耗；
- 不能兑换灵石，也不能产出可由坊市回购的商品。宗门功法兑换后自动学习；其它产出原则上绑定玩家、直接生效或进入宗门建设用途。

宗门贡献点不能支付普通地产、普通建筑、坊市商品、收费或生产力投入，也不能与灵石互换；可以支付请教师长、宗门功法 / 特色产出和宗门特殊建筑。特殊建筑仍需玩家现场建造或改建。

宗门贡献是主经济与内容表完成后的末端回收兜底，精确白名单、贡献值和兑换成本最后校准。当前仅保留末期验算锚点：标准 `24` 回合正常回收约 `25—35` 点，少量参与约 `10—15` 点；请教师长约 `5`，额外宗门法门约 `15`，额外宗门道功约 `20`，宗门特殊建筑约 `25`，小型绑定特色产出约 `5—10`。这些值可在主经济表完成后整体缩放或分别调整，不是锁死价格。

## 10. 死亡、转世与退隐

代表角色死亡或转世时，节点主导权、建筑、建设中状态和已锁定改建计划继续保留并按原时序结算；宗门贡献点也保留且不掉落。死亡后才到账的地产收益暂存至下一回合转世完成后交付，不追溯参与死亡掉落。

玩家主动永久退出或连续掉线 `10` 分钟触发强制退出时，先标记待退隐，实际角色移除统一发生在最近一次尚未向玩家开放的回合开始即时阶段第一步。退隐资产按以下边界处理：

- 角色和全部个人数值停止维护，随身资产由系统回收，退隐本身不产生死亡掉落；
- 节点主导权、建筑、建设 / 改建中状态继续保留为“退隐宗门地产”，不因退出直接转为无主，也不自动赠予其他玩家；
- 已锁定建设状态照常完成；退隐后不再发起新建设；
- 退隐地产的稳定供养作废，本应支付给退出玩家的停留费、功能费、过路费和其它收入由系统回收；
- 其他玩家仍可按原规则停留、使用并支付费用；
- 首轮仍不支持常态易主。事件等正式游戏规则以后可以合法取得退隐地产，易主完成后才按新玩家正常结算。

退出基础归属已经关闭；仍待裁决的是 `CATCHUP-01` 是否制作具体合法易主事件、资格、代价和结果，以及普通关系 / 仇敌 / 盟友的完整范围。宗门身份的局内变化同样不得由实现层自行补造。

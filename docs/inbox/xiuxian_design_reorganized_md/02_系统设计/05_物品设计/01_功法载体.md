# 物品设计｜功法载体

## 1. 当前定版链路

功法投放采用三层载体链：

```text
残页
→ 篇章
→ 完整功法载体
→ 学会功法
→ 研习功法提升掌握度
```

## 2. 残页

残页是可合成道具，不可学习。

规则：

- 不创建 MethodState。
- 不可设为研习目标。
- 不直接解锁功法效果。
- 只参与合成篇章。
- 残页按目标篇章归类，不做精确页码编号。

## 3. 篇章

篇章是可合成道具，不可学习。

规则：

- 不创建 MethodState。
- 不可设为研习目标。
- 不直接作为主修道功内容。
- 只参与合成完整功法载体。
- 篇章合成完整功法时需要精确篇章。

## 4. 完整功法载体

完整功法载体是唯一可学习来源。

规则：

- 可作为学习来源。
- 可用于研习入门。
- 入门后创建 MethodState。
- 默认学习时不消耗载体。
- 高价值道功完整载体默认使用 ItemInstance。
- 普通低阶法门完整载体可使用 ItemStack。

## 5. 缺口

- 功法载体获取来源表。
- 残页 / 篇章 / 完整载体合成配方表。
- 高价值载体的唯一性、绑定、损毁和拓印规则。

# 功法设计｜法门

## 1. 定义

法门不直接推动修为进度，主要提供战斗、探索、采集、移动、生产、事件处理和资源效率能力。

## 2. 当前定版规则

- 法门不能设为主修。
- 法门不直接推动修为进度。
- 法门提供能力、指令、事件选项或资源效率。
- 法门的价值回到时间与资源效率：同样投入 5 天，掌握某法门后能否更快移动、更安全探索、更高效采集、更好处理事件或更少损耗资源。

## 3. 示例用途

- 轻身法门：影响路径开销、逃遁选项、移动事件反馈。
- 战斗法门：提供迎战选项、战斗指令、克制关系。
- 探索法门：增加发现隐藏层、秘境入口、前世线索的能力。
- 生产法门：配方成功率、品质、损耗或副产物。

## 5. 设计历史

早期功法可能混合修为和技能价值。后期功法 v0.4 明确道功 / 法门分工：道功是修为路线，法门是能力与效率。

## 6. 缺口

- 法门分类表。
- 法门与行动 / 事件 / 战斗指令的映射表。
- 法门掌握度与效果强度曲线。

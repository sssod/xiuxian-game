# 字段迁移补丁（v0.1）

> 作用：补充 v2.2 `03_实现交付/04_字段迁移对照表_v2.2.md`。  
> 范围：时间、回合、队列、兜底、托管、局部时停、交锋、突破、回放。

---

## 1. 时间字段迁移

| 旧字段 / 结构 | 新字段 / 结构 | 说明 |
|---|---|---|
| `TurnConfig` | `TimeConfig` | 回合配置改为速度与 tick 配置 |
| `turn_duration_days` | 移除 / 历史兼容 | 不再表示玩家最小推进单位 |
| `decision_countdown_seconds` | `b1_round_real_seconds` / `global_pause_timeout_policy` | 普通行动无统一规划倒计时 |
| `current_turn_id` | `replay_segment_id` / `legacy_turn_id` | 不再作为主时间事实 |
| `current_phase` | `runtime_state` + `SpeedState.current_speed` | 回合阶段改为运行状态 |
| `local_hour_in_turn` | 移除 | 使用绝对 `world_hour` |
| `settlement_status` | `speed_state` / `TimelineReplay.status` | 不再有固定结算阶段 |

---

## 2. 队列字段迁移

| 旧字段 / 结构 | 新字段 / 结构 | 说明 |
|---|---|---|
| `PersonalActionInstruction` | `Command` | 保留行动意图，但去掉回合预算语义 |
| `submitted_instruction_queues` | `submitted_command_changes` | 回放记录队列变更 |
| `planned_duration_days` | `duration_hours` + UI 换算 | 逻辑统一小时 |
| `created_turn_id` | `created_world_day` + `created_world_hour` | 记录绝对创建时间 |
| `auto_continue` | `compatible_followup_actions` / 删除 | 不允许条件自动化 |
| `failure_policy` | `validation_failed → FallbackState` | 校验失败按新兜底规则 |
| `interrupt_policy` | `event_time_mode` + `interrupt_plan` | 事件类型决定时间模式 |
| `overflow_policy` | 按行动模板保留 | 但不再表示跨回合，表示跨时间段 |

---

## 3. 兜底与托管字段

| 旧字段 / 结构 | 新字段 / 结构 | 说明 |
|---|---|---|
| `autopilot_plans` | `ManagedActionState` / `FallbackState` / `timeout_safe_default` | 拆分三种来源 |
| `fallback_to_stay` | `FallbackState.action_type = meditate/rest` | 根据节点风险选择 |
| `休整待机` | `fallback_rest` 或 `explicit_rest` | 必须标记来源 |
| `autopilot_state` | `managed_state` / `fallback_state` | 不混用 |

兜底必须包含：

```text
reason
node_risk
action_type
force_speed=N1
f1_eligible=false
```

## 4. 局部时停与追赶字段

新增：

```text
LocalTimeStopState
CatchupSettlementState
```

事件字段补充：

| 旧字段 | 新字段 | 说明 |
|---|---|---|
| `consumed_hours` | 保留 | 但需区分 local_stop / b1_round / catchup |
| 无 | `event_time_mode` | info / local_time_stop / formal_encounter_b1 / global_pause_p0 |
| 无 | `frozen_world_hour` | 事件玩家冻结时间 |
| 无 | `gap_hours` | 世界与事件玩家时间差 |
| 无 | `catchup_required` | 是否需要 C1 |
| 无 | `default_resolution_used` | 是否 gap 到期默认 |

## 5. 交锋与突破字段

| 旧字段 / 结构 | 新字段 / 结构 | 说明 |
|---|---|---|
| `combat_command_templates` | 保留 | 但必须支持 B1 轮 |
| `breakthrough_chain_templates` | 保留 | 但突破挑战走 `FormalEncounterState` |
| `大境界突破 fixed_required_hours` | `FormalEncounterState.rounds` | 时间由交锋轮数产生 |
| `关键突破物开始时消耗` | `round_resource_consumption` | 资源消耗集中在轮内 |
| 无 | `default_strategy_refs` | 未提交时使用 |
| 无 | `round_real_seconds=60` | B1 窗口 |
| 无 | `round_game_hours=1` | 每轮游戏时间 |

## 7. 存档迁移建议

旧存档加载时：

```text
1. 若存在 current_turn_id，迁移为 legacy_turn_id，仅用于回放索引。
2. 若存在 turn_duration_days，忽略为主规则，写入 migration_notes。
3. 若存在 waiting_lock / settlement phase，迁移为 world_running 或 global_pause_p0，需人工确认当时是否有公共事件。
4. 若角色无当前行动且无队列，根据节点风险生成 FallbackState 并 force_speed=N1。
5. 若旧休整待机来源不明，默认按自动兜底处理，不允许 F1。
6. 若旧大境界突破行动正在执行，迁移为 breakthrough_open_pending 或 FormalEncounterState，需根据是否已进入挑战判定。
7. 若旧事件链挂起，按事件类型迁移为 LocalTimeStopState / FormalEncounterState / GlobalPauseState。
```

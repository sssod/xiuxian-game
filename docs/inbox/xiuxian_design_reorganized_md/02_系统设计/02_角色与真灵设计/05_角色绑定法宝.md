# 角色与真灵设计｜角色绑定法宝

## 1. 当前结论

本文标题沿用目录名，但规则层不把“角色绑定法宝”视为独立法宝类型。角色绑定是法宝实例的绑定与否状态标记。

MVP 阶段不开发完整绑定玩法，只保留基础状态设定。当前明确会使用角色绑定状态的法宝对象是储物空间法宝。其他法宝是否可以绑定、是否存在真灵绑定、宗门授权绑定、后手封存绑定或跨世继承绑定，暂不进入 MVP。

## 2. 基础概念

角色绑定状态指某件法宝实例与当前世角色建立绑定关系。它不是装备栏槽位，不是战力栏位，也不是法宝类型，而是一组归属与保护状态。

绑定后的基础规则：

1. `bind_state = character_bound` 表示法宝绑定对象为当前世角色。
2. 绑定后的法宝不会被普通窃取、扒取、战利品拾取或库存转移直接拿走。
3. 绑定对象死亡后，绑定法宝自主损毁。
4. 自主损毁发生在死亡结算中，不作为普通遗产、战利品或可搬空资产继续流转。
5. 损毁结果需要写入资产日志或事件结果，用于解释法宝去向。

## 3. MVP 边界

MVP 不开发以下内容：

1. 完整认主、解绑、改绑、继承绑定或解除绑定玩法。
2. 绑定状态带来的战斗加成、成长、亲和度、灵性培养或专属技能。
3. 真灵绑定状态、跨世绑定状态或绑定状态随真灵继承。
4. 绑定冲突、绑定争夺、破解绑定、绑定窃取或绑定转移事件链。
5. 绑定状态与后手容量、遗产封存、宗门权限之间的完整结算系统。

若 MVP 中需要展示或提及绑定储物空间法宝，只按概念表达，不开放独立操作流程。

## 4. 字段口径

若后续需要落到数据字段，只使用以下概念字段名，并以法宝文档中的字段为准继续扩展：

```yaml
ArtifactBindingConcept:
  bind_state: unbound | character_bound
  bound_target_ref: string | null
  theft_protection: none | bound_unstealable
  destroy_policy: none | destroy_on_bound_target_death
```

字段含义：

| 字段 | 规则含义 |
| --- | --- |
| `bind_state` | 当前是否绑定当前世角色 |
| `bound_target_ref` | 绑定对象引用，MVP 概念上只指当前世角色 |
| `theft_protection` | 绑定后不被普通窃取或战利品拾取 |
| `destroy_policy` | 绑定对象死亡后自主损毁 |

## 5. 与真灵的关系

角色绑定状态目前不等于真灵绑定状态。

当前口径：

1. 绑定对象死亡后，绑定法宝自主损毁。
2. 损毁后的法宝不默认跨世继承。
3. 真灵不默认获得该法宝的所有权、能力、内部资产或残留效果。
4. 若未来需要真灵绑定或跨世继承，必须另行裁决，不从当前角色绑定概念自动推导。
5. 即使未来允许法宝进入真灵藏宝，也必须走正式后手封存流程，并受真灵藏宝设置数量和单个容量限制。

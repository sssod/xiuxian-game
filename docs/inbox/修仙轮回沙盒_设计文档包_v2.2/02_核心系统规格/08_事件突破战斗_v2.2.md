# 事件、突破与战斗事件链（v2.2）

## 0. 文档定位

本文整理常规事件框架、选择事件、窗口事件、突破事件链和战斗 / 斗法事件链。

事件系统负责把玩家、NPC、宗门、节点和世界状态在特定上下文中转化为事件链、选择、判定和结果包。所有结果必须交给 S1 统一回写。

新版重点：事件结果统一返回 `consumed_hours`，用于修正个人行动指令时间线；旧 `consumed_ticks` 废弃。

---

## 1. 事件系统定位

S10 是世界演化的事件层。

一句话定位：

> S10 决定玩家、宗门和世界在某个时间、地点、状态下会触发什么事件，以及事件结果如何改变角色、节点、宗门和日志。

S10 是事件框架，不替代突破、战斗、死亡、后手回收等专用事件链。

---

## 2. 事件分类

MVP 事件分为：

1. 移动事件。
2. 节点事件。
3. 宗门事件。
4. 世界刷新事件。
5. 秘境 / 窗口事件。
6. 控制权变化事件。
7. 传闻生成事件。
8. 专用事件链入口。

专用事件链包括：

- 突破。
- 战斗。
- 死亡 / 转世。
- 前世后手回收。

## 6. 选择事件

选择事件是最核心的常规事件类型。

本质：

> 系统抛出一个可结算的局面问题，玩家用选项回答这个问题，系统根据回答生成后果。

事件选项不是同义按钮集合，而是不同解题姿态。

五类选择维度：

1. 正面应对。
2. 出奇制胜。
3. 逃避推诿。
4. 解构问题。
5. 欺诈蒙骗。

常规选择事件主选项区合理数量为 1–3 个。高级、稀有、解释成本高的选项可放入溢出区。

事件选项允许模板声明临时资源输入槽。资源输入槽不是独立行动，而是当前事件选项的附加条件或子选项。

规则：

- 事件模板必须显式声明可用资源类型、效果通道、兼容标签和叠加限制。
- 临时追加资源只能从选项确认后的时间点开始生效，不得追溯影响已结算小时。
- 资源必须通过统一资源使用接口校验、消耗、写日志，并通过 S1 结果包回写。
- 突破事件链关键资源按突破规则处理，不进入普通 `ActiveResourceEffect`；普通丹药、符箓或临时增益可按资源模板决定是否产生残余效果。

## 7. 事件对时间线的影响

事件结果可以：

- 消耗小时。
- 使当前行动延误。
- 使行动提前完成。
- 中断当前行动。
- 取消后续行动。
- 改变位置。
- 改变资源状态。
- 改变风险状态。
- 触发子事件。

示例：

```text
移动途中遭遇斗法，消耗 8 小时。
→ 当前移动完成时间推迟 8 小时。
→ 后续采购、探索开始时间随之推迟。
→ 回合结束时显示实际探索投入减少。
```

## 8. 插入事件链与挂起

结算阶段不允许玩家主动暂停。

以下情况可以被动挂起：

- 当前玩家触发需要响应的插入事件链。
- 多人交叉事件链需要等待其他玩家响应。
- 战斗 / 突破 / 死亡 / 后手回收等高价值专用链。

低价值事件默认自动处理，只进入摘要或日志。

高价值事件进入事件响应界面。若玩家离线，则按托管安全规则处理，不得自动执行重大不可逆选择。

## 9. 突破事件链定位

大境界突破是：

```text
固定执行时间持续行动
+ 关键突破物不可逆消耗
+ 高价值专用事件链
```

突破核心价值：

- 让玩家围绕突破进行长期准备。
- 让玩家在突破前理解短板和风险。
- 让突破过程中有有意义的交互。
- 让失败输出可解释标签。
- 让失败为下一世提供优化方向。

---

## 10. 大小境界边界

### 10.1 小境界升级

小境界升级是阶段内成长节点，不进入高风险突破链。

不做：

- 不消耗关键突破物。
- 不进入突破事件链。
- 不触发死亡 / 转世。
- 不生成复杂外部干扰。
- 不需要挑战交锋格。

### 10.2 大境界突破

大境界突破必须满足：

1. 玩家主动发起。
2. 至少消耗一个关键突破物。
3. 属于固定执行时间持续行动。
4. 进入事件链后不可回头补准备。
5. 结果可能改变本世路线、宗门地位、轮回账本和下一世规划。

---

## 11. 突破三层体验

```text
长期准备层
→ 破境确认层
→ 事件链交锋层
```

长期准备层：

- 修炼。
- 提纯 / 巩固。
- 研习主修道功，提高掌握度、当前有效上限与单位时间收益。
- 准备关键突破物。
- 选择突破地点。
- 寻求护法。
- 争取宗门支持。
- 处理心境 / 因果。
- 回收前世后手。

破境确认层：

- 显示固定执行时间。
- 显示关键消耗。
- 显示风险档位。
- 显示主要短板。
- 显示可能失败标签方向。
- 明确不可逆消耗。

事件链交锋层：

- 玩家无法再回头准备。
- 通过指令、资源和判断影响结果质量。

突破模板读取规则：

- 大境界突破模板类型来自主修道功的 `breakthrough_transition_support` 与路线特质。
- 道功掌握度只影响角色是否承载得住目标阶段、风险短板和部分可追回收益。
- 掌握度不改变突破模板类型，不直接提高修为纯度收益，不改变小境界升级奖励质量。
- 关键突破物是进入不可回头事件链的承诺成本，普通行动资源输入不能替代关键突破物。

---

## 12. 关键突破物

关键突破物是玩家从准备阶段跨入不可回头突破事件链的承诺成本。

规则：

- 开始大境界突破至少需要 1 个关键突破物。
- 关键突破物是具体物品实例，不是抽象货币。
- 事件链正式创建时立即消耗。
- 无论成功、失败、中断、残缺突破或身死转世都不返还。
- 必须写入资源使用日志和突破结果包。

---

## 13. 战斗 / 斗法事件链

战斗不是常规实时操作，而是专用事件链。

战斗触发来源：

- 移动事件。
- 节点事件。
- 宗门事件。
- 后手回收。
- 秘境探索。
- 突破干扰。

战斗结果可以：

- 消耗小时。
- 改变角色状态。
- 改变位置。
- 消耗法宝、符箓、丹药。
- 生成战利品。
- 中断或延误后续行动。
- 触发死亡 / 转世。
- 改变节点或宗门状态。

战斗战利品必须来自：

- 持久化随身 / 可调用资产。
- 事件锁定奖励包。
- 预算生成奖励。

不得在战斗开始时临时初始化 NPC 完整库存。

```text
turn_id
world_day
world_hour
trigger_node_id
trigger_route_segment
actor_refs
choice_ref
consumed_hours
result_package_refs
visibility_level
```

高价值事件额外写入：

- 世界日志。
- 角色日志。
- 宗门摘要。
- 轮回账本。
- Debug 日志。

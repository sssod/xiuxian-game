# 宗门组织、库存与宗门 AI 持续行动（v2.3）

## 1. 系统定位

宗门是组织资源平台与世界演化实体。玩家通过身份、贡献、职位、资源申请、NPC 支持、个人行动和事件结果影响宗门；宗门 AI 自行选择和维护持续行动。

每个宗门同一时间最多拥有一个 active `SectContinuousActionState`。

---

```text
SectState {

  headquarters_node_id: String
  influence_nodes: Array

  key_npc_refs: Array

  ai_policy_ref: String
  visible_rumor_refs: Array
  last_settled_world_day: int
  last_settled_world_hour: int
}
```

## 3. 玩家与宗门关系

```text
SectMembership {
  character_id: String
  sect_id: String
  rank: String
  contribution: number
  reputation: number
  role_tags: Array
  resource_access_level: String
  mentor_refs: Array
  faction_relation_tags: Array
}
```

玩家影响宗门的入口：

```text
申请资源；
接受宗门任务；
拜访关键 NPC；
参与宗门事件；
贡献物资；
公开突破或隐瞒突破；
影响节点与传闻；
触发或回收后手。
```

## 4. SectInventory

```text
SectInventory {

  pills: Array
  talismans: Array
```

## 5. 资源申请

资源申请可以作为 `Command.command_type=apply_resource` 或事件选项进入系统。

```text
SectResourceRequest {
  request_id: String
  character_id: String
  sect_id: String
  requested_resource_refs: Array
  purpose_command_ref: String | null
  submitted_world_day: int
  submitted_world_hour: int
  status: pending | approved | rejected | partial | expired
  result_package_refs: Array
}
```

审批依据：

```text
职位；
贡献；
库存；
宗门当前行动；
NPC 支持；
节点压力；
事件状态；
请求用途；
公开影响。
```

## 6. SectContinuousActionState

```text
SectContinuousActionState {
  action_id: String
  sect_id: String
  action_type: recruit | patrol | gather_resource | expand_influence | defend_node | research_method | support_member | trade | recover
  target_node_id: String | null
  started_world_day: int
  started_world_hour: int
  expected_duration_hours: int | null
  progress_hours: int
  resource_inputs: Array
  ai_reason_tags: Array
  status: active | completed | interrupted | failed
  result_package_refs: Array
}
```

宗门 AI 每小时推进当前持续行动，并在完成、失败或中断后由 AI 选择下一项。

---

## 7. 宗门 AI 选择原则

宗门 AI 输入：

```text
宗门库存；
成员状态；
节点影响；
外部威胁；
资源缺口；
秘境窗口；
近期事件；
宗门性格；
玩家贡献和请求；
世界宏观周期。
```

宗门 AI 输出：

```text
SectContinuousActionState；
宗门库存变更；
节点影响变更；
NPC 行动；
任务与传闻；
资源申请结果；
公开日志和隐藏日志。
```

---

## 8. 与玩家行动的关系

玩家不能直接替宗门排持续行动。玩家个人行动可以改变宗门 AI 的输入：

```text
提升贡献；
提供资源；
完成任务；
支援战斗；
说服 NPC；
公开或隐瞒信息；
占领或发现节点；
处理宗门事件。
```

亲自介入使用个人 `Command`，并通过 S1 结果包影响宗门。

---

## 9. 日志与可见性

宗门输出日志分层：

```text
本人可见；
宗门成员可见；
公开传闻；
隐藏世界日志；
Debug 日志。
```

宗门传闻不得泄露不具备可见性的私人事件归因。

---

## 10. 验收要点

```text
每个宗门同一时间最多一个 active SectContinuousActionState；
宗门 AI 可按 world_hour 推进；
玩家资源申请能进入校验、结果包和日志；
宗门库存可作为 ActionResourceInputBinding 来源；
宗门节点影响可改变地图和事件窗口；
宗门 AI 步骤进入 TimelineReplay.sect_ai_steps。
```

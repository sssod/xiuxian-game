# 宗门系统设计

## 1. 当前定位

宗门是玩家长期成长的平台与沙盒世界演化主体，但不是玩家本体。玩家死亡或转世后，宗门仍由 AI 托管并继续演化。

## 2. 身份与权限

MVP 身份序列：

```text
外门弟子 → 内门弟子 → 真传弟子 → 执事 → 长老
```

MVP 不开放宗主。M3 或第三大境界起点后进入长老序列或等价高层决策体验。

权限标签示例：

```text
request_resources
use_training_site
request_breakthrough_support
propose_sect_action
decide_sect_action
lead_task
access_inner_archive
manage_node_affairs
assign_guard_or_support
```

## 3. 宗门资源

宗门追踪五类资源：灵石、修炼资源、材料/矿材、人力/弟子规模、声望/影响力。宗门发放给玩家或 NPC 的资源必须来自真实库存。贡献不是货币，不能绕过库存检查。

## 4. 宗门行动

每个宗门每季度始终只有 1 个宗门主行动。六类主行动：开采/资源介入、驻守/控制强化、探索、远征、建设、培养。

## 5. MVP 不做

- 宗门内部派系 / 山头变量。
- 玩家直接夺宗主位。
- 复杂同宗议会。
- 通过宗门行动直接迫害同宗玩家长期体验。

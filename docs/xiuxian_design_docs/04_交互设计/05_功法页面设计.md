# 交互设计｜功法页面设计

## 1. 当前状态

本页面仍处于交互约束草案阶段，当前只固定功法页面对道功、法门、主修状态、掌握度、道功修炼特性、道功突破模板、功法载体和学习 / 合成边界的展示要求，不维护完整视觉稿、Figma 节点或旧来源清单。

功法页面服务于玩家理解“我拥有哪些功法信息、哪些能学、哪些只是载体、当前主修是什么、不同道功修炼速度、法力密度和突破模板差异是什么”。它不替代行动指令页的研习 / 吐纳行动提交，也不替代储物空间页的物品转移与合成资产流转。

## 3. 用户目标与入口

玩家进入功法页面时，需要完成以下目标：

1. 区分道功和法门。
2. 查看当前主修道功、主修锁定或更换提醒。
3. 查看道功的吸收上限、CP 转化率、法力密度、纯度区间和速成 / 均衡 / 凝实标签。
4. 查看道功详情中的突破模板收益、主要挑战倾向、可能伤损和后期是否包含雷劫阶段。
5. 查看已掌握功法的掌握度、当前可修上限和理论最高上限。
6. 查看残页、篇章、完整功法的差异和合成状态。
7. 判断哪些完整功法可学习、可研习、可设为主修或只可查看。
8. 跳转到修炼行动、功法载体合成或储物空间相关入口。

入口来自主界面功法入口、角色页主修摘要、修为页上限提示、储物空间中的功法载体和功法学习结果包。

## 4. 必须表达

1. 道功 / 法门分类。
2. 主修道功状态。
3. 道功修炼特性摘要：吸收上限、CP 转化率、法力放大系数、纯度下限 / 上限、巩固成本倾向和体验标签。
4. 道功突破模板摘要：成功收益倾向、主要挑战属性、可能伤损、资源倾向和后期是否包含雷劫阶段。
5. 强道功的表达应是“收益更高、突破模板更难”，而不是“更容易完美突破”。
6. 掌握度、当前可修上限、理论最高上限。
7. 残页、篇章、完整功法的差异。
8. 残页和篇章不可学习，只能合成。
9. 完整功法是唯一可学习来源。
10. 主修道功锁定提醒应常驻提示，不在行动规划中强制阻止所有可能升入下一小境界的吐纳。
11. 掌握度影响学习、当前可修上限、过程效率、可见性和稳定性；普通页面不得暗示掌握度会直接提高最终法力、纯度系数、突破模板类型或历史大境界质量。

## 5. 页面区块与信息优先级

界面类型与尺寸约束：

1. 类型：全屏二级页面 / 功法管理专项页。
2. 占据位置：从主界面功法入口、角色页主修摘要、修为页上限提示或储物空间功法载体进入后替换主工作区；若当前 UI 没有固定全局框架，则按完整游戏视口处理。
3. 尺寸等级：主工作区级。主修、道功特性、突破模板、已学功法、可学习功法和载体合成需要在同一主页面内分区表达，不应按小型列表弹窗或物品详情抽屉尺寸创建页面本体。

推荐信息优先级：

1. 主修区：当前主修道功、锁定状态、更换窗口、上限影响、本大境界记录和提示。
2. 道功特性区：吸收上限、CP 转化率、法力密度、纯度范围、巩固成本倾向和速成 / 均衡 / 凝实标签。
3. 突破模板区：成功收益倾向、主要挑战属性、可能伤损、资源倾向、雷劫阶段标记和失败标签方向。
4. 已学功法区：道功、法门、掌握度、可研习状态和能力解锁摘要。
5. 可学习功法区：完整功法来源、学习条件、相性和学习入口。
6. 功法载体区：残页、篇章、完整功法、合成进度和归属状态。
7. 结果与日志区：学习、研习、合成、主修变更和掌握度变化摘要。

页面不固定列表样式、标签样式、排序控件或具体合成组件布局。

## 6. 操作流程与状态

学习完整功法：

```text
选择完整功法
→ 查看学习条件、来源和风险
→ 满足条件后提交学习或研习行动
→ 结果回写掌握度和日志
```

合成功法载体：

```text
查看残页和篇章
→ 满足合成条件
→ 跳转储物或合成入口确认来源资产
→ 生成完整功法后才可学习
```

设置主修道功：

```text
选择可主修道功
→ 查看更换窗口、锁定影响、本大境界记录、上限变化和法力密度变化
→ 查看该道功对应突破模板收益与主要挑战倾向
→ 确认后更新主修状态
→ 修为页面读取新的主修口径
```

研习或吐纳：

```text
选择已学功法
→ 查看可研习或吐纳入口
→ 跳转指令管理或修炼行动
```

## 7. 不表达或 Debug 边界

普通功法页面不展示完整公式、隐藏适配权重、掉落权重、Debug ID、内部合成归属链或未揭示功法内容。道功的吸收上限、转化率、法力密度和纯度范围应以标签、区间或摘要呈现，不展示逐项调参公式。

功法页面不应表达为：

1. 残页和篇章可以直接学习。
2. 不完整载体等同完整功法。
3. 主修提醒会强制阻止所有吐纳。
4. 法门和道功是同一类修炼主线。
5. 功法载体在页面查看时自动移动或自动合成。
6. CP 转化率低就代表道功弱。
7. 掌握度越高就直接提高最终法力、纯度或历史大境界质量。
8. 独立突破品质、完美突破、正常突破或残缺突破。
9. 强道功更容易完美突破。

# 经济系统设计｜地图资源产出

## 1. 当前结论

地图资源产出由地图节点、广义资源槽、资源槽附属设施、控制权、宗门持续行动和世界小时结算共同决定。

节点是主单位；资源不是独立漂浮物，而是挂载在地理节点上的资源槽。资源槽的通用字段、简化类型和人工扩展规则，以《资源槽详细设定》（`../07_地图节点设计/02_资源槽详细设定.md`）为准；一槽一设施类别约束，以《资源槽附属设施通用规则》（`../08_人造设施与洞天福地设计/03_资源槽附属设施通用规则.md`）为准。本文只记录地图资源如何进入经济结算和库存流转。

灵石、低阶货币与聚灵石的对象定义、加工和消耗接口统一见《../05_物品设计/05_灵石及聚灵石.md》。本文只说明地图资源如何成为库存、资源池或设施输入，不重复维护币制规则。

## 2. 节点常态产出流程

```text
节点拥有资源槽
→ 节点等级决定自然资源槽基线、资源品级范围和节点灵气基础
→ 宗门或势力控制节点 / 资源槽附属设施正常运转
→ 按世界小时推进并在宏观周期摘要中汇总产出
→ 写入 sect_storage / node_storage
→ 写入库存日志
```

规则：

- 已控制资源节点的基础产出不占宗门持续行动。
- 资源槽的自然生成基线、资源品级、可波动范围和稀有变体概率受节点等级影响；节点等级也影响灵气浓度、灵气品质、污染、稳定度和相性权重。
- 产出受控制权、影响力、资源丰度、资源槽规模、资源槽附属设施状态、设施规模、设施等级、灾害、敌对干扰、人力占用影响。
- 产出优先进入宗门抽象库存或节点库存，库存底层规则见《../06_储物空间系统设计/03_库存系统.md》。
- 若产出需要具体物品形态，再由物品系统转换为 ItemStack / ItemInstance。
- 每个资源槽和附属设施都应记录自身规模或规模上限；MVP 暂时不限制单个地图节点的资源槽总数量。
- 常规人工扩展资源槽本身不产生特殊资源。它只能作为普通 `aura_node` 承载常规设施，且灵气浓度低于当前地图节点平均浓度；经济收益必须来自附属设施、投入资源、人力维护或后续事件，而不是来自扩展槽自带特殊属性。
- 个人洞府或普通藏宝附着自然资源槽时，该槽被设施化占用，不能同时作为灵田、矿场、市场、传送阵或其他生产 / 公共设施产出来源；恢复常态产出或改建前，必须先清理、迁移、拆除或事件处理洞府 / 藏宝。

## 3. 资源槽类型的产出口径

MVP 使用《资源槽详细设定》（`../07_地图节点设计/02_资源槽详细设定.md`）中的简化资源槽类型。经济系统按下表理解产出来源，不在本文维护第二套资源槽类型表。

| 资源槽类型 | 经济产出口径 |
| --- | --- |
| `aura_node` | 自然灵气节点可提供修炼环境、常规设施承载和低到中强度资源生产条件；人工常规扩展的 `aura_node` 只提供普通设施承载，不自带稀有产出 |
| `material_deposit` | 先形成资源池或资源量，再通过采集、开采、维护、炼制或加工转为库存资产 |
| `ecology_site` | 通过狩猎、采集、保全、驯养或事件结算形成材料、风险事件或驯养机会 |
| `space_site` | 通常不自动产出资源，主要提供洞府、仓储、防护、隐蔽、休整或隐藏入口能力；若有产出，必须来自附属设施或事件 |
| `blessed_land` | 可提供修炼、突破、参悟或稀有资源机会，但必须有明确来源、窗口、争夺状态或预算记录，不作为常规可复制产能 |
| `opportunity_site` | 多数是限时入口、资源名额或争夺条件；产出来自机会窗口结果，不进入常态小时产出 |
| `special` | 按模板声明产出来源、预算、可见性和入库规则 |

`aura_node` 可以承载灵田、修炼设施、传送阵、市场、行政建筑等常规设施。经济系统只关心该槽当前附属设施类别、规模、维护、人力和库存流向，不把灵田、市场、传送阵再拆成新的资源槽类型。

## 4. 宗门持续行动产出

每个宗门同一时间最多拥有一个 active `SectContinuousActionState`。开采 / 资源介入、探索、建设、远征等持续行动都可能产生资源结果，但不应替代已控资源节点的常态产出。

建设或扩展资源槽属于持续行动或节点建设结果之一。MVP 只允许常规人工扩展；扩展完成后新增的是普通 `aura_node` 资源槽，规模可由建设方案设定，但不带特殊属性，不产生高于节点平均灵气的环境收益，也不自动打开稀有资源预算。

## 5. 阶段预算修正

数值草案提出：玩家首次突破到某大境界后，世界激活对应阶段预算。预算进入节点资源槽、宗门库存、市场交易、机会窗口、NPC 个人资产或事件投放。预算打开提供机会，不自动赠送修为。

## 6. 缺口

- ResourceSlot 表、丰度、再生周期、灾害、附属设施产能公式未定。
- 各境界阶段预算的具体数值未定。
- 资源点模板与地图实例未定。
- 常规人工扩展的建设成本、时间、人力和规模公式未定。

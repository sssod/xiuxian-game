# 主题设计｜飞升胜利主题

适用范围：首个主题的体验目标、标准局长、六境成长终点、飞升地点、终局公告、阻拦、共同胜利和全体一致主动结束。

## 1. 主题定位

首个主题以个人修仙竞速为主，地图占地、资源生产、功法构筑、重点 PVE 和玩家竞争共同服务飞升进度。标准支持 `2—4` 人、目标 `90—120` 分钟，期望第 `24` 个外界回合完成飞升，合理胜利验收区间为 `20—24—28`。

第 `20 / 24 / 28` 回合不是强制终局；主题没有绝对最终回合或替代胜者，也没有第 `28` 回合后的专属加时加速。对局在出现合法飞升胜利前持续，或由全体未退隐玩家亲自一致同意共同中止。

## 2. 境界路线

主题只使用：

```text
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → 飞升
```

炼虚与合体不进入该主题。炼气至化神各有初期、中期、后期、圆满四段；大乘不设置局内小境界。所有玩家从炼气初期、当前小境界 `0%` 开始。

基准首次到达为筑基 `R5`、金丹 `R9`、元婴 `R13`、化神 `R17`、大乘 `R21`、飞升 `R24`。这些是数值验收锚点，不是截止线。

## 3. 胜利流程

```text
通过自动修炼、经济、经营与构筑推进
→ 完成筑基和四场固定渡劫
→ 达到大乘
→ 前往主题指定飞升地点
→ 通过地点与事件前置检查
→ 执行无参数“飞升”主要行动
→ 回合末统一判定胜利
```

玩家在规划阶段锁定飞升行动。未抵达只表示本回合无法开始，不是飞升本体失败。角色通过全部前置并正式开始飞升后，飞升过程本身不会失败，也不能被中途打断。

## 4. 阻拦边界

其他玩家可以在飞升正式开始前，通过合法路线控制、关隘、相遇、仇敌事件、战斗、竞价或主题事件阻止大乘玩家抵达或满足前置。前置战斗中死亡触发转世；重伤或平局使本回合无法开始飞升。前置普通战斗使用其事件公开的逃遁规则。

节点主导权本身不允许直接取消已经合法抵达角色的飞升资格；任何地点专有前置必须在地图与主题内容表中显式声明。

## 5. 大乘公告

玩家在本局首次达到大乘时公告一次：

- 当时所在位置；
- 姓名、头像、所属宗门等基础身份。

不公告属性、灵石、物品、功法、持续状态或隐藏计划。公告后不持续追踪，后续位置继续遵守普通地图可见性。

## 6. 共同胜利

1. 任一玩家完成飞升后，当前回合继续结算。
2. 回合末所有已经完成飞升的玩家共同获胜，随后结束对局。
3. 多名大乘玩家同轮抵达时，彼此不存在合法阻止关系的，不因争夺飞升资格自动触发竞争。
4. 到达和完成先后只影响展示排序，不影响共同胜利资格。

## 7. 全体一致主动结束

任一连接正常且未退隐玩家可以发起结束表决，同一外界回合最多一次。发起后全局暂停，只有 `30` 秒表决、连接检测、重连和表决界面继续；阶段计时、思考储备、断线保护、连续掉线累计、输入、战斗、动画和游戏结算全部冻结。

全部未退隐玩家必须亲自同意；掉线、托管、未来策略 AI、房主和会话协调身份都不能代投。全员同意后仍有 `3` 秒撤回缓冲。失败时从暂停前同一确定状态恢复。

结束结果按隐藏规划锁定状态处理：

- 规划尚未全局锁定：完成当前不可拆分即时结算后结束，未锁定草稿与计划无效；
- 规划已经全局锁定：恢复并完整结算本轮；
- 若完整结算产生合法飞升者，优先记录正常飞升胜利；否则记录“共同中止、无胜者”。

共同中止可以展示公开历程和最终状态供复盘，但不得按修为、地产、灵石、战力或综合评分生成替代名次，也不产生飞升胜利记录。详细计时与异常流程由《[单局流程与同步回合](../02_系统设计/01_单局流程与同步回合.md)》维护。

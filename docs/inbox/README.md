# Inbox

本目录是原始资料档案区，用于保存历史设计草稿、Notion 导出、阶段性补充规则和旧版本包。

当前主源：

```text
docs/inbox/修仙游戏设计方案总目录/修仙轮回沙盒_设计文档包_v2 3/
```

使用规则：

- `docs/inbox` 不作为最终文档承载区。
- 迁移正式规则时，优先读取 v2.3 README 与对应 v2.3 主源。
- 旧版本和 `[已过时]` 文件只用于冲突比对、来源追溯和背景补充。
- 正式交付文档应沉淀到 `docs/concept`、`docs/game-design`、`docs/systems-design`、`docs/ui-design`、`docs/worldbuilding`、`docs/production`、`docs/references`、`docs/research` 或 `docs/playtest`。

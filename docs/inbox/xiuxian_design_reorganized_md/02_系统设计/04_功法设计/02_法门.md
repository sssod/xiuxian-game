# 功法设计｜法门

## 1. 文档边界

本文记录“法门”的核心定义、设计理念、能力分类、掌握度与数据口径。

本文只处理法门作为功法类型本身的规则，不展开：

1. 道功的修为路线、修炼上限、主动吐纳和突破路线。
2. 主修道功的设置、切换、锁定和更换窗口。
3. 残页、篇章、完整功法等物品链。
4. 战斗、移动、探索、生产、事件系统各自的完整结算公式。

边界口径：

| 概念 | 本文是否负责 | 说明 |
| --- | --- | --- |
| 功法 | 只定义总分类口径 | 功法是泛称，规则层应拆为道功与法门 |
| 道功 | 不负责 | 道功推动修为并可设为主修 |
| 法门 | 负责 | 法门提供能力、指令、事件选项和效率 |
| 主修功法 | 不负责 | 法门不能设为主修 |
| 功法载体 | 不负责 | 法门也可由完整功法学习，但载体规则归物品系统 |

## 2. 核心定义

法门是不直接推动修为进度的功法类型。它主要提供战斗、探索、采集、移动、生产、事件处理和资源效率能力。

法门的价值应回到时间与资源效率：

```text
同样投入 5 天，掌握某法门后，角色能否更快移动、更安全探索、更高效采集、更好处理事件或更少损耗资源。
```

法门不是主修道功的弱化版本，也不是直接修为倍率。它回答的是“角色会做什么、能选择什么、做得是否更稳更省”，而不是“角色当前境界能推进到哪里”。

## 3. 当前定版规则

1. 法门不能设为主修。
2. 法门不直接推动修为进度。
3. 法门不决定当前可修上限。
4. 法门不决定大境界突破模板类型。
5. 法门可以解锁战斗指令、行动标签、事件选项、生产配方、风险规避能力或资源效率修正。
6. 法门掌握度可以影响解锁强度、稳定性、消耗、成功率、效果质量和风险。
7. 法门可以与灵根、资源、装备、地点和事件标签产生使用相性，但这种相性不直接改变修为进度。

## 4. 法门负责什么

法门负责：

1. 战斗指令和战斗策略。
2. 移动、逃遁、追踪、隐匿和路径开销修正。
3. 探索、采集、寻宝、秘境入口识别和隐藏层发现。
4. 炼丹、炼器、制符、阵法、医术、卜算等技艺成长。
5. 事件选项、事件判定修正和风险规避。
6. 资源获取效率、资源损耗降低、品质提升或副产物产生。
7. 某些生产配方、行动模板或行动修正的解锁。

法门不负责：

1. 主动吐纳的基础修为推进。
2. 自动运转的基础修为收益。
3. 当前可修上限。
4. 主修道功记录。
5. 大境界突破模板类型。
6. 残页或篇章的合成。

## 5. 分类示例

| 法门类型 | 主要作用 | 示例表现 |
| --- | --- | --- |
| 战斗法门 | 解锁迎战选项、战斗指令、克制关系 | 雷法、剑诀、护身术、封禁术 |
| 轻身 / 移动法门 | 影响路径开销、逃遁、追击和移动事件反馈 | 轻身术、遁法、御风诀 |
| 探索法门 | 提高发现隐藏层、秘境入口、前世线索和陷阱的能力 | 望气术、寻脉术、破障术 |
| 采集法门 | 提高资源识别、采集效率、损耗控制或品质 | 采药诀、寻矿术、控火采炼 |
| 生产法门 | 影响配方成功率、品质、损耗或副产物 | 炼丹、炼器、制符、阵法 |
| 生存法门 | 提供解毒、避瘴、疗伤、藏息、护身等能力 | 避瘴诀、敛息术、护体术 |
| 信息法门 | 改善情报、卜算、推演、识别和预警 | 卜算术、鉴宝术、观星术 |

旧文档中的“术法”“神通”“技艺”“轻身功法”“战斗功法”“养身功法”等，如果主要提供能力、指令、事件选项或效率，而不直接推动修为和上限，应统一归入法门。

## 6. 学习与研习

常规法门流程：

```text
获得完整法门载体
→ 选择研习功法
→ 达到入门阈值
→ 创建 MethodState，进入 learned level 1
→ 解锁对应能力、指令、事件选项或效率修正
```

新手流程、师承传授、事件奖励或剧情节点可以直接授予基础法门 learned level 1。该例外用于教学和节奏，不代表残页或篇章可以直接学习。

研习法门属于可选投入执行时间的个人持续行动。它读取：

```text
实际投入小时
悟性 aptitude_comprehension
法门阶级 tier_code
法门品级 quality_code
导师
藏经阁、练功场、工坊、演武场等设施或事件加成
当前神念状态
前置知识、基础法门、装备或资源条件
```

研习法门可以产出：

1. `MethodState` 经验增加。
2. `MethodState` 掌握等级提升。
3. 未入门法门进入 learned level 1。
4. 战斗指令解锁或强化。
5. 行动标签、生产配方或事件选项解锁。
6. 资源效率、成功率、稳定性、消耗、品质或风险修正。

研习法门不能产出：

1. 直接修为进度。
2. 当前可修上限提高。
3. 大境界突破模板类型变化。
4. 缺失残页或篇章自动补齐。
5. 残页或篇章直接变成可用内容。

悟性丹、定心丹等资源可以作为研习法门的行动资源输入，但它们只在研习行动实际执行时提供悟性、稳定性或风险修正，不在非研习行动中产生法门经验。

## 7. 与灵根和资源相性

法门与灵根的关系主要是使用相性，不直接改变修为进度。

高相性可以表现为：

1. 指令更稳定。
2. 元气或神念消耗更低。
3. 效果质量更好。
4. 失败波动更小。
5. 解锁门槛更低。

低相性可以表现为：

1. 消耗更高。
2. 效果波动更大。
3. 失败或反噬风险更高。
4. 需要更高掌握度、境界、资源或装备才能稳定使用。

示例：

```text
雷系灵根相性高：
使用《雷芒指》时指令稳定性、消耗效率或效果质量更好。

木系灵根相性低：
使用火爆类法门时可能消耗更高、效果不稳定或解锁门槛更高。
```

## 8. 与道功的区别

| 判断问题 | 道功 | 法门 |
| --- | --- | --- |
| 是否直接推动修为 | 是 | 否 |
| 是否可设为主修 | 是 | 否 |
| 是否决定当前可修上限 | 是 | 否 |
| 是否决定大境界突破路线标签 | 是 | 否 |
| 是否解锁战斗 / 事件 / 行动能力 | 可有少量附带 | 是主要职责 |
| 是否可被研习提升掌握度 | 是 | 是 |
| 是否可由完整功法学习 | 是 | 是 |

若一个设计同时具备修为推进和能力展开，应按主职责拆分：

1. 推动修为、上限、突破路线的部分写入道功。
2. 战斗、探索、采集、生产、移动、事件选项和效率部分写入法门。

## 9. 数据口径

法门模板建议字段：

```yaml
TechniqueMethod:
  method_id: string
  method_type: technique_method
  display_name: string
  tier_code: string
  quality_code: string
  technique_category: string
  route_affinity_tags: list
  root_affinity_tags: list
  required_realm_tags: list
  prerequisite_method_ids: list
  unlocks_action_tags: list
  unlocks_combat_commands: list
  unlocks_event_option_tags: list
  unlocks_recipe_refs: list
  efficiency_modifiers: list
  risk_modifiers: list
  mastery_curve_id: string
  effect_scaling_profile: map
```

角色对某门法门的掌握状态由 `MethodState` 表达。`MethodState` 不保存残页或篇章收集进度。

```yaml
MethodState:
  method_state_id: string
  character_id: string
  method_id: string
  method_type: technique_method
  learned_from_carrier_id: string
  mastery_level: number
  mastery_exp: number
  unlocked_action_tags: list
  unlocked_combat_commands: list
  unlocked_event_option_tags: list
  unlocked_effect_refs: list
  last_practiced_world_day: number
  last_practiced_world_hour: number
```

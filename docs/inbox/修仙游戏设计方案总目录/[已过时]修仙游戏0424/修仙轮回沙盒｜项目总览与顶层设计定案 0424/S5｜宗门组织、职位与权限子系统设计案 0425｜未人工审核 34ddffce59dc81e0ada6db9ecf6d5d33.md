## 1. 子系统定位

S5 定义宗门作为组织性资源平台时，玩家如何加入、获得身份、提升职位、调用权限并影响宗门决策。

一句话定位：

> S5 决定玩家在宗门中“是什么身份、能影响什么、能申请什么、能调动什么权限”。
> 

宗门不是玩家本体。玩家死亡、转世、离宗或失势后，宗门仍继续存在并由 AI 托管演化。

## 2. MVP 宗门身份层级

MVP 固定五级身份：

```
外门弟子
→ 内门弟子
→ 真传弟子
→ 执事
→ 长老
```

MVP 不开放宗主职位。M3 或等价第三大境界起点后，应允许玩家进入长老序列或等价高层决策体验。

## 3. 身份层级含义

- 外门弟子：入门身份，主要获得基础功法、基础任务、最低宗门保护。
- 内门弟子：稳定修行身份，解锁更好的修炼设施、任务层级和宗门关系入口。
- 真传弟子：重点培养身份，能接触高价值资源、护法、突破名额和核心任务。
- 执事：组织执行层，能影响低到中级宗门行动，管理部分资源或节点事务。
- 长老：宗门高层，能直接影响重大宗门行动、节点控制、培养方向和突破支持。

## 4. 权限类型

MVP 权限不做复杂树状官僚体系，先拆成可检查标签：

```
SectPermission {
  request_resources
  use_training_site
  request_breakthrough_support
  propose_sect_action
  decide_sect_action
  lead_task
  access_inner_archive
  manage_node_affairs
  assign_guard_or_support
}
```

权限来源：

1. 宗门身份层级。
2. 具体职位。
3. 门内声望。
4. 贡献记录。
5. 关键 NPC 支持。
6. 特殊事件授权。

### 4.1 已确定决策：MVP 不引入宗门内部派系 / 山头

**人工决策：MVP 不引入宗门内部派系 / 山头作为系统变量。**

规则口径：

- 宗门内部影响力先通过身份、职位、贡献、门内声望、关键 NPC 支持与特殊事件授权表达。
- 不建立独立的派系归属、山头资源、派系声望、派系斗争、派系投票或派系任务线。
- 文案中可以出现长老、师承、旧识、执事堂等组织氛围，但不进入 MVP 的独立规则层。
- 若后续需要宗门内斗或派系玩法，应作为正式版扩展，不反向影响 MVP 宗门行动与资源调拨闭环。

## 5. 贡献与门内声望

贡献不是货币，不可直接兑换资源。

最小区分：

- 贡献记录：玩家为宗门完成任务、上交资源、参与驻守、解决危机的历史凭证。
- 门内声望：宗门内对玩家可靠性、潜力、影响力的综合评价。
- 职位权限：系统性授予玩家可以影响组织行动的范围。

资源申请应读取贡献与声望作为条件，但最终仍由 S6 检查宗门真实库存。

## 6. 玩家影响宗门的入口

玩家不是直接操控整座宗门，而是通过身份与影响力改变宗门倾向。

MVP 入口：

1. 提议宗门行动。
2. 对宗门行动方向给出建议。
3. 使用职位权限直接发起低到中级行动。
4. 请求宗门资源、护法、突破场地或培养支持。
5. 通过亲自参与 S3 行动提高某项宗门行动执行效果。
6. 通过事件解决、资源上交、节点贡献提高未来采纳率。

## 7. 宗门关系状态

玩家与宗门的关系可用最小状态表示：


显示包装可以使用世界观称谓，但规则层使用抽象状态与权限标签。

## 8. 晋升与降级

晋升条件方向：

- 修为阶段。
- 贡献记录。
- 门内声望。
- 关键任务完成。
- 宗门资源需求。
- 高层支持。
- 突破成功质量。

降级或失势来源：

- 重大失败。
- 宗门声望损失。
- 任务失败。
- 长期不履行职责。
- 事件惩罚。
- 转世后当世身份重置。

降级不应作为无提示惩罚，必须写入日志并给出原因。

## 9. 与突破系统的关系

S5 只决定玩家是否有资格申请：

- 突破场地。
- 护法力量。
- 突破资源调拨。
- 宗门名额。
- 长辈背书。

S4 决定这些支持如何影响突破事件链；S6 决定资源是否真实存在；S7 决定宗门行动是否执行成功。

## 10. 与多人边界的关系

MVP 默认鼓励玩家分宗并行，但不硬性禁止同宗。

如果多名玩家同宗：

- MVP 不做复杂同宗议会。
- 同一宗门行动出现多个建议时，可按权限、职位、声望和提交顺序生成采纳倾向。
- 冲突严重时，系统以宗门 AI 倾向和权限高低决策。
- 不开放玩家直接夺权或互相迫害作为 MVP 核心玩法。

## 11. 与其他系统的接口

- S2：读取玩家当世身份、修为、转世后关系重置。
- S3：判断角色是否在正确节点亲自执行宗门事务。
- S4：提供突破支持资格。
- S6：请求宗门库存与资源调拨。
- S7：提供宗门行动权限与影响力修正。
- S8：读取宗门控制节点和建筑权限。
- S10：接收节点危机、宗门事件和传闻影响。
- S13：处理宗门之间的间接多人竞争。

## 12. MVP 验收标准

1. 玩家能从外门进入至少内门或真传。
2. 玩家能通过贡献和声望提高宗门行动建议采纳率。
3. 玩家能在 M2→M3 前后申请一次突破支持。
4. 玩家进入 M3 后可体验长老序列或等价高层影响能力。
5. 宗门权限检查能阻止低身份玩家直接调用高层资源。

# Inbox

本目录是历史参考与原始资料档案区，用于保存旧正式文档、历史设计草稿、Notion 导出、阶段性补充规则和旧版本包。

当前正式设计文档包：

```text
docs/xiuxian_design_docs/
```

使用规则：

- `docs/inbox` 不作为当前设计权威或实现依据。
- `historical_reference_docs/` 收纳 2026-05-12 迁入的旧正式 docs 目录与旧 `docs/index.md`、`docs/CHANGELOG.md`。
- `修仙游戏设计方案总目录/` 和 inbox 根目录零散文件保留为原始资料、阶段补充和来源追溯。
- 旧版本、`[已过时]` 文件和历史参考文档只用于冲突比对、来源追溯和背景补充。
- 历史资料中的有效信息如需进入 MVP 开发依据，应改写并沉淀到 `docs/xiuxian_design_docs/`，或由用户明确裁决。

# 文案设计｜剧情设定｜四大主线势力剧情线

适用范围：`docs/xiuxian_design_docs/01_文案设计/02_剧情设定` 中的太初、太极、混沌、太素和迎墟者剧情线。

来源说明：本文由包外草稿 `docs/inbox/mainline_outline_shanhai_duanmu_v0_2_1.md` 拆分并吸收到正式设计文档包；正式解释以本文和同目录关联文件为准，源稿只保留为历史参考。

## 1. 当前定位

本文负责把主要势力从世界观组织转化为可推进的剧情线，说明各势力如何提出世界方案、给予玩家机会、制造代价，并在终局中形成风险或路线条件。

## 2. 内容边界

本文维护势力剧情线和叙事功能，不维护宗门系统职位、任务表、资源表或具体 NPC 配置。势力组织设定见 `../01_世界观设定/04_当世势力与外围组织.md`。

## 3. 拆分摘要

1. 太初线围绕万气归根与差异消解，太极线围绕永断天衡与秩序代价，混沌线围绕无界重开与边界风险。
2. 太素线强调铸界、阵材、债契和器物化风险。
3. 归墟 / 迎墟者线提供显性反派压力，但归墟本体仍不是可加入阵营。

## 4. 四大主线势力剧情线（源稿 §13）

### 13.1 太初线：万气归根

#### 剧情功能

太初线提供“统一、修复、归源”的诱惑。它在早期应显得最温和，因为它能修复灵脉、提升修炼效率、缓解资源冲突。中后期才暴露其本质：它不是修复差异，而是吞并差异。

#### 分幕推进

| 幕 | 表现 |
|---|---|
| 序章 / 第一幕 | 归元医修修复树根化灵脉，帮助外围小宗门渡过资源危机 |
| 第二幕 | 玩家发现修复后的节点全部向同一根井输送气机 |
| 第三幕 | 太初方要求玩家交出真名样本，称真灵是“未归之气” |
| 第四幕 | 一炁君启动万气归根阵，玩家可阻止、改造、利用或部分接纳 |

#### 代表任务

1. **《归根药》**：归元医修提供灵药，能净化归墟污染，但会让不同灵根相性趋同。
2. **《无影木》**：玩家发现无影木不投影，因为它的“差异”正被收回根中。
3. **《一炁井》**：根井能恢复枯竭节点，但周围异兽、灵植、功法标签逐渐单一化。
4. **《未归之名》**：太初方称玩家真灵名只是“未归之气”的噪声。
5. **《万气归根》**：终局事件，太初方试图把所有断木余脉统一回源。

### 13.2 太极线：永断天衡

#### 剧情功能

太极线提供“秩序、防灾、保护普通人”的正当性。它不是纯反派，而是有充分历史理由：没有绝地天通，归墟可能早已倒灌。但其极端化会导致绝对管制，且飞升封锁是它的历史代价。

#### 分幕推进

| 幕 | 表现 |
|---|---|
| 序章 / 第一幕 | 天衡巡使帮助封锁异常节点，减少伤亡 |
| 第二幕 | 玩家发现宗门档案被律令删改，真灵名被列入风险名录 |
| 第三幕 | 太极方扩大突破登记、秘境封存、真名审查 |
| 第四幕 | 天衡君启动永断天衡，玩家可支持温和续断或反对极端封绝 |

#### 代表任务

1. **《封潮令》**：协助太极方封堵提前潮。
2. **《断木档案》**：发现秩序派确实救过世界，也隐瞒过争夺建木的利益。
3. **《真名登记》**：玩家被要求登记真灵名，以换取高阶突破许可。
4. **《天衡法台》**：法台能稳定区域，但会关闭所有隐藏层。
5. **《永断天衡》**：终局事件，太极方试图永久加固绝地天通。

### 13.3 混沌线：无界重开

#### 剧情功能

混沌线提供“反管制、破边界、开新路”的诱惑。它适合吸引不满宗门权限、讨厌太极审查、反感太初吞并的玩家。但其极端化会让世界结构崩坏。

#### 分幕推进

| 幕 | 表现 |
|---|---|
| 序章 / 第一幕 | 界隙散修帮助玩家绕过宗门限制进入隐藏层 |
| 第二幕 | 玩家发现界隙叠合导致异兽迁徙异常 |
| 第三幕 | 混沌方主张拆除所有封绝阵基 |
| 第四幕 | 无界君启动无界重开，玩家可借其破局或镇压 |

#### 代表任务

1. **《开隙者》**：学习低相性界隙法门，进入隐藏层。
2. **《错位山门》**：宗门节点与秘境重叠，弟子失踪。
3. **《无界残章》**：古法强大，但会降低地图稳定度。
4. **《裂天盟约》**：混沌方邀请玩家一起拆除天衡法台。
5. **《无界重开》**：终局事件，混沌方试图溶解天地边界。

### 13.4 太素线：铸界与债契

#### 剧情功能

太素线提供“务实、维护、交易、债务”的现实压力。它不主张一套最高理念，但它掌握大阵、撤离、避难、阵材和器械维护，让玩家看到世界并不只靠道理运行，也靠资源与工程运行。

#### 分幕推进

| 幕 | 表现 |
|---|---|
| 序章 / 第一幕 | 太素商队售卖避墟器、撤离舟和节点封存匣 |
| 第二幕 | 玩家发现撤离成本被转化为宗门债务和节点抵押 |
| 第三幕 | 阵材短缺，太素方优先维护高价值地区，引发道义冲突 |
| 第四幕 | 太素铸界者可能帮助另开或藏世，也可能走向众生器化坏结局 |

#### 代表任务

1. **《避墟舟》**：筹集材料或债契，为小宗门撤离争取名额。
2. **《铸界残契》**：发现旧阵基维护记录中隐藏着前史债务。
3. **《节点封存匣》**：可暂时保存一个地图节点，但会抵押资源收益。
4. **《神材失衡》**：阵材短缺导致某些低价值节点被放弃。
5. **《众生器化》**：极端太素线把宗门、洞府、灵脉、真名后手都纳入器物秩序。

### 13.5 归墟 / 迎墟者线：天根入海

#### 剧情功能

归墟线承担世界级灾害压力。迎墟者是显性反派，但应避免脸谱化；他们的理念是“旧世界不可救”，这能解释其极端行为。

#### 分幕推进

| 幕 | 表现 |
|---|---|
| 序章 / 第一幕 | 海眼祭徒伪装成镇潮者，帮助村镇但暗中收集潮刻 |
| 第二幕 | 玩家发现部分“引潮真灵”记录是迎墟者污名化 |
| 第三幕 | 迎墟者公开破坏封绝结构，制造提前潮 |
| 第四幕 | 迎墟祭主试图让归墟沿断木余根倒灌，玩家必须处理即时灾害 |

#### 代表任务

1. **《潮刻》**：潮汐预警石被盗。
2. **《漂木》**：海边出现带断木纹理的归墟漂木。
3. **《引潮污名》**：玩家调查某个真灵是否真的引潮。
4. **《海眼祭》**：迎墟者献祭节点，造成提前潮。
5. **《天根入海》**：终局前置灾害，归墟倒灌进入最终阶段。

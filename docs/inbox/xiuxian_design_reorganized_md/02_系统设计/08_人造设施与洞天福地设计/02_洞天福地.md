# 人造设施与洞天福地设计｜洞天福地

## 1. 当前状态

当前 Library 中没有检索到洞天福地独立设计稿。本文件将洞天福地暂归为节点、隐藏层、前世后手、修炼环境和突破地点的交叉对象。

## 2. 当前可确定口径

洞天福地可作为：

- 高价值地图节点或隐藏层。
- 修炼加成地点。
- 突破地点。
- 前世后手封存点。
- 宗门控制与资源争夺对象。
- 世界窗口事件或秘境入口。

## 3. 约束

- 必须挂载于地图节点或隐藏层，不应成为无位置资产。
- 若作为前世后手，应由后手 / 真灵藏宝规则记录封存、感应、暴露、污染、回收状态。
- 若提供资源产出，应先进入资源槽或资源池；实例化后再进入 `sect_storage`、`node_storage`、事件锁定库存或其他合法资产容器。
- 若提供修炼加成，应进入数值模型的节点灵气 / 设施修正。

## 4. 缺口

- 洞天福地类型表。
- 洞天维护成本。
- 洞天暴露、争夺、封存、污染、转移规则。

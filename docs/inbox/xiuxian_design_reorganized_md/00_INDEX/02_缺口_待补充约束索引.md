## 3. 整理猜测清单

1. “流程设计”中的“单人游戏与多人共玩流程”覆盖 S1/S3/S7/S10/S12/S13/S14 的共世流程，而不是单独剧情流程。
2. “新手教程”以《初次创建到拜入宗门流程》作为主材料。
3. “角色外观与人设”当前缺少独立设定，暂只保留角色生成、年龄、身份、低认知开局等约束。
4. “角色绑定法宝”不是独立法宝类型，而是法宝实例的绑定状态标记；MVP 只保留概念设定，当前明确会使用该状态的对象为储物空间法宝，绑定后不可被窃取，绑定对象死亡后自主损毁。
5. “储物空间法宝”MVP 不开发独立玩法；暂定为基础行囊升级概念，不设置玩法层物品栏上限，不做负重、重量、体积或格子玩法。
6. “交互设计”部分当前主要来自机制规则和 UI 字段约束，不包含 Figma 视觉规格。
7. “库存系统”作为非随身资产容器统一入口；商店、宗门、节点、洞府、藏宝、真灵藏宝、市场、事件锁定和交易暂存不再各自维护独立库存口径。
8. “交易系统”承接宗门外商店、宗门内商店、玩家与非商店 NPC 交易、玩家之间交易；宗门资源申请回归宗门系统设计。

## 1. 已继承的既有约束

### 1.1 S4 突破事件链约束

- 突破不是概率按钮，而是“准备度门槛 + 多阶段事件链”。
- 玩家开始突破前，应能理解当前准备的短板、风险来源和可能失败方向。
- 失败必须可解释，并输出失败原因标签。
- 重大突破通常会接管本季度剩余行动，并通过 S3 / S1 回写结果。
- 失败结果可以包括：失败但存活、残缺突破、身死转世、严重失败及长期后果。
- 突破结果应写入轮回账本，供下一世优化路线使用。

### 1.2 核心体验约束

- 玩家追求修为提升，本质是在追求更高资源获取效率。
- 瓶颈负责把玩家从线性修炼推入多系统准备。
- 突破是对玩家前期路线选择、资源积累和风险控制的集中审判。
- 突破失败不是单纯惩罚，而是把本世损失转化为跨世优化信息与动机。

### 1.3 角色养成约束

- 小境界升级不进入高风险突破链。
- 小境界只需要修为进度、主修道功等级与功法支持范围满足要求。
- 小境界通常允许由主动吐纳、闭关或自动运转触发。
- 大境界瓶颈不能由自动运转跨越，必须由玩家主动选择并进入突破事件链。
- 修为纯度平时隐藏，到达大阶段瓶颈、进入突破准备语境后显示。

### 1.4 战斗 / 事件 / 物品接口约束

- 战斗是高风险事件链中的轻量结算框架，不是独立复杂战棋。
- 战斗框架支持 5 个交锋格预输入、最多 3 个战斗回合。
- 指令来源可以是已掌握术法、法宝、消耗道具、基础指令或事件特殊指令。
- 物品系统已支持“突破资源”作为 MVP 物品类型，且资源使用必须写入日志。
- 事件系统支持专用事件链、结果包、外部干扰、传闻与世界日志。
- 轮回系统支持突破失败导致身死、失败标签、死亡原因与轮回账本写入。

## 2. 核心判断

### 2.1 S4 的事件链方向成立，但缺少玩家体验层桥接

当前 S4 已经能回答：

```
突破需要哪些准备
→ 突破中发生哪些阶段
→ 失败如何解释
→ 结果如何回写
```

但从玩家体验角度，还需要补齐四个问题：

1. 玩家什么时候明确意识到“我正在准备一次不可回头的大事”？
2. 玩家在开始突破前，能否低成本理解本次风险？
3. 进入突破链后，玩家还能做哪些有意义的交互，而不是只看结算？
4. 失败后，玩家能否立刻知道“我下次该补什么”？

### 2.2 大境界突破拆成三层体验

```
长期准备层
→ 破境确认层
→ 事件链交锋层
```

- 长期准备层：玩家通过修炼、提纯、功法等级、关键物品、地点、护法、宗门支持等降低风险。
- 破境确认层：玩家在明确不可逆消耗与风险提示后，选择突破持续行动。
- 事件链交锋层：玩家无法再回头准备，但可以在突破挑战中通过指令、资源和判断影响结果质量。

这样可以同时满足：

- 不把突破退化成概率按钮。
- 不把准备成本全部压进事件链内部。
- 不让玩家进入事件链后完全失去操作感。
- 不在 MVP 中新增一套完全独立小游戏。

## 3. 大小境界突破边界

### 3.1 小境界升级

小境界升级定位为“阶段内成长节点”，不作为高风险核心玩法。

规则建议：

```
当前小境界进度达到上限
+ 主修道功等级支持下一小境界
+ 主修道功支持范围覆盖下一小境界
+ 角色不处于禁止升级状态
→ 自动或常规升级到下一小境界
```

小境界升级不做：

- 不消耗关键突破物。
- 不进入突破事件链。
- 不触发高风险死亡 / 转世。
- 不生成复杂外部干扰。
- 不需要专门的挑战交锋格。

小境界升级可以做：

- 弹出轻量提示。
- 更新阶段编码，例如 A-1 → A-2。
- 增加少量派生属性或解锁功法效果。
- 写入角色日志。
- 在关键小境界节点给出“距离大瓶颈还有多久”的引导。

设计理由：小境界承担的是节奏反馈和成长确认。若每次小境界都进入复杂突破玩法，会显著增加重复操作成本，并削弱大境界突破的仪式感。

### 3.2 主修道功支持范围与小境界边界

已收敛规则：

- 主修道功只能在 A-1 / B-1 / C-1 等大境界突破后的首个小阶段窗口修改。
- 当角色临近大境界突破时，当前大境界已修炼圆满，不能再切换主修道功，因此不能通过临时换功法降低突破难度。
- 小境界升级也必须受主修道功支持范围限制。若某道功只支持到某个阶段上限，角色达到该阶段 100% 后不能继续推进到下一小境界 0%。
- 示例包装：若某功法只支持修炼到“金丹前期 100%”，则不能自动进入“金丹中期 0%”。
- 设计目的：避免旧主修道功的小境界突破奖励污染当前大境界的后续阶段，也避免功法支持范围被阶段自动升级绕过。

### 3.3 大境界突破

大境界突破定位为核心玩法节点。

大境界突破必须满足：

1. 玩家主动发起。
2. 至少消耗一个关键突破物。
3. 进入突破事件链后不可回头补准备。
4. 结果可能改变本世路线、宗门地位、轮回账本和下一世规划。

建议规则：

```
大境界瓶颈成立
+ 主修道功支持目标大境界
+ 主修道功等级达到门槛
+ 至少一个合法关键突破物可用
+ 当前状态允许突破
→ 玩家可选择大境界突破持续行动
```

## 4. 关键突破物设计

### 4.1 定位

关键突破物是玩家从“准备阶段”跨入“不可回头突破事件链”的承诺成本。

它的体验作用不是单纯增加物品消耗，而是制造三个信号：

1. 这不是普通升级。
2. 本次尝试有明确代价。
3. 玩家已经完成了最低限度的破境准备。

### 4.2 基础规则

- 开始大境界突破至少需要 1 个关键突破物。
- 关键突破物是具体物品实例，不是抽象货币。
- 关键突破物较难获得，应来自任务、秘境、宗门名额、节点资源、炼制、后手回收或高价值交换。
- 一旦突破事件链正式创建，关键突破物立即消耗。
- 正式开链后，无论最终成功、失败、中断、残缺突破或身死转世，关键突破物都不会返还。
- 关键突破物必须写入资源使用日志和突破结果包。

### 4.3 与其他突破资源的关系

建议分层：

```
关键突破物：必需，决定能否开链
辅助突破资源：可选，影响风险、交锋修正或奖励质量
突破地点 / 护法 / 宗门支持：外部准备，不一定是物品
```

MVP 可以只强制实现“1 个关键突破物 + 地点条件 + 主修道功条件”。辅助突破资源、复杂护法组合和多物品配方可以后置。

### 4.4 数据字段草案

```
BreakthroughCatalystItem {
  item_id
  tier_code
  quality_code
  supported_major_transition    // A→B / B→C 等
  method_tag_affinity           // body / soul / sword / water / alchemy 等
  catalyst_role                 // core / stabilizer / amplifier / purifier
  purity_or_stability_value
  owner_or_storage_ref
  consumption_rule              // consumed_on_chain_start
  event_flags
}
```

### 4.5 玩家可见信息

关键突破物不应只显示“可用于突破”。建议在物品说明中显示：

- 支持哪个大境界突破。
- 与哪些功法标签更适配。
- 大致提高哪类突破表现。
- 是否只是开链材料，还是同时提供稳定、提纯、护持、增幅效果。

## 5. 主修道功决定突破模板

### 5.1 核心规则

大境界突破的难度、挑战结构和奖励，由当前大境界的主修道功记录决定。

```
当前大境界主修道功记录
→ 读取突破模板
→ 读取功法阶级 + 品级配置表
→ 生成突破挑战序列、难度参数、奖励结构与失败标签池
```

这能让“选择主修道功”成为路线选择，而不是单纯修炼倍率选择。

已收敛规则：主修道功只能在 A-1 / B-1 / C-1 等大境界突破后的首个小阶段窗口修改。进入当前大境界圆满、准备突破下一个大境界时，已经不能再更换主修道功，因此不存在临近突破换功法规避突破模板和难度的问题。

### 5.2 功法类型决定模板

| 主修道功类型 | 突破体验倾向 | 主要短板检查 |
| --- | --- | --- |
| 炼体 / 体魄型 | 冲击强、承载要求高 | 生机、体魄、经脉压力 |
| 神魂 / 观想型 | 神念考验多，心境扰动强 | 神念、心境、心魔 |
| 剑道 / 攻伐型 | 攻击交锋权重高 | 攻击指令质量、元气爆发 |
| 水行 / 调和型 | 稳定、恢复、纯度相关 | 纯度、持续稳定、环境适配 |
| 丹药 / 资源型 | 资源转化收益高 | 资源匹配、转化率、杂质风险 |
| 阵法 / 洞府型 | 地点与布置影响大 | 地点、阵法、外扰防护 |

### 5.3 阶级与品级读取配置表

功法阶级与品级不建议简单解释为“越高越容易突破”。更合理的口径是：

- 高阶功法：上限更高，奖励更强，但可能要求更高准备质量。
- 高品级功法：同阶内更稳定、奖励更好、失败后更容易保留修正空间。
- 低阶功法：要求低、易入门，但突破奖励、后续上限和根基质量较弱。

因此配置表应同时控制：

```
挑战强度
风险类型
基础奖励
完美奖励上限
残缺惩罚类型
失败标签权重
资源适配要求
```

### 5.4 数据字段草案

```
DaoGong.breakthrough_profile {
  supported_transition_range
  min_method_level_by_transition
  template_id_by_transition
  difficulty_table_id           // 由 tier + quality 查表
  reward_profile_id
  fail_tag_profile_id
  required_catalyst_tags
  preferred_catalyst_tags
  environment_affinity_tags
  ritual_text_pack_id
}
```

## 6. 突破奖励设计

### 6.1 奖励来源

突破奖励由三部分组成：

```
境界基础奖励
+ 主修道功奖励
+ 本次突破质量奖励 / 惩罚
```

### 6.2 境界基础奖励

所有成功突破都获得的底层收益：

- 阶段编码提升，例如 A → B。
- 修为上限打开。
- 寿元上限提升。
- 基础派生状态提升，例如生机 / 元气 / 神念上限。
- 解锁更高阶资源节点、任务、宗门权限或行动入口。

### 6.3 主修道功奖励

由功法路线决定：

- 根基标签。
- 特定派生属性倾向。
- 被动能力强化。
- 对后续同类功法 / 法门的适配加成。
- 对资源转化、战斗、防护、神念、炼化等方向的长期路线收益。

### 6.4 突破质量奖励

| 结果 | 奖励 / 后果 |
| --- | --- |
| 完美突破 | 获得完整奖励，并追加根基质量、声望或特殊标签 |
| 正常突破 | 获得基础奖励和主修道功常规奖励 |
| 残缺突破 | 进入新大境界，但带缺陷标签、后续修复需求或成长限制 |
| 失败但存活 | 不升境，消耗关键物，获得道伤 / 短期惩罚 / 失败标签 |
| 身死转世 | 本世结束，写入死亡原因与失败标签，进入轮回账本 |
| 严重失败 | 额外影响真灵、因果、后手、宗门关系、节点状态或传闻 |

### 6.5 奖励要避免的问题

- 避免只奖励战斗数值，否则非战斗路线突破意义不足。
- 避免完美突破和普通突破差距过大，否则玩家会反复追求低风险重试。
- 避免残缺突破等同废档，残缺应是可继续游玩的分支。
- 避免高阶功法绝对最优，路线成本、资源要求和适配条件必须参与平衡。

## 7. 标准流程设计

### 7.1 流程总览

```
达到大境界瓶颈
→ 开放突破准备面板
→ 玩家检查风险与短板
→ 决策阶段选择“突破”持续行动
→ 结算阶段再次校验条件
→ 消耗关键突破物
→ 开启突破事件链
→ 可选：外部干扰事件
→ 特殊突破挑战战斗
→ 根据结果进入成功 / 残缺 / 失败 / 死亡 / 严重失败分支
→ 写入角色状态、资源日志、世界日志、轮回账本
```

### 7.2 阶段 A：瓶颈提示

触发条件：

- 当前大境界末端进度达到瓶颈。
- 当前主修道功支持目标大境界或提示“不支持”。

玩家看到：

- 当前已经到达大境界瓶颈。
- 普通修炼收益下降或不再推进大境界。
- 可以进入突破准备面板。
- 小境界升级规则不再适用，必须通过大境界突破链。

### 7.3 阶段 B：突破准备面板

该阶段不是事件链，玩家可以自由查看，不消耗资源。

建议显示四组信息。

必需项：

- 主修道功是否支持目标大境界。
- 主修道功等级是否足够。
- 是否拥有合法关键突破物。
- 当前状态是否允许突破。

风险项：

- 修为纯度。
- 生机 / 元气 / 神念状态。
- 肉身承载。
- 心境或负面状态。
- 当前地点灵气与安全性。
- 外部干扰风险。
- 寿元压力。

加成项：

- 关键突破物适配度。
- 地点加成。
- 宗门支持。
- 护法 / 阵法 / 法宝 / 后手辅助。
- 前世经验提示。

结果预览：只显示方向性信息，不显示完整精确概率。

```
本次突破主要考验：体魄 / 神念 / 经脉 / 攻伐
当前最大短板：修为纯度偏低、神念不稳
外部风险：当前节点不安全，可能出现外扰
可能失败标签：纯度不足、心境不稳、外部干扰
```

### 7.4 阶段 C：决策阶段选择突破持续行动

玩家在季度决策阶段选择“突破”持续行动。

选择时必须二次确认：

- 本行动会尝试大境界突破。
- 结算开始后会消耗关键突破物。
- 突破链开始后无法返回准备阶段。
- 本季度剩余行动大概率被突破链接管。
- 失败可能造成重伤、道伤、残缺突破、身死转世或长期后果。

确认后，本季度计划中写入：

```
PlannedAction: MajorBreakthroughAttempt
```

### 7.5 阶段 D：结算阶段开链校验

结算阶段执行到突破行动时，先做最后合法性校验。

若关键突破物已经不存在、角色状态不合法、地点不可用或事件窗口失效：

```
突破行动未能开启
→ 不消耗关键突破物
→ 行动格按失败 / 空耗 / 调息规则处理
→ 写入“突破开启失败”日志
```

若条件合法：

```
消耗关键突破物
→ 创建 BreakthroughAttempt
→ S3 普通时间轴暂停或被接管
→ 进入突破事件链
```

设计理由：决策阶段到结算阶段之间，可能发生行动顺序、移动、事件或库存变化。若条件在开链前已经失效，不应无理由消耗关键物。

### 7.6 阶段 E：外部干扰事件

外部干扰发生在突破事件链内，可以插入在特殊挑战战斗之前。

外部干扰来源：

- 当前节点危险等级。
- 敌对宗门或竞争者。
- 妖兽 / 邪祟 / 节点危机。
- 秘境关闭或灵气波动。
- 护法不足。
- 玩家行踪暴露。
- 因果或前世失败阴影。

外部干扰不能让玩家觉得“系统随机没收关键物”。

已收敛规则：

1. 若准备面板显示外扰风险为低，MVP 中不直接中断突破，只最多生成轻度负面修正或额外交锋格。
2. 若外扰风险为中，可能触发护法 / 防护 / 稳定选择，处理不当才进入战斗或突破惩罚。
3. 若外扰风险为高，准备面板必须提前明确警告“可能中断突破”。
4. 直接中断突破只在高风险预警或明确敌对事件下允许。
5. 直接中断突破必须写入明确原因标签，例如“突破地点暴露”“护法不足”“节点危机失控”。

### 7.7 阶段 F：特殊突破挑战战斗

突破挑战建议复用战斗系统的 5 交锋格结构，但把“敌人”替换为“突破模板生成的挑战序列”。

```
突破模板
→ 生成事件侧 5 个挑战交锋格
→ 玩家填入 5 个应对指令
→ 按交锋格依次结算
→ 每格产出稳定度、损耗、失败标签或奖励修正
```

这不是普通战斗，而是“内景 / 天关 / 功法瓶颈 / 心魔 / 经脉冲关”的规则化表现。

## 8. 特殊突破挑战交锋格

### 8.1 交锋格设计原则

每个挑战格都应满足：

1. 玩家能理解本格考验什么。
2. 玩家能选择至少一种基础应对方式。
3. 已有准备会产生明确修正。
4. 失败会输出明确原因标签。
5. 结果能回写到总突破质量。

### 8.2 玩家指令来源

突破挑战中的可用指令建议由三类组成。

基础破境指令：所有角色都可用，避免玩家因缺少战斗技能而无法交互。

示例：

- 稳固生机。
- 调息聚元。
- 凝神守一。
- 顺势化解。
- 强行冲关。

主修道功指令：由当前主修道功提供，体现路线差异。

示例：

- 炼体道功提供“以身承劫”。
- 神魂道功提供“观想镇念”。
- 剑道道功提供“斩破关隘”。
- 水行道功提供“润脉化冲”。

资源 / 法宝 / 后手指令：由物品、法宝、阵法、护法或前世后手提供。

示例：

- 消耗辅药稳定经脉。
- 激活护体法宝抵消冲击。
- 借用宗门静室阵法稳定灵气。
- 动用前世留下的破境感悟。

### 8.3 典型挑战格

#### 体魄考验

语义：突破冲击肉身承载。

```
事件侧：体魄冲击
基础效果：减少 X 点生机
附加检查：若体魄低于阈值，额外减少生机或叠加“肉身承载不足”标签
推荐应对：稳固生机 / 防御 / 炼体类主修指令 / 护体法宝
```

失败标签：

- 肉身承载不足。
- 生机亏损。
- 带伤破境。

#### 神念考验

语义：心神、神识或心魔扰动。

```
事件侧：神念浪潮
基础效果：减少 X 点神念
附加检查：若扣除后神念低于阈值，获得“失魂落魄”状态
失魂落魄：下一个交锋格的玩家指令无效或降级为兜底指令
推荐应对：凝神守一 / 神魂类主修指令 / 镇魂道具 / 前世经验提示
```

失败标签：

- 心境不稳。
- 神念不足。
- 心魔压制。

#### 防护考验

语义：外部或内部冲击直接打击角色状态。

```
事件侧：破境冲击
基础效果：造成 X 点伤害
玩家防御指令可抵消或削弱
若防御不足，溢出部分写入生机 / 元气 / 神念损失
推荐应对：防御 / 护体法宝 / 阵法护持 / 宗门静室加成
```

失败标签：

- 防护不足。
- 护法不足。
- 地点不稳。

#### 攻击考验

语义：玩家必须主动冲破关隘，不能只靠防守。

```
事件侧：关隘阻滞
玩家需要使用攻击 / 冲关类指令抵消阻滞威力
若玩家攻击威力未完全抵消阻滞，结算时剩余威力 × N 形成反噬
推荐应对：强行冲关 / 攻伐类主修指令 / 法宝攻击 / 高元气投入
```

失败标签：

- 冲关无力。
- 元气不足。
- 功法攻伐不足。

#### 经脉考验

语义：修为纯度、经脉稳定和资源转化质量的集中检查。

```
事件侧：经脉逆冲
基础检查：读取修为不纯度 / 纯度短板
每 1% 不纯度提高一定失败风险或增加冲击强度
失败后减少 X 点生机，并获得负面状态
推荐应对：顺势化解 / 提纯类准备 / 水行调和 / 丹药稳定 / 宗门阵法
```

失败标签：

- 修为纯度不足。
- 经脉阻滞。
- 资源转化不稳。

#### 外扰考验

语义：突破中被节点事件、敌对势力或外部环境干扰。

```
事件侧：外部干扰
若护法 / 地点 / 阵法准备足够，可直接抵消或降级
若不足，插入战斗、额外交锋格或突破稳定度损失
推荐应对：护法指令 / 阵法护持 / 防御 / 逃避干扰 / 宗门支持
```

失败标签：

- 外部干扰过强。
- 护法不足。
- 突破地点暴露。

### 8.4 是否显示完整挑战序列

推荐 MVP 规则：

- 玩家在准备面板中看到本次突破的主要考验类型和风险排序。
- 进入特殊挑战战斗后，显示本轮 5 个交锋格的挑战类型。
- 精确数值可以隐藏或用风险档位表达。
- 前世经验、卜算、主修道功熟练度或宗门支持可以提高挑战序列可见度。

设计理由：完全隐藏挑战会变成猜拳；完全显示精确数值会降低神秘感并变成最优解计算。MVP 采用“显示类型 + 模糊强度 + 可解释结果”更适合文字 / 策略体验。

## 9. 突破稳定度与结果判定

### 9.1 事件内状态：突破稳定度

为避免每个交锋格都直接决定生死，建议在事件链内部引入一个临时状态：

```
BreakthroughStability
```

它不是角色持久属性，只在本次突破事件链中存在。

影响来源：

- 初始准备度。
- 关键突破物适配度。
- 地点与护法。
- 每个交锋格结果。
- 外部干扰处理结果。
- 主修道功匹配度。
- 前世经验。

### 9.2 结果判定思路

最终结果不建议由单次随机决定，而应由多项累计状态决定：

```
突破稳定度
+ 角色关键状态剩余量
+ 失败标签严重度
+ 是否完成核心挑战格
+ 是否被外部干扰中断
→ 结果分层
```

结果分层：

| 条件方向 | 结果 |
| --- | --- |
| 稳定度高、关键挑战处理优秀、状态充足 | 完美突破 |
| 稳定度合格、无致命短板 | 正常突破 |
| 稳定度勉强合格，但存在严重短板 | 残缺突破 |
| 稳定度不足，但角色状态未崩溃 | 失败但存活 |
| 生机 / 神念崩溃或严重失败分支成立 | 身死转世 |
| 外扰、因果、真灵、后手等触发严重后果 | 严重失败叠加 |

### 9.3 失败标签写入

每个失败标签都应包含来源：

```
FailureTag {
  tag_id
  severity
  source_stage
  source_slot
  visible_to_player
  reincarnation_ledger_write
  suggested_next_preparation
}
```

示例：

```
修为纯度不足：来自经脉考验，第 5 交锋格
神念不足：来自神念考验，第 2 交锋格
外部干扰过强：来自突破地点暴露，外扰事件
冲关无力：来自攻击考验，第 4 交锋格
```

## 10. 玩家体验流程

### 10.1 第一次看到瓶颈

玩家应获得清晰信号：

```
你已经到达当前大境界瓶颈。
继续普通修炼难以推进境界。
若要进入下一大境界，需要准备关键突破物，并处理当前短板。
```

此时不应直接弹出“是否突破”。应引导玩家打开准备面板。

### 10.2 准备阶段

玩家目标：理解自己缺什么。

理想体验：

```
我现在不是不能突破，而是风险很高。
我的主修道功会带来神念和经脉考验。
我有关键突破物，但地点不安全，纯度也偏低。
我可以先闭关提纯，或者换到宗门静室，再尝试突破。
```

### 10.3 开始突破

玩家目标：完成一次有代价的承诺。

需要有仪式感：

- 显示关键突破物被投入。
- 显示主修道功进入破境运转。
- 显示地点、护法、阵法或后手参与。
- 显示“本季度剩余行动被突破接管”。

### 10.4 突破挑战

玩家目标：在无法回头准备的情况下，用现有资源和判断尽量把结果推向更好。

关键体验：

- 我知道这一格在考验什么。
- 我能选择不同方式应对。
- 我看得到为什么扣了生机 / 元气 / 神念。
- 我知道某个失败标签来自哪一步。

### 10.5 结果展示

结果界面建议分三层。

第一层：结论。

```
突破成功 / 正常突破 / 残缺突破 / 突破失败 / 身死转世
```

第二层：主要原因。

```
本次突破的关键问题：修为纯度不足、神念不足、外部干扰
```

第三层：下一步建议。

```
下次可优先：提高修为纯度、准备镇魂类资源、选择更安全突破地点
```

若身死转世，则同样写入轮回账本，并在下一世准备界面中以“前世经验提示”形式回流。

## 11. 与 S3 行动经济的接口

### 11.1 行动入口

大境界突破应作为一种持续行动，由玩家在季度决策阶段选择。

```
ActionType: MajorBreakthroughAttempt
```

### 11.2 行动消耗

MVP 建议：

- 选择突破行动至少占用 1 个行动格。
- 一旦事件链正式开启，通常接管本季度剩余行动。
- 是否跨季度延续后置，不作为 MVP 必需。

### 11.3 行动失败边界

若结算阶段发现开链条件失效：

- 不进入突破事件链。
- 不消耗关键突破物。
- 根据配置消耗该行动格或转为调息失败结果。
- 写入可解释日志。

若事件链已经开启：

- 关键突破物已消耗。
- 玩家不能返回准备阶段。
- 外部干扰、中断或失败都属于本次突破结果的一部分。

## 12. 与战斗系统的接口

### 12.1 复用而不混同

突破挑战复用战斗系统的：

- 生机 / 元气 / 神念。
- 指令列表。
- 5 个交锋格。
- 交锋格结算。
- 指令资源不足兜底。
- 结果包。

但突破挑战不是普通敌我战斗。它有专用字段：

```
BreakthroughTrialCombat {
  trial_template_id
  transition_code
  major_method_record_ref
  challenge_slots
  breakthrough_stability
  failure_tags
  outcome_profile
}
```

### 12.2 指令不足兜底

若玩家在前几个交锋格过度消耗元气 / 神念，导致后续指令无法执行，应复用战斗系统已有兜底规则：

```
资源不足
→ 指令失手
→ 执行低效守势 / 喘息 / 空过
→ 记录失败原因
```

在突破语境中，这会产生：

- 元气不足。
- 神念不足。
- 冲关失手。
- 稳定度下降。

### 12.3 突破挑战与普通战斗的区别

| 项目 | 普通战斗 | 突破挑战 |
| --- | --- | --- |
| 对手 | NPC / 小队 / 抽象敌方 | 功法瓶颈 / 内劫 / 天关 / 心魔 / 经脉冲击 |
| 目标 | 击败、逃脱、拖延、保护 | 稳定完成突破 |
| 胜负条件 | 生机归零、目标达成等 | 稳定度、关键状态、挑战完成度 |
| 结果 | 伤势、死亡、物品、位置 | 境界结果、失败标签、轮回账本 |
| 指令来源 | 战斗指令为主 | 基础破境指令 + 功法指令 + 资源指令 |

## 13. 与事件系统的接口

### 13.1 外部干扰请求

突破链可以向 S10 请求外部干扰判定：

```
BreakthroughInterferenceRequest {
  actor
  location
  transition_code
  exposure_context
  node_danger_level
  sect_support_context
  protector_context
  karma_or_legacy_flags
}
```

返回：

```
BreakthroughInterferenceResult {
  interference_level
  event_chain_ref
  added_trial_slot
  direct_modifiers
  interruption_possible
  failure_tags
}
```

### 13.2 事件优先级

突破事件链进行中时，普通 S3 时间轴暂停。

外部干扰属于突破链的子事件，而不是独立打断 S4 控制权的随机事件。

### 13.3 传闻与日志

大境界突破建议写入：

- 角色日志：玩家自身完整经历。
- 世界日志：完整系统记录，用于回放和测试。
- 玩家可见传闻：只在公开突破、宗门突破、失败造成动静或高阶突破时生成。

## 14. 与物品系统的接口

### 14.1 关键突破物消耗

使用统一资源请求：

```
ResourceUseRequest {
  actor
  source_inventory
  item_or_resource_type: breakthrough_catalyst
  amount: 1
  use_context: major_breakthrough
  target_event: BreakthroughAttempt
  allow_partial: false
}
```

返回成功后，才创建正式突破事件链。

### 14.2 可选辅助资源

MVP 后续可扩展：

- 稳定类资源：提高突破稳定度。
- 提纯类资源：降低经脉 / 纯度考验风险。
- 镇魂类资源：降低神念 / 心魔考验风险。
- 护体类资源：降低体魄 / 生机考验风险。
- 攻伐类资源：强化攻击考验。

辅助资源不应在 MVP 第一版引入复杂配方；优先作为单个可选投入项或事件指令。

## 15. 与轮回账本的接口

### 15.1 成功写入

成功突破写入：

- 突破阶段。
- 主修道功。
- 关键突破物。
- 地点与外部支持。
- 成功质量。
- 主要奖励标签。
- 对后续路线的提示。

### 15.2 失败写入

失败突破写入：

- 失败阶段。
- 失败交锋格。
- 失败原因标签。
- 已消耗关键突破物。
- 是否外部干扰。
- 是否身死转世。
- 是否产生道伤、残缺、真灵、因果、遗产或宗门后果。
- 下一世可利用的经验提示。

### 15.3 前世经验回流

下一世到达同类瓶颈时，前世经验可以提供：

- 风险提前提示。
- 同类失败标签警告。
- 挑战序列可见度提升。
- 特定准备路径提示。
- 特殊破境指令。

前世经验不直接提供成功率硬加成，也不应直接保证成功。

## 16. MVP 推荐方案

### 16.1 MVP 必做

1. 小境界升级不进入突破链。
2. 大境界突破必须由玩家主动选择。
3. 开始大境界突破至少消耗 1 个关键突破物。
4. 当前大境界主修道功记录决定突破模板。
5. 功法阶级 + 品级通过配置表决定挑战强度和奖励结构。
6. 突破链至少支持 5 个特殊交锋格。
7. 交锋格至少覆盖：体魄、神念、防护、攻击、经脉五类。
8. 失败输出原因标签。
9. 结果支持：正常突破、失败但存活、身死转世。残缺突破可作为优先扩展。
10. 资源消耗、角色状态、日志和轮回账本全部回写。

### 16.2 MVP 可后置

- 多关键物配方。
- 复杂护法 NPC 模拟。
- 完整心魔剧情链。
- 多轮突破战斗。
- 复杂残缺突破修复系统。
- 真灵受损与因果加重的高阶变体。
- 玩家之间破坏彼此突破。
- 市场化购买突破资源。

### 16.3 第一版体验建议

#### M1 → M2

- 1 个关键突破物。
- 1 轮 5 交锋格。
- 外部干扰默认低强度，不建议直接中断突破。
- 失败以存活、道伤、短期惩罚为主，少量严重失败可身死转世。
- 教学重点：让玩家理解准备面板、关键物消耗、交锋格和失败标签。

#### M2 → M3

- 1 个更高阶关键突破物。
- 1 轮 5 交锋格，必要时允许外部干扰插入额外交锋或子战斗。
- 宗门支持、地点、护法、节点局势权重更高。
- 失败可以更强地影响宗门地位、后手、遗产、传闻或转世。
- 教学重点：让玩家理解突破与沙盒世界、宗门经营和跨世优化的连接。

## 18. 风险与设计防线

### 18.1 风险：突破被玩家理解为随机没收资源

防线：

- 准备面板提前显示风险来源。
- 外部干扰必须可解释。
- 每个失败标签显示来源。
- 下一步建议必须可执行。

### 18.2 风险：交互成本过高

防线：

- 小境界不进入突破链。
- M1 → M2 只用 1 轮 5 格。
- 基础破境指令自动提供。
- 可提供“推荐填充”但允许玩家改动。

### 18.3 风险：战斗路线成为唯一最优

防线：

- 突破挑战不是纯伤害竞赛。
- 体魄、神念、经脉、地点、资源、护法都能成为关键。
- 非战斗功法应提供独特破境指令。
- 攻击考验只是若干挑战之一，不应覆盖全部模板。

### 18.4 风险：主修功法切换规避突破难度

已收敛：该风险由主修道功切换窗口规则解决。

规则口径：

- 主修道功只能在 A-1 / B-1 / C-1 等大境界突破后的首个小阶段窗口修改。
- 达到当前大境界圆满、临近下一次大境界突破时，角色已经不能更换主修道功。
- 大境界突破仍读取当前大境界主修道功记录，用于计算突破模板、根基奖励和失败标签池。
- 若某道功支持范围只到某个小阶段上限，该道功不能把角色推进到下一小境界 0%，避免旧主修道功的小境界突破奖励污染当前大境界。

因此，MVP 不需要额外设计“临近突破换功法惩罚”。只要主修道功切换窗口和功法支持范围校验正确，就能避免规避突破难度。

### 18.5 风险：残缺突破变成隐性废档

防线：

- 残缺突破必须可继续游玩。
- 残缺标签应提供修复路径或转世优化价值。
- 残缺不应直接永久封死后续所有大境界，除非是玩家明确接受的高风险路线。

## 19. 当前推荐结论

1. 小境界升级保持轻量，不设突破难度，不消耗关键物，不进入事件链。
2. 大境界突破作为核心玩法，采用“准备面板 + 关键突破物 + 事件链 + 特殊交锋格”的结构。
3. 关键突破物应成为进入事件链的强承诺成本，正式开链后无论成败都消耗。
4. 当前大境界主修道功记录应决定突破模板、挑战倾向和奖励结构；阶级与品级通过配置表影响难度、奖励和失败标签权重。
5. 突破挑战建议复用战斗系统的 5 交锋格框架，但敌方替换为突破模板生成的考验序列。
6. 外部干扰可以插入突破链，但必须在准备面板中有风险提示；M1 → M2 不建议低预警直接中断突破。
7. 结果展示必须把“发生了什么、为什么失败 / 成功、下次该补什么”表达清楚。
8. MVP 第一版优先跑通 M1 → M2 的完整体验，再把 M2 → M3 扩展到宗门支持、节点风险和世界传闻。

---

## 20. 已收敛决策

1. 关键突破物在突破事件链正式创建时消耗；低预警外扰不应直接中断突破。
2. 准备面板 MVP 不显示完整精确成功率，只显示风险档位、短板和主要失败标签方向。
3. 特殊突破挑战结构：M1 → M2 固定 1 轮 5 格；M2 → M3 可配置为 1 轮 5 格 + 外扰变体。
4. 残缺突破：若实现成本可控则进入 MVP；若成本紧张，先保留数据字段，第一版只做正常成功 / 失败存活 / 身死转世。
5. 主修道功模板读取：读取当前大境界主修道功记录。由于主修道功只能在 A-1 / B-1 / C-1 等大境界突破后的首个小阶段窗口修改，临近突破时已经无法更换，因此不需要额外防范临时换功法降低突破难度。
6. 外部干扰允许直接导致突破中断，但只在高风险预警或明确敌对事件下允许；低预警外扰最多生成轻度负面修正或额外交锋格。
7. 前世经验在突破挑战中的强度：先提供风险提示和挑战可见度，不直接提供成功率硬加成。

## 21. 后续待细化问题

1. 残缺突破若进入 MVP，需要定义最小残缺标签、修复入口和转世账本表达。
2. 各类主修道功模板需要配置最小样例，至少覆盖体魄型、神魂型、攻伐型、调和型四类。
3. 关键突破物的产出入口需要与 S9 物品、S6 宗门资源、S8 节点资源进一步对齐。

# 数值设计｜功法研习与内容预算

适用范围：自动研习的基础预算、研习经验、共享与溢出、触类旁通、经验上限、标准研习路线，以及首批功法内容规模。研习位和知识使用规则由系统专题维护。

## 1. 数值口径

玩家始终以每部功法各自的整数 `0—100` 掌握度理解进度；内部保存该功法的研习经验与独立经验上限：

```text
对外掌握度
= min(100, 向下取整(当前研习经验 ÷ 该功法经验上限 × 100))
```

研习经验以 `0.01` 为最小精度累计。招式解锁、掌握阶段、触类旁通来源档位和其它门槛均读取向下取整后的掌握度，不能提前生效。

初始配置、事件或其它来源直接授予整数掌握度时，应把经验设置或增加到 `经验上限 × 指定掌握度 ÷ 100` 的两位小数精确值，避免授予 `25 / 50 / 75` 却显示为低一档。

### 1.1 统一掌握字段职责

道功与法门共用 `25 / 50 / 75` 门槛内容及五阶段发挥倍率 `0.70 / 0.85 / 0.95 / 1.00 / 1.10`。研习算法只负责推进知识掌握；掌握结果进入字段时遵守：

```text
道功实际灵气吸收效率 = α_template × M_dao
道功实际修为强度系数 = β_template × M_dao
战斗法门允许缩放字段 = 模板字段 × M_fa
```

移动法门默认以离散门槛内容为主，不把骰池、理论上限或速度连续乘以 `M_fa`。冷却、固定元气损伤、固定吸收、固定消耗等排除字段继续按系统专题处理。

一条效果链对同一知识来源只读取一次掌握倍率。主修道功的 `M_dao` 已进入修为强度后，该道功自身以修为强度为基础的效果系数不得再次完整乘 `M_dao`；战斗法门仍可独立读取自身 `M_fa`。内容制作优先避免需要拆分的特殊模板；确有必要时只能在内部以 `√M_dao × √M_dao = M_dao` 合成一份掌握贡献，不能把中间乘区暴露给玩家。

## 2. 每内部时间单位的基础研习预算

标准开局悟性下，基础共享研习预算固定为 `B = 20`。任一角色内部时间单位使用：

```text
本单位基础共享研习点
= 向下取整(20 × 当前有效悟性 ÷ 标准开局悟性)
```

普通外界回合提供一个内部时间单位，因此标准 `24` 回合的常规基础预算为 `480 B`；一次小洞天结算提供十个内部时间单位，即额外 `200 B`。触类旁通不增加 `B`，只在基础点分配后提高目标取得的研习经验。

## 3. 共享、排序与溢出

每个内部时间单位独立结算：

1. 只统计研习位内尚未满掌握度的功法；研习位按界面从左到右形成稳定顺序。
2. 在全部有效目标间平均分配整数商，除不尽的余数从左到右各加 `1`。
3. 某目标在后置经验转化后可能封顶时，其填满所需整数基础点为：

```text
向上取整(剩余研习经验 ÷ 当前后置倍率)
```

4. 目标最多消耗上述数量；本次已分配但尚未消耗的整数基础点退回共享池，再按同一规则分给其余未满目标。
5. 最后一个已消耗基础点因倍率产生的少量超额经验在封顶时截断，不能折回为分数 `B`。只有全部在位功法均满后仍剩余的基础点才作废。

掌握度 `50` 与 `75` 只是门槛，不触发自动离位或返还；只有达到经验上限、掌握度 `100` 时自动离位。事件专项经验与请教师长的溢出直接作废，不进入共享池。

## 4. 触类旁通

### 4.1 标签规则

每部功法必须配置 `1` 个主研习标签，最多再配置 `1` 个副标签。主副只影响内容归类与展示顺序，结算效力相同。标签表达可迁移的共同原理或领域，例如剑道、炼体、神识、火行、御器；不得使用“道功”“法门”“战斗”“移动”“高阶”等系统类型或阶级标签。

标签采用扁平、精确匹配，不存在父子层级、模糊匹配或由名称、招式、灵根、属性和事件状态隐式增删标签。首轮目录不收录只出现于一部功法的孤立标签；每个标签至少出现在两部首批功法上，并应存在实际的先学来源与后学目标关系。

### 4.2 来源档位

一部已学习功法按自身掌握度，为其每个标签提供当前最高一档来源加成：

| 掌握度 | 单部来源加成 |
| --- | ---: |
| `0—49` | `0%` |
| `50—74` | `2%` |
| `75—99` | `3%` |
| `100` | `10%` |

`2% / 3% / 10%` 是首轮调参初值。目标功法不能作为自己的来源；同标签来源可以跨道功、移动法门和战斗法门。

### 4.3 汇总与经验转化

对目标的每个标签分别相加所有合法同标签来源；目标有多个标签时，只取汇总值最高的一类，不把不同标签再相加或相乘：

```text
目标后置加成 = max(各目标标签的合法来源加成总和)
本次研习经验 = 分配的基础 B × (1 + 目标后置加成)
```

研习经验保留至 `0.01`。例如 `7 B` 在 `13%` 加成下产生 `7.91` 经验。首轮不设置独立总加成硬上限；功法获取、独立研习投入、禁止自身加速、每部最多两个标签和多标签只取最高共同约束强度。

每个内部时间单位开始时，对已学功法的掌握度、标签和来源档位做一次快照。本单位内新达到 `50 / 75 / 100` 不追溯改变同单位其它目标的倍率，从下一个内部时间单位起生效；小洞天十个单位逐单位重新快照。

界面将实际生效结果包装为“`XX` 类功法触类旁通”，展示最终百分比、生效标签和各来源。最高值并列时可按稳定展示规则选择一个标签，但实际仍只结算一次最高值。

## 5. 经验上限锚点

五宗门同类型初始功法使用统一上限；通用高阶功法先使用默认预算，具体模板可以显式偏离并重新验算：

| 类型 | 初始功法上限 | 通用高阶默认上限 |
| --- | ---: | ---: |
| 移动法门 | `60` | `120` |
| 战斗法门 | `80` | `160` |
| 道功 | `100` | `200` |

在标准悟性、独占研习池且无触类旁通时：

| 路线 | 到 `75` | 到 `100` |
| --- | ---: | ---: |
| 初始移动法门，从开局 `25` 起 | `2` 回合 | `3` 回合 |
| 初始战斗法门，从开局 `25` 起 | `2` 回合 | `3` 回合 |
| 初始道功，从开局 `25` 起 | `3` 回合 | `4` 回合 |
| 默认高阶移动法门，从 `0` 起 | `5` 回合 | `6` 回合 |
| 默认高阶战斗法门，从 `0` 起 | `6` 回合 | `8` 回合 |
| 默认高阶道功，从 `0` 起 | `8` 回合 | `10` 回合 |

三部初始功法共同从 `25` 到 `75` 的总需求为 `120` 经验，即六个标准回合的基础预算；实际到达顺序由共享、排序、标签和溢出决定。

## 6. 标准验收路线

以下只是节奏验收路径，不限制玩家分配研习位：

1. 开局默认把初始道功、初始移动法门和初始战斗法门放入对应研习位。
2. 境界 CP 的标准参考路径让三部初始功法共享 `B`；某部到 `75` 后，玩家在下一回合开始主动移出，让剩余目标取得更多基础点，直至三部均到 `75`。该参考不要求继续到 `100`。
3. 参考路径不使用悟性变化、小洞天、请教师长、事件经验、额外功法或专项收益；每单位必须读取当时主修道功实际掌握阶段，不能预先按 `75` 或固定阶段估算修炼。
4. 玩家可以只研习主修以提高前期修炼效率，但会牺牲移动和战斗法门同期进度；境界总 CP 不因个人分配动态改变。

完整 `24` 回合研习验收另采用一条非强制路线：三部初始功法从 `25` 共同研习至 `100` 约占 `9` 回合；若第 `10` 回合起可研习一部高阶移动法门、一部高阶战斗法门和一部高阶道功，并按经验上限从小到大推进，则已有两部同标签圆满来源时，约可在剩余 `15` 回合内使三部高阶功法达到 `75`；无同标签来源时约到第 `28` 回合完成。三部同标签圆满来源后再把三部高阶功法都推至 `100`，无小洞天时约落在第 `27` 回合。

因此三部完整通用高阶路线的首个常规获取窗口应在第 `9—10` 回合附近开始，使玩家最迟可于第 `10` 回合开始放入研习位。第 `13` 回合或更晚才取得的高阶功法，不默认能在第 `24` 回合前同时完成三类高阶精通；此时属于路线取舍，或由小洞天、事件与合法教学入口补足。

一次小洞天额外 `200 B` 是显著重点奖励，可以把已经建立同标签路线的高阶精通进一步推向圆满，但仍受研习位锁定、逐单位共享、满掌握离位和空位不补充约束，不能作为可自由转移的储备货币。

## 7. 请教师长数值

请教师长每次固定向一部合法本宗门功法增加 `40` 点专项研习经验，相当于标准悟性下两个普通内部时间单位的基础预算。该收益：

- 不生成基础 `B`，不参与共享；
- 不受触类旁通放大；
- 封顶溢出直接作废；
- 另消耗宗门贡献点，绝对价格待宗门经济表配置；
- 不适用于三套通用高阶功法。

从开局掌握度 `25` 计算，一次请教后的参考结果为：初始移动法门 `55 / 60` 经验、掌握度 `91`；初始战斗法门 `60 / 80`、掌握度 `75`；初始道功 `65 / 100`、掌握度 `65`。差异来自经验上限，不按掌握百分比补齐。

## 8. 首批内容预算

首轮固定 `5` 个宗门。每个宗门提供初始道功、初始移动法门、初始战斗法门各一部，共 `15` 部。

通用高阶功法池固定为 `3` 套路线，每套各含一部高阶道功、一门高阶移动法门和一门高阶战斗法门，共 `9` 部。三套路线对所有宗门开放；同套三部共享一个主研习标签，各自可有不同副标签，三套主标签彼此不同。

首批合计 `24` 部功法、`72` 项 `25 / 50 / 75` 阈值内容；按类型统计，道功、移动法门、战斗法门各 `8` 部、`24` 项阈值内容。阈值条目可以是新能力、离散强化或道功限定的属性补位，因此 `72` 不等于 `72` 个主动招式。

每个宗门的三部初始功法中，至少两部通过主或副标签匹配同一套完整高阶路线，另至少一部匹配另一套路线。三套路线均应在第 `9—10` 回合附近提供取得完整三部功法的常规可能；标签不足只降低研习速度，不限制学习或使用。

## 9. 制作验收

1. `2% / 3%` 通常只形成长期小收益，不应单独节省一个完整外界回合；`10%` 与多来源叠加承担可感知的流派优势。
2. 若玩家只为加速后续少量功法而额外研习低阶功法，节省的基础 `B` 不应高于该低阶功法的额外投入；触类旁通是知识本身价值之外的后续回报，不是强制前置税。
3. 初始功法能支持完整飞升，但高阶功法达到 `75` 后，其主要修炼或战斗效率通常应高于初始同类功法达到 `100`；具体局部特色不能反转整体层级。
4. 标准路线需记录每个内部时间单位开始时主修道功的掌握阶段，并与灵气、实际吸收效率和境界 CP 联合验算。
5. 每部道功按品级联合审计 `α_template / β_template / C_template` 综合预算，不能只比较 `α × β`；吸灵型、凝练型与高品级路线须覆盖境界提前、修为强度、内容包和研习机会成本。
6. 每个以修为强度为基础的道功自身效果都必须通过同源字段检查；若修为强度已含 `M_dao`，效果系数不得再次完整读取同一倍率。
7. 略高品级道功在初识 `0.70` 发挥时，通常不能仅凭模板强度稳定全面优于已精通的低一品级道功；熟练或精通后再体现综合升级。

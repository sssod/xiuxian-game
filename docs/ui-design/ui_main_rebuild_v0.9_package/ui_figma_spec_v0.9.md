# 主界面阶段状态 Figma 规格文档 v0.9

**项目**：轮回修仙沙盒 / 大世界地图驱动的回合行动工作台  
**用途**：用于在 Figma 中新建页面，呈现主界面在不同阶段状态下的界面表现。  
**版本状态**：当前为可执行规格草案，不是最终视觉定版。允许后续根据 Figma 实作、交互体验、开发验证继续返工或微调。  
**本版不做**：不写入现有 Figma；不追求像素级视觉终稿；不要求行动卡图片素材。

---

## 0. 规格目标

本规格服务于你下一步在 Figma 中新建页面，目标是避免一次性依赖长 Prompt 或 Figma MCP 生成完整页面导致内容截断、遗漏或结构混乱。

推荐工作方式：

1. 先用本文档确定 Figma 页面、Frame、状态、组件命名。
2. 可选使用随附的 `figma_main_ui_stage_initializer` 插件草案，在 Figma 中批量创建页面与低保真骨架。
3. 再在 Figma 中逐步替换为精细视觉、组件实例、自动布局和交互说明。
4. 顶部与底部左下角已人工审核部分，在新页面中作为冻结参考区复制或重建，不重新设计。

---

## 1. 设计依据摘要

当前主界面应围绕“大世界地图驱动的回合行动工作台”组织：玩家通过可拖动、可缩放、带战争迷雾和节点可见性的大世界地图理解自己、宗门、节点、资源、风险、传闻和世界演化之间的关系。

新版口径已经废弃“季度 / 6 个朔望行动格 / 宗门主行动输入”，改为：

```text
可配置回合时长
+ 天级回合时间预算条
+ 小时级服务端内部结算
+ 个人线性行动指令
+ 宗门 AI 唯一持续行动
+ 地图节点沙盒演化
```

因此 Figma 页面应表达：

```text
顶部阶段信息常驻
地图视口常驻并成为背景与主交互层
左上目标追踪与左下全局消息是覆盖面板
地区级消息锚定到地图节点
右侧专注当前节点详情与行动卡
底部规划条只展示时间预算，不直接编辑行动
```

## 2. Figma 页面规划

建议新建 3 个页面。

### 2.1 页面一：`UI_MainFrame_Rebuild_v0.9`

用于摆放主界面各阶段状态。

建议包含 6 个 `1920×1080` Frame：

| Frame 名称 | 目的 |
|---|---|
| `State_01_Prepare_InfoProcessing_1920x1080` | 准备 / 信息处理态；显示目标栏、地图、节点详情、开始规划 / 托管。 |
| `State_02_Planning_WithContinuation_1920x1080` | 规划态；有默认延续行动，右侧行动卡可加入规划，底部预算条展示。 |
| `State_03_Planning_ContinuationCancelled_1920x1080` | 规划态；默认延续行动已被回退取消，显示“已取消延续”提示。 |
| `State_04_LockedWaiting_Readonly_1920x1080` | 锁定等待态；预算条只读，允许回退取消锁定。 |
| `State_05_AutopilotPreview_1920x1080` | 托管摘要弹层态；右下按钮旁显示托管安全摘要。 |
| `State_06_SidePanelsCollapsed_1920x1080` | 左上、左下、右侧面板隐藏态；显示侧边标签与更完整地图视口。 |

建议横向排列：

```text
x = 0, 2000, 4000, 6000, 8000, 10000
```

每个 Frame 顶部与底部左下角保持一致，便于对照。

### 2.2 页面二：`UI_MainFrame_Components_v0.9`

用于摆放组件级规格。建议包含：

| 组件 Frame | 内容 |
|---|---|
| `C_LeftTop_GoalTrackerPanel` | 主目标 + 2 次级目标 + 置顶 + 线索链入口。 |
| `C_LeftBottom_GlobalNoticePanel` | P0/P1/目标相关全局消息卡、归档、宗门跳转。 |
| `C_Map_NodeMarker_WithBadges` | 节点本体、最多 3 徽记、`+N`、计划编号。 |
| `C_Right_NodeContextPanel_VerticalTabs` | 面板内左侧纵向页签：详情 / 短时行动 / 长时行动 / 资源设施 / 风险线索。 |
| `C_Right_ActionCard_NoImage` | 无图片行动卡：标题、标签、说明、参数区、高级设置、加入规划。 |
| `C_Bottom_TurnTimeBudgetBar_ReadOnlyDisplay` | 天级预算条、编号拥挤处理、当前选中行动摘要。 |
| `C_RightBottom_PlanningControls` | 开始规划 / 锁定提交 / 托管 / 回退，准备态与规划态变体。 |
| `C_AutopilotPopover` | 托管摘要弹层。 |
| `C_CollapsedSideTags` | `目标 N`、`全局 N`、右侧节点面板隐藏标签。 |

---

### 2.3 页面三：`UI_MainFrame_Flows_v0.9`

用于说明交互流程，而不是视觉终稿。

建议包含以下流程图或注释框：

1. 准备阶段 → 开始规划 → 规划阶段。
2. 默认延续行动生成 → 回退删除 → 再回退返回准备阶段 → 再进入规划重新生成延续。
3. 右侧行动卡参数选择 → 加入规划 → 底部预算条展示 → 地图节点计划序号。
4. 锁定提交 → 锁定等待 → 回退取消锁定 → 返回规划阶段。
5. 托管按钮 → 右下弹层 → 确认托管 / 取消。
6. 地图节点徽记 → 打开右侧对应纵向页签。

### 3.1 主 Frame

```text

```

### 3.2 固定顶部栏

```text
TopPhaseBar:
x = 0
y = 0
w = 1920

```

顶部栏已人工审核，原则上不重构。新页面中可作为冻结参考：

```text

世界时间
设置入口
```

### 3.3 地图视口

```text
MapViewport:
x = 0
y = 88
w = 1920
h = 920
```

说明：地图视口覆盖顶部以下、底部以上的整块区域。完整地图内容可以大于视口，通过右键 / 中键 / 空格拖动查看。

建议完整地图内容起步：

```text
WorldMapContent:
w = 2800
h = 1800
```

Figma 低保真阶段可以只在视口中绘制一组可见节点。

### 3.4 固定底部栏

```text
BottomDock:
x = 0
y = 1008
w = 1920
h = 72
```

底部左下角系统入口冻结。底部中部 / 右侧根据阶段变化。

右下主操作保留独立菱形按钮：

- `StartPlanning_Diamond` / `LockSubmit_Diamond` 为可容纳 4 字中文的独立菱形按钮，建议外接框约 `72 x 72`。
- 菱形按钮位于底栏右下控制区，可轻微越过底栏上边界，保持“符令”式视觉重心。
- `开始规划`、`锁定提交` 文本必须位于菱形按钮内部居中，不再使用外置下标或矩形底板。
- `托管`、`回退` 使用圆形按钮，文本在圆内居中。

## 4. 阶段状态 Frame 规格

## 4.1 `State_01_Prepare_InfoProcessing_1920x1080`

### 状态定位

准备 / 信息处理态。玩家阅读目标、查看地图、处理全局重大消息、点选节点，但还没有进入本回合行动规划。

### 可见组件

| 组件 | 状态 |
|---|---|
| 顶部阶段栏 | 可见，当前阶段为准备 / 信息处理。 |
| 地图视口 | 可见，全宽。 |
| 左上目标栏 | 默认可见。 |
| 左下全局消息 | 默认折叠；若有 P0/P1 或目标强相关全局消息则展开。 |
| 右侧节点面板 | 可见，默认详情页签。 |
| 底部左下系统入口 | 可见，冻结。 |
| 右下控制组 | 显示 `开始规划`、`托管`。不显示回退。 |
| 时间预算条 | 不显示。 |

### 关键表现

- 地区级消息不在左侧，而是显示为地图节点旁徽记。
- 目标栏的按钮只定位节点，不直接加入规划。
- 宗门重大消息可在左下显示摘要，但操作只跳宗门面板或定位节点。

---

## 4.2 `State_02_Planning_WithContinuation_1920x1080`

### 状态定位

规划态，存在可延续的上回合持续行动。

### 可见组件

| 组件 | 状态 |
|---|---|
| 顶部阶段栏 | 当前阶段为个人行动规划。 |
| 地图视口 | 可见。 |
| 左上 / 左下 / 右侧面板 | 都可隐藏；默认可见。 |
| 右侧节点面板 | 左侧纵向页签；行动卡参数区默认展开。 |
| 底部预算条 | 可见，只展示不编辑。 |
| 右下控制组 | `锁定提交`、`托管`、`回退`。 |

### 默认延续行动

进入规划态时，若存在可延续行动，则生成普通行动条并占用编号：

```text
① 闭关吐纳｜延续｜投入剩余时间
```

它在预算条里与其他行动同级展示，只额外带 `延续` 标签。

### 行动卡

行动卡无图片，默认展开常用参数：

```text
投入时间：[半天] [1 天] [2 天] [投入剩余时间]
行动倾向：[资源优先] [线索优先] [安全优先]
[加入规划]
[高级设置]
```

---

## 4.3 `State_03_Planning_ContinuationCancelled_1920x1080`

### 状态定位

玩家通过回退删除默认延续行动，但仍停留在规划态。

### 可见组件

| 组件 | 状态 |
|---|---|
| 底部预算条 | 可见，队列为空或已有其他行动。 |
| 当前选中行动摘要 | 显示提示：`已取消延续：闭关吐纳`。 |
| 右下控制组 | `锁定提交` 置灰，除非新增行动；`托管`、`回退`可用。 |

### 关键提示

```text
已取消延续：闭关吐纳。
再次进入规划阶段会重新读取可延续状态。
```

### 回退规则

若队列为空，再次点击回退：

```text
返回准备阶段
```

---

## 4.4 `State_04_LockedWaiting_Readonly_1920x1080`

### 状态定位

玩家已锁定，等待其他玩家锁定或倒计时结束。

### 可见组件

| 组件 | 状态 |
|---|---|
| 顶部阶段栏 | 显示锁定进度，例如 `已锁定 1/3`。 |
| 地图视口 | 可见，只读。 |
| 右侧节点面板 | 保持锁定前选中节点与页签，只读。 |
| 底部预算条 | 可见，只读。 |
| 右下控制组 | 显示 `回退`。 |

### 回退行为

点击回退：

```text
取消锁定
返回规划阶段
保留规划队列
保留地图视口位置
保留右侧选中节点与页签
```

结算开始后不可回退。

---

## 4.5 `State_05_AutopilotPreview_1920x1080`

### 状态定位

玩家点击托管后，不立即提交，而是在右下按钮旁显示托管摘要弹层。

### 弹层位置

```text
靠近右下托管按钮
不居中
不遮挡地图中心
```

### 弹层内容

```text
托管摘要

本回合将优先：
- 保命 / 避险
- 延续安全连续行动
- 基础修炼或休整
- 不暴露核心后手

不会主动：
- 发起大境界突破
- 进入高危秘境
- 回收高风险正式后手
- 消耗稀有不可逆资源

[确认托管] [取消]
```

## 4.6 `State_06_SidePanelsCollapsed_1920x1080`

### 状态定位

展示左右覆盖面板隐藏后，地图视口不重排，只显示侧边标签。

### 可见组件

| 组件 | 状态 |
|---|---|
| 地图视口 | 全宽显示。 |
| 左上目标栏 | 隐藏为 `目标 N`。 |
| 左下全局消息 | 隐藏为 `全局 N`。 |
| 右侧节点面板 | 隐藏为右侧竖向标签，例如 `节点` 或当前节点名。 |
| 底部与顶部 | 常驻。 |

## 5. 组件规格

## 5.1 左上目标栏 `C_LeftTop_GoalTrackerPanel`

### 默认内容

```text
标题：目标追踪
主目标：1 个
次级目标：2 个
入口：查看全部 / 目标管理
```

### 主目标卡

字段：

```text
目标名称
目标类型
线索进度
当前判断
下一步
关联节点
按钮：定位节点 / 查看线索链 / 置顶
```

行为：

- `定位节点`：地图平移并选中节点，右侧打开节点详情。
- `查看线索链`：展开线索来源与链路。
- `置顶`：改变 UI 优先级，不改变任务逻辑。

---

## 5.2 左下全局消息区 `C_LeftBottom_GlobalNoticePanel`

### 自动展开条件

```text
存在 P0
存在 P1
存在当前主目标强相关全局消息
```

### 消息卡字段

```text
级别 / 来源
标题
一句话影响
按钮：打开宗门 / 定位节点 / 归档
```

### 归档

归档只影响 UI，不删除日志。归档后可从日志、宗门摘要、轮回账本查回。

---

## 5.3 地图节点 `C_Map_NodeMarker_WithBadges`

### 显示内容

```text
节点名
状态短标签
最多 3 个徽记
+N
计划编号徽记
```

### 徽记点击

| 徽记 | 行为 |
|---|---|
| 风险 | 打开右侧纵向「风险线索」页签。 |
| 传闻 | 打开右侧纵向「风险线索」页签，定位传闻段。 |
| 宗门印 | 打开右侧纵向「风险线索」页签，定位宗门波及段。 |
| 资源 | 打开右侧纵向「资源设施」页签。 |
| 后手 / 卷轴 | 打开右侧纵向「风险线索」页签，定位后手段。 |
| 目标 / 菱形 | 打开详情或风险线索中的目标关联段。 |

---

## 5.4 右侧节点面板 `C_Right_NodeContextPanel_VerticalTabs`

### 左侧纵向页签

```text
详情
短时行动 N
长时行动 N
资源设施 N
风险线索 N
```

### 页签规则

- 点击节点本体默认进入详情。
- 点击具体徽记直接进入对应纵向页签。
- 详情页最近变化只显示 2 条。
- 页签显示数量。
- 页签栏位于右侧面板内部左侧，内容页位于页签栏右侧；面板整体仍可隐藏，不影响地图重排。

---

## 5.5 行动卡 `C_Right_ActionCard_NoImage`

### 结构

```text
行动名
标签：短时 / 长时 / 固定 / 可投入 / 风险 / 前置
说明
参数区
高级设置
加入规划按钮
```

### 参数区默认展开

可选投入行动：

```text
投入时间：[半天] [1 天] [2 天] [投入剩余时间]
行动倾向：[资源优先] [线索优先] [安全优先]
```

短时行动：

```text
投入时间：[2 小时] [4 小时] [8 小时]
倾向：[安全] [效率] [隐蔽]
```

### 加入规划

点击后：

```text
生成 PersonalActionInstruction
加入规划队列末尾
底部预算条刷新
地图节点显示计划序号
按钮变为：已加入，可继续添加
```

---

## 5.6 底部时间预算条 `C_Bottom_TurnTimeBudgetBar_ReadOnlyDisplay`

### 职责

只展示，不编辑。

展示：

```text
天分段
行动编号
行动名
延续标签
溢出 / 跨回合提示
当前选中行动摘要
```

不支持：

```text
删除
拖动排序
修改时长
修改目标
```

拥挤时：

```text
只显示编号
悬停显示详情
```

---

## 5.7 右下控制组 `C_RightBottom_PlanningControls`

### 准备态

```text
◆ 开始规划
○ 托管
```

不显示回退。

### 规划态

```text
◆ 锁定提交
○ 托管
◌ 回退
```

`开始规划` / `锁定提交` 是右下主 CTA。保持独立菱形形态；文本居中放在菱形内部，避免被底栏或主 Frame 裁切。

### 锁定等待态

```text
◌ 回退
```

回退取消锁定并返回规划态；结算开始后不可回退。

## 6. Figma 命名建议

建议 Figma 图层使用以下前缀：

| 前缀 | 含义 |
|---|---|
| `P_` | Page-level 容器或页面注释。 |
| `S_` | 状态 Frame。 |
| `L_` | Layout 区域。 |
| `C_` | 可复用组件。 |
| `V_` | 变体 / Variant。 |
| `I_` | 图标或徽记。 |
| `T_` | 文本样式样例。 |
| `A_` | 注释 / Annotation。 |

示例：

```text
S_01_Prepare_InfoProcessing_1920x1080
L_MapViewport_FullWidth
C_LeftTop_GoalTrackerPanel
C_Right_ActionCard_NoImage__ShortAction
C_Bottom_TurnTimeBudgetBar__Planning
```

## 8. 交付注意事项

1. 本文是 Figma 规格，不是最终视觉稿。
2. 可先用插件草案生成骨架，再人工微调。

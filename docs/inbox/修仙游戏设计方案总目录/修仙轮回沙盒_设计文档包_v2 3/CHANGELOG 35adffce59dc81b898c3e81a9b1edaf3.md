# CHANGELOG

本文档用于长期维护 v2.3 文档包的稳定设计变更。它记录“改了什么、为什么改、影响哪些原文档”，但不替代原系统文档；当前设计口径仍以对应 v2.3 原文档为准。

## 维护规则

1. 新记录按日期倒序追加。
2. 每条记录应包含变更范围、修改文档、设计决议和后续落地点。
3. 涉及数值模型、公式、行动模板、事件、功法、物品、节点、突破、战斗或 UI 稳定规则的变更，应同时更新原文档与本 changelog。
4. 未稳定的 UI 节点级摆放以当前 UI artifact 为准；只有稳定 UI 决策写入 v2.3 UI/UX 文档和本 changelog。

# 交互设计｜角色页面设计

## 必须表达

- 当前世身份、年龄、寿元、宗门身份。
- 基础属性：体魄、精力、悟性；修炼资质：根骨、悟性、灵根。
- 派生状态：生机、元气、神念。
- 当前主修道功、修为阶段、瓶颈 / 突破状态。
- 残余资源效果，例如体内剩余药性，应常驻提示。
- 真名可见状态：hidden / declared / exposed。

## 不应表达为

- 真灵强度直接加修炼效率。
- 执念容量像传统属性点。
- 单一资质总分直接参与核心判定。

## 待补

- 属性展开层级。
- 残余药性提示样式。

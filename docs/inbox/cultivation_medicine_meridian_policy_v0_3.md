# 修炼口径更新｜丹药药性与经脉压力 v0.3

版本：v0.3  
日期：2026-05-21  
用途：记录本轮关于“丹药常态服用、药性持续消化、经脉压力来源与限制”的新设计口径，作为后续修订修炼玩法、丹药物品、修炼公式和行动配置表的依据。

---

## 1. 当前裁决

本轮口径调整为：

```plain text
丹药可以常态化直接服用。
服用丹药后，不立即获得完整修为，而是在角色体内形成持续药性。
体内药性可以被所有“增加修为”的修行流消化，包括主动吐纳、被动吐纳、主动运转、被动运转、闭关修炼中的修行片段，以及明确允许消化药性的修为事件。
正常修行不再默认造成经脉压力。
经脉压力主要来自丹药、灵材、符箓、阵法灌注、强行吸收外源灵气或其他外源道具。
经脉压力限制角色能够同时服用的丹药数量、强度和叠加类型。
```

这意味着旧口径中的“修为丹药只能作为主动吐纳的行动资源输入”应被替换为：

```plain text
修为丹药是可直接服用的成长资源。
直接服用只创建药性状态，不即时结算完整修为。
药性随后被兼容修为增长流逐步转化、散逸或引发副作用。
```

---

## 2. 设计意图

本次修改的目标是让丹药体验更符合玩家直觉。

玩家通常会预期：

```plain text
我拥有丹药
→ 我可以直接服用
→ 丹药在体内持续生效
→ 我修炼或运转功法时会吸收药力
→ 如果吃太多，就会经脉承载不住
```

相比“必须先选择主动吐纳行动，再把丹药作为行动输入项”，新口径有几个优势：

1. **丹药交互更直接**：丹药本身可以被点击使用，不再只是修炼行动表单里的附属材料。
2. **被动运转有实际意义**：角色不主动修炼时，也可以低效吸收体内药性。
3. **经脉压力语义更清晰**：压力不是惩罚正常修行，而是限制外源资源爆发。
4. **修炼行动边界更自然**：主动吐纳仍然最高效，但不再是唯一能消化丹药的入口。
5. **资源爆发更容易平衡**：通过经脉承载、药性负载、叠加组和过载风险限制同服丹药。

## 3. 核心规则

### 3.1 丹药服用规则

丹药可以直接服用。服用后创建“体内药性”状态。

```plain text
服用丹药
→ 创建体内药性
→ 记录药性类型、持续时间、经脉负载、适配修行流和风险
→ 后续由兼容修为增长流逐步消化
```

直接服用丹药不等于即时获得完整修为。丹药收益必须经过时间、修行流、转化效率和经脉承载结算。

### 3.2 药性消化规则

药性只能被“修为增长流”消化。不是所有行动都会自动满额吸收药性。

| 修为增长流 | 是否消化药性 | 体验定位 | 建议效率方向 |
|---|---:|---|---|
| 主动吐纳 | 是 | 专注修炼，高效吸收体内药性 | 最高 |
| 闭关修炼中的修行片段 | 是 | 长时间低交互批量吸收 | 高 |
| 主动运转 | 是 | 主动运转功法，引导药性 | 中高 |
| 被动吐纳 | 是 | 非专注状态下的自然吐纳 | 低 |
| 被动运转 | 是 | 功法自然运转，缓慢消化药性 | 低 |
| 修为类事件 | 视事件配置 | 灵泉、顿悟、灵气灌注等事件加速吸收 | 由事件定义 |
| 移动、交易、普通社交 | 默认否 | 不属于修为增长流 | 无 |
| 战斗中 | 默认否 | 战斗不默认稳定炼化药性 | 特殊功法或事件可覆盖 |

建议采用以下体验口径：

```plain text
主动修行时，药性吸收快、转化高。
被动运转时，药性也会缓慢转化，但效率明显低于主动修行。
非修行语境下，药性可能暂停、低效散逸，或只留下负载压力。
```

### 3.3 正常修行与经脉压力

正常修行不再默认产生经脉压力。

```plain text
正常吐纳、正常功法运转、常规闭关中的自然修行
→ 不产生经脉压力
```

经脉压力改为“外源灵气与药性承载压力”：

```plain text
服用丹药
使用强效灵材
使用修为类符箓
接受阵法灌注
强行吸收外源灵气
使用高阶不适配资源
触发强制灌注类事件
→ 可能增加经脉压力
```

这样经脉压力的玩家理解应为：

```plain text
不是修炼本身伤经脉，而是短时间塞入太多外源资源才会伤经脉。
```

### 3.4 经脉压力限制同服丹药

经脉压力应限制角色同时服用丹药的能力。限制不只看数量，而应看总负载、药性类型和叠加组。

示例体验：

```plain text
当前经脉承载：60 / 100
清灵丹负载：20
赤焰速元丹负载：50

可以再服用清灵丹：60 + 20 <= 100
不能再服用赤焰速元丹：60 + 50 > 100
```

建议至少有三类限制：

| 限制 | 作用 |
|---|---|
| 总经脉负载上限 | 防止无限吞丹 |
| 同类药性叠加上限 | 防止同一收益通道堆叠爆炸 |
| 强刺激型互斥 | 防止高风险丹药互相叠加绕过节奏 |

### 3.5 药性结束与残余

药性状态结束时可以有多种结果：

| 结果 | 适用情况 |
|---|---|
| 完整转化 | 药性在兼容修行流中被完全吸收 |
| 稳定残余 | 行动停止但药性尚可保留一段时间 |
| 缓慢散逸 | 长时间不修行或转化效率不足 |
| 刺激性散逸 | 强刺激药性未被及时处理，造成压力或副作用 |
| 强制释放 | 特殊药性随世界时间强制消耗，可能浪费或反噬 |
| 事件锁定 | 特殊事件中药性被锁定到事件结果 |

巩固根基可以收束残余药性、降低经脉压力、减少散逸或反噬，但不应把残余修为药性直接转化成修为。

## 4. 药性状态的设计字段

以下是面向设计与体验的字段，不是最终数据库字段。

```yaml
MedicineEffectDesign:
  medicine_id: pill.qinglingdan
  name: 清灵丹
  player_effect: 服用后持续释放温和灵气，提升修为增长
  duration: 12 游戏小时
  best_conversion_channels:
    - 主动吐纳
    - 闭关修炼
  passive_conversion_channels:
    - 被动吐纳
    - 被动运转
  meridian_load: 20
  load_type: mild_cultivation_medicine
  stacking_group: cultivation_aura_medicine
  overuse_risk:
    - 药性散逸
    - 经脉胀痛
    - 根基浮躁
  player_hint: 主动修炼时转化效率最高；被动运转也可缓慢吸收。占用少量经脉承载。
```

策划配置时应优先填写玩家可理解的信息：

| 字段 | 设计目的 |
|---|---|
| `player_effect` | 玩家读到的效果描述 |
| `duration` | 药性持续多久 |
| `best_conversion_channels` | 哪些修行流最适合消化 |
| `passive_conversion_channels` | 是否允许后台低效消化 |
| `meridian_load` | 吃下后占用多少经脉承载 |
| `stacking_group` | 与哪些药性互斥或叠加受限 |
| `overuse_risk` | 过量服用会发生什么 |
| `player_hint` | UI 提示口径 |

## 5. 修为事件与药性

所有“增加修为”的事件可以消化药性，但不能默认无限放大事件收益。事件需要声明是否允许消化药性，以及允许消化多少。

推荐口径：

```yaml
CultivationEventMedicineRule:
  can_consume_active_medicine: true
  consume_mode: partial
  max_consumed_effect_hours: 6
  conversion_multiplier: 1.20
  overuse_check: true
  post_event_medicine_retroactive: false
```

玩家体验示例：

```plain text
你借灵泉机缘加速吸收了体内药性。
由于经脉承载接近上限，部分药力散逸。
```

硬边界：

```plain text
只有事件结算前已经激活的药性，才能被该事件消化。
事件完成后服药，不能回溯放大刚才的事件收益。
```

事件选项可以允许现场服丹，例如：

```plain text
选项：服用清灵丹，引导灵泉药力。
```

这种情况属于事件内明确选择，不是事后补算。

## 6. 行动系统影响

### 6.1 主动吐纳

主动吐纳不再是唯一可消化丹药的渠道，但仍是最高效渠道。

新口径：

```plain text
主动吐纳 = 高效修为增长流 + 高效药性消化流
```

主动吐纳本身不产生经脉压力。只有当角色体内存在药性、使用外源资源或触发外源灌注时，才产生或变化经脉压力。

### 6.2 被动吐纳与被动运转

被动吐纳和被动运转应成为低效修为流。它们可以缓慢消化体内药性，但不能替代主动吐纳。

```plain text
被动吐纳 / 被动运转
→ 少量修为增长
→ 低效药性消化
→ 不主动消耗未服用的丹药
→ 不能完成大境界突破
```

### 6.3 主动运转

主动运转可以作为介于主动吐纳和被动运转之间的行动或修行流。

```plain text
主动运转
→ 主动引导主修功法
→ 中高效率消化药性
→ 可用于不适合完整吐纳但仍想引导药力的场景
```

### 6.4 闭关修炼

闭关修炼可以批量消化体内药性。闭关开始前可以允许玩家查看体内药性、经脉承载和预计药性消化情况。

闭关不是免费收益。资源不足、药性过载、心魔、寿元和外部事件仍可能造成中断或摘要提示。

### 6.5 巩固根基

巩固根基的定位更明确：处理服丹和外源资源带来的经脉压力、残余药性、根基浮躁和过载风险。

```plain text
巩固根基
→ 降低经脉压力
→ 收束残余药性
→ 减少散逸或反噬
→ 改善根基稳定
→ 不直接把药性转化为修为
```

## 7. UI 与玩家提示

### 7.1 丹药详情页

丹药详情应展示：

1. 服用后的持续时间。
2. 药性最适合哪些修行方式吸收。
3. 被动运转是否会缓慢消化。
4. 经脉负载。
5. 当前是否还能服用。
6. 过量风险。

示例：

```plain text
清灵丹
服用后 12 小时内持续释放药性。
主动吐纳时转化效率最高；被动运转也可缓慢吸收。
经脉负载：20。
当前经脉承载：60 / 100，可服用。
```

### 7.2 角色状态页

角色状态页应展示：

```plain text
体内药性：清灵丹，剩余约 8 小时
当前经脉承载：60 / 100
建议：主动吐纳可高效吸收；巩固根基可降低压力
```

### 7.3 行动规划页

主动吐纳、闭关、主动运转等行动规划时，应提示：

1. 本行动是否会消化体内药性。
2. 预计消化多少药性。
3. 是否会增加、降低或维持经脉压力。
4. 是否存在药性散逸、过载或浪费风险。

示例：

```plain text
本次主动吐纳预计消化清灵丹药性 6 小时。
正常吐纳不增加经脉压力；清灵丹药性吸收期间将占用经脉承载。
```

## 8. MVP 范围

MVP 建议实现：

1. 丹药可直接服用。
2. 服用丹药后生成体内药性状态。
3. 主动吐纳、闭关、主动运转、被动吐纳、被动运转可以按不同效率消化药性。
4. 正常修行不产生经脉压力。
5. 丹药和外源资源产生经脉负载。
6. 经脉负载限制同服丹药。
7. 巩固根基可以降低经脉压力、收束残余药性，但不直接转化为修为。
8. 修为事件可通过配置决定是否消化药性。
9. 事件后服丹不能回溯放大事件收益。
10. UI 展示体内药性、剩余时间、经脉承载和建议行动。

MVP 暂不必实现：

1. 大量复杂药性随机曲线。
2. 多药性之间的深度化学反应。
3. 每种丹药独立复杂副作用链。
4. 战斗中药性实时炼化。
5. 事后补药回溯结算。

## 10. 待裁决项

以下内容仍建议后续裁决：

1. 主动运转是否作为玩家可选行动，还是只作为某些功法或状态下的修行流。
2. 被动吐纳与被动运转是否需要分成两个后台流，还是合并为一个“被动修行流”。
3. 经脉承载上限由体魄、境界、功法、根基还是法门共同决定。
4. 同类丹药默认最多同时激活 1 种还是 2 种。
5. 高风险丹药过载后优先产生经脉压力、根基浮躁、心魔还是事件。
6. 药性在移动、战斗、重伤、昏迷、局部时停和 C1 期间的默认推进策略。

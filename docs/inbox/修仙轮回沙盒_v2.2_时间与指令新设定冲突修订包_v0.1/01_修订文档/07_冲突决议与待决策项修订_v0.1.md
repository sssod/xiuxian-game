# 冲突决议与待决策项修订（v0.1）

> 替换范围：v2.2 `03_实现交付/03_冲突决议_待确认问题_风险登记_v2.2.md` 中与时间、回合、行动队列、突破、托管相关的冲突记录。

---

## 1. 本次已消解冲突

### 1.1 固定回合 vs 连续日历

旧口径：

```text
玩家最小推进单位为回合。
当前默认每回合 5 游戏天。
```

新决议：

```text
玩家共享连续世界日历。
服务器以 1 游戏小时为最小 tick。
F1/N1/B1/P0 决定推进速度。
5 日回合不再作为玩家最小推进单位。
```

---

### 1.2 全员锁定统一结算 vs 普通队列实时编辑

旧口径：

```text
全员锁定或超时后自动进入服务器统一结算。
```

新决议：

```text
普通指令编辑不暂停自身角色、其他玩家或世界。
世界在 N1/F1/B1/P0 中持续推进。
全员提交 / 锁定只保留给 P0 公共决策或房间特殊规则。
```

---

### 1.3 时间预算条 vs 短队列

旧口径：

```text
行动自动映射到天级回合时间预算条。
```

新决议：

```text
MVP 队列为当前执行指令 + 最多 3 条预输入指令。
UI 显示队列，而不是要求玩家填满 5 日预算。
```

---

### 1.4 自动休整待机 vs 风险兜底

旧口径：

```text
无后续队列时角色自动进入休整待机。
```

新决议：

```text
低风险节点自动吐纳。
中高风险节点自动休整。
自动兜底强制 N1，不具备 F1 资格。
```

---

### 1.5 显式托管 vs 自动兜底

旧口径易混用：

```text
托管 / 超时生成行动 / 休整待机都可能表示玩家未操作后的安全行动。
```

新决议：

```text
自动兜底：系统填充，等待玩家补指令，不可 F1。
显式托管：玩家主动输入低关注行动，可在满足条件时 F1。
超时安全默认：事件或房间规则的安全处理，不等同于显式托管。
```

---

### 1.6 预输入突破 vs 未来条件脚本

表面冲突：

```text
时间规则提到“开启突破通常允许玩家提前预设”。
指令预输入规则要求“当前已满足条件时才能预输入突破”。
```

消解决议：

```text
“提前预设”不允许解释为未来条件脚本。
它只表示：
1. 当前已满足条件后，提前把开启突破放入普通队列；或
2. 设置突破挑战 B1 轮内默认策略。
```

---

### 1.7 大境界突破固定行动 vs B1 挑战

旧口径：

```text
大境界突破是固定执行时间持续行动，关键突破物在开始时消耗。
```

新决议：

```text
准备期是长期低交互行动。
开启突破是短指令，不 P0。
突破挑战是正式交锋，世界 B1。
真实资源消耗集中在 B1 交锋轮中。
结果结算不 P0。
```

---

### 1.8 插入事件挂起 vs 局部时停 / B1 / P0

旧口径：

```text
结算阶段由插入事件链被动挂起。
```

新决议：

```text
事件按类型切换时间状态：
信息事件 → 不打断；
个人非交锋选择 → 本人局部时停 + 外部 N1；
正式交锋 / 突破挑战 → B1；
全局公共事件 / 同步保护 → P0。
```

## 2. 本次未发现阻塞性待决策项

本次没有必须先向制作人确认才能继续的冲突。

采用的统一判断原则是：

```text
1. 两份新规则优先于 Library v2.2 旧口径。
2. 时间速度与同步问题由《自适应流速可暂停日历制 v2》决定。
3. 普通队列、预输入、兜底、显式托管由《指令预输入机制 v1》决定。
4. v2.2 中不冲突的底层工程原则保留。
```

## 3. 后续仍需数值化 / 实现细化的非阻塞项

以下不是设定冲突，而是实现阶段需要补表：

1. 各长期低交互行动是否 F1 eligible 的模板标签表。
2. 节点风险等级 `low / medium / high / unknown` 的判定数据。
3. 闭关三档预案对应的风险阈值与收益修正。
4. 显式托管低价值事件的模板白名单。
5. B1 交锋轮普通 / 复杂 / 硬上限模板表。
6. 突破挑战各轮资源消耗模板。
7. 24 小时 gap 默认选项与 P0 同步保护事件清单。
8. C1 追赶补结算可结算字段白名单。
9. UI 中速度提示与私人归因屏蔽规则的具体文案表。

## 4. 风险登记

| 风险 | 描述 | 缓解 |
|---|---|---|
| R01 旧回合文档残留 | v2.2 多处仍写“默认 5 日回合” | 全文替换为连续日历；5 日仅可作为历史说明 |
| R02 F1 被误用为跳转 | 玩家可能期待“推进到下一事件” | 明确 F1 是连续 tick 压缩，不是跳转 |
| R03 自动兜底滥用 | 玩家不下指令靠自动吐纳长期 F1 | 自动兜底强制 N1 且不可 F1 |
| R04 托管吞掉关键事件 | 托管变成自动化 AI | 托管只处理低价值事件，重大事件仍通知或降速 |
| R05 突破预设被误解 | 误做“满足条件后自动突破” | 明确当前合法才能预输入 |
| R06 局部时停信息泄露 | 其他玩家从降速推测私人事件 | UI 只显示中性速度，不显示归因 |
| R07 C1 追赶再次触发事件 | 追赶导致循环事件 | C1 只结算确定性内容 |
| R08 B1 拖慢非参战玩家 | 正式交锋会全世界慢速 | 控制交锋轮数，设置默认策略和硬上限 |

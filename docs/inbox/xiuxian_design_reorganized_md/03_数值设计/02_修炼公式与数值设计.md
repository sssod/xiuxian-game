# 数值设计｜修炼公式与数值设计

## 1. 核心路径

```text
RealmSegmentBalance
→ RealmBenchmarkRate
→ ActionCultivationProfile
→ RealmInputFitMatrix
→ ResourceEffectBalance / NodeRealmSupport / SectSupportBalance
→ StatePressureModel
→ BreakthroughScoreBalance
→ ReincarnationEfficiencyPolicy
→ 模拟验证
```

## 2. 每小时修炼结算公式

```text
normalized_gain_per_compatible_hour =
B_s
× A_action
× Q_aptitude
× M_method
× K_mastery
× N_node_aura
× F_facility
× R_resource
× S_sect_support
× P_state_penalty
× C_competition_or_window
```

其中：

```text
B_s = required_normalized_progress_s /
      (target_elapsed_hours_standard_s × expected_cultivation_hour_ratio_s)
```

## 3. 资源输入公式

```text
cultivation_resource_aura_input =
Σ(unit_aura_rate_i × applied_effective_hours_i × resource_quality_factor_i)
```

合流：

```text
raw_aura_input = environment_aura_input + cultivation_resource_aura_input
```

## 4. 残余效果

ActiveResourceEffect 允许跨行动、跨回合保存。决策阶段不推进药性衰减；只有服务器结算阶段、世界小时实际推进时才增加 idle_world_hours。

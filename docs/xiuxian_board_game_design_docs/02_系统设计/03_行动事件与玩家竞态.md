# 系统设计｜行动、事件与玩家竞态

适用范围：即时行动、主要行动、两段式承诺、事件代偿、仇恨关系、战斗 / 竞价选择和多人竞争顺序。

## 1. 即时行动

即时行动只在回合开始开放。在资源、对象和状态合法时不限制次数。

当前已确认：

- 交易；
- 调整装备；
- 服用丹药；
- 切换主修道功，每回合最多一次；
- 查看已知信息；
- 整理库存和不直接产出收益的资产操作。

移动结束后不重新开放即时行动窗口。每名玩家读取独立商店库存与价格，同一即时阶段不刷新，因此不产生玩家间抢购竞态。

## 2. 主要行动

当前已确认属于主要行动：

- 大境界突破；
- 地区影响力经营；
- 医馆等地点提供的专有疗伤；
- 研习功法；
- 飞升。

小洞天停留回合的主要行动自动锁定为闭关修炼。探索、采集、炼丹、炼器、主动战斗等是否进入 MVP 仍待 `S-02` 裁决。

## 3. 两段式行动承诺

```text
移动前：目的地、路线、移动方式、主要行动类型
移动后：对象、投入、数量和其它具体参数
```

移动后不能更换行动类型。成功抵达但没有合法参数时，行动失败，并从当前地点途中事件池抽取独立代偿事件；代偿事件可以触发战斗，但通常不产生玩家间竞争。

## 4. 仇恨与计划信息

规划阶段不公开其他玩家的目的地、路线、移动方式或行动意图。通用规则不提供窃取隐藏计划的能力。

仇恨是移动前设置的方向性宣战关系：

1. 任一方宣战即可使双方相遇时触发事件；
2. 第 `N` 回合设置后，第 `N+1` 回合不能解除，最早在第 `N+2` 回合移动前解除；
3. 普通相遇不触发，仇恨相遇自动中断双方移动；
4. 公开范围、通知方式和其它外交状态仍待后续裁决。

## 5. 竞争解决方式

战斗和竞价是两种通用工具：

1. 明确禁止武斗的事件固定竞价。
2. 其它竞争由参与者分别选择战斗或竞价。
3. 任一参与者选择战斗，全体进入战斗；只有全部未选择战斗时才竞价。
4. 竞价由最高出价者获得目标，当前不支持无代价退出；低价可以表达放弃争胜。

竞价支付资源、同时出价方式、平价处理和支付规则仍是大模块缺口。

## 6. 多人竞争顺序

道中相遇战按先到者先参战；抵达后的目标竞争战按先到者后参战。严格同刻到达时使用随机数决定相对顺序。

连续战斗保留生机、元气、神念和持续状态；护盾每场清空。死亡战利品在整段连续战斗结束后统一结算并交给最终胜利者。

## 2. 单局节奏、境界与终局

### 2.1 已确认

| 编号 | 裁决 |
| --- | --- |
| `S01-R01` | 首个飞升主题采用六个机械大境界：炼气、筑基、金丹、元婴、化神、大乘。炼虚与合体不进入首个主题，也不降格为小境界。 |
| `S01-R02` | 炼气、筑基、金丹、元婴、化神统一采用初期、中期、后期、圆满四个小境界；达到阈值后自动晋级，不占主要行动。 |
| `S01-R03` | 大乘是终局资格境界，不设置本局内继续成长的小境界。 |
| `S01-R04` | 标准局所有玩家统一从炼气初期、当前小境界进度 `0%` 开始；绝对 CP 值以后由境界数值表填写。 |
| `S01-R05` | 首个主题仍要求角色达到大乘、前往指定地点并完成飞升主要行动；不降低终局境界，也不把胜利改为仅取得飞升资格。 |
| `S01-R06` | 原 `45—60` 分钟精确目标不再采用。新的标准目标见 `S01-R07`；首个主题不设置系统强制的最终回合或现实时间上限。 |
| `S01-R07` | 标准局目标现实时长为 `90—120` 分钟，期望在第 `24` 个外界回合结束；合理胜利区间见 `S01-R08`。 |
| `S01-R08` | 标准局胜利回合的数值验收区间为 `20—24—28`：第 `20` 回合是最早合理胜利，第 `24` 回合是期望胜利，第 `28` 回合是最晚标准胜利。早于第 `20` 回合视为成长或机缘可能过强，晚于第 `28` 回合视为超出标准验收区间的延长对局；该区间本身不是强制结束规则。 |
| `S01-R09` | 不设置加时阶段专属的额外全局加速机制，也不设置绝对终局回合。后期节奏通过全局世界资源预算、建筑随回合自然升级和后续追赶机制持续加快。 |
| `S01-R10` | 在飞升胜利出现前，是否提前结束对局由玩家自行决定；系统不因达到某回合数自动选出替代胜者。具体发起、同意和结果表达归多人流程裁决。 |
| `S01-R11` | 六境与飞升的基准首次到达回合为：筑基第 `5` 回合、金丹第 `9` 回合、元婴第 `13` 回合、化神第 `17` 回合、大乘第 `21` 回合、完成飞升第 `24` 回合。上述值是数值验收锚点，不是强制截止。 |
| `S01-R12` | 基准节奏按约四个外界回合推进一个大境界；达到大乘后预留约三个回合用于终局移动、重点 PVE 前置和其他宗门阻拦。小洞天与高效率道功可以提前节奏，突破失败、重伤和路线竞争可以延长节奏。 |
| `S01-R13` | 单次非死亡突破失败通常造成 `1—2` 个外界回合的节奏延迟。失败当轮的主要行动、已使用丹药和自动修炼机会均已损失；不另设固定冷却，状态与资源允许时下一回合可以重试，需要专门恢复或补资源时可延长到两回合。死亡转世不计入该预算。 |
| `S01-R14` | 小洞天仍按一个外界回合推进十个角色内部时间单位，但普通角色的修为增长封顶于当前大境界瓶颈。洞天内不能执行大境界突破，达到瓶颈后的剩余修炼量不预存为下一大境界 CP；恢复、丹药持续、法宝炼化和寿元等其它内部时间效果照常结算。按基准四小境界节奏，一次洞天回合最多节省约三个正常成长回合。转世追赶例外在第 `7` 章继续裁决。 |
| `S01-R15` | 回合末自动修炼的修为增量读取角色所在地的环境灵气浓度；世界资源供给阶段提高地图环境灵气后，低境界和转世重修角色能够获得更高的自然修炼收益。具体简化公式仍待裁决。 |
| `S01-R16` | 首轮 MVP 的自动修炼采用：`节点实际灵气 = 节点基础灵气 × 世界资源供给阶段灵气倍率`；`每内部时间单位自动修炼 CP = 节点实际灵气 × 当前主修道功修为转化率`。道功掌握影响直接折算进转化率，不叠加旧版多层效率乘区。 |
| `S01-R17` | 首轮 MVP 暂不加入道功环境灵气吸收上限。丹药等额外修炼资源后续作为独立加算输入，不反向放大节点灵气；小洞天通过十个内部时间单位放大同一修炼公式。 |
| `S01-R18` | 首轮 MVP 中，每次获得小洞天奖励只产生一次洞天结算：在获得奖励的当前外界回合末按十个角色内部时间单位结算，随后入口关闭；不允许连续停留，也不额外占用下一回合的主要行动。普通角色仍封顶于当前未突破的大境界瓶颈；转世角色可在这十个内部时间单位内自动越过已经完成过的突破，实际追赶进度由本次获得的 CP 决定。 |
| `S01-R19` | 固定地点小洞天采用定期批次投放。第 `10` 回合进行首批投放，当批投放数量为 `玩家数量－1`；此后每经过 `10` 个外界回合再投放一批，即第 `20`、`30`、`40`……回合继续投放，每个后续批次的投放数量固定为 `1`。该周期在延长对局中持续，不因第 `24` 回合的标准胜利锚点停止或额外提速。 |
| `S01-R20` | 随机事件入口与固定地点小洞天分开管理。随机入口通过各事件入口的通过概率控制统计期望，不设置单局投放预算帽；它是常规节奏之外的惊喜产出，因此实际单局次数允许自然波动。 |
| `S01-R21` | 不设置玩家个人进入小洞天的累计次数上限或重复进入冷却。玩家在后续再次满足入口条件时，可以多次进入同一个小洞天洞府，也可以进入不同的小洞天洞府；该规则同时适用于固定地点与随机事件入口。每次进入仍分别执行 `S01-R18` 的一次性洞天结算。 |
| `S01-R22` | 每次尚未完成过的大境界突破只配置一个必需的核心突破物槽。标准经济路径必须允许玩家在此前约四回合的自动修炼阶段内，以最多一次主要行动取得该物品或完成下单；到达瓶颈后不再要求额外的“突破准备”主要行动，持有必需物即可在下一次主要行动发起突破。 |
| `S01-R23` | 必需的核心突破物明确为对应境界的破境丹药，不再配置第二类必需资源。破境丹药在发起突破时提交并按既有失败消耗规则处理；其它物品不能替代必需破境丹药。转世角色自动越过已经完成过的突破时不重复提交破境丹药。 |
| `S01-R24` | 前置破境成功率只由当前主修道功的突破模板基础成功率与本次提交的破境丹药品质加成共同决定。破境丹药品质越高，其配置的成功率加成越高；具体品质表、加成值、加算与上下限规则留待正式数值配置。法宝、非破境丹药及其它战斗构筑不修正这次前置判定。 |
| `S01-R25` | 需要渡劫的突破仍先进行 `S01-R24` 的前置破境成功率判定，判定成功后才进入渡劫战斗。渡劫战斗读取正常战斗规则与战前构筑，法宝、非破境丹药等可以正常生效，但其效果不得回溯改变已经完成的前置破境成功率判定。 |
| `S01-R26` | 每个普通大境界内部的初期、中期、后期、圆满不得平均分配修为 CP 需求。四段需求应总体递增，使玩家在同一大境界内先获得较快的阶段晋升反馈，越接近圆满与大境界瓶颈时所需修炼越多；“约一回合推进一个小境界”不再作为逐段设计目标。 |
| `S01-R27` | 大境界修为总量仍以标准节点、标准道功参考路线约 `4` 个外界回合抵达瓶颈作为配表锚点。四回合约束只校验整个大境界的总修炼时长，不要求四个小境界各占一个完整回合，也不要求各段绝对 CP 相同；高灵气地点、道功效率和掌握成长仍可改变实际用时。 |
| `S01-R28` | 炼气至化神的每个普通大境界统一采用同一段落占比：初期占本境总 CP 的 `15%`，中期占 `20%`，后期占 `25%`，圆满占 `40%`。对应累计阈值为 `15% / 35% / 60% / 100%`；达到前三个阈值时自动进入下一小境界，达到 `100%` 时停在大境界瓶颈。大乘仍按 `S01-R03` 不设置本局内继续成长的小境界。 |
| `S01-R29` | 界面显示当前小境界自身的 `0—100%` 进度，而不是只显示本大境界累计百分比。因此标准开局为“炼气初期 `0%`”；累计达到 `15%` 时转为“炼气中期 `0%`”，累计达到 `35%` 时转为“炼气后期 `0%`”，累计达到 `60%` 时转为“炼气圆满 `0%`”。一次结算跨越多个阈值时按顺序处理晋级并展示汇总结果。 |
| `S01-R30` | 若仅为说明而把标准四回合总修炼量平均看作每回合取得本境总量的 `25%`，则四轮结束状态依次约为：中期 `50%`、后期 `60%`、圆满 `37.5%`、抵达瓶颈。该序列用于验证“前段反馈快、圆满耗时最长”的体验，不要求实际每回合严格取得 `25%`；节点灵气、道功掌握和其它合法修正可以改变逐轮结果。 |
| `S01-R31` | 各大境界可以配置不同的总 CP 绝对值，但不得为不同境界重新改写 `15 / 20 / 25 / 40` 的段落比例。正式配表先确定该境界四回合参考总量，再按统一比例计算四段阈值；必要取整规则与 `1A` 的绝对 CP 尺度一起确定。 |

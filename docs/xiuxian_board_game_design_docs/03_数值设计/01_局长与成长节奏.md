# 数值设计｜局长与成长节奏

适用范围：目标回合数、境界到达预算、初始状态、死亡追赶和正式数值配置阶段门。

## 1. 当前目标

标准局支持 `2—4` 人，现实目标时长 `45—60` 分钟。当前尚未把现实时间换算为目标回合数，也没有各大境界的预期到达回合。

因此，本文件当前是下一阶段 P0 数值入口，而不是已经完成的数值表。

## 2. 已确认的节奏结构

1. 每个外界回合包含一次移动、一个主要行动和一次回合末自动修炼。
2. 小境界自动晋级，大境界突破占主要行动。
3. 金丹升元婴开始需要渡劫。
4. 小洞天一个外界回合推进十个角色内部时间单位。
5. 转世默认清空修为与境界，但保留知识掌握。
6. 达到大乘并完成飞升后，在回合末结束对局。

## 3. `S-01` 必须产出的配置

| 配置 | 需要回答 |
| --- | --- |
| 目标回合数 | 平均值、最短 / 最长合理波动 |
| 境界到达表 | 炼气至大乘的预期回合 |
| 突破预算 | 每次突破的准备与失败时间损失 |
| 小洞天预算 | 一次机缘允许跨越多少正常成长回合 |
| 死亡预算 | 一次转世预计损失多少回合，如何追赶 |
| 初始状态 | 境界、修为、道功 / 法门掌握、属性、物资 |
| 终局预算 | 达到大乘到完成飞升保留多少阻拦窗口 |

## 4. 推荐工作方式

先确定目标总回合数，再倒排：

```text
飞升阻拦窗口
← 大乘到达回合
← 后期突破预算
← 中期构筑与金丹战斗爆发期
← 前期移动、研习和资源建立
← 初始状态
```

不要先逐项填写修为阈值再观察总局长；每个数值必须能归属到一段回合预算。

## 5. 正式数值配置必填门

以下值已经有规则，但仍必须在正式数值配置中人工填写：

- 各境界通用有效修为与属性条上限；
- `C1`：主题通用金丹期体魄半伤常数；
- `C2`：主题通用金丹期神念上限半伤常数；
- `C3(g)`：各大境界通用元气上限制作锚点；
- 各品阶级、属性条和基础冷却对应的绝对 `K1_ref`；
- 境界阈值、自动修炼量、突破成功率与寿元消耗；
- “境界虚浮”固定战斗惩罚；
- G-23 百分比继承取整规则。

这些值不得因可以从其它表推导而从配置清单中消失。

## 6. 依赖的 P0 决策

局长表依赖主要行动与经济闭环：如果探索、采集、炼制、经营和研习的行动成本未定，无法可靠估算玩家每局可完成多少成长行为。

# 系统设计｜突破玩法

## 1. 设计定位

突破是角色从当前大境界跨入下一大境界的高价值事件链，负责回答“何时允许破境、玩家如何准备、突破阶段如何选择、资源与风险如何结算，以及结果如何写入本世和轮回账本”。它不是简单概率按钮，也不是普通修炼进度满后的自动升级。

突破玩法服务于长期准备、主修道功路线、关键突破物、地点与护法选择、宗门支持、外部干扰、失败标签和跨世复盘。玩家体验目标是主动承担风险、识别短板、选择资源投入和接受后果，而不是通过托管、自动脚本或即时补药绕过关键决策。

大境界突破必须由玩家主动发起；小境界升级是阶段内成长节点，不默认进入完整突破事件链。突破挑战复用 B1 提交窗口、默认策略、结果包和回放机制，但不等同普通战斗。

## 2. 当前结论

1. 大境界突破采用“长期准备 → 开启突破短指令 → B1 突破交锋 → 结果报告 → 后续处理”的事件链。
2. 大境界突破必须玩家主动开启；自动运转、普通托管、自动兜底和未来条件脚本不得主动发起高风险突破，也不得替代阶段选择。
3. 突破交锋进入 B1，但突破交锋自身耗时由突破模板声明，不固定等同于 B1 世界推进 1 小时。
4. 每个突破阶段只输入 1 个交锋格；每阶段现实决策窗口默认 60 秒；总交锋结算耗时暂定 1～6 游戏小时。
5. 关键突破物是进入不可回头突破链的承诺成本；创建突破实例后默认消耗或不可逆锁定。
6. 主修道功决定突破模板、阶段倾向、奖励结构和失败标签池，不能在圆满临破境时临时换功法规避模板。
7. 突破失败必须输出失败标签，并写入轮回账本，用于解释本世代价和下一世准备方向。
8. MVP 第一版优先验证 M1 → M2 与 M2 → M3 两段突破链，结果类型可先覆盖正常成功、失败存活和身死转世。
9. 大境界突破和高风险突破契机不能被普通预设或 F1 自动处理；F1 中触发突破契机时应按预设提醒、摘要或中断处理。

## 4. 核心循环或触发入口

突破链从长期准备开始，由玩家在满足条件后主动发起：

```text
长期准备层
→ 玩家确认开启突破短指令
→ 校验境界、主修道功、地点、状态和关键资源
→ 创建突破交锋实例并锁定 / 消耗关键突破物
→ 进入 B1 突破交锋
→ 按突破模板逐阶段选择与结算
→ 输出突破结果包
→ 生成个人结果报告、公开影响和回放记录
→ 进入巩固、疗伤、公开报备、隐瞒、处理道伤或转世等后续选择
```

B1 突破交锋采用当前重组包内的交锋计时裁决：

```text
B1 负责现实提交窗口、房间慢速和非参战世界推进；
突破交锋自身耗时由突破模板声明，不固定等同于 B1 世界推进 1 小时；
每个突破阶段只输入 1 个交锋格；
每阶段现实决策窗口 = 60 秒；
总交锋结算耗时暂定 1～6 游戏小时；
突破阶段耗时参与持续效果、资源、时间、日志和结果包结算。
```

每个突破阶段流程：

```text
1. 展示当前突破态势、阶段类型、可用资源和风险提示；
2. 玩家选择 1 个阶段应对；
3. 60 秒现实倒计时；
4. 玩家可提前提交，并可在倒计时结束前修改；
5. 未提交者执行当前突破默认策略；
6. 系统结算本阶段；
7. B1 让非参战玩家和世界推进 1 游戏小时；
8. 突破交锋自身按阶段模板记录结算耗时；
9. 写入阶段结果包、资源消耗、持续效果扣减和失败 / 奖励标签。
```

突破交锋不使用普通行动队列保存阶段选择。B1 或 P0 期间玩家可以编辑普通行动队列，但普通队列只影响交锋结束后的后续行动，不替代本阶段突破选择。

## 5. 规则与状态

### 5.1 大小境界分工

小境界升级是阶段内成长节点：

1. 可由修为进度、主修道功掌握度、主修道功支持范围和角色状态共同校验。
2. 可按个人即时处理事件或轻量提示处理。
3. 不消耗关键突破物。
4. 不进入完整突破事件链。
5. 默认不进入 B1，除非特殊模板明确把该小境界节点升级为高风险正式交锋。

大境界突破是核心玩法节点：

1. 必须由玩家主动开启。
2. 至少需要满足当前大境界圆满、主修道功承载、地点、状态和资源条件。
3. 开启后进入 B1 突破交锋，真实资源消耗、阶段选择和结果变化写入结果包。
4. 结果可能改变本世路线、宗门地位、轮回账本、后手安全和下一世规划。

### 5.2 准备维度

角色自身准备：

- 修为积累：是否达到尝试突破的基本量级。
- 修为纯度：修炼质量、杂质、速成副作用和资源吸收稳定性。
- 根基质量：当前大境界内的根基完整度和后续承载空间。
- 肉身承载：体魄、生机、经脉压力和伤势是否能承受冲击。
- 心境稳定：心魔、执念、恐惧、前世失败阴影和精神状态。
- 主修道功匹配：当前主修道功是否支持目标大境界，并能提供对应突破模板。
- 寿元压力：是否因寿元逼近而被迫冒险突破。

外部支持：

- 关键突破物：进入不可回头突破链的最低承诺成本。
- 辅助突破资源：稳定、提纯、镇魂、护体、攻伐、调和等资源输入。
- 护法力量：宗门、NPC、阵法、法宝或后手提供的安全支撑。
- 突破地点：宗门静室、洞府、灵脉、秘境节点、前世布置点等。
- 节点灵气：地点环境对突破的支持、相性、危险和波动。
- 宗门培养支持：资源调拨、名额、护法、场地、阵法和身份背书。

跨世与隐藏支持：

- 前世失败经验：提前暴露风险、提高挑战可见度或提供额外选择。
- 真灵强度：作为跨世主体的长期底层支撑。
- 因果负担：可能放大心魔、外扰或突破不稳。
- 正式后手辅助：前世洞府、接引阵、封存资源、护道人安排等。
- 宗门外洞府或普通藏宝线索：可作为资源来源、地点来源或失败后暴露风险。

每个准备维度至少应能产生一种作用：提高成功质量、降低某类失败风险、或在失败后生成可解释标签。

### 5.3 开启突破短指令

开启突破是普通短指令，不是 P0，也不是完整交锋选择。

开启指令可记录：

```text
开启突破；
选择少量开启阶段突破专用道具；
确认当前主修道功对应突破模板；
选择突破交锋默认策略；
确认当前地点、护法、宗门支持和后手输入。
```

开启条件建议至少校验：

```text
normalized_segment_progress >= 1.0
MethodState 掌握度满足当前境界段要求
foundation_quality >= required_foundation_min
meridian_pressure <= allowed_meridian_pressure_max
injury <= allowed_injury_max
mental_risk <= allowed_mental_risk_max
location_allows_breakthrough == true
method_template_available == true
required_resource_available == true
```

若作为预输入指令，只能在当前已经满足条件时入队。不能输入“等闭关完成后自动突破”“等炼出丹药后自动突破”“未来资源满足后自动突破”等条件脚本。

执行前必须重新校验。若地点、状态、模板或资源已失效：

```text
突破指令失败；
不消耗关键突破物；
写入个人日志；
角色进入休整、调息或兜底行动；
世界按速度规则回到 N1 或继续当前合法速度。
```

若开启阶段由临时确认触发，按个人即时处理事件（`event_time_mode=local_time_stop`）处理；安全默认是取消突破并进入休整。未提交确认前不消耗突破专用道具。

若突破契机在 F1 中触发：

1. 普通预设不得自动发起高风险突破。
2. 玩家已设置“不自动突破”时，F1 可只记录突破契机摘要或提示。
3. 玩家设置“满足条件提醒”时，应中断到 N1 / B1 / P0，由玩家确认。
4. 突破挑战仍进入 B1，突破轮内选择不进入普通队列或 F1 自动处理。

### 5.4 关键突破物与资源消耗

关键突破物是玩家从准备阶段跨入不可回头突破链的承诺成本。

规则：

1. 开始大境界突破至少需要 1 个关键突破物或等价资源条件。
2. 关键突破物是具体物品实例、宗门名额、地点窗口或后手资源，不是抽象货币。
3. 开启确认完成并创建突破交锋实例后，关键突破物进入消耗或不可逆锁定。
4. 无论成功、失败、中断、残缺突破或身死转世，已消耗的关键突破物默认不返还。
5. 所有关键消耗必须写入资源使用日志、资产日志、突破结果包和角色日志。

资源分层：

| 类型 | 作用 | 消耗时机 |
| --- | --- | --- |
| 关键突破物 | 决定能否开链，通常也提供基础稳定或路线相性 | 创建突破交锋实例时消耗或锁定 |
| 辅助突破资源 | 降低某类挑战风险、提高稳定度或品质 | 阶段选择确认后消耗 |
| 护法 / 宗门支持 | 抵消外扰、稳定地点、提供额外应对 | 按模板在阶段中占用或消耗 |
| 地点 / 阵法 / 后手 | 改变挑战序列、可见度、风险标签或结果后果 | 创建实例时锁定，阶段中按模板扣减或暴露 |

丹药、灵材、符箓、临时增益资源统一作为行动或事件选项的资源输入项，不做“即时服丹直接涨修为”。突破交锋中是否允许临时追加资源输入，必须由突破阶段模板声明 `resource_input_slot`：

```text
允许：突破阶段声明可使用定心丹、护心符、阵盘、法宝、后手感悟等，从当前阶段起生效；
禁止：突破失败后回溯服丹、回溯改变已结算阶段、普通背包随时即时涨修为；
要求：资源校验、消耗、残余处理和日志必须进入结果包。
```

修为类丹药只能作为主动吐纳等兼容行动的资源输入，不允许在突破交锋中即时增加修为。非修为丹药、护符、法宝和后手资源可按突破模板进入阶段选择；是否产生残余效果由资源模板和突破模板共同决定。

### 5.5 主修道功与突破模板

大境界突破读取当前大境界主修道功记录，用于生成突破模板、挑战倾向、奖励结构和失败标签池。

```text
当前大境界主修道功记录
→ 读取突破路线标签
→ 读取突破模板
→ 读取功法阶级 + 品级配置
→ 生成阶段序列、难度参数、奖励结构、失败标签池
```

主修道功掌握度影响角色是否承载得住目标阶段、是否满足开启条件、以及阶段执行表现；它不把一门道功临时改造成另一种突破模板。

主修道功只能在大境界突破后的首个小阶段窗口常规更换。角色到达当前大境界圆满、准备突破下一大境界时，已经不能临时换功法规避突破模板和难度。

模板至少应定义：

```text
BreakthroughTemplate {
  template_id
  supported_transition
  supported_method_tags
  stage_templates
  default_strategy_options
  initial_score_profile
  stage_resource_slots
  interference_policy
  result_threshold_profile
  failure_tag_pool
  reward_profile_ref
  report_template_ref
}
```

### 5.6 B1 突破交锋

突破交锋是正式交锋，但不等同普通战斗。

| 项目 | 普通战斗 | 突破交锋 |
| --- | --- | --- |
| 核心目标 | 击退、逃脱、争夺、护法或生存 | 稳定破境、提高成功率和品质、控制代价 |
| 对手语义 | NPC、小队、妖兽、敌对事件 | 功法瓶颈、内劫、心魔、经脉冲击、外扰 |
| 输入结构 | 每轮多个战斗交锋格 | 每阶段 1 个突破交锋格 |
| 常用耗时 | 战斗模板结算，常规不足 1 小时按 1 小时 | 阶段模板累计，暂定总耗时 1～6 小时 |
| 结果核心 | 伤势、死亡、物品、位置、目标达成 | 境界结果、突破品质、失败标签、轮回账本 |

一般同境界各个突破阶段耗时相同；不同突破模板的主要差异在突破指令应对、资源取舍和风险标签，而不是默认拉长每阶段耗时。由于突破阶段累计耗时会参与计算，提前炼化中的丹药、符箓、法宝或其他持续效果可能在达到时间节点时生效或扣减剩余持续时间。

MVP 丹药没有即时生效类型，都需要依赖炼化与时间流逝生效，因此丹药不允许在战斗交锋和突破交锋中作为即时指令使用。正式版若引入即时生效丹药，届时可以加入交锋指令列表。

### 5.7 阶段类型与应对指令

每个阶段都应满足：

1. 玩家能理解本阶段主要考验什么。
2. 玩家至少有一种基础应对方式。
3. 已有准备会产生明确修正。
4. 失败会输出明确原因标签。
5. 结果能回写到突破稳定度、成功分、品质分或结果标签。

常见阶段类型：

| 阶段类型 | 语义 | 推荐应对 | 常见失败标签 |
| --- | --- | --- | --- |
| 入定 / 稳住灵台 | 开始破境，稳定心神和节奏 | 凝神守一、稳健突破、动用镇魂资源 | 心境不稳、前世阴影、心魔压制 |
| 灵力冲关 | 把积累转化为破境冲击 | 调息聚元、强行冲关、消耗破境资源 | 修为积累不足、元气不足、冲关无力 |
| 经脉逆冲 | 检验纯度、经脉和资源转化 | 顺势化解、提纯类资源、水行调和 | 修为纯度不足、经脉阻滞、资源转化不稳 |
| 肉身承载 | 检验体魄、生机、伤势和压力 | 稳固生机、以身承劫、护体法宝 | 肉身承载不足、生机亏损、带伤破境 |
| 神念 / 心魔 | 检验神识、心境、执念和因果 | 观想镇念、定心资源、前世经验提示 | 神念不足、心魔压制、因果负担 |
| 关隘攻伐 | 需要主动破关，不能只防守 | 强行冲关、斩破关隘、攻伐法宝 | 功法攻伐不足、冲关失手、反噬 |
| 外扰 / 护法 | 节点、敌对势力、秘境或行踪暴露干扰 | 护法抵御、阵法护持、宗门支援 | 外部干扰过强、护法不足、地点暴露 |
| 境界成形 | 最终定型品质与代价 | 保守成形、追求高品质、接受根基损伤换突破 | 根基不稳、品质受损、残缺突破 |

阶段应对来源：

```text
基础破境指令：所有角色都可用，例如凝神守一、调息聚元、顺势化解、强行冲关；
主修道功指令：由道功路线提供，例如以身承劫、观想镇念、斩破关隘、润脉化冲；
资源 / 法宝 / 后手指令：由物品、符箓、法宝、阵法、护法、宗门支持或前世后手提供；
事件特殊指令：由地点、因果、外扰或模板阶段临时提供。
```

### 5.8 突破交锋状态与结算

突破进入 B1 时，可由准备质量生成初始分与临时状态。初始分只承接准备质量，不直接决定最终结果。

建议初始分来源：

```text
修为积累
修为纯度
根基质量
主修道功掌握度
地点相性
资源适配
护法 / 宗门支持
后手辅助
心境、伤势、经脉压力和因果惩罚
```

每阶段结算可调整：

- `success_score`：代表能否完成突破。
- `quality_score`：代表突破品质、奖励完整度和残缺风险。
- `breakthrough_stability`：代表本次事件链内部稳定度。
- `pressure_state`：代表经脉、心魔、反噬、伤势、寿元压力等临时风险。
- `failure_tags`：记录失败原因、来源阶段、严重度和下一步建议。

最终结果由累计状态决定：

```text
准备质量
+ 阶段选择
+ 阶段资源消耗
+ 状态剩余量
+ 失败标签严重度
+ 外扰处理结果
+ 模板结局
→ 最终突破结果
```

### 5.9 默认策略与超时

突破挑战必须支持默认策略，避免多人时间卡死。

默认策略建议：

- 保命优先。
- 稳健突破。
- 节省珍贵道具。
- 优先成功率。
- 追求高品质。
- 接受根基损伤换突破。
- 失败即中止。

若玩家某阶段 60 秒内未提交，执行当前突破预设。默认策略不得凭空使用未授权的稀有不可逆资源；只有玩家在开启阶段或上一阶段明确授权的资源，才可被默认策略消耗。

### 5.10 外部干扰

外部干扰是突破链内的子事件，不是随机没收资源。

来源：

- 当前节点危险等级。
- 敌对宗门、竞争者或妖兽。
- 秘境关闭、灵气波动、节点危机。
- 护法不足或阵法失效。
- 玩家行踪暴露。
- 因果扰动或前世失败阴影。

外扰规则：

1. 低预警外扰不应直接中断突破，只能生成轻度负面修正、额外压力或可处理阶段。
2. 中预警外扰可以触发护法、防护、稳定选择；处理不当才进入惩罚。
3. 高预警或明确敌对事件可以直接导致突破中断、失败或严重后果。
4. 直接中断必须写入明确原因标签，例如突破地点暴露、护法不足、节点危机失控。
5. M1 → M2 以教学和第一次完整体验为主，外扰默认低强度。
6. M2 → M3 可提高宗门支持、节点控制、护法和传闻扩散权重。

### 5.11 结果类型

突破结果至少支持：

1. 完美突破。
2. 正常突破。
3. 残缺突破。
4. 失败但存活。
5. 身死转世。
6. 严重失败，并附带真灵受损、因果加重、宗门遗产清点风险、无主遗留设施线索暴露、后手污染或宗门关系破裂。

若实现成本紧张，MVP 第一版可先实现：

```text
正常成功
失败存活
身死转世
```

残缺突破和严重失败必须保留数据字段。残缺突破不是隐性废档，应提供修复路径、后续代价或转世优化价值。

### 5.12 失败标签与轮回账本

突破失败必须输出一个或多个失败标签。

标签方向：

- 修为积累不足。
- 修为纯度不足。
- 根基不稳。
- 肉身承载不足。
- 生机亏损或带伤破境。
- 心境不稳。
- 神念不足。
- 心魔压制。
- 功法不合。
- 冲关无力。
- 突破资源不足或不匹配。
- 护法不足。
- 地点灵气不足或不稳定。
- 宗门支持不足。
- 因果负担过重。
- 前世失败阴影未化解。
- 外部干扰过强。
- 后手暴露或污染。

轮回账本写入：

```text
成功：突破阶段、主修道功、关键资源、地点、护法、成功质量、奖励标签、后续路线提示；
失败：失败阶段、失败标签、消耗资源、外扰状态、是否身死转世、是否产生道伤 / 残缺 / 真灵 / 因果 / 遗产 / 宗门后果、下一世准备建议。
```

前世经验不直接保证成功。它可以提前暴露风险、提高挑战序列可见度、提示同类失败标签、解锁特殊准备路径或提供额外破境指令。

### 5.13 结果报告

突破挑战结束后，生成个人结果报告、公开影响和回放记录。

个人报告至少包括：

```text
突破成功 / 失败；
境界变化；
突破品质；
根基变化；
伤势与道伤；
寿元变化；
资源消耗；
主修道功影响；
失败原因标签；
下一次修正方向；
轮回账本记录；
后续可选行动。
```

公开影响根据可见性和事件强度决定，可进入宗门传闻、世界日志、节点变化、身份变化或宗门态势。隐秘突破不得向其他玩家暴露具体来源，只能通过中性速度、公开后果、传闻或调试信息表达。

后续选择按个人即时处理事件处理，例如：

- 巩固境界。
- 疗伤。
- 隐瞒突破。
- 公开报备。
- 请求宗门护法。
- 处理道伤或残缺。
- 清点遗产与后手风险。

## 8. UI 展示边界

突破 UI 应展示玩家可决策信息，而不是完整公式或隐藏权重。

普通界面应展示：

1. 当前目标境界和开启条件是否满足。
2. 关键突破物、辅助资源、地点、护法、宗门支持和后手输入。
3. 当前主修道功对应的突破模板倾向。
4. 修为积累、纯度、根基、肉身、心境、经脉压力和寿元压力的风险提示。
5. B1 阶段剩余提交时间。
6. 当前阶段语义、可用应对、可授权资源和默认策略。
7. 已结算阶段摘要、消耗、失败标签和风险变化。
8. 突破结果报告、境界变化、资源消耗、失败原因和下一次准备方向。

普通界面不应展示：

1. 完整成功分、品质分和稳定度公式。
2. 隐藏随机种子、完整权重表或未公开外扰来源。
3. 其他玩家隐秘突破的具体触发原因、地点、资源或参与者。
4. 普通行动队列可以替代阶段选择的暗示。
5. 低预警外扰会随机没收资源的错误预期。

## 9. MVP 范围

MVP 应实现：

1. 大境界突破必须手动开启。
2. 开启前条件校验和执行前重新校验。
3. 至少 1 个关键突破物或等价资源条件。
4. B1 突破交锋，每阶段 1 个交锋格。
5. 默认策略与 60 秒现实提交窗口。
6. 正常成功、失败存活和身死转世三类结果。
7. 失败标签和轮回账本写入。
8. 个人结果报告、公开影响和回放记录。
9. M1 → M2 与 M2 → M3 两段突破链。

MVP 不实现：

1. 完美突破和残缺突破的完整修复链，但需保留字段。
2. 多角色复杂护法操作。
3. 高复杂外扰战斗链。
4. 完整宗门审批、排队和名额争夺流程。
5. 即时生效丹药。
6. 自动条件脚本主动发起突破。

### 9.1 M1 → M2

目标：教会玩家突破不是概率按钮。

建议：

- 1 个关键突破物。
- 2～5 个突破阶段。
- 外扰默认低强度，不直接中断突破。
- 失败以存活、道伤、短期惩罚为主，少量严重失败可身死转世。
- 教学重点是准备面板、关键物消耗、阶段选择、默认策略和失败标签。

### 9.2 M2 → M3

目标：把突破与宗门、节点、护法、后手和世界传闻连接起来。

建议：

- 1 个更高阶关键突破物。
- 3～6 个突破阶段。
- 可加入外扰变体、护法检验或宗门支持阶段。
- 地点、护法、节点局势和宗门资源权重更高。
- 失败可以更强地影响宗门地位、后手、遗产、传闻或转世。

## 10. 验收约束

1. 小境界升级不进入完整突破链。
2. 大境界突破不能由托管、自动运转或未来条件脚本主动发起。
3. 未达开启条件时，开启突破不可入队。
4. 开启指令执行前资源、地点或状态失效时，不消耗关键突破物。
5. 突破挑战进入 B1，阶段选择不保存到普通行动队列。
6. F1 中触发的大境界突破契机不得被普通预设自动处理。
7. 每阶段只有 1 个突破交锋格，现实提交窗口 60 秒。
8. 未提交阶段选择时执行当前突破预设。
9. 默认策略不得擅自消耗未授权的稀有不可逆资源。
10. 真实资源消耗发生在开启创建实例或阶段结算中，并进入结果包。
11. 突破交锋自身耗时由模板声明，总耗时暂定 1～6 游戏小时。
12. 低预警外扰不直接中断突破，高预警中断必须有原因标签。
13. 结果报告必须显示发生了什么、为什么成功 / 失败、下一次该补什么。
14. 失败标签写入轮回账本。
15. 结果生成个人报告、公开影响和时间轴回放。
16. 残缺突破和严重失败即使暂不完整实现，也必须保留数据字段。
17. MVP 丹药不得在突破交锋中作为即时指令使用。

# 物品设计｜符箓

## 1. 当前状态

当前 Library 中未检索到符箓独立设计稿。本文件只按资源输入与物品系统已有约束整理。

## 2. 当前可确定口径

符箓可作为：

- 行动资源输入。
- 事件选项附加资源。
- 战斗指令来源。
- 防护 / 探索 / 移动 / 毒瘴 / 阵法等上下文资源。

与丹药相同，符箓不应绕过服务端资源使用接口、事件结果包和日志。

## 3. 数据建议

```yaml
TalismanItem:
  item_template_id: string
  tier: string
  quality: string
  compatible_action_tags: list
  compatible_context_tags: list
  combat_command_ref: string | null
  event_option_tags: list
  consume_on_use: bool
  residual_policy: string | null
```

## 4. 缺口

- 符箓分类表。
- 符箓与战斗/事件/移动/探索的效果映射。
- 符箓制作配方、材料、失败副产物。
- 符箓是否可堆叠及堆叠键。

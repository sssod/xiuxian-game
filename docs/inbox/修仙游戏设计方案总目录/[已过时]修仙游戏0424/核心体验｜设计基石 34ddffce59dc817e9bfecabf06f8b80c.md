# 核心体验｜设计基石

## 0. 页面定位

本页面用于沉淀《修仙游戏》的核心体验文档系列。

核心体验文档的优先级高于顶层系统设计和各子系统设计。顶层系统设计负责把核心体验拆解为可执行系统结构；子系统文档负责承接系统边界、规则接口和实现拆分。若后续顶层设计或子系统设计与核心体验文档发生冲突，应优先回到核心体验文档重新校准。

## 1. 当前用途

本系列首先用于厘清以下问题：

1. 玩家为什么要修炼、突破、转世与重修。
2. 玩家长期追求的到底是什么。
3. 修为、资源、宗门、战斗、非战斗能力、天赋、后手之间的核心关系是什么。
4. 哪些设计属于游戏体验基石，不能被后续系统细节反向稀释。

## 2. 与顶层系统设计的关系

顶层系统设计是系统化方案；核心体验文档是体验层原则。

后续推进顺序应为：

```
核心体验
→ 顶层系统设计校准
→ 子系统设计
→ 数值 / 内容 / UI / 技术实现
```

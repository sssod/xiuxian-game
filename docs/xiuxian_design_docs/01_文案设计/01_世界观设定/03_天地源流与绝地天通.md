# 文案设计｜世界观设定｜天地源流与绝地天通

适用范围：`docs/xiuxian_design_docs/01_文案设计/01_世界观设定` 中的创世前史、建木时代和绝地天通历史背景。

来源说明：本文由包外草稿 `docs/inbox/mainline_outline_shanhai_duanmu_v0_2_1.md` 拆分并吸收到正式设计文档包；正式解释以本文和同目录关联文件为准，源稿只保留为历史参考。

## 1. 当前定位

本文负责把创世、建木时代、归墟借建木浸入、绝地天通和建木转封后的后遗症整理为正式世界观背景，为主线剧情提供旧史压力和终局冲突来源。

## 2. 内容边界

本文不把创世阶段和绝地天通阶段做成可回到过去改变因果的玩法时代。相关内容通过梦境、碑文、山海图、宗门档案、残响、功法名与遗迹痕迹呈现。

## 3. 拆分摘要

1. 创世前史提供太初归一、太极分判、混沌无界、归墟回卷等底层世界压力。
2. 建木时代解释诸界通路、神庭往来、飞升旧制和山海万类共存的前史背景。
3. 绝地天通是山海最大前史事件，太极胜利保存现世，也把建木从诸界通路转化为界域隔离，制造飞升封锁、断木遗产和四极大阵等当世矛盾。

## 4. 第一阶段：创世（源稿 §3）

### 3.1 阶段定位

创世阶段不是传统意义上的“可穿越副本”，也不是玩家能改变的过去，而是现世终局冲突的根因。它通过山海图功法志、终局 NPC 对话、开辟级功法残篇、太易推演、太初残响、太极律印、混沌裂隙与归墟潮声逐步显影。

这一阶段回答四个问题：

1. 为什么世界不是天然稳定的？
2. 为什么太初、太极、混沌会成为三大主要势力源头？
3. 为什么归墟不是普通敌国，而是世界级灾害？
4. 为什么玩家真灵不能被写成大道本身或创世神明？

创世相位负责世界底层本体论、终局冲突和高位 NPC / BOSS 势力，不直接作为玩家真灵根脚池。真灵只是开天之后未入后天轮回的先天余气残留，不具备绝对权柄。

### 3.2 节点 C-1：无名之前 / 太易

世界尚未成形，太易无名，万物未显。这里不作为主线势力，只作为“命数、真名、藏世、无名档案”的来源。

**可呈现文本：**

> 最初不是黑暗，也不是虚空。  
> 因为黑暗尚需有光可对，虚空尚需有界可量。  
> 那时无名，故无可被杀，无可被救，也无可被记入山海图。

**功能：**

- 为太易中立 NPC 埋线。
- 为“藏名”“真名抹除”“山海图残文”提供合法性。
- 不把太易做成主线大反派。

### 3.3 节点 C-2：太初一气

太初一气初生，万气尚未分化。太初不是善恶阵营，而是一种“差异尚未成立”的创世压力。

**太初方世界观主张：**

- 万物本是一气。
- 灵根、宗门、真灵名、山海异兽、功法分层，都是后天差异。
- 差异带来争夺、污染、归墟缝隙。
- 因此应把山海重新收束为单一气源。

**太初方叙事诱惑：**

- 能短期修复灵脉枯竭。
- 能让杂乱宗门争斗停止。
- 能让低资质修士借“归一”获得统一修炼模板。
- 能把归墟污染暂时压回一气深处。

**太初方危险：**

- 真灵名会被抹平为“气机残数”。
- 五行、形质、神魂等分化路线会失去意义。
- 宗门、异兽、山海地理都可能被视为应被归并的“歧路”。

**代表势力建议：**

- 核心宗门：太初归元宗。
- 外围组织：归元医盟、元炁院、灵脉赈济使。
- 终局 NPC：一炁君、归元祖、太初残响。
- 早期伪装：灵脉修复组织、灾后赈灵盟、归元医修。
- 中期暴露：节点灵气被统一抽回“根井”。
- 终局行动：启动“万气归根阵”，把山海节点并入太初气源。

### 3.4 节点 C-3：太极分判

太极是阴阳分判、秩序成立、天地重分的相位。它是绝地天通秩序派的本体压力来源，也是上一次归墟大劫的最大胜利者。

**太极方世界观主张：**

- 世界之所以能存在，是因为清浊、上下、神人、山海、归墟之间有边界。
- 建木时代的混杂导致灾难。
- 绝地天通不是错误，而是必要的世界手术。
- 现世应继续封绝，甚至更彻底地律令化。

**太极方叙事诱惑：**

- 能稳定归墟潮。
- 能建立清晰的宗门秩序与突破许可。
- 能保护普通修士与凡人聚落。
- 能让玩家在混乱世界中获得制度支持。

**太极方危险：**

- 旧天路被永久封锁，渡劫与飞升被纳入律令、阵法和终局条件审查；大乘之后只能在终局框架中争取出路。
- 真灵、异兽、秘境、古法会被纳入严格登记。
- 玩家自由探索与非正统功法路线会被视为越界。
- 宗门可能从地方性道统维护组织，变为绝对管制机构。

**代表势力建议：**

- 核心宗门：天衡道庭。
- 外围组织：天衡司、重黎律院、封潮巡使。
- 终局 NPC：天衡君、律天尊、重黎律印守。
- 早期伪装：归墟预警署、突破审查司、秘境封存所。
- 中期暴露：开始追查玩家真名与真灵线索。
- 终局行动：启动“永断天衡”，永久加固绝地天通。

### 3.5 节点 C-4：混沌反开辟

混沌不是归墟本体。混沌是反开辟、边界溶解、重启冲动；它可能借归墟力量，但不等于归墟自然灾害。

**混沌方世界观主张：**

- 太初归一是吞并，太极秩序是囚笼。
- 真正的自由在边界之前。
- 建木转封后的一切宗门、山海图、真名、功法路线都是牢笼。
- 旧世界应被溶解，众生重新进入未定状态。

**混沌方叙事诱惑：**

- 能打破宗门权限限制。
- 能绕过天路不通。
- 能快速开启隐藏层、界隙、古法残篇。
- 能让被太极压制、被太初同化的人获得反抗力量。

**混沌方危险：**

- 身份、地理、功法、关系都可能失去稳定性。
- 异兽迁徙变成异兽异化。
- 秘境窗口变成界隙吞噬。
- 玩家真名可能从“被隐藏”变成“无从存在”。

**代表势力建议：**

- 核心宗门：无界玄宗。
- 外围组织：开隙会、无界行者、裂隙散修。
- 终局 NPC：无界君、混成主、裂天子。
- 早期伪装：反宗门散修联盟、秘境自由开拓者。
- 中期暴露：制造界隙叠合，导致节点地图失序。
- 终局行动：启动“无界重开”，溶解绝地天通与山海边界。

### 3.6 节点 C-5：归墟成灾

归墟是开辟失败、清浊回卷的深层裂口。它不需要有完整人格，也不需要成为可外交势力。玩家可以对抗迎墟者、借墟者、破界者，以及被归墟污染后仍保留意志的个体，但不能把归墟本体写成可加入阵营。

**归墟叙事功能：**

- 是所有阵营都必须面对的外部压力。
- 是太极封绝的正当性来源之一。
- 是混沌借力的危险源。
- 是太初宣称“差异导致裂口”的论据。
- 是玩家终局选择的压力计。

**迎墟者世界观主张：**

- 现有山海已无可救。
- 归墟不是灾害，而是重启。
- 越早迎接归墟，越少痛苦。
- 断木、宗门、山海图、真灵旧名都应沉入归墟。

**代表势力建议：**

- 显性反派组织：迎墟会、归潮祭社、归潮众、海眼教、渊诏盟。
- 主要敌人：引潮使、海眼祭主、归墟化潮主。
- 早期表现：污染水脉、偷取归墟潮刻、献祭海眼节点。
- 中期行动：破坏封绝结构，嫁祸宗门或真灵。
- 终局行动：制造“万潮入根”，让归墟沿断木余脉倒灌。

### 3.7 太始与太素的中立位置

太始、太素不抢三大核心宗门的主轴，但在世界中有重要功能。

| 相位 | 功能 | 主线位置 |
|---|---|---|
| 太始 | 妖兽、山精、源胎、形体演化、神山巨骸 | 可提供异兽生态线、太始源胎、异兽王等中立 / 半敌对内容 |
| 太素 | 神材、炼器、商会、铸界、法宝秩序 | 作为四方镇守之一，承担大阵维护、撤离物资、器械与债务 |

## 5. 第二阶段：绝地天通 / 建木转封（俗称建木断，源稿 §4）

### 4.1 阶段定位

绝地天通 / 建木转封是山海历史层最大前史事件。绝地天通是人神分治、天地秩序重建和上下交通权封绝；建木是诸界往来的宇宙树 / 天梯；游戏中将二者结合为可视化的世界转折事件。“建木断”可作为现世俗称、碑文简称和宗门档案旧名，但正式设定不把建木处理为被简单砍断或完全死去。

本阶段叙事原则：

- 不做“穿越回去阻止绝地天通”。
- 不做“救下建木即可完美结局”。
- 不让颛顼、重、黎成为可对话、可组队、可战斗 NPC。
- 只通过宗门档案、断木碑文、山海残文、功法名、律令残响、象征性遗迹呈现。
- 玩家追查的重点是“现世如何处理它留下的问题”。

### 4.2 事件前世界状态

绝地天通之前，山海世界不是普通人间，而是天地、神民、异兽、真灵、太初残域仍然混杂的早期世界：

- 建木连接山海界、神庭、太初残域和其他可达界域，是诸界交通的主干。
- 昆仑是地上最高的神庭门户。
- 归墟是开辟失败、清浊回卷的深层裂口，也存在于与山海相邻或相牵的危险界域。
- 神兽、异兽、修士、巫祝、早期宗门、真灵承载者共同活动。
- 修行不完全依赖宗门秩序。修炼成仙者既可以通过受封神位借建木往来，也可以在历经飞升考验后直达其他界域。

这一时代的主线状态可以写成：

> 建木不是单纯的树，而是世界的垂直交通。  
> 它让人可近神，让地可接天，让山海异兽可迁徙，也让飞升者可离界远行。
> 但它既连通神庭和诸界，也给太初残域与归墟裂口提供了互相牵引的路径。
> 所谓通天，既是恩赐，也是灾路。

### 4.3 四方势力在建木时代的行动

| 势力 | 建木时代行动 | 对建木转封的态度 | 留给现世的遗产 |
|---|---|---|---|
| 太初方 | 试图以建木为“万气归根”的主脉，把山海灵气回收为一气 | 认为封绝是误断源流；主张重开建木并归一万气 | 归元根井、无影木、太初气井、灵脉归根术 |
| 太极方 | 记录神民混杂与归墟倒灌，推动天地分层，并提出把建木转为界域隔离 | 认为转封是必要秩序；主张继续甚至强化绝地天通 | 断木律令、天衡法台、突破审查、封绝阵、四极镇墟大阵 |
| 混沌方 | 借建木多界连通，制造边界松动与界隙叠合 | 认为封绝是囚笼；主张破界重开 | 无界裂片、混沌秘境、裂界符、边界溶解法 |
| 太素方 | 提供神材、阵基、法器与封存器械 | 认为任何方案都必须落到阵材与维护 | 铸界阵基、避墟器、镇墟法宝、债契体系 |
| 归墟 / 迎墟者 | 归墟潮借建木诸界网络浸入；迎墟者将灾害解释为重启 | 认为建木转封阻碍归墟降临；主张破坏界域隔离 | 海眼潮刻、归墟漂木、污染水脉、引潮仪式 |

### 4.4 导火索详纲

建木转封不写成单一“人想登天，所以天帝降罚”，而采用多方矛盾：民神杂糅失控、归墟借道入世、真灵反复干预、宗门雏形争夺建木支脉、颛顼一系选择分治。

#### 导火索 1：通天术泛滥

早期巫祝、修士、异兽血脉者、神庭使者都可借建木上下通行。受封神位者可以凭神庭秩序往来建木，修炼圆满者也可以通过飞升离开山海界。通天术不再是稀有仪式，而变成争夺权力、资源和寿元的工具。

**现世残留：**

- 某些宗门仍保留“登真”“步虚”“通玄”等功法名。
- 高阶突破失败标签出现“天路不通”。
- 秘境窗口有时会显现旧日神庭门痕。

#### 导火索 2：归墟沿根倒灌

归墟并非主动外交势力，而是灾害压力。建木既连通山海界，也牵连神庭、太初残域和其他界域；当归墟所在界域与建木网络发生牵引后，归墟潮便有了沿根系、支脉和界门浸入山海的路径。此时只封一个海眼或砍断一段枝干不足以止灾，必须整体加厚山海界与其他界域之间的隔离。

**现世残留：**

- 海眼节点周期性污染。
- 归墟漂木带有断木纹理。
- 水行真灵“归潮”可能被污名为引潮者。
- 归墟听潮类法门可预警，但也会提高污染暴露。

#### 导火索 3：真灵反复干预

部分真灵通过跨世藏宝、旧世线索、无主遗留设施反复干预山海时代，造成历史闭环和资源异常。

**现世残留：**

- 玩家发现某处洞府像是“自己”留下，却不属于当前身躯。
- 宗门档案把同一个真灵名记在多个时代。
- 轮回账本出现“非本世行为记录”。
- 真灵支线出现“继承 / 质疑 / 改写 / 利用”的态度选择。

#### 导火索 4：宗门雏形争夺建木支脉

早期宗门不是完整门派，而是围绕神山、灵脉、建木根、异兽巢形成的道统势力。绝地天通前，他们争夺通天资源；绝地天通后，他们成为地方性道统维护组织。

**现世残留：**

- 宗门保存山海残传，但解释各不相同。
- 宗门掌握断木遗址调查权限。
- 宗门节点实际是在管理断木余脉与灵气资源。
- 主线通过宗门权限逐步开放，而不是山海图直接触发大事件。

#### 导火索 5：秩序派选择分治

颛顼、重、黎代表秩序派，但不直接出场。玩家只能看到“重司天、黎司地”的碑文、律令、功法名和残响。

**现世残留：**

- 断木律印。
- 重黎法台。
- 天衡司档案。
- 某些太极方 NPC 宣称自己只是继承必要秩序，而非神话人物本人。

### 4.5 建木转封过程详纲

| 阶段 | 前史事件 | 主线表现 | 现世可探索对象 |
|---|---|---|---|
| 1 | 建木诸脉暴涨，神民与飞升者通行失控 | 旧碑记载“木影覆四海，神民不分籍” | 无影木、树根化灵脉、神庭残门 |
| 2 | 归墟潮借建木诸界网络浸入 | 海眼喷出带木纹的黑潮，神山秘境出现反向潮声 | 归墟漂木、潮刻、污染洞府 |
| 3 | 重司天、黎司地，封绝天地交通 | 律令残响反复出现“上下有别，诸界有隔” | 天衡法台、断木律印、封绝阵基 |
| 4 | 建木主干被封入界垣，连通诸界的能力被反向转为阻隔诸界 | 神山、秘境、残图、遗址形成，旧枝不再通天 | 断木遗址、神山秘境、山海残图 |
| 5 | 四极镇墟大阵成型 | 飞升之力被截流，归墟潮被挡在四海外，界域隔离持续增厚 | 四极阵基、昆仑中枢、太素铸界遗物 |
| 6 | 少数离界者无法回返，多个真灵留下不同记录 | 玩家支线显示“同一事件的不同位置”与“飞升后杳无音讯” | 真灵藏宝、轮回账本、山海图真灵故事 |

“断”不一定是物理砍断。更准确的设定是：建木主干被封绝、分脉、镇压并转入界域隔离；地上只剩断木遗址、无影木、通天根、归墟漂木、山海残图和作为大阵阵骨的不可见主干。

### 4.6 建木转封后的世界后遗症

绝地天通造成长期后果：神、人、山海、上界、太初残域和归墟所在界域重新分层；旧日通天路径断绝；宗门兴起；神山秘境成为建木支脉、神庭残门或隐藏层残余；归墟潮汐周期性冲击山海世界；山海残图记录建木转封前后的地理、历史和真灵痕迹。

| 后遗症 | 系统化承接 |
|---|---|
| 天路断绝 | 大乘后进入渡劫期、旧路飞升失败标签、终局选择压力 |
| 建木界垣化 | 建木余根、断木遗址、通天根和神山秘境既是资源，也是界域隔离的薄弱点 |
| 飞升之力被截流 | 四极镇墟大阵持续消耗灵力，解释世界灵力衰退 |
| 飞升者难归 | 天仙多已杳无音讯，山海界内的高阶目标转向地仙灾劫炼身 |
| 神山秘境残留 | 地图探索、秘境窗口、宗门争夺 |
| 归墟周期潮 | 世界事件倒计时、污染 / 净化压力 |
| 宗门兴起 | 玩家成长平台、资源权限、档案解锁 |
| 真灵旧痕 | 预设真灵支线、自定义承道、轮回账本 |
| 山海残图 | 图鉴 / 收藏 / 成就系统，不作为主线关卡入口 |

### 4.7 地仙、天仙与修炼目标变化

绝地天通前，渡劫期主要是飞升前的关口：修士需要经历三灾九劫等一系列考验，才能真正飞升，或以神位身份借建木往来。绝地天通后，建木限用、界域隔离增厚，飞升变成极少数终局路线或传说结果；即使成功，也很难再回到山海界。

因此，现世大乘之后的道路不再默认以飞升为目标，而是转向**灾劫炼身**。渡劫期的灾劫不按道功生成个人挑战模板，而按灾劫类型提供统一考验。每度过一类灾劫，角色获得对应维度的大幅提升。正式版终局养成至少预留两类具有世界观意义的灾劫：

| 灾劫维度 | 世界观含义 | 作用 |
|---|---|---|
| 来处之劫 | 与真灵跟脚、旧名、前世痕迹相关 | 检验角色如何承认、改写或斩断自己的来源 |
| 去处之劫 | 与阵营归属、道统选择、世界方案相关 | 检验角色最终归向山海、宗门、界外、新路或藏世 |

进入渡劫期后，只要渡过任意一种灾劫，便可称**山海地仙**，简称**地仙**。地仙仍归属山海界，可继续活动、镇守、修复或参与终局重定。飞升离开山海界者称**天仙**。地仙与天仙没有高下之别，只是归属不同：一个仍在山海，一个已去他界。

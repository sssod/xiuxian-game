# 文案设计｜剧情设定｜预设真灵支线

适用范围：`docs/xiuxian_design_docs/01_文案设计/02_剧情设定` 中的预设真灵定义、自由边界、支线结构和支流汇入主线原则。

## 当前定位

本文负责整理预设真灵支线。真灵名提供剧情入口、旧史疑案、道韵奖励和支线视角，但不锁定玩家阵营、功法、结局或固定前世身份。

## 内容边界

本文维护真灵支线的叙事结构和禁区。真灵系统字段、初始化流程、执念预算和后手索引由系统设计文档维护；本文不替代真灵系统规则。

## 预设真灵支线：小支流如何汇入主线

### 真灵定义与自由边界

真灵不是大道本身，也不是神明本体，而是开天辟地时散落、沉积、折损或滞留的先天之气、先天质性、神魂余痕与少量高阶时空残迹。它们因不完全属于后天魂魄体系，所以不会被普通轮回彻底磨灭；但它们也不完整、不绝对、不全知，不天然拥有大道权柄。

每一世的角色只是这些残余气机在后天世界中的一次承载。真灵可以通过轮回账本、真名线索、山海图和后手感应延续，但不能直接继承前世修为、关系、身份和财富。

真灵根脚提供的是：

- 气机相性。
- 真灵名生成方向。
- 功法路线倾向。
- 事件入口。
- 山海旧史感应。
- 真名与前世线索的特殊反馈。
- 真灵故事与山海图收藏入口。

真灵根脚不提供的是：

- 固定阵营。
- 固定前世立场。
- 当前世必须完成的宿命。
- 不可违背的使命。
- 自动获得的高阶身份、宗门职位、家族关系或神明权柄。
- 强制主修功法路线。
- 强制终局功法或结局机制。

玩家在当前世面对前世线索时，可以选择继承、质疑、改写或利用，而不是被前世记录锁死。

| 态度 | 含义 | 玩法表现 |
|---|---|---|
| 继承 | 接受前世线索，愿意承接未竟之事 | 解锁旧传承、旧友 / 旧敌线索、前世后手入口 |
| 质疑 | 不相信山海图、宗门档案或归墟传闻 | 解锁调查、反证、隐藏层探索、档案比对 |
| 改写 | 承认过去存在，但这一世要改变结果 | 解锁新路线、改写事件结果、改变宗门评价 |
| 利用 | 不在乎真相，只利用前世名号和后手 | 更快获得资源或谈判筹码，但真名暴露与反噬风险更高 |

### MVP 第一批预设真灵名基础表

MVP 第一批预设真灵名固定为 **11 个**。这 11 个是真灵专属剧情线的第一批入口，不是完整真灵根脚总池，也不是系统上限。

| 序号 | 类型 | 真灵名 | 主气机 / 路线标签 | 设计定位 |
|---:|---|---|---|---|
| 1 | 木行 | **建青** | 木、建木遗脉、灵植、生发 | 代表建木支脉、灵植修复、生命延展。适合承接“守木”“藏名”“断木遗址共鸣”等线索。 |
| 2 | 火行 | **烛明** | 火、日轮、阳性、炎灾 | 代表扶桑日出、山海炎火、光照与灾火。可接“照见旧史”“焚尽伪档”“火脉异动”等事件。 |
| 3 | 土行 | **息壤** | 土、神山、大荒、承载 | 代表大荒地脉、神山根基、洞府承载。适合“化山”“铸根”“地脉镇封”线索。 |
| 4 | 金行 | **素锋** | 金、神材、矿脉、锋刃 | 代表矿脉、神材、杀伐与裁断。可接“断木兵痕”“神材失窃”“金脉旧誓”等线索。 |
| 5 | 水行 | **归潮** | 水、四海、归墟潮汐、流转 | 代表四海、弱水、归墟潮汐边界。适合“引潮污名”“海眼残图”“归墟预警”等线索。 |
| 6 | 体修 | **山骨** | 形质、骨、石、肉身承载 | 代表神山巨骸、异兽骨脉、肉身承载。偏体魄、防御、承压、化山。 |
| 7 | 魂修 | **梦魂** | 神魂、梦、轮回、前世残响 | 代表梦境、轮回账本、真名残影。偏魂修、梦境事件、死亡边界、藏名线。 |
| 8 | 剑修 | **玉刃** | 锋刃、玉质、杀伐、护道 | 代表神材成刃、玉质剑胎、裁断旧誓。偏剑修，但不强制金灵根。 |
| 9 | 丹修 | **丹阳** | 丹火、生机、扶桑朝元、炼化 | 代表丹火、生机转化、日轮药性。偏丹修、疗伤、灵植、炼化。 |
| 10 | 器修 | **铸魄** | 形质、器魂、神材、法宝 | 代表器物有魄、法宝承灵、神材铸界。偏器修、法宝、藏宝、铸根线。 |
| 11 | 符修 | **玄箓** | 符箓、真名、神识、档案刻写 | 代表符箓、真名保护、山海图刻录与档案改写。偏符修、真名隐藏、残图解读。 |

MVP 选择界面建议显示“真灵名 + 简短山海残句 + 初始相性提示”，避免按“职业选择”或“五行职业”展示。

### 真灵支线汇总表

| 真灵 | 支线关键词 | 支线主问题 | 汇入主线方式 |
|---|---|---|---|
| 建青 | 守木、灵植、生发 | 前世是否守护过建木支脉？守木是救世还是纵容灾路？ | 提供接木 / 另开的建木活性锚点，也可用于续断时保留少量安全支脉 |
| 烛明 | 照见旧史、焚伪档 | 宗门档案与迎墟传闻中哪些记录被伪造？ | 揭露迎墟者污名与太极档案删改，提升断木旧史真相完整度 |
| 息壤 | 化山、地脉、承载 | 某座神山是否由断木余脉与前世牺牲化成？ | 提供镇界地基，可用于续断、接木、藏世、另开 |
| 素锋 | 断木兵痕、裁断 | 断木是否曾由神材兵刃执行？玩家前世是护道者还是执行者？ | 提供裁断仪式，可斩断归墟倒灌、混沌裂界或太初归根阵 |
| 归潮 | 引潮污名、海眼残图 | 前世是否真的引归墟潮入世，还是被迎墟者污名？ | 区分自然归墟潮与人为提前潮，提供镇潮 / 入墟关键判断 |
| 山骨 | 化山、承压、神山巨骸 | 前世是否以身承压，把断木余脉化为神山？ | 提供世界承压值，影响大规模灾害下宗门和地图节点存活 |
| 梦魂 | 藏名、轮回账本 | 哪些记忆是真实前世，哪些是山海图误读或太易隐匿？ | 提供真名保护、隐匿、藏世线索，降低真名狩猎风险 |
| 玉刃 | 旧誓、护道、裁断 | 前世曾斩谁的誓？斩断的是灾路还是生路？ | 提供终局裁断权，可中断某一方极端方案 |
| 丹阳 | 丹火、生机、炼化 | 能否把归墟污染炼化为生机，而非只封或吞？ | 提供净化资源，降低接木 / 另开 / 续断失败率 |
| 铸魄 | 铸根、器魂、法宝 | 前世是否以神材铸根镇压建木？铸物是否困住众生？ | 提供人工天路、法宝阵基、另开线核心材料 |
| 玄箓 | 真名、符箓、档案刻写 | 山海图、宗门档案、真名记录能否被保护或改写？ | 提供真名防护、档案修订、山海图真灵故事补全能力 |
| 自定义真灵 | 承道、自由发展 | 没有既定前世身份，如何参与旧史？ | 可选择任一真灵故事承道，获得一次对应道韵奖励，并以当世行为汇入主线 |

### 支线结构模板

| 支线阶段 | 内容 | 作用 |
|---|---|---|
| 入口 | 山海图残文 / 轮回账本 / 异兽识名 / 藏宝感应 | 给出专属风味 |
| 疑案 | 发现前世记录互相矛盾 | 不让玩家直接继承宿命 |
| 选择 | 继承、质疑、改写、利用 | 记录当前世态度 |
| 证物 | 获得一个主线可用资源或信息 | 汇入四方势力冲突 |
| 收束 | 写入山海图真灵故事，给一次道韵或承道机会 | 形成收藏与数值回报 |

山海图奖励结构支持这一点：预设真灵收集自身全部真灵故事后获得一次对应道韵点数；自定义真灵收集任意真灵故事并选择“承道”后获得一次对应道韵点数；该奖励只能获得一次。

### 真灵支线不应做的事

1. 不让建青必然走接木结局。
2. 不让归潮必然走入墟结局。
3. 不让玄箓必然走藏世结局。
4. 不让玉刃必然敌对混沌。
5. 不让梦魂必然相信前世。
6. 不让自定义真灵变成弱化体验。
7. 不让山海图成为主线大事件入口。

# 功法设计｜道功

## 1. 定义

道功是推动修为的核心功法类型，可设为主修。道功决定角色一世内修行路线根基。

## 2. 当前定版规则

- 道功可以推动修为进度。
- 道功可设为主修。
- 同一时间只能有一个主修道功。
- 主修道功只在大境界第一小阶段常规无成本更换。
- 道功掌握度影响当前可修上限和单位时间收益效率。
- 道功掌握度不影响理论最高上限、纯度、小境界奖励质量、大境界突破模板或不可追回收益。
- MVP 不做废功重修、改修折算、功法上限后的免费续接换主修。

## 3. 学习与研习

完整道功载体是学习来源。常规获得完整载体后，需要研习入门；新手基础功法可通过事件直接授予 learned level 1。

研习功法行动读取：

```text
投入小时、悟性、功法阶级与品级、导师、设施 / 事件加成、神念、前置知识
```

产出：MethodState 经验、等级、入门状态、当前可修上限、收益效率、法门选项等。

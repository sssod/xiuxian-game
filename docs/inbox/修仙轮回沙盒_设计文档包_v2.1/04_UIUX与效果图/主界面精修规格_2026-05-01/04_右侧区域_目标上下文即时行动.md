## 1. 区域职责

右侧区域用于承接玩家在地图上的当前判断：

- 当前位置 / 正在查看 / 计划目标三态。
- 本回合紧凑目标模板。
- 当前选中对象摘要。
- 路线与可达性预估。
- 当前对象的对象级操作。
- 当前位置模式下的即时行动状态变体。

它不是完整宗门面板、完整节点详情页或完整行动规划器。

右侧不得承载阶段推进按钮；`进入个人行动规划 / 锁定提交` 等阶段级操作只出现在底部 `PhaseCTA_Group`。

## 3. 三态上下文头部

节点：

```text
ContextHeader_TripleState
```

显示：

```text
当前位置：云麓宗山门
正在查看：黑石岭矿脉
计划目标：无 / 黑石岭矿脉
```

规则：

- `当前位置` 来自当前角色所在地。
- `正在查看` 来自地图当前选中节点。
- `计划目标` 来自本回合行动草稿。
- 三者必须能被玩家在 1 秒内区分。

## 4. 紧凑目标模板

节点：

```text
GoalTemplateCompact
```

默认推荐：

```text
延续上一回合
探索资源
处理风险
更多
```

主界面内 `GoalTemplateNote` 留空。

以下说明移至主 Frame 外注释区：

```text
模板只整理意图，不直接提交服务器行动。
```

规则：

- 目标模板只是帮助玩家整理意图。
- 默认只展示 3 个推荐 chip 和 `更多`。
- 它不直接生成服务器行动。
- 进入个人行动规划后，目标模板可作为行动指令草稿的输入之一。

## 5. 选中对象摘要

节点：

```text
SelectedObjectSummary
```

当前示例：

```text
正在查看：黑石岭矿脉
```

标签：

```text
已探索
资源紧张
边境争夺
风险中
```

信息行：

```text
控制权：云麓宗影响 56%，赤砂门 31%
危险：中，妖兽踪迹与边境冲突升温
灵气：中等，矿脉异动导致波动
资源：玄铁矿脉、碎灵石、未知伴生矿
当前不可直接执行即时行动。
最近变化：宗门驻守推进至 47%，外宗活动增加。
抵达后可能处理事项：探索矿脉 / 协助驻守 / 调查异动
```

规则：

- 非当前位置节点不显示可立即执行的即时行动按钮。
- 对非当前位置节点，只能显示对象级操作和“抵达后可能处理事项”。
- 完整详情进入节点详情页，不在右侧展开成长文本。

## 6. 路线与可达性

节点：

```text
RouteAndReachabilityCard
```

显示：

```text
预计耗时：约 1.5 天
风险标签：妖兽传闻 / 边境冲突
权限门：无硬阻断
状态门：抵达后再选择持续行动
```

规则：

- 路线预估是客户端预览，不等于服务器最终结算。
- hover 或点击路线时，地图路线浮层和底部预算条可联动展示预览。
- 不在右侧显示小时级排程。

## 7. 对象级操作

节点：

```text
ContextActions_ByState
```

选中节点模式显示：

```text
设为关注目标
预估路线
加入行动计划
查看详情
```

主界面内 `ActionsSubtitle` 与 `NoInstantActionHint` 留空。

以下说明移至主 Frame 外注释区：

```text
右侧只处理当前对象；阶段推进在底部。
非当前位置节点不显示领取、交付、立即探索等即时行动。
```

规则：

- `加入行动计划` 只生成本回合行动草稿，不等于锁定提交。
- 右侧按钮只作用于当前对象，不改变阶段。
- 非当前位置节点不显示领取、交付、立即探索、立即采集等即时行动。
- 若选中节点已经进入行动草稿，右侧切换为计划目标模式，显示修改目标、替换目标、清除草稿、选择抵达后持续行动等操作。

## 8. 当前位置即时行动状态变体

节点：

```text
InstantAction_List_ScrollViewport_CurrentLocationVariant
```

该变体默认隐藏，仅在右侧处于当前位置模式时显示。

当前位置模式触发条件：

```text
当前查看节点 = 当前角色所在地
```

显示：

```text
领取外门俸禄
查看宗门回信
接收委托成品
更多即时事务
```

列表规则：

- 默认只显示 3 个高优先级即时行动。
- 超过 3 个时显示 `更多即时事务`。
- 滚动容器必须开启裁切，按钮不得覆盖底部提示。
- 即时行动不占用回合时间预算。
- 进入个人行动规划后，即时行动区切换为空白冻结提示位，说明文案不进入主界面。

冻结提示：

主界面内留空。

以下说明移至主 Frame 外注释区：

```text
进入个人行动规划后，个人即时行动将冻结。
如需处理即时事务，请返回信息处理阶段并清除行动草稿。
```

## 9. 上下文模式

| 模式 | 触发条件 | 右侧重点 | 不显示 |
|---|---|---|---|
| 当前位置模式 | 当前查看节点 = 当前所在地 | 当前位置即时事务、当前位置持续行动入口 | 非当前位置路线行动 |
| 选中节点模式 | 点击非当前位置节点，尚未加入草稿 | 节点摘要、路线预估、加入行动计划 | 领取、交付、立即采集等即时行动 |
| 计划目标模式 | 选中节点已进入本回合行动草稿 | 计划目标、抵达后行动、投入时间 | 可用即时行动按钮 |
| 已锁定只读 | 玩家已锁定提交 | 已锁定预案摘要、路线只读 | 修改草稿、即时行动 |

## 10. 与地图顶部位置浮窗的关系

地图顶部位置浮窗回答全局位置问题：

```text
当前位置 / 正在查看 / 计划目标
```

右侧统一上下文面板回答当前对象的详情和对象级操作：

```text
该目标是什么 / 为什么重要 / 能做什么 / 是否能加入行动计划
```

规则：

- 两者不可互相替代。
- 地图浮窗保持更高的全局定位优先级。
- 右侧只承接当前上下文，不承担全局日志、完整节点详情或阶段推进。

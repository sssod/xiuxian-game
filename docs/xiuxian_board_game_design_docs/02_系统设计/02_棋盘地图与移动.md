# 系统设计｜棋盘地图与移动

适用范围：六边格地图、路径、距离与速度、共享移动时间轴、相遇和移动中断。

## 1. 地图结构

1. 战略地图以六边格空间关系为基础。
2. 地图可以缺格、断开、稀疏分布或使用特殊连接。
3. 地图不是只有一条连续主路径，允许多路线与绕行。
4. 玩家棋子拥有明确位置，并按普通可见性规则被发现。

## 2. 距离、速度与资源

移动方式使用两个独立维度：

```text
骰池结果 → 本回合最大移动距离
速度系数 → 每经过一格占用的移动时间
```

移动距离更远不自动等于速度更快。所有地图移动都消耗元气；元气为 `0` 时不能移动，但仍可在当前位置执行合法主要行动。

骰池、速度系数、每格元气成本、地形权限和其它移动资源仍待主题数值配置。

## 3. 共享移动时间轴

1. 所有玩家的路径在同一时间轴同步演算。
2. 时间轴在最后一名玩家终止移动时结束。
3. 玩家从进入某格到离开该格的完整区间都视为占据该格。
4. 提前抵达目的地的玩家持续占位到共享时间轴结束。
5. 两名玩家占用同一格的时间区间重叠，即发生相遇。
6. 普通相遇不产生事件；任一方已设置仇恨时，相遇升级为强制事件并中断双方移动。
7. 移动事件只中断相关玩家，无关玩家继续演算。
8. 事件选择延后到行动阶段处理。

## 4. 未抵达与途中内容

骰点不足时，玩家停在实际落点，原定主要行动不执行，并进入该地点的途中事件内容。移动中断事件完全替代原定主要行动；事件结束后不能恢复本轮移动或行动。

## 5. 逃遁移动接口

主动逃遁成功或重伤战败后，角色默认可在相邻 `1` 格内选择合法地点免费移动：

- 目标必须被至少一种已有移动方式允许进入；
- 不能穿越硬阻挡或敌对封锁；
- 不消耗元气、耐久或其它移动资源；
- 不触发新地点事件；
- 没有合法地点时留在原地，但不撤销逃遁结果。

## 6. MVP 缺口

首张地图仍缺：拓扑、地点、特殊连接、出生范围、地形权限、骰池、速度、元气成本、资源点和飞升地点。上述内容应与主题事件包一起裁决。

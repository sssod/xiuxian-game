## 1. 区域职责

左侧区域负责呈现本回合决策前必须看的信息。

它不是完整日志页，也不是所有消息的收件箱。默认只展示影响本回合判断的变动、传闻和宗门进展。即时行动的可执行入口归入右侧当前位置模式或全局事务抽屉。

## 3. 筛选标签

当前筛选项：

```text
必看
目标相关
传闻
宗门
```

规则：

- `必看` 默认选中，包含 P0 / P1 与必须确认的信息。
- 筛选只影响左侧列表，不改变地图节点显隐。
- `P0` 表示必须处理或必须确认的危急信息。
- `P1` 表示强烈建议阅读的信息。

### 4.6 卡片内控件尺寸与间距

左侧卡片内的标签与按钮必须保持明确的层级差异：

- 标签 chip 高度统一为 `24px`，宽度按内容适配。
- 卡片内按钮与底部轻操作按钮统一为 `112 x 30`。
- 标签行与按钮行不得共用同一垂直热区，二者之间至少保留 `8px` 垂直间距，推荐 `10px`。
- P0 安全态标签不得压住正文，安全态卡片采用“标题 → 标签 → 正文”的纵向顺序。

## 5. 底部轻操作区

底部轻操作区只保留信息级操作：

```text
全部归档
只看必看
```

主界面内提示文案留空。

以下说明移至主 Frame 外注释区：

```text
阶段推进已收束至底部右侧。
```

规则：

- `全部归档` 只影响当前提示状态，不应删除日志。
- `只看必看` 只改变左侧筛选，不改变地图节点显隐。
- 左侧不得提供 `进入个人行动规划` 或 `锁定提交`。
- 阶段级按钮统一放在底部 `PhaseCTA_Group`。

## 6. 折叠态 rail

左侧支持折叠为 `LeftRail_Collapsed`。

折叠态建议尺寸：

```text
80 x 842
```

折叠态只显示：

```text
P0 数量
P1 数量
目标相关数量
传闻数量
宗门变化数量
```

点击 rail 可重新展开左侧面板。

## 7. 交互约束

- 左侧区域可以折叠，但信息处理阶段默认展开。
- 卡片列表可滚动。
- 滚动条应轻量显示，不占用卡片内容宽度。
- 卡片按钮只能触发查看、定位、关注、归档、打开面板等信息处理行为，不直接结算行动。
- 进入个人行动规划后，左侧默认折叠为风险 rail。

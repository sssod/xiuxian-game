# 项目总览与阅读顺序修订（v0.1）

> 替换范围：v2.2 `README.md`、`01_项目总览_MVP边界_系统依赖_v2.2.md` 中涉及“回合制房间、默认 5 日回合、行动时间预算条、统一结算”的顶层描述。

---

## 1. 新版一句话定位

本项目是一款支持本地单人测试、私人服务器部署、3 人共玩的**连续日历制多人修仙轮回沙盒**。

玩家控制跨世延续的真灵，当世角色在共享世界日历中修炼、移动、经营关系、争夺资源、突破、战斗、死亡转世与布置后手。世界时间不再以固定 5 日回合为玩家最小推进单位，而是根据全员状态在 F1 / N1 / B1 / P0 之间自适应切换。

推荐开发定位修订为：

```text
共享日历房间
+ 自适应流速推进
+ 跨世角色成长
+ 当前指令 + 短预输入队列
+ 宗门 AI 资源平台
+ 节点地图沙盒
+ 功法掌握与行动资源输入
+ 事件 / 交锋 / 突破权威结算
```

## 2. 核心时间结构

旧 v2.2：

```text
回合制房间
+ 默认每回合 5 游戏日
+ 玩家规划时间预算
+ 全员锁定 / 超时后统一结算
```

新规则：

```text
低交互成长 → F1 高速推进，2 秒 = 1 游戏日
普通多人运行 → N1 常态推进，15 秒 = 1 游戏小时
个人非交锋事件 → 本人局部时停 + 外部 N1，gap ≤ 1 游戏日
正式交锋 / 突破挑战 → B1 交锋慢速，60 秒 = 1 游戏小时
全局公共事件 / 同步保护 → P0 全局暂停
```

底层仍统一：

```text
1 游戏日 = 24 游戏小时
服务器最小结算单位 = 1 游戏小时
```

## 3. MVP 边界修订

MVP 保留：

```text
本地可单人测试
+ 可部署私人服务器
+ 支持 3 人共玩
+ 可保存、暂停、恢复、续开
+ M0 → M3 纵向闭环可跑通
```

新增必须验证：

1. F1 / N1 / B1 / P0 速度切换。
2. 普通指令编辑不触发局部时停。
3. 当前指令 + 最多 3 条预输入队列。
4. 自动兜底：低风险吐纳，中高风险休整，并强制 N1。
5. 显式托管与自动兜底分离。
6. 个人非交锋事件局部时停、gap 上限、C1 追赶补结算。
7. 正式交锋与突破挑战 B1 交锋轮。
8. 个人突破不触发 P0。
9. 不提供“推进至下一事件 / 跳到未来关键节点 / 月末跳转”等玩家侧功能。

## 5. 顶层术语替换

| v2.2 术语 | 修订后术语 | 说明 |
|---|---|---|
| 回合制房间 | 共享日历房间 | 房间仍存在，但普通推进不以固定回合作为玩家操作循环。 |
| 回合时间预算条 | 行动队列 / 当前行动面板 | UI 不再要求填满 5 日预算。 |
| 回合阶段机 | 世界速度状态机 | F1/N1/B1/P0 决定时间推进。 |
| 结算阶段 | 服务器小时 tick / 事件结算 | 游戏时间在世界运行中持续推进。 |
| 全员锁定 | 全局事件确认 / P0 提交 | 只用于公共决策或同步保护，不用于普通行动。 |
| 托管生成行动 | 显式托管 / 超时安全默认 / 自动兜底 | 三者必须区分。 |
| 大境界突破固定行动 | 开启突破短指令 + B1 突破挑战 | 不再是普通固定工期行动。 |

## 6. 与 v2.2 仍兼容的总览内容

以下内容保持不变：

1. 玩家本体是真灵，当世角色可死亡与转世。
2. 宗门不是玩家直接操控对象，而是资源平台与 AI 演化实体。
3. 大地图仍是主界面核心。
4. 功法、丹药、灵材、符箓与资源输入机制继续按 v2.2 新口径执行。
5. 资产容器、日志、结果包、权威服务器和存档回放继续作为开发底座。
6. MVP 仍以 M0 → M3 纵向闭环验证核心体验。

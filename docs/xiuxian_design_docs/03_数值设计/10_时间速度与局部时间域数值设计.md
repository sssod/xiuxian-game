# 数值设计｜时间速度与局部时间域数值设计

## 1. 设计定位

本文负责维护现实游玩时间、外界世界日历、F1 批量推进、局部时间域主观时间、洞天资源年和轮回总时长的数值口径。

本文不替代境界 CP 表、每小时修炼公式、事件文本、洞天类型世界观或页面布局。境界段、修炼收益、事件触发、洞天系统规则和页面表达分别由对应包内文档承接。

## 2. 当前结论

1. 修为时间建模终点为“大乘圆满并突破进入渡劫期”。渡劫之后的劫数、因果、飞升和终局结算不纳入本文时间段。
2. 理论直线现实参考时长默认 32 小时，用于标定门槛满足时的境界推进体验，不等于实际单局总时长；调试上限暂按 50 小时保留。
3. 理论直线外界世界日历目标为约 45-48 年，验收范围为 20-50 年；当前基线约 47.55 年并已接受，不改为 30-40 年保守口径；外界年极限可作为调试参数，调试上限暂按 100 年保留。
4. 局部时间域主观经历目标约 596 年，主要由洞天、时间阵法、秘境时间窗口和宗门时间阵承载。
5. 玩家可见速度状态只保留 N1 / F1 / B1 / P0，不新增独立宏观流年阶段。
6. F1 表示房间处于长期低交互可批量结算状态；在线 F1 固定以 1 外界日作为批次提交上限，内部使用聚合结算、通用事件流采样、日内结算分段、F1 校验断点和 F1 中断断点，不逐小时全量展开，也不按境界、人数或事件密度拉长玩家可见批次。
7. 洞天 / 时间阵法提供局部时间域、场地和部分环境，不等于免费修炼收益。有效修炼年必须受资源包、功法、寿元、心魔、经脉和承载状态限制。
8. 阶段预算、市场、宗门库存、节点资源、NPC 宏观成长和大型投放窗口按外界时间刷新，不按洞天内主观时间刷新。
9. 轮回重修提高路线确定性、稳定性、成功率和结局质量，但不保证完整通关总时长短于单世通关。

## 4. 基准、单位与输入参数

### 4.1 四层时间模型

| 时间层 | 字段建议 | 含义 | 主要读取系统 |
| --- | --- | --- | --- |
| 现实游玩时间 | `real_elapsed_seconds` / `real_elapsed_hours` | 玩家现实中花费的时间 | 体验时长、UI 预估、节奏验收 |
| N1 / B1 现场外界时间 | `live_outer_world_hours` | 玩家处理地图、事件、战斗、突破、交易时同步流逝的外界时间 | 现场事件、短行动、交互节奏、正式交锋 |
| F1 外界流年时间 | `f1_outer_world_days` / `f1_outer_years` | 房间长期低交互时高速推进的共享外界世界日历 | 洞天开放、宗门日程、市场刷新、节点再生、NPC 宏观成长、阶段预算 |
| 角色主观经历时间 / 修行时间 | `subjective_elapsed_years` / `subjective_cultivation_years` / `inner_time_years` | 角色在洞天、时间阵法、闭关局部时间中实际经历的时间，其中一部分才属于修行成长时间 | 寿元消耗、修行成长、功法研习、道功修炼、药性释放、心魔、经脉压力、突破准备 |

基础原则：

1. 现实时间决定玩家体验，不能让玩家在现实中长时间等待。
2. N1 / B1 决定交互时的即时反馈，玩家面对事件、战斗和关键选择时可以慢下来。
3. F1 决定外界流年感，让年份、宗门、市场、洞天窗口和世界预算在低交互阶段快速推进。
4. 主观时间决定修仙质感与寿元压力，角色在局部时间域内真实经历数百年。
5. 寿元按角色所在时间域扣除；角色在洞天 / 时间阵法 / 局部时间域内时按主观时间扣寿，角色在洞天外时按共享外界世界日历扣寿。
6. 世界预算读取外界时间，不读取洞天内主观时间。

### 4.2 速度状态标准方案

| 状态 | 用途 | 现实时间 : 游戏时间 | 规则含义 |
| --- | --- | --- | --- |
| N1 | 常规推进 | 15 秒 = 1 外界小时 | 玩家正在操作、响应事件、移动、交易、队列编辑或处理低频选择 |
| F1 | 长期低交互高速推进 | 默认 1.5 秒 = 1 外界日；保留 1 / 1.5 / 2 秒调参档 | 所有玩家处于可自动结算状态时启用；内部批量结算，不逐小时全量展开 |
| B1 | 交锋慢速 | 60 秒 = 1 外界小时 | 正式战斗、突破挑战、秘境关键交锋、玩家直接交锋 |
| P0 | 全局暂停 | 时间不流动 | 公共决策、同步保护、主机暂停、无安全默认的关键阻塞 |

速度优先级：

```text
P0 > B1 > N1 > F1
```

不新增独立宏观流年阶段。此前宏观流年方案的复杂性收进 F1 内部批量结算内核，玩家侧仍只看见 F1。

### 4.3 32 小时理论直线默认基线

理论直线参考终点：

```text
大乘圆满 -> 突破进入渡劫期
```

32 小时只分配到玩家可见速度状态 N1 / F1 / B1，不再单列“局部闭关表现”现实时间桶。洞天闭关、时间阵法、长行动和托管都属于 F1 内部可批量结算内容。

| 模式 | 现实占比 | 现实小时 | 换算口径 | 外界年贡献 | 设计作用 |
| --- | ---: | ---: | --- | ---: | --- |
| N1 现场交互 | 66% | 21.12h | 36h = 1 外界年 | 0.59 年 | 地图、事件、宗门、交易、队列、短行动、普通选择 |
| F1 长期低交互 / 外界流年 | 22% | 7.04h | 1.5 秒 = 1 外界日，即 1h 约 6.67 外界年 | 46.93 年 | 洞天闭关、时间阵法、长行动、托管、宗门职责、外界流年 |
| B1 关键慢速轮 | 12% | 3.84h | 144h = 1 外界年 | 0.03 年 | 突破、战斗、关键交锋 |
| 合计 | 100% | 32.00h | - | 约 47.55 年 | 当前基线已接受，接近 50 年上限，保留事件和路线浮动空间 |

本基线不应硬编码为唯一可运行值。调参和 Debug 至少保留以下参数：

| 参数 | 默认值 | 调试边界 | 用途 |
| --- | ---: | ---: | --- |
| `real_time_baseline_hours` | 32 小时 | 最高 50 小时 | 重排 N1 / F1 / B1 现实时间占比、境界段现实目标和验收节奏 |
| `f1_seconds_per_outer_day` | 1.5 秒 | 1 / 1.5 / 2 秒调参档 | 调整长期低交互等待体感，并重算 F1 外界年贡献 |
| `outer_year_acceptance_limit` | 50 外界年 | 最高 100 外界年 | 检查外界日历跨度、世界窗口数量和宏观资源刷新是否越界 |

正式平衡仍以默认 32 小时、F1 默认 1.5 秒 / 外界日和当前约 47.55 外界年为主口径。调试值用于验算弹性、压力测试和阶段目标重排，不表示普通玩家目标必然延长到 50 小时或 100 年。

## 5. 公式或模型

### 5.1 F1 进入条件

F1 的基础判定：

```text
can_enter_F1(room):
  if room.has_active_global_pause: return false
  if room.has_active_formal_encounter: return false
  if room.has_unresolved_hard_interaction: return false
  if any(player.has_required_input_without_default): return false
  if any(player.current_state not in f1_eligible_states): return false
  return true
```

`f1_eligible_states` 包括：

```text
洞天 / 时间阵法闭关；
普通长期闭关；
长期修炼；
长距离移动且使用安全路线；
显式托管；
宗门低风险职责；
休整 / 疗伤；
资源采集 / 加工等低交互长行动；
离线托管且存在合法安全策略。
```

不满足 F1 的典型情况：

```text
玩家正在处理事件选择；
玩家正在编辑关键队列；
玩家进入 B1 突破或战斗；
公共决策需要 P0；
玩家行动队列为空且没有托管；
事件没有安全默认；
洞天闭关缺少资源绑定、结束条件或中断策略；
玩家间冲突即将触发且需要人工确认。
```

### 5.2 F1 批量推进、断点与退出

安全断点不等于任何状态变化时间点。本文中 F1 断点只表示：

```text
继续按 F1 聚合推进前，必须先提交结果并重新校验房间状态的时间点。
```

F1 批量推进的目标时间：

```text
F1_target_time = min(
  next_required_validation_breakpoint,
  next_required_interrupt_breakpoint,
  next_outer_day_commit_boundary
)
```

F1 内部时间点分为三层：

| 类型 | 是否提交批次 | 是否退出 F1 | 用途 |
| --- | --- | --- | --- |
| 日内结算分段 | 否 | 否 | 只用于计算分段收益、资源消耗、效果过期、倍率变化和摘要聚合 |
| F1 校验断点 | 是 | 不一定 | 提交结果、执行预设、重检是否仍满足 F1；满足则继续 |
| F1 中断断点 | 是 | 是 | 退出到 N1 / B1 / P0，等待玩家、交锋或公共决策处理 |

在线 F1 的批次提交口径固定为：

| 场景 | 批次提交上限 | 说明 |
| --- | --- | --- |
| 在线 F1 | 1 外界日 / 批 | 对应默认 1.5 秒现实时间；批次内不展开 24 个全量 `hour_tick`，只计算当日聚合收益、日内结算分段、预定事件和通用事件流采样 |
| F1 校验 / 中断断点 | 小于 1 外界日 | 若必须提交并重检或退出的断点发生在当日内，则推进到该日内断点 |
| 后台追赶 / Debug / 性能保护 | 可使用更长技术批次 | 不作为在线 F1 节奏参数；必须按同样的 F1 校验断点和 F1 中断断点切分，并保持结果包、摘要和回放可复盘 |

达到在线 F1 的外界日提交边界时，系统提交本日聚合结果、摘要和回放引用，然后重新检查是否仍满足 F1 条件。日边界本身不要求退出 F1，也不改变玩家看到的 F1 速度。

F1 校验断点包括：

```text
当前行动完成；
局部时间域结束；
资源耗尽且会影响当前行动合法性或触发停止 / 切换预设；
风险阈值触发玩家预设策略，例如停止闭关、切换低风险行为或提醒；
已订阅、已排队或已设置预案的洞天 / 秘境 / 宗门窗口开启；
外界日提交边界。
```

F1 遇到以下情况退出：

```text
任一玩家需要人工响应且无安全默认；
B1 战斗 / 突破 / 玩家冲突触发；
P0 公共决策触发；
洞天控制权、入口、席位、宗门重大事件需要确认且无安全默认；
处理等级为 `hard_interrupt` 的事件；
处理等级为 `soft_interrupt` 的事件没有预设或安全默认；
心魔 / 经脉 / 药性 / 寿元风险超过硬阈值，进入死亡边缘、严重心魔、不可逆道伤或关键资源损毁；
行动完成后无合法后续行动，且不是显式托管；
玩家主动打开关键编辑界面；
批次提交后的摘要策略明确要求暂停确认。
```

F1 不因以下情况退出：

```text
F1 处理等级为 `summary` 的普通事件；
F1 处理等级为 `auto` 的低风险事件；
只影响数值的小额波动；
玩家打开只读报告或地图查看；
非相关 NPC 的后台成长；
不需要玩家响应的市场与资源变化。
```

以下情形不作为 F1 校验或中断断点，只作为日内结算分段或摘要处理：

```text
普通资源收益、消耗和衰减；
丹药、药性、阵法效果在日内改变倍率；
小额状态波动；
F1 处理等级为 `silent / summary / auto` 的事件；
市场、宗门库存、节点资源的常规刷新；
非相关 NPC 后台成长；
未被玩家订阅、未排队、未要求响应的窗口开启或关闭；
低价值传闻、价格变化、普通资源波动；
阶段预算激活，除非该预算激活同时产生已订阅窗口、公共决策或无默认的重大事件。
```

### 5.3 F1 处理等级

闭关承诺不表示“闭关期间没有事件”。事件仍会触发，只是不需要逐小时全量检查。

F1、N1、后台追赶和局部时间域应复用同一套事件候选池、进入 / 移出条件、权重、伪随机状态和压制逻辑。F1 只是以 1 外界日作为在线结算区间；事件是否写摘要、自动处理、形成 F1 校验断点或形成 F1 中断断点，由 F1 处理等级和默认策略决定。F1 处理等级不同于事件层级：事件层级与修为境界阶段和地图节点等级匹配，F1 处理等级只决定批量结算时是否打断或摘要。

若同一 F1 日内或同一结算时间桶内多个事件因预定、阈值、危险率、权重随机或双层保底机制同时产生触发提案，仍按事件候选池的提案裁决规则处理。随机事件候选池采用二段抽样：第一段由候选池 / 语义桶级无事件权重判断本池是否出事件，第二段在本池事件内按 `event_select_weight = effective_weight + event_pity_bonus_weight` 抽选具体事件。触发来源只作为回放、审计和调试字段；竞态先按事件层级裁决，高层级事件优先，同层级事件按当前 `event_select_weight` 加权再随机。通用限量首版只保留个人单事件限量和全世界 P0 限量；未选中的普通随机提案默认按策略保留或衰减伪随机状态。

| F1 处理等级 | 是否退出 F1 | 处理方式 |
| --- | --- | --- |
| `silent` | 否 | 后台记录或仅影响数值，不打扰玩家 |
| `summary` | 否 | 写入 F1 摘要，例如小额资源变化、低风险传闻 |
| `auto` | 否 | 按玩家预设、托管策略或安全默认处理，并写入摘要 |
| `soft_interrupt` | 视情况 | 有预设或安全默认则自动处理并形成 F1 校验断点；无预设且无安全默认则退出 F1 到 N1 |
| `hard_interrupt` | 是 | 立即退出 F1，进入 N1 / B1 / P0 |

普通预设不得自动处理：

```text
高风险突破；
主动转世；
叛宗；
强 PvP；
消耗稀有不可逆资源；
重大路线选择；
暴露核心后手；
开启高危藏宝；
决定他人利益的公共选择。
```

### 5.4 分域时间分配

不能用“生涯总时间 x 固定比例 = 修行成长时间”的单一比例切分。首版按时间域分配：

```text
局部时间域主观时间：主要分配给修行成长与局部闭关支持行为；
洞天外 F1 外界流年：主要分配给资源、生产、等待、长期游历和少量早期 / 普通修炼；
N1 / B1 现实交互时间：主要分配给短行动、选择、战斗、现场探索和交易。
```

局部时间域默认：

```text
local_domain_growth_ratio = 0.70
local_domain_support_ratio = 0.30
method_study_ratio = 0.20
dao_cultivation_ratio = 0.80
```

以 `local_domain_inner_years = 596 年` 粗算：

| 项 | 年数 |
| --- | ---: |
| 局部时间域总主观时间 | 596 年 |
| 局部修行成长时间 | 约 417 年 |
| 功法研习 | 约 83 年 |
| 道功修炼 | 约 334 年 |
| 局部支持行为 | 约 179 年 |

洞天外 F1 外界流年约 45-48 年，内部建议：

| 类别 | 建议占比 | 作用 | 是否属于修行成长 |
| --- | --- | --- | --- |
| 世界资源积累 / 大型窗口等待 | 35%-45% | 阶段预算积累、洞天开放、秘境、天象、市场周期、宗门库存成熟 | 否 |
| 长耗时生产与准备 | 20%-30% | 炼丹、炼器、材料加工、聚灵石准备、阵法维护、洞天席位申请 | 多数否，少量可作为研习或准备 |
| 长期游历 / 远程行程 / 宗门职责 | 15%-25% | 长线探索、远途路线、驻守、宗门任务、资源点经营 | 通常否 |
| 洞天外普通修炼 / 低阶修炼 | 10%-20% | 前期无洞天时的吐纳、普通静室、低阶灵地修炼 | 是 |

### 5.5 洞天资源年

洞天 / 时间阵法的基础定位：

```text
提供局部时间域；
提供部分环境灵气或空间稳定；
提供闭关、参悟、突破准备的场地；
但不自动提供完整修炼资源链。
```

有效修炼必须同时满足：

```text
有时间：洞天内主观年；
有资源：丹药、聚灵石、灵材、洞天灵气池、宗门护持、阵法燃料；
有功法：当前功法支持本境界推进；
有承载：寿元、体魄、经脉、心神能承受；
有适配：灵根、道功、资源和洞天相性不冲突。
```

资源不足年份：

1. 仍消耗寿元。
2. 修为收益大幅降低，建议只保留 0%-20% 的基础吐纳收益。
3. 心魔、经脉压力、枯坐、状态恶化和事件风险上升。
4. UI 必须提示“资源不足，继续闭关会耗寿低效”。

### 5.6 定期开放与外界日历节奏

按默认约 45-48 年外界日历支持：

```text
季度窗口：约 180-192 次；
半年窗口：约 90-96 次；
年度窗口：约 45-48 次；
三年一次的大型洞天 / 秘境：约 15-16 次；
十年一次的大型天象：约 4-5 次。
```

开放节奏建议：

| 开放类型 | 外界周期 | 适用阶段 | 作用 |
| --- | --- | --- | --- |
| 宗门低阶时间阵 | 30-90 日 | 炼气、筑基 | 教学后期、低阶闭关、宗门贡献消耗 |
| 小洞天 / 宗门秘室 | 半年 | 筑基、金丹、元婴 | 席位争夺、资源准备、阶段修炼 |
| 中型洞天窗口 | 1 年 | 金丹、元婴、化神 | 核心闭关、突破准备、宗门调度 |
| 高阶秘境时间域 | 3 年 | 化神、炼虚、合体 | 高风险机缘、资源争夺、阵营冲突 |
| 大型天象 / 终局窗口 | 10 年 | 大乘、渡劫前 | 终局前准备、因果、劫数、世界事件 |

### 5.7 轮回重修口径

需要废止旧隐含设定：

```text
合理轮回重修一定会让总通关时间短于单世通关。
```

当前口径：

```text
合理轮回的主要收益 = 提高稳定性、成功率、资源利用率、路线确定性和结局质量；
合理轮回可能缩短某一世的境界推进时间；
合理轮回不承诺缩短完整通关总时长；
若世界资源不足，轮回后总时长允许变长，用于等待资源产出、阶段预算积累和大型投放事件生成。
```

## 8. 调参验收口径

1. 默认 32 小时理论直线基线下，外界世界日历应落在 20-50 年，当前基线约 47.55 年；Debug 可验算最高 50 小时现实基线和 100 外界年极限。
2. F1 可见速度默认 1.5 秒 = 1 外界日，并保留 1 / 1.5 / 2 秒调参档；任一档位下内部都不得执行 24 个全量 hour tick。
3. 所有玩家都进入洞天修炼时，房间能稳定进入 F1，并推进到最近局部时间域出口、F1 校验断点、F1 中断断点或外界日提交边界。
4. 闭关期间心魔、资源耗尽、洞天异动等事件能通过事件流触发，而不是被闭关承诺吞掉。
5. F1 处理等级为 `auto` 的事件写入摘要并继续 F1；无预设重大事件必须退出 F1。
6. 资源不足年份导致耗寿低效，而不是继续高效修炼。
7. 洞天修炼仍强需求修为丹药、聚灵阵、聚灵石、洞天灵气池、宗门护持和功法适配。
8. 非相关 NPC 和远端节点不逐小时全量刷新，应使用惰性结算或宏观周期结算。
9. F1 批量结算结果可复盘，包括采样随机种子、事件流、日内结算分段、F1 校验断点、F1 中断断点、外界日提交边界和聚合收益。
10. 轮回重修在资源不足与大型投放事件等待存在时，允许总通关时间长于单世通关，同时提高成功率与结局质量。

## 9. MVP 范围

MVP 应实现：

1. N1 / F1 / B1 / P0 四个公开速度状态。
2. F1 以 1.5 秒 = 1 外界日作为默认基准，并保留 1 / 1.5 / 2 秒配置档。
3. 在线 F1 固定以 1 外界日作为批次提交上限，并推进到最近 F1 校验断点、F1 中断断点或外界日提交边界，而不是逐小时全量展开。
4. 局部时间域、外界日历和现实耗时的分层字段。
5. 洞天 / 时间阵法闭关的资源年、寿元、风险和中断策略。
6. F1 处理等级、摘要和硬中断。
7. 轮回总时长不保证缩短的结果提示和验算字段。

MVP 不实现：

1. T0-T5 全量具体倍率、成本、风险和开放表定稿。
2. 所有境界完整 596 年局部时间域分配曲线。
3. 完整离线托管保护窗口和多人长期无人在线推进策略。
4. 渡劫后的劫数、因果、飞升和终局结算。
5. HTML 调参器不进入正式设计包正文；开发调参与验算工具由 `../../numeric_tuning` 维护，输出若被采用必须先改写回正式数值文档。

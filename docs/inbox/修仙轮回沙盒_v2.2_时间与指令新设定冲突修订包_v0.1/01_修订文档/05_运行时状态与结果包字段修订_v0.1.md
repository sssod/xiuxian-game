# 运行时状态与结果包字段修订（v0.1）

> 替换范围：v2.2 `03_实现交付/01_运行时状态_数据模型_结果包_v2.2.md` 中与 `RoomState`、`TurnConfig`、`PersonalActionInstruction`、`ContinuousActionState`、`TurnReplay`、事件状态相关的字段。  
> 保留范围：角色、真灵、宗门、地图、资产容器、物品、功法、资源输入、残余效果、后手、结果包基础结构。

---

## 1. 总体字段迁移原则

```text
world_day / world_hour 保留并升为主时间事实；
turn_id 不再表示玩家最小同步回合；
local_hour_in_turn 废弃；
TurnConfig 替换为 TimeConfig；
current_phase 从回合阶段改为世界运行状态；
PersonalActionInstruction 改为短队列 Command；
TurnReplay 改为 TimelineReplay；
新增 SpeedState / LocalTimeStopState / CatchupSettlementState / FormalEncounterState / GlobalPauseState。
```

## 17. 存档新增最小要求

存档必须额外保存：

```text
TimeConfig
SpeedState
CommandQueue
Command validation history
FallbackState
ManagedActionState
LocalTimeStopState
CatchupSettlementState
FormalEncounterState
GlobalPauseState
TimelineReplay index
```

保留：

```text
world_day / world_hour / macro_period_id
角色与真灵
宗门 AI 当前持续行动
地图节点、资源槽、秘境窗口
ActiveResourceEffect
资产容器与物品
日志与随机状态
```

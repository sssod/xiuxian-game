适用范围：`docs/xiuxian_design_docs/01_文案设计/02_剧情设定` 中由主线文案推导出的系统、数值和交互要求。

## 1. 当前定位

本文负责把主线文案对系统、数值和交互的要求从剧情正文中拆出，避免世界观文件直接维护实现细节。本文记录的是文案侧约束和字段建议，不替代正式系统、数值或交互文档。

## 3. 拆分摘要

系统约束：山海图是成就 / 图鉴 / 收藏系统，不承担主线关卡入口；归墟入侵优先表现为节点隐藏、失联和保全状态；事件、功法、宗门和藏宝接口读取主线变量。

数值约束：大乘期为最高常规境界，`realm_cap` 与 `ascension_blocked` 是世界级硬边界；主线变量用于记录四方影响、归墟潮压、大阵完整度、节点保全和轮回结果，不在本文定具体公式。

交互约束：普通 UI 应让玩家看到节点消失、残影、镇墟碑、真灵镇痕、山海图残文和收藏奖励；不应把山海图做成大事件按钮，也不应提前暴露隐藏剧情、完整前世身份或 Debug 判定。

## 4. 山海图在主线中的位置（源稿 §15）

### 15.1 系统定位

山海图是统一成就 / 图鉴 / 收藏系统，不是创世真相，不是完整可靠史书，也不是多个宗门版本互相冲突的推理系统。它可以展示山海地理、历史、真灵故事、人物志、地方志、功法志和生涯成就，但不承担大事件入口、主线关卡入口、终局功法强投放入口或结局机制绑定入口。

### 15.2 主线中的四个作用

| 作用 | 表现 |
|---|---|
| 记录 | 记录玩家发现的断木遗址、归墟海眼、神山秘境、人物志、真灵故事 |
| 提示 | 给出残文、未考、佚名、被抹去真名等文本风味 |
| 奖励 | 给道韵点数、执念可选项、收藏进度 |
| 回顾 | 让玩家理解三阶段历史，但不替代主线事件系统 |

### 15.3 山海图不应承担

- “点山海图进入主线副本”。
- “比较多个宗门版本山海图来判定真伪”。
- “收集山海图自动解锁终局功法”。
- “山海图完成度直接锁定结局”。


### 15.4 山海图奖励结构

山海图主要投放 **真灵 / 执念相关数值奖励**。

| 收集项 | 奖励 |
|---|---|
| 收集自身预设真灵的全部真灵故事 | 奖励一次对应道韵点数 |
| 自定义真灵收集任意真灵故事并选择“承道” | 奖励一次对应道韵点数 |
| 收集完整人物志 | 解锁特定执念可选项 |
| 收集完整地方志 | 解锁特定执念可选项 |
| 收集完整功法志 | 解锁特定执念可选项 |

关键规则：

- 预设真灵：收集自身全部真灵故事后，获得一次对应道韵奖励。
- 非预设 / 自定义真灵：收集任意真灵故事后，可以选择“承道”，获得该故事对应道韵奖励。
- 该奖励只能获得一次。
- 自定义真灵与预设真灵在奖励次数上保持公平。
- 山海图不作为终局功法投放主入口。
- 山海图不作为大事件触发入口。

### 15.5 山海图基础流程

```text
节点探索 / 宗门档案 / 秘境窗口 / 异兽事件 / 真灵藏宝
→ 获得山海残图、山海旧名、断木碑文、归墟潮刻、人物轶闻、地方志残页、功法残录
→ 写入山海图、轮回账本与真灵线索
→ 补全人物志 / 地方志 / 功法志 / 真灵故事
→ 达成收藏进度后获得道韵点数或执念可选项
```

### 15.6 山海图与其他系统的边界

山海图可以与以下系统联动：

- 轮回账本：记录真灵故事、承道奖励、前世线索显现状态。
- 执念系统：通过人物志、地方志、功法志的完整收集解锁特定执念可选项。
- 探索系统：记录发现过的地点、秘境、断木遗址和归墟海眼。
- 功法系统：记录功法来源、残篇传闻和功法志收藏，但不作为终局功法强投放入口。
- 成就系统：记录玩家生涯成就和收藏进度。

山海图不替代：

- 主线事件系统。
- 宗门任务系统。
- 世界事件系统。
- 终局选择系统。
- 功法解锁与修炼数值系统。

## 5. 归墟入侵与地图节点机制（源稿 §16）

### 16.1 归墟不是占领，而是隐藏节点

归墟入侵建议不要表现为普通敌方势力占领地块，而是把地图节点设为“隐藏 / 失联 / 入墟”。

这是非常适合文字策略游戏的设定：玩家不是看见怪物站在地图上，而是发现熟悉的节点消失了、无法派遣、无法采集、无法打开藏宝、山海图地方志变成残缺。

### 16.2 节点状态表

| 状态 | 显示 | 可交互性 | 说明 |
|---|---|---|---|
| `normal` | 正常显示 | 全部可用 | 普通节点 |
| `tide_warning` | 潮刻预警 | 可用但有风险 | 归墟前兆 |
| `guixu_trace` | 灰影 / 黑潮纹 | 部分功能受限 | 归墟痕迹出现 |
| `breach` | 节点破口 | 高风险交互 | 迎墟者或海眼造成破口 |
| `hidden_by_guixu` | 地图上消失或仅留残影 | 不可常规进入 | 节点入墟 |
| `suppressed` | 镇墟碑标记 | 可恢复部分功能 | 被玩家或宗门镇压 |
| `preserved_by_reincarnation` | 真灵镇痕 | 大部分保留 | 玩家主动轮回保护 |
| `recovered` | 恢复显示 | 可重新开发 | 后续净化或重开 |

### 16.3 真灵藏宝与地图隐藏

主动轮回保护大部分地图节点，所以真灵藏宝大概率仍在。该规则可以明确系统化：

| 地图状态 | 真灵藏宝状态 |
|---|---|
| `normal` | 可按常规线索发现 |
| `guixu_trace` | 可发现，但可能有污染风险 |
| `hidden_by_guixu` | 暂时不可达，线索失联 |
| `preserved_by_reincarnation` | 大概率保留，后续新世可重新感应 |
| `recovered` | 可重新开启，但可能出现归墟污染变体 |

这样主动轮回不仅是数值重开，也有清晰的世界收益：保地图、保 NPC、保藏宝、保地方志。

- `mvp_low_affinity_time_space_flavor` 用于标注时间 / 空间意象功法，但不对应真灵根脚。


### 18.4.1 功法体系分层与主线投放

功法体系继续区分道功与法门：

- **道功**负责修为路线、当前可修上限、修炼相性、突破路线标签、奖励结构和失败标签池。
- **法门**负责战斗、移动、探索、采集、生产、事件选项和效率修正。

终局功法仍然以数值、前置、资源、路线强度和系统门槛为主，不涉及结局机制绑定。终局功法不通过山海图这类强世界观系统进行强投放。

#### 第一档：宗门常规功法

| 道功示例 | 来源 | 定位 |
|---|---|---|
| 青木养真诀 | 山林宗门 | 稳健入门，木行灵气 |
| 潮息纳元经 | 海域宗门 | 周期性修炼收益 |
| 大荒行气篇 | 荒野宗门 | 低资源环境适应 |
| 石骨炼形诀 | 山岳宗门 | 体魄、承载、低风险 |
| 归藏静息法 | 隐修宗门 | 低暴露、神念稳定 |
| 昏晓残篇 | 古法残篇 | 时间意象，低相性前期投放，不代表时间真灵根脚 |
| 开隙步法 | 秘境机关术 | 空间意象，低相性移动法门，不代表空间真灵根脚 |

#### 第二档：山海高阶功法

| 山海道功 | 山海来源 | 路线特点 |
|---|---|---|
| 昆仑登真道 | 神山 / 昆仑遗脉 | 上限高、地点依赖强、突破模板稳定 |
| 归墟吞海经 | 归墟 / 海眼 | 高风险高收益、资源吞噬、失控压力 |
| 建木通玄篇 | 断木遗址 / 建木支脉 | 灵气吸收强、真名暴露风险 |
| 大荒万兽形经 | 异兽 / 大荒生态 | 肉身、战斗、异兽相性 |
| 弱水浮生诀 | 弱水 / 海外秘境 | 移动、生存、神念漂流 |
| 扶桑朝元经 | 东方日出神木 | 周期性爆发、阳性资源相性 |

对应法门示例：

| 法门 | 类型 | 作用 |
|---|---|---|
| 望山海术 | 探索 / 信息 | 发现隐藏层、山海残图、异兽踪迹 |
| 驭兽残章 | 战斗 / 事件 | 处理异兽事件、降低冲突风险 |
| 归墟听潮法 | 信息 / 生存 | 预判归墟潮汐和海域窗口 |
| 断木寻根术 | 探索 | 感应建木根系、断木遗址 |
| 昆仑步虚法 | 移动 | 高阶路线、神山通行、逃遁 |
| 神材辨质术 | 采集 / 生产 | 识别形质神材、炼器前置 |

#### 第三档：开辟级终局功法

终局功法不是“五太灵根路线”，而是多个先天气机发展到极限后，触及创世相位压力。

| 终局道功 | 前置气机 / 系统标签 | 触及相位 | 定位 |
|---|---|---|---|
| 清浊开天录 | 清浊、净化、污染对抗 | 太极 / 太初残响 | 分清浊、定天地、抗归墟 |
| 两仪合真经 | 阴阳、突破稳定、双相修炼 | 太极残响 | 突破稳定、秩序、双相修炼 |
| 五行归藏经 | 五行、资源循环、灵根合流 | 太素 / 太始残响 | 五行合流、资源与灵根大成 |
| 形神铸界经 | 形质 + 神魂、体修、炼器、洞府 | 太始 / 太素残响 | 肉身、神魂、法宝、洞府合一 |
| 宙宇定界篇 | 高阶古法、秘境、洞天、局部时间域 | 太易 / 太极残响 | 时空意象的高阶功法；MVP 不作为真灵标签 |
| 归墟反开经 | 浊气 + 水 + 归墟污染 + 混沌残响 | 混沌残响 | 高风险反开辟线 |

投放顺序建议：

```text
普通宗门功法
→ 宗门权限 / 秘境窗口 / 断木遗址 / 归墟窗口 / 特定资源前置
→ 山海高阶道功
→ 境界、资源、路线标签、污染 / 净化状态、世界事件进度达标
→ 开辟级终局功法残篇或完整传承出现
→ 玩家根据数值强度与路线需求选择是否修炼
```

关键边界：

- 终局功法不绑定结局机制。
- 终局功法不锁定玩家阵营。
- 终局功法不要求玩家拥有对应预设真灵名。
- 山海图可以记录功法志，但不负责强制投放终局功法。
- 时间 / 空间意象功法可以存在，但 MVP 不形成时间 / 空间真灵根脚。

### 18.5 宗门接口

宗门可承接：

- 山海残传库存。
- 神山路线档案。
- 异兽谱。
- 断木遗址调查权限。
- 归墟潮汐预警。
- 高阶山海道功传承。
- 山海旧史解释与宗门立场。
- 迎墟势力预警与清剿任务。
- 四极势力外围联系。
- 撤离、镇守、节点保全与归墟失联状态。

宗门不应承接：

- 玩家真灵宿命判定。
- 当前世主线身份绑定。
- 对真灵前世立场的绝对解释权。
- 山海图多版本冲突核心玩法。

### 18.6 后手与藏宝接口

- 真灵藏宝：同一真灵跨世感应，作为正式后手，但受数量、容量和一次性取出规则限制。
- 宗门外洞府 / 普通藏宝：作为无主遗留设施，可能由玩家后世、NPC 或其他势力通过钥匙、功法、线索、位置、事件条件或破阵开启。
- 山海旧世线索：可附着在真灵藏宝、普通藏宝、断木遗址、神山隐藏层、归墟漂木等对象上。
- 山海图：可记录藏宝相关人物志、地方志或真灵故事进度，但不作为藏宝开启的唯一强入口。
- 归墟隐藏节点：若藏宝所在节点被隐藏，则藏宝暂时失联；若节点被主动轮回保全，则藏宝保留概率提高。

# 角色与真灵设计｜角色属性

## 1. 当前结论

角色属性属于当前世“身躯与灵魂”层，不默认跨世继承。真灵层不保存当前修为、功法等级、背包、宗门职位或普通关系。

## 2. 最小基础属性

S2 当前建议的最小基础属性：

| 属性 | 主要作用 |
| --- | --- |
| 体魄 | 影响生机、负伤承受、肉身类突破准备 |
| 精力 | 影响元气、持续行动承受、疲劳与恢复 |
| 悟性 | 影响功法学习、理解、修炼效率 |

角色养成稿进一步建议：修炼相关资质不要做单一“资质总分”，而应拆分为具体子项。

## 3. 修炼资质子项

MVP 建议保留：

```text
根骨 / 悟性 / 灵根
```

其中：

- 根骨偏向身体承载、经脉基础、修炼容器质量。
- 悟性偏向理解、参悟、功法学习和复杂路线掌握。
- 灵根偏向灵气亲和、路线标签适配与吸收方向。

## 4. 派生状态

最小派生状态：

| 状态 | 用途 |
| --- | --- |
| 生机 | 健康、伤病、濒死、肉身完整度 |
| 元气 | 气力 / 法力 / 可支配能量 |
| 神念 | 灵魂、神识、心神稳定；M0 可 UI 隐藏或弱化，数据层保留 |

战斗系统读取生机 / 元气 / 神念。S4 读取修为、纯度、肉身承载、心境、因果、寿元压力等突破输入。

## 5. 后天改变

- 体魄、精力、根骨、悟性可以后天改变，但必须通过明确行动、事件、突破奖励、宗门培养或资源使用写入后天修正记录。
- 灵根 MVP 不支持后天修改，只作为先天生成、执念遗留或特殊开局结果参与适配判定。
- 心性、神魂稳定、道心等暂不作为资质三件套，而作为角色状态、神念派生、神魂路线或突破准备维度处理。

## 6. 数据字段建议

```yaml
CharacterAttributes:
  physique: number
  energy: number
  comprehension: number
  foundation: number
  spiritual_root_tags: list
  derived_life: number
  derived_qi: number
  derived_spirit: number
  acquired_modifiers: list
  injuries_and_conditions: list
```

## 7. 设计历史

早期 S2 使用体魄、精力、悟性作为最小基础属性；后续角色养成稿补充根骨、悟性、灵根三类修炼资质。整理口径：体魄/精力是通用基座，根骨/悟性/灵根是修炼资质子项；悟性可同时作为最小基础属性和修炼资质，后续字段命名需统一。

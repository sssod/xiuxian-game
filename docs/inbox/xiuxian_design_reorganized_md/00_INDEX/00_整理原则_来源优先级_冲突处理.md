## 2. 当前采用的修正案优先级

后期重大修改项优先覆盖早期草稿中的相同主题：

- 《自适应流速可暂停日历制 v2》覆盖早期定额规划口径和时间推进中与“暂停、加速、局部时停”有关的旧口径。
- 《指令预输入机制 v1》覆盖早期行动队列、托管、自动兜底、预输入合法性相关旧口径。
- 《功法系统_收敛设定汇总_v0.4》覆盖早期功法、主修道功、残页/篇章/完整功法、掌握度、改修窗口相关旧口径。
- 《修为修炼公式_资源输入与丹药药性处理补充_v0.2》覆盖早期“丹药炼化 / 即时服丹 / 资源输入”的模糊口径。
- 《核心数值设计方案_境界基准收益模型_v0.1》与《修为年限_现实时间_阶段预算数值方案_v0.1》覆盖早期未成型的修为收益、境界期望时间、玩家现实体验时长等数值方向。

## 3. 已识别冲突与处理

### 3.1 S12 命名冲突

早期顶层拆分中存在“S12 宗门 AI 策略子系统”的表述；当前 Library 中可检索的 S12 具体文档是《离线、超时与稳健托管子系统》。本整理按当前具体文档处理 S12 为托管系统，并将宗门 AI 纳入宗门系统 / S7 / S14 的待补项。

### 3.2 S9 命名冲突

早期顶层拆分中 S9 曾指“节点控制、影响力与易主”；当前 Library 中可检索的 S9 文档为《物品、资源使用与随身资产子系统》。本整理按“设计文档框架”组织：节点控制内容归入地图节点设计 / 宗门系统 / 沙盒世界演化，物品内容归入物品设计与经济系统。

### 3.3 早期定额规划 vs 小时日历

早期 S3 / S1 文档以定额规划和 tick 为主。后期《自适应流速可暂停日历制 v2》和数值草案引入世界日历、小时 tick、F1/N1/B1/P0。整理口径：当前规则以共享世界日历和世界小时作为底层结算粒度；玩家规划使用普通行动短队列、显式托管和阶段摘要承接；具体接缝需要后续 S1/S3/S14 修订。

### 3.4 丹药独立炼化 vs 行动资源输入

早期文档中丹药、灵材、资源输入存在多个接口。后期 v0.2 已明确：MVP 不设计独立持续行动“丹药炼化”，丹药、灵材、符箓、临时增益资源统一作为行动或事件选项的资源输入项。

### 3.5 功法残页/篇章可学习性

早期可能存在“残页/篇章学习”或“内容缺失导致修炼卡点”的空间。后期功法 v0.4 明确：残页和篇章不可学习，只作为合成道具；只有完整功法可学习。

## 2. VS0：技术底座

### 目标

建立可运行的连续日历房间和服务端权威 tick。

### 必做

```
本地单人房间创建；
私人服务器运行；
WorldClock：world_day / world_hour；
TimeConfig：F1/N1/B1/P0 参数；
SpeedState：速度切换与中性 UI 原因；
服务器小时 tick；
P0 全局暂停；
B1 交锋轮调度；
LocalTimeStopState；
CatchupSettlementState；
TimelineReplay；
基础日志与存档。
```

### 验收

```
能创建房间并进入 world_running；
world_hour 按 N1 推进；
全员长期低交互时进入 F1；
触发个人局部事件后事件玩家冻结，其他世界 N1；
gap 提示在 12h / 18h / 24h 正确触发；
事件结束后 C1 只补确定性内容；
触发正式交锋后进入 B1，1轮=1小时；
P0 下 world_hour 不推进；
Debug 面板能看到 speed_state、world_day、world_hour、local_time_stop、catchup、encounter。
```

## 3. VS2：个人行动经济与事件

### 目标

让玩家在连续日历中使用短行动队列，并通过局部时停处理普通个人事件。

### 必做

```
当前执行指令 + 最多 3 条预输入；
入队时当前合法性校验；
执行前再次合法性校验；
队列为空 / 校验失败后自动兜底；
低风险自动吐纳，中高风险自动休整；
自动兜底强制 N1 且不参与 F1；
显式托管行动；
普通个人事件局部时停；
事件默认选项与 P0 同步保护；
C1 追赶补结算；
移动行动与路线事件按 world_hour 推进。
```

### 验收

```
玩家能新增、删除、调整最多 3 条后续普通指令；
未满足条件的突破不能入队；
队列不会因为前序炼丹可能成功而允许后序使用丹药；
行动完成后下一条合法则自动执行；
下一条不合法时跳过、个人日志记录、自动兜底、降 N1；
自动吐纳 / 自动休整不会触发 F1；
显式托管 7 日在安全条件下可参与 F1；
普通个人事件中事件玩家 frozen_world_hour 不变，其他玩家继续 N1；
C1 追赶期间不触发新随机事件。
```

## 6. VS6：大境界突破

### 目标

跑通准备期、开启突破短指令、B1 突破挑战、结果报告。

### 必做

```
突破准备期作为普通长期行动；
开启突破指令合法性校验；
当前已满足条件时才可预输入开启突破；
未预设时弹出局部时停确认；
默认选项为取消突破并进入休整；
突破挑战使用 FormalEncounterState；
B1：1轮=1小时，60秒提交窗口；
轮内默认突破策略；
真实资源消耗发生在挑战轮内；
公开影响进入宗门传闻 / 世界日志。
```

### 验收

```
未达突破条件时，开启突破不可入队；
已达条件且地点、状态、道具合法时，开启突破可入队；
执行前道具缺失时，突破指令失败，不消耗道具，进入兜底并降 N1；
突破挑战开始后世界 B1；
5 轮突破消耗 5 游戏小时；
玩家未提交某轮时执行突破预设；
挑战结束后生成个人报告与公开影响；
后续“疗伤 / 巩固 / 公开报备”等按普通个人事件处理。
```

## 7. VS9：3 人共玩

### 目标

验证多人共享日历、速度隐私、显式托管、局部时停和 B1 交锋。

### 必做

```
3 人共享 world_day / world_hour；
速度状态只显示中性信息；
个人事件不暴露给其他玩家；
F1 只在全员显式长期低交互时出现；
任一玩家进入自动兜底则世界 N1；
局部时停 gap 上限；
B1 交锋所有玩家共享慢速；
P0 公共事件全员暂停；
显式托管可维持低关注玩家状态；
玩家不能看到其他玩家详细行动队列。
```

### 验收

```
A 触发个人事件时，B/C 只看到当前速度：常态推进；
A gap 到 24 小时时自动默认或 P0 同步保护；
B/C 不知道 A 事件归因；
A 队列空转入自动吐纳时，F1 不成立；
A 主动显式托管时，可在其他条件满足时参与 F1；
正式交锋期间非参战玩家也按 B1 世界时间推进；
玩家直接冲突进入 B1。
```

## 8. 后端任务拆分

| 任务 | 内容 | 验收 |
| --- | --- | --- |
| T01 WorldClock 与 TimeConfig | `world_day / world_hour`、速度参数、tick 换算 | N1/F1/B1/P0 换算正确 |
| T02 SpeedState | 速度优先级、F1 eligibility、速度日志 | P0 > B1 > N1 > F1 |
| T03 CommandQueue | 当前指令 + 3 后续、入队校验、执行前校验 | 队列变更可回放 |
| T04 FallbackState | 队列空 / 校验失败兜底 | force_speed=N1, f1_eligible=false |
| T05 LocalTimeStopState | 冻结事件玩家、gap 提示、安全默认 | gap 12/18/24h 行为正确 |
| T06 CatchupSettlementState | 确定性补结算 | 追赶期间无随机事件 |
| T07 FormalEncounterState | B1 交锋轮、默认策略、硬上限 | 60 秒窗口与轮结算正确 |
| T08 Breakthrough B1 | 开启短指令、挑战转交锋、轮内资源消耗 | 突破结果可复盘 |

# 角色与真灵设计｜真灵与执念

## 1. 三层主体

```text
真灵：跨世延续主体
执念：转世初始化遗留容量系统
身躯与灵魂：当前世角色实例
```

真灵层不保存当前身躯、灵魂、修为、功法等级、背包、宗门职位、普通关系、当前天赋完整属性表或完整前世记忆副本。

## 2. TrueSpirit MVP 字段

```yaml
TrueSpirit:
  spirit_id: string
  true_name: string
  true_name_visibility: hidden | declared | exposed
  spirit_strength: number
  obsession_capacity: number
  formal_contingency_slots: number
  incarnation_count: int
  highest_stage_reached: string
  dao_rhyme_tags: list
  reincarnation_ledger_refs: list
  legacy_sense_log_refs: list
  formal_legacy_refs: list
```

真灵强度只承担两项核心数值价值：

1. 决定执念容量。
2. 决定正式后手最大设置次数。

真灵强度不直接提高修炼效率，避免与执念容量产生冗余。

## 3. 执念容量权重制

```yaml
ObsessionPackage:
  source_life_id: string
  capacity_used: number
  carried_talent_tags: list
  carried_birth_background: string | null
```

规则：

- 真灵强度提供 obsession_capacity。
- 每个遗留配置有 obsession_weight。
- 总权重不得超过容量。
- 权重不是 RPG 属性点。
- MVP 优先支持天赋标签与出生背景。

## 4. 天赋标签

天赋标签区分：

```yaml
TalentTag:
  tag_id: string
  tag_type: additive | random_pool
  affected_attributes: list
  fixed_value_modifiers: dict
  coefficient_modifiers: dict
  affected_random_pool: string | null
  random_pool_replacement_rules: list
  route_affinity_tags: list
```

## 5. 出生背景

出生背景影响：

- 初始资源。
- 初始身份。
- 家族关系。
- 宗门关系。
- 区域声望。

## 6. 轮回账本

轮回账本用于记录突破失败、死亡、前世经验、后手线索、失败标签、资产去向、真名暴露变化和下一世初始条件。它不是完整前世记忆复制，而是长期复盘和线索系统。

## 7. 设计历史

早期三层模型确立跨世主体；S2 将其转成子系统字段；后期数值草案强调轮回应成为低效率世代的效率修正机制，也可成为高效率世代的主动策略选择，而不是被寿元或事件门槛半强迫。

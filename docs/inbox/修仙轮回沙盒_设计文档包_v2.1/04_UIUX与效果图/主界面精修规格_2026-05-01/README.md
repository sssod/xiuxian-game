## 精修决策摘要

- 顶部阶段进度必须在上部区域中心对齐。
- 玩家角色信息固定在左上角，包含头像、姓名 / 境界、所属宗门 / 宗门职位、三条状态数值条。
- `A-2` 小标已移除；当前不再用额外圆形标记表达境界或玩家编号。
- `时间暂停` 文本和状态胶囊已移除。
- 生机、元气、神念使用“当前值 / 保留值 / 最大值”数据模型。
- 保留值不是已损失值，也不是当前值覆盖层；它代表最大可恢复上限被锁定的右侧区间。
- 具体数值默认不常驻外露，放入数据条内部 hover / click 浮层。
- 地点信息不放在角色卡中，改为地图区域顶部中间浮窗。
- 地图左上图层面板下移，确保地图顶部中间浮窗信息露出。
- 左侧、右侧、底部区域仍沿用 v2.1 回合行动工作台结构。

# 修炼系统数值投放收敛裁决

适用范围：`docs/xiuxian_design_docs` 中修炼、修为境界、功法、丹药、突破、角色属性、交互和投放数值相关文档。

## 1. 当前定位

本文用于沉淀当前修炼系统数值投放的最高层裁决，先统一 CP、法力、纯度、道功、巩固修为、功法研习度和经脉压力的职责边界，再由各主题文档承接详细规则。

本文不替代《修炼公式与数值设计》（`../03_数值设计/02_修炼公式与数值设计.md`）、《修炼玩法设计》（`../02_系统设计/11_修炼玩法设计.md`）、《角色修为与境界》（`../02_系统设计/02_角色与真灵设计/03_角色修为与境界.md`）或其他正式主题文档。本文只维护跨文档收敛裁决、禁止误用口径和待裁决问题。

## 2. 使用方式

1. 凡涉及修炼成长、道功数值、战斗出力、突破准备、丹药资源输入和 UI 表达的文档，先按本文确认术语职责。
2. 主题文档可以展开公式、字段和流程，但不得把本文已收窄的职责重新扩张。
3. 包外资料中的旧公式、旧字段和旧口径只有在改写进正式包后才成为设计依据。
4. 未裁决的设计取舍进入对应文档“待裁决与待补”，不要在正文中伪装成定稿。

## 3. 核心裁决

一句话定稿：

```text
CP 概念不变：CP 是外部灵气输入经道功转化后的标准修为点，用于管理境界进展。
法力是玩家直观感知的修为强弱：法力 = CP × 纯度 × 道功放大系数。
纯度是 (0, 1] 的惩罚系数；道功放大系数才是单位 CP 强度。
巩固修为不推进主 CP，只填充当前大境界的巩固 CP 条，用于提高当前大境界纯度。
```

### 3.1 CP

`CP / cultivation_points` 是标准修为点，也可以称为修为绝对值进度。它负责：

1. 把外部灵气输入转化为可比较、可记录的标准化进度。
2. 管理当前境界、小阶段、瓶颈、突破开启门槛和日志阈值。
3. 作为修炼公式、境界段根表和结果包的基础输出。

CP 不再直接等同战斗出力，也不直接代表玩家直观感知的修为强弱。

### 3.2 法力

法力是玩家直观感知的修为强弱值。当前公式为：

```text
major_realm_mana =
  major_realm_cp
  × major_realm_purity
  × dao_method_mana_amplifier

total_mana = Σ major_realm_mana
```

当前暂不引入境界权重，保持 CP 作为跨境界绝对值。若未来 CP 改成每个大境界内部局部值，需另行裁决 `realm_weight_i`。

### 3.3 纯度

纯度是 CP 转化为法力时的惩罚系数：

```text
0 < purity <= 1
```

纯度越低，表示修为越虚浮；纯度越高，表示修为越凝实。纯度不是正向倍率，也不超过 1。道功真正的单位 CP 强度由 `mana_amplifier` 表达。

纯度按大境界记录。当前大境界的纯度只对应当前大境界 CP 和法力；进入下一大境界后，上一大境界记录锁定。普通巩固修为不能再修改历史大境界纯度。

### 3.4 道功

道功数值至少拆为三类职责：

| 字段 | 职责 |
| --- | --- |
| `aura_absorption_cap_per_hour` | 环境灵气吸收上限，表示单位时间可承接多少环境灵气 |
| `cp_conversion_rate` | 已承接灵气转化为 CP 的速度 |
| `mana_amplifier` | 单位 CP 对应法力的道功放大系数 |

转化率高表示修炼速度快，不等于道功绝对强。同品级道功中，低转化率道功可以拥有更高 `mana_amplifier`，表现为修得慢但单位 CP 法力更凝实。

### 3.5 巩固修为

巩固修为不是惩罚流程，而是玩家主动提高当前大境界法力密度的修炼选择。

当前裁决：

1. 巩固修为不增加主 CP。
2. 巩固修为不推进境界进度。
3. 巩固修为不增加功法研习度。
4. 巩固修为只填充当前大境界巩固 CP 条。
5. 巩固修为只通过提高当前大境界纯度来提高法力。

普通巩固修为不能补救上一大境界未巩固导致的历史法力损失。稀有事件、特殊消耗品、高阶法门、剧情后手或宗门秘法可以作为未来例外，但不进入 MVP 默认循环。

### 3.6 功法研习度

功法研习度只影响学习、上限、效率、可见信息和过程稳定性，不影响最终法力、历史纯度或既往阶段质量。

功法研习度可以影响：

1. 是否学会道功或法门。
2. 当前可修上限。
3. 修炼行动效率。
4. 达到同一 CP 所需总时间。
5. 路线提示、可见信息、稳定操作和部分解锁项。

功法研习度不得影响：

1. CP 到法力的纯度系数。
2. 道功放大系数。
3. 已获得 CP 的法力密度。
4. 小阶段奖励质量。
5. 大境界突破后的属性质量。
6. 既往修炼结果。

### 3.7 经脉压力

经脉压力职责收窄为身体承载和外源输入风险。它用于：

1. 体魄考验。
2. 药性容量。
3. 丹药、灵材、符箓、阵法灌注、强行吸收外源灵气等外源输入的过载风险。

经脉压力暂时不用于：

1. 当前大境界纯度计算。
2. 法力公式。
3. 根基系统。
4. 心境稳定。
5. 普通战斗出力。
6. 复杂突破质量链。

边界句：

```text
纯度负责“修为是否凝实”。
经脉压力负责“身体能否承受药性和外源输入”。
```

## 4. 数值出口收敛

| 场景 | 当前出口 | 边界 |
| --- | --- | --- |
| 环境灵气输入 | 受道功吸收上限限制后，按道功转化率生成 CP | 节点、灵脉、洞府、聚灵阵、宗门设施等不直接发放法力 |
| 丹药 / 消耗品输入 | 受药性容量、体魄承载、服用规则和释放时长限制后，按道功转化率生成 CP 或巩固填充 | 不即时涨法力，不绕过修炼 / 巩固流程 |
| 主修道功 | 提供吸收上限、CP 转化率、法力放大系数、纯度区间和巩固效率 | 不通过掌握度事后改写历史结果 |
| 主修道功掌握度 | 提供上限、效率、相性、可见信息和过程稳定性 | 不增加最终法力，不改历史纯度 |
| 修炼行动 | 生成主 CP、更新当前大境界法力派生值、消化体内药性 | 不增加功法研习度 |
| 巩固修为 | 填充当前大境界巩固 CP 条，提高当前大境界纯度和法力 | 不推进境界，不补历史大境界 |
| 战斗 | 主要读取法力、属性、境界倍率、小阶段倍率、状态和装备 / 法门修正 | 不直接读取 CP 当战斗力 |
| 突破 | 开启门槛读取 CP；质量 / 风险 MVP 可读取法力相对推荐值 | 暂不塞入复杂根基、心境、心魔、纯度惩罚链 |

## 5. 禁止回写的旧口径

1. 不要把 CP 直接写成战斗力。
2. 不要把转化率写成道功绝对强弱。
3. 不要把纯度写成超过 1 的正向倍率。
4. 不要让功法研习度影响最终法力、历史纯度或历史小阶段奖励。
5. 不要让巩固修为增加主 CP 或推进境界。
6. 不要让普通巩固修为修补上一大境界纯度。
7. 不要让经脉压力同时承担纯度、根基、心境、突破和战斗等多重职责。
8. 不要在 MVP 阶段引入过多根基、心境、心魔和复杂突破评分。
9. 不要让切换主修道功按新道功回溯重算法力。
10. 不要让丹药即时涨法力或绕过修炼 / 巩固流程。

## 6. 待裁决与待补

| 项目 | 当前口径 | 需要裁决或补充 |
| --- | --- | --- |
| 巩固 CP 条开启时机 | MVP 默认主进度达到当前阶段要求后显性提示 | 是否允许任意时点中途巩固 |
| `consolidation_cost_factor` | 可先用 1 作为默认值 | 不同道功差异和数值范围 |
| 历史大境界纯度修复 | 普通巩固不能修复；仅保留稀有例外 | 例外资源、代价、模板和 UI 提示 |
| 主修道功切换折算 | 暂不写死公式 | 正式 CP / 法力折算应按单位 CP 法力密度还是其他规则 |
| 法力总和 | 当前为 `Σ major_realm_mana` | 是否引入境界权重 |
| 战斗 `mana_factor` 曲线 | 战斗主要读取法力 | 曲线、阈值和与属性 / 装备关系 |
| 突破推荐法力 | 可用 `current_mana / recommended_mana_for_breakthrough` | 阈值表和提示文案 |
| 道功 `mana_amplifier` 数值范围 | 字段职责已定 | 按阶级、品级和路线补表 |
| 巩固资源 | 默认同类外部输入可进入巩固填充 | 是否需要专门凝实类资源 |
| UI 纯度表达 | 当前允许显示百分比或包装词 | 普通玩家最终显示“72%”还是“虚浮 / 稳固 / 凝实” |

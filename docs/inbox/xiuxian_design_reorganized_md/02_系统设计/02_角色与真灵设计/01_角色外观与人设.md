# 角色与真灵设计｜角色外观与人设

## 1. 当前状态

当前 Library 中未检索到独立的角色外观、美术人设、立绘模板、服饰体系或年龄段形象文档。本文件只整理已有系统约束，不新增外观设定。

## 2. 已有约束

- 玩家初次入世可从凡人少年开始，第一阶段示例为 10 岁投生。
- 角色拥有当前姓名、年龄、寿元上限、性别或身体模板、出生地点、家庭背景、初始社会身份等初始化字段。
- 真灵真名前期默认隐藏于当世身份之后；中后期可主动归本溯源宣告真名，也可能因高阶事件被动暴露。
- 玩家主体不是单一肉身，而是跨世延续真灵；因此外观与人设应服务“本世身份”和“跨世主体”的张力。

## 3. 可落地字段建议（约束占位）

```yaml
CharacterPresentation:

  appearance_tags: list

  true_name_visibility: hidden | declared | exposed
```

## 4. 设计历史

早期文档主要关注真灵、执念、身躯灵魂三层结构，而非美术外观。当前不应把外观设计反向绑定真灵强度、修为收益或执念容量。

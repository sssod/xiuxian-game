# UI/UX 时间速度与队列界面修订（v0.1）

> 替换范围：v2.2 `04_UIUX与效果图/01_UIUX需求方案_v2.2.md` 中回合阶段条、结算进度条、5 日时间预算条、锁定提交、托管预览等与时间规则冲突的部分。  
> 保留范围：大地图主界面、节点上下文面板、地图图层、角色/物品/功法/宗门/日志入口、行动资源输入折叠项、残余药性提示等不冲突内容。

---

## 1. 主界面定位修订

旧：

```text
大世界地图驱动的回合行动工作台。
```

新：

```text
大世界地图驱动的共享日历行动工作台。
```

玩家关注：

```text
当前世界时间；
当前公开速度；
当前行动；
后续 1～3 条预输入；
当前位置 / 节点风险；
当前兜底规则；
个人局部事件 / 交锋 / P0 的待处理状态。
```

---

## 2. 顶部时间区

顶部不再显示“回合阶段条 / 结算动态进度条”作为主结构，改为：

```text
世界日历块
+ 当前速度图标
+ 当前速度名称
+ 当前角色摘要
+ 当前待处理状态入口
```

速度显示：

| 速度 | UI 文案 | 归因展示 |
|---|---|---|
| F1 | 高速推进 | 不显示具体玩家原因 |
| N1 | 常态推进 | 不显示“某玩家正在选择 / 编辑” |
| B1 | 交锋慢速 | 公开交锋可显示事件名；隐秘交锋仅显示交锋慢速 |
| P0 | 全局暂停 | 可显示公共事件名或同步保护 |

若 F1 降到 N1，中性提示：

```text
进入常态推进
```

禁止：

```text
因为某玩家触发事件，所以进入常态推进；
某玩家正在编辑指令；
某玩家处于局部时停；
某玩家正在突破。
```

---

## 3. 底部行动队列面板

替换旧“5 日时间预算条”。

推荐显示：

```text
当前指令
后续 1
后续 2
后续 3
当前兜底规则
显式托管入口
```

示例：

```text
当前：闭关修炼《青木引气诀》10 日
后续 1：调息 2 日
后续 2：开启筑基突破
后续 3：空
兜底：低风险自动吐纳；中高风险自动休整
```

面板原则：

```text
看起来像简单队列，不像脚本编辑器；
不显示 if-else；
不显示预计未来满足条件；
不显示“如果炼丹成功则突破”；
不提供甘特图式长计划。
```

---

## 4. 队列编辑交互

玩家打开普通指令输入界面时：

```text
若世界为 F1 → 降至 N1；
若世界为 N1 → 保持 N1；
若世界为 B1 / P0 → 仍可编辑普通队列，但不能替代交锋轮选择 / 全局选择；
角色当前行动继续结算；
不触发局部时停。
```

按钮修订：

| 旧按钮 | 新处理 |
|---|---|
| 开始规划 | 删除或改为“编辑队列” |
| 锁定提交 | 删除普通用途；只用于 P0 / 公共事件确认 |
| 回退 | 保留为删除队尾指令 / 撤销未提交编辑 |
| 托管 | 保留为显式托管入口，不立即提交 |

---

## 5. 入队校验提示

只提示当前是否合法。

示例：

```text
可入队：当前已满足筑基突破条件。
不可入队：当前未拥有筑基丹。
不可入队：当前地点不允许突破。
不可入队：当前灵力储备不足。
```

禁止提示：

```text
预计 8 日后满足；
如果前序炼丹成功则可执行；
如果前序失败则跳过；
若资源不足则自动改用替代道具。
```

---

## 6. 执行失败提示

仅给玩家个人提示。

示例：

```text
预输入指令未执行：开启筑基突破。
原因：缺少筑基丹。
已自动转入：吐纳。
世界进入常态推进，等待你输入新指令。
```

队列为空：

```text
队列已空。
当前处于低风险节点，已自动转入吐纳。
世界进入常态推进，等待你输入新指令。
```

---

## 7. 个人局部时停界面

事件玩家本人显示：

```text
你的时间已停滞
当前脱节：X 游戏小时
最大脱节：1 游戏日
```

gap 提示：

| gap | UI |
|---:|---|
| 0～12 小时 | 常规显示 |
| 12～18 小时 | 轻提示：世界正在继续推进 |
| 18～24 小时 | 强提示：即将执行默认处理或同步保护 |
| 24 小时 | 自动默认 / P0 同步保护 |

非事件玩家只显示：

```text
当前速度：常态推进
```

---

## 8. C1 追赶界面

事件结束后显示短摘要：

```text
正在追赶至当前世界时间……
补结算：6 游戏小时
```

追赶完成后显示：

```text
已同步至当前世界时间。
补结算内容：修炼进度、资源消耗、伤势恢复。
追赶期间未触发新随机事件。
```

---

## 9. B1 交锋界面

交锋顶部显示：

```text
当前速度：交锋慢速
第 N 轮 / 预计上限
本轮剩余：60 秒
本轮游戏时间：1 小时
```

每轮允许：

```text
提前提交；
倒计时结束前修改；
未提交则执行默认策略。
```

突破挑战使用相同 B1 框架，但文案为：

```text
突破挑战
本轮道基态势
本轮可用突破资源
当前突破预设
```

---

## 10. 显式托管预览

托管入口仍建议在底部 dock 右侧。

点击后显示摘要，不立即提交：

```text
显式托管：7 日
当前位置风险：低
默认行动：托管吐纳
收益：低
会自动处理：普通邀约、普通传闻、低价值机会、轻微状态波动
不会自动处理：死亡风险、正式交锋、重大心魔、重大机缘、不可逆选择、大境界突破挑战、多人直接冲突、宗门重大事件
满足条件时可参与高速推进
```

---

## 11. 资源输入与残余效果保留

v2.2 中行动资源输入折叠项继续保留，但应显示在具体行动编辑卡内，而不是独立行动入口。

新增提醒：

```text
局部时停期间，你的药性衰减暂停；外部世界继续推进。
C1 追赶时将补结算确定性药性衰减与兼容小时。
```

## 12. 日志入口修订

日志需新增分类：

```text
队列变更；
入队校验；
执行前校验失败；
自动兜底；
显式托管；
速度切换；
局部时停；
gap 默认处理；
C1 追赶；
B1 交锋轮；
P0 全局事件。
```

私人日志仅自己可见；公开日志按可见性与传闻规则生成。

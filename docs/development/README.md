# Development Docs

This directory contains implementation-facing planning and progress documents. These files are outside `docs/xiuxian_design_docs` so ChatGPT Library exports of the formal design package do not include development planning material.

Development documents may reference the formal design package at `../xiuxian_design_docs`, but they are not design authorities. When a development decision changes stable gameplay, numeric, or UI behavior, restate the accepted decision in the relevant formal design document.

Development documents should use English as their primary language unless a specific Chinese design term must be preserved for traceability.

## Documents

- `01_MVP_Development_Plan.md`: single-player MVP development schedule, execution progress, acceptance gates, validation matrix, and deferred multiplayer backlog.

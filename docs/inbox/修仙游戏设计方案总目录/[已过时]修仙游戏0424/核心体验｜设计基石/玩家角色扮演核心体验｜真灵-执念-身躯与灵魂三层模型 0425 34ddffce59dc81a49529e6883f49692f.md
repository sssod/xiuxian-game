# 玩家角色扮演核心体验｜真灵-执念-身躯与灵魂三层模型 0425

## 0. 页面定位

本文用于沉淀玩家角色扮演的核心体验方案，放置于“核心体验｜设计基石”页面下。

本文不是角色属性数值表、转世系统详细规格或技能系统详细案，而是用于固定三层角色模型与转世初始化的体验原则。

核心命题：

> 玩家创建的是一点跨世不灭的真灵，而不是一次性人物。每一世的身躯与灵魂都是新的，负责承担本世行动、成长、失败和关系。前世对下一世的主要内生影响不表现为完整人格或完整记忆继承，而是通过“执念容量”选择少量初始化遗留，主要包括天赋标签与出生背景。转世年龄、转世地域和附近宗门作为无成本基础选项决定本世开局位置与节奏。真名是玩家自见的跨世主体锚点，前期默认隐藏于当世身份之后，中后期可以通过归本溯源主动宣告，或因高阶事件被动暴露。真灵提供长期身份感与容量成长，执念提供初始化构筑，身躯与灵魂提供本世沉浸和风险代价。
> 

---

## 1. 三层角色结构

玩家角色分为三层：

```
真灵：跨世不灭的玩家主体
执念：转世初始化遗留包
身躯与灵魂：本世实际行动、成长、承受后果的角色实例
```

判断一个要素属于哪一层，可以采用以下标准：

1. 如果它必须跨越所有转世永久存在，则属于真灵。
2. 如果它只用于选择转世初始化遗留，则属于执念。
3. 如果它只在当前生命中存在并承担行动后果，则属于身躯与灵魂。

---

## 2. 真灵层

玩家进入游戏时，创建的不是一名完整的人物角色，而是一点跨世不灭的真灵。

玩家的长期身份感来自：

```
我不是某一世的张三、李四、某宗弟子或某位长老。
我是一点真灵。
张三、李四、某宗弟子、某位长老，都是我在不同世中的显化。
```

### 2.1 真灵应包含的最小要素

| 要素 | 设计含义 | 影响内容 |
| --- | --- | --- |
| 真名 | 玩家跨世主体的唯一锚点 | 玩家自见；轮回账本、跨世叙事、归本溯源、极少数高位事件识别 |
| 真灵强度 | 真灵层的主要长期追求 | 决定执念容量；决定正式后手的最大设置次数 |
| 轮回履历 | 玩家可查阅的跨世日志 | 记录前世数量、最高境界、重大突破、失败原因、正式后手记录；不直接提供数值加成 |
| 道韵 | 真灵层的顶级稀有追求 | 对匹配技能标签的功法 / 术法 / 技能提供正向加成；稀有投放，不作为每世稳定成长项 |
| 后手感应 | 辅助玩家寻找前世遗产和正式后手的工具入口 | 越靠近目标，轮回账本展示越多细节；本质是日志解谜与追踪玩法 |

真灵强度是最稳定、最主要的跨世成长目标。它最大的价值不是直接提高修炼速度，而是提高“上一世到下一世的内生性可继承要素”容量，也就是执念容量。执念容量已经可以通过天赋标签与出生背景影响下一世的修炼效率、路线适配和早期资源效率，因此不再额外设计“真灵强度直接提高修炼效率”的规则。否则会形成重复收益。

其次，真灵强度决定玩家能够布置多少个正式后手。

### 2.2 真名显示与暴露

玩家自己始终能够看到自己的真名。界面可以显示为：

```
当世角色名（真名）
示例：沈青岚（玄微）
```

其中，当世角色名属于这一世，真名属于跨世主体。这个显示只对玩家自己成立，不代表 NPC 或其他玩家在早期就能识别该真灵。

真名暴露状态可先分为三档：

```
hidden：前期默认隐藏，只有玩家自己可见
claimed / declared：玩家主动归本溯源，宣告真名
exposed：因重大事件、突破、旧怨追踪、后手争夺或他人识破而被动暴露
```

真名前期默认隐藏于当世身份之后；中后期可以主动归本溯源宣告真名，也可以因高阶事件被动暴露。

| 状态 | 规则含义 | 优势 | 风险 |
| --- | --- | --- | --- |
| 未宣告真名 | 只以当世身份活动 | 低调、安全，不易被其他玩家或高阶事件锁定 | 难以调用真名层面的深层力量 |
| 归本溯源 / 宣告真名 | 主动承认并显化跨世真名 | 后续修行、突破、道韵调用或高阶事件中获得优势 | 更容易触发累世旧怨、后手争夺和高阶追踪，也会被其他玩家或高阶存在识别 |
| 被动暴露 | 因重大突破、后手争夺、旧怨追踪或高阶敌对方识破而暴露 | 可能触发高价值剧情或世界反馈 | 失去低调优势，暴露轮回主体身份和部分旧世线索 |

整体节奏：

```
前期：玩家可以低调经营当世身份。
中期：玩家开始接触真名、道韵和跨世后手的深层规则。
后期：玩家可能主动归本溯源，也可能因重大事件被动暴露。
```

### 2.3 道韵机制口径

道韵是顶级长期追求，不是每一世稳定刷出来的路线熟练度。它应来自重大突破、稀有机缘、高价值事件链或非常规选择。

道韵不按固定“大路线”硬分类，而是对技能标签产生加成。功法、术法或其他技能可以由多个标签组合描述，只要技能带有对应标签，就可以吃到对应道韵的正向收益。

示例：

```
沧浪剑诀：剑道 / 水行 / 攻伐
玄龟炼体法：炼体 / 水行 / 防御
青木回春术：木行 / 治疗 / 生机
```

如果玩家拥有“剑道道韵”，则所有带有“剑道”标签的技能都可能获得正向加成；如果同时拥有“水行道韵”，则带有“水行”标签的技能也可能获得正向加成。一个技能可以同时受多个道韵影响，但具体叠加方式、上限和收益类型后续再进入数值设计。

### 2.4 普通前世遗产与正式后手

需要明确区分两类跨世外在资产。

| 类型 | 类比 | 规则含义 | 玩家体验 |
| --- | --- | --- | --- |
| 普通前世遗产 | 地图公共宝箱 | 存在于世界中，可能被他人发现、搬空、污染、转移或破坏 | 玩家依靠记忆、线索、地图变化和运气寻找遗产 |
| 正式后手 | 真灵解锁的保险库 | 只有经过正式布置并占用后手次数的内容，才进入更强追踪、保护或解锁规则 | 玩家相信关键安排不会无日志、无原因地消失 |

正式后手不是无限保险箱，而是由真灵强度支持的稀缺机制。真灵强度越高，可布置的正式后手次数越多。

正式后手的设计重点不是让玩家规避所有风险，而是保证三件事：

1. 它可追踪。
2. 它有日志。
3. 如果失效、暴露或被破坏，必须有原因和追查路径。

后手感应不应被设计成常规强度加成。它更适合作为轮回账本的一种交互规则：玩家越接近前世遗产、正式后手或关键地点，账本中对应条目的描述越清晰，从模糊感应逐渐变成可行动线索。

### 2.5 真灵不应包含的内容

真灵层不应保存以下内容：

- 当前身躯。
- 当前灵魂。
- 当前修为。
- 当前功法等级。
- 当前背包物品。
- 当前宗门职位。
- 当前普通社会关系。
- 当前天赋的完整属性表。
- 所有前世记忆的完整可读副本。

如果这些都进入真灵，转世就不再是转世，而只是换皮复活；如果这些都永久叠加，玩家也会被早期选择锁死。

## 3. 执念层

执念不再承担完整叙事桥接层、路线志向层或前世人格残留层的职责。为了降低复杂度，它应被简化为一系列角色初始化设定：玩家根据真灵强度提供的执念容量，选择本次转世重修要携带到下一世的少量遗留。

```
真灵强度提供容量
→ 玩家选择若干可携带遗留
→ 遗留影响下一世初始化
→ 新身躯与新灵魂生成
```

### 3.1 执念应包含的最小遗留

MVP 中，执念遗留优先只包含两类：

| 遗留类型 | 设计含义 | 影响内容 |
| --- | --- | --- |
| 天赋标签 | 玩家将前世积累、失败修正或路线偏好压缩成下一世的初始资质倾向 | 影响角色初始属性、修炼适配、突破短板分布、早期路线效率 |
| 出生背景 | 玩家选择下一世以什么社会身份、家庭 / 地域资源、宗门接触条件开始 | 影响初始资源、初始身份、家族关系、宗门关系、区域声望 |

出生背景暂定只覆盖五类开局影响：

1. 初始资源。
2. 初始身份。
3. 家族关系。
4. 宗门关系。
5. 区域声望。

更细的资源数量、关系强度、声望范围和身份模板，下沉到角色初始化与出生背景系统案中展开。

### 3.2 无成本转世选项

以下内容不再占用执念容量，而是作为转世时的基础选择项：

| 选项 | 设计含义 | 说明 |
| --- | --- | --- |
| 转世年龄 | 决定新角色觉醒时的年龄段 | 例如早觉醒、标准觉醒；影响节奏，但不作为稀缺遗留 |
| 转世地域 | 决定新角色开始所在大区域 | 用于控制地图入口和玩家规划，不消耗执念容量；可选范围限制为已知区域 |
| 附近宗门 | 决定新角色初始接近哪个宗门或势力范围 | 影响宗门入口和早期资源环境，不消耗执念容量；可选范围限制为已知宗门 |

转世地域和附近宗门需要限制在玩家已知的信息范围内，但不要求当世角色或前世角色必须亲身抵达过。只要该区域或宗门已经通过地图、情报、传闻、宗门资料、后手感应或其他可靠信息进入玩家认知，就可以作为候选。

### 3.3 执念容量的作用

执念容量只用于限制可携带遗留的数量或强度。

```
真灵强度越高
→ 执念容量越大
→ 可携带更多或更强的天赋标签 / 出生背景
→ 下一世初始化质量更高
```

执念容量不在本草稿中展开具体消耗公式。可以先明确：不同天赋标签和出生背景的容量占用一定不完全均等，应综合解锁难度、效果强度、稀有度和对开局效率的影响决定。具体采用格子制、权重制还是其他容量模型，下沉到转世初始化与天赋标签系统案中设计。

### 3.4 执念边界

执念适合回答：

- 下一世携带了哪些初始天赋倾向？
- 下一世以什么出生背景开始？
- 真灵强度提升后，玩家能多带什么？
- 玩家如何把前世失败修正为下一世的初始化优势？

执念不再负责回答：

- 下一世从哪个地域开始。
- 下一世靠近哪个宗门。
- 下一世几岁觉醒。
- 玩家是否完整记得前世。
- 玩家是否永久背负前世惩罚。
- 玩家这一世必须走什么路线。

## 4. 身躯与灵魂层

身躯与灵魂是玩家在当前世中实际操作的角色。

转世重修后，身躯和灵魂都与前世没有直接延续关系。玩家延续的是更底层的真灵，而不是上一世灵魂换了一个身体。

```
真灵觉醒在新的身躯与新的灵魂之中，形成这一世的“我”。
```

这不是夺舍。普通生命有身躯与灵魂，但不具备玩家意义上的跨世真灵。真灵觉醒不是替换灵魂，而是在新的身魂结构中显现跨世主体。

### 4.1 身躯与灵魂应包含的要素

| 要素 | 设计含义 | 影响内容 |
| --- | --- | --- |
| 年龄与寿元 | 本世生命阶段与时间压力 | 可行动年限、寿元压力、突破紧迫感 |
| 身躯资质 | 肉身、根骨、体质、经脉、气血等 | 修炼效率、炼体路线、肉身突破项、伤势承受 |
| 灵魂资质 | 神识、悟性、心性、魂魄稳定等 | 悟道、法术、心境、幻境、部分突破项 |
| 当前修为 | 本世境界与小阶段进度 | 资源层级、行动能力、宗门身份、突破门槛 |
| 功法与法术 | 本世实际学习和使用的体系 | 修炼路径、战斗 / 非战斗能力、突破匹配度 |
| 当前资源 | 本世掌握的物品、灵石、材料、法器等 | 行动支付、突破准备、后手布置 |
| 宗门身份 | 本世在宗门中的职位与权限 | 组织资源接口、宗门行动影响、任务层级 |
| 当前关系 | 本世与 NPC、宗门、地区的社会关系 | 任务、支持、护法、冲突、情报 |
| 伤势与道伤 | 本世承受的损耗 | 修炼折损、突破风险、是否需要疗伤或转世 |
| 本世道心 | 本世人格、目标、心境稳定度 | 突破事件、心魔、路线选择、关键抉择 |

### 4.2 角色初始属性发散设计

角色初始属性可以先分为四组：

| 属性组 | 属性示例 | 生成方式 | 主要用途 |
| --- | --- | --- | --- |
| 一般身躯属性 | 根骨、经脉、体魄、气血、灵根承载 | 标准模板公式生成 | 修炼速度、炼体路线、伤势承受、肉身类突破准备 |
| 一般灵魂属性 | 神识、悟性、心性、魂魄稳定、感知 | 标准模板公式生成 | 功法参悟、法术学习、心境事件、幻境 / 心魔抵抗 |
| 特殊属性 | 灵根、特殊体质、特殊命格等 | 随机池生成 | 路线适配、稀有开局、特殊事件入口 |
| 社会开局属性 | 初始资源、初始身份、家族关系、宗门关系、区域声望 | 出生背景生成 | 初始资源供给、宗门入口、早期任务、区域便利度 |

一般属性采用角色属性标准模板生成。特殊属性本身就是随机生成。社会开局属性主要由出生背景决定。

一般属性基础公式：

```
一般属性 = 固定值 + 系数 * 年龄%分段函数
年龄% = 当前年龄 / 寿元上限
```

附加型天赋施加影响后，公式变为：

```
一般属性 = 固定值 + 天赋附加固定值 +（系数 * 天赋附加系数）* 年龄%分段函数
```

这里的年龄%分段函数用于表达同一角色在不同生命阶段的属性变化。例如，体魄可以在壮年阶段最强，在幼年与衰老阶段较弱。

### 4.3 天赋标签：附加型与随机池型

天赋标签目前只保留两类：附加型与随机池型。后续如有明确必要，再增加新的天赋类型。

二者不是“稳定收益”和“高风险高收益”的关系，而是作用对象不同。

| 类型 | 作用对象 | 规则含义 | 示例 |
| --- | --- | --- | --- |
| 附加型天赋 | 一般属性模板 | 修改标准属性公式中的固定值或系数 | 根骨固定值 +2、体魄年龄曲线系数 +20%、神识固定值 +1 |
| 随机池型天赋 | 特殊属性随机池 | 替换或约束某类特殊属性的随机池 | 灵根只从五行单灵根池中随机，且最低品质不低于某阈值 |

随机池型天赋主要影响特殊属性。特殊属性本身就是随机生成的，因此随机池型天赋的作用不是“给一个更大但不稳定的数值范围”，而是替换特定随机池、限制随机下限、排除某些结果或提高某类特殊结果的出现概率。

示例“只会随机成五行单灵根且最低 5 品”仅用于理解随机池型天赋，不代表最终灵根系统一定采用“五行单灵根”或“品级”设定。

生成流程：

```
一般属性：
角色标准模板
+ 出生背景修正
+ 附加型天赋对固定值 / 系数的修正
+ 年龄%分段函数
= 本世一般属性

特殊属性：
基础随机池
+ 随机池型天赋替换 / 约束随机池
= 本世特殊属性
```

因此，附加型天赋和随机池型天赋不会冲突，也不存在谁是上位替代。前者负责稳定塑造一般属性，后者负责改变特殊属性的随机生成边界。

## 5. 转世流程

转世流程可以整理为：

```
本世结束或主动计划转世成立
→ 结算本世身躯与灵魂
→ 提取少量真灵成长
→ 记录轮回履历、失败原因与正式后手状态
→ 检查普通前世遗产与正式后手线索
→ 根据真灵强度计算执念容量
→ 玩家选择要携带的天赋标签与出生背景
→ 玩家无成本选择转世年龄、已知转世地域和已知附近宗门
→ 新身躯与新灵魂生成初始属性
→ 真灵觉醒
→ 下一世开始
```

转世触发来源暂定支持三类：

1. 寿元耗尽转世。
2. 突破失败转世。
3. 主动计划转世。

这个流程的关键是：

- 真灵负责“我仍然是我”。
- 执念负责“我能把哪些内生遗留带到下一世”。
- 无成本转世选项负责“这一世从哪里、几岁、靠近哪个宗门开始”。
- 身躯与灵魂负责“这一世具体能做什么、会付出什么代价”。

## 6. MVP 字段草案

### 6.1 真灵层 MVP 字段

```
TrueSpirit {
  true_name
  true_name_exposure_state
  true_spirit_strength
  obsession_capacity
  formal_legacy_limit
  reincarnation_log_refs
  dao_resonance_tags
  legacy_sense_log_refs
  formal_legacy_refs
}
```

MVP 中，真灵强度只承担两项核心数值价值：

1. 决定执念容量，即上一世到下一世的内生性可继承要素容量。
2. 决定正式后手的最大设置次数。

真灵强度不直接提高修炼效率。原因是：执念容量已经能让玩家携带更强或更多的天赋标签与出生背景，而这些初始化遗留会直接影响角色初始属性、修炼适配、突破短板分布和早期资源效率。如果再让真灵强度直接加成修炼效率，就会与执念容量形成冗余设计。

`true_name_exposure_state` 用于记录真名暴露状态。MVP 可先采用三档：`hidden`、`declared`、`exposed`。

### 6.2 执念层 MVP 字段

```
ObsessionPackage {
  source_life_id
  capacity_used
  carried_talent_tags
  carried_birth_background
}
```

MVP 中，执念只影响：

- 携带哪些天赋标签。
- 携带哪一种出生背景。
- 消耗多少执念容量。

转世年龄、转世地域和附近宗门不放入执念容量消耗中，而是作为本次转世的无成本基础选项记录在新角色初始化参数中。转世地域与附近宗门需要来自玩家已知信息范围，但不要求曾经亲身抵达。

```
ReincarnationStartOptions {
  awakening_age_type
  start_region_id
  nearby_faction_id
  known_region_required
  known_faction_required
}
```

附加型天赋作用于一般属性模板，修改固定值或年龄曲线系数；随机池型天赋作用于特殊属性生成，替换或约束特定随机池。

MVP 不实现独立灵魂修行路线，也不实现夺舍玩法。

## 7. 已收敛项与下沉到详细系统案的内容

### 7.1 已收敛项

1. 真灵强度只影响执念容量与正式后手最大设置次数，不直接提高修炼效率。
2. 道韵不按封闭路线树划分，而是对功法 / 术法 / 技能的标签提供加成；具体加成方式后续再定。
3. 执念容量只用于携带天赋标签与出生背景；转世年龄、转世地域、附近宗门不消耗执念容量。
4. 执念容量消耗不做均等化。不同天赋标签和出生背景的占用，应综合解锁难度、效果强度、稀有度和对开局效率的影响决定。
5. 天赋标签目前只保留两类：附加型与随机池型。后续确有必要时，再增加新类型。
6. 出生背景影响五类内容：初始资源、初始身份、家族关系、宗门关系、区域声望。
7. 转世地域与附近宗门限制为已知区域、已知宗门，但不要求玩家角色必须亲身抵达过。
8. 真灵因果系统暂不设计，相关常驻因果索引和负面倍率从本草稿移除。
9. 转世触发来源支持三类：寿元耗尽转世、突破失败转世、主动计划转世。
10. 真名前期默认隐藏于当世身份之后；中后期可以主动归本溯源宣告真名，也可以因高阶事件被动暴露。

### 7.2 下沉到详细系统案的内容

以下内容不在本核心体验草稿中继续展开：

1. 执念容量的具体公式、容量单位、标签占用和出生背景占用。
2. 一般属性标准模板的完整属性表、固定值、系数和年龄%分段函数。
3. 附加型天赋对固定值与系数的具体修正规则。
4. 随机池型天赋对特殊属性随机池的替换、约束和展示规则。
5. 出生背景的具体模板、数值、关系强度和区域声望规则。
6. 转世年龄、已知区域、已知宗门的候选生成规则。
7. 道韵对技能标签的具体加成方式、叠加规则、收益类型和上限。
8. 主动计划转世的触发条件、代价、收益和与寿元 / 突破失败转世之间的平衡。

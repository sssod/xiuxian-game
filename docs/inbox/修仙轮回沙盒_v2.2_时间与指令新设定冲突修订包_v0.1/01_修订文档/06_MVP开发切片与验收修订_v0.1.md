# MVP 开发切片与验收修订（v0.1）

> 替换范围：v2.2 `03_实现交付/02_MVP开发切片与验收清单_v2.2.md` 中 VS0、VS2、VS6、VS9 与时间推进、队列、托管、突破相关的验收项。

## 1. 切片总览修订

| 切片 | 原目标 | 修订后核心目标 |
|---|---|---|
| VS0 | 回合、权威结算、存档、日志 | 连续日历、速度状态机、权威 tick、存档、日志 |

## 2. VS0：技术底座修订

### 目标

建立可运行的连续日历房间和服务端权威 tick。

### 必做

```text
本地单人房间创建；
私人服务器运行；
WorldClock：world_day / world_hour；
TimeConfig：F1/N1/B1/P0 参数；
SpeedState：速度切换与中性 UI 原因；
服务器小时 tick；
P0 全局暂停；
B1 交锋轮调度；
LocalTimeStopState；
CatchupSettlementState；
TimelineReplay；
基础日志与存档。
```

### 验收

```text
能创建房间并进入 world_running；
world_hour 按 N1 推进；
全员长期低交互时进入 F1；
触发个人局部事件后事件玩家冻结，其他世界 N1；
gap 提示在 12h / 18h / 24h 正确触发；
事件结束后 C1 只补确定性内容；
触发正式交锋后进入 B1，1轮=1小时；
P0 下 world_hour 不推进；
Debug 面板能看到 speed_state、world_day、world_hour、local_time_stop、catchup、encounter。
```

删除旧验收：

```text
能配置每回合游戏天数，默认 5 天；
能配置决策倒计时，默认 120 秒；
能从个人行动阶段锁定；
能执行一次空结算进入下一回合。
```

## 3. VS2：个人行动经济与事件修订

### 目标

让玩家在连续日历中使用短行动队列，并通过局部时停处理普通个人事件。

### 必做

```text
当前执行指令 + 最多 3 条预输入；
入队时当前合法性校验；
执行前再次合法性校验；
队列为空 / 校验失败后自动兜底；
低风险自动吐纳，中高风险自动休整；
自动兜底强制 N1 且不参与 F1；
显式托管行动；
普通个人事件局部时停；
事件默认选项与 P0 同步保护；
C1 追赶补结算；
移动行动与路线事件按 world_hour 推进。
```

### 验收

```text
玩家能新增、删除、调整最多 3 条后续普通指令；
未满足条件的突破不能入队；
队列不会因为前序炼丹可能成功而允许后序使用丹药；
行动完成后下一条合法则自动执行；
下一条不合法时跳过、个人日志记录、自动兜底、降 N1；
自动吐纳 / 自动休整不会触发 F1；
显式托管 7 日在安全条件下可参与 F1；
普通个人事件中事件玩家 frozen_world_hour 不变，其他玩家继续 N1；
C1 追赶期间不触发新随机事件。
```

## 4. VS3：修炼与小境界修订

新增验收：

```text
闭关修炼、吐纳、养伤等长期低交互行动可触发 F1；
闭关三档预案能处理轻微药性波动 / 经脉负荷 / 杂念；
严重闭关异常不被预案吞掉，转入局部时停或 B1；
小境界选择作为普通个人事件处理，gap≤1日；
修炼资源输入仍按实际兼容小时结算，局部时停时玩家自身药性衰减暂停。
```

## 5. VS6：大境界突破修订

### 目标

跑通准备期、开启突破短指令、B1 突破挑战、结果报告。

### 必做

```text
突破准备期作为普通长期行动；
开启突破指令合法性校验；
当前已满足条件时才可预输入开启突破；
未预设时弹出局部时停确认；
默认选项为取消突破并进入休整待机；
突破挑战使用 FormalEncounterState；
B1：1轮=1小时，60秒提交窗口；
轮内默认突破策略；
真实资源消耗发生在挑战轮内；
突破结果不 P0；
公开影响进入宗门传闻 / 世界日志。
```

### 验收

```text
未达突破条件时，开启突破不可入队；
已达条件且地点、状态、道具合法时，开启突破可入队；
执行前道具缺失时，突破指令失败，不消耗道具，进入兜底并降 N1；
突破挑战开始后世界 B1；
5 轮突破消耗 5 游戏小时；
玩家未提交某轮时执行突破预设；
挑战结束后不进入 P0；
后续“疗伤 / 巩固 / 公开报备”等按普通个人事件处理。
```

删除旧验收：

```text
大境界突破作为固定执行时间持续行动；
关键突破物在行动开始时统一消耗；
突破结果作为 P0 优先报告。
```

## 6. VS9：3 人共玩修订

### 目标

验证多人共享日历、速度隐私、显式托管、局部时停和 B1 交锋。

### 必做

```text
3 人共享 world_day / world_hour；
速度状态只显示中性信息；
个人事件不暴露给其他玩家；
F1 只在全员显式长期低交互时出现；
任一玩家进入自动兜底则世界 N1；
局部时停 gap 上限；
B1 交锋所有玩家共享慢速；
P0 公共事件全员暂停；
显式托管可维持低关注玩家状态；
玩家不能看到其他玩家详细行动队列。
```

### 验收

```text
A 触发个人事件时，B/C 只看到当前速度：常态推进；
A gap 到 24 小时时自动默认或 P0 同步保护；
B/C 不知道 A 事件归因；
A 队列空转入自动吐纳时，F1 不再成立；
A 主动显式托管时，可在其他条件满足时参与 F1；
正式交锋期间非参战玩家也按 B1 世界时间推进；
玩家直接冲突进入 B1，不局部时停，不 P0。
```

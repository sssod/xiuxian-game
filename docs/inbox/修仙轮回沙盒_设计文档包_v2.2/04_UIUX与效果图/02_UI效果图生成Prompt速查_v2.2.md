# UI 效果图生成 Prompt 速查（v2.2）

**用途**：从 UI/UX 需求稿快速生成 ChatGPT / 图像工具可用的界面提示词。  
**画幅默认**：PC 横屏 16:9，1920×1080。  
**视觉默认**：古典修仙卷轴感 + 清晰策略面板 + 克制装饰 + 中高信息密度 + 分层折叠 + 地图观感优先。

## 2. 通用 Prompt 模板

```text
请生成一张 PC 横屏 16:9 的游戏 UI 效果图，分辨率参考 1920×1080。
题材是修仙轮回沙盒，类型是文字 / 策略 / 回合制决策游戏。
界面名称：{界面名}。
视觉风格：古典修仙卷轴感，清晰策略面板，克制装饰，中高信息密度但分层折叠，地图观感优先。
不要做成 MMORPG 热血战斗 HUD，不要做成纯视觉小说，不要做成现代金融仪表盘，不要做成纯 4X 战棋格子地图。
核心布局：{布局描述}。
必须包含：{核心组件}。
交互状态：{当前阶段 / 按钮状态 / 冻结状态 / 地图图层状态}。
强调玩家心智：先看世界地图变化，再决定本回合个人行动。
```

```text
中心是大世界地图画布，地图显示已探索区域、战争迷雾、传闻标记、宗门势力边界和当前角色位置。
顶部是回合阶段条：回合开始 → 信息处理 / 即时行动 → 个人行动 → 锁定提交，当前高亮“信息处理 / 即时行动”。
左侧是待处理变动中心，显示 P0/P1 风险、主目标相关变化、重要世界传闻数量。

视觉风格古典修仙卷轴感，清晰策略面板，地图观感优先。
```

## 4. 个人行动规划：地图点选目标

```text
修仙题材策略文字游戏 UI，个人行动规划阶段，PC 横屏 16:9，1920×1080。
中心是大世界地图画布，地图进入行动规划模式。
底部展开回合时间预算条：第1天、第2天、第3天、第4天、第5天。
玩家在地图上点击目标节点，地图显示从当前位置到目标节点的路线预估、移动方式、预计小时耗时、风险标签、权限门和状态门。
右侧节点上下文面板显示目标节点摘要、可达性状态、抵达后可能执行的持续行动。
底部预算条中已经写入一段移动行动和一段可选投入持续行动，例如“探索黑石岭，投入 3 天”。超过 1 天的可选投入行动使用 `< 1 > 天` 天数步进输入，中间数字可键入；短于或等于 1 天的行动显示固定耗时。
持续行动详情中展开“资源输入”折叠项，只显示与当前行动兼容的资源，例如主动吐纳可选择清灵丹，显示完整药性 12 小时、本次预计消耗 6 小时、剩余约 6 小时药性将暂留体内。
角色摘要区显示残余资源效果提示和主修锁定提醒，不使用全局丹药栏，不显示独立“丹药炼化”行动。
个人即时行动已冻结，界面提示如需处理即时事务需退回并清除行动草稿。
视觉风格古典修仙卷轴感，地图与时间轴联动明显。
```

## 5. 宗门面板：当前持续行动

```text
修仙题材策略文字游戏 UI，宗门面板，PC 横屏 16:9。
中心仍然是大世界地图，右侧打开宗门面板。
宗门面板页签为：宗门概览、宗门当前持续行动、库存与权限、资源申请、身份贡献、宗门日志。
当前选中“宗门当前持续行动”。主区域显示宗门当前重点：强化黑石岭驻守，进度40%，预计仍需约3回合，投入人力中，材料低，灵石低，风险为边境冲突升温。
面板下方显示可亲自介入机会：前往黑石岭驻守、协助调查。
不显示宗门经营命令，不显示宗门主行动输入，不显示玩家投票或建议。
地图上高亮黑石岭节点和宗门控制范围。
```

```text
中心是大世界地图画布，顶部从回合阶段条切换为结算动态进度条：结算开始 → 移动推进 → 行动执行 → 宗门AI → 节点事件 → 插入事件 → 结果回写 → 回合结束。

界面不提供主动暂停按钮。

```

```text
背景是大世界地图，结算已完成。

下方显示资源变化、状态变化、位置变化、宗门持续行动进展、下回合可延续行动。
视觉风格清晰、可信、适合文字策略游戏。
```

## 8. 锁定前风险确认

```text
修仙题材策略文字游戏 UI，锁定前风险确认弹窗，PC 横屏 16:9。
背景仍能看到大世界地图和底部回合时间预算条，但被轻微压暗。
弹窗分为四组：硬错误、高风险提醒、未处理高价值个人即时事务、重要世界传闻。
硬错误使用最醒目的层级并阻止提交。
高风险提醒包含主修即将锁定、残余药性可能散逸、稀有资源输入会在行动开始后消耗等提示。高风险提醒和未处理事务不阻止锁定，但需要玩家确认。
底部按钮为返回修改和确认锁定。
视觉风格克制、清晰、古典修仙卷轴感。
```

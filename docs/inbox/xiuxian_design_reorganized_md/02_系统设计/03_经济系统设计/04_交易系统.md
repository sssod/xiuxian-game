# 经济系统设计｜交易系统

## 1. 当前状态

交易系统当前只具备框架性约束，没有完整商店、市场、价格、税费或玩家交易规则表。

## 2. 已有结论

- 灵石是主经济循环通货。
- 低阶货币不进入修行世界主循环。
- 灵石可以兑换低阶货币，但低阶货币不应反向成为主要修行资源入口。
- 聚灵石不是货币面额，而是高密度灵气物品。
- NPC 不应在战斗或交易开始时临时生成完整库存。
- 店铺库存属于 ShopStock，不属于掌柜个人背包。
- 市场挂牌属于 MarketListing，必须有资产来源和日志。

## 3. 新手交易

第一阶段中，“准备干粮”适合用即时交易承载早期资源准备教学，不占用季度行动格。

## 4. 交易与抢劫边界

MVP 可保留店铺 / 仓库作为正式版可抢劫、查抄或洗劫对象的规则接口，但不实现完整抢劫玩法。抢劫目标应是 ShopStock / NodeStorage / EventLocked 等资产容器，而不是掌柜个人背包。

## 5. 缺口

- 商店模板。
- 市场挂牌规则。
- NPC 价格策略。
- 宗门采购 / 配给 / 俸禄价格口径。
- 玩家直接交易是否开放及其权限、日志和可见性。
- 通胀系数与价格显示 UI。

# NPC 设计

## 1. 当前定位

NPC 不应全量模拟成每人都有完整钱包、背包、消费偏好和逐小时生活的社会经济系统。MVP 应采用分层持久化。

核心问题：如果 NPC 战斗或交易开始时临时生成库存，会导致来源不可信、交易与战斗不一致、刷物品、宗门库存可信度下降、后手冲突和性能边界失控。

当前推荐：

```text
身份广覆盖
+ 库存分层持久化
+ 聚合经济流
+ 活跃集宏观模拟
+ 汇总结算
+ 事件相交局部精算
+ 惰性追赶
```

## 2. 分层持久化原则

| 层级 | 定位 | 个人资产口径 |
| --- | --- | --- |
| N0 | 抽象人群 / 劳力池 | 无独立身份或库存 |
| N1 | 轻量身份 NPC | 身份可持久化，通常无个人库存 |
| N2 | 功能服务 NPC | 服务入口，库存通常归机构、店铺、宗门或节点 |
| N3 | 关键角色 NPC | 状态、关系、关键资产、个人随身资产和宏观行动持久化 |
| N4 | 世界轴心 NPC / 势力代理 | 高优先级宏观行动、事件链、持久化资产和世界影响 |

N3 / N4 可持有真实个人随身资产、个人储藏或事件锁定资产。N2 若只是掌柜、摊主、管事、接引或服务 NPC，则不自动拥有其所代表的全部商店库存、宗门库存或节点库存。

NPC 同时只能有一个明确所属组织。MVP 阶段该所属组织一般为宗门，记录为宗门身份、职位、权限和关系；无明确组织时为空。家族不是宗门下级，也不是宗门之后的备用归属，而是与宗门同级的组织形态。MVP 不开发家族、帮派、商会、王朝官署等非宗门组织。

## 3. NPC 与机构库存

NPC 个人失败不等于组织资产全量失守。

错误口径：

```text
掌柜 = 商店库存持有人；
宗主 = 宗门库房持有人；
村长 = 节点仓库持有人。
```

正确口径：

```text
商店库存属于 shop_stock；
宗门库存属于 sect_storage；
节点库存属于 node_storage；
入口 NPC 只是服务入口、权限影响者或事件参与者。
```

机构资产的底层规则见《06_储物空间系统设计/03_库存系统》。商店与交易规则见《03_经济系统设计/04_交易系统》。

## 4. NPC 交易

玩家与非商店 NPC 交易必须使用持久化资产或事件明确锁定资产。

可交易来源：

1. NPC 已持久化的随身 / 可调用资产。
2. NPC 合法个人储藏或洞府库存中当前可调用的资产。
3. 事件链在结算前明确锁定的交易包、赔偿、赎买、赠予或奖励包。
4. 有预算来源并写入日志的轻量交易包。

禁止口径：

1. 交易开始时临时生成完整 NPC 库存。
2. 把商店货架写成掌柜个人背包。
3. 把宗门库房写成宗主或长老个人资产。
4. 用 NPC 个人交易绕过绑定、事件锁定、资源预留、后手封存或市场挂牌限制。

## 5. 战斗、死亡与资产

战斗可获得资产只来自：

1. NPC 已持久化的随身 / 可调用资产。
2. 事件链在结算前明确锁定的奖励包或掉落包。
3. 由事件预算生成的非个人库存奖励，且必须写入来源日志。

N3 / N4 死亡后，应先结算死亡事件链，再读取剩余资产容器。NPC 随身物品和 NPC 个人洞府库存属于遗产，需进入分配、继承、清点或回收流程；宗门托管 / 职务资产归宗门，不随个人死亡流失；普通藏宝按无主遗留设施处理；正式后手按真灵藏宝处理。

死亡遗产结算顺序：

```text
死亡事件链
→ 处理死亡原因、战斗损坏、遗失、封存、遗言和现场控制权
→ 结算父事件链明确指定的战利品、赔偿、赌注、任务结算和当场损失
→ 锁定剩余可继承资产
→ 分类处理宗门托管 / 职务资产、宗门管辖洞府库存、普通个人遗产、市场挂牌资产和正式后手
→ 按继承主体顺序选择一个最终接收主体
→ 写入资产流水、可见日志、隐藏世界日志、传闻或轮回账本
```

MVP 不展开复杂继承人关系网。除当场损失、宗门清点、职务回收、市场冻结和正式后手等例外外，普通个人遗产的剩余归属权整体移交给一个主体，不做多主体比例分配。

普通个人遗产继承顺位：

```text
道侣
→ 子嗣
→ 弟子
→ 所属组织（MVP 为宗门）
→ 世界
```

若前一顺位不存在、不可用、无继承资格或被事件链禁止继承，则顺延到下一顺位。所属组织只读取 NPC 当前唯一明确组织；MVP 阶段通常就是宗门。若未来开发家族或其他组织，它们也只占用同一个所属组织顺位，不作为宗门之后的额外继承层级。“世界”不是凭空生成预算，而是表示资产脱离可追踪个人 / 组织继承关系，可由事件模板转入无主遗留设施、传闻、隐藏层、市场回收、节点储藏或其他世界流转状态。

当场损失包括已由死亡事件链明确转移给胜利者、劫掠者、救援者或任务对象的资产，也包括战斗中损坏、破碎、消耗、遗失、污染、封禁、失效或转入事件锁定状态的资产。高价值物品、法宝、功法载体、突破资源和后手相关资产的转移必须写入可追踪记录。

NPC 死亡后的宗门相关遗产规则，同时用于玩家角色转世前留下的宗门个人洞府库存：宗门可锁定、清点并把普通库存回收到 `sect_storage` 或临时清点容器。该规则不适用于宗门外个人洞府、普通藏宝和真灵藏宝。

宗门外个人洞府和普通藏宝是无主遗留设施，后续只能通过钥匙、功法、线索、位置、事件条件或强行破阵开启，并可能被其他角色提前打开。正式后手资产按真灵藏宝处理，由同一真灵跨世感应和开启，不因普通死亡自动暴露，也不变成 NPC 掉落。

## 6. NPC 修炼追赶

N3 未进入活跃集时，不按固定宏观阶段逐项模拟完整修炼行动。重新进入活跃集时，用成长画像、俸禄 / 基础供给、闭关周期、风险画像和随机命名空间汇总修为变化。

N4 每个宏观周期应有个人宏观行动，但不得无条件增加宗门持续行动数量。若 N4 行动与玩家、宗门持续行动或关键节点交叉，进入事件链精算；若未交叉，用汇总结算写入状态、宗门倾向、传闻候选或隐藏世界日志。

## 7. 缺口

1. NPC 分层标准表。
2. NPC 关系、好感、性格与事件权重。
3. 宗门关键 NPC 和长老序列配置。
4. NPC 战斗模板与掉落 / 随身资产表。
5. 玩家与非商店 NPC 的议价、赠予、贿赂、债务、赎买和关系变化公式。

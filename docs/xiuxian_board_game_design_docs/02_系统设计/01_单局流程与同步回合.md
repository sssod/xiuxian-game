# 系统设计｜单局流程与同步回合

适用范围：房间大厅、正常外界回合、阶段计时与提交、回合开始更新、隐藏规划、同步移动、统一行动结算、内部时间成长、未响应安全默认、掉线 / 重连 / 托管、永久退出、全员离线和主动结束。

## 1. 房间大厅与开局

房主创建房间时设置目标席位 `2—4`。大厅本身没有强制结束倒计时；只有同时满足以下条件才开始 `10` 秒自动开局倒计时：

```text
目标席位全部有人
+ 每名玩家确认了一个未重复宗门
+ 全员准备
```

- 玩家准备前可自由选择或更换尚未被占用的宗门；准备后锁定当前宗门。
- 取消准备会解除开局锁定，但不自动放弃已占用宗门。
- 两名玩家近同时确认同一宗门时，按服务器 / 会话稳定收到顺序处理；落后者保持未选择并收到冲突提示。
- 任一玩家取消准备、掉线、离开，或宗门唯一条件失效时，倒计时立即取消。条件以后重新满足时，从完整 `10` 秒重新开始。
- 房主要以更少人数开局，必须先在未倒计时状态修改目标席位；房主不能强制开始、替他人准备或在倒计时中清除未准备席位。
- 条件保持到倒计时结束后自动开局，不要求房主二次确认。
- 房主离开大厅时，身份移交给当前最早加入且仍连接的玩家；无人可接替时关闭房间。
- 房主只管理大厅设置，在对局中没有暂停、踢出、结算、托管或终局特权。

该自由选择规则显式替代旧“随机生成顺序、玩家依次选择宗门”的方案。宗门与出生区域仍分别确定，详见《[宗门、地产与建筑经营](07_宗门地区经营.md)》与《[棋盘地图与移动](02_棋盘地图与移动.md)》。

## 2. 正常回合预算与阶段计时

每名玩家在正常回合拥有：

- 回合开始即时阶段内任意次当前合法的即时行动；
- 一次地图移动；
- 一个主要行动。

标准房间的基础输入时限为：

| 输入阶段 | 基础时限 |
| --- | ---: |
| 回合开始即时阶段 | `60` 秒 |
| 隐藏规划 | `90` 秒 |
| 抵达后的行动细节输入 | `45` 秒 |
| 事件强制选择、多人竞争等短响应 | `30` 秒 |

每名玩家另有 `180` 秒整局跨阶段个人思考储备。基础时限耗尽且本人尚未完成时才开始消耗；多名未完成玩家同时消耗各自储备，储备不按回合恢复。计时只在玩家已取得控制权并能够合法输入时运行，世界更新、移动演算、自动战斗、服务器结算和不可操作播放不占输入时间。

所有相关玩家提前完成时进入 `3` 秒收束倒计时；任一玩家在锁定前撤回，收束取消。房主不能在对局中改变标准计时。未来若提供快速 / 宽松预设，必须在开局前向全员公开并固定。

## 3. 回合阶段

### A. 回合开始更新

在玩家操作前，按当前外界回合处理：

1. 更新常规资源阶级开放上限；
2. 更新全局建筑等级，完成应在本回合开始建成或改建的建筑；
3. 启用因历史最高境界在上一回合提高而从本回合生效的低阶物品成熟；
4. 完成上一回合提交的炼丹 / 炼器订单；
5. 完成应在本回合开始发生的转世与死亡后地产收入交付；
6. 展示世界状态、待处理提醒和本回合全图灵气固定增量。

待退隐玩家本应取得的个人订单、收入或其它个人结果不写入其账户，按退出资产规则直接回收；地图建设等仍有公共意义的状态照常完成。

### B. 待退隐处理

世界更新完成后、即时阶段向任何玩家开放前，执行本回合所有待退隐角色。这是回合开始即时阶段的第一个系统步骤，也是正常流程中实际移除角色的唯一边界。

若主动退出或连续掉线阈值在当前即时阶段已经向玩家开放后才发生，只标记待退隐，延至下一外界回合的同一边界；角色不能在移动、行动、战斗、回合末或即时阶段中途被移除。

### C. 回合开始即时阶段

玩家可以学习功法道具、调整研习位与构筑、服用合法丹药、切换主修、处理宗门贡献、领取订单及整理资产。通用玩家交易和即时坊市购买不开放。结束即时阶段后，本轮研习位、主修与准备构筑按各自规则锁定。

即时阶段“完成”在阶段锁定前可以撤回；已经单独确认并立即结算的即时行动不因撤回完成状态而回滚，尚在编辑的未确认调整则被丢弃。

### D. 隐藏规划

玩家锁定目的地、路线、境界骰池 / 移动法门 / 移动法宝组合，以及主要行动类型。突破同时选定破境丹，固定小洞天同时锁定目标洞府。其他玩家只能看到提交状态，不能看到计划内容。

计划提交在阶段锁定前可以撤回。全部玩家提交后使用同一 `3` 秒收束；共同锁定前不公开任何隐藏输入。

### E. 同步移动

系统投掷或生成移动结果，在共享时间轴演算路径、收费关隘、停止位置与相遇。只有相关玩家因相遇或强制事件中断；无关玩家继续。移动阶段记录事件，选择与战斗延后到行动结算。

### F. 行动细节输入

合法抵达者为已承诺行动补充对象、数量、投入、商品、配方或其它参数。未抵达者不再输入。单人参数确认并开始结算后不能事后撤回；多人暗标或同时选择在所有相关玩家共同锁定前保持隐藏。

### G. 统一行动结算

独立行动分别结算；涉及复数玩家的竞争才暂停全局队列。竞争完成后从暂停点恢复。单人临时选择、单人 PVE 或独立渡劫不要求无关玩家重复提交。

### H. 回合末成长与世界结算

1. 对获得小洞天奖励的角色执行一次十个内部时间单位结算；其他角色执行一个内部时间单位。
2. 每个内部时间单位先自动修炼，处理小境界阈值与瓶颈，再自动研习；随后处理明确按内部时间推进的恢复、丹药持续、法宝炼化和寿元。
3. 瓶颈、重伤和死亡按成长规则限制收益；成功突破者当轮末从新境界取得第一笔标准 CP。
4. 结算有主节点稳定经营收益与本轮待结算地产收费，使其从下一回合即时阶段可用。
5. 处理事件要求的世界结果、固定地点小洞天投放和其它主题结算。
6. 回合末统一检查已完成飞升的共同胜利者。

未裁决更细的同层结算顺序时，内容模板不得依赖隐式先后获得额外收益。

## 4. 两段式承诺、锁定与安全默认

移动前只锁定出行计划和主要行动类型；抵达后才首次选择对象、数量、投入等参数。移动后不能更换行动类型。

规划时必须预检查当前已知的路线、元气、过路费、目标地点和行动最低条件；同步状态变化造成的费用不足按经济专题处理，不产生债务或强制出售。

输入计时与个人思考储备均耗尽时，使用无消费、无策略猜测、无额外收益的安全默认：

- **即时阶段**：保留已确认并结算的结果，丢弃未确认编辑并结束本人即时输入。
- **隐藏规划**：执行“留驻”——不移动、不使用移动资源、不执行主要行动，但正常参加回合末成长。不得自动提交屏幕草稿。
- **行动参数**：主动放弃已承诺行动，不支付未确认费用，也不取得“客观上没有任何合法参数”才有的代偿事件。
- **多人竞争**：不出价、不追加投入，或放弃该项可选竞争资格；已经按上位规则不可撤回的前置成本不返还。
- **强制事件选择**：每个模板必须预先指定无额外消费、风险最低且不改变他人资产的安全默认；没有合法安全默认的模板不得进入正式内容表。

## 5. 小洞天与暂停边界

小洞天只在取得奖励的当前回合末把该角色的内部时间单位数从 `1` 替换为 `10`。首轮没有后续回合继续停留、主动退出、关闭倒计时或强制返回分支；本次结算结束后入口关闭，下一外界回合角色恢复普通流程。

洞天十单位期间不能补换研习位或执行大境界突破。普通角色修为封顶于当前瓶颈；转世角色可以自动越过历史已完成突破。

通常只有涉及多个玩家的竞争处理暂停全局统一行动队列。单人战斗、独立渡劫、单人事件选择和参数输入只等待相关玩家。主动结束表决是唯一另行定义的全局暂停例外，见第 `9` 章。

## 6. 掉线、重连与 MVP 安全托管

每名玩家拥有独立于个人思考储备的断线保护：

```text
单次断线最多保护 60 秒
整局累计最多保护 180 秒
```

- 系统确认掉线后立即按现实时间消耗保护；掉线者的输入计时与思考储备冻结。
- 不依赖掉线者的输入、独立事件、独立 PVE 和界面查看继续；流程只有真正抵达共同锁点时才在剩余保护内等待。
- 在单次和累计保护均未耗尽前重连，玩家恢复同一席位和尚未锁定输入，继续使用断线前剩余的输入时间，不获得完整新时限。
- 任一保护额度耗尽且仍未重连时，当前输入立即采用安全默认并进入 MVP 无策略托管；以后需要输入时不再新增等待。
- 重连不回滚已经锁定、结算或托管产生的结果，只接管尚未锁定的本人输入。
- 追赶摘要只包含公开事件、本人资产 / 状态变化和托管动作，不泄露其他玩家隐藏计划、暗标或未公开选择。
- 掉线与托管状态向全体公开，但不公开其隐藏内容。

MVP 托管只继续已经锁定构筑下的自动战斗、回合末成长、恢复、炼化、寿元、地产与世界结算；不会主动移动、消费、竞价、换功、调整构筑、发起冲突或逃遁。玩家连接正常时可以主动开启或退出安全托管，但只能影响尚未锁定输入；房主不能操作他人托管。

未来单人模式策略 AI 成熟后，托管可以升级为只读取该席位合法信息的保守策略 AI，并作为主动降低操作 / 决策负担的辅助功能。该策略模型不属于 MVP，也不进入当前阶段门。

## 7. 永久退出、连续掉线与退隐

连接正常的玩家可以通过二次确认主动永久退出；断线、关闭客户端、断线保护耗尽或主动托管本身不等于永久退出。确认后立即永久放弃新的主动决策并标记待退隐：未锁定输入使用安全默认，已锁定移动、行动、竞争、战斗和事件因果链照常结算。

连续掉线另设不可回归阈值：

```text
60 / 180 秒断线保护：停止等待，进入临时托管
连续掉线 10 分钟：永久失去重连资格，标记待强制退隐
```

- 主动托管且连接正常时不累计连续掉线。
- 恢复连接会立即暂停累计；稳定连接满 `30` 秒后清零。稳定期内再次掉线则从先前累计继续。
- 达到 `10` 分钟的一刻立即永久失去重连资格；当前轮由托管继续，但不在阶段中途移除角色。
- 主动退出与强制退出都在第 `3.B` 节的最近一次合法回合开始边界实际退隐。若当前即时阶段已经开放，则延至下一回合。

退隐时：

- 角色、当前修为、状态、知识、掌握和全部个人数值停止维护；
- 随身灵石、物品、法宝、未学功法载体和未领取个人结果由系统回收；
- 退隐本身不产生死亡掉落；若角色在实际退隐前的已锁定战斗中死亡，仍按正常死亡结算；
- 个人订单和收入不建立幽灵账户；
- 地产保留为退隐宗门地产，稳定供养作废，原应支付给退出玩家的费用由系统回收；
- 已锁定公共建设状态照常完成；事件等正式规则以后仍可合法取得退隐地产，易主后按新玩家正常结算；
- 只剩一名未退隐玩家不自动胜利，仍须正常完成飞升。

## 8. 全员离线、会话协调与无存续玩家

对局中的房主 / 会话协调身份若离开或退隐，移交给当前最早加入且仍连接的未退隐玩家；该身份只维持连接职责，没有对局特权。

所有未退隐玩家暂时离线时，世界流程冻结，不让托管席位在无人观看时无限推进；连续掉线资格计时仍按现实时间继续。任一仍有重连资格的玩家恢复后，从保存状态继续。平台会话保存时长是未来产品配置，不改变玩法结果。

只要仍有一个席位未达到连续掉线 `10` 分钟，世界保持冻结并允许其重连。最后一个未退隐席位也达到阈值时，已无可恢复世界的玩家，不推进无人回合，直接按全员退隐记录“共同中止、无胜者”。这是无存续玩家时对回合开始退隐边界的唯一结果等价例外。

## 9. 主动结束表决

任一连接正常且未退隐玩家可以发起；同一外界回合最多一次。发起后立即进入真正的全局暂停：阶段计时、个人思考储备、断线保护、连续掉线累计、游戏输入、自动战斗、动画推进和所有游戏结算全部冻结。只有 `30` 秒表决、连接检测、重连和表决界面继续运行。

- 全部未退隐玩家必须亲自同意；掉线、MVP 托管、未来策略 AI、房主和会话协调身份都不能代投或取得额外票权。
- 表决只公开谁已响应、谁未响应和最终结果，不公开隐藏计划、暗标或未公开选择。
- 全员同意后进入 `3` 秒撤回缓冲；任一玩家撤回则取消。缓冲结束后决定不可撤销。
- 明确反对或 `30` 秒内未全员同意即失败，从暂停前同一确定状态恢复全部计时与结算。

结束生效点按隐藏规划是否已经全局锁定区分：

1. **规划尚未全局锁定**：完成当前已经开始的不可拆分即时结算后结束；未锁定计划与未确认草稿放弃，不产生支付或效果。
2. **规划已经全局锁定**：恢复并完整结算本外界回合，包括移动、行动、战斗、回合末成长与飞升判定。
3. 若完整结算中产生合法飞升者，优先记录正常飞升胜利；否则记录“共同中止、无胜者”。复盘可以展示最终状态，但不得按修为、地产、资产或战力生成替代名次。

## 10. 最小流程验算

以下边界必须在多人流程与内容验收中保留：

1. 大厅宗门冲突按稳定收到顺序处理；倒计时中掉线会取消倒计时。
2. 全员提交后的 `3` 秒内撤回会取消收束，隐藏内容不公开。
3. 规划超时执行留驻，不使用草稿、不消费移动资源，但仍正常成长。
4. 参数超时放弃行动，不冒充“客观无合法参数”取得代偿。
5. 断线保护内重连恢复剩余输入时间；保护耗尽后托管结果不可回滚。
6. 连续掉线 `9` 分 `50` 秒时重连会暂停累计；稳定不足 `30` 秒再次掉线则续算。
7. 主动退出或掉线阈值在回合 / 即时阶段中途发生时，只标记待退隐，不中途移除。
8. 退隐回合的个人订单、供养与收费直接回收，公共建设照常完成。
9. 全员暂时离线时世界冻结；最后一个席位达到阈值时不运行无人回合。
10. 结束表决失败后从原状态恢复；规划锁定后一致结束仍须完整结算本轮，并优先承认同轮合法飞升。

## 11. 当前缺口

- 同层世界结算若未来真实内容存在互相依赖时的正式顺序表；
- 每个强制选择事件模板的具体安全默认；
- 平台会话保存时长，以及是否提供快速 / 宽松房间预设；
- 未来单人模式保守策略 AI 的决策模型，不属于 MVP。

# 主题设计｜飞升胜利主题

适用范围：首个基础主题的单局目标、终局条件、飞升地点、终局公告与共同胜利。

## 1. 主题定位

首个主题以个人修仙竞速为主。玩家通过移动、行动、自动修炼、境界突破、资源获取和构筑竞争推进个人成长，最终达到大乘境界并在指定地点完成飞升。

标准局支持 `2—4` 人，目标现实时长 `45—60` 分钟；竞争为主、合作为辅，避免淘汰和长期压制成为主要乐趣。

## 2. 胜利流程

```text
提升修为与构筑
→ 完成各大境界突破
→ 达到大乘
→ 前往主题指定飞升地点
→ 通过飞升前置检查
→ 完成飞升行动
→ 回合末统一判定胜利
```

飞升是一个主要行动。玩家在移动前锁定“飞升”，合法抵达后不再选择对象、投入或其它参数。

## 3. 飞升前置与阻拦

1. 玩家必须达到大乘并抵达指定飞升地点。
2. 未抵达只表示本回合无法开始飞升，不属于飞升失败。
3. 仇敌相遇、地图控制或其它合法规则可以在飞升开始前阻拦玩家。
4. 前置战斗中死亡会触发转世；重伤或平局会使本回合飞升无法开始。
5. 前置普通战斗允许逃遁，除非事件明确禁逃。
6. 角色通过全部前置检查并正式开始飞升后，飞升不再失败，也不能被中途打断。

## 4. 大乘公告与信息边界

玩家首次达到大乘时公告：

- 该时点所在位置；
- 姓名、头像、所属宗门等基础身份。

不公告属性、资源、道功、持续状态或隐藏计划。公告后不提供额外持续追踪；后续位置继续遵守普通地图可见性。

## 5. 共同胜利

1. 任一玩家完成飞升后，当前回合继续结算。
2. 回合结束时，所有已经完成飞升的玩家共同获胜。
3. 多名大乘玩家同轮抵达飞升地点时，若彼此没有仇恨关系，不因争夺飞升资格自动触发竞争。
4. 到达先后只影响展示排序，不影响共同胜利资格。
5. 完成该次回合末判定后，本局结束。

## 6. 主题配置缺口

进入 MVP 配置前仍需确定：

- 首张地图与飞升地点；
- 大乘预期到达回合；
- 飞升地点周边的阻拦路线和地区控制机会；
- 首批主题事件、敌人、资源和奖励；
- 初始状态配置包；
- 主题属性、境界和移动数值表。

# 储物空间系统设计｜储物空间法宝

## 1. 当前状态

当前 Library 中未检索到储物空间法宝独立设计稿。本文件仅列出与 S9、经济系统、后手系统相关的约束。

## 2. 当前可确定边界

储物空间法宝不应在 MVP 中打破资产位置和日志规则。若存在，它应作为资产容器的一种特殊表现，而不是绕过库存、负重、交易、战斗和后手日志的万能背包。

可能映射：

```yaml
StorageArtifact:
  item_instance_id: string
  owner_ref: string
  contained_container_ref: CharacterStorage | EventLocked | SealedLegacy
  access_conditions: list
  bind_state: string
  visibility: string
  ledger_refs: list
```

## 3. 与后手系统

储物空间法宝可作为正式后手封存载体或前世遗产容器，但如果是正式后手，必须占用后手容量并具备可追踪日志、失效原因和追查路径。

## 4. 缺口

- 储物空间法宝是否进入 MVP。
- 是否允许战斗中取用储物空间物品。
- 储物空间与基础行囊、洞府储藏、宗门库存的权限边界。

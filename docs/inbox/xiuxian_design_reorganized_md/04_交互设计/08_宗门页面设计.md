# 交互设计｜宗门页面设计

## 必须表达

- 玩家身份：外门、内门、真传、执事、长老。
- 权限标签与资源申请资格。
- 宗门五类库存：灵石、修炼资源、材料/矿材、人力/弟子规模、声望/影响力。
- 每季度 1 个宗门主行动。
- 玩家建议、宗门 AI 采纳倾向、行动预览、执行完成度与结果日志。
- 宗门资源支持突破必须显示库存检查与预留状态。

## 多人边界

同宗玩家建议冲突不做复杂议会，按权限、职位、声望、贡献、宗门 AI 倾向等生成采纳倾向。

## 待补

- 宗门页面布局。
- 资源库存详情。
- 宗门行动结果报告。
- 贡献、声望、权限的 UI 映射。

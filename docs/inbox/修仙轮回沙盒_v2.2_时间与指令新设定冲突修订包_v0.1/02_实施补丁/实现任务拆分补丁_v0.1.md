# 实现任务拆分补丁（v0.1）

> 作用：给开发排期使用，将新时间 / 指令规则拆成可落地任务。

---

## 1. 后端 / 服务端

### T01 WorldClock 与 TimeConfig

- 实现 `world_day / world_hour`。
- 实现 N1/F1/B1/P0 参数。
- 移除普通推进对 `turn_duration_days` 的依赖。

验收：N1 下 15 秒推进 1 游戏小时；F1 下 2 秒推进 1 游戏日；P0 下不推进。

### T02 SpeedState

- 实现速度优先级 P0 > B1 > N1 > F1。
- 实现 F1 eligibility 判定。
- 自动兜底阻断 F1。
- 速度切换写日志。

### T03 CommandQueue

- 当前指令 + 最多 3 条预输入。
- 入队校验。
- 执行前校验。
- 队列失败日志。

### T04 FallbackState

- 队列空 / 校验失败生成兜底。
- 根据节点风险选择吐纳 / 休整。
- 强制 N1。
- `f1_eligible=false`。

### T05 LocalTimeStopState

- 事件玩家冻结。
- 外部 N1。
- gap 12/18/24 小时提示。
- 安全默认 / P0 同步保护。

### T06 CatchupSettlementState

- C1 确定性补结算。
- 禁止随机事件。
- 最多 2 秒补 1 游戏日。

### T07 FormalEncounterState

- B1 交锋轮。
- 60 秒倒计时。
- 默认策略。
- 硬上限 24 轮。

### T08 Breakthrough B1

- 开启突破短指令。
- 当前合法才可预输入。
- 挑战转入 `FormalEncounterState`。
- 资源消耗按轮执行。
- 结果不 P0。

## 2. 前端 / UI

### U01 顶部速度显示

- 世界日历。
- 速度图标。
- 中性速度提示。
- 不显示私人归因。

### U02 行动队列面板

- 当前行动。
- 后续 1～3。
- 兜底规则。
- 显式托管入口。

### U03 队列编辑

- F1 中打开编辑降 N1。
- 入队校验提示。
- 执行失败个人提示。

### U04 局部时停界面

- gap 显示。
- 12/18/24 小时提示。
- C1 追赶摘要。

### U05 B1 交锋界面

- 本轮态势。
- 60 秒提交窗口。
- 默认策略。
- 突破挑战专用资源提示。

## 3. 内容 / 数据

### D01 行动模板标签

每个行动模板需要标记：

```text
long_low_interaction: bool
f1_eligible_when_explicit: bool
can_be_auto_fallback: bool
risk_sensitive_fallback: bool
```

### D02 节点风险表

每个节点需有：

```text
risk_level: low | medium | high | unknown
safe_fallback_action: meditate | rest
```

### D03 事件时间模式

事件模板需标记：

```text
event_time_mode: info | local_time_stop | light_encounter | formal_encounter_b1 | global_pause_p0
safe_default_option_ref
p0_required_if_timeout
```

### D04 突破挑战模板

突破模板需拆：

```text
open_requirements
round_templates
default_strategy_options
round_resource_consumption
result_report_template
```

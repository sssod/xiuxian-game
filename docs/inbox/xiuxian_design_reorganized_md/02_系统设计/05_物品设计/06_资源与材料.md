# 物品设计｜资源与材料

## 1. 当前结论

MVP 不需要让所有资源都是具体物品实例。推荐层级：

- 宗门大宗资源可先抽象为库存数值。
- 节点自然产能可先作为 ResourcePool / ResourceSlot。
- 普通材料、丹药、符箓可作为可堆叠物品。
- 法宝、功法载体、正式后手物、高价值突破资源、带独立状态的物品应作为实例物品。

正式后手物指已封存进真灵藏宝的实例物品。它们可由同一真灵跨世感应和开启，但必须受真灵藏宝设置数量和单个容量限制。宗门个人洞府中的材料或资源可按宗门遗产清点回收；宗门外洞府和普通藏宝中的材料不按遗产回收，需满足开启条件或破阵结果后才能取出。

## 2. 宗门抽象资源

MVP 宗门追踪五类资源：

1. 灵石。
2. 修炼资源。
3. 材料 / 矿材。
4. 人力 / 弟子规模。
5. 声望 / 影响力。

声望 / 影响力不是货币，不直接兑换物品，而是行动修正、外部响应、控制权竞争和事件承担参数。人力不是物品，可被占用、损耗、恢复或转化为执行完成度修正。

## 3. 配方生产

```yaml
Recipe:
  recipe_id: string
  input_resources: list
  required_facility: string
  required_skill_tags: list
  action_cost: object
  output_profile: object
  byproduct_profile: object
  failure_profile: object
  random_allowed_fields: list
```

配方消耗明确资源，产出明确目标物品；随机只在配方允许范围内发生。

## 4. 缺口

- 材料 / 矿材分类表。
- 修炼资源与具体丹药、灵材、配给之间的转换规则。
- 配方表、设施需求、品质随机规则。

# UI/UX 需求方案（v2.3）

## 1. 主界面定位

主界面是大世界地图驱动的共享日历行动工作台。

玩家关注：

```text
当前世界时间；
当前公开速度；
当前行动；
后续 1～3 条预输入；
当前位置 / 节点风险；
当前兜底规则；
显式托管入口；
个人局部事件 / 交锋 / P0 的待处理状态；
日志、传闻、宗门、功法、物品入口。
```

本版只定义稳定 UI 需求，不绑定现有 Figma 主界面稿。

---

## 2. 顶部时间区

顶部显示：

```text
世界日历块
+ 当前速度图标
+ 当前速度名称
+ 当前角色摘要
+ 当前待处理状态入口
```

速度显示：

| 速度 | UI 文案 | 归因展示 |
|---|---|---|
| F1 | 高速推进 | 不显示具体玩家原因 |
| N1 | 常态推进 | 不显示私人事件或编辑归因 |
| B1 | 交锋慢速 | 公开交锋可显示事件名；隐秘交锋仅显示交锋慢速 |
| P0 | 全局暂停 | 可显示公共事件名或同步保护 |

F1 降到 N1 时，中性提示：

```text
进入常态推进
```

---

## 3. 地图主体

地图是第一视野主体，展示：

```text
当前节点；
可见路线；
已知通行状态；
节点风险；
资源槽摘要；
宗门影响；
秘境 / 机会窗口；
公开传闻；
队列目标路线；
玩家可见事件标记。
```

地图不得显示其他玩家私人事件来源。隐秘交锋、局部时停和私人突破只通过中性速度与公开后果体现。

---

## 4. 底部行动队列面板

底部队列面板显示：

```text
当前指令
后续 1
后续 2
后续 3
当前兜底规则
显式托管入口
```

示例：

```text
当前：闭关修炼《青木引气诀》10 日
后续 1：调息 2 日
后续 2：开启筑基突破
后续 3：空
兜底：低风险自动吐纳；中高风险自动休整
```

面板原则：

```text
看起来像简单队列；
不显示 if-else；
不显示预计未来满足条件；
不提供甘特图式长计划；
不把普通队列用于 B1 轮内选择。
```

---

## 5. 队列编辑交互

玩家打开普通指令输入界面时：

```text
F1 → 世界进入 N1；
N1 → 保持 N1；
B1 / P0 → 可编辑普通队列，但交锋轮选择 / 全局选择仍使用专用界面；
角色当前行动继续结算；
其他玩家界面只显示中性速度。
```

按钮建议：

| 功能 | UI 入口 |
|---|---|
| 编辑队列 | 队列面板主按钮 |
| 删除后续指令 | 队列项内删除 |
| 调整后续顺序 | 队列项拖拽或上移 / 下移 |
| 显式托管 | 队列面板右侧入口 |
| P0 公共确认 | P0 专用面板 |
| B1 本轮提交 | B1 专用面板 |

---

## 6. 入队校验提示

只提示当前是否合法。

示例：

```text
可入队：当前已满足筑基突破条件。
不可入队：当前未拥有筑基丹。
不可入队：当前地点不允许突破。
不可入队：当前灵力储备不足。
```

提示不展示未来推演、条件链和替代脚本。

---

## 7. 执行失败提示

仅给玩家个人提示。

示例：

```text
预输入指令未执行：开启筑基突破。
原因：缺少筑基丹。
已自动转入：吐纳。
世界进入常态推进，等待你输入新指令。
```

队列为空：

```text
队列已空。
当前处于低风险节点，已自动转入吐纳。
世界进入常态推进，等待你输入新指令。
```

---

## 8. 个人局部时停界面

事件玩家本人显示：

```text
你的时间已停滞
当前脱节：X 游戏小时
最大脱节：1 游戏日
```

gap 提示：

| gap | UI |
|---:|---|
| 0～12 小时 | 常规显示 |
| 12～18 小时 | 轻提示：世界正在继续推进 |
| 18～24 小时 | 强提示：即将执行默认处理或同步保护 |
| 24 小时 | 自动默认 / P0 同步保护 |

非事件玩家只显示：

```text
当前速度：常态推进
```

---

## 9. C1 追赶界面

事件结束后显示短摘要：

```text
正在追赶至当前世界时间……
补结算：6 游戏小时
```

追赶完成后显示：

```text
已同步至当前世界时间。
补结算内容：修炼进度、资源消耗、伤势恢复。
追赶期间未触发新随机事件。
```

---

## 10. B1 交锋界面

交锋顶部显示：

```text
当前速度：交锋慢速
第 N 轮 / 预计上限
本轮剩余：60 秒
本轮游戏时间：1 小时
```

每轮允许：

```text
提前提交；
倒计时结束前修改；
未提交则执行默认策略。
```

突破挑战使用相同 B1 框架，但文案为：

```text
突破挑战
本轮道基态势
本轮可用突破资源
当前突破预设
```

---

## 11. 显式托管预览

托管入口建议位于队列面板右侧。

点击后显示摘要，不立即提交：

```text
显式托管：7 日
当前位置风险：低
默认行动：托管吐纳
收益：低
会自动处理：普通邀约、普通传闻、低价值机会、轻微状态波动
不会自动处理：死亡风险、正式交锋、重大心魔、重大机缘、不可逆选择、大境界突破挑战、多人直接冲突、宗门重大事件
满足条件时可参与高速推进
```

---

## 12. 资源输入与残余效果

行动资源输入显示在具体行动编辑卡内。

显示内容：

```text
可投入资源；
资源来源容器；
兼容小时；
可能残余效果；
经脉压力；
相性提示；
入队校验状态；
执行前再次校验提示。
```

局部时停提示：

```text
局部时停期间，你的药性衰减暂停；外部世界继续推进。
C1 追赶时将补结算确定性药性衰减与兼容小时。
```

## 13. 日志入口

日志分类：

```text
队列变更；
入队校验；
执行前校验失败；
自动兜底；
显式托管；
速度切换；
局部时停；
gap 默认处理；
C1 追赶；
B1 交锋轮；
P0 全局事件；
宗门传闻；
节点变化；
资源消耗；
突破报告；
轮回账本。
```

私人日志仅自己可见；公开日志按可见性与传闻规则生成。

---

## 14. 主入口信息架构

建议主入口：

```text
地图；
队列；
角色；
功法；
物品；
宗门；
日志；
传闻；
Debug（开发模式）。
```

移动端或窄屏优先保留：

```text
顶部时间 / 速度；
地图；
当前行动；
队列抽屉；
日志提醒。
```

# INDEX｜重编后设计文档总索引

## 1. 本包定位

本包以《设计文档框架》为骨架，将当前 Library 中检索到的设计资料重新编排为长期维护文档。框架目标是“确保设计类内容以该结构组织，避免跨文档查询与冲突”。

## 2. 顶层稳定结论

- 项目是一款房间制多人修仙轮回沙盒，面向可保存、可续开、可局域网 / 私人服务器部署的长期方向。
- 玩家控制的核心不是宗门或国家，而是跨世延续的真灵 / 修士主体。
- MVP 当前边界：本地可单人测试、可部署私人服务器、支持 3 人共玩。
- 单人房是一等公民；多人是在单人 PvE 宗门沙盒基础上加入真实玩家变量。
- 当前行动经济采用“宗门行动阶段 + 角色行动阶段”的双层季度结构；角色每季度有 6 个朔望行动格。
- 技术路线为 Godot 客户端 + Godot Headless / Dedicated Server，服务端权威结算，规则与内容尽量数据驱动。

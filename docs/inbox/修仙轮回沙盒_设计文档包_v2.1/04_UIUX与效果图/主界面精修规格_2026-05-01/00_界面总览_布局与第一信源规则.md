## 1. 界面定位

本界面是 MVP 主循环中的大世界地图驱动回合行动工作台，处于“回合开始后的信息处理 / 个人即时行动”状态。

玩家在此界面完成：

- 阅读上一回合摘要和待处理变动。
- 确认当前角色状态。
- 判断当前位置、正在查看节点和计划目标。
- 处理仍可用的个人即时行动。
- 进入个人行动规划前做目标选择。

本界面不是角色详情页、宗门经营页或单独地图页。角色、宗门、地图、回合预算等信息必须围绕“大地图上的回合判断”服务。

## 3. 当前精修后的优先表达

首屏最重要的信息层级：

1. 当前处于哪个回合阶段。
2. 当前玩家角色是谁、境界如何、所属宗门与职位是什么。
3. 角色三项可行动状态：生机、元气、神念。
4. 当前地点、正在查看对象和计划目标。
5. 本回合仍可处理哪些变动 / 传闻 / 即时行动。
6. 能否进入个人行动规划。

## 4. 与 v2.1 UIUX 文档的关系

v2.1 UIUX 文档定义主界面的系统定位和总体结构。本组文档定义当前 Figma 精修稿的落地细节。

后续开发遇到冲突时：

- 主界面视觉布局、组件摆放、默认文案、状态表现，以本组文档为准。
- 回合、字段、结算、行动经济、宗门 AI 等系统语义，以 v2.1 系统文档为准。
- 不得重新引入 `quarter`、`action_slot`、`QuarterReplay`、宗门主行动输入或六朔望行动格。

## 5. 当前不落地为功能的内容

以下内容只作为界面状态表达，不代表本阶段已有完整实现：

- hover / click 后显示数值条具体数值。
- 全局入口按钮打开的账本、库存、宗门、日志、设置详细页面。
- 地图拖动、缩放、节点点击的完整运行时交互。
- 右侧目标模板自动推荐算法。
- 头像最终美术资源。

这些内容在实现时应保留接口和组件状态，但不得擅自扩展玩法逻辑。

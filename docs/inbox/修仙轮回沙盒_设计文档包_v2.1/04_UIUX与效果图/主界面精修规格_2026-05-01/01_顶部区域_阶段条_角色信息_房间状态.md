## 1. 顶部区域职责

顶部区域负责持续展示全局状态，但不得挤占地图判断空间。

包含：

- 左上角色信息卡。
- 顶部居中的回合阶段进度。
- 右上房间摘要。
- 决策倒计时与锁定状态。
- 全局入口按钮。

顶部区域不再显示 `时间暂停` 文本或状态胶囊。

### 3.2 已移除内容

`A-2` 圆形小标已移除。

原因：

- `A-2` 与 `炼气七层` 均容易被理解为角色境界或角色编号。
- 当前主界面只需要一处清晰境界表达。
- 若后续需要玩家席位编号，应重新设计为房间成员 / 多人状态的一部分，不放在角色境界旁。

### 3.3 头像表现

当前头像为临时 UI 占位：

- 外框：圆形，`52 x 52`。
- 底色：淡青绿。
- 内部：背光、头部、肩部和 `青` 字。
- 仅用于角色识别占位，不代表最终美术风格。

最终头像资源接入前，组件必须保留固定尺寸，避免角色卡布局抖动。

## 4. 生机 / 元气 / 神念数值条

状态条组节点：

```text
VitalsBars_LockedCap_Default
```

### 4.1 数据模型

每条状态条使用：

```text
当前值 / 保留值 / 最大值
```

字段语义：

| 字段 | 含义 |
|---|---|
| 当前值 | 当前可用状态值 |
| 保留值 | 被锁定、暂不可恢复的最大上限部分 |
| 最大值 | 理论最大容量 |
| 可恢复上限 | `最大值 - 保留值` |

重要规则：

```text
当前值 <= 最大值 - 保留值
```

示例：

```text
生机：当前 72 / 保留 20 / 最大 100
可恢复上限 = 80
数值条右侧 20% 显示为锁定段
当前填充最高只能到 80%
```

### 4.2 当前示例数据

| 名称 | 当前值 | 保留值 | 最大值 | 可恢复上限 |
|---|---:|---:|---:|---:|
| 生机 | 72 | 20 | 100 | 80 |
| 元气 | 58 | 8 | 80 | 72 |
| 神念 | 36 | 6 | 60 | 54 |

### 4.3 视觉结构

每条状态条由以下层级构成：

| 层级 | 作用 |
|---|---|
| 空槽 | 表示理论最大容量 |
| 当前填充 | 从左向右显示当前值 |
| 锁定上限段 | 紧贴数值条右侧，表示保留值 |
| 上限分割线 | 标记可恢复上限边界 |
| 隐藏数值浮层 | hover / click 后显示 `当前 / 保留 / 最大` |
| 命中区域 | 覆盖整条数值条，供 hover / click 使用 |

锁定上限段必须与空槽状态明显不同：

- 位置：始终贴在数值条右端。
- 宽度：`保留值 / 最大值 * 条宽`。
- 表现：灰褐半透明底 + 斜纹。
- 分割：左侧有可恢复上限分割线。

锁定上限段不是当前值上面的浅色覆盖层。

### 4.4 尺寸公式

状态条绘制基准：

```text
track_x = 44
track_width = 228
track_height = 9
```

实现公式：

```text
usable_max = max - reserved
clipped_current = min(current, usable_max)
fill_width = clipped_current / max * track_width
locked_x = track_x + usable_max / max * track_width
locked_width = reserved / max * track_width
```

当前 Figma 示例：

| 名称 | 当前填充宽度 | 锁定段 x | 锁定段宽度 |
|---|---:|---:|---:|
| 生机 | `164.16` | `226.4` | `45.6` |
| 元气 | `165.3` | `249.2` | `22.8` |
| 神念 | `136.8` | `249.2` | `22.8` |

### 4.5 数值显示方式

具体数值默认不常驻外露。

每条数值条有隐藏浮层：

```text
Vital_生机_ValueOverlay_HoverClick
Vital_元气_ValueOverlay_HoverClick
Vital_神念_ValueOverlay_HoverClick
```

交互规则：

- hover 数值条时显示浮层。
- 点击数值条时可固定显示浮层，再次点击或移出后收起。
- 浮层内容格式固定为 `当前 / 保留 / 最大`。
- 浮层压在数值条 UI 上方，不额外占用角色卡外部空间。

## 5. 阶段进度条

阶段条节点：

```text
TopPhaseBar_StageChips_Centered
```

布局：

- 必须相对整个 `1920 x 88` 顶部区域水平居中。
- 当前坐标为 `x = 715`，宽度 `491`。
- 不随左侧角色卡变宽而偏移。

阶段顺序：

```text
✓ 回合开始
✓ 报告阅读
● 信息处理 / 即时行动
⌕ 个人行动
⌕ 锁定提交
```

状态语义：

| 状态 | 表现 |
|---|---|
| 已完成 | 绿色浅底，绿色文字，前缀 `✓` |
| 当前阶段 | 深绿色底，白字，前缀 `●` |
| 未开始 | 米色底，灰色文字，前缀 `⌕` |

```text

```


- 轮回账本。

- 日志。

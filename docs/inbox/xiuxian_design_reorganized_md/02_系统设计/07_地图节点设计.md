# 地图节点设计

## 1. 当前结论

地图采用有向带权节点图。地图主单位是地理节点；资源和建筑挂载在地理节点的槽位层。

## 2. 节点字段

```yaml
WorldNode:
  node_id: string
  node_type: string
  region_id: string
  route_edges: list
  resource_slots: list
  building_slots: list
  control_state: object
  influence_state: object
  garrison_state: object
  event_slots: list
  hidden_layers: list
  legacy_layers: list
  danger_level: string
```

## 3. MVP 节点类型

- 山门。
- 城镇 / 坊市。
- 村庄。
- 资源节点。
- 荒野。
- 秘境入口。
- 前世后手 / 隐藏层。
- 禁地 / 高危节点。
- 道路 / 交通设施。

## 4. 控制权

节点归属采用“控制权 + 影响力”混合模型。控制权变更采用阈值 + 事件模型，玩家不需要逐个节点手动点击接管。

玩家可通过探索、驻守、建设、开采、处理事件、削弱对手影响力、宗门远征推动节点易主。

## 5. 隐藏层

隐藏层状态：

```text
unknown → rumored → located → partially_revealed → revealed → resolved
```

前世后手层在当前重整口径下拆分为三类：

1. 宗门个人洞府遗产清点层：玩家转世前留下的宗门个人洞府库存，按 NPC 死亡后的宗门相关遗产规则回收宗门。
2. 宗门外个人洞府 / 普通藏宝层：不按遗产回收，需要钥匙、功法、线索、位置、事件条件或破阵结果开启，可能被其他角色提前打开。
3. 真灵藏宝层：正式后手，由同一真灵跨世感应和开启，受设置数量与单个容量限制；MVP 阶段不展示被他人搬空、损坏或移动。

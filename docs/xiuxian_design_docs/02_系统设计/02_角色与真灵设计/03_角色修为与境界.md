# 系统设计｜角色修为与境界

## 1. 设计定位

角色修为与境界是当前世角色的显性成长主线，负责说明角色处于什么境界、如何确认小阶段进度、何时进入瓶颈、何时可以发起大境界突破，以及修为结果如何写入当前世状态和真灵轮回账本。

本文只维护系统层状态、阶段结构、突破边界、主修道功约束、玩家可决策入口和验收规则。玩家通过什么行动推进修炼由《修炼玩法设计》（`../11_修炼玩法设计.md`）维护；修为阈值、目标小时、修炼收益公式和调参边界由数值设计文档维护；突破挑战细节由《突破玩法设计》（`../14_突破玩法设计.md`）承接。

## 2. 当前结论

1. 修为与境界属于当前世角色状态；死亡或转世后，当前境界、当前修为、当前主修道功、普通资源和宗门职位不默认跨世继承。
2. 规则层以 `realm`、`minor_stage`、`current_realm_segment_id`、`cultivation_points / CP` 和 `normalized_segment_progress` 表达境界进度；表现层可以显示炼气、筑基、金丹等包装名。
3. 第一大境界采用 9 个小阶段，表现为 1-9 层；第二大境界开始采用 4 个小阶段，表现为初期 / 中期 / 后期 / 圆满。
4. 小境界升级主要承担节奏反馈、阶段确认、轻量收益和瓶颈引导，不进入完整突破事件链。
5. 大境界突破是核心玩法节点，必须由玩家主动发起，并进入准备、开启、B1 突破挑战和结果报告结构。
6. 主修道功锁定当前大境界修行根基；离开大境界第一小阶段后，本大境界主修道功默认锁定，直到下一大境界第一小阶段。
7. 法力是玩家感知的修为强弱，由各大境界记录按 `CP × 纯度 × 道功放大系数` 派生；境界推进和大境界突破入口看 CP，法力只作为战斗出力、突破事件内考验和风险预览的一部分。
8. 每个大境界保存独立修炼记录，记录本大境界主修道功、CP、纯度、放大系数快照、巩固条和法力；进入下一大境界后，上一记录锁定，普通巩固修为不能补历史纯度。

## 4. 核心循环或触发入口

修为与境界围绕“修炼推进 → 小阶段确认 → 瓶颈准备 → 大境界突破 → 结果回写”循环运行：

```text
当前世角色拥有 realm / minor_stage / cultivation_state
→ 玩家安排修炼行动或资源输入
→ 修炼系统按 hour_tick 结算 CultivationTickResult
→ 更新 cultivation_points、当前大境界 CP 和法力派生值
→ 达到小阶段上界时执行小境界升级判定
→ 达到当前大境界最终小阶段上界后进入瓶颈 / 突破准备
→ 玩家可选择巩固修为，提高当前大境界纯度和法力
→ 玩家主动发起突破短指令
→ 进入 B1 突破挑战
→ 合并突破结果包
→ 写入角色状态、日志、宗门传闻和轮回账本必要摘要
```

大境界突破流程固定为：

```text
准备期
→ 开启突破短指令
→ 突破挑战 B1
→ 个人结果报告
→ 后续选择
```

修为与境界的关键中断点包括小阶段上界、当前大境界圆满、突破条件不足、突破 B1 开始、突破结果合并、死亡 / 转世和主修道功锁定提示。

## 5. 规则与状态

### 5.1 境界结构

当前建议结构：

| 阶段编号 | 表现境界 | 小阶段结构 | 设计作用 |
| --- | --- | --- | --- |
| 0 | 凡人 / 锻体 | 可选 | 出身、教学、低阶 NPC 和剧情状态 |
| 1 | 炼气 | 1-9 层 | 新手阶段，快速建立修炼反馈 |
| 2 | 筑基 | 初期 / 中期 / 后期 / 圆满 | 第一次大境界质变 |
| 3 | 金丹 | 初期 / 中期 / 后期 / 圆满 | 宗门骨干、资源经营成型 |
| 4 | 元婴 | 初期 / 中期 / 后期 / 圆满 | 区域强者、宗门高层 |
| 5 | 化神 | 初期 / 中期 / 后期 / 圆满 | 第一阶段大后期 |
| 6 | 炼虚 | 初期 / 中期 / 后期 / 圆满 | 扩展阶段，世界层级跃迁 |
| 7 | 合体 | 初期 / 中期 / 后期 / 圆满 | 扩展阶段，大世界强者 |
| 8 | 大乘 | 初期 / 中期 / 后期 / 圆满 | 飞升前顶点 |
| 9 | 渡劫 / 飞升准备 | 劫数阶段 | 终局，不建议做成纯经验条 |

第一大境界的 9 层不要求均分，前期可以反馈更快，后期可以形成第一次瓶颈。第二大境界开始的四段也不要求按固定比例均分。

玩家看到的每个小阶段都显示为该小阶段自身进度 `0%-100%`。每个小阶段的 0% 与 100% 对应数值根表中的 CP 下界和上界。CP 字段名为 `cultivation_points`，表格和公式字段中可使用 `cp_` 前缀。

CP 管境界进度，法力管修为强弱。普通 UI 可以同时显示“修为进度”和“法力”，但不得把 CP 直接包装成战斗力。

系统设计层只规定“小阶段独立显示进度”和“大小阶段结构”，不规定具体数值比例、阶段上下界或修为绝对值上下界。具体阈值由《修为境界与期望游玩时间建模》（`../../03_数值设计/01_修为境界与期望游玩时间建模.md`）维护。

### 5.2 抽象编码与包装口径

早期文档中的 `A-1`、`B-1`、`C-1` 可以继续作为设计讨论中的抽象示例，但不作为最终唯一字段。

| 抽象示例 | 表现含义示例 | 说明 |
| --- | --- | --- |
| A-1 到 A-9 | 炼气 1-9 层 | 第一大境界九层结构 |
| B-1 到 B-4 | 筑基初期到圆满 | 第二大境界开始四段结构 |
| C-1 到 C-4 | 金丹初期到圆满 | 后续大境界沿用四段结构 |

若配置表需要保存抽象顺序，可用稳定排序字段派生；玩家界面优先展示包装名和阶段名。

### 5.3 小境界升级

小境界升级承担节奏反馈和阶段确认，不等同于大境界突破挑战。

小境界升级应满足：

1. 可在每小时修炼结算后自动判定。
2. 可按个人即时处理事件处理，但不进入完整突破事件链。
3. 不消耗关键突破物。
4. 不触发死亡、转世或重大不可逆惩罚。
5. 默认不进入 B1，除非特殊模板明确把小境界节点升级为高风险正式交锋。
6. 结果写入个人日志，必要时进入可见性系统或宗门传闻。

小境界升级收益保持轻量：

| 收益类型 | 说明 |
| --- | --- |
| 阶段推进 | 更新 `minor_stage`、当前境界段和进度归零 / 续接规则 |
| 小阶段倍率 | 调整当前大境界内的阶段倍率，例如初期、中期、后期、圆满的战斗表现差异 |
| 派生属性小幅提升 | 少量提高生机、元气、神念 |
| 功法效果解锁或强化 | 在主修道功支持范围内解锁少量被动、行动修正或提示型能力 |
| 瓶颈引导 | 提示距离大境界圆满、突破准备或主修道功锁定的关系 |
| 日志与可见性 | 写入角色日志；关键节点可生成中性传闻 |

小境界升级不应免费补发关键突破物、不改变大境界突破模板、不改变主修道功理论最高上限、不绕过主修道功支持范围，也不让阶段性不可追回收益被功法掌握度事后补回。

### 5.4 大境界突破

大境界突破用于把 CP 达标后的破境尝试、道功突破模板、资源承诺、明确属性验证、伤损结果和世界影响集中结算。开启突破只表示当前成长门槛、模板、资源和场景合法，并安排进入突破事件；未提交确认前不消耗突破专用道具。进入 B1 后，资源消耗和伤损发生在突破事件内。

开启大境界突破时，角色数值门槛只检查当前大境界 CP：

```text
current_realm_cp >= required_cp
```

还需要完成模板、资源和场景合法性检查：

```text
main_dao_method_supports_next_realm == true
locked_main_dao_method_breakthrough_template_available == true
required_breakthrough_resource_available == true
location_allows_breakthrough == true
```

法力、生机、元气、神念、体魄、精力、根骨和悟性不在开启阶段阻止突破；它们只在突破事件内部作为直接考验项。经脉压力、伤势、心境、心魔或根基类条件不作为本文默认开启门槛；伤势、经脉过载等状态只能通过持续状态修正上述明确属性后间接影响突破事件。

大境界突破成功后的永久收益由两类来源共同组成：

```text
境界基础收益
+ 道功突破模板收益
```

| 收益来源 | 主要内容 |
| --- | --- |
| 境界基础收益 | 进入新 `realm`、打开修为上限、提高寿元上限、提高基础派生状态、解锁更高阶资源、任务、宗门权限或行动入口 |
| 境界倍率 | 更新 `realm_power_multiplier`，形成进入新大境界后的战斗表现质变 |
| 属性质变 | 提高体魄、神识、灵力上限、经脉承载上限等核心承载能力 |
| 修为稳定度 | 新境界初入时 fullness / 稳定度较低，后续通过巩固境界提高 |
| 道功突破模板收益 | 由当前大境界锁定主修道功的突破模板决定路线收益、属性倾向、被动能力、资源转化方向和失败标签池 |
| 伤损与状态后果 | 突破过程中的伤势、元气亏损、神念受创或经脉过载只影响当前状态或恢复成本，不降低成功后的永久突破品质 |
| 世界与宗门影响 | 生成个人报告、宗门传闻、世界日志、身份变化或后续选择入口 |
| 轮回账本影响 | 记录重大突破、失败标签、最高境界和下一次修正方向 |

大境界突破结果主类型只保留：

1. 成功。
2. 失败存活。
3. 失败死亡。

成功但带伤表示新境界事实已经成立，境界基础收益和道功突破模板收益已经写入，只是当前战力被伤势、元气亏损、神念受创或经脉过载等状态暂时压制。它不是残缺突破，也不降低永久收益。

### 5.5 主修道功与境界边界

主修道功是本大境界修行根基。

已收敛规则：

1. 角色同一时间只有一个主修道功。
2. 主修道功只在大境界第一小阶段常规开放无时间成本更换，例如炼气 1 层、筑基初期、金丹初期。
3. 离开第一小阶段后，本大境界主修道功锁定，直到进入下一大境界第一小阶段。
4. 小境界升级必须受主修道功支持范围限制。
5. 若某道功只支持到某个小阶段上限，该道功不能把角色推进到下一小境界 0%。
6. 大境界突破读取当前大境界主修道功记录，用于计算突破模板、挑战倾向、路线收益和失败标签池。
7. 道功掌握度影响当前可修上限和单位时间修炼效率，但不改变理论最高上限、不改变大境界突破模板类型、不直接提高当前大境界纯度、法力放大系数或小境界升级奖励质量。

MVP 不在小境界升级关口插入“是否继续突破小阶段”的确认事件；主修锁定提醒应由修为摘要区、主修功法界面和常驻提示承担。

### 5.6 大境界修炼记录、纯度与法力

每个大境界保存一条修炼记录，用于固化本大境界主修道功、CP、纯度、道功放大系数和法力结果。

规则：

1. 当前大境界 CP 只统计本大境界内获得的 CP。
2. 当前大境界纯度只作用于当前大境界 CP。
3. 当前大境界法力由 `cp_total_in_realm × current_purity × mana_amplifier_snapshot` 派生。
4. 进入下一大境界后，上一大境界记录锁定。
5. 普通巩固修为只能修改当前大境界记录的 `consolidation_filled` 与 `current_purity`。
6. 普通巩固修为不能修改上一大境界纯度，也不能补救历史法力损失。
7. 稀有事件、特殊消耗品、高阶法门、剧情后手或宗门秘法若未来允许修改历史大境界纯度，必须单独写模板，不进入 MVP 默认循环。

当前总法力：

```text
total_mana = Σ major_realm_mana
```

若未来 CP 改为每个大境界内部局部值，需要单独裁决是否引入境界权重。

### 5.7 死亡、转世与轮回账本

修为与境界属于当前世角色状态。死亡与转世后，当前境界、当前修为、当前主修功法、普通资源和宗门职位不默认跨世继承。

死亡或转世后，应写入轮回账本的内容包括：

1. 本世最高境界。
2. 重大突破结果。
3. 失败标签与修正方向。
4. 宗门遗产清点结果。
5. 宗门外个人洞府 / 普通藏宝等无主遗留设施线索。
6. 真灵藏宝索引和必要履历。

真灵藏宝可由同一真灵跨世感应和开启，但受设置数量与单个容量限制，不等于前世普通资源自动继承。

## 6. 资源、角色、地图、事件或 NPC 接口

| 接口 | 读取 | 写入 |
| --- | --- | --- |
| 角色属性 | 体魄、精力、根骨、悟性、灵根、派生状态、寿元和持续状态导出的修正 | 境界收益、派生状态提升、寿元上限变化和突破伤损结果 |
| 主修道功 | 当前主修道功、掌握度、支持境界范围、功法标签和突破模板入口 | 主修锁定状态、路线收益、失败标签池和功法相关日志 |
| 修炼玩法 | 修炼行动、资源输入、巩固修为、闭关状态和 tick 结果 | CP 进度、法力派生、纯度变化、瓶颈状态、小阶段升级记录和可突破状态 |
| 突破玩法 | 突破开启条件、B1 挑战模板、轮内资源和结果类型 | 新境界、成功 / 失败 / 死亡结果、伤损状态、失败标签、后续选择和报告摘要 |
| 宗门与 NPC | 宗门身份、资源支持、突破地点、宗门传闻和权限规则 | 突破传闻、宗门身份变化、权限变化和供养关系反馈 |
| 地图与设施 | 洞府、灵地、突破地点、安全性和地点是否允许突破 | 地点消耗、公开动静、世界日志和节点风险变化 |
| 真灵与轮回 | 真灵身份、执念、轮回账本、后手和藏宝状态 | 最高境界、重大突破、失败标签、死亡转世摘要和后手线索 |

所有修为变化必须通过结果包合并，不允许修炼、突破、事件或资源系统绕过当前世角色状态直接改写境界事实。

## 7. 数据字段建议

| 字段 | 含义 |
| --- | --- |
| `CharacterState.realm` | 当前大境界事实字段 |
| `CharacterState.minor_stage` | 当前小阶段事实字段 |
| `CharacterState.cultivation_state` | 当前修炼状态结构 |
| `CultivationState.character_id` | 修炼状态所属当前世角色 |
| `CultivationState.realm` | 与角色事实字段同步的大境界 |
| `CultivationState.minor_stage` | 与角色事实字段同步的小阶段 |
| `CultivationState.current_realm_segment_id` | 当前境界段配置引用 |
| `CultivationState.normalized_segment_progress` | 当前小阶段标准化进度，普通 UI 可转成 0%-100% |
| `CultivationState.cultivation_points` | 当前累计 CP / 标准修为点 |
| `CultivationState.total_mana` | 当前总法力，可由各大境界记录求和派生或缓存 |
| `CultivationState.current_major_realm_record_id` | 当前大境界修炼记录引用 |
| `CultivationState.bottleneck_state` | `none`、`approaching` 或 `reached` |
| `CultivationState.meridian_pressure` | 经脉压力，用于药性容量、外源承载和体魄过载风险 |
| `CultivationState.resource_aura_input` | 最近或当前体内药性 / 资源灵气输入记录 |
| `CultivationState.last_settled_world_day` | 最近修炼结算世界日 |
| `CultivationState.last_settled_world_hour` | 最近修炼结算世界小时 |

建议结构：

```text
CharacterState {
  character_id: String
```

## 8. UI 展示边界

普通 UI 应展示：

1. 当前境界、当前小阶段、当前小阶段 CP 进度和瓶颈状态。
2. 当前法力、当前大境界纯度和巩固 CP 条摘要。
3. 当前主修道功、主修锁定状态、支持境界范围和必要提醒。
4. 达到瓶颈或进入突破准备后的 CP 门槛、突破模板、主要考验项、资源准备、地点要求和风险提示。
5. 小境界升级日志、大境界突破报告、成功 / 失败 / 死亡结果、当前伤损状态、失败标签和后续选择。
6. 必要的寿元、伤势、体内药性、经脉压力和药性容量摘要。

普通 UI 不应展示：

1. 境界段内部 ID、抽象编码作为唯一玩家理解入口。
2. 标准化进度、效率倍率、公式追踪、资源效果消耗明细和调参表。
3. 未揭示的真灵后手、他人突破归因、Debug 随机种子或内部结果包完整字段。

纯度、法力、巩固进度、经脉压力和心魔风险在达到大境界瓶颈、进入突破准备或触发相关事件后可以提高优先级；日常修为页仍可显示当前法力和纯度摘要。

## 9. MVP 范围

MVP 应实现：

1. 第一大境界到第二大境界的完整修炼体验。
2. 第一大境界 1-9 层、第二大境界初期 / 中期 / 后期 / 圆满的阶段结构。
3. `realm`、`minor_stage`、`cultivation_points`、`normalized_segment_progress` 和 `bottleneck_state`。
4. 当前大境界修炼记录、纯度、巩固 CP 条、法力和总法力摘要。
5. 每小时修炼结算后的小境界升级判定。
6. 主修道功在大境界第一小阶段开放更换，离开后锁定。
7. 大境界突破的准备期、开启短指令、B1 突破挑战入口和结果报告承接。
8. 成功、失败存活、失败死亡等基础结果类型。
9. 死亡 / 转世时把本世最高境界、重大突破和失败标签写入轮回账本。

MVP 不实现：

1. 渡劫 / 飞升终局完整玩法。
2. 小境界升级的高风险正式交锋模板。
3. 每个小阶段都插入确认事件。
4. 复杂多主修、并修、临时更换主修绕过锁定。
5. 当前境界、当前修为、当前主修道功或普通资源跨世自动继承。
6. 完整高阶宗门政治、飞升世界层级和所有境界的完整资源曲线。
7. 普通巩固修为修补历史大境界纯度。

## 10. 验收约束

1. 角色状态必须保存当前事实：`realm`、`minor_stage` 和 `CultivationState`；数值表负责成长规则，不把阈值散落进系统文档。
2. 普通 UI 必须显示每个小阶段自身 0%-100% 进度，不能把跨境界累计修为直接当成玩家主进度条。
3. CP 达标只能作为开启条件，不能把大境界突破做成单次概率按钮或自动升级。
4. 大境界突破必须由玩家主动发起，并进入突破挑战与结果报告结构。
5. 小境界升级默认不进入 B1，不触发死亡、转世或重大不可逆惩罚。
6. 小境界升级不得绕过主修道功支持范围，也不得改变主修道功理论最高上限。
7. 离开大境界第一小阶段后，本大境界主修道功必须锁定；任何例外都需要明确系统规则和代价。
8. 死亡与转世不得默认继承当前境界、当前修为、当前主修功法、普通资源和宗门职位。
9. 成功但带伤必须表达为“已突破 + 当前伤损状态”，不得降级为残缺突破或降低永久收益。
10. 公式、倍率、阈值、目标小时和调参验算不得在本文重复维护，应引用对应数值文档。
11. 法力必须由当前及历史大境界记录派生，不能用当前新道功回溯重算历史大境界法力。
12. 普通巩固修为不得修改已锁定大境界记录。

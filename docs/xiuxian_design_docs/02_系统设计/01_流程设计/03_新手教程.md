# 系统设计｜新手教程

## 1. 设计定位

本文固定首次进入游戏后的第一阶段教学流程，负责说明玩家如何从“真灵初次显化、当前角色低认知、低资源、低控制力”的状态开始，逐步理解真灵名、当前角色、地图、背包、货币、行动规划、移动、事件选择、功法学习和入门检测。

新手教程不是强制主线，也不替代房间创建、真灵初始化、角色初始化、行动指令、移动、事件、功法或宗门系统的完整规则。本文只维护第一阶段教学目标、教学节点、触发顺序、信息边界和最小验收链路。

## 2. 当前结论

1. 教程叙事以真灵和当世承载者为起点，不使用当前角色的家族、门第、职业或凡俗履历作为剧情锚点。
2. 玩家需要在第一阶段区分“真灵名”和“当前角色姓名”：真灵名关联跨世主体和主线，角色姓名关联本世操作与社会交互。
3. 第一阶段主循环从真灵初始化和当前角色创建开始，经起点区域、行动规划、基础学艺、远行移动事件和入门事件，进入外门弟子正式修炼循环。
4. 教程地点应读取初始化角色的出生位置；固定教学内容应以“起点区域”“附近入门节点”“可接触学艺点”组织，不硬绑定世俗身份。
5. MVP 新手阶段只一次性确认并展示角色生成时已确定的资质；机缘或特定场景中的资质遮蔽与再揭示属于后续扩展。

## 4. 核心循环或触发入口

第一阶段从玩家首次进入游戏房间并完成真灵选择开始：

```text
首次进入游戏房间
→ 真灵初始化：选择预设真灵名 / 自定义真灵名
→ 展示真灵背景故事
→ 创建初始化角色
→ 查看角色自知信息、初始日志与地图起点
→ 起点区域信息获取
→ 行动规划教学
→ 基础学艺 / 初始功法接触
→ 远行准备
→ 移动事件
→ 抵达入门节点
→ 执行特殊持续行动“拜入宗门”
→ 入门事件：登记姓名与来处 → 检测资质 → 判定分配 → 传授功法
→ 进入外门弟子正式修炼循环
```

第一阶段结束后，下一阶段建议承接为：

```text
外门日常
→ 选择功法修炼
→ 功法经验与境界进度
→ 宗门任务 / 资源获取
→ 首次瓶颈
→ 首次突破尝试
```

转世重修后的角色初始化教学不进入首次新手教程强制链路，但第一阶段 UI 与术语不能与后续转世规则冲突：

```text
本世结束 / 主动转世
→ 结算执念
→ 自定义新角色姓名、性别、年龄、出生大致区域与外观预选择
→ 消耗执念设定属性、出生具体位置与初始物资
→ 进入新世流程
```

## 5. 规则与状态

### 5.1 主体设定

教程叙事必须遵守新的主体设定：

- 玩家控制的当前角色是由真灵塑造出的当世承载者，不拥有世俗背景身份。
- 世界主线剧情直接与真灵、真灵名和真灵线索关联，不与当前角色的家族、门第、职业或凡俗履历关联。
- 初次角色可以有姓名、性别、年龄、出生位置、外观、属性和物资，但这些不是世俗身份。

当前角色面板只展示角色姓名、年龄、性别、出生位置、外观、已知状态与自知信息，不展示家庭背景、门第身份或凡俗职业。

### 5.2 真灵与初始化角色

教程第一步展示真灵初始化结果：

| 真灵入口 | 教程处理 | 角色初始化边界 |
| --- | --- | --- |
| 预设真灵名 | 展示专属真灵背景故事，并说明当前角色是该真灵第一次显化的当世承载者 | 使用预设属性、出生位置、性别、年龄与外观，只允许自定义角色姓名 |
| 自定义真灵名 | 展示通用真灵背景故事，并说明该真灵进入通用弱剧情线 | 使用通用预设属性与年龄，允许自定义角色姓名与性别，出生位置与外观随机生成 |

预设真灵名进入专属剧情线，自定义真灵名进入通用弱剧情线。教程只能解释当前入口差异，不能提前要求玩家完成真灵主线。

### 5.3 起点区域与基础信息

玩家以低认知状态进入世界，先通过角色日志、新手提示、起点区域交互理解基础 UI 与世界信息。

起点区域可以是村庄、小镇、荒野边缘、山门外围或其他安全教学节点。无论具体地点如何，都只承担空间、资源和操作教学，不承担世俗身份说明。

云麓宗、武馆、山路等仍可作为示例内容或默认教学路线，但不是由玩家角色的世俗身份触发。

### 5.4 行动规划、即时交易与结果包

行动规划教学闭环：

```text
移动行动 + 持续行动
→ 提交
→ 结算
→ 事件
→ 对话选择
→ 结果包
```

准备干粮通过即时行动 / 交易完成，不占用行动规划中的持续行动排期，用于教学“即时行动 vs 持续行动”。

第一阶段需要让玩家理解角色状态、日志、自知信息、隐藏信息、行动规划、即时行动、移动行动、持续行动、结算、事件选择和结果包之间的差异。

### 5.5 资源准备与基础学艺

教程需要让玩家理解资源准备，包括铜钱、干粮、功法学习成本和远行补给。

功法教学不只表达数值收益：轻身功法可支持逃遁，战斗功法可改善迎战反馈。基础学艺或初始功法接触只承担入门前教学，不提前展开完整功法成长系统。

### 5.6 远行移动事件

移动事件不是随机插曲，而是远行风险的主要承载方式。事件解决后应能返回移动主流程。

移动事件可以根据起点区域和目标入门节点变化，但不得以“玩家原本属于某个家族 / 职业 / 身份”为前置条件。

### 5.7 入门事件

抵达山门只是空间条件；身份改变来自“拜入宗门”特殊持续行动触发的入门事件。

入门事件中的登记步骤应登记姓名、年龄、来处和当前可公开信息。检测资质、判定分配、传授功法保留，但不登记或验证世俗背景身份。

新手失败分支如杂役、记名、被拒或凡俗路线只作为后续分支保留，不进入 MVP 第一阶段闭环。

### 5.8 真灵主线提示

第一阶段可以埋入一次轻量真灵主线提示，用于建立“世界主线与真灵相关”的认知。该提示不要求玩家完成主线，也不应压过行动、移动、资源和入门教学。

## 8. UI 展示边界

普通 UI 应展示真灵名、当前角色姓名、当前角色已知状态、角色日志、自知信息、起点区域、可用行动、行动提交反馈、即时交易入口、移动目标、事件选择、结果包摘要、入门检测结果和进入外门循环的明确反馈。

普通 UI 不展示家庭背景、门第身份、凡俗职业、隐藏真灵主线细节、Debug 随机种子、完整事件权重、完整资质公式、内部教程阶段 ID 或未揭示的后续转世参数。

教程提示只能解释当前玩家正在接触的操作和状态，不应把后续系统的完整规则提前塞入第一阶段。

## 9. MVP 范围

MVP 应实现：

1. 首次进入房间后的真灵初始化结果展示。
2. 当前世角色的姓名、年龄、性别、出生位置、外观、已知状态、自知信息和初始日志展示。
3. 起点区域基础信息获取。
4. 行动规划教学，覆盖移动行动、持续行动、提交、结算、事件选择和结果包。
5. 即时交易或即时行动准备干粮，并明确其不占用持续行动排期。
6. 一段可返回移动主流程的远行移动事件。
7. 通过“拜入宗门”特殊持续行动触发入门事件，完成登记、资质检测、分配和传授功法。
8. 第一阶段结束后进入外门弟子正式修炼循环。

MVP 不实现：

1. 强制主线任务链。
2. 基于家族、门第、职业或凡俗履历的教学前置条件。
3. 资质遮蔽与再揭示的复杂机缘分支。
4. 杂役、记名、被拒、凡俗路线等新手失败分支。
5. 转世重修初始化的完整交互教学。

## 10. 验收约束

1. 新手教程不能把当前角色写成具有世俗背景身份的主角；后续身份、关系和宗门地位必须来自实际游玩结果。
2. 真灵名和当前角色姓名必须在界面、日志和教程文本中保持区分。
3. 起点区域、远行事件和入门节点可以替换，但不得以家族、门第、职业或凡俗履历作为前置条件。
4. 即时交易与持续行动排期必须在教学中明确区分。
5. 移动事件结束后必须能返回移动主流程，不能把远行风险做成无回路插曲。
6. 入门事件必须由“拜入宗门”特殊持续行动触发；抵达山门本身只满足空间条件。
7. 资质检测在 MVP 中一次性确认并展示角色生成时已确定的资质，不引入复杂遮蔽分支。
8. 第一阶段结束时，玩家必须能进入外门弟子正式修炼循环。

# 字段迁移对照表（v2.1）

## 0. 文档定位

本文用于统一旧 sources 中 `quarter / action_slot / tick / sect_action` 等字段到新版回合制口径。

本表不是最终数据库 migration 脚本，但可作为实现阶段重命名、默认值补齐和兼容读取的依据。

---

## 1. 时间字段迁移

| 旧字段 / 旧概念 | 新字段 / 新概念 | 迁移说明 |
|---|---|---|
| `quarter` | `turn_id` | 若表示玩家最小同步回合，统一改为 `turn_id` |
| `current_quarter` | `current_turn_id` | 房间当前回合编号 |
| `created_quarter` | `created_turn_id` + `created_world_day` | 高价值记录建议补世界日 |
| `started_quarter` | `started_turn_id` + `started_world_hour` | 连续行动需要小时级起点 |
| `start_quarter` | `start_turn_id` | 资源预留 / 项目起点 |
| `expiry_quarter` | `expiry_turn_id` | 资源预留 / 事件窗口到期回合 |
| `failure_quarter` | `failure_turn_id` + `failure_world_day` | 后手失效记录 |
| `current_year + current_quarter` | `current_year + current_world_day + current_turn_id` | 年份保留为显示 / 寿元语境 |
| 世界季节 / 季度刷新 | `macro_period_id` / `season_id` | 若表示宏观周期，不迁为 `turn_id` |

---

## 2. 行动时间字段迁移

| 旧字段 / 旧概念 | 新字段 / 新概念 | 迁移说明 |
|---|---|---|
| `action_slot` | 废弃 | 不再作为规则单位 |
| `6 个朔望行动格` | `TurnTimeBudgetBar` | UI 改为天级预算条 |
| `remaining_action_slots` | `remaining_hours` | 结算内部剩余小时 |
| `base_cost_slots` | `base_travel_hours` | 路线基础耗时 |
| `consumed_ticks` | `consumed_hours` | 事件结果耗时 |
| `tick_index` | `hour_tick` / `world_hour` | 内部小时 tick |
| `quarter timeline` | `turn hourly timeline` | 回合小时级时间线 |
| `0–1 次持续行动限制` | 移除 | 改为实际耗时 + 内容入口控制 |
| `初始节点 + 第一个目标节点限制` | 移除 | 地点不再作为持续行动数量硬限制 |

---

## 3. 行动结构迁移

| 旧结构 / 字段 | 新结构 / 字段 | 说明 |
|---|---|---|
| `CharacterActionPlan` | `PersonalActionInstruction[]` | 玩家提交线性行动指令队列 |
| `ContinuousActionState.started_quarter` | `started_turn_id` + `started_world_hour` | 连续状态起点改为回合 + 小时 |
| `compatible_followup_actions` | 保留 | 用于跨回合延续 |
| `interruption_rules` | 保留 | 但应读取 `interrupt_policy` |
| 推荐执行时间 / 最小执行时间 | `duration_mode` + `fixed_required_hours` + `min_effective_hours` | 持续行动拆为固定与可选投入 |

新版核心结构：

```text
PersonalActionInstruction {
  instruction_id: String,
  actor_ref: String,
  action_type: String,
  action_template_id: String,
  target_node_id: String,
  duration_mode: String,
  planned_duration_hours: int,
  use_remaining_time: bool,
  fixed_required_hours: int,
  min_effective_hours: int,
  failure_policy: String,
  interrupt_policy: String,
  overflow_policy: String,
  auto_continue: bool,
  created_turn_id: int
}
```

## 4. 宗门字段迁移

| 旧字段 / 概念 | 新字段 / 概念 | 说明 |
|---|---|---|
| `current_main_action` | `active_continuous_action` | 宗门当前唯一持续行动 |
| `SectActionPlan` | `SectContinuousActionState` | 若表示宗门 AI 当前行动，迁移为持续行动状态 |
| `SectDecisionIntent` | 移除 | 玩家不再提交宗门主行动意图 |
| `propose_sect_action` | 移除 | 权限字段废弃 |
| `decide_sect_action` | 移除 | 权限字段废弃 |
| `player_intervention_intent` | `PersonalActionInstruction` with `sect_related` tag | 亲自介入改为个人行动 |
| 宗门经营命令 | 移除 | 不作为即时行动入口 |
| 宗门主行动反馈 | 宗门当前持续行动摘要 | 只显示 AI 行动状态，不显示采纳反馈 |

新版宗门结构：

```text
SectState {
  resource_stock: SectResourceStock,
  active_continuous_action: SectContinuousActionState,
  strategic_tendency: Dictionary,
  ai_memory_tags: Array
}
```

## 5. 事件字段迁移

| 旧字段 | 新字段 | 说明 |
|---|---|---|
| `EventContext.quarter` | `EventContext.turn_id` | 触发回合 |
| `EventContext.tick` | `EventContext.world_hour` / `local_hour_in_turn` | 触发小时 |
| `EventOutcome.consumed_ticks` | `EventOutcome.consumed_hours` | 事件耗时 |
| `interrupt_s3_plan` | `interrupt_plan` | 泛化为中断当前指令计划 |
| `remaining_action_slots` in interrupt context | `remaining_hours` | 剩余时间预算 |

---

## 6. 地图字段迁移

| 旧字段 | 新字段 | 说明 |
|---|---|---|
| `WorldState.current_quarter` | `current_turn_id` + `current_macro_period_id` | 区分玩家回合和世界宏观周期 |
| `TemporaryNode.created_quarter` | `created_turn_id` + `created_world_day` | 临时节点创建时间 |
| `RouteEdge.base_cost_slots` | `base_travel_hours` | 路线耗时以小时表达 |
| 每季度世界刷新 | 回合检查 + 宏观周期刷新 | 不把全部刷新绑定到每回合 |

## 7. 经济字段迁移

## 8. 后手字段迁移

## 9. 回放字段迁移

| 旧字段 / 结构 | 新字段 / 结构 |
|---|---|
| `QuarterReplay` | `TurnReplay` |
| `quarter` | `turn_id` |
| `submitted_decisions` | `submitted_instruction_queues` |

---

## 10. 推荐兼容策略

实现迁移时建议：

1. 数据加载层临时接受旧字段。
2. 读入后立即转换成 v2.1 运行时结构。
3. 保存时只写 v2.1 字段。
4. Debug 面板显示旧字段来源和默认补齐记录。
5. 对无法判断语义的旧 `quarter` 字段，必须人工标注是 `turn_id` 还是 `macro_period_id`。

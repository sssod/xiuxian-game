# 系统设计｜角色外观与人设

## 1. 设计定位

本文负责固定玩家当前世角色的外观、人设与身份表达边界，说明角色如何被看见、如何被称呼、当前身体状态如何记录，以及这些信息与真灵、转世、宗门身份和 UI 表达之间的关系。

本文只维护当前世承载者的可视、人设和初始化身份边界。真灵初始化流程由《真灵初始化与角色初始化流程》（`../01_流程设计/02_真灵初始化与角色初始化流程.md`）承接；真灵、执念和跨世主体规则由《真灵与执念》（`06_真灵与执念.md`）维护；属性、修为和数值收益不由本文定义。

## 2. 当前结论

1. 玩家控制的当前角色不再拥有世俗背景身份，而是真灵塑造出的当世承载者。
2. 角色外观与人设只描述“这一世如何被看见、如何被称呼、当前处于什么身体状态”，不描述家庭出身、门第身份、凡俗职业、官籍、族属关系或主线身份。
3. 世界主线剧情直接与真灵、真灵名和真灵线索关联，不与当前角色的世俗身份关联。
4. 当前角色可以在游玩过程中获得宗门身份、声望、关系和称号，但这些是游玩结果，不是初始化背景身份。
5. 外观只影响视觉呈现、角色识别和叙事氛围，不反向绑定真灵强度、修为收益或执念容量。

## 4. 核心循环或触发入口

角色外观与人设主要在三类入口中生成或更新：

```text
首次进入房间
→ 初始化真灵
→ 创建当前世角色
→ 写入姓名、年龄、性别或身体模板、出生位置、外观、初始属性与初始物资
→ 写入当前角色可见日志
→ 进入共享世界
```

```text
转世重修
→ 读取真灵与执念状态
→ 重新创建当前世角色
→ 玩家无成本设置姓名、性别、年龄、出生大致区域和外观预选择
→ 玩家可消耗执念设定属性、出生具体位置和初始物资
→ 写入新一世角色表达与转世记录
```

```text
游玩过程获得身份
→ 宗门、事件、关系或声望系统授予职位、称号、服饰或外显状态
→ 更新当前世角色表达
→ 不回写为初始化背景身份
```

## 5. 规则与状态

### 5.1 外观与人设边界

角色拥有当前姓名、年龄、寿元上限、性别或身体模板、出生位置、外观、初始属性与初始物资等初始化字段。

玩家角色初始化不生成家庭背景、门第身份、凡俗职业、官籍、族属关系或初始社会身份。出生位置只表示空间起点，不表示世俗身份。

玩家主体不是单一肉身，而是跨世延续的真灵；因此外观与人设应服务“本世承载者”和“跨世主体”的张力，而不是建立世俗背景身份。

真灵真名前期默认隐藏于当世身份之后；中后期可主动归本溯源宣告真名，也可能因高阶事件被动暴露。

### 5.2 初次角色外观规则

玩家第一次进入游戏房间时先初始化真灵，再创建初始化角色。

选择预设真灵名时：

1. 真灵名绑定专属剧情线。
2. 初始化角色使用该真灵名对应的预设角色属性、出生位置、性别、年龄与外观。
3. 玩家可以自定义当前角色姓名。
4. 外观可以具有与真灵剧情线相关的视觉特征，但不得写成家族血脉、门第身份或凡俗履历。

选择自定义真灵名时：

1. 真灵名进入通用弱剧情线。
2. 初始化角色使用通用预设角色属性与预设年龄。
3. 玩家可以自定义当前角色姓名与性别。
4. 出生位置与外观随机生成。
5. 随机外观池应保持可读、可区分、低资源开局感，但不生成世俗身份解释。

### 5.3 转世重修外观规则

转世重修后的角色需要重新初始化。玩家可无成本设置：

1. 当前角色姓名。
2. 性别。
3. 年龄。
4. 出生位置的大致区域。
5. 外观预选择。

玩家可消耗执念设定：

1. 角色属性。
2. 出生具体位置。
3. 初始物资。

外观预选择只决定当前身躯的视觉方向，不消耗执念，除非后续另行设定高稀有外观或特殊显化规则。执念不得用于购买世俗背景身份。

### 5.4 人设表现原则

当前角色可以有“气质”“体貌特征”“衣着状态”“行动姿态”等表现标签。

多世轮回可以保留弱相似气质或真灵共鸣感，但它应服务识别与叙事，不直接提供数值收益。

宗门服饰、称号、职位、关系和声望应由游玩过程赋予，并随当前世变化。

真名暴露后的 UI 与叙事表现应强调真灵层身份，不应补造当前角色的世俗背景。

## 6. 资源、角色、地图、事件或 NPC 接口

| 接口 | 读取 | 写入 |
| --- | --- | --- |
| 真灵初始化 | 真灵名类型、专属剧情线、通用弱剧情线、预设角色模板 | 当前世角色表达初态、真名可见性初态 |
| 角色属性 | 初始属性、寿元、可消耗执念设定项 | 与外观无直接收益绑定的角色展示字段 |
| 转世重修 | 真灵状态、执念可用量、上一世记录 | 新一世姓名、年龄、出生区域、外观预选择和转世表达记录 |
| 宗门与关系 | 宗门职位、称号、声望、关系、服饰来源 | 当前世可见身份、称号、服饰和关系表现 |
| 事件与剧情 | 真名暴露、归本溯源、高阶事件触发条件 | 真名可见性、外显状态和叙事表现变化 |

外观系统不得直接写入修为收益、真灵强度、执念容量、战斗倍率或资源产出倍率。

## 7. 数据字段建议

| 字段 | 含义 |
| --- | --- |
| `CharacterPresentation.character_id` | 当前世角色标识 |
| `CharacterPresentation.true_spirit_id` | 绑定的真灵标识 |
| `CharacterPresentation.display_name` | 当前世角色显示名 |
| `CharacterPresentation.init_context` | 初始化来源：首次预设真灵、首次自定义真灵或转世重修 |
| `CharacterPresentation.age` | 当前世年龄 |
| `CharacterPresentation.sex_or_body_template` | 性别或身体模板 |
| `CharacterPresentation.birth_region_id` | 出生大致区域 |
| `CharacterPresentation.birth_location_id` | 出生具体位置；可为空或随机 |
| `CharacterPresentation.sect_identity` | 游玩过程中获得的宗门身份；初始化阶段为空 |
| `CharacterPresentation.earned_titles` | 游玩过程中获得的称号列表 |
| `CharacterPresentation.appearance_tags` | 外观、气质、体貌特征等表现标签 |
| `CharacterPresentation.appearance_profile_id` | 外观模板或随机外观档案标识 |
| `CharacterPresentation.clothing_context_tags` | 衣着状态、宗门服饰或场景服饰标签 |
| `CharacterPresentation.true_name_visibility` | 真名可见性：隐藏、已宣告或被暴露 |
| `CharacterPresentation.has_secular_background_identity` | 是否拥有初始化世俗背景身份；玩家角色固定为 `false` |

禁用为玩家初始化字段：

| 字段 | 含义 |
| --- | --- |
| `birth_background_id` | 禁止生成出生背景身份 |
| `family_background_id` | 禁止生成家族背景身份 |
| `initial_social_identity` | 禁止生成初始社会身份 |
| `initial_secular_profession` | 禁止生成凡俗职业履历 |
| `main_story_identity_binding` | 禁止把当前世角色身份绑定为主线身份锚点 |

字段建议是实现提示，不等同于最终数据库或代码结构。

## 8. UI 展示边界

普通 UI 应展示当前世角色姓名、年龄、性别或身体模板、外观摘要、服饰状态、已获得的宗门身份、称号、关系摘要和真名可见状态。

普通 UI 不应展示或暗示角色拥有初始化世俗背景身份，也不应把出生位置解释成家族、门第、官籍、凡俗职业或主线身份来源。

外观模板标识、随机池权重、Debug 标签、内部剧情线标识、真名暴露触发条件和禁用字段校验结果只进入 Debug / QA 表达，不进入普通界面。

## 9. MVP 范围

MVP 应实现：

1. 首次进入房间时根据预设真灵名或自定义真灵名生成当前世角色表达。
2. 当前世角色姓名、年龄、性别或身体模板、出生位置、外观标签和真名可见性初态。
3. 转世重修时重新初始化当前世角色表达。
4. 宗门身份、称号和服饰作为游玩过程结果写入当前世表达。
5. 初始化阶段固定不生成世俗背景身份。

MVP 不实现：

1. 完整角色外貌生成器。
2. 年龄段形象自动变化。
3. 高稀有外观或特殊显化消耗规则。
4. 凡俗、外门、内门、真传、执事、长老等完整服饰层级。
5. 真名暴露后的完整专属 UI 与叙事演出。

## 10. 验收约束

1. 玩家角色初始化不得生成家庭背景、门第身份、凡俗职业、官籍、族属关系或初始社会身份。
2. 出生位置只能作为空间起点，不能被 UI、剧情或系统规则解释为世俗身份来源。
3. 外观、人设标签和外观模板不得直接提供真灵强度、修为收益、执念容量、战斗倍率或资源产出倍率。
4. 宗门职位、称号、关系和声望必须来自游玩过程，不能作为初始化背景写入。
5. 真名可见性必须区分隐藏、主动宣告和被动暴露，不能默认公开为当前世身份。
6. 转世重修时当前世角色表达必须重新初始化，但真灵主体和跨世记录仍由真灵系统承接。

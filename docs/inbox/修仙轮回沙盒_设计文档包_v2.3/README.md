**版本**：v2.3 calendar_preinput

**定位**：面向开发流程的连续日历制文档包。本文档包合并 v2.2 主包、时间规则与指令预输入规则，统一为共享世界日历、自适应流速、短指令队列、局部时停、B1 交锋轮与 `TimelineReplay` 数据契约。

---

## 1. 本交付包用途

本交付包是后续开发排期、原型实现、数据契约、验收与 QA 的当前本地依据。核心口径：

```text
共享日历房间
+ 自适应流速推进
+ 当前执行指令 + 最多 3 条预输入指令
+ 自动兜底与显式托管分离
+ 个人局部时停 + C1 追赶补结算
+ 正式交锋 / 突破挑战 B1 交锋轮
+ 宗门 AI 自行演化
+ 完整功法载体学习与掌握度成长
+ 丹药 / 灵材 / 符箓作为行动资源输入
+ 权威服务器小时 tick 与结果包回写
```

底层时间事实：

```text
1 游戏日 = 24 游戏小时
服务器最小结算单位 = 1 游戏小时
主时间字段 = world_day / world_hour
公开速度档位 = F1 / N1 / B1 / P0
内部追赶机制 = C1
```

当前包不引入现有 Figma 主界面稿作为版面依据。Figma 相关内容将在本包交付后另行迭代；本包中的 UI/UX 文档只描述稳定交互规则、信息结构、速度展示和队列控件要求。

# 系统设计｜自动战斗、竞价与逃遁

适用范围：战前构筑、自动执行、普通胜负、多人连续战斗、竞价入口、主动逃遁和战后资产结算。

## 1. 自动战斗定位

正式战斗采用冷却驱动、战前构筑、战中自动执行。旧五格指令预输入与战棋走位不属于本方案。

战前构筑包含：

- 当前主修一本道功；
- 最多 `5` 个法门招式位；
- 攻击、防御、飞遁三个固定类型法宝位；
- 道功、法门、攻击 / 防御法宝提供的统一招式列表；
- 玩家维护的从左到右触发顺序。

飞遁法宝提供常驻被动和逃遁加成，不提供循环释放的战斗招式。所有法宝效果受炼化门槛约束。

## 2. 招式来源与列表

1. 当前主修道功的已解锁招式自动进入列表；非主修道功招式不能使用。
2. 玩家从已解锁法门招式中装配最多 `5` 个。
3. 攻击与防御法宝在炼化程度高于 `50` 后提供招式。
4. 切换主修后，旧道功招式退出，新道功招式追加到列表末尾。
5. 道功预留 `5` 个来源位置；每件法宝预留 `2` 个来源位置，实际数量由模板决定。
6. 法宝招式不读取道功 / 法门掌握倍率。

## 3. 自动执行

1. 开战时所有具有冷却的招式先等待一次完整冷却。
2. 常驻被动从开战时生效，但法宝被动必须先满足炼化门槛。
3. 同一角色多个招式同刻就绪时，从列表左到右扫描。
4. 冷却未完成、资源不足、条件不成立或无合法目标的招式被跳过，不阻塞右侧。
5. 元气不足的已就绪招式保持等待；元气恢复后继续按左右顺序尝试。
6. 双方同刻有可触发招式时，由本场战斗随机种子决定双方先后。
7. 没有始终可用的基础攻击；低冷却招式承担持续输出职责。

意外战斗读取本回合移动前完成的配置，不在开战时重新开放换装、服丹或换主修。

## 4. 状态、胜负与平局

战斗直接读取并回写生机、元气、神念和持续状态，不在开战或战后自动回满。

普通结束条件：

```text
生机 <= 0 → 死亡并战败
否则神念 <= 0 → 重伤并战败
```

普通战斗最长 `60` 秒。超时且双方均未战败时直接平局，不比较剩余属性或伤害量。平局时双方保留状态、原定行动失败、竞争目标无人获得；飞升前置战平局不能开始飞升。

MVP 战斗效果只支持：

- 生机、元气或神念直接伤害；
- 护盾；
- 直接伤害增伤 Buff；
- 直接伤害减伤 Buff。

不支持命中、闪避、暴击、伤害浮动、元素克制、持续伤害或控制。

## 5. 护盾与持续状态摘要

护盾只保护生机，每场从 `0` 开始，来源相加，战后清空；连续战斗每场也重新清空。同一来源再次触发时补充至来源上限并刷新持续时间。受到伤害时优先扣除剩余持续时间最短的护盾来源。

Buff 可以配置最大层数和持续时间；再次生效刷新共享持续时间。可变数值 Buff 强制单层，新值无条件替代旧值。

## 6. 通用逃遁

除渡劫和事件明确禁逃外，普通战斗默认允许逃遁。逃遁是角色通用操作，不要求飞遁法宝或法门。

- 初次尝试可直接发起；失败后等待 `5` 秒才能重试；
- 失败使所有招式的当前剩余冷却各增加 `1` 秒；
- 成功立即脱离，视为战败并放弃原定主要行动；
- 成功后按移动文档选择默认相邻 `1` 格内合法地点免费移动；
- 渡劫战斗禁止逃遁。

基础成功率、飞遁法宝加成和随机规则见自动战斗数值文档。

## 7. 死亡资产结算

死亡角色失去全部随身可转移资产。每件独立物品或每个堆叠单位独立以 `10%` 概率成为战利品，剩余 `90%` 系统回收；胜者不能选择掉落物。

无合法玩家胜者时全部回收，不生成地图拾取物。连续战斗结束后统一判定所有阵亡者掉落并交给最终胜者，中间不结算。死亡掉落法宝对新归属者以炼化度 `0` 初始化。

## 8. MVP 缺口

自动战斗规则已稳定，但仍缺首批敌人、技能模板、冷却 / 成本表、正式 `C1/C2/K1_ref`、NPC 构筑逻辑和战斗验算用例。竞价仍缺支付、平价和提交细则。

# 修仙模拟棋盘｜独立设计文档包

适用范围：`2—4` 人、同步回合、地图扩张与个人飞升竞速的修仙题材棋盘模拟游戏方案。

## 1. 当前定位

本目录是独立、自包含的新方案设计包。当前已完成两轮裁决的专题回写：标准局目标 `90—120` 分钟、期望第 `24` 回合；六境成长；固定地图与地产经营；完整主要行动和经济框架；自动研习；标准 CP / 修为强度 / 掌握分层；统一总护盾；固定渡劫；转世重返；大厅、计时、掉线、托管、退隐与主动结束等规则均已归入专题正文。

设计开发仍冻结。本包当前用于继续关闭跨系统规则缺口、制作首张地图和正式内容 / 数值表，不授权修改运行时、客户端、工具、测试或平衡实现。

本包不修改、不覆盖 `docs/xiuxian_design_docs`。

## 3. 当前规则快照

- `2—4` 人；标准 `90—120` 分钟；合理胜利区间 `20—24—28`，无强制终局回合；
- 炼气、筑基、金丹、元婴、化神、大乘六境；炼气初期 `0%` 开局；
- 每回合一次移动、一个主要行动；同时规划、同步移动、统一结算；
- 固定六边格地图、四出生区域和共享竞争区；特定节点唯一主导宗门；
- 灵石占地与稳定供养是核心循环，建筑按回合自动升至四级；
- 通用玩家交易移除；坊市、采集、生产、购地、改建、小洞天、突破等使用主要行动；
- 一道功与三法门研习位自动成长，`B = 20`，五阶段掌握倍率；
- 标准 CP 只负责境界进度；修为强度读取 `S0 + 本世累计标准修为量`，普通改修不改变标准 CP 或境界；
- 筑基确定突破；之后四次进入固定难度渡劫，破境丹品级提供护劫护盾，允许逃遁；
- 普通与护劫护盾写入整场持续的统一总护盾，普通单次 `50%`、总量 `100%` 开战生命上限；
- 死亡后下一回合转世，知识、历史突破、贡献和地产保留，灵石与随身物品损失；
- 大厅满员且全员准备后 `10` 秒开局；标准阶段时限 `60 / 90 / 45 / 30` 秒，每人 `180` 秒思考储备；
- 断线保护 `60 / 180` 秒后进入 MVP 安全托管，连续掉线 `10` 分钟进入待退隐；所有实际退隐都发生在回合开始即时阶段；
- 达到大乘并在指定地点完成飞升主要行动获胜，同轮可共同胜利；全体一致可共同中止但无替代胜者。

详细例外和公式必须回到专题正文查阅。

## 4. 来源边界

1. 用户对新方案的明确裁决优先。
2. 本包已经回写的专题正文是当前口径；核心入口只提供摘要。
3. `docs/inbox/修仙模拟棋盘核心玩法_阶段稿_v0.1.md` 与 `docs/inbox/修仙模拟棋盘_行动修炼与自动战斗方案_v0.2.md` 只用于恢复思路和识别冲突。
4. `docs/xiuxian_design_docs` 只可作为历史参考；未在本包重新表述的旧规则不属于新方案。
5. handoff 只记录工作上下文，不提供当前规则。
6. 当前 UI artifact / Figma 只承接稳定界面决策的节点布局和组件位置，不决定玩法。

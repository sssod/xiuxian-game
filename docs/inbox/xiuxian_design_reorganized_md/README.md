# 修仙轮回沙盒｜设计文档重整包

本目录是当前设计文档修订基准，但不是最终定稿。后续文档工作应优先在本包内完成：细化规则、去重、修正引用、裁剪低价值或过时内容，并由人工主导关键取舍。

包外资料仅作为参考，包括 `docs/inbox` 中本包之外的材料，以及 `docs` 其他目录下的索引、正式文档和历史文档。参考资料中的有效信息如需采用，应改写并沉淀到本包内部，不应让本包依赖外部文件才能解释。

## 使用方式

1. 从 `00_INDEX/INDEX_总索引.md` 进入文档包。
2. 按主题修订对应文档，优先维护包内引用与主题边界。
3. 遇到来源冲突、重复口径、陈旧内容或无法机械判断的设计取舍，返回用户裁决。
4. 除非用户明确要求，不修改源码、运行配置、正式 docs 或 `docs/CHANGELOG.md`。

## 目录结构

- `00_INDEX/`：当前总索引。
- `02_系统设计/`：按框架重排的系统与玩法文档。
- `03_数值设计/`：数值模型、公式、投放与验算文档。
- `04_交互设计/`：页面与交互约束文档；节点级布局以当前 UI artifact / Figma 为准。

# 移动玩法设计

## 1. 当前结论

S3 决定玩家在共享世界日历中“人在哪里、能去哪里、做什么、花多少世界小时、冒多少风险、最后停在哪里”。移动行动是普通行动队列的重要指令类型。

## 2. 移动预览

移动预览应同时表达：

- 时间成本。
- 元气 / 状态成本。
- 补给成本。
- 路线风险。
- 中转与停靠规则。
- 事件触发可能性。

第一阶段中，远行准备通过干粮、轻身功法、战斗功法和山路事件教学移动风险。

## 3. 移动事件

移动事件覆盖：

- 离开节点。
- 进入节点。
- 途经节点。
- 目标节点。
- 每个移动结算段结束时所在路线段。

移动事件可产生遭遇战、路线阻断、资源消耗、信息发现、行踪暴露、延误或安全抵达。

## 4. 能力影响

- 轻身功法可支持逃遁和路径开销优化。
- 战斗功法可改善迎战反馈。
- 法门和道具可作为事件选项依据。

## 5. 缺口

- 路线权重公式。
- 交通设施模板。
- 补给消耗公式。
- 移动风险概率与事件候选池。

# 数值设计｜数值验算

## 1. 当前验算目标

数值验算应回答核心问题：

> 当前世代在当前境界段的实际效率，是否高于、等于或低于设计基准？

当效率低于基准时，轮回应变得有价值；当效率高于基准时，继续修行必须仍然合理。

## 2. 推荐验算链

```text
RealmSegmentBalance
→ benchmark hour rate
→ 行动规划样例
→ 资源输入样例
→ 状态压力样例
→ 突破资格样例
→ 突破挑战初始分数
→ 轮回效率判断
```

## 3. 必测场景

- 无资源普通修炼。
- 宗门静室 + 普通丹药修炼。
- 高价值资源集中闭关。
- 行动被事件打断后的残余药性处理。
- 小境界升级。
- 大境界突破资格。
- 低效率世代转世收益。
- 高效率世代继续修行收益。

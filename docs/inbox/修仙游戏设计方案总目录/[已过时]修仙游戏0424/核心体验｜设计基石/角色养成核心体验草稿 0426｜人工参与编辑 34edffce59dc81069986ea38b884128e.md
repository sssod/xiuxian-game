## 1. 已读取并继承的上位约束

### 1.1 核心体验约束

- 修为提升不是孤立数值增长，而是提高本世资源获取效率。
- 瓶颈与突破负责把玩家从线性修炼推入多系统准备。
- 转世重修的价值在于用前世资本塑造更好基础，使下一世同境界效率更高。
- 同境界下的“更强、更快、更富、更有准备”必须可感知。

### 1.2 角色与轮回约束

- 玩家主体分为真灵、执念、身躯与灵魂三层。
- 当前修为、当前功法等级、当前背包、当前宗门职位等属于本世身躯与灵魂，不默认跨世继承。
- 跨世影响主要通过真灵强度、执念容量、天赋标签、出生背景、轮回账本、前世经验、道韵与正式后手实现。
- 资质不是一个单独总评分，而应拆成具体子项，例如根骨、悟性、灵根等。
- 寿元是当前世角色的时间预算，也是修炼、突破、延寿、转世决策的核心压力来源。
- 根骨与悟性允许通过后天条件改变，否则会把先天随机与执念容量压力推得过重。
- 灵根在 MVP 中不支持后天修改，只作为先天生成、执念遗留或特殊开局结果参与适配判定。

### 1.3 行动经济约束

- 世界以季度推进，一个季度有 6 个朔望行动格。
- 修炼、闭关、探索、后手回收等属于持续行动，由 tick 推进收益、进度或事件入口。
- Tick 是统一时间单位，不是统一收益公式。
- 高收益修炼应依赖洞府、灵气节点、宗门设施、修炼资源、闭关条件或秘境环境。
- 插入事件链可以中断行动时间轴；重大突破通常接管本季度剩余行动。

### 1.4 突破与物品约束

- 突破准备读取修为积累、修为纯度、肉身承载、心境、功法匹配、突破资源、护法、地点灵气、宗门支持等维度。
- 功法 / 术法载体是物品，学习后进入角色能力系统。
- 丹药、修炼资源、突破资源、法宝、消耗道具等都应通过资源使用接口进入事件或行动结算。
- 物品、功法、资质子项等可统一使用阶级 Tier + 品级 Quality 表达，但规则层仍避免绑定具体修仙包装。

## 2. 一句话定位

> 角色养成的核心体验，是玩家围绕“灵气摄入 → 功法转化 → 修为储存 → 上限约束 → 功法 / 资源 / 环境 / 资质 / 寿元优化”持续做选择，并把每一轮优化转化为更高资源获取效率与同境界战力。
> 

角色不是简单刷经验升级。玩家应该逐渐理解：

```
我为什么修炼？
→ 为了提高本世资源获取效率与同境界生存 / 行动能力。

我为什么要选功法、找洞府、用丹药、布置聚灵阵？
→ 为了提高单位行动格内的修为收益、资源利用率和功法加成质量。

我为什么要提升功法等级？
→ 为了解锁当前修为上限、提高吸收 / 转化表现，并改善突破准备。

我为什么要转世改善资质或前期功法路线？
→ 因为同样达到前世修为时，更好的前期功法与突破质量会留下更强根基，使同境界战力更高。
```

## 3. 核心体验目标

### 3.1 修炼是“资源转化效率”玩法

修炼不是把时间直接换经验，而是把外界灵气、丹药药力、地点条件、功法能力和角色资质共同转化为修为与功法加成。

玩家每次规划修炼时，理想上都能判断：

- 当前地点灵气是否值得修炼。
- 主修道功是否适合当前阶段。
- 是继续吐纳，还是先研习功法提高上限。
- 是直接吃丹药，还是等到更高转化率后再吃。
- 是在普通节点修炼，还是花行动格前往宗门静室、洞府、灵脉或秘境。
- 是堆积当前修为，还是准备突破、延寿、转修或转世优化基础。

### 3.2 好资质不是单纯“速度更快”

资质好的角色不只是每 tick 获得更多修为，还应体现为：

- 同样修为进度消耗更少外部灵气或丹药。
- 同样丹药药力产生更少逸散损失。
- 更容易适配高阶或特殊功法。
- 更容易在突破准备中补足关键短板。
- 更容易把修炼资源转化成稳定、纯净、可突破的修为。

### 3.3 主修道功是路线身份，不是普通技能

主修道功决定角色如何吸收灵气、如何转化修为、能达到多高上限，以及拥有哪些被动生效能力。

玩家选择主修道功，本质是在选择当前大境界的修炼路线：

- 偏快修但纯度较低。
- 偏慢修但突破更稳。
- 偏环境依赖，适合特定灵气节点。
- 偏丹药转化，适合资源富裕路线。
- 偏生存，被动提供护身、辟谷、解毒等效果。
- 偏神魂，神念成长、心魔抵抗或神魂攻防更强。
- 偏后期，早期效率低但高阶段上限更好。

## 4. 核心概念定义

### 4.1 修为

修为是本世角色的阶段性成长进度，数据层建议拆为：

```
CultivationState {
  current_stage_code          // A-1 / A-2 / B-1 等
  cultivation_progress        // 当前阶段内进度
  cultivation_purity          // 修为纯度，影响突破准备；平时隐藏，到大阶段瓶颈后显示
  purity_visibility_state     // hidden / visible_at_major_bottleneck
  bottleneck_state            // none / soft_cap / breakthrough_required 等
  main_daogong_ref            // 当前主修道功
  major_method_record_refs    // 每个大境界锁定 / 记录的主修道功，用于计算固化根基
  progress_cap_context        // 当前修为上限来源
}
```

MVP 可以先只显示阶段与进度。`cultivation_purity` 数据层保留，但平时隐藏；当角色达到大阶段瓶颈、进入突破准备语境时再显示。

原因是修为纯度在平时波动较大、影响较小，属于低价值干扰信息；到达瓶颈后，玩家开始准备突破，并且拥有巩固、提纯等修正途径，纯度信息才具有明确决策价值。

### 4.2 灵气

灵气是修为增长的主要外部输入，不等于货币灵石。

灵气可以来自：

- 环境背景浓度。
- 节点灵脉、洞府、宗门静室、秘境等地点条件。
- 聚灵阵等固定浓度加成。
- 定向吸收类加成。
- 丹药、灵液、灵米、修炼配给等修炼资源。
- 特殊事件或后手释放的灵气。

### 4.3 道功

道功是具备修为提升效果的功法。

```
DaoGong {
  method_id
  tier_code
  quality_code
  method_tags
  stage_support_range
  level_cap_profile
  absorption_profile
  conversion_profile
  passive_effect_refs
  breakthrough_support_profile
  compatibility_requirements
}
```

道功的规则口径：

- 只有道功可以被设为主修功法。
- 只有当前主修道功提供被动生效能力。
- 道功至少提供“自动运转 / 被动吸收”的基础能力。
- 道功可以额外提供辟谷、驻颜、护身、解毒、凝神、藏息等被动效果。
- 道功的阶级与品级决定其最终上限、突破支持质量和成长潜力。
- 道功当前等级决定角色当前能触达的修为上限。

### 4.4 法门

法门是不具备修为提升效果的功法 / 技艺 / 术法体系。

法门可以提供：

- 战斗指令。
- 非战斗能力。
- 采集、炼丹、炼器、阵法、医术、卜算等技艺成长。
- 特定事件选择。
- 资源获取效率或风险降低。

但法门不能被设为主修功法，也不会直接推动修为进度。

### 4.5 主修道功

主修道功是角色当前正在运转并以内化修为为目标的核心功法。

规则口径：

- 同一时间只能有一个主修道功。
- 只有具备修为提升效果的道功能被设为主修道功。
- 主修道功决定被动吸收、主动吐纳、丹药炼化、当前修为上限与部分突破匹配。
- 未设主修道功时，角色不能获得正常修为增长；只能进行低效基础吐纳或新手特殊流程。
- 主修道功不等于装备栏，不占用装备位，也不阻止角色使用法门、法宝或道具。

### 4.6 寿元

寿元是当前世角色的最大时间预算，不只是死亡倒计时。

```
LifespanState {
  age                         // 当前年龄
  lifespan_limit              // 当前寿元上限
  aging_phase                 // 幼年 / 壮年 / 衰老等阶段，可按年龄%派生
  lifespan_pressure_state     // safe / pressured / urgent / exhausted
  lifespan_extension_sources  // 已生效的延寿来源记录
  lifespan_risk_tags          // 寿元折损、道伤、衰败、燃寿等风险标签
}
```

寿元与修炼玩法的关系：

- 角色需要在寿元耗尽前完成修炼、积累、突破或转世安排。
- 修为阶段提升可以增加寿元上限，使突破不仅提升资源效率，也延长本世可操作时间。
- 寿元压力会改变玩家策略：稳健修炼、冒险突破、寻求延寿资源、请求宗门支持、主动计划转世。
- 高修为但寿元逼近，会推动玩家把资源用于突破准备、延寿或后手布置，而不是无限横向积累。
- 寿元不足时，系统应显式提示风险，避免玩家在无感知状态下突然死亡。

MVP 中建议至少支持三类寿元变化：

1. 突破延寿：重大突破成功后提高寿元上限，是最基础、最稳定的延寿来源。
2. 资源延寿：丹药、灵物、宗门供养、秘境机缘等可以提高寿元或延缓寿元压力。
3. 损耗折寿：重伤、道伤、失败突破、燃烧寿元类事件可降低寿元上限或增加寿元风险标签。

## 5. 修为收益来源

### 5.1 主修道功自动运转

自动运转是主修道功最基础的被动效果。

定位：

> 自动运转用于表现“修士日常吐纳不息”的世界观，但不能替代 S3 中的主动修炼行动。
> 

已收敛规则：

- 自动运转收益按 tick 结算。
- 主动吐纳期间，自动运转不额外生效，避免同一 tick 同时吃到“主动吐纳 + 自动运转”的双重修为收益。
- 突破事件链、昏迷、重伤、封印等状态下，自动运转不生效。
- 其他行动中，只要角色状态、地点和功法条件允许，自动运转可以提供少量被动修为收益。
- 被动收益受当前修为上限、瓶颈、伤势、地点安全、功法适配影响。
- 自动运转不能完成大境界突破，也不能自动消耗高价值丹药或突破资源。
- 小境界升级通常允许由自动运转触发。例如 A-1 进度因自动运转达到 100%，在功法上限和状态合法时，可以自动进入 A-2。
- 大阶段瓶颈不能由自动运转跨越。若角色达到 A 阶末端瓶颈，自动运转最多把角色推到可准备突破状态，不能自动发起或完成 A → B 的大境界突破。
- 托管状态下，自动运转可以作为保底，但高收益仍应来自明确选择的持续行动。

设计理由：修为提升会提高战斗数值，因此自动运转不能在主动吐纳和高风险事件中叠加放大；但作为世界观保底与长期成长来源，它可以在多数非吐纳行动中按 tick 稳定结算。

### 5.2 主动运转主修道功：吐纳

吐纳是核心修为增长持续行动。

规则口径：

- 消耗行动格。
- 主动吐纳期间自动运转不额外生效；该 tick 的修为收益以吐纳结算为准。
- 读取当前位置灵气环境。
- 读取主修道功吸收速度与转化效率。
- 读取角色资质、状态、当前阶段和瓶颈状态。
- 增加修为进度。
- 同时增加主修道功经验。
- 可以搭配丹药、灵液、宗门配给、聚灵阵、洞府、秘境等修炼资源或地点效果。

吐纳的体验重点是：玩家用行动格换取“修为进度 + 主修道功熟练”的复合收益。

### 5.3 研习 / 修炼功法

“修炼功法”在本草稿中建议明确为：研习、参悟、演练某一功法，使其获得经验，但不直接增加修为。

规则口径：

- 消耗行动格。
- 目标可以是道功，也可以是法门。
- 只增加目标功法经验，不直接增加修为。
- 如果目标是当前主修道功，提升后可能解锁更高修为上限或强化吸收 / 转化表现。
- 如果目标是法门，提升后可能解锁战斗指令、非战斗行动、事件选项或资源效率。

形成取舍：

```
吐纳：修为 + 主修道功经验
研习功法：目标功法经验更高，但没有修为收益
```

### 5.4 消耗丹药等修炼资源

丹药、灵液、灵米、修炼配给等不应直接“加修为数字”，而是提供额外可摄入灵气或转化辅助。

规则口径：

- 丹药使用后生成一个“药力 / 灵气输入包”。
- 输入包仍需要通过主修道功与角色资质进行转化。
- 转化成功部分进入修为。
- MVP 中，未转化部分主要表现为逸散、浪费或短期不适，不引入丹毒 / 杂质累计设定；正式版可扩展为丹毒、杂质、经脉负担等长期副作用。
- 高阶丹药对低阶角色不应无脑高效，可能受到承载、识别、炼化、反噬或浪费限制。
- MVP 中丹药最好绑定吐纳 / 闭关 / 疗伤等行动使用，避免完全绕过行动经济。

## 6. 灵气摄入、转化与储存

### 6.1 有效灵气浓度

角色能摄入多少灵气，首先取决于当前有效灵气浓度。

```
有效灵气浓度 = 环境背景浓度 + 固定浓度加成 + 动态定向加成
```

### 6.2 环境背景浓度

环境背景浓度来自角色所在节点或特殊场景。

示例：

- 凡人城镇：低。
- 普通山野：低到中。
- 宗门外门静室：中。
- 宗门核心修炼地：中到高。
- 灵脉节点：高。
- 秘境窗口：高但不稳定。
- 前世洞府：视布置质量而定。

环境背景浓度用于让“在哪里修炼”成为策略问题。

### 6.3 功法基础吸收速度

功法基础吸收速度决定角色在当前浓度下，每 tick 最多能摄入多少灵气。

它不等于最终修为收益。

```
摄入速度高
→ 单位 tick 能吸入更多灵气
→ 但如果转化率不足，浪费也会变多
```

高吸收低转化的路线适合资源富裕、时间紧张、能承受副作用的角色；低吸收高转化的路线适合资源稀缺、追求纯度和突破稳定的角色。

### 6.4 聚灵阵型加成：固定浓度加成

聚灵阵、洞府阵法、宗门静室等可以提供固定浓度加成。

规则语义：

- 直接提高当前环境的基础可用浓度。
- 在低浓度地点效果明显。
- 受阵法阶级、品级、维护状态、灵石 / 聚灵石供给、节点限制影响。
- 不要求玩家功法标签匹配，但可能有容量或维护成本。

聚灵阵的体验价值是：把资源、建设、宗门设施与个人修炼效率连接起来。

### 6.5 定向吸收类加成：动态浓度加成

定向吸收类加成来自功法标签、法宝、阵法、地点属性、资源匹配或道韵等。

规则语义：

- 不只是简单加固定值，而是根据当前环境、功法标签和资源标签动态放大可用浓度。
- 例如水行功法在水行灵气节点中获得更高有效浓度。
- 定向吸收适合制造路线差异：同一地点对不同功法、不同灵根、不同道韵的角色价值不同。
- 动态加成应在 UI 中解释来源，例如“水行灵气充沛，沧浪类道功摄入效率提高”。

### 6.6 转化率

转化率决定摄入灵气中有多少真正变成修为。

建议由以下因素影响：

- 角色灵根与功法标签适配。
- 根骨 / 经脉承载。
- 悟性对功法理解程度。
- 主修道功阶级、品级、当前等级。
- 当前状态：伤势、疲劳、心境、道伤等。MVP 不启用丹毒 / 杂质累计状态，正式版再扩展。
- 灵气来源纯度：环境、丹药、灵液、污染灵气等。
- 当前阶段是否接近瓶颈。

### 6.7 储存结果

每次修炼结算可以拆成三部分：

```
摄入灵气
→ 成功转化部分：增加修为进度
→ 未转化逸散部分：直接损失
→ MVP 短期副作用部分：疲劳、短期不适、短期经脉压力或修炼效率下降
```

MVP 暂不引入可累计的丹毒 / 杂质系统。正式版应保留类似设定的扩展空间，用于表现长期吞服丹药、跨阶吸收、污染灵气、强行冲修等玩法后果。

MVP 仍应保留“修为纯度”接口，供突破系统读取；但纯度平时不显式展示，到大阶段瓶颈后再显示。

### 6.8 修为纯度

修为纯度用于连接日常修炼与突破准备。

建议语义：

- 稳定、适配、循序渐进的修炼提高或维持纯度。
- 强行吞服不适配丹药、在污染环境修炼、跨阶吸收、带伤冲修等行为可能降低纯度。
- 纯度不足在 S4 中表现为突破短板或失败标签。
- 玩家可以通过巩固、闭关、疗伤、净化资源、改换功法、宗门支持等方式修正。

显示规则：

- 未到大阶段瓶颈时，修为纯度默认隐藏。
- 达到大阶段瓶颈、进入突破准备语境后，修为纯度显式显示。
- 显示时应同时开放或提示提纯 / 巩固路径，避免只暴露问题但不给玩家修正手段。

设计理由：修为纯度在普通修炼阶段影响较小、波动较大，长期显示会制造低价值信息噪声；到达瓶颈后，它变成突破准备的关键变量，信息价值显著提高。

## 7. 修为上限规则

角色当前能达到的最高修为上限来自多层限制。

### 7.1 阶段瓶颈上限

阶段瓶颈是境界结构本身产生的上限。

- 小阶段可通过修炼达到阶段末端。
- 小境界升级通常可以由主动吐纳、闭关或自动运转触发，只要没有功法上限、状态或事件限制。
- 重大阶段需要突破事件链解锁，不能由自动运转直接完成。
- 达到大阶段瓶颈后，继续普通吐纳不应继续显著增加修为；收益可转化为巩固、纯度、功法经验或突破准备。

### 7.2 主修道功最终上限

主修道功的阶级与品级决定它作为主修时理论上能支持角色走到多高。

示例语义：

```
A阶中品道功：适合 A 阶修行，可能支持 A 阶瓶颈，但对 B 阶突破支持不足。
B阶上品道功：可支持更高阶段，并在重大突破中提供更好质量。
残缺道功：可能前期强，但后续阶段缺页或存在功法不合风险。
```

### 7.3 主修道功当前等级上限

主修道功的当前等级决定当前可达到的实时修为上限。

```
道功等级不足
→ 修为达到当前功法理解上限
→ 玩家需要研习 / 参悟 / 补全 / 请教 / 获得后续篇章
→ 功法等级提升
→ 解锁更高当前修为上限
```

### 7.4 上限冲突处理

当多个上限同时存在时，取最严格者。

```
当前可修炼上限 = min(
  当前阶段瓶颈上限,
  主修道功最终支持上限,
  主修道功当前等级上限,
  特殊状态限制
)
```

特殊状态包括重伤、封印、道伤、残缺突破、功法污染等。

## 8. 修为与境界提升收益颗粒度

### 8.1 总原则：三层成长

角色成长拆成三层：

```
阶段内修为进度：A-1 0% → A-1 100%
→ 小境界提升：A-1 100% → A-2 0%
→ 大境界突破：A-4 100% → B-1 0%
```

三层分别承担不同体验：

1. 阶段内修为进度：表现同一小境界内修为绝对值增加，并均匀提高当前主修道功对生机、元气、战斗指令等常规战斗数值的加成；神念采用差异化成长曲线，只在神魂类功法、特殊道功或特定根基中获得显著提升。
2. 小境界提升：给稳定台阶式成长，使玩家感受到同一大阶段内的境界推进。
3. 大境界突破：给结构性跃迁，打开新资源层级、新寿元空间、新权限和新风险。

不再额外设计“小境界内里程碑”。原因：`A-1` 中 `A` 已经代表大阶段，`1` 已经代表小境界；如果再在 A-1 内加入初入 / 小成 / 有成 / 圆满等正式概念，会增加过多层级。

### 8.2 派生条计算口径：生机 / 元气乘法，神念差异化

生机、元气采用“基础属性乘以修炼加成”的模型；神念不采用体魄 / 精力式的通用基座放大模型，而采用差异化成长模型。

```
最终生机 = 体魄值 ×（基础常数 + 当前主修道功·生机加成值 + 已固化根基·生机加成值）× 状态系数
最终元气 = 精力值 ×（基础常数 + 当前主修道功·元气加成值 + 已固化根基·元气加成值）× 状态系数
最终神念 = 阶段基础神念 + 当前主修道功·神念加成值 + 已固化神魂根基加成 + 神魂类功法 / 法宝 / 状态修正
```

设计含义：

- 体魄每次增加，都会通过乘法直接放大最终生机，不会被主修道功加成值稀释。
- 精力每次增加，都会通过乘法直接放大最终元气，不会被主修道功加成值稀释。
- 日常修炼提高的是“当前主修道功加成值”，因此同样的体魄 / 精力，在更高修为和更好主修道功下会转化为更高生机与元气。
- 主修道功切换会改变当前主修道功加成值，并向前追溯到当前已有修为积累。
- 神念不作为普通战斗资源条，不用通用基座属性持续放大。它应保持较强脆弱性，并通过神魂类功法、特殊突破、神魂法宝、心魔 / 幻境 / 因果事件等来源形成差异化成长。
- 大境界突破得到的根基加成不向后追随主修道功切换，因为它已经固化为角色生命层次的一部分；其中神魂相关突破可以额外固化为“已固化神魂根基加成”。

### 8.3 阶段内修为进度：A-1 0% → A-1 50%

阶段内进度提升代表同一小境界内部的修为绝对值增加。它不只是改变 `cultivation_progress`，还会均匀提高“当前主修道功加成值”。

建议口径：

- 修为进度本身变化。
- 修为绝对值随 0%–100% 均匀增加。
- 当前主修道功在生机、元气、战斗指令上的加成值随 0%–100% 均匀增加。
- 若当前主修道功具备神魂类或凝神类成长，神念加成值也可随 0%–100% 增加；普通道功通常不给或只给极少神念成长。
- 最终生机、元气通过“基础属性 × 当前主修道功加成值”重新计算；神念通过差异化公式重新计算。
- 不直接改变体魄、精力、根骨、悟性、灵根等基础属性。
- 不默认增加寿元。
- 不默认解锁新行动、新职位、新资源阶级。

### 8.4 阶段内进度的数值规划方式

阶段内进度采用连续插值，而不是离散里程碑。

```
当前主修道功加成值 = 小境界起点加成值 + 小境界进度百分比 × 小境界加成成长量
```

派生条再根据该加成值计算：

```
最终生机 = 体魄值 ×（基础常数 + 当前主修道功·生机加成值 + 已固化根基·生机加成值）× 状态系数
最终元气 = 精力值 ×（基础常数 + 当前主修道功·元气加成值 + 已固化根基·元气加成值）× 状态系数
最终神念 = 阶段基础神念 + 当前主修道功·神念加成值 + 已固化神魂根基加成 + 神魂类功法 / 法宝 / 状态修正
```

如果角色更换主修道功：

```
当前修为阶段与进度保留
→ 当前主修道功加成曲线替换为新道功曲线
→ 生机 / 元气 / 指令效果按新曲线重新计算
→ 神念按新主修道功是否具备神魂加成重新计算
→ 已固化根基加成不变
```

这就是“主修功法加成值向前追溯”的含义：角色过去积累的修为不清零，但新的主修道功会用自己的运转方式重新解释和发挥这份修为积累。

### 8.5 小境界提升：A-1 100% → A-2 0%

小境界提升是同一大境界内的稳定台阶。

建议口径：

- 通常允许由自动运转触发。例如 A-1 100% 在结算中自然进入 A-2 0%。
- 角色 `current_stage_code` 改变。
- 当前小境界进度重置为新阶段 0%。
- 派生状态获得一档稳定提升。
- 修为上限进入新的小阶段。
- 可解锁部分同阶权限、功法层数、法门门槛或宗门评价。
- 不默认显著增加寿元，除非具体功法、事件或配置另有说明。
- 不默认打开下一阶资源层级。

### 8.6 大境界突破：A-4 100% → B-1 0%

大境界突破是结构性跃迁，不只是更大的小境界升级。

建议口径：

- 必须通过突破事件链或等价重大事件完成，不能由自动运转完成。
- 写入轮回账本与角色履历。
- 提供大幅寿元上限提升。
- 切换到新的大阶级模板。
- 解锁更高阶资源层级、地点准入、物品使用、宗门权限或世界事件可见性。
- 根据该大境界记录 / 锁定的主修道功、功法品级、突破质量和特殊资源，生成一组“已固化根基加成”。
- 已固化根基加成写入角色本世根基，不会因为之后更换主修道功而改变。
- 为降低日志、存档和玩家理解成本，固化根基的计算应优先读取“每个大境界修炼的是哪个主修道功”这类摘要记录，而不是追踪每个 tick 的历史功法。
- 若突破质量极高，也可以额外给予少量体魄、精力、根骨、悟性等基础属性后天增幅；这是稀有奖励，不是大境界突破默认收益。

这一口径能支撑转世重修体验：

> 如果下一世使用更好的前期主修道功、更高质量地完成同一大境界突破，那么当角色重新达到前世同等修为时，当前主修道功加成值与已固化根基加成都会更好，因此同境界战力会明显高于前世。
>

| 成长层级 | 示例 | 默认是否改变基础属性 | 默认是否改变派生状态 | 默认是否增加寿元 | 默认是否解锁权限 | 主要体验 |
| --- | --- | --- | --- | --- | --- | --- |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 阶段内进度 | A-1 0% → 50% | 否 | 是，均匀连续；提高当前主修道功加成值，神念仅在神魂路线显著成长 | 否 | 否 | 修为绝对值增加，常规战斗数值同步成长 |
| 小境界提升 | A-1 100% → A-2 0% | 否 | 是，台阶式；进入同阶下一段加成曲线 | 默认否 | 同阶权限少量解锁 | 同阶内稳定变强 |
| 大境界突破 | A-4 100% → B-1 0% | 默认否；高质量突破可给稀有后天增幅 | 是，显著提升；生成已固化根基加成 | 是 | 是，结构性解锁 | 进入新资源层级 |

## 9. 主修道功替换规则草案

主修替换需要允许玩家在进入新大境界时调整路线，但不能让玩家在同一大境界中随时切换功法来优化所有历史收益。

### 9.1 已收敛规则：只在大境界第一阶段开放无行动格替换

主修道功切换不消耗行动格，但只允许在一个大境界的第一小境界内进行。

示例：

```
A-1：允许选择 / 替换 A 阶主修道功。
A-2 及之后：A 阶主修路线锁定，原则上不再自由替换。
B-1：允许选择 / 替换 B 阶主修道功。
B-2 及之后：B 阶主修路线锁定，原则上不再自由替换。
```

设计理由：

- 大境界突破时，前一个大阶段的主修功法永久加成已经结算并固化。
- 新大境界第一阶段时，新阶段的永久加成尚未固化，因此允许玩家调整新阶段路线。
- 进入该大境界第二小境界后，视为该大境界路线已经稳定，后续不再允许自由替换。
- 这样只需要记录“每个大境界修炼的是哪个主修道功”，就能计算主修功法永久加成，无论日志、存档还是玩家理解都更轻量。

### 9.2 基本替换条件

MVP 建议满足以下条件才能替换主修道功：

1. 当前处于某个大境界的第一小境界，例如 A-1 / B-1 / C-1。
2. 角色已经掌握候选道功。
3. 候选道功具备修为提升效果。
4. 候选道功支持角色当前大境界，或至少不会低于当前修为状态。
5. 角色不处于战斗、突破事件链、昏迷、重伤、被封印、强制事件链等状态。
6. 当前地点或状态允许安全调息。

### 9.3 主修记录与根基结算

每个大境界应记录一个主修道功摘要：

```
MajorStageMethodRecord {
  major_code                 // A / B / C...
  selected_daogong_ref        // 该大境界最终锁定的主修道功
  selected_at_stage_code      // 通常为 A-1 / B-1 / C-1
  locked_after_stage_code     // 通常为 A-2 / B-2 / C-2
  method_tier_quality_snapshot
  compatibility_snapshot
  final_foundation_bonus_refs
}
```

规则口径：

- 大境界第一阶段内可以替换记录中的主修道功。
- 一旦角色离开该大境界第一阶段，记录锁定。
- 大境界突破或该大境界根基结算时，读取该记录计算固化根基加成。
- 之后即使玩家在更高大境界更换主修道功，旧大境界的固化根基不再变化。

### 9.4 当前修为处理

角色已获得的修为不因替换主修道功直接清零。

主修道功切换会改变当前主修道功加成值。稳定切换后，系统应使用新主修道功的加成曲线重新计算当前修为阶段与进度对应的生机、元气和战斗指令效果。神念是否变化，取决于新主修道功是否具备神魂类或凝神类加成。

```
当前修为阶段与进度保留
→ 当前主修道功加成曲线替换
→ 生机 / 元气 / 战斗指令重新计算
→ 神念按新主修道功的神魂加成重新计算
→ 已固化根基加成与已固化神魂根基加成保持不变
```

### 9.5 非开放期的转修边界

当前不在大境界第一阶段时，MVP 原则上不开放自由主修替换。

如果后续需要支持跨路线转修，应作为高成本特殊事件链，而不是普通切换。

MVP 暂时只保留接口，不实现复杂转修。

### 9.6 突破锁定

重大突破事件链开始后，主修道功应被锁定。

- 突破审查读取锁定时的主修道功。
- 事件链中不能临时切换主修来规避短板。
- 突破结果写入时，记录主修道功、功法匹配与根基固化结果。

## 10. 功法升级奖励草案

### 10.1 道功升级奖励

道功升级应优先服务修为成长闭环。

可配置奖励包括：

1. 解锁更高当前修为上限。
2. 提高基础吸收速度。
3. 提高灵气转化率。
4. 提高修为纯度维持能力。
5. 解锁或强化被动效果。
6. 降低特定修炼环境的门槛。
7. 提高丹药 / 修炼资源炼化效率。
8. 提供突破准备加成。
9. 降低某类突破失败标签风险。
10. 解锁功法专属事件、抉择或后续篇章线索。

MVP 中，道功每级不必都增加数值，但至少应明确：

- 哪些等级解锁上限。
- 哪些等级强化修炼效率。
- 哪些等级解锁被动或突破支持。

### 10.2 法门升级奖励

法门升级不直接提高修为，但应提高资源获取效率或系统交互能力。

可配置奖励包括：

- 解锁战斗指令。
- 降低元气消耗；神魂类法门可降低神念消耗或提高神念抗性。
- 提高事件成功率。
- 解锁采集、炼丹、炼器、阵法、医术、卜算等行动入口。
- 提高特定资源产出质量。
- 降低探索、移动、战斗、突破辅助中的风险。
- 解锁特殊标签，使其与道韵、资质或宗门职位产生联动。

### 10.3 升级奖励设计原则

- 不要让所有功法都只做“修炼倍率 +X%”。
- 高品级功法应有更好的成长曲线、稳定性或突破奖励，而不只是起始更强。
- 残缺、污染、誓约、宗门绑定功法可以有高收益，但必须有清晰代价或使用边界。
- 功法升级应制造阶段性目标，让玩家在“继续吐纳”和“先研习功法”之间产生取舍。

## 11. 修炼相关资质与基础属性草案

### 11.1 总原则：没有单一“资质总分”

底层规则不建议设置一个独立的“资质总等级”。

资质是玩家理解角色成长潜力的汇总概念，实际参与判定的是具体子项。

MVP 建议先保留三类核心资质子项：

```
根骨 / 悟性 / 灵根
```

同时，角色还应保留通用基础属性，例如：

```
体魄 / 精力
```

UI 可以显示综合评价，但综合评价只用于提示，不直接参与核心判定。

### 11.2 体魄与精力：派生条的基座属性

体魄与精力不是修炼资质三件套，但它们是角色派生状态的关键基座。

体魄主要影响：

- 生机上限。
- 负伤承受。
- 肉身完整度。
- 体力型行动承受。
- 部分肉身突破准备。

设计口径：体魄每次增加，都会通过乘法公式放大最终生机。修为进度提高的是当前主修道功的生机加成值，也会被体魄乘上，因此不会稀释体魄作为生机基座的价值。

精力主要影响：

- 元气上限。
- 持续行动承受。
- 疲劳与恢复。
- 主动运转功法的稳定性。
- 部分高消耗战斗指令或修炼行动的承载。

设计口径：精力每次增加，都会通过乘法公式放大最终元气。修为进度提高的是当前主修道功的元气加成值，也会被精力乘上，因此不会稀释精力作为元气基座的价值。

体魄与精力可以后天改变，但与根骨、悟性一样，应通过明确行动、事件、突破奖励、宗门培养或资源使用写入后天修正记录，不应由普通修为进度自动增加。

### 11.3 根骨

根骨偏向身体承载、经脉基础与修炼容器质量。

主要影响：

- 单 tick 可安全摄入的灵气上限。
- 丹药药力承载与副作用风险。
- 肉身类突破准备。
- 修为储存稳定性。
- 带伤修炼、强行冲修时的风险。
- 部分炼体类道功适配。

体验含义：根骨好的角色更能“吃得下、撑得住、存得稳”。

后天改变口径：根骨可以后天改善，但必须通过高成本、低频、可解释的修正路径实现，例如洗髓、淬体、重塑经脉、炼体闭关、突破反馈、宗门培养或特殊机缘。

### 11.4 悟性

悟性偏向理解、参悟、功法学习与复杂路线掌握。

主要影响：

- 功法经验获取。
- 道功 / 法门升级速度。
- 高复杂度功法学习门槛。
- 转修、补全残篇、理解功法缺陷的效率。
- 突破事件中的提示、选择理解或心境处理。
- 炼丹、阵法、卜算、医术等非战斗技艺成长。

体验含义：悟性好的角色更能“看得懂、学得快、改得动”。

后天改变口径：悟性可以后天改善，但应更多来自参悟、讲法、读经、碑刻、秘境悟道、前世经验触发、道韵共鸣或重大事件反馈。

### 11.5 灵根

灵根偏向灵气亲和、路线标签适配与吸收方向。

主要影响：

- 有效灵气浓度修正。
- 特定属性 / 标签灵气的吸收效率。
- 道功兼容性。
- 定向吸收类加成效果。
- 丹药、灵物、环境标签的适配。
- 某些道功、法门或突破资源的使用门槛。

MVP 边界：灵根不支持后天修改。可以存在临时的定向吸收加成、阵法辅助、丹药辅助、法宝辅助或功法适配补偿，但这些都不改变角色灵根本体。

### 11.6 心性 / 神魂稳定的边界

心性、神魂稳定、道心等建议暂不作为资质三件套之一，也不作为体魄 / 精力式通用基座属性，而是作为角色状态、神念派生、神魂路线或突破准备维度处理。

设计理由：

- S4 已经需要心境稳定作为突破输入。
- 战斗系统已经读取神念作为灵魂 / 心神状态条。
- 神念需要保留脆弱性和特殊性，不能被普通基础属性稳定放大成第三条常规资源。
- 如果把心性也做成常规资质，很容易让角色初始化过重，并削弱神魂类功法的独特价值。

神念成长边界：

- 普通修为进度默认不显著提高神念。
- 普通伤害默认不直接伤害神念。
- 神念主要受神魂攻击、幻境、心魔、诅咒、因果、夺舍、搜魂、突破内劫、严重修炼副作用等影响。
- 神魂类功法、凝神类道功、特殊神魂法宝、心魔劫成功处理、秘境悟道等，可以提供明显神念成长或神念抗性。
- 大境界突破可以固化神魂根基，但应主要由突破类型、功法路线和事件质量决定，而不是所有突破一律大幅提高神念。

### 11.7 后天基础改变总原则

体魄、精力、根骨与悟性的后天改变是必要设计，用于减轻先天随机和执念容量的负担，并让本世修炼、宗门培养和突破质量能反向改善角色基础。

暂定口径：

```
体魄：允许后天改善。
精力：允许后天改善。
根骨：允许后天改善。
悟性：允许后天改善。
灵根：MVP 不允许后天修改。
```

后天改变设计原则：

1. 可改变，但不廉价：必须消耗行动格、稀缺资源、事件机会、宗门支持或承担风险。
2. 可验证，但不刷点：每次改变都应来自明确行动链、事件链、突破反馈或资源使用结果。
3. 可修正短板，但不抹平差异：后天改善可以弥补低资质角色，但不应让先天高资质、执念遗留和稀有机缘失去价值。
4. 分阶段开放：低阶段只允许小幅修正，中高阶段才开放更强的洗髓、悟道或重塑机会。
5. 有代价与风险：失败可能造成伤势、道伤、寿元折损、修为纯度下降、资源浪费或阶段性负面状态。
6. 保留来源记录：后天改变需要写入角色履历，便于 UI 解释、突破审查和轮回账本摘要。

## 12. 丹药与修炼资源使用规则草案

### 12.1 丹药不是直接经验包

丹药应提供药力，而不是直接增加修为。

```
服用丹药
→ 生成药力输入
→ 主修道功炼化
→ 按转化率进入修为
→ 未转化部分逸散或产生短期副作用
```

### 12.2 阶级与阶段匹配

丹药的阶级与角色阶段需要匹配。

- 同阶丹药：正常收益。
- 低阶丹药：收益降低，但安全。
- 高阶丹药：潜在收益高，但 MVP 中主要表现为浪费、承载不足或短期反噬风险；正式版可扩展为长期丹毒 / 杂质。
- 不适配标签丹药：MVP 中主要表现为转化率低或短期心境 / 身体扰动；正式版可扩展为杂质 / 丹毒 / 心境污染等长期后果。

### 12.3 使用窗口

MVP 建议丹药使用分为两类：

1. 小型修炼丹药：可在吐纳行动中使用。
2. 高价值丹药：需要闭关、静室、护法或特定持续行动炼化。

这样可以避免玩家在即时操作中一次性吞大量资源，绕过行动格与风险。

### 12.4 丹药副作用接口

MVP 暂时不引入丹药丹毒 / 杂质设定，也不设置可累计丹毒值或杂质值。

MVP 中，丹药不适配或跨阶使用的后果优先表现为：

```
low_conversion_efficiency
wasted_pill_power
short_term_fatigue
temporary_meridian_pressure
spirit_agitation_short
```

这些结果主要用于当次或短期事件解释，不形成长期可累计丹毒 / 杂质系统。

正式版应预留扩展接口，未来可加入：

```
pill_residue
meridian_burden
unstable_cultivation
purity_loss
spirit_agitation
```

这些正式版标签可以在突破审查中转化为风险提示或失败原因。

## 13. 玩家 UI 与反馈原则

角色养成面板需要让玩家理解“为什么这次修炼收益是这个结果”。

### 13.1 修炼预览

规划吐纳或闭关时，UI 应显示方向性预估：

- 当前地点灵气：低 / 中 / 高 / 不稳定。
- 主修道功吸收表现：较低 / 正常 / 较高。
- 资质与功法适配：不合 / 可用 / 适合 / 极佳。
- 预计修为收益：少量 / 稳定 / 较高。
- 预计功法经验：少量 / 稳定 / 较高。
- 预计损耗或副作用：无 / 轻微 / 明显。
- 是否接近当前上限。
- 若已达到大阶段瓶颈，显示修为纯度与可用提纯 / 巩固路径。

### 13.2 修炼结果日志

每次修炼结算应输出可回放摘要：

```
本 tick 在青岚山外门静室吐纳。
主修道功：青木引气诀。
环境灵气：中。
聚灵阵：生效。
灵根适配：较好。
摄入灵气大部分成功转化，修为小幅提升，道功经验增加。
```

### 13.3 上限提示

当收益下降或停滞时，系统应明确告诉玩家原因：

- 已达到当前主修道功等级上限。
- 已达到当前阶段瓶颈，需要突破。
- 当前功法不支持更高阶段。
- 当前地点灵气过低。
- 当前丹药不匹配，转化损失过高。
- 当前伤势或道伤影响修炼。

## 15. MVP 最小可验证闭环

### 15.1 角色与功法

- 角色拥有当前阶段、修为进度、修为绝对值、主修道功、功法经验。
- 角色拥有年龄、寿元上限与寿元压力状态。
- 角色拥有根骨、悟性、灵根三个资质子项。
- 体魄、精力、根骨与悟性至少有先天基础值与后天修正记录；灵根 MVP 不开放后天修改。
- 至少有 2 个道功，差异体现在吸收速度、转化率、上限、被动效果或功法加成曲线。
- 至少有 1 个法门，用于验证“非修为功法不能设为主修”。

### 15.2 行动

- 玩家可以选择“吐纳”持续行动，获得修为与主修道功经验。
- 主动吐纳时，自动运转不额外生效。
- 玩家可以选择“修炼 / 研习功法”持续行动，只获得目标功法经验。
- 主修道功可以自动运转，在多数非吐纳、非突破、非重伤状态下提供少量被动收益。
- 自动运转通常允许触发小境界升级，但不能完成大境界突破。
- 玩家可以在大境界第一小境界内无行动格替换主修道功。

### 15.3 环境与资源

- 至少存在普通环境、宗门静室、聚灵阵 / 灵脉节点三类灵气环境。
- 至少一种丹药可以用于吐纳，并通过转化率结算收益与损耗。
- MVP 不引入丹毒 / 杂质累计系统，但保留正式版扩展接口。
- 至少一种延寿或寿元修正来源可以进入日志，MVP 可优先使用突破延寿或延寿丹。
- 高收益修炼需要地点、资源或行动投入，不由被动自动运转替代。

### 15.4 上限与瓶颈

- 功法当前等级能限制当前修为上限。
- 研习主修道功能提高该上限。
- 达到阶段瓶颈后，系统提示需要突破准备。
- 达到大阶段瓶颈后，显示修为纯度与提纯 / 巩固路径。
- 寿元压力会推动玩家选择突破、延寿、后手布置或主动计划转世。
- S4 能读取修为积累、纯度、功法匹配、寿元压力和资源使用痕迹。

## 16. 已收敛问题与剩余待决问题

### 16.1 本轮已收敛

1. 自动运转结算口径
    - 自动运转按 tick 结算。
    - 主动吐纳时自动运转不生效。
    - 突破、昏迷、重伤、封印等状态下自动运转不生效。
    - 其他行动中，若角色状态与环境合法，自动运转可以提供少量被动修为收益。
    - 自动运转不能完成大境界突破。
    - 小境界升级通常允许由自动运转触发。
2. 修为纯度显示口径
    - 修为纯度数据层保留。
    - 未到大阶段瓶颈时默认隐藏。
    - 达到大阶段瓶颈、进入突破准备语境后显示。
    - 显示时应同时提供或提示提纯 / 巩固路径。
3. 丹药副作用 MVP 口径
    - MVP 暂时不引入丹药丹毒 / 杂质设定。
    - 不设置可累计丹毒值或杂质值。
    - 不适配丹药主要表现为转化率低、药力浪费、短期疲劳、短期经脉压力或短期心神扰动。
    - 正式版应保留丹毒 / 杂质 / 长期残留等扩展接口。
4. 主修道功切换口径
    - 主修道功切换不消耗行动格。
    - 只允许在大境界第一小境界内自由替换，例如 A-1 / B-1 / C-1。
    - 离开该大境界第一小境界后，当前大境界主修路线锁定。
    - 每个大境界只需记录该大境界最终锁定的主修道功，用于计算固化根基加成。
    - 已固化根基不会因为之后更换主修道功而改变。

### 16.2 剩余待决问题

1. 跨路线转修是否在正式版中作为高成本事件链实现？若实现，是否允许改写当前大境界主修记录？
2. 功法等级采用固定等级、阶段式熟练度，还是按篇章 / 层数解锁？
3. 道功最终上限与当前等级上限如何在 UI 上避免让玩家误解？
4. 灵根是否采用特殊包装，例如单灵根、双灵根、异灵根，还是先统一为标签 + 阶级品级？MVP 已暂定不支持灵根后天修改。
5. 聚灵阵固定浓度加成是否消耗灵石、聚灵石或宗门设施维护资源？
6. 定向吸收加成是否会消耗 / 污染 / 改变节点灵气状态，还是只作为个人修炼修正？
7. 寿元增长的 MVP 最小口径采用“突破延寿”即可，还是需要同时实现延寿丹 / 延寿灵物？
8. 寿元压力状态是否显式显示为安全 / 有压 / 紧迫 / 耗尽，还是只在关键节点弹出提醒？
9. 根骨后天改善的 MVP 最小路径采用“洗髓资源 + 持续行动”，还是需要独立洗髓事件链？
10. 悟性后天改善的 MVP 最小路径采用“参悟机会 + 持续行动”，还是先用限时明悟状态替代永久改善？
11. 后天基础属性改善是否允许跨阶提升，还是每个大阶段只允许有限次数修正？
12. 体魄 / 精力与主修道功加成值的乘法公式中，基础常数、功法加成值和状态系数的初始量级应如何配置？
13. 神念的阶段基础值、神魂类功法加成、已固化神魂根基加成之间应采用怎样的初始量级？

## 17. 暂定设计命题

> 角色养成不是“花时间涨经验”，而是“用功法把世界中的灵气与资源转化为本世修为”。主修道功决定路线，环境决定摄入，资质决定转化，寿元决定时间压力，功法等级决定当前上限，功法阶级与品级决定长期上限和突破质量。阶段内修炼提高当前主修道功加成值，主修切换可以重新解释既有修为积累；生机和元气依赖体魄 / 精力的乘法放大，神念则保留脆弱且特殊的差异化成长；大境界突破把当时的功法、质量和资源投入固化为根基，不随之后主修切换改变。玩家通过选择地点、资源、功法、行动、延寿方式、后天基础修正和转世基础，持续提高同境界下的资源利用率，并最终把修炼推进到瓶颈、突破与跨世优化循环中。

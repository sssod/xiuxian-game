# 经济系统设计｜地图资源产出

## 1. 当前结论

地图资源产出由地图节点、广义资源槽、资源槽附属设施、控制权、宗门持续行动和世界小时结算共同决定。

节点是主单位；资源不是独立漂浮物，而是挂载在地理节点上的资源槽。建筑和设施不是与资源槽并列的第二套槽位，生产、修炼、加工、防护、交通、市场、宗门行政等设施都必须附属于广义资源槽。

## 2. 节点常态产出流程

```text
节点拥有资源槽
→ 节点等级决定资源槽数量、资源品级范围和节点灵气基础
→ 宗门或势力控制节点 / 资源槽附属设施正常运转
→ 按世界小时推进并在宏观周期摘要中汇总产出
→ 写入 sect_storage / node_storage
→ 写入库存日志
```

规则：

- 已控制资源节点的基础产出不占宗门持续行动。
- 资源槽的自然生成数量、资源品级、可波动范围和稀有变体概率受节点等级影响；节点等级也影响灵气浓度、灵气品质、污染、稳定度和相性权重。
- 产出受控制权、影响力、资源丰度、资源槽附属设施状态、设施规模、设施等级、灾害、敌对干扰、人力占用影响。
- 产出优先进入宗门抽象库存或节点库存，库存底层规则见《06_储物空间系统设计/03_库存系统》。
- 若产出需要具体物品形态，再由物品系统转换为 ItemStack / ItemInstance。
- 同一个资源槽只能建造一类设施；设施规模和级别可以升级或衰退，但不得在同一槽内叠加多类设施。
- 每个资源槽必须有规模上限。上限由资源类型、资源品级、节点等级、地形、控制权和特殊事件共同决定。

## 3. MVP 资源槽与设施对应

MVP 阶段先使用资源类型到可建设施类别的白名单，不开放自由组合。

| 资源槽类型 | 可建设施类别 | 口径 |
| --- | --- | --- |
| 灵气节点 | 修炼房 / 静室 / 聚灵阵类修炼设施 | 修炼房可内含聚灵阵；同槽只能选择这一类修炼设施，规模和等级可变 |
| 灵田 / 药谷 | 灵植园 / 药园 / 培育棚 | 产出灵植、药材或种植资源，不能同时建矿场或修炼房 |
| 矿脉 | 采矿场 / 炼矿前置设施 | 产出矿石、灵石原矿或炼器材料，后续加工再进入设施链 |
| 灵泉 / 灵液池 | 灵泉维护 / 灵液收集设施 | 提供灵液、炼丹辅助或修炼环境输入 |
| 妖兽巢穴 / 生态资源 | 狩猎营地 / 驯养栏 / 看守点 | 产出妖兽材料、风险事件或驯养机会 |
| 洞府空间 / 可建空间 | 洞府 / 藏宝 / 仓储类设施 | 以储物、防护、隐蔽、休整为主，不自动产出资源 |
| 洞天福地 | 保全 / 封禁 / 参悟 / 突破场地类操作 | 属于不易改造资源，通常不允许常规生产建筑替换 |
| 市场锚点 / 交通锚点 / 行政地块 | 坊市、渡口、传送阵、宗门行政等公共设施 | 仍按广义资源槽承载，不能绕过一槽一设施类别和规模上限 |
| 秘境窗口 / 特殊资源 | 入口维护 / 探索准备 / 临时封锁 | 多数是机会窗口或事件入口，不作为常态建筑地块 |

## 4. 宗门持续行动产出

每个宗门同一时间最多拥有一个 active `SectContinuousActionState`。开采 / 资源介入、探索、建设、远征等持续行动都可能产生资源结果，但不应替代已控资源节点的常态产出。

## 5. 阶段预算修正

数值草案提出：玩家首次突破到某大境界后，世界激活对应阶段预算。预算进入节点资源槽、宗门库存、市场交易、机会窗口、NPC 个人资产或事件投放。预算打开提供机会，不自动赠送修为。

## 6. 缺口

- ResourceSlot 表、丰度、再生周期、灾害、附属设施产能公式未定。
- 各境界阶段预算的具体数值未定。
- 资源点模板与地图实例未定。

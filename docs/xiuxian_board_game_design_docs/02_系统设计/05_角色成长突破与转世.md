# 系统设计｜角色成长、突破与转世

适用范围：角色属性、三条持久状态、自动修炼、境界、突破、寿元、小洞天、重伤、死亡和转世。

## 1. 属性范围

当前世角色使用：

- 基础属性：体魄、精力；
- 修炼资质：根骨、悟性、灵根等级与标签；
- 持久状态：生机、元气、神念；
- 战斗派生：护盾；
- 寿元：当前年龄、寿元上限；
- 后天永久与临时修正。

真灵、执念、旧法力纯度和跨世历史属性不进入新方案。

## 2. 三条持久状态

每条状态包含：

```text
当前值
最大值
保留值
可支配上限 = 最大值 - 保留值
```

当前值不能超过可支配上限。生机上限主要读取体魄，元气上限主要读取精力；神念使用独立基础值与修正。

生机归零触发死亡与转世；否则神念归零进入重伤。元气归零不直接战败，但不能执行任何需要消耗元气的地图移动。

## 3. 回合末自动修炼

普通修炼不占主要行动。每轮行动结算后，角色按当前主修道功和仍生效的丹药获得修为。

以下情况不获得本轮自动修为：

- 重伤；
- 本轮死亡并转世；
- 已处于大境界瓶颈且突破失败。

三条状态没有脱离道功的统一自然恢复。恢复来自道功被动、丹药、地点或其它明确效果。

## 4. 境界与突破

1. 日常系统读取有效修为；标准 CP 只用于换功折算和封顶溢出保存。
2. 小境界达到阈值自动晋级。
3. 大境界突破必须占用主要行动。
4. 重伤、危险地点和敌对地点不能发起突破。
5. 当前道功模板提供突破基础成功值，突破丹药参与最终成功率。
6. 金丹升元婴开始需要渡劫，之后每次大境界突破都需要渡劫。

需要渡劫时：

```text
选择突破丹药
→ 先判定突破成功率
→ 失败则直接进入失败结果
→ 成功才生成渡劫战斗
→ 战斗胜利则突破成功
→ 战斗失败则按生机 / 神念结果处理
```

失败损失不回退，包括三条状态损失、主要行动和突破丹药。

## 5. 重伤

神念恢复到 `1` 或以上时立即解除重伤。常见恢复来自疗伤丹药或医馆专有行动。

重伤黑名单为：

- 切换主修道功；
- 回合末自动修炼；
- 大境界突破；
- 飞升。

未列入黑名单的移动、即时行动和主要行动不得仅因重伤被隐式禁用。

## 6. 小洞天与寿元

小洞天只能由随机事件或固定事件授予，不是可直接选择的地图行动。一个外界回合推进十个角色内部时间单位，依次结算修炼、丹药、资源、恢复、炼化和寿元。

寿元主要限制玩家在小洞天中长期低效率修炼。普通地图回合消耗一个基础单位寿元，小洞天消耗十个；外部世界仍只推进一个回合。

## 7. 死亡与转世

转世是严重惩罚，不是主动优化循环，也不会淘汰玩家。

| 类型 | 转世结果 |
| --- | --- |
| 道功、法门知识 | 保留 |
| 掌握进度与知识来源招式 | 保留，但受新境界限制 |
| 体魄、精力、资质与三条状态 | 不保留，按新出生配置生成 |
| 随身资产与法宝 | 全部失去 |
| 修为与境界 | MVP 默认全部失去 |

出生地点、最低物资、地区资产、宗门关系和追赶机制仍待 `S-04` 裁决。

## 8. MVP 缺口

主要缺口为：目标回合与境界节奏、属性和境界表、恢复量、G-23 百分比继承取整、转世出生与追赶。P0 阶段应先处理节奏和追赶，再回到取整细节。

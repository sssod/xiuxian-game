# 项目总览、MVP 边界与系统依赖（v2.3）

## 1. 项目定位

本项目是一款支持本地单人测试、私人服务器部署、3 人共玩的连续日历制多人修仙轮回沙盒。

玩家控制跨世延续的真灵，当世角色在共享世界日历中修炼、移动、经营关系、争夺资源、突破、战斗、死亡转世与布置后手。世界时间由服务器维护，并根据玩家与世界状态在 F1 / N1 / B1 / P0 之间自适应切换。

开发定位：

```
共享日历房间
+ 自适应流速推进
+ 跨世角色成长
+ 当前执行指令 + 最多 3 条预输入指令
+ 宗门 AI 资源平台
+ 节点地图沙盒
+ 功法掌握与行动资源输入
+ 事件 / 交锋 / 突破权威结算
```

---

## 2. MVP 目标

MVP 需要验证：

```
本地单人测试
+ 私人服务器部署
+ 3 人共享房间
+ 保存、暂停、恢复、续开
+ M0 → M3 纵向闭环
+ 共享日历时间推进
+ 指令队列、兜底、托管与局部时停
```

最小可玩目标：

1. 创建房间并进入共享世界日历。
2. 角色拥有当世身份、基础境界、位置、资产容器和功法状态。
3. 玩家可提交当前行动与后续短队列。
4. 服务器按小时 tick 结算行动、资源输入、事件、宗门 AI 与节点变化。
5. 普通个人事件走局部时停，结束后 C1 追赶。
6. 正式交锋与突破挑战走 B1 交锋轮。
7. 角色可突破、受伤、死亡、转世并保留真灵层记录。
8. 存档、日志、结果包与回放可用于调试。

## 3. 时间与同步结构

底层时间事实：

```
1 游戏日 = 24 游戏小时
服务器最小结算单位 = 1 游戏小时
主时间字段 = world_day / world_hour
宏观周期字段 = macro_period_id
```

公开速度档位：

| 档位 | 名称 | 现实时间 : 游戏时间 | 使用场景 |
| --- | --- | --- | --- |
| F1 | 高速推进 | 2 秒 = 1 游戏日 | 全员处于明确长期低交互行动 |
| N1 | 常态推进 | 15 秒 = 1 游戏小时 | 默认多人运行；局部时停外部世界速度 |
| B1 | 交锋慢速 | 60 秒 = 1 游戏小时 | 正式战斗、突破挑战、秘境关键交锋 |
| P0 | 全局暂停 | 游戏时间不流动 | 公共决策、同步保护、主机暂停规则 |

内部机制：

| 机制 | 名称 | 用途 |
| --- | --- | --- |
| C1 | 追赶补结算 | 局部时停结束后，将滞后玩家补结算至当前世界时间 |

## 4. 玩家主循环

玩家主循环围绕地图、角色状态、队列、事件和结果日志展开：

```
查看世界日历、速度与地图状态
→ 查看角色当前行动与后续队列
→ 编辑当前已经合法的普通指令
→ 服务器持续按速度推进小时 tick
→ 行动完成、事件触发、交锋开始或公共暂停
→ 处理个人事件 / B1 交锋轮 / P0 公共决策
→ 查看个人日志、公开日志和阶段摘要
→ 继续行动或转世后重入世界
```

普通指令编辑不冻结角色当前行动，也不冻结其他玩家或世界。若世界处于 F1，玩家打开普通队列编辑会使世界进入 N1。

## 5. 核心系统依赖

### S1 共享日历与权威结算总线

S1 维护 `world_day / world_hour`、`SpeedState`、服务器小时 tick、结果包合并、日志与回放。所有子系统结果都通过 S1 回写。

### S2 真灵、角色与修炼成长

角色是当世载体，真灵是跨世身份。修炼、功法、资质、寿元、伤势、境界、轮回账本和遗产后手共同决定长期成长。

### S3 个人行动队列与资源输入

个人行动使用 `CommandQueue`。每名角色拥有当前执行指令与最多 3 条预输入指令。丹药、灵材、符箓等资源通过 `ActionResourceInputBinding` 绑定到具体行动或事件选项。

### S4 地图节点与世界演化

地图由节点、路线、资源槽、势力影响、风险等级、可见性和事件窗口组成。节点变化按世界小时推进。

### S5 宗门组织与宗门 AI

宗门是组织资源平台。玩家通过身份、贡献、职位、资源申请、亲自参与和事件结果间接影响宗门。每个宗门同一时间最多维护一个 `SectContinuousActionState`。

### S6 经济、物品与 NPC 持久化

资产容器、物品、功法载体、临时资源效果、NPC 状态和交易来源需要可追踪、可校验、可存档。

### S7 后手遗产与可见性

后手、遗产、传闻、地图可见性、资源竞争与机会窗口承担多人间接竞争。

### S8 事件、突破与战斗

事件按 `event_time_mode` 决定时间处理。突破挑战复用 `FormalEncounterState`，结果进入个人报告、宗门传闻与世界日志。

## 6. MVP 阶段验收总线

MVP 验收以以下能力为硬门槛：

1. `WorldClock` 与 `TimeConfig` 可运行。
2. F1 / N1 / B1 / P0 切换和日志可复盘。
3. 当前指令 + 最多 3 条预输入可编辑、校验、执行和失败兜底。
4. 自动兜底强制 N1 且 `f1_eligible=false`。
5. 显式托管可作为玩家主动低关注行动进入队列。
6. 个人局部时停 gap 上限、提示和 C1 追赶可验证。
7. B1 交锋轮有默认策略、提交窗口和硬上限。
8. 突破挑战走 B1，资源消耗发生在挑战轮内。
9. 存档和回放记录 `TimelineReplay`、速度片段、队列变更、局部时停、追赶、交锋轮和结果包。

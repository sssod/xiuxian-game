# 文案设计模块

适用范围：`docs/xiuxian_design_docs/01_文案设计`。

## 1. 当前定位

本文案设计模块负责维护世界观设定、主线剧情、势力剧情、真灵支线，以及文案侧对系统、数值和交互的要求与约束。

本模块由包外草稿 `docs/inbox/mainline_outline_shanhai_duanmu_v0_2_1.md` 拆分吸收而来。草稿只作为历史来源保留；后续设计解释、MVP 规划和跨文档引用应以本模块和其他正式包内文档为准。

## 2. 使用方式

1. 查世界观最高裁决、地理、历史和势力背景时，先读 `01_世界观设定`。
2. 查主线结构、剧情幕、势力线、真灵支线和文案侧系统约束时，读 `02_剧情设定`。
3. 需要把剧情内容转成玩法、数值或 UI 时，先读 `02_剧情设定/07_系统数值交互约束.md`，再进入对应 `02_系统设计`、`03_数值设计` 或 `04_交互设计` 文档。
4. 若本模块与既有系统、数值或交互文档存在冲突，先标为待裁决，不直接覆盖正式主题文档。

## 3. 文档清单

### 3.1 世界观设定

- `01_世界观设定/01_世界基线与核心裁决.md`：主线最高优先级裁决和世界观边界。
- `01_世界观设定/02_地理格局与四极镇墟大阵.md`：昆仑中心地理、四方镇守、四极大阵、建木界垣、大乘后渡劫期、地仙 / 天仙与旧飞升路封锁解释。
- `01_世界观设定/03_天地源流与绝地天通.md`：创世、建木时代、归墟借建木浸入、绝地天通、建木转封和灾劫炼身后遗症。
- `01_世界观设定/04_当世势力与外围组织.md`：三大核心宗门、太素、迎墟者和外围小型组织。

### 3.2 剧情设定

- `02_剧情设定/01_主线总纲与阶段结构.md`：主线一句话版本、三阶段结构、现世四幕和最终定稿口径。

- `02_剧情设定/03_第二幕与第三幕_核心入世至归墟复潮.md`：核心地域入世、四证合流、四方摊牌、四极失衡和天根入海。
- `02_剧情设定/04_第四幕_重定天地与结局.md`：续断、接木、入墟、另开、藏世和坏结局。
- `02_剧情设定/05_四大主线势力剧情线.md`：太初、太极、混沌、太素和迎墟者剧情线。
- `02_剧情设定/06_预设真灵支线.md`：预设真灵定义、MVP 第一批真灵、支线结构和禁区。
- `02_剧情设定/07_系统数值交互约束.md`：山海图、归墟地图机制、主线变量、系统接口和功法 / 宗门 / 藏宝接口建议。

# 修仙轮回沙盒｜正式设计文档包

本目录是当前正式设计文档包，是 MVP 开发、设计解释和后续校准的首要依据。开发过程中仍可继续细化规则、修正引用、裁剪低价值或过时内容，并由人工主导关键取舍。

包外资料仅作为参考，包括 `docs/inbox` 中本包之外的原始材料与历史参考文档。参考资料中的有效信息如需采用，应改写并沉淀到本包内部，不应让本包依赖外部文件才能解释。

## 使用方式

1. 从 `00_INDEX/INDEX_总索引.md` 进入文档包。
2. 新建文档或进行结构性修订前，参考 `00_INDEX/文档模板与包内引用规范.md` 选择通用、系统设计、数值设计或交互设计模板。
3. 按主题修订对应文档，优先维护包内引用与主题边界。
4. 遇到来源冲突、重复口径、陈旧内容或无法机械判断的设计取舍，返回用户裁决。
5. MVP 开发应以本包为设计合同；历史资料只能作为恢复线索，不能直接越过本包驱动实现。

## 目录结构

- `changelog.md`：记录正式设计文档包相对 Notion 基线的近期变更摘要。
- `00_INDEX/`：当前总索引、文档模板、包内引用规范和跨主题待裁决清单。
- `01_文案设计/`：世界观设定、主线剧情、势力剧情、真灵支线，以及文案侧对系统、数值和交互的要求与约束。
- `02_系统设计/`：按框架重排的系统与玩法文档。
- `03_数值设计/`：数值模型、公式、投放与验算文档。
- `04_交互设计/`：页面与交互约束文档；节点级布局以当前 UI artifact / Figma 为准。

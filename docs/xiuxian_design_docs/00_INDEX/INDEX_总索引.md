# INDEX｜正式设计文档包总索引

适用范围：`docs/xiuxian_design_docs` 正式设计文档包的入口、阅读顺序和维护口径。

## 1. 当前定位

`docs/xiuxian_design_docs` 是当前正式设计文档包。本文负责说明包内文档入口、主题分组、阅读顺序和后续修订时的基本约束。

本包是 MVP 开发和设计校准的首要依据。包外材料仅作为参考；若采用包外信息，应改写并沉淀到本包内部，不让读者必须跳出本包才能理解当前设计。

## 2. 使用方式

1. 先从本文确认目标主题所属目录和文档，再进入对应文件修订。
2. 新建文档或进行结构性修订时，先遵循《文档模板与包内引用规范》（`文档模板与包内引用规范.md`）。
3. 修改具体主题文档时，保持该文档只回答一个清晰主题；跨主题内容用包内关联表承接。
4. 遇到包内材料之间的冲突时，优先标记为待裁决或待补，不静默合并为定稿。
5. 包外材料只能用于恢复线索或识别冲突；被采纳内容必须改写进本包正文。

## 3. 规则或清单

### 3.1 修订重点

- 细化仍然粗略或只列约束的主题。
- 去除重复、陈旧、低价值或互相冲突的表述。
- 清理包内引用，避免依赖包外文档才能解释。
- 将实现影响记录为约束、风险、待决问题或验收条件。
- 无法机械判断的设计裁剪、取舍和冲突交由用户裁决。

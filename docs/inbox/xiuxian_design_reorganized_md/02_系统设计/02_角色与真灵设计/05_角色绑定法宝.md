# 系统设计｜角色绑定法宝

## 1. 设计定位

本文维护法宝实例与当前世角色建立绑定关系后的系统规则。文件名沿用“角色绑定法宝”，但当前规则层不把它视为独立法宝类型；角色绑定只是法宝实例上的归属、保护和死亡结算状态。

本文回答“某件法宝绑定当前世角色后如何被保护、如何参与死亡结算、是否跨世继承、MVP 是否开放操作”的问题。不维护法宝品类、法宝战斗效果、储物空间法宝内部容器、库存取放、真灵藏宝容量或完整后手玩法。

## 2. 当前结论

1. 角色绑定不是 `artifact_kind`，不进入法宝类型表；它只表示某件法宝实例当前是否绑定当前世角色。
2. MVP 阶段不开发完整认主、解绑、改绑、继承绑定、绑定争夺或绑定破解玩法，只保留基础状态设定。
3. 当前明确会使用角色绑定状态的法宝对象是储物空间法宝；其他法宝是否允许角色绑定暂不进入 MVP。
4. `bind_state = character_bound` 表示法宝绑定对象为当前世角色，普通窃取、扒取、战利品拾取或库存转移不能直接拿走该法宝。
5. 绑定对象死亡后，绑定法宝自主损毁，不作为遗产、战利品、可搬空资产或默认后手继续流转。
6. 角色绑定不等于真灵绑定，也不默认跨世继承；若未来允许进入真灵藏宝，仍必须走正式后手封存流程并占用对应数量或容量限制。

## 4. 核心循环或触发入口

角色绑定状态围绕“创建、检查、保护、死亡结算、记录”循环维护。

1. 创建：系统在明确规则允许时给法宝实例写入 `bind_state = character_bound` 和绑定目标。MVP 中仅保留概念设定，不开放玩家主动认主入口。
2. 检查：库存转移、战利品拾取、偷取、资产清点、事件奖励、后手封存和 UI 展示读取绑定状态。
3. 保护：若法宝绑定当前世角色，普通窃取、扒取、战利品拾取或库存转移不得直接转移该法宝。
4. 死亡结算：绑定对象死亡时，绑定法宝按自主损毁处理，不进入普通遗产、战利品或可搬空资产。
5. 记录：绑定创建、保护拦截和死亡损毁都应写入资产日志、事件结果或结算摘要，用于解释法宝去向。

中断点包括绑定目标失效、绑定目标死亡、法宝本体破碎、正式后手封存裁决、事件锁定、库存转移失败和 UI 状态刷新。

## 5. 规则与状态

### 5.1 基础概念

角色绑定状态指某件法宝实例与当前世角色建立绑定关系。它不是装备栏槽位，不是战力栏位，也不是法宝类型，而是一组归属与保护状态。

基础规则：

1. 绑定对象是当前世角色，不是默认真灵、宗门、账号或跨世身份。
2. 绑定状态只改变归属保护和死亡去向，不自动提供战斗加成、成长、亲和度、灵性培养或专属技能。
3. 绑定后的法宝仍是普通法宝实例，仍受法宝状态、资产位置、权限、可见性、事件锁定和日志规则约束。
4. 若绑定法宝是储物空间法宝，储物空间本身仍不绕过库存、后手、遗产、宗门审计和真灵藏宝容量边界。

### 5.2 状态枚举

| 状态 | 含义 | MVP 口径 |
| --- | --- | --- |
| `unbound` | 法宝实例未绑定当前世角色 | 默认状态 |
| `character_bound` | 法宝实例绑定当前世角色 | 可用于概念设定和储物空间法宝 |

MVP 不启用以下状态：

1. 真灵绑定。
2. 跨世绑定。
3. 宗门授权绑定。
4. 后手封存绑定。
5. 临时绑定、争夺绑定、破解绑定或继承绑定。

### 5.3 保护与损毁

角色绑定后的保护规则：

1. 普通窃取、扒取、战利品拾取和库存转移不能直接拿走绑定法宝。
2. 绑定保护不等于无敌保护；法宝仍可按法宝、事件或战斗规则受损、失灵、破碎或销毁。
3. 绑定对象死亡后，绑定法宝自主损毁。
4. 自主损毁发生在死亡结算中，不作为遗产、战利品、宗门回收资产或普通藏宝资产继续流转。
5. 损毁结果需要写入资产日志或事件结果，说明损毁原因来自绑定对象死亡结算。

### 5.4 与真灵和后手的关系

角色绑定状态目前不等于真灵绑定状态。

当前口径：

1. 损毁后的法宝不默认跨世继承。
2. 真灵不默认获得该法宝的所有权、能力、内部资产或残留效果。
3. 角色绑定不提供绕过正式后手流程的例外。
4. 若未来允许绑定法宝进入真灵藏宝，必须另行裁决，并按《个人洞府库存、藏宝与后手系统设计》（`../18_个人洞府库存_藏宝与后手系统设计.md`）走正式后手封存流程。
5. 即使未来允许法宝进入真灵藏宝，也必须占用真灵藏宝设置数量或单个容量限制。

## 6. 资源、角色、地图、事件或 NPC 接口

| 接口对象 | 读取内容 | 写入或约束 |
| --- | --- | --- |
| 法宝实例 | `bind_state`、绑定对象、保护策略、损毁策略、法宝状态 | 绑定状态不得改写为法宝品类 |
| 当前世角色 | 角色 ID、死亡状态、资产可调用范围 | 死亡结算触发绑定法宝自主损毁 |
| 库存系统 | 容器、取放权限、转移请求、事件锁定、资产日志 | 转移和拾取前必须检查绑定保护 |
| 战斗和事件 | 法宝可用性、损坏结果、现场控制权 | 不能在绑定保护未处理前提前分配战利品 |
| 后手与藏宝 | 正式封存记录、真灵藏宝数量和容量 | 角色绑定不能自动转化为跨世后手 |
| UI | 是否绑定、不可转移原因、死亡损毁去向 | 普通 UI 不展示内部调试字段 |

## 7. 数据字段建议

| 字段 | 含义 |
| --- | --- |
| `bind_state` | 法宝实例绑定状态；MVP 只使用 `unbound` 与 `character_bound` |
| `bound_target_ref` | 绑定对象引用；MVP 概念上只指当前世角色 |
| `theft_protection` | 绑定后的普通窃取、扒取、战利品拾取或库存转移保护策略 |
| `destroy_policy` | 绑定对象死亡后的法宝去向；角色绑定使用 `destroy_on_bound_target_death` |
| `binding_source_ref` | 绑定来源或裁决来源，用于后续追踪；MVP 可为空或由事件记录承接 |
| `binding_ledger_refs` | 绑定创建、保护拦截、损毁结算等资产日志引用 |

概念字段结构：

```yaml
ArtifactBindingConcept:
  bind_state: unbound | character_bound
  bound_target_ref: string | null
  theft_protection: none | bound_unstealable
  destroy_policy: none | destroy_on_bound_target_death
  binding_source_ref: string | null
  binding_ledger_refs: list
```

字段建议是实现提示，不等同于最终数据库或代码结构。法宝实例字段的总体口径以《法宝》（`../05_物品设计/03_法宝.md`）为准。

## 8. UI 展示边界

普通 UI 可以展示：

1. 法宝是否已绑定当前世角色。
2. 绑定法宝不可普通转移、不可普通拾取或不可普通窃取的原因。
3. 绑定对象死亡后法宝会自主损毁的风险提示。
4. 若绑定法宝作为储物空间法宝出现，只展示概念状态和不可用原因，不开放独立取放、扩容或内部空间操作。

普通 UI 不展示：

1. 内部绑定来源 ID、日志 ID、调试枚举或原始保护策略字段。
2. 真灵绑定、跨世绑定、宗门授权绑定等尚未裁决状态。
3. 绑定破解、争夺、继承或后手绕行入口。
4. 法宝内部资产的未裁决去向推演。

## 9. MVP 范围

MVP 应实现或保留：

1. 角色绑定是法宝实例状态标记，不是独立法宝类型。
2. `unbound` 与 `character_bound` 两种概念状态。
3. 绑定后不被普通窃取、扒取、战利品拾取或库存转移直接拿走。
4. 绑定对象死亡后绑定法宝自主损毁。
5. 损毁或转移拦截结果可写入资产日志或事件结果。
6. 储物空间法宝可作为当前明确使用角色绑定状态的对象，但不开放独立玩法。

MVP 不实现：

1. 完整认主、解绑、改绑、继承绑定或解除绑定玩法。
2. 绑定状态带来的战斗加成、成长、亲和度、灵性培养或专属技能。
3. 真灵绑定、跨世绑定、宗门授权绑定或后手封存绑定。
4. 绑定冲突、绑定争夺、破解绑定、绑定窃取或绑定转移事件链。
5. 绑定状态与后手容量、遗产分配、宗门权限之间的完整结算系统。

## 10. 验收约束

1. 任何文档或实现不得把“角色绑定法宝”解释为新的法宝类型、装备槽位或战力栏位。
2. 绑定法宝不能被普通窃取、扒取、战利品拾取或库存转移直接拿走。
3. 绑定对象死亡时，绑定法宝必须按自主损毁处理，不能进入普通遗产、战利品或可搬空资产。
4. 角色绑定不得自动转化为真灵绑定、跨世继承或正式后手。
5. 若未来允许绑定法宝进入真灵藏宝，必须先经过独立裁决，并受真灵藏宝数量或容量限制。
6. 储物空间法宝即使被角色绑定，也不能绕过库存权限、资产日志、遗产清点、开启条件和后手封存规则。

## 11. 待裁决与待补

| 项目 | 当前口径 | 需要裁决或补充 |
| --- | --- | --- |
| 非储物空间法宝是否可绑定 | MVP 暂不进入 | 后续若需要，应按法宝类型、玩法入口和风险分别裁决 |
| 真灵绑定 | 当前不存在 | 是否需要独立状态、跨世范围、开启条件和容量限制 |
| 宗门授权绑定 | 当前不存在 | 是否作为宗门资产权限、身份权限或法宝安全策略 |
| 后手封存绑定 | 当前不从角色绑定自动推导 | 是否允许绑定法宝正式封存，以及封存时内部资产如何处理 |
| 解除绑定 | MVP 不开放 | 是否存在解绑代价、事件条件、失败风险和日志要求 |
| 绑定保护突破 | MVP 不开放 | 是否允许特殊事件、战斗结果或破解玩法绕过普通保护 |

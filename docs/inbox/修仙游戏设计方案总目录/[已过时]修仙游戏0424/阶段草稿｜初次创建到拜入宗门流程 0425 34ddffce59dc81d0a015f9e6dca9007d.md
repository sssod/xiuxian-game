# 阶段草稿｜初次创建到拜入宗门流程 0425

## 背景

本文记录当前 Canvas 草稿中已经模拟完成的第一阶段玩家流程：从初次创建真灵、投生凡人少年、理解基础信息与行动系统，到最终抵达宗门山门并拜入宗门。

该阶段的目标不是一次性定稿完整数值，而是通过玩家流程模拟，反推最小原型需要支持的字段、UI 入口、事件结构、回合结算顺序与设计原则。

## 阶段目标

- 验证玩家从“低认知、低资源、低控制力”的初次入世状态开始，是否能自然理解角色、地图、背包、货币、行动格与事件选择。
- 验证新手任务是否能作为柔性引导，而不是强制主线。
- 验证“移动行动 + 持续行动 → 提交 → 结算 → 事件 → 对话选择 → 结果包”的基础闭环。
- 验证角色日志、新手指引、即时行动、移动预览、功法学习、移动事件、入门事件等系统是否能在最小原型阶段串联。
- 提炼第一阶段的系统边界与后续待决策项。

## 冲突检查决议（2026-04-25）

本节记录本草稿与现有核心体验、顶层定案和 S3 子系统设计案的冲突检查结论。以下决议用于约束本页后续修订：

1. **行动格术语**：以顶层定案与 S3 为准，统一使用“6 个朔望行动格”，不使用“朔望月行动格”。
2. **入门后 follow-up 修炼**：以 S3 行动经济为准。入门后的修炼只作为“入门事件链内部教学 / 奖励结算”，可以消耗剩余行动格或给予少量固定功法经验，但不计为第二个普通持续行动。
3. **资质来源**：以角色核心体验稿为准。资质在角色出生 / 身躯生成时已经生成，入门事件只负责检测、揭示和评级，不在山门现场生成资质。
4. **属性显示边界**：数据层仍保留完整角色属性接口；本阶段只在新手 UI 中显式暴露体魄、精力、悟性与派生状态，其他属性可隐藏、默认、待检测或暂不参与计算。
5. **食物 / 补给规则**：以 S3 配置化原则为准。本页不定死“每行动格食物消耗”规则，只表达“远行需要补给”。具体消耗频率、缺粮 debuff 与适用范围进入后续移动 / 补给配置。
6. **家庭支持事件约束**：父母给予铜钱与干粮应视为一次性家庭支持事件，需受位置、关系、家庭库存、日志与事件状态约束。
7. **日志可见性约束**：角色日志只展示角色可知信息；系统世界日志默认玩家不可见，玩家端表现为世界传闻，后者只是前者子集。

## 核心结论

第一阶段应覆盖以下完整体验链：

```
创建真灵
→ 初次投生
→ 获得角色自知信息
→ 通过角色日志查询人物、地图、传闻、修行认知
→ 通过新手任务找村长打听宗门
→ 尝试规划前往山门，发现当前移动能力不足
→ 打听轻身之法
→ 与父母对话获得一次性家庭支持（铜钱与干粮）
→ 前往镇集武馆
→ 学习凡品功法，推荐轻身功法
→ 第二回合模拟山门路线，准备远行干粮，也可选择原地继续学艺
→ 第三回合正式前往山门
→ 途中触发移动事件，可迎战或用轻身功法逃遁
→ 抵达山门，执行拜入宗门
→ 入门事件检测并揭示已生成资质，归入外门
→ 获得宗门传授功法
→ follow-up 修炼教学 / 奖励结算，作为入门事件链内部结算获得少量功法经验，不计为第二个普通持续行动
```

- 初始家庭不提供修行优势，避免破坏“初次入世低构筑”的原则。

| --- | --- | --- | --- |

| 东田垄 | 农田节点 | 家中常去帮工的田地 | 已知，可自由行动 |

| 北山脚 | 边缘山地节点 | 可拾柴、采山货，长辈提醒不要深入 | 已知，存在风险 |
| 南土路 | 道路节点 | 通往镇集，偶有行商与宗门杂役经过 | 已知，儿童单独远行受限 |

| 云麓山道 | 山路节点 | 从村长处得知，通往云麓宗山门 | 初步解锁，不可查看详情 |
| 云麓宗山门 | 宗门入口节点 | 从村长处得知，秋季招新地点 | 初步解锁，不可查看详情 |
| 镇集 | 外部聚落节点 | 从村长处得知，镇上有武馆可学艺 | 任务解锁后可前往，详情需抵达后查看 |
| 镇集武馆 | 技艺学习节点 | 从村长处得知，可学习凡俗武艺功法，至少包含战斗功法与轻身功法 | 任务解锁后可作为目标，详情需抵达后查看 |

设计含义：

- 初始地图不应完全未知，角色应知道自己生活范围内的节点。
- “已知节点”“半知节点”“初步解锁但不可查看详情节点”需要区分。
- 更远区域、宗门山门详情、资源点和危险区域仍需通过探索、传闻或亲身抵达解锁。

## 3. 初始属性、状态、背包与货币

### 3.1 基础属性与派生状态

当前为新手阶段 UI 暴露字段，不等于完整角色属性系统。数据层仍应保留完整角色属性接口；本页只显式展示玩家在 M0 阶段需要理解和使用的最小字段。

当前区分两层：

- 基础属性：相对稳定，用于描述角色身体与精神底子。
- 派生状态：由基础属性计算得出，用于承载当前健康、气力、损耗与恢复。

基础属性：

| 显示名 | 实现字段建议 | 含义 | 初始值 |
| --- | --- | --- | --- |
| --- | --- | --- | ---: |
| 体魄 | `physique` | 身体强健程度，影响生机上限、负伤承受、劳损抗性等 | 10 |
| 精力 | `energy` | 精神与气力底子，影响元气上限、持续行动、疲劳承受等 | 10 |
| 悟性 | `comprehension` | 理解、领悟与学习能力，影响单位时间的功法经验获取效率 | 10 |

派生状态：

| 显示名 | 实现字段建议 | 含义 | 当前公式 | 初始值 |
| --- | --- | --- | --- | --- |
| --- | --- | --- | --- | ---: |
| 生机 | `vitality` | 健康、伤病、濒死风险承载状态 | 生机上限 = 体魄 × 10 | 100 / 100 |
| 元气 | `stamina` | 可支配气力、疲劳、行动消耗承载状态 | 元气上限 = 精力 × 10 | 100 / 100 |

当前暂定：

- 10 岁男性人类标准初始模板为：体魄 10，精力 10，悟性 10。
- 天赋标签“平平无奇”不提供任何数值修正。
- 因此该角色与所有同模板、同年龄、同性别的人类拥有一致的基础属性、学习效率基准与派生状态。

| 平平无奇 | 天赋标签 | 无数值加成，无特殊事件权重修正 |

由于项目很快会进入修行与辟谷阶段，最小原型不引入完整饥饿度系统，仅保留移动途中的干粮消耗。

| 规则项 | 当前规则 |
| --- | --- |

## 4. 角色日志、信息可见性与新手辅助

### 4.1 角色日志入口

角色日志是玩家查询角色已知信息的主入口，用于汇总角色已经知道、经历或听闻的信息。

| 日志分类 | 用途 |
| --- | --- |
| 人物关系 | 记录亲缘关系、熟人、恩怨、师承、宗门关系等 |
| 地图条目 | 记录已知节点、半知节点、路径、地点印象与可达性 |
| 见闻记录 | 记录角色亲眼所见、亲身经历、参与过的事件 |
| 传闻记录 | 记录从村民、行商、杂役、宗门人员等来源听到的未验证信息 |
| 生活常识 | 记录当前角色天然知道的村庄、家庭、生计、货币等基础信息 |
| 修行认知 | 记录功法、境界、入门规则、灵石等修行相关认知的解锁过程；当前已知“秋季招新、10 岁可试、宗门管饭” |

设计含义：

- 角色日志是玩家查询信息的主入口，不等同于系统世界日志。
- 角色日志只记录角色可知信息；系统真实状态、隐藏判定和完整世界日志不直接暴露。
- 世界日志默认玩家不可见，玩家端表现为世界传闻，后者只是前者子集；完整世界日志主要服务测试、调试与回放。
- 家庭、村庄、节点、背包、货币、修行认知等内容，都可以映射进角色日志的对应分类。
- 最小原型阶段只需要实现入口与分类，不需要设计完整日志 UI 与条目格式。

### 4.2 新手任务与指引

新手辅助拆成两类：

| 类型 | 职责 |
| --- | --- |
| 新手指引 | 只负责在界面上露出重点信息，降低玩家漏读关键事实的概率 |
| 新手任务 | 提供明确步骤感，支持 UI 跳转、打开对应界面或定位可交互对象 |

新手任务是柔性引导，不是强制主线。它的目标是：如果玩家按部就班推进，就能理解基础操作、信息查询、回合决策、移动、持续行动、交易、事件与对话选择；但玩家仍可以在同一阶段选择其他合理行动。

## 5. 新手任务链：从打听宗门到镇集学艺

### 5.1 任务一：打听山上仙门

| 任务字段 | 当前内容 |
| --- | --- |
| 任务名称 | 打听山上仙门 |
| 任务类型 | 即时行动任务 |

## 6. 第一回合：移动到镇集武馆并学艺

### 6.1 回合决策结构

第一回合不是单纯移动，而是完整的“移动行动 + 持续行动”样例。

| 任务字段 | 当前内容 |
| --- | --- |
| 任务名称 | 去镇集学艺 |
| 任务类型 | 回合决策教学任务 |
| 任务目标 | 使用角色决策界面规划并提交“移动行动 + 持续行动”的第一回合决策，前往镇集武馆并消耗剩余时间学艺 |
| 玩家操作 | 点击“镇集武馆”，选择“移动至此”；抵达后在剩余行动格中安排“学艺”持续行动；结算时从武馆可教功法中选择一门 |
| 回合组合 | 移动行动 + 持续行动 |
| 行动消耗 | 移动按路径消耗半月行动格；学艺按持续行动占用剩余行动格；移动每半月消耗 1 份食物 |
| 提交结果 | 玩家确认后提交本回合决策，进入第一回合结算阶段 |
| 预期结果 | 角色抵达镇集武馆，结算学艺持续行动，并触发学艺特殊事件 |

### 6.2 学艺持续行动

| 规则项 | 当前规则 |
| --- | --- |
| 原地学艺 | 默认消耗 6 个行动格 |
| 先移动再学艺 | 移动可能消耗 1-2 格，剩余 4-5 格用于学艺 |
| 食物消耗 | 学艺不消耗食物，只有移动段消耗 |
| 经验获取 | 根据实际学艺行动格、悟性和其他修正结算功法经验 |

### 6.3 特殊事件：武馆择艺

第一回合决策提交后，系统进入结算阶段。角色移动到镇集武馆后，执行“学艺”持续行动，并触发特殊事件“武馆择艺”。

| 事件字段 | 当前内容 |
| --- | --- |
| 事件名称 | 武馆择艺 |
| 事件类型 | 对话选择事件 |
| 触发条件 | 第一回合结算中，角色在镇集武馆执行“学艺”持续行动 |
| 事件目标 | 让玩家从武馆可教授的凡品功法中选择一门开始学习 |
| 核心交互 | 与武馆教头对话，通过选项决定学习功法门类与具体功法 |
| 结果差异 | 不同选项指向不同功法、铜钱消耗、经验获取、后续能力变化与事件权重 |
| 教学重点 | 对话选择是本游戏处理事件结果的核心系统之一；功法学习会消耗资源与行动时间 |

### 6.4 武馆功法供给规则

| 规则项 | 当前规则 |
| --- | --- |
| 功法品级 | 当前均为凡品功法 |
| 必备门类 | 每个武馆至少包含战斗功法与轻身功法 |
| 可选门类 | 防御功法、养身功法等可按武馆配置出现 |
| 同类同品差异 | 通过“最高可修等级”简单体现优劣 |
| 学习费用 | 选择不同功法时消耗不同数量铜钱 |
| 学习时间 | 学艺持续行动默认消耗 6 个行动格；若本回合先移动，则消耗移动后剩余行动格 |
| 学习效率 | 悟性影响单位时间的功法经验获取效率 |

示例对话选择：

| 选项 | 玩家表达 | 功法门类 | 示例结果方向 |
| --- | --- | --- | --- |
| A | “我想学能护身打斗的功夫。” | 战斗功法 | 提升基础战斗能力；对赶路问题帮助有限 |
| B | “我想学挨打保命的功夫。” | 防御功法 | 提升受伤承受或防护能力；可能降低部分风险事件损失 |
| C | “我想学走山路、赶远路的身法。” | 轻身功法 | 提升移动能力或降低山路通行压力；符合当前新手目标 |
| D | “我想学调养身体的法门。” | 养身功法 | 提升恢复、体魄/生机相关成长或长期稳定性 |

### 6.5 功法简化模型

| 字段 | 含义 |
| --- | --- |
| `method_name` | 具体功法名，不同武馆可不同 |
| `method_grade` | 功法品级，当前为 mortal / 凡品 |
| `method_category` | 功法门类：战斗、防御、轻身、养身等 |
| `max_level` | 该功法最高可修等级，同类同品下用于体现优劣 |
| `learn_cost_copper` | 初次学习消耗铜钱 |
| `exp_current` | 当前功法经验 |
| `exp_to_next_level` | 升至下一级所需经验 |

功法经验公式占位：

```
本次功法经验 = 学艺行动格数量 × 基础经验 × 悟性效率系数 × 其他修正
```

其中：

- 若角色本回合原地学艺，默认可投入 6 格。
- 若角色本回合先移动到武馆，移动可能消耗 1-2 格，剩余 4-5 格用于学艺。
- “平平无奇”不提供额外修正。
- 具体数值暂不展开，最小原型只需验证“悟性影响单位时间经验效率”。

### 8.3 移动事件：山路遇险

本回合路途较远，应触发一次移动事件，用于教学“伪随机事件触发机制”和“事件可引出战斗”。

| 事件字段 | 当前内容 |
| --- | --- |
| 事件名称 | 山路遇险 |
| 事件类型 | 移动事件 / 伪随机事件 |
| 触发条件 | 长距离移动途中，由伪随机事件触发机制判定触发 |
| 事件目标 | 让玩家理解远行并非纯路径消耗，途中可能发生事件 |
| 事件场景 | 山路上遭遇强盗、野兽或可疑拦路者，具体包装可配置 |
| 核心选择 | 正面迎战，或使用轻身功法逃遁 |
| 可能结果 | 战斗胜利、战斗受伤、逃遁成功、逃遁失败转入战斗、损失物品或元气 |

示例对话选择：

| 选项 | 玩家表达 | 主要判定 | 可能结果 |
| --- | --- | --- | --- |
| A | “不能退，正面迎战。” | 战斗功法、体魄、元气、装备等 | 进入战斗事件；胜利可获得少量战利品或见闻，失败可能受伤 |
| B | “不与他们纠缠，用轻身功法逃开。” | 轻身功法等级、元气、路径环境等 | 逃遁成功则跳过战斗并继续赶路；失败可能转入战斗或额外消耗元气 |

设计含义：

- 移动事件不只是随机插曲，而是远行风险的主要承载方式。
- 轻身功法不仅影响路径开销，也可以作为事件选项的能力依据。
- 如果玩家第二回合选择学习战斗功法，则应在迎战选项中获得更好反馈；如果选择轻身功法，则应在逃遁选项中获得更好反馈。
- 战斗事件此处只需要最小占位：能进入、能结算胜负/损耗、能返回移动流程即可。

| 触发条件 | 入门事件通过，角色归入外门 |
| 事件目标 | 让玩家选择接下来修炼哪一门或哪几门功法 |
| 可选范围 | 宗门传授的基础功法，可能包含主修功法、护道术法、基础轻身/养身等 |
| 玩家选择 | 选择一门功法集中修炼，或选择多门功法分配剩余修炼时间 |
| 时间消耗 | 消耗本回合入门后剩余的修炼行动格/修炼时间 |
| 经验结算 | 按投入时间、悟性、功法类型与其他修正获得功法经验 |
| 后续目标 | 进入正式修炼循环：修炼 → 瓶颈 → 突破 → 成长/失败后转世 |

修炼经验结算延用功法经验框架：

```
本次功法经验 = 投入修炼行动格 × 基础经验 × 悟性效率系数 × 功法/环境/资源修正
```

设计含义：

- 第三回合把“凡俗准备阶段”过渡到“宗门修行阶段”。
- 入门不是纯剧情播片，而是一个特殊持续行动触发的事件链。
- 资质判定首次引入隐藏深层属性，但只在角色达到对应系统入口时揭示。
- 宗门传授功法后立即 follow-up 修炼，可以让玩家在入门当回合看到修炼系统的第一层反馈。
- 多功法选择为后续构筑留接口，但最小原型可先支持“一门集中修炼”，再扩展到多门分配。

## 10. 已确定设计原则

1. 真灵与角色必须分层：真灵负责跨世延续，角色负责当前世的身体、身份、位置与关系。
2. 初次入世要低构筑、低认知：玩家第一次不能直接做复杂构筑，否则会要求玩家在不了解系统时做高成本决策。
3. 基础属性与派生状态分层：体魄、精力、悟性用于描述角色底子；生机、元气用于承载当前损耗。
4. 标签系统可以先作为差异入口：“平平无奇”即使无数值效果，也验证角色模板 + 标签修正结构。
5. 信息可见性本身是核心玩法变量：玩家不知道什么，和玩家拥有什么一样重要。
6. 角色自知信息要明显多于真灵初始认知：当前角色应知道姓名、家庭、村庄、近处道路和日常货币。
7. 早期经济只保留一个交易单位：初始阶段只解锁铜钱，先验证凡人日常交易、帮工报酬、食物购买等最小经济闭环。
8. 角色日志是玩家扮演的信息容器：汇总当前角色已知信息，但不暴露系统世界日志和隐藏事实。
9. 新手指引应从角色已知信息中生成：例如“秋季招新”是修行认知，“3 回合内抵达山门”是对该认知的目标化表达。
10. 新手辅助要区分指引与任务：指引负责重点信息露出，任务负责步骤推进与 UI 跳转。
11. 新手任务可以用受控失败教学系统边界：通过无法抵达山门的模拟移动，引出行动格、移动能力和轻身功法。
12. 早期目标链应复用核心 NPC 与家庭关系：村长承载外部信息，父母承载家庭支持。
13. 食物只作为早期远行约束，不做完整生存系统：移动每半月消耗一份食物，持续行动不消耗食物。
14. 回合决策由移动行动与持续行动组合构成：一个季度内可先移动，再用剩余行动格安排学习、修炼、探索等持续行动。
15. 对话选择是事件处理的核心交互系统：事件文本 + 选项 + 结果包。
16. 功法学习需要资源、时间与悟性三者共同参与：选择功法门类与具体功法后，消耗铜钱与学艺行动格获得功法经验。
17. 新手任务是柔性推荐，不是强制轨道：玩家可以按推荐准备干粮，也可以选择原地再学战斗功法等其他合理行动。
18. 移动预览要同时表达时间、元气与补给需求：行动格是时间成本，元气是角色状态成本，干粮是移动补给成本。
19. 即时交易适合承载早期资源准备教学：准备干粮通过即时行动-交易完成，不占用季度行动格。
20. 远行结算应允许事件打断并返回主流程：长距离移动途中可由伪随机事件触发移动事件，事件解决后继续移动。
21. 功法既是数值能力，也是事件选项依据：轻身功法可支持逃遁，战斗功法可改善迎战表现。
22. 入门是特殊持续行动触发的事件链：抵达山门只是空间条件，真正改变身份的是“拜入宗门”触发的入门事件。
23. 资质检测是对出生时已生成隐藏深层属性的首次正式揭示：灵根/资质类信息不应开局可见，而应在入门、检测、机缘等对应场景中揭示。

## 11. 待决问题

- 初始季节是否固定为春季，还是根据投生时间随机但保证有足够准备期。
- 当前季度 6 个朔望行动格的命名是否准确，是否需要改为“半月行动格”或其他更清楚的术语。
- 初步解锁但不可查看详情的地图节点，在 UI 上应如何区分于已抵达节点、半知节点和完全未知节点。
- 父母提供的铜钱与干粮数量应是多少，是否固定或受家庭背景影响。
- 镇集武馆学习凡品功法的费用、耗时与成功结果如何定义。
- 第一批凡品功法门类应如何配置最低集合：战斗、轻身必有，防御、养身是否作为可选项。
- 同类同品功法的最高可修等级应如何取值，是否足以体现早期功法优劣。
- 武馆学艺费用是否只与功法门类相关，还是还受最高可修等级影响。
- 悟性到经验效率的公式如何设计，是否采用线性、分段或阈值加成。
- 第二回合移动预览中，轻身功法如何具体影响行动格消耗、元气消耗或山路开销。
- 第二回合是否默认推荐再学战斗功法，还是只作为可选提示。
- 即时交易是否完全不消耗元气，还是存在轻微元气消耗。
- 食物不足 debuff 应影响移动速度、生机、元气，还是仅作为风险标签。
- 第三回合移动事件的触发概率、伪随机权重和保底机制如何设计。
- 移动事件中“逃遁”和“迎战”的判定分别引用哪些属性、功法等级和状态。
- 最小战斗事件是否只做结果包，还是需要一个简化战斗回合。
- 入门资质判定应检测哪些深层属性，是否需要在首次角色创建时预生成。
- 外门身份获得后，宗门节点地图应一次性解锁到什么范围。
- 宗门传授的第一批功法应包含哪些门类，是否允许玩家多功法分配修炼时间。
- 最小原型是否需要“见闻/传闻/人物关系”作为早期信息系统。

## 12. 阶段收束

至此，第一阶段流程已经完成：玩家从初次创建真灵，到以 10 岁凡人少年身份投生，经过村庄信息获取、行动格教学、武馆学艺、远行准备、山路事件、拜入宗门、资质判定与初授功法，正式进入宗门修炼阶段。

下一阶段建议从“外门弟子进入正式修炼循环”开始，继续模拟：

```
外门日常
→ 选择功法修炼
→ 功法经验与境界进度
→ 宗门任务/资源获取
→ 首次瓶颈
→ 首次突破尝试
```

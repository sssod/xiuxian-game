## 1. 区域职责

右侧区域用于承接玩家在地图上的当前判断：

- 本回合目标模板。
- 当前选中节点摘要。
- 当前位置即时行动。

它不是完整宗门面板、完整节点详情页或完整行动规划器。

## 3. 目标模板模块

节点：

```text
ModuleA_GoalTemplates
```

标题：

```text
目标模板
本回合先确定方向，再规划行动
```

目标模板项：

```text
延续上一回合计划
推进修炼
处理宗门事务
探索资源
追踪传闻
准备突破
休整避险
```

当前选中：

```text
探索资源
```

推荐文案：

```text
当前推荐：探索资源 / 处理宗门事务
```

规则：

- 目标模板只是帮助玩家整理意图。
- 它不直接生成服务器行动。
- 进入个人行动规划后，目标模板可作为自动生成行动指令的输入之一。

## 4. 选中节点摘要模块

节点：

```text
ModuleB_SelectedNodeSummary
```

标题：

```text
正在查看：黑石岭矿脉
```

标签：

```text
已探索
资源紧张
边境争夺
风险中
```

信息行：

```text
• 节点类型：资源型地理节点
• 所属区域：边界荒野
• 控制权：云麓宗影响 56%，赤砂门影响 31%，其他 13%
• 灵气：中等，矿脉异动
• 危险：妖兽踪迹、宗门冲突
• 资源：玄铁矿脉、碎灵石、未知伴生矿
• 当前不可直接执行即时行动
• 抵达后可能处理事项：探索矿脉 / 协助驻守 / 调查异动 / 采集矿材
```

路线迷你卡：

```text
从当前位置出发
预计耗时：约 1.5 天
移动方式：步行 / 轻身术
风险标签：妖兽传闻、边境冲突
```

按钮：

```text
设为本回合目标
查看节点详情
```

规则：

- 非当前位置节点不显示可立即执行的即时行动按钮。
- 对非当前位置节点，只能显示“抵达后可能处理事项”。
- `设为本回合目标` 是客户端意图选择，不等于提交行动。

## 5. 当前位置即时行动模块

节点：

```text
ModuleC_CurrentLocationInstantActions
```

标题：

```text
当前位置：云麓宗山门
你人在这里，可处理当前位置即时事务。
```

列表项：

```text
领取外门俸禄
查看宗门回信
整理随身物品
查看功法详情
查看宗门当前持续行动
```

底部提示：

```text
即时行动不占用回合时间预算。进入个人行动规划后将冻结。
```

规则：

- 即时行动必须早于个人行动规划。
- 点击即时行动后应进入服务器校验，不直接本地改状态。
- 宗门相关即时入口只能查看或申请，不得出现宗门主行动命令。

## 6. 与地图顶部位置浮窗的关系

地图顶部位置浮窗回答全局位置问题：

```text
当前位置 / 正在查看 / 计划目标
```

右侧模块回答当前对象的详情问题：

```text
该目标是什么 / 为什么重要 / 能做什么
```

两者不可互相替代。

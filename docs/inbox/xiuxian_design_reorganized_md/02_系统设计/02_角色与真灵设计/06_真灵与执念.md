# 角色与真灵设计｜真灵与执念

## 1. 当前结论

玩家主体采用三层模型：

```text
真灵：跨世延续主体
执念：转世重修时获得并消费的一次性初始化代币
身躯与灵魂：当前世角色实例
```

本次约束：

- 真灵是真正跨世延续的玩家主体，世界主线剧情直接与真灵、真灵名和真灵线索关联。
- 玩家控制的当前角色是真灵塑造出的当世承载者，不拥有世俗背景身份。
- 执念基于转世前的修为境界结算，只在下一世角色初始化时作为一次性代币消费，不作为长期跨世货币累计。
- 执念只用于影响新一世初始化条件，不携带当前身躯、当前灵魂、当前修为、功法等级、背包、宗门职位、普通关系、完整属性表或完整前世记忆。

## 2. 真灵字段边界

```yaml
TrueSpirit:
  spirit_id: string
  true_name: string
  true_name_mode: preset | custom
  story_line_id: string
  story_line_type: dedicated | generic_weak
  true_name_visibility: hidden | declared | exposed
  spirit_strength: number
  incarnation_count: int
  highest_stage_reached: string
  dao_rhyme_tags: list
  reincarnation_ledger_refs: list
  legacy_sense_log_refs: list
  formal_contingency_refs: list
```

字段边界：

- `true_name` 与 `story_line_id` 决定真灵主线入口。预设真灵名绑定专属剧情线；自定义真灵名进入通用弱剧情线。
- `spirit_strength` 不直接提高修炼效率，也不直接生成本次执念代币。本次执念代币按转世前修为境界结算。
- `formal_contingency_refs` 记录正式后手 / 真灵藏宝索引，可以长期跨世存在，但不等同于执念消费项，也不等同于普通遗产。
- 真灵层只保存跨世主体、主线、道韵、轮回账本和正式后手索引，不保存本世角色运行态。
- 真灵藏宝作为正式后手可由同一真灵跨世感应和开启，但必须受设置数量和单个容量限制，不能把前世背包、洞府库存或宗门资源无限搬到下一世。

## 3. 执念结算与消费

```text
本世结束 / 主动计划转世
→ 结算本世身躯与灵魂
→ 记录本世最高或结算修为境界
→ 按修为境界生成本次执念预算
→ 进入新一世角色初始化
→ 选择无成本基础参数
→ 消耗执念设定强化参数
→ 生成新身躯与灵魂
→ 本次执念结算关闭
```

无成本基础参数：

- 当前角色姓名。
- 性别。
- 年龄。
- 出生位置的大致区域。
- 外观预选择。

执念当前已确认可影响的强化参数：

- 角色属性设定。
- 出生具体位置设定。
- 初始物资设定。

规则：

- 每个执念选项有 `obsession_weight` 或等价消耗值。
- 玩家选择的总权重不得超过本次执念预算。
- 权重不是 RPG 属性点，不允许拆成根骨 +1 / 悟性 +1 等细碎购买。
- 执念选项应是离散配置，例如属性定型包、具体出生点、初始物资包。
- 未消耗执念设定的项目按普通生成规则处理。
- 未使用的执念不进入真灵长期余额，不作为下一次转世的可累积资源。

## 4. 执念可选范围

### 4.1 角色属性设定

角色属性设定用于改变新一世身躯与灵魂的初始属性生成结果。

允许方向：

- 选择完整属性定型包。
- 选择属性生成倾向包。
- 选择已解锁的初始化属性模板。

约束：

- 不拆成可自由分配的零散属性点。
- 不直接复制前世完整属性表。
- 不直接继承前世修为、功法等级或战斗能力。
- 如果后续允许天赋标签进入执念范围，必须重新定义为属性设定包或独立执念选项，不沿用旧的“携带天赋标签”表述。

### 4.2 出生具体位置设定

出生位置分为无成本的大致区域与消耗执念的具体位置。

无成本：

- 选择出生位置的大致区域。

消耗执念：

- 指定更具体的起点节点。
- 选择特殊落点。
- 选择更接近特定资源、宗门、遗产线索或安全教学节点的位置。

约束：

- 出生具体位置只表示空间落点，不生成家庭背景、门第身份、凡俗职业、官籍、族属关系或初始社会身份。
- 具体位置可以影响玩家接触到的地点、NPC、宗门与事件入口，但不得绑定世界主线身份。
- 高价值起点必须通过执念权重体现，不能伪装成无成本地区选择。

### 4.3 初始物资设定

初始物资设定用于改变新一世进入世界时可直接使用或携带的资源。

允许方向：

- 基础生存物资包。
- 学艺或入门准备物资包。
- 路途补给包。
- 已解锁的轻量遗留物资包。

约束：

- 初始物资包不等于前世背包复制。
- 初始物资包不直接授予宗门职位、社会身份、家族关系或区域声望。
- 初始物资可以改善开局风险和路线选择，但不应替代后续修炼成长。
- 宗门个人洞府库存的遗产清点不生成初始化物资包；它按 NPC 死亡后的宗门相关遗产规则回收宗门。
- 宗门外个人洞府和普通藏宝只能作为线索、位置或开启条件相关内容进入初始化选择，不自动转为可携带物资。
- 真灵藏宝不消耗执念开启，但受正式后手的设置数量和单个容量限制；取出后按一次性取出处理。

## 5. 禁用与修正项

以下旧设需要修正：

- “真灵强度提供执念容量”修正为“转世前修为境界结算本次执念预算”。
- “MVP 优先支持天赋标签与出生背景”修正为“当前已确认范围为角色属性设定、出生具体位置设定、初始物资设定”。
- `carried_birth_background`、`birth_background_id`、`family_background_id`、`initial_social_identity` 等玩家初始化字段禁用。
- “出生背景影响初始资源、身份、家族关系、宗门关系、区域声望”不再适用于玩家角色初始化。相关效果若仍需要保留，应拆分为初始物资、出生具体位置、可接触事件入口或游玩中获得的关系与声望。
- 执念不得用于购买世俗背景身份，也不得将当前角色绑定为世界主线身份。

## 7. 轮回账本

轮回账本用于记录死亡、突破失败、主动转世、前世经验、后手线索、宗门遗产清点、宗门外洞府 / 普通藏宝开启线索、失败标签、资产去向、真名暴露变化、执念预算来源和本次执念消费结果。

轮回账本不是完整前世记忆复制，也不是背包、关系、身份或修为的跨世搬运系统。它服务长期复盘、线索追踪和真灵层叙事。

轮回账本可以保存真灵藏宝索引和宗门外藏宝线索，但不改变资产归属规则：宗门个人洞府库存按宗门遗产清点，宗门外洞府和普通藏宝按开启条件或破阵处理，真灵藏宝按同一真灵跨世开启处理。

## 8. 待定项：仅限执念可选范围

- 角色属性设定的具体粒度：完整属性定型包、生成倾向包、属性模板之间如何取舍。
- 天赋标签是否允许进入执念可选范围；若允许，作为属性设定包、独立选项还是特殊解锁项。
- 出生具体位置的等级：普通具体节点、特殊落点、资源邻近点、宗门邻近点、遗产线索邻近点的权重差异。
- 初始物资包的分类、上限和权重：生存、学艺、入门、路途、轻量遗留物资是否分层。
- 已解锁初始化遗留是否存在独立类别；若存在，哪些必须归入属性、位置或物资三类，哪些需要新增执念选项类型。
- 高稀有外观或特殊真灵显化是否允许成为执念选项；默认外观预选择不消耗执念。
- 各执念选项的权重表、互斥关系、解锁条件和前置境界要求。

# NPC 设计

## 1. 当前定位

NPC 不应全量模拟成每人都有完整钱包、背包、消费偏好和逐小时生活的社会经济系统。MVP 应采用分层持久化。

## 2. 分层持久化原则

核心问题：如果 NPC 战斗开始时临时生成库存，会导致来源不可信、交易与战斗不一致、刷物品、宗门库存可信度下降、后手冲突和性能边界失控。

当前推荐：

```text
身份广覆盖
+ 库存分层持久化
+ 聚合经济流
+ 活跃集宏观模拟
+ 汇总结算
+ 事件相交局部精算
+ 惰性追赶
```

## 3. NPC 与机构库存

NPC 个人失败不等于组织资产全量失守。掌柜不是商店库存持有人，宗主不是宗门库房持有人。机构资产存于 ShopStock / SectStorage / NodeStorage。

## 4. NPC 修炼追赶

N3 未进入活跃集时，不逐季度模拟完整修炼行动。重新进入活跃集时，用成长画像、俸禄/基础供给、闭关季度数、风险画像和随机命名空间汇总修为变化。

## 5. 缺口

- NPC 分层标准表。
- NPC 关系、好感、性格与事件权重。
- 宗门关键 NPC 和长老序列配置。
- NPC 战斗模板与掉落/随身资产表。

# 数值设计｜投放数值设计

## 1. 当前结论

投放数值由阶段预算、资源槽、事件生成预算、宗门库存、市场交易、NPC 个人资产 / 事件资产和世界窗口共同控制。

## 2. 阶段预算机制

- 玩家首次突破到某大境界后，世界激活对应阶段预算。
- 预算进入节点资源槽、宗门库存、市场交易、机会窗口、NPC 个人资产 / 事件资产和事件投放。
- 节点资源槽从预算池抽样时，必须结合节点等级决定资源槽数量、资源品级范围、稀有变体概率和灵气浓度基础。
- 资源槽不是可直接领取库存；只有通过采集、加工、宗门持续行动、事件结算或资源槽附属设施产出，才实例化为 `sect_storage`、`node_storage`、事件锁定资产或角色行囊资产。
- 同一资源槽只能建设一类设施；投放数值必须给出该资源槽的设施规模上限，避免通过多设施叠加放大产出。
- 高于当前预算境界的 NPC 默认只按背景速度成长，不发生明显修为提升或突破。
- 不高于当前预算境界的 NPC 与其他玩家可受预算打开影响。

## 3. 投放不等于赠送

预算打开提供机会，不自动赠送修为。玩家仍需通过探索、宗门、市场、节点、事件、NPC 关系和风险选择创造高价值闭关条件。

## 4. 待补

- 每个境界资源包模板表。
- 阶段预算每个宏观周期的具体点数。
- 节点资源槽如何从预算池抽样，以及节点等级如何映射到资源槽数量、资源品级范围、灵气浓度和设施规模上限。
- 玩家资源充足倍率如何避免重复套利。

# 数值设计｜修为境界与期望游玩时间建模

状态：包内校准稿  
更新日期：2026-05-11

## 1. 设计定位

本文负责修为境界体系、标准修士背景年限、玩家现实体验目标、修为绝对值阈值、小境界修为绝对值上下界、阶段预算打开规则和 NPC 成长分层。

本文是小境界 `cp_lower_bound / cp_upper_bound` 的维护入口。修炼公式与数值设计文档只消费本文的上下界，不另行维护小境界比例表或具体上下界表。

本文不展开每小时修炼公式、资源输入公式、状态压力曲线、突破轮内评分和 tick 明细；这些内容由《02_修炼公式与数值设计.md》维护。本文不记录外部来源列表；已采纳的规则在正文中完整重述，保证本目录包内文档可独立阅读。

## 2. 当前结论

当前采用以下基准口径：

```text
标准修士修炼年限 = 世界观背景墙 / NPC 默认成长尺度 / 寿元压力参考 / 数值底表
玩家现实体验时间 = 随境界线性增长的目标
玩家实际成长速度 = 世界阶段预算、资源集中、灵地、丹药、宗门支持、功法掌握和主动决策共同压缩
```

稳定结论：

1. 标准修士年限不直接换算成玩家现实等待时间。
2. 玩家主线成长现实耗时按境界线性增长，不按标准年限指数增长。
3. 修炼调参以 `RealmSegmentBalance + normalized_segment_progress` 为核心，修为绝对值 `cultivation_points` 作为阈值、表现和日志映射。
4. 修为绝对值不直接线性换算成战斗力；战斗表现还必须读取境界倍率、小阶段倍率、根基质量、主修道功、状态、装备和战斗模板。
5. 玩家高倍率不来自无来源角色光环，而来自可追踪资源包、灵地、设施、宗门、功法、机会窗口和风险承受。
6. 阶段预算打开提供世界资源机会，不自动赠送修为。
7. 大境界突破由准备质量和 B1 轮内决策共同决定，不是修为达标后的概率按钮或自动升级。

## 4. 时间换算基准

数值设计使用以下底层时间单位：

```text
1 游戏日 = 24 游戏小时
1 游戏年 = 360 游戏日
服务器最小结算单位 = 1 游戏小时
```

公开速度只影响现实等待，不改变数值单位：

| 速度 | 现实换算 | 数值含义 |
| --- | --- | --- |
| N1 | 15 秒 = 1 游戏小时 | 常规世界推进、主动决策、短行动、队列编辑 |
| F1 | 2 秒 = 1 游戏日 | 长期低交互行动的压缩推进 |
| B1 | 60 秒 = 1 游戏小时 | 正式交锋、突破挑战、关键慢速轮 |
| P0 | 游戏时间不流动 | 公共决策、同步保护、主机暂停 |

按当前换算：

| 速度 | 1 游戏日 | 1 游戏年 |
| --- | --- | --- |
| N1 | 6 分钟 | 36 小时 |
| F1 | 2 秒 | 12 分钟 |
| B1 | 24 分钟 | 不用于长期修炼 |

裁决：

```text
N1 不是年级修炼的主承载速度。
F1 不是玩法目标，只是压缩低交互等待的手段。
B1 只用于突破挑战、正式交锋和关键慢速轮。
玩家核心玩法是在 N1、事件、宗门、地图、市场、NPC 和风险选择中创造高价值闭关条件，再用 F1 快速消化。
```

## 6. 修为绝对值 CP

修为绝对值表示角色当前累计修为规模，字段名为 `cultivation_points`。表格字段和公式字段可使用 `cp_` 前缀表示 cultivation points，但正文优先写“修为绝对值”，避免直接使用缩写造成歧义。

修为绝对值用于：

1. 小境界 / 大境界阈值判断。
2. 修炼收益、资源收益和闭关收益的表现映射。
3. NPC 成长速度与世界背景年限校准。
4. 突破开启条件。
5. 调试面板和高级详情展示。

推荐大境界圆满阈值按约 x5 递增：

| 境界 | CP 范围 | 圆满阈值 | 标准背景年限 |
| --- | ---: | ---: | ---: |
| 炼气 | 0-1,000 | 1,000 | 8 年 |
| 筑基 | 1,000-5,000 | 5,000 | 30 年 |
| 金丹 | 5,000-25,000 | 25,000 | 80 年 |
| 元婴 | 25,000-125,000 | 125,000 | 180 年 |
| 化神 | 125,000-625,000 | 625,000 | 360 年 |
| 炼虚 | 625,000-3,125,000 | 3,125,000 | 600 年 |
| 合体 | 3,125,000-15,625,000 | 15,625,000 | 900 年 |
| 大乘 | 15,625,000-78,125,000 | 78,125,000 | 1200 年 |
| 渡劫 / 飞升准备 | 78,125,000 以上 | 视终局规则 | 不建议纯 CP |

`cultivation_points` 是稳定表现值，不是调参唯一单位。调参应优先查看当前 `RealmSegmentBalance` 的目标小时、标准化进度需求、效率上下限和当前小阶段上下界。

## 7. 境界段与上下界关系

`RealmSegment` 是从一个稳定修炼状态推进到下一个关键里程碑的最小数值成长段，可以表示：

```text
炼气一层 -> 炼气二层
炼气九层 -> 炼气圆满
炼气圆满 -> 筑基开启资格
筑基准备期 -> 筑基成功并完成初步巩固
```

`RealmSegmentBalance` 必须能读取或保存：

```text
segment_id
realm_from
minor_stage_from
realm_to
minor_stage_to
segment_type
target_elapsed_hours_standard
expected_cultivation_hour_ratio
required_normalized_progress
cp_lower_bound
cp_upper_bound
raw_cultivation_required
min_efficiency_ratio
max_efficiency_ratio
```

字段口径：

1. `cp_lower_bound / cp_upper_bound` 来自本文的小境界修为绝对值上下界。
2. `raw_cultivation_required` 默认可由 `cp_upper_bound - cp_lower_bound` 派生，用于表现和日志映射。
3. `normalized_segment_progress` 是当前境界段调参进度，默认 `0.0` 到 `1.0+`。
4. `normalized_segment_progress >= 1.0` 表示达到该境界段目标，可进入下一阶段或开启突破资格校验。
5. `normalized_segment_progress > 1.0` 是超额准备，可转化为突破初始优势、品质修正或稳定性修正。

不得用一条全局经验曲线覆盖全部境界。不同境界、不同小阶段可以有不同 CP 跨度、目标小时、有效修炼小时占比、资源密度和效率边界。

## 8. 小境界修为绝对值上下界

小境界阈值使用修为绝对值上下界，而不是在系统设计文档中维护比例表。本节是小境界修为上下界的唯一信源；其他文档只引用本节，不重复维护比例表。

配置原则：

1. 每个小阶段都有独立的修为绝对值下界 `cp_lower_bound` 与上界 `cp_upper_bound`。
2. 玩家界面显示该小阶段自身进度 `0%-100%`，由当前 `cultivation_points` 在该阶段上下界之间换算。
3. 不同小阶段的修为绝对值跨度可以不同，允许后续按节奏、资源密度、瓶颈强度和玩法内容逐段定制。
4. 第一大境界默认分 9 层；第二大境界开始默认分初期 / 中期 / 后期 / 圆满四段。
5. 下表是默认种子配置，不是硬编码比例；后续平衡可直接改每一行上下界。

显示进度换算：

```text
minor_stage_display_progress =
  clamp(
    (cultivation_points - cp_lower_bound)
    / (cp_upper_bound - cp_lower_bound),
    0,
    1
  )
```

## 10. 玩家有效修炼倍率

按 F1 换算，1 游戏年约等于 12 分钟现实时间。若玩家每阶段只进行有限 F1 闭关，则实际游戏年远低于标准背景年限。

| 阶段 | 标准背景年限 | 玩家 F1 闭关现实时间 | 对应实际游戏年 | 需要的有效修炼倍率 |
| --- | ---: | --- | --- | --- |
| 炼气 -> 筑基 | 8 年 | 20-40 分钟 | 1.7-3.3 年 | x2.4-x4.8 |
| 筑基 -> 金丹 | 30 年 | 45-60 分钟 | 3.75-5 年 | x6-x8 |
| 金丹 -> 元婴 | 80 年 | 75-90 分钟 | 6.25-7.5 年 | x10.7-x12.8 |
| 元婴 -> 化神 | 180 年 | 100-120 分钟 | 8.3-10 年 | x18-x21.6 |
| 化神 -> 炼虚 | 360 年 | 120-150 分钟 | 10-12.5 年 | x28.8-x36 |
| 炼虚 -> 合体 | 600 年 | 150-180 分钟 | 12.5-15 年 | x40-x48 |
| 合体 -> 大乘 | 900 年 | 170-210 分钟 | 14.2-17.5 年 | x51-x63 |
| 大乘 -> 渡劫 | 1200 年 | 190-230 分钟 | 15.8-19.2 年 | x62-x76 |

推荐阶段倍率方向：

| 阶段 | 标准修士倍率 | 普通 NPC 预算后 | 重点 NPC / 竞争者 | 正常玩家 | 资源充足玩家 |
| --- | --- | --- | --- | --- | --- |
| 炼气 | x1 | x1.2-x1.8 | x2-x4 | x2-x4 | x3-x5 |
| 筑基 | x1 | x1.5-x2.5 | x3-x6 | x4-x7 | x6-x8 |
| 金丹 | x1 | x1.5-x3 | x4-x8 | x7-x10 | x10-x13 |
| 元婴 | x1 | x2-x4 | x5-x10 | x12-x16 | x18-x22 |
| 化神 | x1 | x2-x4 | x6-x12 | x20-x28 | x29-x36 |
| 炼虚 | x1 | x2-x5 | x8-x15 | x30-x40 | x40-x48 |
| 合体 | x1 | x2-x5 | x10-x18 | x40-x55 | x51-x63 |
| 大乘 | x1 | x2-x5 | x12-x20 | x50-x65 | x62-x76 |

这些倍率不是角色坐着吐纳时的无来源加成，而是资源、灵地、宗门支持、功法、机会窗口和风险承受的综合结果。

## 11. 资源包与阶段循环

玩家高倍率应来自可追踪的阶段修炼资源包。

| 资源包 | 作用 |
| --- | --- |
| 灵地时段包 | 提供高 aura 兼容小时 |
| 丹药药力包 | 提供修为灵气输入，但增加经脉压力或药性残余风险 |
| 灵材辅助包 | 降低副作用或提高突破准备质量 |
| 宗门护持包 | 降低风险，提高闭关稳定性 |
| 功法参悟包 | 提高 `MethodState` 掌握度，间接提升修炼效率 |
| 突破专用包 | 在 B1 突破轮内可消耗 |
| 秘境机缘包 | 高收益、高风险，可能附带状态标签 |

资源包不直接给等级，而是提供：

```text
compatible_hours
normalized_progress_bonus
risk_modifier
meridian_pressure_delta
method_mastery_delta
breakthrough_quality_modifier
```

推荐主循环：

```text
发现资源线索
-> 争取节点 / 宗门 / 市场 / 事件
-> 获得阶段资源包
-> 绑定到修炼或突破准备行动
-> F1 短闭关消化
-> 小境界 / 瓶颈反馈
-> 重复 2-4 次
-> 突破准备
-> B1 突破挑战
```

## 12. 阶段预算机制

阶段预算用于解释沙盒世界为何随玩家境界推进而开放新资源。

```text
WorldStageBudgetState {
  active_budget_realm: Realm
  unlocked_realm_history: Array
  unlocked_by_character_refs: Array
  current_macro_period_id: String
  budget_pools: Dictionary<Realm, RealmBudgetPool>
  next_realm_leakage_rate: number
  catchup_policy: Dictionary
  high_realm_npc_progress_policy: Dictionary
}
```

每个境界对应一个预算池：

```text
RealmBudgetPool {
  realm: Realm
  total_budget_points_per_macro_period: number
  production_budget_refs: Array
  node_resource_budget: number
  sect_inventory_budget: number
  market_trade_budget: number
  opportunity_window_budget: number
  npc_personal_budget: number
  method_carrier_budget: number
  breakthrough_material_budget: number
  active: bool
}
```

预算激活规则：

```text
on_major_breakthrough_success(character, new_realm):
  if character.is_player_controlled
     and new_realm > WorldStageBudgetState.active_budget_realm:
      WorldStageBudgetState.active_budget_realm = new_realm
      activate_budget_pool(new_realm)
      schedule_budget_distribution(next_macro_period)
```

裁决：

1. 阶段预算是世界产出预算的境界调度层，不是角色奖励池。
2. 预算激活是系统事实，不等于公开传闻。
3. 是否公开某玩家突破，由可见性、宗门传闻、玩家选择和事件结果决定。
4. 预算打开提供资源机会，不自动发放修为。
5. 预算投放必须进入节点资源槽、宗门库存、市场、机会窗口、NPC 个人资产、事件锁定奖励或其他可审计资产链路。

## 13. 阶段预算投放

推荐每个阶段预算按以下方向投放。表中比例是境界调度建议；实际投放必须落到资源池、资源槽、库存、市场、事件或资产容器。

| 预算出口 | 建议占比 | 作用 |
| --- | --- | --- |
| 节点资源槽 | 35%-45% | 灵草、矿材、灵脉波动、妖兽材料、秘境产物 |
| 宗门库存 / 任务 | 20%-25% | 宗门资源申请、护法、丹药、功法载体 |
| 市场 / 交易 | 10%-15% | 坊市、商队、黑市、拍卖 |
| 机会窗口 / 事件 | 15%-20% | 秘境窗口、遗迹、机缘事件、争夺事件 |
| NPC 个人库存 | 5%-10% | NPC 可交易、可赠予、可争夺、可掉落资源 |

预算不应瞬间刷满，而应在 1-3 个宏观周期内逐渐显现：

```text
突破当刻：个人结果、宗门反应、少量相关机会。
下一个宏观周期：节点资源槽开始出现新阶段资源。
第二个宏观周期：宗门库存、市场、NPC 资源开始扩散。
第三个宏观周期：该阶段资源成为稳定世界预算。
```

## 14. 先锋资源与预算打开

为了让第一个突破到新境界的玩家合理成立，需要区分先锋资源和阶段预算。

先锋资源是突破前就能少量获得的下一阶段关键资源：

```text
next_realm_leakage_rate = 5%-10%
```

来源：

```text
高风险节点；
一次性秘境；
宗门特殊申请；
师承任务；
遗迹；
黑市；
强敌掉落；
后手遗产；
小概率事件。
```

先锋资源仍必须来自已存在资产、事件锁定奖励、后手遗产、专属资源池或明确预算泄漏，不允许无限刷新，也不允许绕过来源日志和可见性记录。先锋资源不足以让整个世界大量成长，但足以让主动玩家集中资源完成突破。

## 15. NPC 与其他玩家成长分层

NPC 成长由其境界是否高于当前阶段预算决定。

高于当前预算境界的 NPC：

```text
npc.realm > WorldStageBudgetState.active_budget_realm
```

规则：

```text
只走标准修士背景速度；
无法稳定获得本境界所需资源；
每个宏观周期修为进度变化很小；
默认不发生小境界晋升；
默认不发生大境界突破；
除非剧情、后手、宗门重大事件或专属资源池触发。
```

建议：

```text
visible_progress_cap_per_macro_period = 0.1%-0.5%
breakthrough_allowed = false by default
minor_stage_advance_allowed = scripted_only
```

不高于当前预算境界的 NPC：

```text
npc.realm <= WorldStageBudgetState.active_budget_realm
```

可以吃到阶段预算，但仍低于玩家主动路径倍率。

| NPC 类型 | 预算打开后的有效修炼倍率 |
| --- | --- |
| 普通 NPC | x1.2-x2 |
| 宗门重点培养 NPC | x2-x4 |
| 天才 / 亲传 / 关键竞争者 | x4-x8 |
| 剧情级竞争者 | x8-x12，但需要显式记录来源 |

其他玩家：

```text
低参与玩家：x2-x4
正常参与玩家：x5-x12
资源集中玩家：接近领先玩家倍率
显式托管玩家：倍率明显降低，错过高价值机会
```

预算打开不会自动赠送修为；其他玩家仍需要决策、行动、争夺和突破。

## 16. 突破承接

修为绝对值或标准化进度达标只是开启条件。真正突破由准备质量、B1 轮内策略、轮内资源消耗、状态变化和模板结局共同决定。

大境界突破结构：

```text
准备期
-> 开启突破短指令
-> 突破挑战 B1
-> 个人结果报告
-> 后续选择
```

开启条件建议至少读取：

```text
normalized_segment_progress >= 1.0
method_mastery_norm >= required_method_mastery_norm
foundation_quality >= required_foundation_min
meridian_pressure <= allowed_meridian_pressure_max
injury <= allowed_injury_max
mental_risk <= allowed_mental_risk_max
location_allows_breakthrough == true
method_template_available == true
required_resource_available == true
```

突破成功后应立即形成境界质变，但提升来源不是 CP 瞬间暴涨，而是：

| 来源 | 占比感 | 具体变化 |
| --- | --- | --- |
| 境界倍率 | 40%-50% | `realm_power_multiplier` 进入新境界 |
| 属性质变 | 20%-30% | 体魄、神识、灵力上限、经脉承载上限提升 |
| 修为稳定度 | 10%-20% | 新境界稳定度从低值起步，后续通过巩固提高 |
| 术法 / 行动解锁 | 情境性强 | 飞行、婴火、神识离体、天地元气调用等 |

推荐战斗表现公式方向：

```text
combat_power =
  base_stat_score
  * realm_power_multiplier[realm]
  * minor_stage_multiplier
  * foundation_quality_factor
  * method_mastery_factor
  * current_cultivation_fullness_factor
  * state_factor
  + equipment_spell_bonus
```

当前小阶段进度；
当前瓶颈状态；
预计还需游戏时间；

境界：筑基中期
进度：约 42%

本次闭关：90 游戏日

风险：经脉压力 +6，心魔风险低
```

```

## 18. 调参验收口径

修为境界与期望时间调参至少验证：

1. 玩家看到的每个小阶段都能从自身 `0%-100%` 推进。
2. 小阶段之间的修为绝对值跨度、有效修炼小时和资源需求可以不同。
3. 炼气前期反馈明显快于后段，炼气 8-9 层能形成第一次瓶颈感。
4. 筑基以上默认四段结构可用，但不强迫所有境界复用同一比例。
5. 主动经营时间和 F1 闭关消化时间合计能落入本文的玩家现实目标。
6. 高倍率资源必须受到境界适配、状态压力和段级效率上限约束。
7. 阶段预算打开后，世界机会增加，但角色不会无来源获得修为。
8. 高于当前阶段预算的 NPC 不会无来源小境界晋升或大境界突破。
9. 大境界突破不能只靠修为绝对值达标自动完成。
10. UI 摘要能解释“还差多少、为什么慢、如何变快、风险在哪里”。

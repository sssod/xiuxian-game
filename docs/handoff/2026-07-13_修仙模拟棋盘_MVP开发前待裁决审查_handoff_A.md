## 4. 本轮回写后真正仍待裁决的规则项目

### 4.1 `CATCHUP-01`｜落后者专属追赶与节点易主事件

当前已有的基础追赶：

- 全图灵气按回合固定增长，低境界总 CP 不动态抬高；
- 转世角色保留历史突破记录，重修满历史境界后自动跨越；
- 转世灵石补足到基础经营节点标价 `0.5` 倍下限；
- 后期自然灵气让重修者更快返回历史最高境界。

仍需用户决定：

1. 首轮 MVP 是否还需要“只有落后者可用”的专属追赶；
2. 若需要，落后判定读境界、历史最高境界、地产、灵石、死亡次数还是组合条件；
3. 追赶是资源补给、移动帮助、小洞天机会、地产易主事件还是其它形式；
4. 是否允许落后者通过事件取得退隐宗门地产或其它有主节点；
5. 效果持续多久、何时失效、是否可叠加；
6. 若不进入 MVP，必须明确写成首轮延期，并验证现有自然追赶足以完成对局。

这是当前最重要的剩余规则裁决之一，因为它会改变死亡惩罚、地产稳定性和后半局竞争。

### 4.2 `DIPLOMACY-01`｜普通关系、仇敌完整表与盟友范围

当前只确认：

- 普通收费、资源转移和无主节点争购不自动建立仇敌；
- 仇敌是宗门之间的关系，并能在移动相遇时触发强制事件；
- 首轮没有盟友免租或折扣；
- 现有文本对仇敌建立、解除和持续回合只有局部边界，没有完整入口和效果表。

仍需用户决定：

1. MVP 是否保留玩家主动宣战 / 解除仇敌；
2. 发起时点、解除时点、最低持续期、公开范围和是否需要成本；
3. 仇敌对相遇、PVP、节点使用、收费、关隘和飞升前阻拦的完整效果；
4. 普通关系是否只是“非仇敌”默认态，还是拥有独立效果；
5. 盟友功能是明确延期，还是制作一个无经济折扣的最小版本；
6. 宗门身份在 MVP 中是否固定整局，任何中途改宗是否明确延期。

若决定首轮不制作外交系统，必须同步删除或封闭会调用主动宣战、解除和盟友效果的入口，不能保留半套仇敌状态。

### 4.3 `GATE-01`｜关隘障碍与路线反制范围

当前地图框架要求：

- 固定六边格地图；
- 每个出生区至少两条通往共享区的路线；
- 路线不能被永久封死；
- 关隘可以收费，所有者使用自有节点时免自身关隘费用与障碍。

仍需用户决定：

1. MVP 的关隘只是固定地图收费节点，还是允许玩家设置临时路线障碍；
2. 若允许设置，使用即时行动、主要行动、建筑功能还是事件；
3. 设置与解除时点、成本、持续期、同一路线叠加和所有者上限；
4. 反制、绕行、强行突破或支付通行的规则；
5. 与仇敌 / 普通关系、飞升阻拦和替代路线的关系；
6. 若延期玩家障碍，首图只保留固定收费关隘，并从 MVP 内容表移除动态障碍字段。

该项目必须在首张地图定稿前关闭或明确延期，否则路线风险、节点价值和飞升阻拦无法配表。

### 4.4 内容依赖后才能关闭的局部规则门

这些项目不宜现在脱离内容空谈，但在正式内容表冻结前必须有答案：

| 项目 | 当前边界 | 关闭方式 |
| --- | --- | --- |
| 通用竞价合同 | 无主地产暗标已完整；其它事件可以调用战斗或竞价 | 每个实际调用竞价的事件明确支付资源、最低出价、败方支付与平价规则；若首轮无其它通用竞价，明确延期通用合同 |
| 同层世界结算顺序 | 现有模板不得利用隐式先后获利 | 内容表完成后列出真实依赖；若没有相互依赖，验收声明“不需要额外顺序表” |

### 4.5 在线产品策略，不属于玩法重裁但必须在开发计划前定需求

多人基础行为已经关闭，但以下实施面对的产品政策仍需明确：

- 全员离线冻结后的会话保存时长；
- 保存到期时是否直接记为无胜者中止，以及玩家看到的恢复 / 过期提示；
- 标准计时之外是否在 MVP 提供快速 / 宽松房间预设；若不提供，只实现标准 `60 / 90 / 45 / 30 + 180` 秒方案；
- 未来策略 AI 托管不属于 MVP，MVP 只实现安全默认托管；
- 联机身份验证、重连席位识别和会话迁移属于开发方案，不应反向改写玩法裁决。

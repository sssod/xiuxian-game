# 修炼系统数值投放收敛裁决

适用范围：`docs/xiuxian_design_docs` 中修炼、修为境界、功法、丹药、突破、角色属性和投放数值相关文档。

## 1. 当前定位

本文用于临时沉淀“修炼系统消耗资源与时间后，已有设计已经承诺投放哪些数值”的收敛盘点。后续用户裁决后，再把稳定结论写回对应主题文档。

本文不替代《修炼公式与数值设计》（`../03_数值设计/02_修炼公式与数值设计.md`）、《修炼玩法设计》（`../02_系统设计/11_修炼玩法设计.md`）或其他正式主题文档，也不新增具体数值表。本文只记录当前正式包内已经出现的投放项、归属边界和待裁决问题。

本轮只聚焦“获得数值”侧，不展开资源消耗、时间消耗、资产来源、投放预算和完整反套利公式。

## 2. 使用方式

1. 后续收敛修炼数值投放时，先以本文确认已有投放项，避免重复新增同义字段。
2. 若用户确认某项应属于修炼系统直接投放，再写回修炼玩法、修炼公式或角色修为文档。
3. 若某项只应作为突破、功法、丹药、事件或属性系统的投放，应在写回时保留系统边界，避免修炼系统吞并其他系统职责。
4. 发现正式包内新增冲突或旧口径残留时，先补入本文待裁决项，再统一处理。

## 3. 当前已有数值投放项

### 3.1 修炼行动直接结算

以下项目已经在修炼玩法、修炼公式和修为境界文档中作为修炼行动或 `CultivationTickResult` 的结算输出出现。

| 投放项 | 已有字段或口径 | 当前归属判断 | 边界 |
| --- | --- | --- | --- |
| 修为绝对值 | `cultivation_points_gain`、`cultivation_points_before / after` | 修炼系统主投放 | 主动吐纳、闭关修炼和少量自动运转可以推进；修为丹药必须依附主动吐纳兼容小时，不允许即时服药涨修为 |
| 境界段标准化进度 | `normalized_gain`、`normalized_segment_progress_before / after` | 修炼系统主投放 | 用于小阶段推进、瓶颈和突破开启；普通 UI 包装为当前小阶段 0%-100% 进度 |
| 经脉压力 | `meridian_pressure_delta`、`state_pressure_delta` | 修炼副产物，可正可负 | 高倍率、跨阶资源、污染环境、带伤冲修等会增加；巩固根基、保守修炼或资源可降低或预防 |
| 根基质量 / 根基稳定 | `foundation_quality_delta` | 修炼与巩固共同承接 | 巩固根基可改善；突破准备和突破品质会读取；具体范围、阈值和公式未定 |
| 修为纯度 | `purity_delta` | 修炼质量结果 | 受修炼质量、杂质、速成副作用和资源吸收稳定性影响；既往纯度不应被功法掌握度事后改写 |
| 残余资源效果 | `active_resource_effect_delta`、`resource_effects_consumed` | 资源状态投放 / 清理项 | 行动中断或资源未完整释放会生成残余；巩固根基可收束残余修为药性，但不能转为修为进度 |
| 突破准备变化 | `breakthrough_readiness_delta` | 修炼到突破的桥接输入 | 修炼数值只提供准备质量和初始分输入，最终突破仍由 B1 突破挑战决定 |
| 时间域与寿元结算摘要 | `effective_cultivation_inner_years`、`unsupported_inner_years`、`lifespan_time_domain_used` | 结算结果，不是收益本身 | 洞天 / 时间阵法闭关必须记录有效修炼年、资源不足年和寿元扣除口径 |

### 3.2 研习功法结算

研习功法属于修炼相关行动，但已有设计明确它不直接投放修为。

| 投放项 | 已有字段或口径 | 当前归属判断 | 边界 |
| --- | --- | --- | --- |
| 功法掌握经验 | `mastery_exp_gain` | 功法系统主投放 | 研习道功或法门获得；悟性丹只在研习行动兼容小时内生效 |
| 功法掌握等级 | `mastery_level_before / after` | 功法系统主投放 | 可提高道功当前可修上限、单位时间收益或法门解锁强度 |
| 标准化掌握度 | `mastery_norm_before / after` | 功法系统主投放 | 可被突破开启条件、功法效果缩放和 UI 摘要读取 |
| 当前可修上限变化 | `cap_stage_before / after` | 道功掌握结果 | 只影响当前可修上限，不提高道功理论最高上限 |
| 解锁项 | `unlocked_effect_refs` | 功法系统投放 | 可包括被动、提示型收益、行动标签、战斗指令、事件选项或配方 |
| 研习压力变化 | `state_pressure_delta` | 研习副产物 | 神念、伤势、心魔、疲劳、跨阶学习和资源输入会影响 |

研习道功和研习法门都不能直接投放修为进度，不能补齐残页或篇章，不能改变大境界突破模板类型，不能事后改写小境界奖励质量或修为纯度既往结果。

### 3.3 小境界与大境界承接投放

修炼行动把角色推到阶段节点后，小境界升级和大境界突破会承接额外数值变化。

| 场景 | 已有投放项 | 当前归属判断 | 边界 |
| --- | --- | --- | --- |
| 小境界升级 | 更新 `minor_stage`、当前境界段和进度续接 / 归零规则 | 角色修为与境界系统承接 | 可由修炼结算触发，但不进入完整突破事件链 |
| 小境界升级 | 小阶段倍率 | 角色修为与境界系统承接 | 用于当前大境界内战斗表现差异；具体倍率未定 |
| 小境界升级 | 生机、元气、神念少量提升 | 角色属性 / 境界系统承接 | 已被列为轻量收益，但具体数值和是否每层都有待裁决 |
| 小境界升级 | 主修道功支持范围内的少量被动、行动修正或提示型能力 | 功法 / 修为境界共同承接 | 不应改变道功理论最高上限或突破模板 |
| 大境界突破成功 | 新 `realm`、修为上限打开、寿元上限提高、基础派生状态提高 | 角色修为与突破系统承接 | 必须由玩家主动发起并经过突破挑战，不由修为达标自动完成 |
| 大境界突破成功 | `realm_power_multiplier` 境界倍率 | 角色修为 / 战斗表现承接 | 形成大境界质变，但修为绝对值不等于线性战斗力 |
| 大境界突破成功 | 体魄、神念 / 神识、元气 / 灵力、经脉承载等核心承载能力提升 | 角色属性 / 突破结果承接 | 术语存在待统一问题：属性数值文档使用“神念、元气”，突破收益描述中仍有“神识、灵力上限” |
| 大境界突破结果 | 突破品质、根基变化、伤势、寿元变化、资源消耗、失败标签 | 突破系统承接 | 完美、正常、残缺、失败存活、身死转世等结果都需写入结果包和轮回账本 |

### 3.4 丹药与行动资源输入的数值出口

丹药和资源不是修炼系统凭空奖励，而是绑定行动、事件、炼化或突破模板后产生数值出口。

| 资源类型 | 已有数值出口 | 当前归属判断 | 边界 |
| --- | --- | --- | --- |
| 修为丹药 | `resource_aura_input` / `cultivation_resource_aura_input`，再转入修为进度和压力 | 修炼资源输入 | 只能挂载主动吐纳或闭关内部主动吐纳片段；不提供即时经验药或独立炼化涨修为 |
| 悟性丹 | `method_exp_gain` 修正 | 研习资源输入 | 只在研习功法兼容小时内产生功法经验收益 |
| 解毒 / 避瘴丹 | `toxic_risk_delta`、`poison_pressure_delta` | 环境与事件资源输入 | 不直接投放修为 |
| 疗伤丹 | `vitality_recovery`、`injury_delta` | 状态恢复资源输入 | 不作为修为成长主路径 |
| 定心丹 / 清神丹 | `mind_stability_delta`、`risk_tag_delta`、突破修正 | 巩固、研习、突破资源输入 | 可降低风险或稳定心神，不应回溯重算已结算阶段 |
| 突破丹药 | `breakthrough_success_delta`、`breakthrough_quality_delta`、`risk_delta` | 突破事件链资源 | 由突破模板专门结算，不进入普通残余药性状态 |
| 属性丹 / 洗髓丹 | `attribute_modifier`、`aptitude_modifier` | 角色属性 / 资质投放 | 需要安全环境和显式炼化，未完成前不提前发放完整效果 |
| 延寿丹 / 寿元丹药 | `lifespan_extension` | 寿元投放 | 完成炼化后增加寿元上限，并受寿元模块统一总量限制 |
| 危险剧情丹药 / 强制释放 | `forced_release` 分支 | 非 MVP 预留 | MVP 完全不投放实际内容，只保留字段和未来分支 |

### 3.5 明确不是直接投放的项目

以下项目已经在正式包内被限制为输入、机会或修正，不应被误写成修炼系统直接发放。

| 项目 | 当前边界 |
| --- | --- |
| 阶段预算 | 打开世界资源机会，不自动赠送修为、库存或角色资产 |
| 节点灵气、设施、宗门支持、洞天 | 进入修炼公式的输入或修正，不绕过行动时间、资源输入、主修道功和角色状态压力 |
| 法门 | 不直接推动修为，不决定当前可修上限，不成为主修；只提供能力、指令、事件选项、效率、消耗、品质或风险修正 |
| 道功掌握度 | 可影响当前可修上限和单位时间收益，但不提高理论最高上限，不改变突破模板，不事后补发纯度或小境界奖励 |
| 修炼过程中的功法掌握增长 | 主动吐纳、闭关修炼和自动运转只读取当前主修道功掌握度，不增加主修道功掌握经验或掌握等级 |
| 洞天内主观时间 | 可用于局部修炼年和寿元压力，不驱动外界阶段预算、市场、宗门库存、节点资源或 NPC 宏观成长刷新 |
| 残余修为药性收束 | 可止损、减压、降低副作用和清理残余，但不转化为修为进度 |

## 4. 当前收敛判断

按已有设计，修炼系统已经承诺的核心数值获得不是单一“经验值”，而是至少包含四层：

1. 主成长层：修为绝对值、境界段标准化进度。
2. 行动附带层：残余资源效果、时间域与寿元结算摘要。
3. 质量与压力层：经脉压力、根基质量、修为纯度、心魔 / 伤势等状态压力变化。
4. 阶段承接层：小境界轻量收益、大境界突破收益、突破品质与失败标签。

裁决：修炼过程不再增加当前主修道功的功法掌握度。主动吐纳、闭关修炼和自动运转可以读取当前主修道功、掌握度、相性、吸收和转化口径来计算修为收益与风险，但不得写入 `method_mastery_delta`、`MethodState.mastery_exp` 或掌握等级变化。功法掌握增长只由研习功法等功法系统行动承接。

后续若要继续“收窄修炼系统投放”，应优先把修炼行动直接投放限定在主成长层和质量与压力层；功法研习、属性丹、延寿丹、突破丹药、法门解锁和世界预算仍由各自系统作为主归属，只在修炼页面或结果包中展示摘要。

## 5. 待裁决与待补

| 项目 | 当前口径 | 需要裁决或补充 |
| --- | --- | --- |
| 修炼系统直接投放边界 | 已排除修炼过程增加主修道功掌握度；暂列修为、标准化进度、压力、根基、纯度、残余和突破准备变化 | 继续裁决残余、突破准备变化和状态压力中哪些应保留为修炼系统直接输出 |
| 小境界收益归属 | 已有轻量阶段收益、派生状态小幅提升和功法效果解锁 | 是否作为修炼结果写入，还是只在角色修为与境界文档维护 |
| 根基质量与修为纯度 | 已多处作为突破准备和质量口径出现 | 需要定义数值范围、增减来源、显示时机、是否长期累计和修正路径 |
| 经脉压力 / 心魔 / 伤势 | 已作为状态压力参与收益与惩罚 | 需要统一哪些属于修炼系统输出，哪些属于持续状态系统事实字段 |
| 神念 / 神识、元气 / 灵力术语 | 当前包内存在术语混用 | 需要在写回时统一为角色属性文档的正式字段，或补充世界观别名关系 |
| 属性丹、洗髓丹、延寿丹 | 已有完成炼化后投放属性、资质或寿元的口径 | 是否纳入“修炼系统资源投放”讨论，还是作为丹药 / 属性 / 寿元专题单独收敛 |
| 突破准备变化 | `breakthrough_readiness_delta` 已在修炼结果包中出现 | 需要确定它是独立数值、多个准备维度摘要，还是由根基、纯度、压力、资源和地点派生 |
| 小境界派生属性数值 | 目前只写“少量提高生机、元气、神念” | 需要补具体数值、曲线、是否每层固定、是否受主修道功或突破品质影响 |

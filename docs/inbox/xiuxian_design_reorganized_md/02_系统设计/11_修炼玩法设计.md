# 修炼玩法设计

## 1. 设计定位

修炼玩法负责玩家如何通过行动、资源、环境、功法和状态管理推进修为。它回答的是“玩家做什么、看到什么、如何规划和止损”，不负责定义每小时收益公式或境界段数值表。

修炼不是挂机等待。玩家的核心循环是：

```text
在 N1、事件、宗门、地图、市场和 NPC 互动中创造高价值修炼条件
→ 规划主动吐纳、闭关、资源输入或巩固根基
→ 在 F1 中快速消化低交互等待
→ 通过小境界反馈、瓶颈提示和突破准备调整下一轮经营
```

## 2. 当前结论

1. 玩家主动修炼以行动规划为入口，不以单独经验药按钮为入口。
2. 主动吐纳是获得修为和主修道功经验的主要行动。
3. 研习功法获得目标功法经验，不直接获得修为。
4. 自动运转提供少量被动收益，通常可触发小境界升级，但不能完成大境界突破。
5. 巩固根基用于处理状态、压力、残余药性和突破准备，不替代主动吐纳获得修为。
6. 修为类丹药只能作为主动吐纳的资源输入，不提供独立“丹药炼化”行动。
7. 资源输入采用行动内折叠项；已有残余效果在角色面板或行动规划器中常驻提示。
8. 修为绝对值表示角色当前累计修为规模，字段名为 `cultivation_points`；修炼公式、效率倍率、境界段修为绝对值和 `CultivationTickResult` 由修炼数值文档维护。

## 3. 行动类型

| 行动 | 玩家意图 | 主要收益 | 玩法边界 |
| --- | --- | --- | --- |
| 主动吐纳 | 投入时间推进当前境界段 | 修为进度、主修道功经验、资源输入转化 | 可挂载修为丹药和灵气类资源 |
| 闭关修炼 | 长时间低交互修炼 | 批量推进修为、消化资源和环境收益 | 可进入 F1；仍按小时结算 |
| 自动运转 | 非吐纳状态下的低额自然推进 | 少量修为或稳定性收益 | 不能完成大境界突破 |
| 研习功法 | 学习或提高道功 / 法门掌握 | 功法经验、可修上限、提示型或知识型收益 | 不直接给修为 |
| 巩固根基 | 降低压力、稳定根基、处理残余药性 | 经脉压力下降、根基稳定、纯度修正或药性收束 | 不把残余修为药性转化为修为 |
| 突破准备 | 为大境界突破集中处理短板 | 资源、地点、护法、状态、纯度和根基准备 | 不等同于开启突破 |
| 显式托管 | 玩家主动设置低交互保守行动 | 低收益、低风险、减少离线损失 | 不主动发起高风险突破 |

## 4. 主动吐纳

主动吐纳是修为推进的核心行动。玩家选择持续时间、地点、主修道功和兼容资源输入后，系统按实际兼容小时结算。

主动吐纳读取：

1. 当前境界与小阶段。
2. 当前主修道功和掌握度。
3. 所在节点灵气、设施、机会窗口和宗门支持。
4. 角色资质、伤势、心魔、经脉压力、根基质量和修为纯度语境。
5. 行动内选择的资源输入。

主动吐纳不应被设计成“立刻获得修为”的按钮。即使玩家使用丹药，资源也必须随主动吐纳实际执行小时释放。

## 5. 自动运转

自动运转表示角色在多数非吐纳、非突破、非重伤状态下维持的低额修行。

规则：

1. 自动运转可以产生少量修为或稳定性收益。
2. 自动运转可以触发普通小境界升级。
3. 自动运转不能完成大境界突破。
4. 自动运转不应消耗玩家未显式选择的关键资源。
5. 自动运转结果应进入日志，但普通 UI 不需要展示完整数值公式。

自动运转的目的不是替代主动吐纳，而是让连续世界中角色不会因为没有显式闭关就完全停摆。

## 6. 巩固根基

巩固根基用于处理日常修炼带来的副作用和突破前状态短板。

它可以用于：

1. 降低经脉压力。
2. 稳定根基质量。
3. 在突破准备语境中改善修为纯度或状态短板。
4. 选择性收束残余修为药性，减少散逸或压力风险。
5. 为后续主动吐纳或大境界突破创造更稳定条件。

巩固根基不能用于：

1. 把残余修为药性直接转化成修为进度。
2. 替代主动吐纳消化修为丹药。
3. 免费修复所有压力和伤势。
4. 绕过大境界突破准备条件。

当角色体内存在稳定残余药性时，巩固根基默认不自动消耗；界面必须让玩家明确选择“保留药性”或“收束药性”。刺激型或强制释放型药性应强提示风险，建议继续主动吐纳或巩固根基收束。

## 7. 行动资源输入

行动资源输入是玩家在规划某个行动时选择额外投入一类资源。资源只在行动实际执行期间按兼容小时生效，并进入该行动的结算管线。

示例：

```text
行动：主动吐纳 2 天
额外输入：清灵丹 × 1

行动：研习《青木养真诀》1 天
额外输入：启悟丹 × 1

行动：探索毒瘴谷
额外输入：避瘴丹 × 1
```

行动资源输入不改变行动本身类型：

1. 主动吐纳仍然是主动吐纳。
2. 研习功法仍然是研习功法。
3. 探索、移动、治疗、突破事件选项仍然保留原语境。
4. 资源只是挂载输入，不成为默认独立行动入口。

## 8. 修为丹药规则

修为类丹药只作为主动吐纳的额外资源输入。

合法：

```text
主动吐纳 24 小时，附加清灵丹 × 1。
```

非法：

```text
即时服用清灵丹，立即获得修为。
单独执行丹药炼化 12 小时。
移动途中服用清灵丹，持续获得修为。
```

主动吐纳中存在两条输入流：

| 输入流 | 玩法含义 |
| --- | --- |
| 环境灵气流 | 节点灵气、聚灵阵、灵液池等，受道功吸收速度和状态限制 |
| 修为丹药资源流 | 丹药释放定额灵气包，跳过道功吸收速度，但仍进入转化与承载压力 |

修为丹药不是提高节点灵气浓度、提高聚灵阵效果或简单提高最终倍率，而是在主动吐纳期间释放额外修为灵气输入。

## 9. 残余效果

当行动时间短于资源完整有效时长、行动被事件打断，或资源只消耗了部分兼容小时，系统生成残余效果。

残余效果应表达：

1. 资源名称。
2. 剩余可生效小时。
3. 当前稳定性。
4. 后续可承接行动。
5. 散逸、反噬或经脉压力风险。

稳定残余示例：

```text
体内仍有未尽药性：清灵丹，约 6 小时。
执行主动吐纳可继续承接。
若长时间不处理，药性可能散逸。
```

刺激型残余示例：

```text
体内仍有烈性药性：赤焰速元丹，约 4 小时。
非修炼行动期间可能快速散逸并造成经脉压力。
建议：继续主动吐纳或巩固根基收束。
```

## 10. 资源输入界面

资源输入主入口放在具体行动界面内，采用行动内折叠项。玩家选择具体行动后，只显示与该行动兼容的资源输入。

主动吐纳界面示例：

```text
行动：主动吐纳
计划投入：12 小时
可用资源输入：
- 清灵丹：20 灵气 / 小时，最多 12 小时
- 木髓液：适配木系道功，释放稳定

当前选择：清灵丹 × 1
预计本次释放：12 / 12 小时
```

如果行动时间不足：

```text
行动：主动吐纳
计划投入：6 小时
当前选择：清灵丹 × 1
完整药性：12 小时
预计本次释放：6 / 12 小时
剩余：约 6 小时药性，将暂留体内
```

不采用默认全局资源栏作为主入口，避免资源栏变成背包搜索和倍率堆叠界面。已有残余效果仍应在角色面板或行动规划器中常驻提示。

## 11. F1 与低交互消化

闭关修炼、主动吐纳、研习功法、巩固根基、疗伤和显式托管等长期低交互行动可以按规则进入 F1。

F1 的玩法意义：

1. 压缩现实等待。
2. 快速消化玩家已创造的高价值修炼条件。
3. 让低交互行动不阻塞多人房间体验。

F1 不改变数值单位。修炼、资源输入、残余效果、压力变化和小境界判定仍按世界小时与实际兼容小时结算。

## 12. 反馈与提示

普通玩家 UI 应优先展示可决策信息：

1. 当前小阶段自身进度。
2. 本次行动预计收益区间。
3. 是否会消耗资源输入。
4. 是否产生残余药性。
5. 经脉压力、根基、伤势或心魔是否接近风险阈值。
6. 是否接近瓶颈或突破准备语境。
7. 巩固、疗伤、提纯或换地点等可执行修正路径。

Debug / QA 信息不进入普通 UI，例如完整公式追踪、原始效率倍率、裁剪前后倍率和境界段内部 ID。

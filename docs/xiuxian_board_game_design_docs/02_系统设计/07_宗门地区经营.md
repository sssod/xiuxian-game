# 系统设计｜宗门地区经营

适用范围：宗门作为地区影响力、地图占地和轻量经营系统的定位、已确认接口与 MVP 阶段门。

## 1. 设计定位

宗门不再承担复杂组织模拟或世界演化核心。它是一套类似棋盘地产经营的辅助系统，为个人修仙提供资源、路线控制和竞争机会，但不取代飞升竞速成为主进度轴。

## 2. 已确认规则

1. 玩家通过主要行动与资源投入获取地区影响力。
2. 地区影响力承担地点归属、升级和地图功能的基础职责。
3. 经营结果可以提供资源、封锁区域或其它地图能力。
4. 与玩家存在仇恨关系的其他玩家拥有高地区影响力时，该地点可以成为敌对地点，并阻止玩家在此发起大境界突破。
5. 宗门经营收益必须服务个人成长、移动或构筑。

## 3. 尚未形成的最小闭环

当前仍未裁决：

- 地区影响力的空间单位；
- 首次取得与升级条件；
- 多玩家共同投入或争夺方式；
- 收益频率与收益类型；
- 封锁阈值与反制方式；
- 竞价 / 战斗在地区争夺中的使用；
- 转世后的影响力归属；
- 宗门是否拥有共享资产或仅表达个人地产。

## 4. MVP 范围选择门

下一阶段必须先二选一：

1. 首轮 MVP 实现一个最小地区影响力闭环；或
2. 仅保留地点标签、敌对地点接口和未来扩展位，把可玩经营延期。

在该范围选择完成前，不应制作复杂宗门职位、成员、库存、外交或世界模拟规则。

# 流程设计｜真灵初始化与角色初始化流程

## 1. 当前结论

玩家主体采用三层模型：

```text
真灵：跨世延续主体
执念：转世初始化遗留容量系统
身躯与灵魂：当前世角色实例
```

真灵负责“我仍然是我”；执念负责“我能把哪些内生遗留带到下一世”；身躯与灵魂负责“这一世具体能做什么、付出什么代价”。

本次流程裁决：

- 玩家控制的当世角色不再拥有世俗背景身份。角色不是带着家族、门第、官籍、凡俗履历进入世界的“身份人物”，而是真灵塑造出的当世承载者。
- 世界主线剧情直接绑定真灵、真灵名与真灵线索，不绑定当前角色的世俗身份。
- 当前角色仍然拥有姓名、性别、年龄、出生位置、外观、属性、物资、宗门身份等可玩字段，但这些字段不得回退成“世俗背景身份”或主线身份锚点。

## 2. 初始化类型边界

初始化分为两类：

```text
真灵初始化：玩家第一次进入游戏房间时执行一次
角色初始化：生成当前世身躯与灵魂；初次进入与转世重修都会执行
```

真灵初始化确立跨世主体、真灵名与主线剧情线。角色初始化只确立当前世角色实例，不生成玩家角色的世俗背景身份。

## 3. 初次进入房间流程

玩家第一次进入游戏房间时，先初始化真灵，再创建初始化角色。

```text
玩家进入游戏房间
→ 创建真灵
→ 选择真灵名
→ 绑定真灵剧情线
→ 介绍真灵背景故事
→ 创建初始化角色
→ 写入角色自知信息与初始日志
→ 进入新手流程 / 第一阶段房间推进
```

### 3.1 预设真灵名

玩家选择已经预设好的真灵名时：

- 真灵名绑定对应的专属剧情线。
- 真灵背景故事按该真灵名播放或写入初始日志。
- 初始化角色直接使用该真灵名对应的预设角色属性、出生位置、性别、年龄与外观。
- 玩家可以自定义当前角色姓名。
- 不生成家庭背景、门第身份、凡俗职业、官籍、家族关系等世俗背景身份。
- 世界主线从真灵线索展开，当前角色只是该真灵第一次显化的当世承载者。

### 3.2 自定义真灵名

玩家自定义真灵名时：

- 真灵名不绑定专属剧情线，进入通用弱剧情线。
- 真灵背景故事使用通用版本，只保留与真灵存在、入世异常和世界主线入口相关的信息。
- 初始化角色使用通用预设角色属性与预设年龄。
- 玩家可以自定义当前角色姓名与性别。
- 出生位置与外观随机生成。
- 不生成世俗背景身份。

### 3.3 初次角色生成约束

- 资质、根骨、悟性等角色属性在身躯与灵魂生成时已经确定；入门事件只负责检测、揭示和评级。
- 初次入世仍保持低认知、低资源、低控制力，但“低认知”来自新显化角色对世界理解有限，不来自世俗出身身份。
- 出生位置只表示初始空间落点。它可以影响玩家接触到的地点、NPC、宗门与事件入口，但不得生成玩家角色的家族、门第或社会身份。
- 初始日志应区分“真灵背景故事”和“当前角色自知信息”。前者服务主线，后者服务本世操作。

## 4. 转世重修后的角色初始化流程

```text
本世结束 / 主动计划转世
→ 结算本世身躯与灵魂
→ 提取真灵成长
→ 记录履历、失败原因、后手状态
→ 检查遗产与后手线索
→ 按转世前修为境界结算执念
→ 创建新角色初始化草案
→ 选择无成本基础参数
→ 选择是否消耗执念设定强化参数
→ 生成新身躯与灵魂
→ 写入新世初始日志
```

转世触发来源暂定支持三类：

1. 寿元耗尽转世。
2. 突破失败转世。
3. 主动计划转世。

无成本基础参数：

- 当前角色姓名。
- 性别。
- 年龄。
- 出生位置的大致区域。
- 外观预选择。

执念可影响的强化参数：

- 角色属性设定。
- 出生具体位置设定。
- 初始物资设定。

规则：

- 执念是基于转世前修为境界获得的一次性初始化代币，只在本次角色初始化中消费。
- 未消耗执念设定的角色属性、出生具体位置与初始物资按普通生成规则处理。
- 出生位置的大致区域是无成本选择；确定具体地点、特殊落点或高价值起点需要消耗执念。
- 外观预选择不等于世俗身份选择。它只影响当前身躯的视觉呈现，不绑定家族、门第、职业或主线身份。
- 转世重修仍不生成玩家角色的世俗背景身份。前世履历由真灵轮回账本承载，本世身份由游玩过程获得。

## 5. 执念权重制

后期已确认：执念容量采用权重制。

```text
TrueSpirit.obsession_capacity = 本次转世可承载的执念容量上限
ObsessionOption.obsession_weight = 某遗留或强化配置的占用权重
```

规则：

- 玩家选择的总权重不得超过当前执念容量。
- 权重不是属性点，不允许拆成根骨 +1 / 悟性 +1 等细碎购买。
- 遗留与强化仍是离散选项，例如属性定型包、具体出生点、初始物资包、已解锁初始化遗留。
- “出生背景”不再作为玩家角色的主动遗留分类。若旧资料出现出生背景，应改写为出生位置、初始物资、区域接触面或已解锁线索，不得写成世俗身份。
- 执念可选范围与权重表另行细化；本文件只固定流程入口、允许影响的参数类别和禁用的世俗身份边界。

## 6. 初始化字段建议

```yaml
TrueSpiritInit:
  spirit_id: string
  true_name: string
  true_name_mode: preset | custom
  story_line_id: string
  story_line_type: dedicated | generic_weak
  incarnation_count: int

CharacterInit:
  character_id: string
  true_spirit_id: string
  init_context: first_entry | reincarnation
  character_name: string
  gender: string
  age: int
  attribute_profile_id: string
  birth_region_id: string | null
  birth_location_id: string | random
  appearance_profile_id: string | random
  initial_material_package_ids: list
  obsession_spent: number
  has_secular_background_identity: false
```

## 7. 设计历史

早期“真灵 / 执念 / 身躯灵魂”用于厘清玩家主体。后续 S2 将其转化为字段和接口。当前整理以 S2 与三层模型草稿共同为准。

本次修订进一步收敛：玩家角色不再以世俗身份承担主线，主线直接与真灵关联；角色初始化只负责当前世可玩实例，转世差异主要通过真灵成长、执念消费、出生位置、属性、外观与物资体现。

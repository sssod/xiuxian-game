# 交互设计｜储物空间页面设计

## 当前状态

本页只记录储物空间页面的稳定交互约束，不定义视觉布局稿。

## 必须表达

- 随身资产、个人储藏、宗门库存、节点库存、市场挂牌、事件锁定、后手封存等资产位置。
- 可堆叠物品与独立实例物品的差异。
- 物品是否 combat_ready、是否绑定、是否可用于当前行动 / 事件 / 战斗。
- 残余效果不只在背包显示，还需在角色状态中提示。

## 不应表达为

- MVP 不做背包格子、重量、通用负重上限；物品栏数量只保留程序层上限，不在界面表达为玩法容量。
- 不以装备栏决定法宝和道具可用性。

## 本次裁决记录

2026-05-11：MVP 不把物品栏数量表达为玩法容量；若程序层存在数量上限，界面只按技术限制或异常提示处理，不设计为背包格子、负重或容量成长玩法。

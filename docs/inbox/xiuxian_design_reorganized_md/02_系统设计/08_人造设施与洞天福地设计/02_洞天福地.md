# 人造设施与洞天福地设计｜洞天福地

## 1. 当前状态

当前 Library 中没有检索到洞天福地独立设计稿。本文件将洞天福地归为地图节点或隐藏层中的高价值资源槽，并说明它和设施、后手、修炼环境、突破地点的关系。

## 2. 当前可确定口径

洞天福地首先是资源，不是常规建筑或可自由改造地块。MVP 阶段按 `blessed_land` 或等价资源槽处理，通常具有较高灵气、特殊相性、空间稳定性、突破机会、隐藏层或稀有产出条件。

洞天福地可作为：

- 高价值地图节点或隐藏层中的资源槽。
- 修炼加成地点。
- 突破地点。
- 前世后手封存点。
- 宗门控制与资源争夺对象。
- 世界窗口事件或秘境入口。

洞天福地不应默认允许常规生产建筑替换。它可以被发现、争夺、封禁、保全、维护、参悟、污染、破坏或作为突破场地使用；若允许建设，也应使用 `limited_build`、`preserve_only` 或 `no_build` 等受限改造口径。

## 3. 约束

- 必须挂载于地图节点或隐藏层中的资源槽，不应成为无位置资产。
- 作为资源槽时，应记录资源品级、品级范围、灵气影响、可见性、控制权、争夺状态和改造限制。
- 不应把洞天福地当成普通设施。宗门或角色只能在其上附加保全、封禁、参悟、突破场地、入口维护等受限设施或操作，不能随意改建为矿场、药园、坊市或普通修炼房。
- 若作为真灵藏宝，应由正式后手规则记录封存、同一真灵跨世感应、开启、数量容量限制和一次性取出状态；MVP 阶段不进入遗产分配、继承或回收，不展示被他人搬空、损坏或移动。
- 若作为宗门外个人洞府或普通藏宝，应作为无主遗留设施记录钥匙、功法、线索、位置、事件条件或破阵开启规则，允许因条件泄露或防御被攻破而被其他角色提前打开。
- 若提供资源产出，应先进入资源槽或资源池；实例化后再进入 `sect_storage`、`node_storage`、事件锁定库存或其他合法资产容器。
- 若提供修炼加成，应进入数值模型的节点灵气 / 资源槽修正 / 设施修正；其中设施修正只能来自洞天福地允许的受限附属设施。

## 4. 缺口

- 洞天福地类型表。
- 洞天维护成本。
- 洞天暴露、争夺、封存、污染、转移规则。

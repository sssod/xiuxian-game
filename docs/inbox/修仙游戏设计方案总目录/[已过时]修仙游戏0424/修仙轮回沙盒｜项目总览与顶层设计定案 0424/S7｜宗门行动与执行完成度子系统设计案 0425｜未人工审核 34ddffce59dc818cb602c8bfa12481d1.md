## 2. MVP 宗门主行动与常态结算

### 2.1 已确定决策：每宗门每季度始终 1 个主行动

**人工决策：每个宗门每季度始终只有 1 个宗门主行动。**

规则口径：

- 宗门主行动是本季度需要宗门高层、组织资源或玩家影响力进行取舍的重点动作。
- 不随宗门规模、长老数量或建筑数量增加主行动数量。
- 后续扩展也优先通过行动质量、执行完成度、常态收益、持续项目、建筑效果和事件结果表达宗门规模，而不是增加每季度主行动数量。
- 该规则用于控制宗门行动阶段复杂度，避免玩家和 AI 每季度处理过多组织行动。

### 2.2 MVP 六类宗门主行动

MVP 宗门主行动包括：

1. 开采 / 资源介入。
2. 驻守 / 控制强化。
3. 探索。
4. 远征。
5. 建设。
6. 培养。

这些主行动改变宗门库存、节点资源、建筑状态、宗门影响力、控制权事件、玩家贡献与声望、秘境或后手窗口。

### 2.3 不占用宗门主行动的常态结算

很多宗门收益或维护行为不占用每季度 1 个宗门主行动，而是由既有控制权、建筑、驻守状态或持续项目自动结算。

典型例子：

- 已经控制的矿场，在占领和设施正常期间持续产出矿材。
- 已经控制的药田，在无灾害和无破坏时按季度产出修炼资源。
- 已建成的基础设施提供持续修正。
- 已建立的驻守状态提供持续安全或控制稳定。
- 已完成的培养体系提供基础弟子成长或维护收益。

常态结算可以受节点状态、建筑损坏、资源枯竭、敌对干扰、灾害事件、库存维护和人力占用影响，但它不是宗门主行动。

### 2.4 主行动与常态结算的区分

判断标准：

- 如果该行为是在已有控制和设施基础上的稳定产出 / 维护，则走常态结算。
- 如果该行为需要改变节点状态、扩大产能、抢夺控制权、处理危机、探索未知、建设新设施、发起远征或重点培养，则占用宗门主行动。

例如：

- “控制矿场后的基础采矿产出”不占主行动。
- “加大开采、修复矿场、抢占矿场、处理矿脉异变、探索矿脉深层”占主行动或触发事件链。

## 4. 建议、采纳与决策

玩家对宗门行动的影响分三档：

1. 建议：低身份玩家提出倾向，系统根据贡献、声望、宗门需求决定是否采纳。
2. 提议：中高身份玩家能提出更具体行动方案，但仍可能被宗门 AI 调整。
3. 决策：执事 / 长老等具备权限时，可直接发起部分行动，但仍受库存、节点和风险校验。

采纳因素：

- 玩家身份与职位。
- 门内声望与贡献。
- 宗门当前战略倾向。
- 库存是否足够。
- 目标节点是否可达 / 有权限。
- 行动风险与收益。
- 竞争宗门压力。

## 5. 执行完成度

MVP 不直接使用二元成功 / 失败，而使用执行完成度区间。

```
ExecutionResult {
  failed
  partial
  normal
  strong
  exceptional
}
```

影响因素：

- 投入资源。
- 投入人力。
- 行动类型与目标节点匹配度。
- 宗门影响力 / 控制权。
- 节点危险与事件状态。
- 角色亲自介入。
- 竞争宗门干扰。
- 随机波动。

## 6. 角色亲自介入

宗门行动一般不受玩家当前位置限制，但玩家亲自介入时必须走 S3。

S3 负责判断：

- 玩家是否抵达正确节点。
- 是否在正确 tick / 事件窗口介入。
- 路线是否合法。
- 当前位置与季度计划是否合法。

S7 负责决定介入效果：

- 提高执行完成度。
- 增加玩家贡献与声望。
- 提供额外发现率。
- 降低失败损失。
- 触发个人风险或事件链。

## 7. 六类行动的最小规则

### 7.1 开采 / 资源介入

宗门主行动中的开采不是指所有资源节点的日常产出，而是指对资源节点进行重点介入。

占用主行动的情况：

- 新发现资源点后的组织开采。
- 抢占或恢复矿场、药田、灵脉等资源节点。
- 加大开采力度以换取短期库存增长。
- 处理资源异变、塌方、污染、妖兽盘踞等危机。
- 深入资源层，尝试发现更高价值资源槽。

不占用主行动的情况：

- 宗门已经控制的矿场、药田、灵脉等节点，在状态稳定期间按季度自动结算基础产出。
- 已建成资源建筑或采集设施提供的常态收益。

过度开采或危机处理可能降低节点资源状态、损坏建筑或触发 S10 事件。

### 7.2 驻守

提高节点安全、控制稳定、事件响应与宗门影响力。个人驻守可与宗门驻守协同。

### 7.3 探索

揭示节点隐藏层、资源槽、秘境窗口、路线或后手线索。高价值发现转交 S10 / S11。

### 7.4 远征

对远端节点、高危区域或竞争节点进行组织性介入。MVP 中远征优先作为事件链入口，不展开大型战争。

### 7.5 建设

创建、修复或升级节点建筑槽。建设结果改写 S8 建筑状态，并消耗 S6 库存。

### 7.6 培养

将宗门资源投入弟子、玩家、护法或某类修炼方向。可提高人才、支持突破或增强未来行动能力。

## 9. 宗门 AI 最小口径

MVP 宗门 AI 不做深度人格模拟，只使用倾向权重：

- 扩张。
- 保守。
- 培养。
- 财政恢复。
- 节点控制。
- 秘境争夺。
- 风险规避。

玩家建议会改变本季度权重，但不保证完全支配宗门。

## 10. 与多人竞争的关系

MVP 多人主要通过宗门节点控制和世界资源名额竞争发生间接互动。

S7 输出：

- 哪个宗门向哪个节点投入行动。
- 哪个宗门获得资源名额。
- 控制权或影响力是否变化。
- 是否触发竞争事件。

S13 决定这些结果如何对其他玩家可见，以及是否形成多人间接竞争提示。

## 11. 与其他系统的接口

- S1：接入季度阶段与统一结算。
- S3：读取玩家亲自介入资格。
- S5：读取权限、职位、建议采纳修正。
- S6：读取并消耗库存、人力、声望。
- S8：读取目标节点、路线、控制权、资源槽、建筑槽。
- S10：触发节点事件、远征事件、危机事件。
- S11：探索或建设可能影响前世后手。
- S13：输出多人间接竞争结果。

## 12. MVP 验收标准

1. 每个宗门每季度始终只有 1 个宗门主行动。
2. 已控制资源节点可以在不占用主行动的情况下进行常态产出结算。
3. 玩家能提出建议并看到采纳 / 不采纳反馈。
4. 宗门主行动真实消耗 S6 库存并改写 S8 节点状态。
5. 玩家亲自介入能提高执行完成度或改变事件结果。
6. 至少一次宗门主行动引发节点控制、资源名额变化或资源节点状态变化。

# 数值设计｜自动战斗与逃遁数值

适用范围：直接伤害、护盾、增减伤 Buff、固定元气损伤 / 吸收、掌握倍率、炼化、TTK、逃遁概率、渡劫验收与死亡掉落数值。

## 1. 直接伤害总式

```text
基础威力 P0
= 有效修为 × K1
+ 实际自损量 × K2

通用增伤 U = sum(u_i), u_i >= 0

减伤后保留比例 Q
= product(1 - m_i), 0 <= m_i < 0.9

Buff 修正后威力 P1
= P0 × (1 + U) × Q

属性减伤系数 R(D, C)
= C / (C + max(D, 0))
```

所有通用增伤进入一个加算乘区；所有通用减伤来源的剩余比例连乘。综合减伤不设硬上限，但单项不得达到 `90%`。

## 2. 生机与神念伤害

生机先由护盾一比一吸收：

```text
A = min(当前护盾, P1)
P2 = P1 - A

P2 <= 0：最终生机伤害 = 0
P2 > 0：最终生机伤害
= max(1, floor(P2 × R(目标体魄, C1)))
```

神念不受护盾保护：

```text
P1 <= 0：最终神念伤害 = 0
P1 > 0：最终神念伤害
= max(1, floor(P1 × R(目标神念上限, C2)))
```

`C1`、`C2` 是必须在正式数值配置中人工填写的主题常数，当前分别以通用金丹期平均体魄和平均神念上限为锚点。

## 3. 掌握倍率与基础系数

知识来源招式：

```text
实际 K1 = 基础 K1 × 掌握阶段倍率
实际 K2 = 基础 K2 × 掌握阶段倍率
```

| 掌握度 | 阶段 | 倍率 |
| --- | --- | ---: |
| `0—24` | 初识 | `0.70` |
| `25—49` | 熟悉 | `0.85` |
| `50—74` | 熟练 | `0.95` |
| `75—99` | 精通 | `1.00` |
| `100` | 圆满 | `1.10` |

`75` 是模板标准效果。倍率只作用于模板明确标记的 `K1 / K2` 等字段；冷却、固定元气损伤、固定吸收、固定消耗、移动字段、离散强化和护劫护盾不读取该通用倍率。法门先应用已解锁的离散强化，再对允许字段应用掌握倍率。

基础 `K2` 离散取 `0 / 0.5 / 1 / 1.5 / 2`，普通最高 `2`；稀有或特殊内容最高 `3`。

## 4. `K1_ref` 与 TTK 制作预算

完整构筑预计承载约 `10—15` 个输出、防御或恢复类招式，内容量约为 `2:1`；抵消后约 `3—5` 个净伤害招式持续削减属性条。

设基础冷却为 `c` 秒：

```text
b_ref(c) = min(0.10, 0.006 × c)
S_ref(t, g, c) = B_t(g) × b_ref(c)
```

标准净伤害招式预算为属性条上限 `0.6% / 秒`，单次参考伤害上限 `10%`。未触发上限时：

| 净伤害招式数 | 理论 TTK |
| ---: | ---: |
| `3` | `55.6` 秒 |
| `4` | `41.7` 秒 |
| `5` | `33.3` 秒 |

在精通、无 Buff、无护盾、无 `K2` 追加的基准下，用同阶通用有效修为和对应属性减伤反解 `K1_ref`。普通基础 `K1` 为参考值的 `0.5—1.5` 倍，普通硬上限为 `2` 倍；特殊突破必须声明。

生机与神念分别维护参考系数。多属性招式共享预算：

```text
sum(S_ref_j / B_j) <= b_ref(c)
```

制作期只读取模板基础冷却；战斗中的冷却变化不重算 `K1`。

## 5. 自损

招式释放前校验实际自损不会使施术者对应属性归零；必须至少保留 `1` 点。成功发动后立即支付，自损不因目标被护盾、减伤或低收益结果退还。

## 6. 固定元气损伤与吸收

固定元气损伤 `D` 不读取有效修为、目标百分比、境界差、通用增减伤、护盾或属性减伤。

内容制作使用招式或来源品阶级对应大境界的通用元气上限 `C3(g)`：

```text
普通内容：0.05 × C3(g) <= D <= 0.20 × C3(g)
普通硬上限：D <= 0.25 × C3(g)
```

落地后写成固定值。`K3` 离散取 `0 / 0.25 / 0.5 / 0.75 / 1`；普通吸收主要使用 `0.25` 或 `0.5`，`0.75` 为高强度，`1` 仅用于稀有或特殊招式。

```text
L = min(目标当前元气, D)
G0 = floor(L × K3)
G = min(G0, 施术者元气可支配上限 - 当前元气)
```

零损伤或零回复时招式仍照常释放、支付成本并进入冷却。

知识来源 `D/K3` 只随离散招式等级变化。法宝招式在炼化度高于 `50` 后只缩放 `D`，不重复缩放 `K3`。

## 7. 炼化数值

```text
r <= 50：法宝效果为 0
r > 50：实际效果 = 基础效果 × r / 100
```

每普通回合末 `+5`，小洞天一回合 `+50`，上限 `100`。飞遁法宝逃遁加成同样受炼化倍率影响。

## 8. 逃遁概率

只比较当前大境界：

| 逃遁者相对对手 | 基础成功率 |
| --- | ---: |
| 低两个及以上 | `10%` |
| 低一个 | `25%` |
| 相同 | `50%` |
| 高一个 | `75%` |
| 高两个及以上 | `90%` |

飞遁法宝模板配置 `F0 = 0—30` 个百分点：

```text
r <= 50：F(r) = 0
r > 50：F(r) = F0 × r / 100

最终成功率 = min(100%, 基础成功率 + F(r))
```

每次尝试独立判定，不累计失败补偿；随机结果读取本场战斗随机种子。允许最终达到 `100%`。

## 9. 死亡掉落

每件独立物品或每个堆叠单位独立以 `10%` 概率成为战利品，剩余 `90%` 系统回收。胜利者不能挑选；无玩家胜者时全部回收。

## 10. 渡劫数值验收

金丹、元婴、化神、大乘四场强制渡劫分别使用目标境界固定敌人预算，不读取外界回合、失败次数、物品成熟、建筑等级或玩家地产。首轮平衡锚点为：在对应标准目标回合，使用该境界正常战斗构筑并消耗 `Q3 上品` 破境丹的角色，跨标准构筑样本单次胜率约 `70%—80%`。该值只用于测试，不向玩家承诺单场概率。

`Q1` 下品提供最大生命 `10%` 护劫护盾时，培养充分且构筑合理的角色仍需存在可靠胜法；`Q5` 绝品提供 `80%` 锚点时应显著提高容错，但不能使明显缺少战斗法门、法宝、恢复与核心战力的角色稳定通过。五档 `10% / 20% / 35% / 55% / 80%` 为调参初值。

渡劫允许按第 `8` 章通用公式逃遁。护劫护盾与其它护盾的叠加顺序、通用上限及最终比例仍待统一配置；关闭前不得在敌人预算中假定一种未裁决叠加顺序。

## 11. 正式配置门

以下仍不得遗漏：

- 各境界有效修为、体魄、神念、元气和属性条上限；
- 人工填写 `C1`、`C2`；
- `C3(g)`；
- 各档绝对 `K1_ref`；
- 首批招式冷却、成本、`K1/K2/D/K3`、护盾和 Buff 数值；
- 敌人构筑与 `60` 秒 TTK 验算；
- 四场固定渡劫敌人、标准构筑样本、护劫护盾叠加顺序和最终数值。

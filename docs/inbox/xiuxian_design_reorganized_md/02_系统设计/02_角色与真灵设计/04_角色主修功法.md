# 角色与真灵设计｜角色主修功法

## 1. 当前结论

角色同一时间只有一个主修道功。只有道功能成为主修，法门不能设为主修。

主修道功决定：

- 主动吐纳与自动运转读取的修炼路线。
- 当前境界段的修为转化口径。
- 当前可修上限。
- 大境界突破路线与挑战模板读取。
- 一部分被动加成、资源适配与角色状态反馈。

## 2. 改修窗口

后期功法 v0.4 明确：主修道功只在大境界第一小阶段常规无成本更换，例如 A-1 / B-1 / C-1。

不做：

- 废功重修。
- 改修折算。
- 功法上限后的免费续接换主修。
- 临近大境界突破时临时换功降低挑战。

## 3. 掌握度作用边界

道功掌握度影响：

- 当前可修上限。
- 单位时间收益效率。

道功掌握度不影响：

- 理论最高上限。
- 已错过的不可追回收益。
- 修为纯度收益。
- 小境界升级奖励质量。
- 大境界突破模板类型。

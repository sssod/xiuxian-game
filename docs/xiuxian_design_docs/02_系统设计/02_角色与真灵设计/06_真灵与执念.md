# 系统设计｜真灵与执念

## 1. 设计定位

本文负责定义玩家跨世主体“真灵”、转世初始化代币“执念”，以及它们与当前世身躯、轮回账本、正式后手和真灵藏宝之间的系统边界。

真灵是跨世延续主体，承载真名、主线线索、道韵、轮回账本和正式后手索引；执念是转世重修时按上一世结算生成、只在下一世初始化阶段消费的一次性预算。本文不维护当前世角色外观、属性数值、修为公式、普通行囊、洞府库存或 UI 布局细节。

## 2. 当前结论

1. 玩家主体采用“真灵 / 执念 / 身躯与灵魂”三层模型：真灵跨世延续，身躯与灵魂是当前世角色实例，执念只服务下一世初始化。
2. 世界主线剧情直接与真灵、真灵名和真灵线索关联，不与当前世角色的世俗背景身份绑定。
3. 执念预算基于转世前修为境界结算，不由真灵强度直接提供，也不作为长期跨世货币累计。
4. 执念只能影响新一世初始化条件，不携带当前身躯、当前灵魂、当前修为、功法等级、普通背包、宗门职位、普通关系、完整属性表或完整前世记忆。
5. 真灵藏宝属于正式后手，可由同一真灵跨世感应和开启，但受设置数量、单个容量和取出规则限制，不等于前世背包或洞府库存搬运。

## 4. 核心循环或触发入口

真灵与执念围绕“初始化、当前世运行、结算、转世、后手感应”循环运作。

```text
首次进入房间
→ 选择预设真灵名或自定义真灵名
→ 创建 TrueSpirit
→ 按真灵名类型绑定专属剧情线或通用弱剧情线
→ 创建当前世身躯与灵魂
→ 进入共享世界
```

```text
本世结束 / 主动计划转世
→ 结算本世身躯与灵魂
→ 记录本世最高或结算修为境界
→ 按修为境界生成本次执念预算
→ 进入新一世角色初始化
→ 选择无成本基础参数
→ 消耗执念设定强化参数
→ 生成新身躯与灵魂
→ 本次执念结算关闭
```

```text
死亡或转世后的后手检查
→ 写入轮回账本
→ 清点宗门个人洞府库存和有主遗产
→ 保留宗门外洞府 / 普通藏宝等无主遗留设施线索
→ 检查真灵藏宝索引和开启条件
→ 在新一世按规则感应、定位或开启正式后手
```

中断点包括寿元耗尽死亡、突破失败死亡、主动转世确认、转世初始化取消、执念预算耗尽、互斥选项冲突、后手开启条件不足和真名暴露状态变化。

## 5. 规则与状态

### 5.1 三层模型

```text
真灵：跨世延续主体
执念：转世重修时获得并消费的一次性初始化代币
身躯与灵魂：当前世角色实例
```

规则：

1. 真灵是真正跨世延续的玩家主体，保存跨世主线、真名、道韵、轮回账本和正式后手索引。
2. 身躯与灵魂是当前世角色实例，保存当前姓名、外观、属性、修为、寿元、行囊、关系、宗门身份和运行态。
3. 执念只在新一世角色初始化时消费，用于影响初始化条件。
4. 真灵不保存当前世普通背包、完整属性表、功法等级、修为状态、普通关系或宗门职位。
5. 当前世角色不拥有初始化世俗背景身份；宗门职位、称号、关系和声望必须来自游玩过程。

### 5.2 真灵字段边界

```yaml
TrueSpirit:
  spirit_id: string
  true_name: string
  true_name_mode: preset | custom
  story_line_id: string
  story_line_type: dedicated | generic_weak
  true_name_visibility: hidden | declared | exposed
  spirit_strength: number
  incarnation_count: int
  highest_stage_reached: string
  dao_rhyme_tags: list
  reincarnation_ledger_refs: list
  remnant_sense_log_refs: list
  formal_contingency_refs: list
```

字段规则：

1. `true_name` 与 `story_line_id` 决定真灵主线入口。
2. 预设真灵名绑定专属剧情线，自定义真灵名进入通用弱剧情线。
3. `true_name_visibility` 记录真名隐藏、主动宣告或被动暴露状态。
4. `spirit_strength` 不直接提高修炼效率，也不直接生成本次执念代币。
5. `formal_contingency_refs` 记录正式后手 / 真灵藏宝索引，不等同于执念消费项，也不等同于普通遗产。
6. 真灵层只保存跨世主体、主线、道韵、轮回账本和正式后手索引，不保存当前世运行态。

### 5.3 执念预算结算

执念预算按转世前修为境界生成。具体境界档位、预算数值和调参表不在本文维护。

规则：

1. 执念预算来源是本世结束时记录的最高或结算修为境界。
2. 本次执念预算在下一世角色初始化阶段打开，并在初始化完成后关闭。
3. 未使用执念不进入真灵长期余额，不作为下一次转世的可累积资源。
4. 执念预算不得由真灵强度、真名稀有度、真灵剧情线或前世财富直接生成。
5. 执念预算应进入轮回账本，记录来源世代、来源境界、总预算、已消费选项和消费关闭状态。

### 5.4 执念消费规则

无成本基础参数：

1. 当前角色姓名。
2. 性别。
3. 年龄。
4. 出生位置的大致区域。
5. 外观预选择。

执念当前已确认可影响的强化参数：

1. 角色属性设定。
2. 出生具体位置设定。
3. 初始物资设定。

消费规则：

1. 每个执念选项有 `obsession_weight` 或等价消耗值。
2. 玩家选择的总权重不得超过本次执念预算。
3. 权重不是 RPG 属性点，不允许拆成根骨 +1、悟性 +1 等细碎购买。
4. 执念选项应是离散配置，例如属性定型包、具体出生点、初始物资包。
5. 未消耗执念设定的项目按普通生成规则处理。
6. 互斥选项必须通过互斥组或等价规则阻止同时选择。

### 5.5 角色属性设定

角色属性设定用于改变新一世身躯与灵魂的初始属性生成结果。

允许方向：

1. 选择完整属性定型包。
2. 选择属性生成倾向包。
3. 选择已解锁的初始化属性模板。

约束：

1. 不拆成可自由分配的零散属性点。
2. 不直接复制前世完整属性表。
3. 不直接继承前世修为、功法等级或战斗能力。
4. 如果后续允许天赋标签进入执念范围，必须重新定义为属性设定包或独立执念选项，不沿用旧的“携带天赋标签”表述。

### 5.6 出生具体位置设定

出生位置分为无成本的大致区域与消耗执念的具体位置。

无成本：

1. 选择出生位置的大致区域。

消耗执念：

1. 指定更具体的起点节点。
2. 选择特殊落点。
3. 选择更接近特定资源、宗门、宗门遗产清点线索、无主遗留设施线索或安全教学节点的位置。

约束：

1. 出生具体位置只表示空间落点，不生成家庭背景、门第身份、凡俗职业、官籍、族属关系或初始社会身份。
2. 具体位置可以影响玩家接触到的地点、NPC、宗门与事件入口，但不得绑定世界主线身份。
3. 高价值起点必须通过执念权重体现，不能伪装成无成本地区选择。

### 5.7 初始物资设定

初始物资设定用于改变新一世进入世界时可直接使用或携带的资源。

允许方向：

1. 基础生存物资包。
2. 学艺或入门准备物资包。
3. 路途补给包。
4. 已解锁的轻量遗留物资包。

约束：

1. 初始物资包不等于前世背包复制。
2. 初始物资包不直接授予宗门职位、社会身份、家族关系或区域声望。
3. 初始物资可以改善开局风险和路线选择，但不应替代后续修炼成长。
4. 宗门个人洞府库存的遗产清点不生成初始化物资包；它按有主遗产规则回收宗门。
5. 宗门外个人洞府和普通藏宝作为无主遗留设施，只能以线索、位置或开启条件相关内容进入初始化选择，不自动转为可携带物资。
6. 真灵藏宝不消耗执念开启，但受正式后手的设置数量和单个容量限制；取出后按一次性取出处理。

### 5.8 轮回账本

轮回账本用于记录死亡、突破失败、主动转世、前世经验、后手线索、宗门遗产清点、宗门外洞府 / 普通藏宝等无主遗留设施开启线索、失败标签、资产去向、真名暴露变化、执念预算来源和本次执念消费结果。

规则：

1. 轮回账本服务长期复盘、线索追踪和真灵层叙事。
2. 轮回账本不是完整前世记忆复制，也不是背包、关系、身份或修为的跨世搬运系统。
3. 轮回账本可以保存真灵藏宝索引和宗门外藏宝线索。
4. 轮回账本不得改变资产归属规则：宗门个人洞府库存按有主遗产清点，宗门外洞府和普通藏宝作为无主遗留设施按开启条件或破阵处理，真灵藏宝按同一真灵跨世开启处理。

### 5.9 正式后手与真灵藏宝

正式后手由真灵层保存索引，不由执念预算购买，也不自动变为初始化物资。

规则：

1. 真灵藏宝可以跨世存在，并由同一真灵感应和开启。
2. 真灵藏宝必须受设置数量和单个容量限制。
3. 真灵藏宝取出后按一次性取出处理，不能作为无限跨世仓库。
4. 前世普通背包、洞府库存、宗门资源和普通藏宝不得自动进入真灵藏宝。
5. 宗门外洞府、普通藏宝和真灵藏宝的归属、容量和开启规则由个人洞府库存、藏宝与后手文档维护；本文只定义真灵层索引和执念边界。

### 5.10 旧口径修正

| 旧字段 / 旧口径 | 当前处理 |

## 7. 数据字段建议

| 字段 | 含义 |
| --- | --- |
| `true_spirit` | 真灵主体结构，保存真名、剧情线、真名可见性、道韵、轮回账本和正式后手索引 |

## 8. UI 展示边界

普通 UI 应展示：

1. 当前真灵名或真名可见性状态。
2. 当前世角色与真灵的关系摘要。
3. 转世前来源境界、本次执念总预算、已消费预算和剩余预算。
4. 可选执念项的类型、权重、互斥状态、解锁状态和玩家可理解效果。
5. 无成本基础参数与消耗执念的强化参数之间的区别。
6. 轮回账本中的关键前世摘要、后手线索和真名暴露变化。

普通 UI 不应展示：

1. 真灵强度作为修炼效率或执念容量来源。
2. 执念权重的内部调参公式。
3. 前世完整背包、完整属性表、完整关系网或完整记忆复制。
4. 禁用字段、内部 ID、Debug 权重、隐藏剧情线标识和后手完整开启判定。
5. 出生位置被包装成家庭背景、门第身份、官籍、凡俗职业或主线身份来源。

## 9. MVP 范围

MVP 应实现：

1. 真灵主体结构：真名、真名模式、剧情线、真名可见性、轮回次数、最高境界、轮回账本引用和正式后手索引。
2. 预设真灵名绑定专属剧情线，自定义真灵名进入通用弱剧情线。
3. 转世前按修为境界生成本次执念预算。
4. 新一世初始化时支持无成本基础参数和执念强化参数。
5. 执念强化参数至少支持角色属性设定、出生具体位置设定和初始物资设定三类。
6. 执念选项权重、预算消耗、互斥组、解锁条件和初始化完成后的预算关闭。
7. 轮回账本记录转世、失败标签、资产去向、后手线索、真名变化和执念消费结果。
8. 真灵藏宝作为正式后手索引存在，并承接个人洞府库存、藏宝与后手文档的容量和开启规则。

MVP 不实现：

1. 长期累计执念余额。
2. 以真灵强度直接生成执念预算或修炼效率加成。
3. 前世修为、功法等级、普通背包、完整属性表、普通关系和宗门职位跨世继承。
4. 世俗背景身份购买或携带。
5. 细碎属性点购买。
6. 天赋标签作为已确认执念选项。
7. 无限容量跨世仓库或自动搬运前世洞府库存。
8. 完整前世记忆复制。

## 10. 验收约束

1. 任何跨世主体规则必须区分真灵、执念、当前世身躯与灵魂三层。
2. 执念预算必须由转世前修为境界结算，不得由真灵强度、真名稀有度或前世财富直接生成。
3. 未使用执念不得累计到下一次转世。
4. 执念选项不得拆成自由属性点，也不得直接复制前世完整属性表。
5. 出生位置选项不得生成家庭背景、门第身份、凡俗职业、官籍、族属关系或初始社会身份。
6. 初始物资包不得复制前世背包、宗门资源或洞府库存。
7. 真灵藏宝不得绕过正式后手的设置数量、单个容量、开启条件和一次性取出规则。
8. 轮回账本不得作为完整前世记忆、关系、身份、背包或修为搬运系统。
9. 世界主线身份锚点必须绑定真灵、真灵名和真灵线索，不得绑定当前世世俗身份。
10. 包内其他文档若需要使用执念选项，必须以本文的三类已确认范围为准；新增类型进入待裁决，不静默扩展。

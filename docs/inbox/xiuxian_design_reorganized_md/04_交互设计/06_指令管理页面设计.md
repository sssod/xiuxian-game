# 交互设计｜指令管理页面设计

## 队列面板

建议显示：

```text
当前指令
后续 1
后续 2
后续 3
当前兜底规则
```

## 入队校验

入队时只提示当前是否合法：

```text
可入队：当前已满足突破条件。
不可入队：当前未拥有筑基丹。
不可入队：当前地点不允许突破。
不可入队：当前灵力储备不足。
```

不提示复杂未来推演，例如“预计 8 日后满足”或“如果前序炼丹成功则执行”。

## 执行失败提示

```text
预输入指令未执行：开启筑基突破。
原因：缺少筑基丹。
已自动转入：吐纳。
```

或：

```text
队列已空。
当前处于低风险节点，已自动转入吐纳。
世界进入 N1，等待你输入新指令。
```

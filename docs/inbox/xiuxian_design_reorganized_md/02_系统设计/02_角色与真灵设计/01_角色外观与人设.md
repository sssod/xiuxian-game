# 角色与真灵设计｜角色外观与人设

## 1. 当前结论

玩家控制的当前角色不再拥有世俗背景身份，而是真灵塑造出的当世承载者。角色外观与人设只描述“这一世如何被看见、如何被称呼、当前处于什么身体状态”，不描述家庭出身、门第身份、凡俗职业或主线身份。

世界主线剧情直接与真灵、真灵名和真灵线索关联，不与当前角色身份关联。当前角色可以在游玩过程中获得宗门身份、声望、关系和称号，但这些是游玩结果，不是初始化背景身份。

## 2. 外观与人设边界

- 角色拥有当前姓名、年龄、寿元上限、性别或身体模板、出生位置、外观、初始属性与初始物资等初始化字段。
- 玩家角色初始化不生成家庭背景、门第身份、凡俗职业、官籍、族属关系或初始社会身份。
- 出生位置只表示空间起点，不表示世俗身份。
- 外观只影响视觉呈现、角色识别和叙事氛围，不反向绑定真灵强度、修为收益或执念容量。
- 真灵真名前期默认隐藏于当世身份之后；中后期可主动归本溯源宣告真名，也可能因高阶事件被动暴露。
- 玩家主体不是单一肉身，而是跨世延续真灵；因此外观与人设应服务“本世承载者”和“跨世主体”的张力，而不是建立世俗背景身份。

## 3. 初次角色外观规则

玩家第一次进入游戏房间时先初始化真灵，再创建初始化角色。

### 3.1 预设真灵名

选择预设真灵名时：

- 真灵名绑定专属剧情线。
- 初始化角色使用该真灵名对应的预设角色属性、出生位置、性别、年龄与外观。
- 玩家可以自定义当前角色姓名。
- 外观可以具有与真灵剧情线相关的视觉特征，但不得写成家族血脉、门第身份或凡俗履历。

### 3.2 自定义真灵名

选择自定义真灵名时：

- 真灵名进入通用弱剧情线。
- 初始化角色使用通用预设角色属性与预设年龄。
- 玩家可以自定义当前角色姓名与性别。
- 出生位置与外观随机生成。
- 随机外观池应保持可读、可区分、低资源开局感，但不生成世俗身份解释。

## 4. 转世重修外观规则

转世重修后的角色需要重新初始化。玩家可无成本设置：

- 当前角色姓名。
- 性别。
- 年龄。
- 出生位置的大致区域。
- 外观预选择。

玩家可消耗执念设定：

- 角色属性。
- 出生具体位置。
- 初始物资。

外观预选择只决定当前身躯的视觉方向，不消耗执念，除非后续另行设定高稀有外观或特殊显化规则。执念不得用于购买世俗背景身份。

## 6. 人设表现原则

- 当前角色可以有“气质”“体貌特征”“衣着状态”“行动姿态”等表现标签。
- 多世轮回可以保留弱相似气质或真灵共鸣感，但它应服务识别与叙事，不直接提供数值收益。
- 宗门服饰、称号、职位、关系和声望应由游玩过程赋予，并随当前世变化。
- 真名暴露后的 UI 与叙事表现应强调真灵层身份，不应补造当前角色的世俗背景。

## 7. 设计历史

早期文档主要关注真灵、执念、身躯灵魂三层结构，而非美术外观。当前不应把外观设计反向绑定真灵强度、修为收益或执念容量。

本次修订将“本世身份”收敛为游玩过程中获得的关系、宗门职位和称号；初始化阶段只生成当前世承载者的可操作与可视信息，不再生成世俗背景身份。

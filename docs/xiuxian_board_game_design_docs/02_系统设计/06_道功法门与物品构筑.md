# 系统设计｜道功、法门与物品构筑

适用范围：功法知识的取得与研习、掌握阶段、阈值内容、主修改修、战斗招式来源、法宝装配与炼化，以及功法道具和丹药接口。自动研习公式与内容数量由数值专题维护。

## 1. 道功、法门与知识

1. 角色同一时间只主修一部已经学会的道功；只有当前主修推动自动修炼并提供当前主修限定内容。
2. 法门不占主修位，也不直接推动修为。移动法门提供移动能力，战斗法门提供战斗能力。
3. 道功与法门都可以一对多提供招式、被动或离散强化；招式不单独积累经验，而读取其知识来源的掌握状态。
4. 首轮所有可主修道功均可持续修炼至大乘，不设置低阶道功境界硬上限。初始道功可以完成飞升，但后期修炼与正面战斗效率整体低于通用高阶功法。
5. 宗门只决定初始预设与特色投放，不限制玩家学习其它合法功法或组合三套通用高阶路线。

## 2. 学习功法

未学习的道功或法门以可转移功法道具存在。持有者可以在回合开始即时阶段消耗道具并学会知识，普通功法道具的初始掌握度为 `0`。尚未使用的功法道具是随身资产，死亡时按普通物品掉落或回收；学会后的知识、经验与掌握度跨世保留。

宗门贡献兑换的宗门功法不生成道具，而在兑换完成时自动学习，默认掌握度 `0`，避免以掉落或转手外泄。事件也可以直接授予知识，其初始掌握度由事件结果显式配置，不强制为 `0`。

不同功法分别保存研习经验和掌握度。低阶功法的经验不能折算、继承或转移到高阶功法；改修也不改变两部道功各自的知识记录。旧功法仍可作为备用构筑、触类旁通来源或情境选择。

## 3. 自动研习与研习位

“研习功法”不再是通用主要行动。角色通过研习位在每个内部时间单位自动取得研习经验：

- 最多放置 `1` 部已学习道功与 `3` 部已学习法门，允许留空；
- 放入研习位不改变当前主修、当前移动法门、已装配战斗招式或其它构筑；
- 研习位只在每回合开始即时阶段调整。玩家可以先学习功法道具或兑换宗门功法，再自由放入、移除和排序；提交移动计划后锁定至下一回合；
- 本回合中途学会的新功法只能下一回合放入。达到 `100` 的功法自动离位，空位保持至下一回合；
- 下一回合开始的信息确认阶段集中提示空位，玩家可以确认后继续留空；
- 随机事件掌握奖励只作用于事件结算时位于研习位中的已学功法，通常选一部目标，溢出作废；
- 一次小洞天的十个内部时间单位全程锁定研习位，逐单位结算。满掌握后自动离位但不能在洞天中补位。

每个内部时间单位的成长顺序固定为“先自动修炼，后自动研习”。同单位研习提升不能追溯放大已结算修为，从下一单位开始生效。

基础 `B = 20`、共享、溢出、独立经验上限、触类旁通和标准路线的详细数值见《[功法研习与内容预算](../03_数值设计/04_功法研习与内容预算.md)》。

## 4. 掌握阶段与标准倍率

玩家界面统一显示整数 `0—100` 掌握度：

| 掌握度 | 阶段 | 标准效果倍率 |
| --- | --- | ---: |
| `0—24` | 初识 | `0.70` |
| `25—49` | 熟悉 | `0.85` |
| `50—74` | 熟练 | `0.95` |
| `75—99` | 精通 | `1.00` |
| `100` | 圆满 | `1.10` |

`75` 是模板标准效果；`100` 不解锁第四项标准内容，但提供圆满倍率。阶段内不连续插值。

每部道功至少配置三个轴：

```text
α_template：标准修炼效率，决定单位灵气写入标准 CP 的速度
β_template：修为强度系数，决定相同标准进度下当前道功能发挥的修为强度
C_template：主修限定被动、恢复 / 辅助、属性补位与可用招式的内容预算
```

标准倍率只作用于模板明确标记的字段。道功的实际灵气吸收效率与修为强度系数分别读取 `α_template × M_dao`、`β_template × M_dao`；战斗法门允许缩放的直接伤害、护盾等 `K1 / K2` 字段读取本法门的 `M_fa`；允许缩放的恢复 / 辅助效果按来源模板读取对应掌握倍率。

以下默认不读取通用掌握倍率：移动骰池、理论上限和速度；冷却、固定元气损伤、固定吸收、固定消耗；道功纯属性补位；破境丹品级与护劫护盾；触类旁通百分比；法门阈值已经写明的离散强化值。模板未声明的字段不得因掌握阶段自动缩放。掌握提高代表道功发挥增强，不得描述为取得标准 CP、境界进步或凭空获得修为。

同一知识来源在单条效果链只读取一次掌握倍率。当前主修道功的 `M_dao` 已进入修为强度后，由该道功自身提供、并以修为强度为基础的效果不再在效果系数上第二次读取 `M_dao`：

```text
主修道功自身修为效果
= 修为强度（已含 M_dao）× 道功模板效果系数

战斗法门修为效果
= 修为强度（已含 M_dao）× 法门模板效果系数 × M_fa
```

内容制作优先避免需要拆分同源倍率的特殊结构。少数确有必要的模板只能在内部使用 `√M_dao × √M_dao = M_dao`，并只在配表与验算中保留；普通玩家界面不展示该中间过程。

## 5. `25 / 50 / 75` 阈值内容

每部功法在掌握度 `25`、`50`、`75` 各提供一项可识别内容变化；到 `100` 不强制第四项。

### 5.1 道功

道功可以提供被动、恢复、辅助、招式或纯角色属性补位。纯属性补位只允许出现在道功阈值中，并且仅当该道功处于当前主修且达到门槛时生效；收集多部非主修道功不能叠加全局属性。

初始道功在 `25` 只提供一项开局收益，配置为被动或恢复类内容，不承担开局输出。初始道功与通用高阶道功都可以继续在后续门槛提供其它路线内容。

### 5.2 法门

法门每个阈值必须选择三种互斥模板之一：

- `新增能力`：新建本法门的一项招式或移动能力；
- `单招强化`：只修改本法门一项指定能力，最多调整两个相关字段；
- `整门强化`：选择一个共同维度，以较低单项幅度修改本法门全部符合条件的能力。

同一阈值不能同时新增能力并附赠强化。同一能力可以在不同阈值连续获得单招强化；整门强化也作用于之后才解锁且符合条件的本法门能力。所有强化都只绑定本法门，不能扩散到同标签或其它法门，也不占额外招式位。

战斗法门可调整伤害、护盾、固定元气影响、消耗、冷却、条件或持续时间；移动法门可调整骰池分布、理论上限、速度、元气消耗或其它移动效果。先按 `25→50→75` 应用已解锁内容形成当前模板，再对允许字段应用掌握倍率，随后进入状态、法宝和系统其它修正。

初始战斗法门在 `25` 必须解锁一项入门攻击，在 `50` 解锁一项宗门特色招式，`75` 可新增第三项或强化前两项。初始移动法门在 `25` 建立基础移动能力，`50 / 75` 可新增或强化。法门详情必须把强化展示在原能力上，不伪装为新候选招式。

## 6. 触类旁通与内容池

每部功法配置一个主研习标签，最多一个副标签。已学同标签功法可以按掌握里程碑为目标功法提供后置经验加速；标签精确匹配、可跨道功与法门、目标不能自我加速，多标签目标只取汇总值最高的一类。具体 `2% / 3% / 10%` 来源档位、共享算法和首批内容预算由研习数值专题唯一维护。

首轮固定五宗门三类初始功法共 `15` 部，三套所有宗门可取得的通用高阶路线共 `9` 部，合计 `24` 部与 `72` 项阈值内容。`72` 包含新能力、离散强化和道功属性补位，不等于主动招式数量。

高阶功法达到 `75` 后，其主要修炼或战斗效率通常应高于初始同类功法达到 `100`，但初始功法继续保留前期价值、较低成本、标签来源和情境用途。所有宗门都必须在合理时点取得三套高阶路线，升级压力不能成为出生宗门或随机投放造成的不可解除惩罚。

## 7. 请教师长

请教师长是对应宗门传法类建筑提供的专项主要行动，不是通用研习行动。每次只选择一部已经学习的本宗门道功或法门，不要求位于研习位；一次主要行动限制已经使每回合最多请教一次，不另设冷却。

每次固定增加 `40` 研习经验并消耗宗门贡献点，不消耗灵石，不受触类旁通放大，封顶溢出作废。三套通用高阶功法不适用本宗门师长入口。具体建筑和贡献点价格待宗门内容表配置。

## 8. 设置与切换主修

设置或切换主修是回合开始即时行动，每回合最多一次；死亡或重伤时禁止。目标必须是已经学会的道功，且阶级不得低于当前主修道功阶级。

不设置最低掌握度，也不限制当前处于大境界内的初期、中期、后期、圆满或瓶颈。掌握度 `0—100` 的合法目标可在任意合法回合开始切换；低掌握目标只按实际阶段提供效果。

改修结算遵守：

1. 标准 CP 是境界进度的唯一记录，改修不增加、减少、折算或替换标准 CP；旧“标准 CP × 新旧转化率 × 损失系数”公式不再使用。
2. 当前主修使用新道功的 `β_template × M_dao` 重算本世完整累计标准修为量所形成的修为强度；不保存已完成大境界的旧道功强度快照，也不要求为高品级道功重修历史境界。
3. 改修只改变修为强度、以后吸收灵气写入标准 CP 的速度、主修限定被动与可用招式；标准 CP、小境界、大境界、境界能力、已完成突破和历史最高境界全部保持不变。
4. 两部道功之间不转移研习经验或掌握度。标准路线可以设置参考改修回合，但该回合不是合法性窗口。
5. 旧主修招式退出自动战斗列表，新主修已解锁招式追加至列表末尾；道功属性补位和主修限定被动随主修状态切换。

成长公式由《[角色成长、突破与转世](05_角色成长突破与转世.md)》唯一维护。普通改修界面只需预览“境界进度不变、灵气吸收速度变化、修为强度变化、功法内容变化”，不得重新引入标准 CP 折算、换功损失系数或阶段窗口。

## 9. 战斗招式与装配

战前构筑包含：

- 当前主修道功的已解锁招式与被动；
- 从已解锁战斗法门招式中装配最多 `5` 个；
- 攻击、防御、飞遁三个固定法宝位；
- 当前生效的攻击与防御法宝招式；
- 所有有效招式合并后的手动排序列表。

法门强化条目与道功属性补位不占招式位。初始和高阶战斗法门都提供三项主动招式时，知识库最多形成“六选五”候选；若阈值使用强化或被动，候选数量相应减少。

飞遁法宝不提供循环战斗招式，只提供被动、移动或逃遁加成。法宝招式读取法宝模板、阶级、品级与炼化，不读取功法掌握倍率。

## 10. 法宝炼化

法宝炼化度为 `0—100` 整数：

```text
r <= 50：全部法宝加成与招式不生效
r > 50：实际效果 = 基础效果 × r / 100
```

三个已装配法宝各自在普通回合末增加 `5` 点，小洞天一次十单位结算增加 `50` 点，上限 `100`；进度不分摊。卸下后在归属不变时保留且不衰减。

法宝易主时只保存当前归属与当前炼化度，并按取得途径重新初始化：

| 获得途径 | 初始炼化度 |
| --- | ---: |
| 死亡掉落 | `0` |
| 普通转移 | `50` |
| 炼器取得 | `100` |
| 来源未明确 | `30` |

售出后购回仍按普通转移初始化。首轮不存在法宝绑定机制；通用玩家交易已移除，但其它明确转移仍读取本表。

## 11. 丹药与其它物品接口

普通丹药可以在回合开始即时阶段服用，并按模板参与恢复、自动修炼或其它明确效果。破境丹在突破行动确认时消耗，不通过普通服丹入口替代突破条件。

普通修为丹药默认只向对应内部时间单位提供可被当前主修吸收的等效灵气 `L_pill`：它与节点灵气分别乘实际灵气吸收效率后精确相加，不放大节点灵气，也不直接授予标准 CP。只有事件或主题奖励明确声明为“直接境界进度”时，才可绕过吸收效率写入标准 CP。

物品阶级、五档品级、坊市、采集、炼制和成熟规则见《[资源、物品、坊市与生产](08_资源物品坊市与生产.md)》；本文件不复制经济算法。

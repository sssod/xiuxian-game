# 功法系统收敛设定汇总 v0.4

> 文档定位：汇总当前已收敛的功法、道功、法门、功法载体、主修规则与 MVP 边界。本文是对现有 v2.1 设计文档的补充收敛稿，可作为后续修为公式、功法数据表、UI 与实现字段的讨论基础。

---

## 0. 当前定版总口径

功法系统的核心定位：

```text
功法不是单纯技能树，也不是单纯修为倍率表。
道功决定一世内的修行路线根基；法门决定角色在战斗、探索、采集、生产、事件中的能力展开。
功法载体、宗门权限、节点资源、后手封存共同构成功法获取与传承链。
```

当前定版要点：

```text
1. 功法分为道功与法门。
2. 道功可以推动修为增长，可以设为主修。
3. 法门不直接推动修为增长，只提供能力、指令、事件选项或资源获取效率。
4. 残页、篇章、完整功法载体是物品链。
5. 残页和篇章不可直接学习，只能合成。
6. 只有完整功法载体可以作为学习来源。
7. 常规功法获得完整载体后，需要研习入门。
8. 新手基础功法可由事件直接授予 learned level 1。
9. 道功掌握度影响当前可修上限与单位时间收益。
10. 道功掌握度不提高功法理论最高上限。
11. 道功掌握度不影响修为纯度收益、小境界升级奖励质量、大境界突破模板类型，也不制造阶段性不可追回收益。
12. 主修道功是本大境界修行根基。
13. 主修道功只在大境界第一小阶段常规开放无时间成本更换。
14. 离开第一小阶段后，本大境界主修道功锁定。
15. MVP 不做废功重修、不做改修折算、不做免费续接换功。
```

## 1. 功法类型

### 1.1 功法 Method

“功法”是泛称，不建议在规则层作为精确类型直接判断。

规则层建议拆为：

```text
DaoMethod：道功
TechniqueMethod：法门
```

### 1.2 道功 DaoMethod

道功是可推动修为增长的功法，可设为主修。

道功负责：

```text
1. 主动吐纳的基础吸收能力。
2. 主动吐纳的基础转化特质。
3. 自动运转的基础收益。
4. 当前可修阶段上限。
5. 大境界突破转接模板的路线特质。
6. 主修路线标签。
7. 与灵根、资源、节点环境的修炼相性。
```

道功不负责：

```text
1. 战斗指令的完整展开。
2. 采集、炼丹、阵法、隐匿等技艺体系的完整展开。
3. 替代法门系统。
```

### 1.3 法门 TechniqueMethod

法门不直接推动修为进度。

法门负责：

```text
1. 战斗指令。
2. 探索、移动、采集、炼丹、炼器、阵法、医术、卜算等能力。
3. 事件选项。
4. 资源获取效率。
5. 风险规避能力。
6. 某些生产配方、行动模板或行动修正。
```

法门的价值应回到时间与资源效率：

```text
同样 5 天回合时间，掌握某法门后，玩家能否更快移动、更安全探索、更高效采集、更好处理事件或更少损耗资源。
```

## 2. 功法投放与载体链

### 2.1 投放链

功法相关投放采用三层：

```text
残页
→ 篇章
→ 完整功法载体
→ 学会功法
→ 研习功法提升掌握度
```

### 2.2 残页

残页是可合成道具，不可学习。

规则：

```text
1. 不创建 MethodState。
2. 不可设为研习目标。
3. 不可直接解锁功法效果。
4. 只参与合成篇章。
5. 残页按目标篇章归类，不做精确页码编号。
```

示例：

```text
《青木养真诀·引木气残页》× 4
→ 《青木养真诀·引木气篇章》
```

不做：

```text
第 1 页、第 2 页、第 3 页、第 4 页必须全齐。
```

### 2.3 篇章

篇章是可合成道具，不可学习。

规则：

```text
1. 不创建 MethodState。
2. 不可设为研习目标。
3. 不可直接作为主修道功内容。
4. 只参与合成完整功法载体。
5. 篇章合成完整功法时需要精确篇章。
```

示例：

```text
引木气篇
养生机篇
藏真元篇
木脉生息篇
→ 《青木养真诀完整玉简》
```

### 2.4 完整功法载体

完整功法载体是唯一可学习来源。

规则：

```text
1. 可作为学习来源。
2. 可用于研习入门。
3. 可在入门后创建 MethodState。
4. 默认学习时不消耗载体。
5. 高价值道功完整载体默认使用 ItemInstance。
6. 普通低阶法门完整载体可使用 ItemStack。
```

特殊例外预留：

```text
一次性传功玉简：consume_on_learn = true
```

MVP 默认不做一次性消耗。

## 3. 功法合成规则

### 3.1 合成归属

功法合成属于物品系统，不属于研习功法。

```text
残页合成篇章：Item Synthesis / Recipe
篇章合成完整功法载体：Item Synthesis / Recipe
研习功法：学习完整载体或提升已学功法掌握度
```

研习功法不负责：

```text
1. 修复残页。
2. 校勘错漏。
3. 推演缺失内容。
4. 创造功法。
5. 融合功法。
6. 把残页或篇章变成可用内容。
```

### 3.2 MVP 合成耗时

MVP 中：

```text
残页合成篇章，不占用回合时间预算。
篇章合成完整功法载体，不占用回合时间预算。
```

归类为：

```text
个人即时操作 / 物品整理操作
```

理由：

```text
残页和篇章的获得已经通过探索、任务、交易、宗门权限、秘境或后手支付了时间与资源成本。
合成本身再收时间，会增加低价值摩擦。
```

未来可扩展：

```text
高阶功法校订
功法誊抄
装订封印
传承洗练
```

但这些不进入 MVP。

## 4. 学习与研习功法

### 4.1 学习完整功法

常规功法流程：

```text
获得完整功法载体
→ 选择研习功法
→ 达到入门阈值
→ 创建 MethodState，level = 1
→ 可设为主修或使用法门能力
```

新手例外：

```text
宗门入门事件 / 新手基础功法奖励
→ 可直接授予 learned level 1
```

### 4.2 研习功法行动

研习功法属于可选投入执行时间的个人持续行动。

读取因素：

```text
1. 实际投入小时数。
2. 悟性 aptitude_comprehension。
3. 功法阶级 tier_code。
4. 功法品级 quality_code。
5. 是否有导师。
6. 是否有宗门藏经阁、静室、讲经等设施或事件加成。
7. 当前神念状态。
8. 相关基础法门或前置知识。
```

研习功法可以产出：

```text
1. MethodState.exp 增加。
2. MethodState.level 提升。
3. 未入门功法进入 learned level 1。
4. 道功当前可修上限提高。
5. 道功单位时间收益提高。
6. 法门指令、事件选项或行动修正解锁。
7. 可追回的知识型、提示型、法门型收益。
```

研习功法不能产出：

```text
1. 缺失篇章自动补齐。
2. 残页自动修复。
3. 功法理论最高上限提高。
4. 大境界突破模板类型变化。
5. 小境界升级奖励质量变化。
6. 修为纯度收益变化。
7. 阶段性不可追回收益。
```

## 5. 道功掌握度

### 5.1 定义

道功掌握度表示角色对该道功的理解、运转熟练度与当前承载能力。

它可以影响：

```text
1. 当前可修上限。
2. 主动吐纳单位时间收益。
3. 自动运转单位时间收益。
4. 某些可追回的知识型、提示型、法门型收益。
```

它不能影响：

```text
1. 修为纯度收益。
2. 小境界升级奖励质量。
3. 大境界突破模板类型。
4. 大境界突破模板自身风险结构。
5. 功法理论最高上限。
6. 阶段性不可追回收益。
```

### 5.2 理论最高上限与当前有效上限

道功有两个上限概念：

```text
1. 功法理论最高上限 theoretical_max_cap_stage
2. 掌握度当前上限 mastery_current_cap_stage
```

当前有效上限：

```text
effective_current_cap_stage = min(
  theoretical_max_cap_stage,
  mastery_current_cap_stage
)
```

因为残页、篇章不可直接学习，所以不再存在：

```text
已学内容上限
缺失篇章上限
缺失残页上限
```

### 5.3 示例：《青木养真诀》

```text
理论最高上限：B-1 100%

level 1：当前可修至 A-2 100%
level 2：当前可修至 A-3 100%
level 3：当前仍可修至 A-3 100%，单位时间收益提高
level 4：当前可修至 B-1 100%
level 5：当前仍可修至 B-1 100%，单位时间收益进一步提高
```

不会发生：

```text
level 5 让《青木养真诀》修到 B-2。
level 5 让 A-3 → B-1 的突破模板变成另一个模板。
level 不够导致 A-1 → A-2 时永久少拿属性。
level 不够导致修为纯度永久变差。
```

## 6. 主修道功规则

### 6.1 主修定义

主修道功是一世内当前大境界的修行根基。

规则：

```text
1. 同一时间只能有一个主修道功。
2. 只有道功能设为主修。
3. 主修道功决定主动吐纳、自动运转、修为上限与突破路线读取。
4. 主修道功常规只在大境界第一小阶段内可无时间成本更换。
```

### 6.2 常规改修窗口

常规改修窗口：

```text
A-1
B-1
C-1
D-1
……
```

离开第一小阶段后：

```text
本大境界主修道功锁定。
```

### 6.3 不开放免费续接换功

不因为以下原因开放免费换主修：

```text
1. 当前功法理论上限达到。
2. 当前掌握度上限达到。
3. 玩家后悔选择主修。
4. 玩家想临时换更优突破模板。
5. 玩家本世想继续但当前路线不够理想。
```

MVP 不做：

```text
废功重修
改修折算
免费续接换功
中途换主修惩罚
```

### 6.4 主修锁定提醒

MVP 不在 B-1 → B-2 等结算升级关口插入确认事件。

原因：

```text
1. 小境界升级发生在结算阶段。
2. 插入确认会打断主动吐纳或自动运转结算。
3. 玩家选择不升级会造成行动规划未成功的损失感。
4. MVP 应保持小境界升级轻量顺滑。
```

提醒位置改为 UI 常驻：

```text
主修功法更换界面
主修道功详情界面
角色修为摘要区
```

示例 UI 文案：

```text
当前处于 B-1，仍可无时间成本更换本大境界主修道功。
当修为推进至 B-2 后，本大境界主修道功将锁定，直至进入 C-1。
```

## 7. 道功自然上限设计规范

### 7.1 推荐自然上限

可作为主修根基的道功，其自然最高上限原则上应落在某个大境界第一小阶段。

推荐：

```text
A 段道功：A-1 / A-2 / A-3 / B-1
B 段道功：B-1 / B-2 / B-3 / C-1
C 段道功：C-1 / C-2 / C-3 / D-1
```

### 7.2 不推荐自然中段上限

不推荐：

```text
A-1 / A-2 / A-3 / B-1 / B-2
```

原因：

```text
这会把玩家自然卡在 B-2，而 B-2 已离开 B 阶改修窗口。
```

### 7.3 传承系列拆分

同一传承可以连续，但规则层应拆成多个完整道功模板。

示例：

```text
lineage_id = qingmu_lineage

《青木养真诀》：A-1 → B-1
《青木长生经》：B-1 → C-1
《青木洞玄篇》：C-1 → D-1
```

它们共享传承标签、宗门来源、世界观文本和资源相性，但在规则层是不同完整道功。

## 8. 大境界突破与道功关系

### 8.1 突破模板来自道功路线特质

大境界突破模板类型由道功本身的路线特质决定，不由掌握度等级决定。

可以是：

```text
《青木养真诀》本身具有 A-3 → B-1 的木系稳健突破转接。
```

不可以是：

```text
《青木养真诀》level 1 匹配低级模板，level 5 匹配高级模板。
```

### 8.2 掌握度只影响是否承载得住目标阶段

示例：

```text
《青木养真诀》理论最高：B-1
突破转接：A-3 → B-1

level 2 当前只能修到 A-3：
- 可以修到 A-3 100%。
- 不能使用该功法完成 A-3 → B-1。
- 原因是当前掌握度承载不住 B-1。

level 4 当前能修到 B-1：
- 可以使用 A-3 → B-1 的木系稳健突破转接。
- 但突破模板类型不是由 level 4 生成，而是功法本身特质。
```

## 9. 法门规则

### 9.1 法门不推动修为

法门不直接增加修为进度。

法门的主要价值：

```text
1. 解锁战斗指令。
2. 解锁事件选项。
3. 修正行动收益。
4. 降低行动风险。
5. 提高资源获取效率。
6. 影响生产、采集、移动、探索等非修为活动。
```

### 9.2 法门与灵根相性

灵根与法门的关系主要是使用相性。

示例：

```text
雷系灵根相性高：
使用《雷芒指》时指令稳定性、消耗效率或效果质量更好。

木系灵根相性低：
使用火爆类法门时可能消耗更高、效果不稳定或解锁门槛更高。
```

法门相性不直接改变修为进度。

## 10. 闭关、托管与功法

### 10.1 闭关

闭关不是独立行动类型，而是行动包装 / 行动前缀。

可表达为：

```text
闭关吐纳
闭关研习
闭关巩固
闭关突破
```

底层仍是：

```text
主动吐纳
研习功法
巩固根基
大境界突破
```

闭关表达：

```text
1. 高连续性。
2. 高专注。
3. 高打断损失。
4. 更强跨回合延续倾向。
```

MVP 不建议闭关自带收益倍率，否则会变成所有修炼行为的默认最优包装。

### 10.2 托管

托管是 AI 在玩家缺席、超时或明确授权时生成低风险行动。

托管可以选择：

```text
低风险主动吐纳
研习功法
巩固根基
休整
警戒
停留
安全连续行动延续
```

托管不等于闭关。

托管不得主动：

```text
1. 发起大境界突破。
2. 进入高危秘境。
3. 回收高风险正式后手。
4. 消耗稀有不可逆资源。
5. 执行死亡 / 转世 / 真名暴露等重大选择。
```

## 12. 示例功法

### 12.1 《青木养真诀》

```text
类型：道功
传承：青木一脉
自然段位：A 段道功
理论最高：B-1 100%
路线标签：wood, stable, vitality, orthodox
突破转接：A-3 → B-1
定位：稳健、生机、低风险、慢速成长
```

掌握度：

```text
level 1：当前可修至 A-2 100%
level 2：当前可修至 A-3 100%
level 3：当前仍可修至 A-3 100%，单位时间收益提高
level 4：当前可修至 B-1 100%
```

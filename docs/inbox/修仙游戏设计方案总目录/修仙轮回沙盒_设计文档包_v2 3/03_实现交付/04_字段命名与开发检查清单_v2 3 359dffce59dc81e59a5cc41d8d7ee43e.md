# 字段命名与开发检查清单（v2.3）

## 1. 主时间字段

必须使用：

```
current_world_day
current_world_hour
current_macro_period_id
world_day
world_hour
hour_tick
```

适用范围：

```
房间状态；
行动创建、开始、完成；
事件触发；
资源输入消耗；
局部时停冻结；
C1 追赶；
B1 交锋轮；
P0 记录；
节点刷新；
宗门 AI 推进；
日志与回放。
```


检查点：

```
FallbackState.force_speed 必须为 N1；

```

检查点：

```

```

检查点：

```
每个 result_package 必须带 world_day / world_hour；
每次速度变化必须写入 speed_segments；
每次队列变更必须写入 submitted_command_changes；
每次校验失败必须写入 command_validation_records 与个人日志；
每次 B1 交锋轮必须写入 formal_encounter_rounds。
```

## 9. 开发前检查

新增 schema、接口、存档字段或 UI 状态前，检查：

```
是否能落到 world_day / world_hour；
是否需要 SpeedState 记录速度变化；
是否需要进入 TimelineReplay；
是否会暴露私人归因给其他玩家；
是否区分自动兜底、显式托管、超时安全默认；
是否需要 CommandValidationResult；
是否会在 C1 追赶期间触发随机事件；
是否会让普通队列承担 B1 轮内选择；
是否需要 ResultPackage 回写；
是否需要 Debug 面板显示。
```

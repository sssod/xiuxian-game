# 经济系统设计｜地图资源产出

## 1. 当前结论

地图资源产出由地图节点、资源槽、建筑槽、控制权、宗门行动和季度常态结算共同决定。

节点是主单位；资源和建筑不是独立漂浮物，而是挂载在地理节点上的槽位层。

## 2. 节点常态产出流程

```text
节点拥有资源槽
→ 宗门或势力控制节点 / 建筑正常运转
→ 每季度常态结算产出
→ 写入 sect_storage / node_storage
→ 写入库存日志
```

规则：

- 已控制资源节点的基础产出不占宗门主行动。
- 产出受控制权、影响力、建筑状态、资源丰度、灾害、敌对干扰、人力占用影响。
- 产出优先进入宗门抽象库存或节点库存，库存底层规则见《06_储物空间系统设计/03_库存系统》。
- 若产出需要具体物品形态，再由物品系统转换为 ItemStack / ItemInstance。

## 3. 宗门行动产出

宗门每季度始终只有 1 个宗门主行动。六类主行动中，开采 / 资源介入、探索、建设、远征等都可能产生资源结果，但不应替代已控资源节点的常态产出。

## 4. 阶段预算修正

数值草案提出：玩家首次突破到某大境界后，世界激活对应阶段预算。预算进入节点资源槽、宗门库存、市场交易、机会窗口、NPC 个人资产或事件投放。预算打开提供机会，不自动赠送修为。

## 5. 缺口

- ResourceSlot 表、丰度、再生周期、灾害、建筑产能公式未定。
- 各境界阶段预算的具体数值未定。
- 资源点模板与地图实例未定。

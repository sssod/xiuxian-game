# 系统设计｜单局流程与同步回合

适用范围：正常回合的行动预算、同步阶段、全局结算暂停边界和小洞天回合分支。

## 1. 当前结论

每个正常回合，每名玩家拥有：

- 回合开始阶段内不限制次数的合法即时行动；
- 一次地图移动；
- 一个主要行动。

玩家同时规划、同步移动、统一行动结算。移动和主要行动属于同一回合；没有抵达目标时，原定主要行动失效。

## 2. 正常回合阶段

```text
A. 回合开始与即时行动
→ 交易、调整装备、服丹、切换主修、整理资产

B. 隐藏规划
→ 目的地、路线、移动方式、主要行动类型
→ 等待全部玩家确认

C. 同时移动结算
→ 投掷移动骰池
→ 在共享移动时间轴演算路径
→ 相遇或强制事件只中断相关玩家
→ 记录事件，不在移动阶段处理选择

D. 行动细节输入
→ 抵达者首次选择原定行动的具体参数
→ 被中断者提交事件输入

E. 统一行动结算
→ 独立行动分别结算
→ 多人竞争时暂停全局结算
→ 竞争完成后恢复剩余结算

F. 回合末成长与世界结算
→ 自动修炼
→ 持续状态、寿元和其它世界结果
→ 飞升共同胜利判定
```

只有涉及复数玩家的竞争处理会暂停全局行动结算。单人临时选择或单人战斗不要求无关玩家重复提交。

## 3. 两段式承诺摘要

移动前只锁定行动类型和出行计划，移动后才首次选择对象、投入、数量等具体参数。移动后不能把行动类型改成另一类型。

若成功抵达但不存在合法参数，行动失败，并从当前地点途中事件池抽取一次独立代偿事件。

## 4. 小洞天回合分支

进入小洞天的当前回合立即获得十倍角色内部时间结算。后续回合：

```text
回合开始
→ 执行其它合法即时行动
→ 选择继续停留或主动退出

继续停留：
  跳过移动
  主要行动锁定为闭关修炼
  推进十个内部时间单位

主动退出：
  返回进入位置
  恢复本回合普通移动和主要行动

洞天关闭：
  先完成本轮十倍结算
  再强制返回进入位置
```

外部地图、其他玩家和世界事件只推进一个外界回合；洞天关闭时间也按外界回合计数。

## 5. MVP 缺口

同步流程仍缺多人房间准备、阶段时限、未提交安全默认、掉线重连、托管、永久退出和对局中止规则。这些属于 MVP P0 阶段门，不能留给实现阶段自行决定。

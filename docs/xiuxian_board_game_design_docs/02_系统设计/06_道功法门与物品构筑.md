# 系统设计｜道功、法门与物品构筑

适用范围：主修道功、知识掌握、招式解锁、换功折算、法宝装配与炼化、丹药和物品获取接口。

## 1. 主修道功与法门

1. 角色同一时间只主修一本道功，只有当前主修推动自动修炼。
2. 法门不占主修位，不直接推动修为。
3. 道功和法门都可以一对多提供招式。
4. 招式不独立积累经验，而读取知识来源掌握度。

## 2. 掌握度

道功与法门使用 `0—100` 整数掌握度：

| 掌握度 | 阶段 | `K1/K2` 倍率 |
| --- | --- | ---: |
| `0—24` | 初识 | `0.70` |
| `25—49` | 熟练 | `0.85` |
| `50—74` | 精通 | `1.00` |
| `75—100` | 圆满 | `1.15` |

新获得知识默认从 `0` 点开始；初始配置、导师或事件可以直接授予更高进度。尚未获得的功法没有掌握状态。

掌握阶段只在阈值处变化，阶段内不连续插值。回合末自动修炼不增加掌握度；通用入口是“研习功法”主要行动。

## 3. 招式解锁与装配

1. 同一知识来源的多个招式共享掌握进度，但可有不同解锁门槛和离散等级。
2. 法门招式从已解锁内容中选择最多 `5` 个装配。
3. 道功招式只读取当前主修道功。
4. 换主修后旧道功招式退出，新道功招式追加至列表末尾。
5. 转世保留知识来源招式与掌握进度，但受新境界限制。

固定元气损伤 `D` 与 `K3` 只随离散招式等级变化，不读取掌握阶段倍率。

## 4. 换功

切换主修在回合开始即时阶段进行，每回合最多一次；死亡或重伤时禁止。目标道功阶级不得低于当前主修道功阶级。

```text
折算后标准 CP
= 旧标准 CP
× 旧道功 CP 转化率 / 新道功 CP 转化率
× 换功损失系数
```

MVP 换功损失系数为 `1`。换功不能使大境界上升或下降，但可以改变当前大境界内的小境界。封顶溢出 CP 暂存，成功突破后释放；不足当前大境界下限时保留大境界并获得“境界虚浮”。

属性上限变化时，生机、元气、神念按原百分比继承；具体可支配上限和取整规则仍在 G-23。

## 5. 法宝装配

角色拥有攻击、防御、飞遁三个固定类型法宝位。攻击与防御法宝可以提供招式；飞遁法宝不提供循环战斗招式，但提供被动、移动或逃遁加成。

法宝招式读取法宝模板、阶级 / 品级、自身等级和当前炼化程度，不读取知识掌握倍率。

## 6. 炼化程度

炼化用于防止死亡掉落法宝被新持有者立即发挥。范围为 `0—100` 整数：

```text
r <= 50：全部法宝加成与招式不生效
r > 50：实际效果 = 基础效果 × r / 100
```

三个已装配法宝每个普通回合末各增加 `5` 点，不分摊；小洞天一个外界回合增加 `50` 点。卸下后在归属不变时保留进度且不衰减。

易主时只保留当前一任归属与当前炼化度：

| 获得途径 | 初始炼化度 |
| --- | ---: |
| 死亡掉落 | `0` |
| 交易或普通转移 | `50` |
| 炼器取得 | `100` |
| 来源未明确 | `30` |

售出后购回仍按交易初始化。新方案不使用法宝绑定机制。

## 7. 丹药与其它物品

丹药可以在回合开始即时阶段服用，参与自动修炼、突破或明确效果。完整丹药类别、炼丹、炼器、材料、货币和物品获取循环尚未裁决；它们属于 `S-02` 与经济闭环阶段门。

## 8. MVP 缺口

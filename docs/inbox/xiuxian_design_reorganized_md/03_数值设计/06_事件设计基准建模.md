## 3. MVP 建模方向

- 模板 + 条件 + 结果包 + 子事件请求。
- 稳定随机种子，不能靠刷新 UI 改变候选。
- 主选项区 1–3 个 + 溢出选项。
- 默认隐藏不可用选项。

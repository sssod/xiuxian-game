# 系统设计｜棋盘地图与移动

适用范围：首张固定六边格地图、出生区域、路线与关隘、移动骰池组合、共享移动时间轴、相遇、逃遁落点和固定地点小洞天。

## 1. 地图结构

战略地图以六边格空间关系为基础，可以缺格、断开、稀疏分布或使用显式特殊连接。地图具有多路线与绕行，不是单一连续主路径。普通六边格不可购买；只有主题预先标记的特定经营节点可以取得主导权。

首轮 MVP 只实现一张固定基础地图，不实现程序化随机地图。`2—4` 人共用同一拓扑，并按人数从预设出生座位组合中选择分布均衡、尽量相距较远的座位。

## 2. 出生区域与共享区域

固定地图由四个经过设计的出生区域和共享竞争区域组成：

1. 每个出生区域支持前 `1—5` 回合的基础经营、资源取得和至少一条可靠取得首枚筑基丹的路径。
2. 天险可以形成区域边界，但不得完全封闭。
3. 每个出生区域至少有两条通往共享区域的独立路线：较短路线可以经过可收费、可设障碍的关隘；另一条可以更长或风险更高，但不得被玩家永久封锁。
4. 高价值地产、固定小洞天、重点 PVE 与飞升前置逐步集中到共享区域，推动中后期直接互动。

出生区域是与宗门身份解耦的对局座位。宗门选择完成后才分配座位；任一宗门都可出现在任一地区。出生地点外观可使用所选宗门的驻地、别院或临时据点，但区域拓扑与基础经济条件不因宗门改变。

未来若支持随机地图，也只能在玩家对应的特定区域块内选择合法出生点，不能全图完全随机。

## 3. 经营节点与关隘

地图标记已有建筑节点、已有资源节点和待开发优质地块三类经营资产，同一节点只有一个主导宗门；详细取得、建筑和收费规则见《[宗门、地产与建筑经营](07_宗门地区经营.md)》。

关隘类节点不提供地点功能，角色沿对应路线通过时结算过路费。主导宗门可以按关隘模板设置障碍，使该路线不能通过；所有者不缴过路费，也不受自己的障碍阻挡。每个出生区域仍必须保留一条不能被永久封锁的替代路线。设置、撤除、成本、持续期与反制尚待地图内容表裁决。

## 4. 移动组合

每次大境界提升解锁一档境界基础移动骰池。玩家规划时可以从当前已经解锁的任一档选择，不强制使用最高档；高境界池必须配置更高固定或选用元气成本，使短途节省与远行保持取舍。

移动法门可以改变所选境界骰池的分布与理论最大点数，并产生额外元气消耗。移动法宝在法门调整后增加固定点数，同时额外消耗灵石与耐久。移动结果为：

```text
实际可移动格数
= 经当前移动法门调整后的境界基础骰池结果
+ 本次启用移动法宝的固定加成
```

首轮取消独立速度系数。设：

```text
M = 经法门调整后的境界骰池理论最大点数
  + 本次启用移动法宝的固定加成

单格耗时 = 标准移动单位时间 ÷ M
实际到达或停止时刻 = 实际经过格数 × 单格耗时
```

任一组合走满自身理论最大距离时，均在一个标准移动单位时间结束。法宝固定加成同时提高距离与速度，由灵石和耐久成本制衡。移动法门的掌握投入、骰池修改和额外消耗属于其模板价值；法宝仍受炼化门槛。

选择境界骰池与法门只消耗元气；启用移动法宝时在此之外支付灵石与耐久。元气为 `0` 或无法支付已知成本时，不能选择对应移动组合，但仍可在当前位置执行合法主要行动。

## 5. 共享移动时间轴

1. 所有玩家的路径在同一时间轴同步演算，直到最后一名玩家停止。
2. 玩家从进入某格到离开该格的完整区间都占据该格；提前抵达者持续占据目的地至时间轴结束。
3. 两名玩家占用同一格的时间区间重叠即发生相遇。普通相遇不触发事件；任一方所属宗门已建立对应仇敌关系时，相遇升级为强制事件并中断双方移动。
4. 局部事件只中断相关玩家，无关玩家继续演算；事件选择延后到行动结算阶段。
5. 骰点不足者按实际格数计算停止时刻并占据落点，原定主要行动失效，进入该地点途中内容。
6. 分数到达时刻和严格同刻的正式比较精度待数值配置，但不得重新引入独立速度属性。

## 6. 固定地点小洞天

固定地点小洞天与随机事件入口是两条独立投放渠道。固定投放时序：

- 第 `10` 回合开放首批，数量为“玩家数－1”，每个数量单位对应一个独立地点和一次进入资格；
- 第 `20`、`30`、`40`……回合各再开放一个地点；延长对局持续此周期，不因第 `24` 回合锚点停止或提速；
- 新周期优先从当前关闭的固定洞府中选择；既可从未开放，也可曾被使用后关闭；
- 若所有固定洞府都仍开放且未使用，则随机选择一个，舍弃其旧资格并由本轮资格顶替；资格不叠加。

开放后保持可用，直到某名玩家成功进入，不在投放回合结束时过期。一次资格被使用后，本次开放关闭，但地点保留，可在后续周期再次开放；任何玩家都没有累计进入上限或重复冷却。

固定洞府采用“先到先挑战”，不进行灵石竞价，也不默认触发 PVP：

1. 合法抵达者按共享时间轴到达时刻排序，最早者先挑战入口重点 PVE；通过即取得洞天，失败或逃遁后下一到达者才挑战。
2. 严格同刻抵达者相互独立挑战同一套 PVE；通过者中战斗用时最短者取得资格，仍同时时用稳定随机种子裁定。
3. 资格一经取得，本次开放立即关闭，其余玩家的小洞天主要行动落空。
4. 入口重点 PVE 可以按事件模板随外界回合升档；洞府已开放多久不会冻结难度。

取得后只在当回合末结算一次十个内部时间单位，不进入连续停留分支。随机事件入口通过各事件概率控制统计期望，不设单局预算帽。

## 7. 逃遁落点

主动逃遁成功或重伤战败后，角色默认可在相邻 `1` 格内选择合法地点免费移动：

- 目标必须被至少一种已有移动方式允许进入；
- 不能穿越硬阻挡或敌对封锁；
- 不消耗元气、灵石、耐久或其它移动资源；
- 不触发新地点事件；
- 没有合法地点时留在原地，但不撤销逃遁或战败结果。

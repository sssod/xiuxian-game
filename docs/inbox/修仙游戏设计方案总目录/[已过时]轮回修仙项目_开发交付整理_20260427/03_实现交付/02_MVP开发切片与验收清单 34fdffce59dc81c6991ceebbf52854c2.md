# MVP 开发切片与验收清单

## 0. 文档定位

本文将整理后的设计拆成可实现、可测试、可验收的开发切片。目标是避免一次性实现完整大系统，而是通过纵向闭环逐步验证核心体验。

MVP 总目标：

```
本地可单人测试
+ 可部署私人服务器
+ 支持 3 人共玩
+ M0 → M3 纵向闭环
```

## 1. 开发切片总览

| 切片 | 名称 | 核心目标 |
| --- | --- | --- |
| VS0 | 技术底座 | 房间、权威结算、存档、配置、日志 |
| VS1 | 角色与新手入门 | 真灵、当世角色、初始地图、拜入宗门 |
| VS2 | 行动经济与事件 | 6 行动格、移动、选择事件、结果包 |
| VS3 | 修炼与小境界 | 主修道功、吐纳、自动运转、小境界升级 |
| VS4 | 宗门资源平台 | 身份、权限、库存、宗门主行动 |
| VS5 | 物品与经济可信 | 资产容器、物品、灵石、关键突破物 |
| VS6 | 大境界突破 | M1→M2、失败标签、轮回账本 |
| VS7 | 世界演化 | 节点控制、资源槽、秘境窗口、传闻 |
| VS8 | 转世与后手 | 死亡、执念、正式后手、回收链 |
| VS9 | 3 人共玩 | 多人锁定、托管、分宗间接竞争 |

## 2. VS0：技术底座

### 目标

建立可运行的房间循环和服务端权威结算框架。

### 必做

- 本地单人房间创建。
- 简化私人服务器运行。
- 房间状态。
- 季度阶段机。
- 玩家锁定。
- 服务端统一结算。
- 结果包接口。
- 基础日志。
- 存档保存 / 读取。
- 配置加载。
- Debug 状态查看。

### 验收

- 能创建房间并进入季度开始。
- 能从角色行动阶段锁定。
- 能执行一次空结算进入下一季度。
- 退出后可读取存档继续。
- Debug 面板能看到阶段、季度、玩家、状态版本。

## 3. VS1：角色与新手入门

### 目标

跑通“创建真灵 → 初次投生 → 获取基础信息 → 拜入宗门”的新手流程。

### 必做

- 真灵创建。
- 当世角色生成。
- 基础属性：体魄、精力。
- 资质子项：根骨、悟性、灵根。
- 状态条：生机、元气、神念。
- 初始村庄节点。
- 已知 / 半知 / 初步解锁节点。
- 角色日志。
- 新手任务：找村长打听宗门。
- 家庭支持事件。
- 镇集武馆学习轻身功法。
- 前往山门。
- 入门事件链。
- 获得外门身份与基础功法。

### 验收

- 玩家能从青禾村出发，按流程抵达宗门山门。
- 途中至少触发一次移动事件。
- 入门事件能揭示资质子项并给予外门身份。
- 入门 follow-up 修炼作为事件链奖励结算，不计为第二个普通持续行动。

## 4. VS2：行动经济与事件

### 目标

让玩家每季度用 6 个朔望行动格规划移动和持续行动，并触发常规事件。

### 必做

- 6 行动格 UI / 数据。
- 节点驱动行动规划。
- 即时行动、移动行动、持续行动。
- 待锁定预案。
- 服务端生成 tick 时间轴。
- 移动事件。
- 选择事件。
- 事件结果包。
- 角色结束位置权威写入。
- 休整 / 警戒 / 停留。

### 验收

- 玩家可在当前节点选择 0–1 个持续行动。
- 玩家可移动到目标节点并消耗行动格。
- 服务端可改变实际结束位置。
- 常规事件显示 1–3 个主选项。
- 事件结果包能改变角色状态、库存或日志。

## 5. VS3：修炼与小境界

### 目标

跑通基础修炼成长，不进入大突破。

### 必做

- 主修道功。
- 自动运转。
- 主动吐纳。
- 研习功法。
- 修为进度。
- 功法经验。
- 主修道功支持范围。
- 小境界升级。
- 修为纯度数据层保留。
- 寿元基础显示。

### 验收

- 主动吐纳消耗行动格并增加修为。
- 自动运转可在合法 tick 提供少量收益。
- 主动吐纳期间不叠加自动运转。
- 修为达到条件后可从 A-1 升到 A-2。
- 小境界升级不进入突破事件链。
- 主修道功不支持下一阶段时，修为推进被限制。

## 6. VS4：宗门资源平台

### 目标

让宗门成为真实资源平台，而不是背景文本。

### 必做

- 宗门身份层级。
- 权限标签。
- 贡献记录。
- 门内声望。
- 宗门库存五类资源。
- 资源申请。
- 资源预留。
- 每宗门每季度 1 个主行动。
- 主行动六类之一至少实现 2–3 类。
- 常态资源节点产出。
- 执行完成度。
- 玩家亲自介入宗门行动。

### 验收

- 玩家可因身份获得设施使用或资源申请权限。
- 宗门支持资源来自真实库存。
- 贡献不能直接兑换资源。
- 宗门每季度只执行一个主行动。
- 已控制资源节点可常态产出。
- 玩家介入宗门行动需要 S3 抵达节点或事件窗口。

## 7. VS5：物品与经济可信

### 目标

建立资产容器、物品、灵石、关键突破物和 NPC 库存可信边界。

### 必做

- 资产容器。
- 灵石。
- 低阶货币接口。
- 聚灵石接口。
- ItemStack / ItemInstance。
- 物品 Tier + Quality。
- 随身资产标签。
- 无装备栏战斗资源来源。
- 资源使用日志。
- 关键突破物。
- ShopStock。
- N3 / N4 库存持久化。
- 禁止战斗开始临时初始化 NPC 完整库存。

### 验收

- 玩家获得物品后有明确资产容器。
- 玩家使用资源会写日志。
- 关键突破物是具体实例。
- 商店库存不属于掌柜个人。
- 战斗战利品只来自持久化资产、事件锁定奖励或预算生成奖励。
- 背包不使用重量、体积、格子限制。

## 8. VS6：大境界突破

### 目标

跑通第一次关键突破链 M1 → M2。

### 必做

- 大境界瓶颈。
- 突破准备面板。
- 风险档位。
- 主要短板。
- 失败标签方向。
- 关键突破物消耗。
- 主修道功读取突破模板。
- 1 轮 5 格突破挑战。
- 成功 / 失败存活 / 身死转世。
- 失败标签写入轮回账本。
- 突破结果包。

### 验收

- 玩家不能通过自动运转跨越大境界。
- 玩家必须主动选择突破。
- 事件链创建时消耗关键突破物。
- 突破失败不是只显示“失败”，而有原因标签。
- 身死转世能进入转世流程。
- 轮回账本能显示本次突破信息。

## 9. VS7：世界演化

### 目标

让世界节点和宗门行动产生可见变化。

### 必做

- 35±10 节点首图。
- 3 个主要宗门。
- 宗门核心 / 腹地 / 边界 / 荒野结构。
- 资源槽。
- 建筑槽基础。
- 节点影响力。
- 控制权变化事件。
- 秘境 EntranceSlot。
- 传闻池。
- 世界日志。

### 验收

- 至少一个资源节点支持常态产出。
- 至少一个边界节点能发生影响力变化。
- 至少一个秘境窗口可开启。
- 世界日志可记录节点高价值变化。
- 玩家只能看到可见信息或传闻，不看到全世界日志。

## 10. VS8：转世与后手

### 目标

验证跨世反馈不是纯惩罚。

### 必做

- 死亡事件链。
- 轮回账本。
- 执念容量权重制。
- 下一世初始化选择。
- 正式后手容量。
- 藏物后手。
- 信息后手。
- 后手感应。
- 后手回收事件。
- 后手失效原因链。

### 验收

- 玩家死亡后可转世。
- 玩家能携带有限执念遗留。
- 玩家能布置至少一种正式后手。
- 后手记录挂载到节点。
- 下一世能通过账本和感应找到后手线索。
- 后手风险只在节点明确变化时检定。
- 后手失效有原因链。

## 11. VS9：3 人共玩

### 目标

支持 3 人房间，并验证分宗并行与间接竞争。

### 必做

- 3 玩家加入同一房间。
- 独立真灵与当世角色。
- 多玩家锁定 / 超时。
- 托管。
- 3 个主要宗门。
- 分宗加入。
- 宗门行动并行结算。
- 节点控制 / 资源名额竞争。
- 行动可见性。
- 传闻传播。

### 验收

- 3 名玩家可在同一房间提交季度行动。
- 全员锁定或超时后自动结算。
- 超时玩家不阻塞房间。
- 托管不会主动执行高风险突破或暴露后手。
- 一个玩家所属宗门改变节点状态后，另一个玩家通过传闻或地图变化感受到影响。
- 不需要直接 PvP 即可产生竞争压力。

## 12. MVP 总验收清单

### 12.1 运行

- 本地单人可创建并游玩。
- 私人服务器可部署。
- 3 人可共玩。
- 可保存、恢复、续开。
- 无人在线不自动推进。

### 12.2 玩家闭环

- 创建真灵。
- 初次投生。
- 拜入宗门。
- 修炼到瓶颈。
- 准备突破。
- 尝试突破。
- 失败或成功。
- 死亡后可转世。
- 下一世可利用账本或后手优化。

### 12.3 宗门闭环

- 加入宗门。
- 获得身份。
- 使用权限。
- 申请资源。
- 影响宗门行动。
- 宗门有真实库存。
- 宗门行动改变节点或库存。

### 12.4 世界闭环

- 节点图可移动。
- 资源槽产出。
- 节点事件触发。
- 秘境窗口开启。
- 控制权 / 影响力变化。
- 世界日志和传闻更新。

### 12.5 技术闭环

- 结果包统一回写。
- 存档保存关键状态。
- Debug 可追踪资源、事件、行动和随机。
- 版本号可记录。

## 13. 延后内容

以下不进入 MVP：

- 完整高境界体系。
- 深度 NPC 生态。
- 全量市场模拟。
- 玩家直接交易。
- 强 PvP。
- 玩家互相护法。
- 共同秘境。
- 宗门内派系。
- 宗主职位。
- 大规模宗门战争。
- 完整炼丹炼器工业链。
- 背包重量 / 体积 / 格子系统。
- 装备栏和战斗中换装备。
- 创意工坊和商业化系统。

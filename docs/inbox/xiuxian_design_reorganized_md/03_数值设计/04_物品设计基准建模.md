# 数值设计｜物品设计基准建模

## 1. 当前结论

物品基准应围绕资产可信、分阶预算、堆叠/实例边界、资源输入效果和日志追踪，而不是简单奖励倍率。

## 2. 可用基础

- 物品分为可堆叠物品或独立实例物品。
- 生成预算用于控制世界投放。
- ResourceEffectBalance 将资源价值折算为 benchmark_hours_saved。
- 丹药等资源以单位效果 × 有效小时进入行动结算。
- 高价值法宝、完整道功载体、正式后手物应使用 ItemInstance。
- 正式后手物必须占用真灵藏宝的设置数量或单个容量，不得用数值建模绕过后手容量限制；宗门外洞府和普通藏宝中的物品属于无主遗留设施资产，只有开启或破阵后才进入可用资产流转。

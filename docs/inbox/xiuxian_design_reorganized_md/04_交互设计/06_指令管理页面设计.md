## 队列面板

建议显示：

```text
当前指令
后续 1
后续 2
后续 3
当前兜底规则
```

## 入队校验

入队时只提示当前是否合法：

```text
可入队：当前已满足突破条件。
不可入队：当前未拥有筑基丹。
不可入队：当前地点不允许突破。
不可入队：当前灵力储备不足。
```

不提示复杂未来推演，例如“预计 8 日后满足”或“如果前序炼丹成功则执行”。

## 执行失败提示

```text
预输入指令未执行：开启筑基突破。
原因：缺少筑基丹。
已自动转入：吐纳。
```

或：

```text
队列已空。
当前处于低风险节点，已自动转入吐纳。
世界进入 N1，等待你输入新指令。
```

## B1 交锋边界

B1 或 P0 期间可以编辑普通行动队列，但普通队列只影响交锋结束后的后续行动，不替代本轮战斗或突破选择。

B1 专用面板应显示：

```text
当前速度：交锋慢速
本轮剩余现实提交时间：60 秒
战斗：5 个交锋格 / 轮，常规 3 轮共 30 分钟，结算不足 1 小时按 1 小时
突破：1 个交锋格 / 阶段，阶段耗时由突破模板声明，总耗时暂定 1～6 小时
默认策略：未提交时执行当前预设
```

普通行动队列页面不得保存战斗 5 格序列、突破阶段选择、敌方行为预案或未知事件选项。

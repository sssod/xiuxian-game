# 数值设计｜移动、行动与竞争数值

适用范围：六境基础移动骰池、移动法门修改、移动法宝固定加成、元气 / 灵石 / 耐久成本、派生到达时刻和地图竞争的配置门。

## 1. 当前移动公式

玩家从已解锁的境界基础骰池中选择一档，再应用当前移动法门和可选移动法宝：

```text
实际移动格数
= 法门调整后的境界骰池结果
+ 法宝固定移动加成

M = 法门调整后的境界骰池理论最大点数
  + 法宝固定移动加成

单格耗时 = 标准移动单位时间 ÷ M
到达或停止时刻 = 实际经过格数 × 单格耗时
```

首轮不再配置独立速度系数。改变骰池理论上限会同时改变单格耗时；法宝固定加成也同时提高距离与速度。任一组合走满理论最大距离时，都在一个标准移动单位时间结束。

## 2. 必须配置的六境基础表

炼气、筑基、金丹、元婴、化神、大乘各配置：

- 基础骰池表达；
- 期望值、最小值、理论最大点数；
- 固定或选用元气成本；
- 地形通行标签或限制；
- 与低阶池的保留用途。

玩家可选择任何已解锁档，不强制使用最高档。高境界池必须以更高元气成本换取距离或稳定性，避免无代价支配低阶池。历史 `1D1 / 1D2 / 1D6 / 2D6` 仅是旧阶段示例，不属于当前数值。

## 3. 移动法门表

每个法门模板需要配置：

- 可作用的境界基础池与合法条件；
- 在 `25 / 50 / 75` 阈值下的骰池分布修改、理论上限变化或离散强化；
- 额外元气成本；
- 由掌握投入与使用消耗换取的收益；
- 是否改变地形权限或其它移动字段。

移动骰池、理论上限和派生耗时不读取通用掌握倍率；只读取法门阈值内容显式写出的修改。模板不得通过同一阈值把新增能力与强化混写。

## 4. 移动法宝表

移动法宝提供额外固定点数，计入实际格数和 `M`。每个模板需配置：

- 固定加成；
- 启用时机与叠加限制；
- 额外灵石成本与耐久成本；
- 炼化度对其效果的缩放；
- 是否同时提供通用逃遁加成。

启用法宝仍支付境界基础池和移动法门的元气成本。距离、速度、灵石和耐久必须联合验算，不能同时免费取得四项优势。

## 5. 共享时间轴与比较

提前抵达者持续占据目的地；骰点不足者按实际格数计算停止时刻；道中相遇比较同一格的占据区间。正式数值表必须统一：

- 标准移动单位时间；
- 分数单格耗时的保存精度；
- 到达时刻比较精度；
- 严格同刻判定与稳定随机介入时点；
- 特殊连接和关隘的附加耗时。

这些配置不得重新引入独立速度属性。

## 6. 竞争数值边界

无主节点首次争购固定使用灵石暗标，出价同价按更早抵达、严格同刻稳定随机处理。节点标价、建造预留和出价绝对值属于地产价格表。

其它事件若调用通用竞价，仍需配置支付资源、最低出价、加价粒度、败方支付与多人一次性结算；不能从无主节点暗标规则静默推导。

固定地点小洞天不使用竞价：同刻挑战者以战斗用时、再以稳定随机结果裁定。

## 7. 验算要求

1. 高境界与法门不能无代价同时取得最大距离、最快到达、最低元气和最高地形权限。
2. 低阶池在短途与节省元气时仍有合法价值。
3. 多路线与不同 `M` 能形成可预测但不绝对的相遇、避让和先到优势。
4. 先到者持续占位不会让关键地点永久被单一移动模板支配。
5. 法宝灵石与耐久成本能制衡其对距离和速度的双重提升。
6. 输入与演算时间需支持标准 `90—120` 分钟、期望 `24` 回合的局长。

## 8. 当前缺口

- 六境基础骰池、期望、上下限与元气成本；
- 移动法门分布模板、阈值强化与额外元气；
- 移动法宝固定加成、灵石、耐久与叠加限制；
- 标准移动单位时间、分数精度、特殊连接和地形表；
- 节点标价、建造成本与通用竞价数值。

# 数值设计｜移动、行动与竞争数值

适用范围：移动骰池、速度、元气成本、到达时间、竞价和地图竞争的数值配置门。

## 1. 已确认模型

移动距离与速度分离：

```text
移动骰池结果 → 可移动格数
速度系数 → 单位格移动时间
路径格数 × 单位格时间 → 到达时间
```

移动消耗元气。玩家从进入一格到离开该格的完整区间都占据该格；相遇由占用区间是否重叠判断。

## 3. 竞争数值

战斗和竞价是通用竞争工具。竞价仍缺：

- 使用货币或其它资源；
- 明标 / 暗标与同时提交方式；
- 最低出价和加价粒度；
- 平价处理；
- 败方是否支付；
- 三人以上竞价的一次性结算；
- 竞价与地区影响力的换算。

在经济循环确定前，不应先填写竞价数值。

## 4. 逃遁移动数值接口

MVP 通用逃遁距离为相邻 `1` 格。后续法宝、法门或其它效果可以修正距离，但必须继续遵守地图通行权限和硬阻挡。

逃遁成功率属于自动战斗数值文档，不在本文重复维护。

## 5. 验算要求

未来移动表至少需要验证：

1. 快速方式不会同时无代价获得最大距离、最高速度和最低元气成本；
2. 不同路径可以形成有意义的相遇与绕行；
3. 先到者持续占位不会使关键地点永久偏向单一移动方式；
4. 元气不足会限制移动，但不会让玩家失去当前位置的全部行动权；
5. 一轮移动与行动输入时间符合 `45—60` 分钟局长目标。

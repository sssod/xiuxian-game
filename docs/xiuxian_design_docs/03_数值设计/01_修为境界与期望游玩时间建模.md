# 数值设计｜修为境界与期望游玩时间建模

## 1. 设计定位

本文负责维护修为境界体系、标准修士背景年限、玩家现实体验目标、修为绝对值阈值、小境界修为绝对值上下界、阶段预算打开规则和 NPC 成长分层。

本文是小境界 `cp_lower_bound / cp_upper_bound` 的唯一维护入口。修炼公式与数值设计文档只消费本文的上下界，不另行维护小境界比例表或具体上下界表。

本文不展开每小时修炼公式、资源输入公式、状态压力曲线、突破轮内评分和 tick 明细；这些内容由《修炼公式与数值设计》（`02_修炼公式与数值设计.md`）维护。本文只记录能支撑境界成长、阶段预算和期望游玩时间的数值基准。

## 2. 当前结论

1. 标准修士年限是世界观背景墙、NPC 默认成长尺度、寿元压力参考和数值底表，不直接换算成玩家现实等待时间。
2. 玩家主线成长现实耗时按境界线性增长，不按标准修士年限指数增长。
3. 修炼调参以 `RealmSegmentBalance + normalized_segment_progress` 为核心，修为绝对值 `cultivation_points` 作为阈值、表现和日志映射。
4. 小境界进度读取本阶段 `cp_lower_bound / cp_upper_bound`，界面显示该小阶段自身 `0%-100%` 进度。
5. 玩家高倍率不来自无来源角色光环，而来自可追踪资源包、灵地、设施、宗门、功法、机会窗口和风险承受。
6. 阶段预算打开提供世界资源机会，不自动赠送修为。
7. 大境界突破由准备质量和 B1 轮内决策共同决定，不是修为达标后的概率按钮或自动升级。
8. 理论直线现实参考时长默认 32 小时，参考终点为“大乘圆满并突破进入渡劫期”；渡劫之后不按本文纯修为时间段推进；调试上限暂按 50 小时保留。
9. 理论直线外界世界日历目标为约 45-48 年，当前基线约 47.55 年并已接受，常规验收范围为 20-50 年；外界年极限调试上限暂按 100 年保留。
10. 玩家可见速度状态只保留 N1 / F1 / B1 / P0；F1 默认基准为 1.5 秒 = 1 外界日，并保留 1 / 1.5 / 2 秒调参档；不新增独立宏观流年阶段。

## 4. 基准、单位与输入参数

### 4.1 境界体系

MVP 优先平衡到化神；化神之后先保留表结构和扩展接口。

| 阶段编号 | 境界 | 小阶段建议 | MVP 状态 | 设计作用 |
| --- | --- | --- | --- | --- |
| 0 | 凡人 / 锻体 | 可选 | 可弱化 | 出身、教学、低阶 NPC |
| 1 | 炼气 | 1-9 层 | 必做 | 新手阶段，快速建立修炼反馈 |
| 2 | 筑基 | 初期 / 中期 / 后期 / 圆满 | 必做 | 第一次大境界质变 |
| 3 | 金丹 | 初期 / 中期 / 后期 / 圆满 | 必做 | 宗门骨干、资源经营成型 |
| 4 | 元婴 | 初期 / 中期 / 后期 / 圆满 | 必做或后期 MVP | 区域强者、宗门高层 |
| 5 | 化神 | 初期 / 中期 / 后期 / 圆满 | 第一阶段终局 | 世界层级跃迁前顶点 |
| 6 | 炼虚 | 初期 / 中期 / 后期 / 圆满 | 扩展 | 中后期资料片 / 灵界层 |
| 7 | 合体 | 初期 / 中期 / 后期 / 圆满 | 扩展 | 大世界强者 |
| 8 | 大乘 | 初期 / 中期 / 后期 / 圆满 | 扩展 | 飞升前顶点 |
| 9 | 渡劫 / 飞升准备 | 劫数阶段 | 终局 | 不建议设计为纯经验条 |

第一大境界使用 9 层，前期反馈更快，后期形成第一次瓶颈。第二大境界开始默认使用初期 / 中期 / 后期 / 圆满四段，但各段跨度允许逐境界单独调整。

### 4.2 时间单位

数值设计使用以下底层时间单位：

```text
1 游戏日 = 24 游戏小时
1 游戏年 = 360 游戏日
服务器最小结算单位 = 1 游戏小时
```

公开速度只影响现实等待，不改变数值单位。本文使用“外界小时 / 外界日 / 外界年”指共享世界日历时间，底层仍可由 `world_day / world_hour` 表达：

| 速度 | 现实换算 | 数值含义 |
| --- | --- | --- |
| N1 | 15 秒 = 1 外界小时 | 常规世界推进、主动决策、短行动、队列编辑 |
| F1 | 默认 1.5 秒 = 1 外界日；保留 1 / 1.5 / 2 秒调参档 | 长期低交互行动的批量压缩推进 |
| B1 | 60 秒 = 1 外界小时 | 正式交锋、突破挑战、关键慢速轮 |
| P0 | 外界时间不流动 | 公共决策、同步保护、主机暂停 |

按默认 F1 换算：

| 速度 | 1 游戏日 | 1 游戏年 |
| --- | --- | --- |
| N1 | 6 分钟 | 36 小时 |
| F1 | 1.5 秒 | 9 分钟 |
| B1 | 24 分钟 | 不用于长期修炼 |

当前裁决：

```text
N1 不是长期修炼的主承载速度。
F1 不是玩法目标，而是长期低交互状态下按外界日提交边界、F1 校验断点和 F1 中断断点批量结算的手段。
B1 只用于突破挑战、正式交锋和关键慢速轮。
玩家核心玩法是在 N1、事件、宗门、地图、市场、NPC 和风险选择中创造高价值闭关条件，再用 F1 快速消化。
```

时间层级不得混用：

| 时间层 | 口径 |
| --- | --- |
| 现实游玩时间 | 玩家现实中花费的时间，用于体验目标和 UI 预估 |
| N1 / B1 现场外界时间 | 玩家处理地图、事件、战斗、突破、交易时同步流逝的外界时间 |
| F1 外界流年时间 | 房间长期低交互时高速推进的共享外界世界日历 |
| 角色主观经历时间 / 修行时间 | 角色在洞天、时间阵法、闭关局部时间中实际经历的时间，其中一部分才属于修行成长时间 |

32 小时理论直线默认基线见《时间速度与局部时间域数值设计》（`10_时间速度与局部时间域数值设计.md`）。本文的分阶段现实体验目标已经按默认 32 小时全局基线重排；若调试基线放大到最高 50 小时，应按同一阶段比例重新换算，而不是恢复旧分阶段目标。

### 4.3 标准修士背景年限

标准修士年限用于世界背景、NPC 默认成长、寿元压力和数值底表，不直接决定玩家等待时间。

| 阶段 | 标准修士背景年限 | 用途 |
| --- | ---: | --- |
| 炼气 -> 筑基 | 8 年 | 新手阶段背景尺度 |
| 筑基 -> 金丹 | 30 年 | 普通宗门弟子与精英分层 |
| 金丹 -> 元婴 | 80 年 | 宗门骨干到高层的分水岭 |
| 元婴 -> 化神 | 180 年 | 老祖级别成长尺度 |
| 化神 -> 炼虚 | 360 年 | 世界层级跃迁尺度 |
| 炼虚 -> 合体 | 600 年 | 高阶世界长期尺度 |
| 合体 -> 大乘 | 900 年 | 顶级势力尺度 |
| 大乘 -> 渡劫 | 1200 年 | 终局背景尺度 |
| 渡劫 / 飞升 | 不建议纯年限 | 应以劫数、因果、世界事件和终局挑战为主 |

### 4.4 核心输入参数

| 参数或字段 | 含义 | 口径 |
| --- | --- | --- |
| `cultivation_points` | 角色当前累计修为绝对值 | 用于阈值、表现、日志、突破开启和高级详情 |
| `RealmSegment` | 从一个稳定修炼状态推进到下一个关键里程碑的最小成长段 | 可表示小境界、圆满资格、突破准备和突破后巩固 |
| `RealmSegmentBalance` | 境界段调参记录 | 保存目标小时、效率边界、上下界、进度需求和资源密度 |
| `normalized_segment_progress` | 当前境界段标准化进度 | 默认 `0.0` 到 `1.0+`，超过 `1.0` 可表示超额准备 |
| `cp_lower_bound / cp_upper_bound` | 当前小境界修为绝对值上下界 | 来自本文配置表，其他文档只消费 |
| `raw_cultivation_required` | 该境界段表现和日志所需原始修为差 | 默认由 `cp_upper_bound - cp_lower_bound` 派生 |
| `target_elapsed_hours_standard` | 标准修士推进该段的目标游戏小时 | 用于世界背景和 NPC 默认成长 |
| `expected_cultivation_hour_ratio` | 该段预期有效修炼小时占比 | 用于区分经营、闭关、事件和等待 |
| `min_efficiency_ratio / max_efficiency_ratio` | 该段效率上下限 | 约束资源包和高倍率叠加 |
| `WorldStageBudgetState` | 世界阶段预算状态 | 控制新境界资源机会何时打开 |

## 5. 公式或模型

### 5.1 小阶段显示进度

小境界阈值使用修为绝对值上下界，而不是在系统设计文档中维护比例表。每个小阶段都有独立的修为绝对值下界 `cp_lower_bound` 与上界 `cp_upper_bound`。

```text
minor_stage_display_progress =
  clamp(
    (cultivation_points - cp_lower_bound)
    / (cp_upper_bound - cp_lower_bound),
    0,
    1
  )
```

配置原则：

1. 玩家界面显示该小阶段自身进度 `0%-100%`。
2. 不同小阶段的修为绝对值跨度可以不同。
3. 第一大境界默认分 9 层；第二大境界开始默认分初期 / 中期 / 后期 / 圆满四段。
4. 默认种子配置不是硬编码比例；后续平衡可直接改每一行上下界。

### 5.2 境界段推进

`RealmSegment` 可以表示：

```text
炼气一层 -> 炼气二层
炼气九层 -> 炼气圆满
炼气圆满 -> 筑基开启资格
筑基准备期 -> 筑基成功并完成初步巩固
```

`RealmSegmentBalance` 必须能读取或保存：

```text
segment_id
realm_from
minor_stage_from
realm_to
minor_stage_to
segment_type
target_elapsed_hours_standard
expected_cultivation_hour_ratio
required_normalized_progress
cp_lower_bound
cp_upper_bound
raw_cultivation_required
min_efficiency_ratio
max_efficiency_ratio
```

字段口径：

1. `cp_lower_bound / cp_upper_bound` 来自本文的小境界修为绝对值上下界。
2. `raw_cultivation_required` 默认可由 `cp_upper_bound - cp_lower_bound` 派生，用于表现和日志映射。
3. `normalized_segment_progress >= 1.0` 表示达到该境界段目标，可进入下一阶段或开启突破资格校验。
4. `normalized_segment_progress > 1.0` 是超额准备，可转化为突破初始优势、品质修正或稳定性修正。

不得用一条全局经验曲线覆盖全部境界。不同境界、不同小阶段可以有不同 CP 跨度、目标小时、有效修炼小时占比、资源密度和效率边界。

### 5.3 玩家有效修炼倍率

玩家现实体验时间由主动经营时间和 F1 闭关消化时间共同构成。按 F1 换算，1 游戏年约等于 12 分钟现实时间；若玩家每阶段只进行有限 F1 闭关，则实际游戏年远低于标准背景年限。

```text
required_effective_multiplier =
  standard_cultivation_years
  / player_actual_game_years_consumed
```

这些倍率不是角色坐着吐纳时的无来源加成，而是资源、灵地、宗门支持、功法、机会窗口和风险承受的综合结果。

### 5.4 资源包循环

玩家高倍率应来自可追踪的阶段修炼资源包。资源包不直接给等级，而是提供：

```text
compatible_hours
normalized_progress_bonus
risk_modifier
meridian_pressure_delta
method_mastery_delta
breakthrough_quality_modifier
```

推荐主循环：

```text
发现资源线索
-> 争取节点 / 宗门 / 市场 / 事件
-> 获得阶段资源包
-> 绑定到修炼或突破准备行动
-> F1 短闭关消化
-> 小境界 / 瓶颈反馈
-> 重复 2-4 次
-> 突破准备
-> B1 突破挑战
```

### 5.5 阶段预算机制

阶段预算用于解释沙盒世界为何随玩家境界推进而开放新资源。

```text
WorldStageBudgetState {
  active_budget_realm: Realm
  unlocked_realm_history: Array
  unlocked_by_character_refs: Array
  current_macro_period_id: String
  budget_pools: Dictionary<Realm, RealmBudgetPool>
  next_realm_leakage_rate: number
  catchup_policy: Dictionary
  high_realm_npc_progress_policy: Dictionary
}
```

每个境界对应一个预算池：

```text
RealmBudgetPool {
  realm: Realm
  total_budget_points_per_macro_period: number
  production_budget_refs: Array
  node_resource_budget: number
  sect_inventory_budget: number
  market_trade_budget: number
  opportunity_window_budget: number
  npc_personal_budget: number
  method_carrier_budget: number
  breakthrough_material_budget: number
  active: bool
}
```

预算激活规则：

```text
on_major_breakthrough_success(character, new_realm):
  if character.is_player_controlled
     and new_realm > WorldStageBudgetState.active_budget_realm:
      WorldStageBudgetState.active_budget_realm = new_realm
      activate_budget_pool(new_realm)
      schedule_budget_distribution(next_macro_period)
```

裁决：

1. 阶段预算是世界产出预算的境界调度层，不是角色奖励池。
2. 预算激活是系统事实，不等于公开传闻。
3. 是否公开某玩家突破，由可见性、宗门传闻、玩家选择和事件结果决定。
4. 预算打开提供资源机会，不自动发放修为。
5. 预算投放必须进入节点资源槽、宗门库存、市场、机会窗口、NPC 个人资产、事件锁定奖励或其他可审计资产链路。

### 5.6 先锋资源与预算打开

为了让第一个突破到新境界的玩家合理成立，需要区分先锋资源和阶段预算。

```text
next_realm_leakage_rate = 5%-10%
```

先锋资源来源：

```text
高风险节点；
一次性秘境；
宗门特殊申请；
师承任务；
遗迹；
黑市；
强敌掉落；
后手遗产；
小概率事件。
```

先锋资源仍必须来自已存在资产、事件锁定奖励、后手遗产、专属资源池或明确预算泄漏，不允许无限刷新，也不允许绕过来源日志和可见性记录。先锋资源不足以让整个世界大量成长，但足以让主动玩家集中资源完成突破。

### 5.7 NPC 与其他玩家成长分层

NPC 成长由其境界是否高于当前阶段预算决定。

高于当前预算境界的 NPC：

```text
npc.realm > WorldStageBudgetState.active_budget_realm
```

规则：

```text
只走标准修士背景速度；
无法稳定获得本境界所需资源；
每个宏观周期修为进度变化很小；
默认不发生小境界晋升；
默认不发生大境界突破；
除非剧情、后手、宗门重大事件或专属资源池触发。
```

建议：

```text
visible_progress_cap_per_macro_period = 0.1%-0.5%
breakthrough_allowed = false by default
minor_stage_advance_allowed = scripted_only
```

不高于当前预算境界的 NPC：

```text
npc.realm <= WorldStageBudgetState.active_budget_realm
```

可以吃到阶段预算，但仍低于玩家主动路径倍率。其他玩家仍需要决策、行动、争夺和突破；预算打开不会自动赠送修为。

### 5.8 突破承接

修为绝对值或标准化进度达标只是开启条件。真正突破由准备质量、B1 轮内策略、轮内资源消耗、状态变化和模板结局共同决定。

大境界突破结构：

```text
准备期
-> 开启突破短指令
-> 突破挑战 B1
-> 个人结果报告
-> 后续选择
```

开启条件建议至少读取：

```text
normalized_segment_progress >= 1.0
method_mastery_norm >= required_method_mastery_norm
foundation_quality >= required_foundation_min
meridian_pressure <= allowed_meridian_pressure_max
injury <= allowed_injury_max
mental_risk <= allowed_mental_risk_max
location_allows_breakthrough == true
method_template_available == true
required_resource_available == true
```

突破成功后应立即形成境界质变，但提升来源不是 CP 瞬间暴涨，而是境界倍率、属性质变、修为稳定度和术法 / 行动解锁共同构成。

推荐战斗表现公式方向：

```text
combat_power =
  base_stat_score
  * realm_power_multiplier[realm]
  * minor_stage_multiplier
  * foundation_quality_factor
  * method_mastery_factor
  * current_cultivation_fullness_factor
  * state_factor
  + equipment_spell_bonus
```

## 6. 配置表或根表

### 6.1 修为绝对值 CP

修为绝对值表示角色当前累计修为规模，字段名为 `cultivation_points`。表格字段和公式字段可使用 `cp_` 前缀表示 cultivation points，但正文优先写“修为绝对值”，避免直接使用缩写造成歧义。

修为绝对值用于：

1. 小境界 / 大境界阈值判断。

5. 调试面板和高级详情展示。

### 6.5 玩家现实体验目标

玩家主线成长体验不再按修为跨度机械缩放。阶段现实目标由三类因素共同决定：

1. 玩家信息吸收和决策效率：炼气期之前玩家仍在学习修炼、资源、宗门、地图和风险表达，N1 占比高，现实耗时不能因修为跨度低而压得过短。
2. 独立时间域解锁程度：筑基到金丹开始引入独立时间域，主要修为来源逐步转向时间域内修炼。
3. 多人同步进入 F1 的可行性：金丹以后通过高速率、集中开放的时间域窗口促使玩家集体闭关，提高外部世界 F1 占比。

默认 32 小时理论直线基线下，阶段现实目标为：

| 阶段 | 标准背景年限 | 现实目标 | N1 现场 / 学习 / 经营 | F1 外界 / 时间域闭关 | B1 突破 / 交锋 | 设计定位 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 炼气 -> 筑基 | 8 年 | 3.00h | 2.45h | 0.30h | 0.25h | 外部世界修炼为主，最快也只有 F1；前期信息量高，现实时间以 N1 为主 |
| 筑基 -> 金丹 | 30 年 | 3.20h | 2.30h | 0.55h | 0.35h | 引入独立时间域，主要修为来源开始转向时间域内；外部仍 N1 为主、F1 为辅 |
| 金丹 -> 元婴 | 80 年 | 3.60h | 2.38h | 0.80h | 0.42h | 时间域开始集中开放，促使多人闭关并抬升 F1 占比 |
| 元婴 -> 化神 | 180 年 | 4.00h | 2.63h | 0.90h | 0.47h | 中期核心循环稳定，时间域、资源准备和突破反馈共同承担节奏 |
| 化神 -> 炼虚 | 360 年 | 4.30h | 2.78h | 1.00h | 0.52h | 高阶窗口和资源争夺增加，F1 占比继续提高 |
| 炼虚 -> 合体 | 600 年 | 4.50h | 2.83h | 1.10h | 0.57h | 集中闭关更强，外部事件、宗门和世界窗口复杂度上升 |
| 合体 -> 大乘 | 900 年 | 4.60h | 2.84h | 1.15h | 0.61h | 顶级资源、道统竞争和突破准备为主 |
| 大乘 -> 渡劫 | 1200 年 | 4.80h | 2.91h | 1.24h | 0.65h | 终局前准备，F1 占比最高但不能替代关键决策 |
| 合计 | 3358 年 | 32.00h | 21.12h | 7.04h | 3.84h | 对齐 32 小时、约 47.55 外界年默认基线 |

50 小时 Debug 基线按同一阶段比例放大：

```text
debug_stage_real_hours = default_stage_real_hours * debug_real_time_baseline_hours / 32
debug_stage_N1_hours = default_stage_N1_hours * debug_real_time_baseline_hours / 32
debug_stage_F1_hours = default_stage_F1_hours * debug_real_time_baseline_hours / 32
debug_stage_B1_hours = default_stage_B1_hours * debug_real_time_baseline_hours / 32
```

MVP 优先目标为炼气到化神，默认合计约 13.8 小时，其中 N1 约 9.76 小时，F1 约 2.55 小时，B1 约 1.49 小时。MVP 仍应保留后续阶段表结构，避免化神以后重排时破坏全局 32 小时基线。

### 6.7 资源包类型

| 资源包 | 作用 |
| --- | --- |
| 灵地时段包 | 提供高 aura 兼容小时 |
| 丹药药力包 | 提供修为灵气输入，但增加经脉压力或药性残余风险 |
| 灵材辅助包 | 降低副作用或提高突破准备质量 |
| 宗门护持包 | 降低风险，提高闭关稳定性 |
| 功法参悟包 | 提高 `MethodState` 掌握度，间接提升修炼效率 |
| 突破专用包 | 在 B1 突破轮内可消耗 |
| 秘境机缘包 | 高收益、高风险，可能附带状态标签 |

### 6.8 阶段预算投放

推荐每个阶段预算按以下方向投放。表中比例是境界调度建议；实际投放必须落到资源池、资源槽、库存、市场、事件或资产容器。

| 预算出口 | 建议占比 | 作用 |
| --- | --- | --- |
| 节点资源槽 | 35%-45% | 灵草、矿材、灵脉波动、妖兽材料、秘境产物 |
| 宗门库存 / 任务 | 20%-25% | 宗门资源申请、护法、丹药、功法载体 |
| 市场 / 交易 | 10%-15% | 坊市、商队、黑市、拍卖 |
| 机会窗口 / 事件 | 15%-20% | 秘境窗口、遗迹、机缘事件、争夺事件 |
| NPC 个人库存 | 5%-10% | NPC 可交易、可赠予、可争夺、可掉落资源 |

预算不应瞬间刷满，而应在 1-3 个宏观周期内逐渐显现：

```text
突破当刻：个人结果、宗门反应、少量相关机会。
下一个宏观周期：节点资源槽开始出现新阶段资源。
第二个宏观周期：宗门库存、市场、NPC 资源开始扩散。
第三个宏观周期：该阶段资源成为稳定世界预算。
```

### 6.9 NPC 与玩家分层倍率

不高于当前预算境界的 NPC 可吃到阶段预算，但仍低于玩家主动路径倍率。

| NPC 类型 | 预算打开后的有效修炼倍率 |
| --- | --- |
| 普通 NPC | x1.2-x2 |
| 宗门重点培养 NPC | x2-x4 |
| 天才 / 亲传 / 关键竞争者 | x4-x8 |
| 剧情级竞争者 | x8-x12，但需要显式记录来源 |

其他玩家：

```text
低参与玩家：x2-x4
正常参与玩家：x5-x12
资源集中玩家：接近领先玩家倍率
显式托管玩家：倍率明显降低，错过高价值机会
```

### 6.10 突破后质变来源

| 来源 | 占比感 | 具体变化 |
| --- | --- | --- |
| 境界倍率 | 40%-50% | `realm_power_multiplier` 进入新境界 |
| 属性质变 | 20%-30% | 体魄、神识、灵力上限、经脉承载上限提升 |

## 8. 调参验收口径

1. 玩家看到的每个小阶段都能从自身 `0%-100%` 推进。
2. 小阶段之间的修为绝对值跨度、有效修炼小时和资源需求可以不同。
3. 炼气前期反馈明显快于后段，炼气 8-9 层能形成第一次瓶颈感。
4. 筑基以上默认四段结构可用，但不强迫所有境界复用同一比例。
5. 主动经营时间和 F1 闭关消化时间合计能落入本文的玩家现实目标，并能与 32 小时理论直线基线解释一致。
6. 高倍率资源必须受到境界适配、状态压力和段级效率上限约束。
7. 阶段预算打开后，世界机会增加，但角色不会无来源获得修为。
8. 高于当前阶段预算的 NPC 不会无来源小境界晋升或大境界突破。
9. 大境界突破不能只靠修为绝对值达标自动完成。
10. UI 摘要能解释“还差多少、为什么慢、如何变快、风险在哪里”。

## 9. MVP 范围

MVP 应实现：

1. 炼气到化神的境界结构、小阶段显示和修为绝对值上下界。
2. `cultivation_points`、`RealmSegmentBalance`、`normalized_segment_progress`、`cp_lower_bound / cp_upper_bound` 的基础结算口径。
3. 炼气到化神的玩家现实体验目标和有效修炼倍率校准。
4. 资源包驱动的高倍率来源记录。
5. 阶段预算打开机制，以及预算进入节点资源槽、宗门库存、市场、机会窗口、NPC 个人资产或事件锁定奖励的审计边界。
6. 高于当前阶段预算 NPC 的成长压制规则。
7. 大境界突破只把修为达标作为开启条件，由突破玩法继续处理。

MVP 不实现：

1. 化神以后完整调参曲线和所有境界资源包模板。
2. 渡劫 / 飞升阶段的纯 CP 经验条推进。
3. 每个宏观周期的具体预算点数和所有投放公式。

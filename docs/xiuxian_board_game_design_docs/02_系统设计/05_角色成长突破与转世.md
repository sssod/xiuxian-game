# 系统设计｜角色成长、突破与转世

适用范围：角色属性、持久状态、自动修炼、境界与突破、小洞天、重伤、死亡和转世。境界绝对 CP、灵气尺度和回合锚点由数值专题维护。

## 1. 当前世属性与持久状态

角色使用：

- 基础属性：体魄、精力；
- 修炼资质：根骨、悟性、灵根等级与标签；
- 持久状态：生机、元气、神念；
- 战斗派生：护盾；
- 寿元：当前年龄、寿元上限；
- 后天永久与临时修正。

真灵、执念、旧法力纯度和完整轮回账本不进入本方案。体魄、精力、根骨、悟性、灵根等级与标签都可以被明确的事件或成长效果改变；初始宗门与灵根不构成永久构筑锁定。

三条持久状态均包含：

```text
当前值
最大值
保留值
可支配上限 = 最大值 - 保留值
```

当前值不得超过可支配上限。生机上限主要读取体魄，元气上限主要读取精力，神念使用独立基础值与修正。最大值变化时的百分比继承和取整仍待 `G-23` 配置。

生机归零触发死亡；否则神念归零触发重伤。元气归零不直接战败，但角色不能选择需要支付元气的地图移动，仍可在当前位置执行其它合法行为。三条状态没有脱离功法的统一自然恢复，恢复必须来自道功、丹药、地点或其它明确效果。

## 2. 境界结构与进度

首个飞升主题采用六个机械大境界：

```text
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘
```

炼虚与合体不进入该主题，也不降格为小境界。炼气至化神均使用初期、中期、后期、圆满四段；大乘只承担终局资格，不设置本局内小境界或继续积累无用途进度。

每个普通大境界的固定总 CP 在开局时由内容表确定，不随实际回合、全图灵气、历史最高境界或玩家个人状态动态改变。四段统一占该境总 CP 的：

| 小境界 | 本段占比 | 累计阈值 |
| --- | ---: | ---: |
| 初期 | `15%` | `15%` |
| 中期 | `20%` | `35%` |
| 后期 | `25%` | `60%` |
| 圆满 | `40%` | `100%` |

达到前三个阈值时自动晋级，不占主要行动；达到 `100%` 时停在大境界瓶颈。界面显示当前小境界自身的 `0—100%`，因此标准开局是“炼气初期 `0%`”；累计跨越多个阈值时依次晋级并汇总展示。

系统区分内置的标准 CP 记录与当前有效修为。主修切换不改写标准 CP，常规系统读取当前有效修为；有效修为的精确计算仍是显式待裁决项，不得恢复旧的标准 CP 折算公式。详见《[道功、法门与物品构筑](06_道功法门与物品构筑.md)》。

## 3. 自动修炼

普通修炼不占主要行动。每个角色内部时间单位先结算自动修炼，再结算功法自动研习：

```text
节点实际灵气
= 节点基础灵气 + 当前回合全图灵气固定增量

本内部时间单位自动修炼 CP
= 节点实际灵气 × 当前主修道功修为转化率
```

开始结算时锁定所在地实际灵气、当前主修道功、该道功掌握度和当前有效修为转化率。本单位后续研习带来的掌握提升只能从下一个内部时间单位开始影响修炼；小洞天的十个单位逐单位重复该顺序。

首轮暂不设置道功对环境灵气的吸收上限。丹药等额外修炼资源作为独立加算输入，不反向放大节点灵气。全图灵气的整数 `A` 尺度和回合加法见《[局长与成长节奏](../03_数值设计/01_局长与成长节奏.md)》。

以下情况不取得本单位修为：

- 重伤；
- 角色在本外界回合死亡；
- 已处于未完成的大境界瓶颈。

瓶颈后的修为不会预存到下一大境界。突破失败或逃遁后，角色仍停留在原瓶颈，本回合末新增 CP 作废；成功突破者则按第 `5` 章从新境界 `0 CP` 开始取得当轮末第一笔修为。

## 4. 突破行动的合法性

大境界突破是角色自身的主要行动，不属于建筑或地产提供的功能。角色达到当前大境界瓶颈并持有对应破境丹后，可以在任意允许最终停留的合法地图节点执行；首轮不设置专用突破建筑、固定渡劫地点或由主导权控制的入口。

玩家在规划阶段锁定突破行动并选定一枚合法破境丹，可以照常规划移动。完成移动与抵达事件后，只有角色仍存活、仍在瓶颈且当前节点允许停留时，才能确认并消耗丹药。移动途中、尚未结束的事件、其它战斗或不能停留的格位不能开始突破。

在无主或其它宗门主导节点突破仍结算普通停留费，但突破本身不收功能费，也不产生渡劫收入。自有节点免停留费。节点主导者、普通宗门关系和地点灵气不能禁止、加强或削弱已合法抵达角色的突破；关隘只能在路线层阻止到达。

每次历史上尚未完成的突破只需要一个核心突破物槽，固定为对应破境丹，不存在第二类必需资源，也不能用其它物品替代。标准经济路线应允许玩家在此前约四个自动修炼回合内，以最多一次主要行动取得该丹药或完成下单；到瓶颈后不再增加“突破准备”行动。

## 5. 五次突破

首轮取消一切独立破境概率。道功不配置基础破境成功率，破境丹也不提供成功率加成。

### 5.1 炼气突破筑基

玩家消耗一枚固定 `Q2 中品` 筑基丹后确定晋升筑基；没有前置概率，也没有渡劫 PVE。筑基丹仍是必需核心物品，不可省略或替代，其固定蓝框品级不提供虚构的战斗增益。

### 5.2 后四次强制渡劫

筑基突破金丹、金丹突破元婴、元婴突破化神、化神突破大乘时，玩家消耗对应破境丹后直接进入绑定目标境界的固定难度渡劫 PVE。四场敌人各有固定战力预算：

- 不随外界回合、失败次数、玩家战力、世界物品成熟、建筑等级或地产规模升降；
- 每次挑战使用独立战斗，不允许其他玩家加入、协助、攻击或用节点主导权修改结算；
- 提交前公开敌人摘要、固定难度、失败后果、逃遁规则和本枚丹药提供的护劫护盾；预览不消耗资源；
- 成功只奖励完成境界晋升，不另设普通掉落；失败、逃遁或中止均无战利品。

后四类破境丹的 `Q1—Q5` 只映射为本次渡劫开始时的一次护劫护盾：

| 品级 | 护劫护盾调参锚点 |
| --- | ---: |
| 下品 | 最大生命 `10%` |
| 中品 | 最大生命 `20%` |
| 上品 | 最大生命 `35%` |
| 极品 | 最大生命 `55%` |
| 绝品 | 最大生命 `80%` |

护盾数值在开战时读取角色当时最大生命计算，按通用护盾吸收规则结算，只存在于当次渡劫。胜利、失败、逃遁或中止后立即清除，不带回地图或下一场战斗，不降低敌人档位，也不保证胜利。与其它护盾的叠加顺序、通用上限和五档最终数值仍待战斗数值表裁决。

渡劫允许玩家在通用战斗规则的合法时点主动逃遁。逃遁立即结束战斗并判定本次突破失败；主要行动、破境丹、法宝耐久、非破境丹药和其它已消耗资源均不返还。角色保留战斗结束时实际生命、元气、伤势、冷却和其它跨战斗状态，不额外判死，也不自动恢复。若继续战斗至生命归零，则按通用死亡与转世规则处理。

失败、逃遁或中止均不保留渡劫资格。本次丹药失效，下一次突破行动必须重新提交一枚合法破境丹，并只读取新丹药品级；不设固定冷却、免丹重试、失败保底或敌人动态削弱。状态与资源允许时可在下一回合重试。

## 6. 突破完成时序

筑基确定突破或渡劫获胜后：

1. 角色立即进入目标大境界，并立即更新当前境界与本局历史最高境界；
2. 新境界基础属性、战斗规则、资格与其它派生效果立即生效，但不自动完全恢复状态、清除伤势或刷新冷却；
3. 本回合移动已经完成，新解锁的境界移动骰池与只能在规划 / 准备阶段调整的构筑从下一合法时点使用；
4. 本回合末自动修炼读取新境界，从该境 `0 CP` 开始结算第一笔修为；该笔收益计入本境四回合参考节奏；
5. 历史最高境界可立即用于日志、公开进度与资格判断，但由此触发的低阶物品成熟只从下一外界回合生效，不追溯本轮物品。

一场未致死渡劫失败通常造成 `1—2` 个外界回合延迟：本轮主要行动、丹药和瓶颈处自动修炼机会已损失；若需要恢复或补资源可延长至两回合。死亡转世另按第 `9` 章计算。

## 7. 小洞天

每次合法取得小洞天奖励，只在取得当回合末产生一次十个角色内部时间单位的结算，随后本次入口关闭。首轮不允许连续停留，不占用下一回合主要行动，也不存在“继续停留 / 主动退出”分支。

十个单位逐单位结算自动修炼、功法研习、恢复、丹药持续、法宝炼化和寿元。普通角色修为封顶于当前未完成的大境界瓶颈，洞天内不能主动执行突破，剩余 CP 不预存。按四回合大境界基准，一次洞天最多约节省三个普通成长回合。

固定地点与随机事件入口分开投放；玩家没有累计进入次数上限或重复冷却，可以在以后再次满足条件时重入同一或不同洞府。固定地点开放、挑战与竞争详见《[棋盘地图与移动](02_棋盘地图与移动.md)》；功法研习的十单位行为详见《[道功、法门与物品构筑](06_道功法门与物品构筑.md)》。

## 8. 重伤

神念恢复至 `1` 或以上时立即解除重伤。重伤只禁止：

- 切换主修道功；
- 自动修炼；
- 大境界突破；
- 飞升。

未列入黑名单的移动、即时行动和主要行动不得仅因重伤被隐式禁用。战斗或地点模板仍可依据其它明确条件限制行为。

## 9. 死亡、转世与追赶

转世是严重失败惩罚，不是主动优化循环，也不淘汰玩家。

| 类型 | 死亡与转世结果 |
| --- | --- |
| 已学习道功、法门、掌握度和已解锁内容 | 跨世保留 |
| 本局历史最高已达境界与已完成突破 | 跨世保留 |
| 宗门身份与宗门贡献点 | 保留，贡献点不掉落 |
| 节点主导权、建筑、建设中状态与已锁定改建 | 作为宗门地产保留并继续结算 |
| 当前境界、当前 CP、当前世属性与三条状态 | 清空并按转世出生配置重建 |
| 灵石和其它随身可转移资产 | 清空并按死亡掉落规则处理 |
| 尚未通过即时行动学习的功法道具 | 仍是普通随身物品，可掉落或回收 |

有合法玩家战胜方时，每件独立物品或每个堆叠单位（包括每单位灵石）独立以 `10%` 成为战利品，其余系统回收；无合法玩家胜者时全部回收。已学知识不是物品，不参与掉落。

死亡当回合不取得自动修炼。下一外界回合开始时，角色在本局开局分配的原始出生座位完成转世并恢复正常操作；不额外空过等待回合，也不能选择自有地产或高价值区域重生。

死亡后才产生或本回合末才到账的地产持续收益与收费收入不追溯参与本次掉落，暂存至下一回合转世完成后交付。交付后若角色灵石低于“炼气期基础经营节点基准标价的 `0.5` 倍”，系统只补足到该下限；达到或超过则不补。转世不重新赠送破境丹、原料、法宝或宗门特色开局资源。

转世角色重修至历史上已完成的境界瓶颈时，自动进入下一境界：不占主要行动、不消耗丹药、不重复渡劫。普通修炼与小洞天均适用；小洞天可以连续跨越多个已完成边界，并继续推进历史最高境界内进度，但最多停在第一个历史未完成的瓶颈。历史记录只免除重复突破，角色尚未重新达到相应境界前，不能使用其移动骰池、属性或其它能力。

后期全图灵气增长与固定低境界 CP 形成基础追赶。调参参考为：无小洞天时约 `2—3` 个后续外界回合重新进入历史最高大境界；取得一次小洞天时争取在该十单位结算内重新进入。重新进入只到该境起点，不恢复死亡前该境内 CP。落后者专属追赶、节点易主事件和退出归属仍待后续裁决。

## 10. 当前缺口

- 各大境界绝对 CP、`1A` 的绝对 CP、道功转化率与有效修为精确公式；
- 属性、恢复、寿元和 `G-23` 上限变化取整表；
- 四场渡劫敌人构筑、护劫护盾叠加顺序与最终数值；
- 落后者判定、专属追赶、地产易主事件和玩家退出时的宗门资产处理。

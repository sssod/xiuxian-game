# INDEX｜设计文档重整包总索引

## 1. 当前定位

`docs/inbox/xiuxian_design_reorganized_md` 是当前设计文档修订基准。包内文档优先于包外参考材料，但仍需继续人工审核与修订。

包外材料仅作为参考，包括 `docs/inbox` 中本包之外的材料，以及 `docs` 其他目录下的索引、正式文档和历史文档。若采用包外信息，应改写并沉淀到本包内部。

## 2. 修订重点

- 细化仍然粗略或只列约束的主题。
- 去除重复、陈旧、低价值或互相冲突的表述。
- 清理包内引用，避免依赖包外文档才能解释。
- 将实现影响记录为约束、风险、待决问题或验收条件。
- 无法机械判断的设计裁剪、取舍和冲突交由用户裁决。

1. 《自适应流速可暂停日历制 v2：阶段性时间规则》
2. 《指令预输入机制 v1：阶段性规则文档》

二者之间若出现表述张力，按以下原则消解：

```text
时间 / 速度 / 同步 / gap / B1 / P0 规则 → 以自适应流速日历制为准。
普通指令队列 / 预输入合法性 / 兜底 / 显式托管 → 以指令预输入机制为准。
突破“预设”一词 → 不解释为未来条件脚本，只解释为：
  A. 当前已经合法后放入普通队列的开启突破指令；或
  B. 突破挑战 B1 轮内的默认策略预设。
```

## 4. 本次没有阻塞性待确认项

本次修订中存在若干旧新口径冲突，但均可通过“新规则优先 + 系统专门性优先”直接消解，无需先向制作人追加确认。

唯一需要特别标注的解释性处理是：

```text
《自适应流速可暂停日历制 v2》中“开启突破通常允许玩家提前预设”
不解释为“未满足条件时可以写入未来自动突破脚本”。
它只允许：
1. 当前已满足条件后，将开启突破作为普通队列指令入队；或
2. 配置突破挑战中的 B1 轮内默认策略。
```

# 主题设计｜主题棋盘通用规范

适用范围：所有故事主题棋盘与通用修仙棋盘框架之间的职责分工、配置接口和覆盖边界。

## 1. 设计定位

本游戏不是只有一张固定棋盘，而是一套可以承载多个故事主题的多人修仙棋盘框架。通用框架维持一致的回合、成长、移动、竞争和自动战斗规则；主题棋盘负责地图、内容与目标。

主题可以改变玩家追求的故事和地图机会，但不能静默改写通用核心。确需例外时，必须在主题文档中显式声明覆盖的通用条目、覆盖原因和玩家提示。

## 2. 通用框架职责

通用框架负责：

- 多人房间的基础人数与回合推进；
- 回合开始、隐藏规划、同步移动、行动结算和回合末结算；
- 六边格地图、路径、移动时间和相遇；
- 即时行动、主要行动、事件、战斗与竞价；
- 修为、境界、突破、寿元、死亡与转世；
- 道功、法门、招式、法宝、丹药等概念职责；
- 主题胜利条件的触发与回合末判定接口。

## 3. 主题棋盘职责

每个主题必须配置：

1. 地图拓扑、地点类别、特殊连接与出生范围；
2. 剧情结构、地点事件、途中事件、固定事件和随机事件；
3. 可投放的道功、法门、招式、法宝、丹药、资源与敌人；
4. 主题属性表、境界节奏、移动与战斗数值常数；
5. 胜利目标、终局地点、终局事件和共同胜利规则；
6. 主题特有资源、地区规则和通用规则覆盖项；
7. 初始状态配置包。

## 4. 初始状态配置包

同一主题的 MVP 默认让所有玩家读取同一份初始状态配置包，不制造随机先天强弱差异。配置至少包含：

| 配置项 | 作用 |
| --- | --- |
| 起始境界与修为 | 决定本局成长起点 |
| 初始道功、法门与掌握度 | 决定初始修炼和构筑能力 |
| 基础属性与三条状态 | 决定初始角色数值 |
| 基础物资与货币 | 决定第一轮可用资源 |
| 初始法宝 / 丹药 | 决定初始构筑与准备能力 |
| 出生地点范围 | 决定地图起点分配 |

具体值归主题数值配置，不在通用规范中固定。

## 5. 主题覆盖规则

主题覆盖必须满足：

1. 明确指出被覆盖的通用规则；
2. 不用内容模板暗中改写所有玩家都应知道的基础行为；
3. 在开局配置或事件开始前向玩家展示；
4. 不破坏多人同步结算、资源守恒或胜利判定的可解释性；
5. 不把旧正式包或包外草案作为运行时解释依赖。

## 6. MVP 缺口

通用规范已稳定，但首个主题仍缺实际地图、地点、事件、敌人、资源、初始状态和完整数值表。上述内容是下一阶段 P0 阶段门，不代表已经获得裁决。

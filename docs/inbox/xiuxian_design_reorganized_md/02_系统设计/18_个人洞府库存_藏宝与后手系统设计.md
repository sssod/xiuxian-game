# 个人洞府库存、藏宝与后手系统设计

## 1. 当前结论

跨世外在资产分为普通遗产和正式后手。

## 2. 普通遗产

普通遗产像世界中的公共宝箱，可能被发现、搬空、污染、转移、破坏。它可以为玩家带来线索和收益，但不能保证跨世可控。

## 3. 正式后手

正式后手是经正式行为封存、布置、记录并占用真灵后手容量的长期资产。必须满足：

- 可追踪。
- 有日志。
- 失效有原因。
- 有追查路径。

## 4. 后手状态

```text
safe
unstable
exposed
contested
damaged
polluted
looted
destroyed_with_trace
```

looted / destroyed_with_trace 必须记录原因和追查入口。

## 5. 回收流程

```text
获得线索
→ 前往节点
→ 搜寻 / 破解 / 开启持续行动
→ S11 读取隐藏层和条件
→ 可能触发 S10 / 战斗
→ 成功转移资产 / 权限 / 信息
→ 更新账本与节点状态
```

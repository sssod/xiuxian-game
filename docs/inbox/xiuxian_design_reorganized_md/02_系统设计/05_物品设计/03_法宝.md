# 物品设计｜法宝

## 1. 当前结论

法宝是高价值可用资产，可以作为战斗、事件、防护、后手、突破支持和资源循环的一部分。

## 2. 战斗定位

战斗系统不采用装备栏 / 换装备 / 换法宝概念；随身携带的法宝、道具和已掌握术法神通都可以按条件生成可用指令。

法宝可以：

- 提供主动战斗指令。
- 被动触发效果。
- 替角色承受后果。
- 抵抗状态或被针对性破坏。
- 受损、失灵、破碎。

## 3. 经济定位

法宝属于独立实例物品的典型候选，因为其状态、耐久、来源、绑定、灵性、充能等字段会影响战斗、突破、交易、后手和消耗结果。

## 4. 数据字段建议

```yaml
ArtifactInstance:
  item_instance_id: string
  template_id: string
  tier: string
  quality: string
  owner_container_ref: string
  bind_state: string
  durability_state: string
  charge_state: number | null
  spirit_state: string | null
  combat_ready: bool
  active_command_refs: list
  passive_effect_refs: list
  ledger_refs: list
```

## 5. 缺口

- 法宝类型表、品质表、主动/被动效果表。
- 修复、拆解、回收、充能、灵性恢复公式。
- 绑定法宝与真灵后手之间的规则。

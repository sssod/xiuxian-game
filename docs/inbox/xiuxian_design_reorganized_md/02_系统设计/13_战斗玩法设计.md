# 战斗玩法设计

## 1. 定位

战斗 / 斗法不是独立复杂战棋、实时操作或高频刷怪系统，而是高风险事件链中的轻量结算框架。

它服务于：移动遭遇、节点危机、秘境遭遇、宗门任务、突破外扰、护法失败后的直接冲突、资源争夺、剧情切磋或死战。

## 2. 与 S3 的关系

```text
S3 结算时间轴推进
→ 某 tick / 节点 / 路途段触发战斗事件
→ 当前结算暂停
→ 进入战斗 / 斗法事件链
→ 生成战斗结果包
→ 回写 S3 / 父事件链
→ 根据结果继续原计划、消耗剩余行动时间、强制中断、改变位置、进入重伤 / 死亡 / 转世等状态
```

## 3. 战斗资源

三条战斗相关属性条：

| 显示名 | 含义 | 承载 |
| --- | --- | --- |
| 生机 | 生命、健康、肉身完整度 | 受伤、濒死、肉身崩溃 |
| 元气 | 法力、气力、可支配能量 | 术法消耗、法宝驱动、疲惫 |
| 神念 | 灵魂、神识、心神稳定 | 神魂攻击、幻术、心魔、操控 |

## 4. 后果边界

战斗作用于本世身躯与灵魂，通常不直接改变真灵强度、执念容量、转世初始化选择或已定正式后手。严重失败可通过死亡、神魂重创、因果加重、宗门外洞府或普通藏宝线索暴露等父事件结果间接影响轮回系统。

真灵藏宝作为 MVP 正式后手，由同一真灵跨世感应和开启，受设置数量与单个容量限制；战斗不应把它当作普通战利品、遗产或可被他人直接搬空的资产。宗门外个人洞府和普通藏宝是无主遗留设施，可因战斗后果暴露线索、阵法受损或控制权变化而被其他角色提前开启。

MVP 不以玩家间直接斗法为核心验证项。

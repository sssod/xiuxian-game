# 数值设计｜投放数值设计

## 1. 设计定位

本文负责维护世界投放的数值口径：阶段预算如何被激活、预算如何分配到资源槽 / 事件 / 宗门 / 市场 / NPC 资产等投放通道、节点资源槽如何按节点等级抽样，以及投放机会如何避免被误读为直接赠送。

本文不负责具体采集、加工、交易、库存、事件或宗门行为规则；这些系统规则由对应系统设计文档维护。本文只定义投放层的单位、输入、分配模型、配置表、结算输出和调参边界。

## 2. 当前结论

1. 投放数值由阶段预算、资源槽、事件生成预算、宗门库存、市场交易、NPC 个人资产 / 事件资产和世界窗口共同控制。
2. 玩家首次突破到某大境界后，世界激活对应阶段预算；预算打开代表世界机会增加，不代表玩家直接获得修为或库存。
3. 节点资源槽从预算池抽样时，必须结合节点等级决定资源槽数量、资源品级范围、稀有变体概率、灵气浓度基础和设施规模上限。
4. 资源槽不是可直接领取库存；资源只有通过采集、加工、宗门持续行动、事件结算或资源槽附属设施产出，才实例化为具体资产。
5. 高于当前预算境界的 NPC 默认只按背景速度成长，不发生明显修为提升或突破；不高于当前预算境界的 NPC 与其他玩家可受预算打开影响。
6. 同一资源槽只能建设一类设施，且必须受设施规模上限约束，避免通过多设施叠加放大产出。
7. 阶段预算、资源成熟、市场、宗门库存和大型投放窗口按外界世界日历推进，不读取洞天内主观时间。
8. 轮回后若世界资源不足，允许增加世界资源积累等待和大型投放事件等待。

## 4. 基准、单位与输入参数

### 4.1 单位口径

| 项目 | 口径 |
| --- | --- |
| 阶段预算 | 以大境界或阶段为单位打开的世界投放预算 |
| 宏观周期 | 阶段预算结算、刷新或抽样的时间窗口，具体周期长度待定 |
| 外界世界日历 | 阶段预算、资源成熟、市场、宗门库存、NPC 宏观成长和大型窗口读取的时间 |
| 局部主观时间 | 洞天 / 时间阵法内角色经历时间，不驱动外界投放刷新 |
| 投放通道 | 预算进入资源槽、宗门库存、市场交易、机会窗口、NPC 资产或事件池的分类 |
| 资源槽抽样 | 节点资源槽从预算池抽取资源类型、品级、稀有变体概率和灵气浓度基础的过程 |
| 资产实例化 | 资源从预算或资源槽机会转为 `sect_storage`、`node_storage`、事件锁定资产或角色行囊资产 |
| 设施规模上限 | 单一资源槽可承载附属设施的规模上限，用于限制设施产出放大 |

### 4.2 输入参数

| 参数 | 来源 | 说明 |
| --- | --- | --- |
| `realm_stage_id` | 境界与阶段配置 | 当前世界已打开的预算阶段 |
| `first_breakthrough_actor_id` | 突破记录 | 首次突破并激活阶段预算的角色 |
| `stage_budget_points` | 阶段预算配置 | 某阶段每个宏观周期可分配预算点数，具体值待补 |
| `budget_cycle_id` | 世界时间 / 预算系统 | 当前宏观预算周期 |
| `outer_world_time_delta` | 时间速度数值 | 本次投放推进读取的外界时间增量 |
| `local_inner_time_delta` | 局部时间域 | 仅用于审计，不参与投放刷新 |
| `budget_channel_weight` | 投放通道权重表 | 各通道分配预算的比例或权重 |
| `node_level` | 地图节点设计 | 节点等级，用于决定资源槽数量、资源品级范围、稀有概率和灵气浓度 |
| `resource_rank_range` | 资源槽抽样表 | 节点可抽到的资源品级范围 |
| `rare_variant_probability` | 资源槽抽样表 | 稀有变体出现概率 |
| `base_aura_density` | 资源槽抽样表 | 节点资源槽的灵气浓度基础 |
| `facility_scale_cap` | 资源槽设施上限表 | 单资源槽可建设设施规模上限 |
| `npc_realm_stage` | NPC 系统 | NPC 当前境界阶段，用于判断是否受预算打开影响 |

## 5. 公式或模型

### 5.1 阶段预算激活

```text
StageBudget(realm_stage_id) activates
  when first_breakthrough(actor, realm_stage_id) is true
```

规则：

1. 某大境界阶段预算在首个玩家或关键角色突破到该阶段后激活。
2. 阶段预算激活后，世界可以在后续宏观周期中将预算分配到各投放通道。
3. 阶段预算不直接写入玩家库存，不直接增加玩家修为。

### 5.2 预算通道分配

```text
channel_budget_points =
  stage_budget_points
  * normalized(budget_channel_weight)
```

预算通道包括：

1. 节点资源槽。
2. 宗门库存。
3. 市场交易。
4. 机会窗口。
5. NPC 个人资产 / 事件资产。
6. 事件投放。

规则：

1. 通道权重的具体数值待补；当前只固定分配结构。
2. 通道预算代表可生成机会或可抽样额度，不代表最终进入玩家资产。
3. 同一资源不应在多个通道中重复确认归属；实例化后必须进入唯一资产位置或锁定记录。

### 5.3 节点资源槽抽样

```text
node_resource_slot_profile =
  sample_resource_slot(
    node_level,
    channel_budget_points,
    resource_rank_range,
    rare_variant_probability,
    base_aura_density,
    facility_scale_cap
  )
```

节点等级至少影响：

1. 资源槽数量。
2. 资源品级范围。
3. 稀有变体概率。
4. 灵气浓度基础。
5. 设施规模上限。

资源槽转为资产的入口包括：

1. 采集。
2. 加工。
3. 宗门持续行动。
4. 事件结算。
5. 资源槽附属设施产出。

### 5.4 NPC 与其他玩家成长门槛

```text
if npc_realm_stage > active_budget_realm_stage:
  npc_growth_mode = background_only
else:
  npc_growth_mode = budget_affected
```

规则：

1. 高于当前预算境界的 NPC 默认只按背景速度成长，不发生明显修为提升或突破。
2. 不高于当前预算境界的 NPC 与其他玩家可受预算打开影响。
3. 该规则用于防止世界投放在玩家阶段之外制造不可控的高阶资源压力。

### 5.5 投放不等于赠送

预算打开提供机会，不自动赠送修为。玩家仍需通过探索、宗门、市场、节点、事件、NPC 关系和风险选择创造高价值闭关条件。

### 5.6 外界日历与轮回等待

投放系统只读取外界世界日历：

```text
stage_budget_progress += outer_world_time_delta
market_refresh += outer_world_time_delta
sect_inventory_maturation += outer_world_time_delta
node_resource_regeneration += outer_world_time_delta
major_window_schedule += outer_world_time_delta
```

洞天内主观数百年不生成数百年外界投放。角色在局部时间域中修炼时，资源成熟、宗门库存、市场和 NPC 宏观成长只按外界经过时间推进。

轮回重修不保证总通关时间缩短。若关键资源、洞天窗口、天象或大型投放事件尚未成熟，新一世可以需要额外等待外界资源积累；该等待用于提高成功率、路线确定性或结局质量，而不是无来源缩短总时长。

## 7. 结算输出

### 7.1 普通系统输出

1. 阶段预算激活记录：阶段、触发角色、触发时间和当前预算状态。
2. 宏观周期预算分配结果：各投放通道获得的预算额度。
3. 节点资源槽抽样结果：槽位数量、资源品级范围、稀有变体、灵气浓度基础和设施规模上限。
4. 资产实例化结果：资源进入 `sect_storage`、`node_storage`、事件锁定资产或角色行囊资产的记录。
5. NPC 成长门槛结果：背景成长或预算影响成长的判定。

### 7.2 Debug / 验算输出

1. 各通道权重、归一化结果和预算消耗。
2. 每次资源槽抽样使用的节点等级、预算额度和随机结果。
3. 同一资源从预算机会到最终资产位置的链路。
4. 资源充足倍率、设施加成和事件奖励是否重复作用的检查日志。
5. 超出通道上限、设施规模上限或阶段预算的钳制记录。

## 8. 调参验收口径

1. 阶段预算打开只能增加世界机会，不能绕过探索、交易、宗门、事件或采集流程直接给玩家资产。
2. 节点资源槽的资源品级、稀有概率、灵气浓度和设施规模上限必须受节点等级约束。
3. 同一资源槽只能建设一类设施，设施产出不得通过多设施叠加突破上限。
4. 资产实例化后必须有唯一位置或锁定记录，不能同时被宗门、节点、事件和角色库存重复持有。
5. 高于当前预算境界的 NPC 不应因预算打开而发生明显修为提升或突破。
6. 玩家资源充足倍率、设施增益、事件奖励和市场机会不得在同一收益上重复套利。
7. 预算通道权重、节点抽样和资源包模板必须能被 `08_数值验算.md` 验证是否造成阶段资源失衡。
8. 洞天内主观时间不得刷新阶段预算、市场、宗门库存、节点资源或大型投放窗口。
9. 轮回导致的路线稳定和成功率提升，不得被表达为必然缩短完整通关总时长。

## 9. MVP 范围

MVP 应实现：

1. 阶段预算激活记录。
2. 投放通道结构和预算分配配置。
3. 节点等级到资源槽数量、资源品级范围、稀有变体概率、灵气浓度和设施规模上限的抽样表。
4. 资源槽机会到资产实例化位置的记录口径。
5. NPC 是否受当前预算阶段影响的成长门槛。
6. 外界日历驱动的预算推进记录，并排除局部主观时间驱动投放刷新。

MVP 不实现：

1. 完整境界资源包模板的最终数值。
2. 所有宏观周期预算点数和通道权重的定稿曲线。
3. 高阶长期世界经济模拟。
4. 自动化市场价格平衡器。
5. 玩家资源充足倍率的完整反套利公式。
